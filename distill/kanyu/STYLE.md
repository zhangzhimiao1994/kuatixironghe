## 二、R 节硬规矩

1. **每条必须是原书原话，逐字**。异体字、异文照抄（如「𦵏」「攏／壟」「氣／气」在同一本里混用，照原样），不改写成今字，不动标点。
2. **不许把注疏当经文**：葬書的经文是正文，〈…〉里的是《錦囊》注疏——两者都要标清是「经文」还是「注」。
3. **不许把后世术家的说法冒充原书**：書里没有的做法，写「（补充）」，并说明依据。
4. **一条 skill 的 R 节至少 3 条引文**；少于 3 条说明这个主题在原书里撑不起来，回去并到邻近 skill。
5. **回书核**：写完用归一化（只留字形，忽略空白与标点差异）比对源文件；核不过的删掉或改掉，不许强留。

## 三、判读口径

1. **象征层只命名、不承诺**：堪舆讲的是「形势之象」，擇日讲的是「神煞之例」——一律写「倾向 / 按书里这一类读」，不写「一定 / 必然 / 命中 / 保证发财发贵」。原书里的断语（「葬王者」「千乘之葬」「家亡国灭」）属于**書里的评价语**，引用时要标明是书里的说法，不当作事实承诺。
2. **不接的活**：不接阴宅实地下葬的作业指导（那是要人到现场、担后果的事）；不给医疗、法律、投资结论；不替用户拍板。
3. **数据不足照实说**：没有具体形势描述（山形、水口、朝向、周边）或没有具体日期，就说缺什么、要到什么程度才能判，**不许用占位信息硬判**。
4. **術語照写、简称不给**：维度名、权重、危机层级、STEP 编号照写；自造的方法零件名（「两栏」「三问」这类）不进正文。
5. **神煞要么给全，要么不报**：擇日报神煞时必须同时给出起例来源（哪一卷、哪一例）与宜忌依据（卷十·宜忌）；只报一个神煞名而不说出处 = 不合格。
