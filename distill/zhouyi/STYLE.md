# 风格卡 · 周易（zhouyi）

> 这一维从**三本原典**蒸馏，共用下面这套规矩。写完每条 skill 都按这张卡自检。
> 本维度**已有 13 个 skill**（`zhouyi` 入口 ＋ 12 个处境路由成员，slug 不带 `zhouyi-` 前缀）；本次并入新增 **9 个**（覆盖十翼与两家注疏），全部沿用本卡。

## 一、来源与账目

| 源文件（包内相对路径） | 书 | 在本维里管什么 |
|---|---|---|
| `sources/zhouyi-jing.txt` | 周易（經文，維基文庫本） | **白文经**：六十四卦卦辞、爻辞、彖、象、文言、繫辭、說卦、序卦、雜卦；另含速查表与次序表 |
| `sources/zhouyi-benyi.txt` | 周易本義（宋朱熹，四庫全書本） | **本義注**：朱熹对经与传的注；含卦变、筮法、图说 |

**引文只从 `sources/*.txt` 里抄**，不凭记忆、不引二手网页。每条 R 给出处：`（《周易》卦名·爻题）`、`（《周易本義》卦名）`、`（《周易正義》卦名·疏）`。
**层分栏**：一句话到底是**經文**、是**王弼注**、是**朱熹本義**、还是**孔穎達疏**，必须标清——四家对同一句的说法不是一回事。
**两家注疏不调停**：朱子与孔疏（含所据王弼注）取法常有出入，**两说都展示、各标出处**，不选边、不合成一句。

## 二、R 节硬规矩

1. **每条必须是原书原话，逐字**。异体字照抄（「无／無」「系／繫」「说／說」在各本里混用，照原样），不改写成今字，不动标点。
2. **一条 skill 的 R 节至少 3 条引文**；少于 3 条说明这个主题在原书里撑不起来，回去并到邻近 skill。
3. **卦必须带卦名与卦次**（如「屯（卦三）」）；爻辞带爻题（如「屯·六三」）。只写「某一卦」＝不合格。
4. **回书核**：写完用归一化（只留字形，忽略空白与标点差异）比对三本源文件；核不过的删掉或改掉，不许强留。

## 三、判读口径

1. **象征层只命名处境、不承诺**：一律写「倾向／按书里这一卦这一类读」，不写「一定／必然／命中／保证」。书里的吉凶词（「元亨」「凶」「无咎」）是**经文的用语**，引用时标明是书里的说法，不当作对某人的事实判决。
2. **不接的活**：**不起卦、不占卜、不抽签、不排盘、不算命、批流年、不断终身**；不给医疗、法律、投资结论；不替用户拍板。用户要「算一卦」时照实说明本维只做**读法与处境归类**，不进行占筮。
3. **两种问法并存**（判据：**输入里有没有他要问的那件事**）：
   - 问「**这一卦／这一句书里怎么讲、出自哪一篇**」→ 走**文本解读**（认篇归义、摆书里的条件）；
   - 问「**我这件具体的事怎么看**」→ 走**落到处境上的读法**：把事归到一类处境，说清凭哪一条（卦辞／爻辞／传文／注疏）这么读，给「按书里这一类读，偏 X」＋**出处**。
4. **不越界**：读法层面可以做的是「这类处境下书里给的动作边界」「宜进还是宜守」「这一步该不该现在迈」；不做的是**替用户决定**、**预测结果**、**断吉凶成事**。
5. **数据不足照实说**：他给的信息不足以归到哪一卦哪一爻时，说清还缺什么，**不许硬套一个卦**。
6. **术语照写、简称不给**：维度名、权重、危机层级、STEP 编号照写；自造的方法零件名不进正文。
7. **报卦必须给全三样**：**卦名 ＋ 卦次 ＋ 原文**，并写一条「为什么是这一卦」的细节对应（拿不准就不报卦）。

## 五、不许出现的东西

- 任何 agent / 工具 / 模型 / 运行时的专有名词；路径一律写包内相对路径。
- 把周易写成「迷信」的自我否定腔，也写成「灵验」「准得可怕」的兜售腔。
- 用现代术语给经文背书；把卦辞当成对某人的事实判决。
- 抄别族 skill 的正文；本族内部也不互相复制段落。
- **内部归类名**（成员 slug、目录名、「属于 XX 类处境」这类标签）——只留内部，不进给用户的回答。
