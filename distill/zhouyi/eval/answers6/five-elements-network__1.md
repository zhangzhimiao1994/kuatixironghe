# 换季鼻炎、脾气变坏：一条会自己转回来的循环

先说一句要紧的：下面做的是系统层面的关系分析，不是看病，也不替代就医；鼻炎的诊断、用药请交给医生。这里把"五脏"当喻体，用来看几个方面怎么互相带动。

## 一、先把要素归位

你描述里能拎出五个反复一起出现的方面：

| 方面 | 归类 | 归类理由 |
|---|---|---|
| 鼻窍、呼吸道（症状所在） | 金 | 收敛、宣降、与外界交换的通道，出问题最先表态 |
| 情绪起伏、脾气变坏 | 木 | 生长、疏泄，最容易因郁而化火的那股力量 |
| 烦躁、上火感、睡不好 | 火 | 驱动、活跃，郁久了就往这里堆 |
| 胃口、运化、抵抗力底子 | 土 | 承载与转化，是滋养其他部分的中间层 |
| 精力根基、换季的消耗 | 水 | 蕴藏与滋养，被反复抽用后最先露底 |

**〔先确认〕** 这五项里有没有不搭的？如果你觉得"胃口/抵抗力"其实没受影响，可以拿别的方面替换，我按你确认的版本再往下画。

## 二、画出它们怎么互相带动

- 相生链：水→木→火→土→金→水（根基养疏泄、疏泄济活跃、活跃温运化、运化养通道、通道复归于根基）
- 相克链：金克木、木克土、土克水、水克火、火克金

关键在两条：
1. **换季一到，金（鼻窍）先受**：外界一变，最先表态的就是这道通道。
2. **木→火→克金**：情绪一郁、一烦，化出"火"，沿"火克金"顶到鼻窍。

## 三、沿链条推一遍，就看清"为什么每年都这样"

换季 → 金受扰、鼻窍不通 → 因不通而烦躁、脾气变坏，木升火 → 火克金，鼻症加重 → 人更烦 → 火更旺……形成一个**"木火刑金"的自锁环**。

这正是"每年都这样""只治局部不管用、一停就复发"的典型信号：它不是一条直线，是一个能自己转回来的圈。如果底子（土、水）本就薄，运化托不住通道、根基涵不住情绪，这个圈会比一般人转得更快。

## 四、落一个能动手的干预点

**理想方案**：疏木 —— 先把情绪的出口打开（规律作息、把"一到换季就烦"这件事本身写下来看清它），从上游掐断"木升火"这一段。

**现实可行的次优方案**：补土 —— 先把胃口、睡眠、日常节奏稳下来，让运化这条链托住鼻窍，同时减少熬夜对根基的抽取。

两条一起做，等于在上游和中游各设一道闸，比只对着鼻子使劲更接近"断链"。
