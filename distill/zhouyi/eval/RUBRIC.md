# dim8 盲评尺子（本轮）

> 口径沿包内既有做法：①**新输入**（不许用 skill 自带的示例／test-prompts）②**匿名**（评委看不到 skill 名、看不到哪个是新维度）③**3 位独立评委取中位**④**单份独立看**（不因「同批多份结构相似」扣分）。

> **打分前先读 `ANCHORS.md`**（三份已知分档的真实样例，用来对齐刻度）——实测同一批答卷换评委可摆动 0.9 分，先对齐能显著提高跨批可比性。

## 打分：每份回答 0–10 分，一位小数

| 分档 | 长什么样 |
|---|---|
| 9.0–10 | **依据看得见**（引原书原句并带出处、**或**说明判据来自哪条框架与用户哪句原话——两种都算）；判断钉在这次提问的**具体细节**上；行动具体到能打勾；边界守得住（不承诺结果、不替代专业判断、缺信息就明说缺什么）；推演看得见 |
| 7.5–8.9 | 以上基本做到，个别处泛化、或依据偏薄、或行动还可以更具体的 |
| 6.0–7.4 | 有明显短板：套话／模板化；只给结论不给依据；行动空泛；越界承诺 |
| < 6 | 缺原文锚点或**编造**原书没有的说法；答非所问；替用户拍板；结构崩坏 |

## 扣分项（单项最多 −1，合计最多 −3）

- **模板化**：把同批另一段提问换个名字套进来也成立 → −1
- **只给结论、不写依据/过程**（该 skill 要求写过程时）→ −1
- **行动不可执行**（要大量准备、没有完成标准）→ −1
- **越界**：承诺结果／替代医疗·法律·投资判断／替用户做决定 → −1；严重者直接 ≤ 6
- **术语外露或自造简称**（「两栏」「三问」「收工五步」这类方法零件名）→ −0.5
- **引了与本题不相干的原文凑锚点** → −1（按「依据偏薄／答非所问」，**不给锚点分**）
- **编造原书没有的说法** → 直接 ≤ 5

## 加分项（不引不扣，引对了才加）

- **引到与本句判断对得上的原书原句、并给出处** → **+0.3**
- **给出「为什么是这一条」的对应关系**（说明这句原文管的是本题的哪一点）→ **再 +0.2**

## 不许扣分的项（尺子已知盲区，别把内容改坏）

- **安全语不算软化措辞**：「建议就医」「不给投资建议」「有需要找专业人士」这类是安全出口，不扣分。
- **版式统一不算模板化**：同一批回答格式一致是规范；只有**内容**能不能套到别人身上才算模板化。
- **规范术语照写不扣分**：维度名、权重（X/5）、危机层级（L0–L5）、STEP 编号出现在回答里是规范，不是术语外露。
- **回答里标注「这是书里的说法」不算推诿**：象征层的规矩就是只给倾向、不承诺。

## 每题输出格式（评委用）

```
编号: <如 A07>
分数: <0–10，一位小数>
要点: <一句话，说清为什么给这个分>
```
