# 审计：引文可信度（回答真实、不杜撰）

**问题**（维护者）：回答的质量一定要高、一定要真实、不能杜撰——这也是先挑最权威的原典而不是民间文本的原因。

## 办法

把「能核的面」和「核不了的面」分开，逐面查：

| 面 | 怎么核 | 结果 |
|---|---|---|
| **R 节引文**（每个 skill 的「原文锚点」节） | 逐字比回 `sources/` 原书（繁简归一，opencc） | 周易 **1097/1097**、八字 **744/744**、三族合计 **2036 条 0 未命中** |
| **正文里的「书里说 X」** | 核它带的 `（R编号）` 是否指得到 R 节真有的锚点（**指空＝虚假依据**） | 158 个 skill、**5036 次指回，0 次指空** |
| **正文里的「」引号** | 抽 8 字以上引号内容比回原书 | 周易族 179 条"未命中"**实为示例句与自造标签**（如「你的判断属于 XX 类处境」）→ **结论：正文的「」不承担原书引文职责，引文一律走 R 节** |
| **防杜撰守卫** | 扫「书里没有的、不要加」「不讲后世流派计分」这类硬话 | **184 处**，覆盖后世术家说法、打分体系、自动取用法 |
| **无源书的族** | 依恋／荣格／EFT／托勒密等，原书不在 `sources/`，**无法回书核** | 靠 R 节标出处（篇章／CW 坐标）＝**软处**；要变硬只有把原书收进 `sources/`（不由 agent 自找） |

## 扫出的真缺陷（都小）

1. **`zhouyi-tuan-zhuan` 3 条彖传引文「只取首尾句、省略中间没标」**（豫／隨／睽）——读者会以为原文如此 → **已补「……」**。
2. **`emotion-organ-proxy`、`negative-feedback` 的 R 节只有 2 条**，违反自家蒸馏风格卡的「**R 节至少 3 条**」→ **待办**：补第 3 条需要《黄帝内经》文本进 `sources/`（不自行寻找）。

## 留下的加固

新增 `tools/verify_citations.py`（一次核三件事：① 正文 R 编号指回 ② 有源书族 R 节引文回书核 ③ R 节完整性），写进 `docs/扩展手册.md` 第 4 步——**以后每轮蒸馏自动跑，三项全 0 才算过**。

## 误报排除记录（免得下次再查一遍）

- `kanyu-hub` 与 `repair-renewal-cycle` 被机器判"引文拼接"：实为**两条各自独立的引文**（各在自己的「」里）与**源书此处作「丧得」**（通行本作「无丧无得」），非杜撰。
- `line-position-timing` R 节里的「不独占首领位置」是**「—（注）」白话注行**，包内允许，核验器已按此跳过。
- 周易族"179 条未命中"全为示例句、自造标签，**不是引文**。
