# 排盘与星历（象征层前置）

> 象征层（托勒密星盘）**要报具体盘面配置，前提是手里有一张真盘**。这份文档规定：什么时候排、怎么装、装不上怎么降级——两条路都不许编。

## 一、顺序

1. **有出生信息 + 有 Python + 能联网** → 按国内镜像装纯 Python 星历库，用包内脚本排盘（见下）。
2. **装不上 / 没有 Python / 没网** → 只走「读法层面的倾向」：用**一句白话**把倾向指回书上那一类（只给类别、不堆术语）+ **≥2 条**他能拿自己经历去对的对照 + 一个能打勾的动作；**不得报任何具体盘面配置**（不写「你的中天在水性」这类具体断言）。
3. **只有时段没有准点**（如「辰时」= 7–9 点）→ 可以排，但**必须把不确定度写进判读**（见第四节）。
4. **降级时要交代**：只用一句用户听得懂的话（「手里没有可算的盘」），不写内部话、不报书名卷名。

## 二、安装（国内镜像）

纯 Python 实现（Meeus 算法），**不需要星历数据文件、不需要编译**：

```
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pymeeus
```

备份镜像（清华不通时换）：

```
python -m pip install -i https://mirrors.aliyun.com/pypi/simple/ pymeeus
```

- 官方源（pypi.org）在本环境实测下载不动，**优先走上面的国内镜像**。
- 若环境要装 `pyswisseph` / `numpy` 这类带编译的包：本机有 gcc/g++/make，`numpy` 从清华源可装；**`pyswisseph` 实测在 Python 3.14 下 build wheel 失败（`failed-wheel-build-for-install`）——别试，直接用 pymeeus**。
- 装完先自检：

```
python -c "from pymeeus.Sun import Sun; from pymeeus.Epoch import Epoch; print('ok')"
```

## 三、排盘

```
python tools/paipan.py --date 1994-11-10 --time 07:30 --tz 8 \
    --lat 28.4546 --lon 117.9686 --place 江西上饶
```

输出：上升、中天、七政（日/月/水/金/火/木/土）的黄经与星座、元素、距上升的整宫位、东出/西没，以及主要相位表、与日月成相位的项。

**拿到这张表之后**，才可以引用具体配置（某星在某座、在第几宫、与谁成相或冲）——没有这张表就不许报配置。

## 四、出生时间的准确度（必须标注）

| 输入情况 | 能做什么 | 必须标注 |
|---|---|---|
| 准到分钟 | 上升/中天可用 | 无 |
| **只到时段**（辰时 07–09 这类两小时） | 照时段中点排；**行星所在星座通常可用**（月亮两小时内约走 1°，接近交界的不算） | 上升/中天**在时段内会大幅移动**——实算例：上饶 1994-11-10，07:00 上升天蝎 23°40′、07:30 射手 00°04′、09:00 射手 19°32′，**两小时内跨了一个星座**；据此的判断一律标「未校正」 |
| 只到日 | 只能算行星黄经（星座级） | 上升、中天、宫位**一律不给** |

## 五、口径

- 只用托勒密《Tetrabiblos》的读法，**不掺**其它占星体系，也**不与中式命理名词并排**；术语用中文（宫位、主星、三重性、擢升、界、相、角宫、续宫、晨出、昏没）。
- 用户给的是中式出生信息（农历、时辰）时，**只把它当出生时刻的数据来源**，转换后在回答里仍只说一种话。
- **不排健康 / 寿命的断言**（🏥），不替用户做婚姻、职业、生育决定。
- 盘中得到的只是**倾向**：措辞用「偏向 / 更像 / 倾向于」，不用「一定 / 必然 / 命中」。
