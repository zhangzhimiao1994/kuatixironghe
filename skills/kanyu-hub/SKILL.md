# 堪舆择日总览：一处形势、一个日子怎么读

**来源**：葬書（郭璞）、撼龍經/疑龍經（楊筠松）、欽定協紀辨方書（清乾隆官修） ｜ 证据等级：firsthand（原书原话）/ reliable-secondary（可靠转述）/ inference（推断，须标注）

## 触发条件

⛔ **硬闸门（先看这条）：本维度只在用户「显式」要堪舆/看地、或显式要择日时才进入。**
判据是**显式词**，不是泛化词：
- 相地一侧的显式词：堪舆、风水、看地、相地、看宅、看形势、来龙、龙穴砂水、点穴、安葬、阴宅。
- 择日一侧的显式词：择日、挑日子、看日子、吉日、宜忌、神煞、黄道黑道、太岁、冲煞、建除、立成、用事。
- **泛化词一律不算、权重写 0**：山、水、河流、朝向、地势、地形、环境、方位、宅子、房子——
  它们单独出现（「我家朝南」「最近搬到山边住」「办公室采光不好」）**不是**要看地。
- 术语问句算显式（「风水这个词到底指什么」「龙穴砂水是讲什么」），可以进入。
- 这条闸门**优先于**下面的「应该触发」清单：清单里的词只有在用户已显式表达要看地/要择日时才是信号。
- **闸门没过 → 不激活、也不显示**：本维度在激活矩阵与正文里**整行都不出现**，连「本轮不激活」都不写。用户没点它，列出来就是多嘴。（对比：过了闸门、但信号只有 0 的维度，仍要列一行注「本轮不激活」。）

**应该触发**（用户会怎么说话，且已显式表达要看）：
- 问一处地、一座宅的形势：来龙去脉、山形水势、朝向、水口、周边环境，好不好、怎么读。
- 直接用堪舆的话问：龙穴砂水、点穴、乘生气、藏风得水、支垄之辨、倒杖、砂法。
- 问某个具体日子宜不宜做某件事：嫁娶、出行、动土、安葬、开市、签约、搬家、上梁。
- 用择日的术语问：吉日、宜忌、神煞、黄道黑道、太岁、冲煞、建除、立成、用事。
- 手里已有一处房/宅/地的现场情况，或一个具体日期，想按书里的口径读一读趋势。

**不应触发**（看起来像但其实不是）：
- **没有显式要堪舆/看地，也没有显式要择日**——只是话里出现了山、水、朝向、地势、环境、方位、宅子这类泛化词（「我家朝南」「搬到山边住」「办公室采光差」）→ 一律不激活本维度。
- 纯心理困扰（反复的情绪、亲密关系、空虚、被批评后的反应）→ 本包观察层的心理类维度更合适。
- 要起卦、算命、看八字、批流年大运、断终身 → 不属本维度：本维度在择日一途只论「日子与要做的事」，不取生辰、不算命。
- 现代医学、法律、投资问题 → 不作结论，退回专业渠道。
- 只想核对四本书的版本、作者、成书年代一类文献问题 → 那是文献考据，不是本入口的形势/日子判读。

## I：核心解释

这个维度只办两件事，各有一支来源，入口负责先分清是哪一件、再交给对应的子 skill。

1. **相地——读一处地、一座宅的形势。** 来源是葬書三篇与楊筠松诸篇。它给的是「形势之象」的读法：先「葬者乘生氣也」立总纲（R1），再讲「藏風得水」的取用（R2），再分「勢」与「形」两层去看（R3），一路落到支垄、倒杖、砂法。撼龍經给出天下大势的分法——「須彌山是天地骨」（R4），由此分干龙枝龙、辨九星；疑龍經三篇与十问则专挑「疑」处：明明像穴，究竟是真龙落穴还是虚穴（见 R5 的惜水避风之喻）。
2. **择日——读一个日子宜不宜做某件事。** 来源是欽定協紀辨方書三十六卷。它先立「神煞有起例」的前提：選擇神煞本有建除、堪輿、叢辰诸家，但「義不盡傳起例尤多襲誤」（R6），所以此书要重新辑例、正误。全流程是：本原（河洛八卦、二十四方位、诸家五行）→ 義例（各类神煞的起例）→ 立成（把起例汇成表）→ 宜忌（神煞轻重相胜、趋避取舍，见 R7「有其情即有其力力有相勝」）→ 用事（按要做的事列宜忌）→ 公規（祀典历法）→ 利用（變通制煞）→ 辨訛（辨世俗术家之讹）。R8 点出择日的体用：龙山的固定方向是「体」，年月日时的无定之数是「用」，两者相合才算利用。
3. **本入口只做「分诊」与「口径」。** 它判的是：这件事属于相地还是择日、该落到哪一个子 skill、报神煞时要带哪一卷的起例、缺什么信息该先补。真正的形势判读与日子判读，由被选中的 kanyu-* 子 skill 按各自的原文给出。象征层只给倾向与读法，不替用户下断语。
4. **两件事共用一个前提：先有「具体的东西」。** 相地要先有一处具体的形势（山形、水口、朝向、周边），择日要先有一个具体的日期与一件具体要做的事。没有这两样，先说缺什么，不拿空话顶上。

**本维度的口径边界（先记住，再谈判读）**：

- **只给倾向，不给命中断语。** 堪舆讲的是「形势之象」，择日讲的是「神煞之例」；一律写「按书里这一类读，倾向是……」，不写「一定 / 必然 / 命中 / 保证发财发贵」。书里的断语（「葬王者」「千乘之葬」「家亡国灭」）属于书里的评价语，引用时标明是书里的说法，不当作事实承诺。
- **报神煞必须带卷次与起例依据。** 说某个日子犯某煞，要同时给出它起于哪一卷、依哪一例（如卷三·義例一、卷九·立成），并回到卷十·宜忌的轻重相胜去取舍；只报一个神煞名而不说出处，等于没说。
- **缺具体形势/具体日期就照实说缺什么。** 相地没有山形、水口、朝向、周边，择日没有具体日期与事由，就说明要到什么程度才好判，绝不用占位信息硬判。
- **不接的活。** 不接阴宅实地下葬的作业指导（那是要人到现场、担后果的事）；不给医疗、法律、投资结论；不替用户拍板。

## A1：来源应用

书上给的结构，直接决定了子 skill 的边界（不是我的发挥）：

- **葬書（`sources/zangshu.txt`）**：内篇一立「乘生氣」（R1）；内篇二讲「藏風得水」与支垄取用不同（R2）；内篇三讲「勢來形止」两层的尺度与「全氣之地當葬其止」（R3）；外篇讲支葬、垄葬、择其特、乘金相水穴土印木；雜篇讲形势品类吉凶。相地一支的头 9 个 skill 就照这个骨架拆，对应 `kanyu-zangshu-*`。
- **撼龍經／疑龍經／葬法倒杖（`sources/hanlongjing.txt`）**：撼龍經从「須彌山是天地骨」（R4）起分大势，再辨贪巨禄文廉武破辅弼九星；疑龍經上篇「幹上尋龍」、中篇「枝中幹、州縣都會」、下篇「真龍落穴與虛穴」；后附疑龍十問、衛龍篇、變星篇；葬法倒杖讲认太极、分两仪与倒杖十二法、二十四砂葬法。相地一支的后 10 个 skill 照此拆，对应 `kanyu-hanlong-*`、`kanyu-yilong-*`、`kanyu-wei-long-pian`、`kanyu-bian-xing-pian`、`kanyu-dao-zhang-shi-er-fa`、`kanyu-er-shi-si-sha-zang-fa`。
- **疑龍經（`sources/yilongjing.txt`）**：与四庫本的疑龍經部分互校；R5「明堂惜水如惜血，穴裏避風如避賊」在这里有标点，讀來更顺；两者冲突时以四庫本（`sources/hanlongjing.txt`）为准。它不单独再拆 skill，只作 `kanyu-yilong-*` 三篇的校勘依据。
- **欽定協紀辨方書（`sources/xieji.txt`）**：卷一卷二本原、卷三至卷八義例（年神、建除、月神、日神、黄道黑道与诸贵人、岁禄禄马）、卷九立成、卷十宜忌（R7）、卷十一用事、卷十二至卷十三公規、卷十四至卷三十二年表月表日表、卷三十三利用·選擇要論與楊筠松造命歌（R8）、卷三十四利用·制煞要法、卷三十五附录、卷三十六辨訛。择日一支的 15 个 skill 照三十六卷的结构拆，对应 `kanyu-xieji-*`。

一句话记法：**相地分「原理（葬書）」与「操作（楊筠松）」两支，择日分「起例—查表—宜忌—用事—变通—辨訛」一条链。** 入口的职责就是认出用户问的是其中哪一格。

## A2：典型触发场景

1. 「老家要翻修，村里人说这块宅基地朝向不好，到底怎么看好坏？」→ 相地。
2. 「这块地背后有山、前面有水，是不是就是书上说的好穴？」→ 相地（藏风得水/形势）。
3. 「下个月想办婚礼，哪天比较合？避开什么？」→ 择日（用事·嫁娶）。
4. 「装修想挑个动土的日子，怎么挑？」→ 择日（用事·動土）。
5. 「听人说今年犯太岁、某天冲我生肖，这说法书上有根据吗？」→ 择日（神煞起例/辨訛）。
6. 「这是块地的简图和水口情况，帮我看看龙从哪来、穴该往哪落。」→ 相地（干龙枝龙/疑龙）。

**步骤**

1. **分诊**　输入：用户原话 → 输出：判断这件事是「相地」还是「择日」，以及是否两者都沾。
   🔴 **CHECKPOINT**：先用用户自己的话把他问的事复述一遍，请其校正（「你问的是某块地好不好的事，对吗」），再往下走。
2. **查缺**　输入：分诊结果 → 输出：还差哪样具体信息。
   - 相地缺少：这处地势的实况（山形来去、水从哪里来从哪里走、朝向、四周遮护）。
   - 择日缺少：具体日期（年月日，能的话到干支）与具体要做的那件事。
   🔴 **CHECKPOINT**：缺的信息一次说清「要到什么程度才好读」，最多补问 2 个问题；能用已有信息先给一次倾向就先给，不整篇只提问。
3. **分派**　输入：分好诊、补齐信息的问题 → 输出：落到上表对应的 kanyu-* 子 skill，由它按原文给出这一处形势或这一个日子的读法。本入口只分派、不替它判读；若问题同时沾相地与择日，按「先形势、后日子」的顺序各落一个子 skill。
4. **收口**　输入：子 skill 的读法 → 输出：一次完整回复——先用这个维度的口径把倾向讲清楚（哪一支、照书里哪一卷/哪一篇、得到什么倾向），再落一个用户今天/这周能去核实或能打勾的动作（去现场补哪一样、把日期和事写清楚再来）。结尾先给判断、再请校正；不在正文时报任何内部路径名、文件名与自造简称，最多再问 2 个问题。

**形势取数（相地前置，可选）**：手里只有地名或经纬度、没有现场形势描述时，可用包内 `tools/xingshi.py` 取数（高程/高差/坡度坡向/八向遮护/水系方位），拿到一份可核对的形势描述再判读；映射关系与局限见 `docs/形势取数与映射表.md`。**先查再跑（硬规定）**：取数前先跑 `python tools/install_deps.py`（含数据源连通体检）或 `python tools/xingshi.py --check`；有不可用项就停下、报清楚，**不许跑到一半才发现取不到**。取不到就照实写——「取到 0 条」≠「现场没有」。**三种入口**：① `--url` 直接吃地图 App 的分享链接（高德/百度），自动解出坐标与地名、并按高德 GCJ-02／百度 BD-09 转成 WGS-84（不转会系统性偏 500–1200 m）；② `--place` 给地名（会列候选让你核对）；③ `--lat/--lon` 直给，用 `--crs` 说明是哪家地图读的。另有一级 **`--area KM` 区域大势粗读**：出区域整体倾斜方向与高带／低带方位（标注「粗读」，分辨率更粗）。水系有两层：OSM（带河名，乡野常缺漏）＋ **离线河网**（无河名，但按河流级别排干枝，补乡野缺漏）。**取数不等于判读**——地理量翻成书里术语的那几步是「（补充）」，回答里要保留这个标注；仍不点穴、不给葬法、不接阴宅实地作业指导。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把倾向说成断语 | 「这宅一定发财」「这天必出事」这类命中式承诺 | 改回「按书里这一类读，倾向是……」；书里的断语（如「葬王者」）只当书里的评价语引用 |
| 报神煞不带出处 | 只说「这天犯某某煞」，不说哪一卷、哪一例 | 补上卷次与起例依据（如卷三·義例一、卷九·立成），并说明卷十·宜忌的轻重取舍；只报名字＝不合格 |
| 缺信息硬判 | 没有具体形势或具体日期，却照样给结论 | 照实说缺什么、要到什么程度才能判，绝不用占位信息硬判 |
| 越界接活 | 教人怎么实地安葬、给医疗法律投资意见、替人拍板 | 停手：只做形势与日子的读法；危险或专业问题退回提醒与建议转专业渠道 |
| 书名/引文张冠李戴 | 把注疏当经文、把后世术家说法当原书 | 引文只从 `sources/*.txt` 抄；注明是经文还是注；书里没有的做法标「（补充）」并说明依据 |

**边界规则**：
1. 象征层只给倾向、只命名，不给命中断语；不承诺发财发贵、不预测必然结果。
2. 报神煞必须同时给卷次与起例依据，并回到卷十·宜忌的轻重相胜来取舍。
3. 缺具体形势或具体日期，就说缺什么、要到什么程度；不用占位信息硬判。
4. 不接阴宅实地作业指导，不给医疗、法律、投资结论，不替用户拍板。
5. 术语照写，不给自造简称；维度名、卷次、篇名按原样写。

**自查清单**：
- [ ] 先分了诊（相地/择日），再谈别的？
- [ ] 报神煞时带了卷次与起例依据？
- [ ] 结论是「倾向」而不是「一定/必然」？
- [ ] 缺信息时说了缺什么，而没有硬判？
- [ ] 引文是从 `sources/*.txt` 抄的，且注明了经文/注、原书/补充？
- [ ] 没有越界接阴宅实地作业、医疗法律投资，也没替用户拍板？

**安全兜底**：涉及就医 / 用药 / 危机 / 重大财产时，只做提醒与陪伴，不作诊断或担保，建议转专业渠道。

## 练习手册

1. **分诊默写**：拿 10 句真实提问，只判「相地 / 择日 / 都不是」，再说该落哪一支，最后对照 E 节路由表核。
2. **出处补齐**：随便挑一个神煞名，回 `sources/xieji.txt` 找出它起于哪一卷，并抄下卷十·宜忌里对应的取舍句。
3. **一句一核**：从葬書里选 3 句原文，标明是「经文」还是「注」，再解释它在相地流程里管哪一步。
4. **缺信息改写**：拿一句没有具体信息的问话（如「我这房子风水好吗」），写一段「还缺什么 + 先能给的倾向」，练不硬判。

## 反例黑名单

1. 把「乘生氣」「藏風得水」讲成灵验保证或现代科学名词的翻版。
2. 只报一个神煞名，不给卷次与起例依据。
3. 没有具体形势/日期就下结论，或用占位信息凑判断。
4. 用堪舆择日去接阴宅实地下葬、医疗、法律、投资，或替用户拍板。
5. 把后世术家做法冒充原书，或把《錦囊》注疏当葬書经文引用。
6. 给用户报内部路径名、文件名或自造的零件名当分析结果。

## 灰色地带

- **相地与择日都沾**：如「想找块地、顺便挑下葬的日子」。先按「先形势、后日子」的顺序分两步，各落一个子 skill，并说明哪一步缺什么信息；不把两件事混成一句断语。
- **用户先问一处宅的形势，又只给了朝向没有周边**：先按已有信息给一次倾向读法，同时说清还缺周边与来水走向才能细判。
- **民间说法与书上不合**：如通书里某些日子的说法。先照书里（卷三十五附录、卷三十六辨訛）说明它的来历与书上对它的分辨，不替民间说法背书，也不简单斥为迷信。
- **用户坚持要「到底行不行」的二选一**：把它改写成可检验、可核实的读法（照书里这一类读，倾向如何，还差哪条信息），把拍板的权力交回用户。
- **问的是书上没有的做法**：照实说书里没有，标「（补充）」并说明依据，不拿后世术家说法冒名顶替。
