# 喜忌篇：格名与宜忌的歌诀

**来源**：sources/sanmingtonghui.txt（《三命通會》卷十一·喜忌篇） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 是 bazi-hub 下的子技能，随 hub 的硬闸门走：用户没显式提到八字、四柱、命理、格局、用神这些词时，整行不出、不激活。

**应该触发**：
- 用户问喜忌篇开头「四柱排定三才次分」与「有見不見之形」怎么讲。
- 用户问「時逢七煞見之未必為凶，月制干强其煞反為權印」在说什么。
- 用户问「財官印綬全備藏蓄於四季之中」与「官星財氣長生鎮居於寅申巳亥」是不是对偶两句。
- 用户读到「日祿歸時沒官星」「陽水疊逢辰位」「陰木獨遇子時」，想弄清这几种格名各指什么日时组合。
- 用户问「拱祿拱貴填實則凶」里「填實」是什么意思。
- 用户问「四柱純煞有制定居一品之尊，畧有一位正官官煞混雜反賤」为什么会因一位正官而反贱。
- 用户问「官煞兩停喜者存之憎者棄之」怎么取舍。
- 用户问「五行絶處即是胎元，生日逢之名曰受氣」怎么读。
- **用户给出四柱、问「我这盘照喜忌篇该按哪一句看」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问官、煞、印、財、食、傷几样之间怎么互相牵制翻覆 → 转 bazi-sanming-liu-shen。
- 用户问看命为什么先看月令、为什么以日干为主本 → 转 bazi-sanming-ji-shan-pian。
- 用户问一组四柱整体清浊、刚柔、寒暖 → 转 bazi-sanming-qi-xiang-pian。
- 用户问某个八字成不成格、成格破格通则 → 转 bazi-sanming-ge-ju。
- 用户要按生日报流年大运、断终身寿夭 → 本族不接。
- 用户没提八字词，只说「我今年是不是犯太岁」 → 泛化词，不激活。

## I：核心解释

喜忌篇是一份「逐句点格名、逐句说宜忌」的歌诀。它不像六神篇那样讲两神互变，而是把常见日时组合与官煞去留摊成一条条，读的时候要按句对号。

1. **开篇定的看命次序**。R1 说看命以「日上天元」为主，配合八字支干，并且承认「有見不見之形，無時不有」——除了明见的干支，还有藏、拱、暗合这类不见之形也算在内。R2 接着说这些神煞相绊时要「輕重較量」。所以喜忌篇的每一句，都要放在这两句的框架里读。
2. **时上七煞的可转**。R3：时逢七煞未必为凶，若月令能制、日干得强，这一个煞反可作权印。这是把「煞」从固定凶物改成看条件的一层。
3. **四季与四生的对偶**。R4、R5 是一对：财官印綬「全備藏蓄於四季之中」指辰戌丑未四库，官星财气「長生鎮居於寅申巳亥」指四生地。这两句是拿十二支的库与生分两类说藏蓄。
4. **食神干旺之方与遇而不遇**。R6：戊日庚申时是食神干旺之方，但岁月若见甲丙卯寅犯之，就成「遇而不遇」——组合本好，被旁边的字搅了。
5. **印綬的两句**。R7「月生日干無天財乃印綬之名」说月令生日干的称呼；R11 又提醒各类禄格（正禄、倒禄、飞禄）既忌官星也嫌羁绊。
6. **禄与贵的两句**。R8「日祿歸時沒官星號青雲得路」点名日禄归时格；R12「拱祿拱貴填實則凶」说拱禄拱贵格最怕所拱之位被填实——书里一句「填實則凶」即是此格的忌。
7. **两类「之乡／之地」格**。R9「陽水疊逢辰位是壬騎龍背之鄉」、R10「陰木獨遇子時為六乙䑕貴之地」是两组日时点题。读的时候只按原句认它指的是哪一日的哪个时，不替它加后世条件。
8. **偏财格的忌**。R13「時上偏財别宫忌見」：时上偏财这一格，忌别处又见同类，与下文「時上偏財怕逢兄弟」同旨。
9. **官煞去留是本篇的重头**。R14 说类有去官留煞、也有去煞留官；四柱纯煞有制可居一品之尊，略见一位正官而成官煞混杂则反贱。R15「月令雖逢建祿切忌㑹煞為凶」、R17「官煞兩停喜者存之憎者棄之」都接着这一层：官煞并见时要在两停之间做取舍，留在哪一边看喜憎。
10. **煞旺的两面**。R18 说四柱煞旺、运纯身旺，可为官清贵；R19 说柱中七煞全彰而身旺极，反主极贫无寿。同一句「煞旺」配上不同的身，落到两头——这里的「無夀」是书里的评价语。
11. **制伏太过也是病**。R20「偏官時遇制伏太過乃是貧儒」：偏官时遇，制伏得太过，反成贫困——制煞不是越多越好。
12. **受气一句**。R21「五行絶處即是胎元，生日逢之名曰受氣」说绝处当胎元看，生日逢之叫受气。
13. **收尾两句**。R22 点背禄逐马格（十干背禄、岁时喜见财星、运至比肩则背禄逐马，五行正贵忌冲刑克破之宫）；R23 又总断一句——阴阳罕测，不可一例而推，务禀中和之气，神分贵贱。
14. **一句话读法**：喜忌篇是按「日时/干支组合 → 归哪一格 → 这一格的喜与忌」逐条查的歌诀；R1、R2、R23 三句是它的读法总纲。

## A1：来源应用

书上给的做法：

- **读格先认组合**：先从日干与时支认出是哪一格（R6 戊日庚申时、R8 日禄归时、R9 壬骑龙背、R10 六乙鼠贵、R12 拱禄拱贵、R11 正倒禄飞、R13 时上偏财、R22 背禄逐马），再按该格那一句找喜与忌。
- **藏蓄两类分开看**：R4 说的是四季库，R5 说的是寅申巳亥生位，不要把两句合成一句。
- **忌「别宫／填實／覊絆」**：R13 的「别宫忌見」、R12 的「填實則凶」、R11 的「嫌覊絆」，都是指旁处的字把这格搅坏。
- **官煞去留的取舍**：R14、R15、R17 连起来——官煞并见时要在「喜者存之憎者棄之」之间定去留，纯煞有制与官煞混杂是两条不同的路。
- **煞看身配**：R18、R19 是同一句「煞旺」配不同的身，一头清贵一头极贫；R20 则说制伏太过反成贫困。
- **收束**：R23 总说不可一例而推，务禀中和之气，不拿一格去套所有人。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日干与时支的组合（认格的第一把手）、四柱干支是否见拱夹暗藏（不见之形）、月令与四季（辰戌丑未）四生（寅申巳亥）落在哪几支、官煞是否并见、煞旺配的身强弱。
2. **逐条核书里的条件**：先按 R1 分「明见」与「不见之形」→ 按 R2 相绊时较轻重 → 认出是哪一格（R6、R8、R9、R10、R12、R13、R22）→ 读该句的喜与忌（R12 填實、R13 别宫、R11 覊絆）；涉官煞的按 R14、R15、R17 看去留，涉煞旺的按 R18、R19、R20 分身配与制过。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「戊日庚申时而岁月见甲丙卯寅，按 R6 这一路读，偏遇而不遇」，并给出处（如「《三命通會》卷十一·喜忌篇」）。
4. **收口**：这一句是**书里的读法**，不是对这个人的判决；**不应期、不断终身、不替人决定**。

**书里没有的、不要加**：本篇是格名速查，不含「旺衰计分」「自动取喜用」这类做法；书里的「一品之尊」「極貧無夀」「師尼娼婢」都是它自己的评价语，引用时标明，不落成对某人的判决。要断某人的终身、寿夭、婚姻，不在本 skill 范围内。

4. 用户问「拱祿拱貴填實則凶」的「填實」指什么。
5. 用户看到「純煞有制定居一品」又看到「官煞混雜反賤」，问多一位正官为什么反坏。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–4 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 5–6 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **认组合（文本解读）**　输入：用户所引的一句 → 输出：从日干与时支认出这一句指的是哪一格（或对偶的哪一半：四季还是四生）。
   🔴 **CHECKPOINT**：认不出是明见的干支还是拱夹暗藏时，先照 R1 说清「有見不見之形」两路都可能，再问用户手里有没有那两个字。
3. **对回 R（文本解读）**　输入：这一句 → 输出：指出它在 R 节第几条，读出原句的喜与忌（如「别宫忌見」「填實則凶」「忌官星亦嫌覊絆」）。
4. **配去留与身煞（文本解读）**　输入：涉及官煞的句子 → 输出：按 R14、R15、R17 讲去留取舍；涉及煞旺的按 R18、R19、R20 分清配身的两头与制过之弊。
5. **取盘上的料（落盘）**　输入：用户四柱 → 输出：日干与时支的组合、是否见拱夹暗藏、月令与四季四生落在哪几支、官煞是否并见、煞旺配的身强弱。
6. **逐条核条件、给读法（落盘）**　输入：第 5 步的料 ＋ 本 skill 的条件 → 输出：按 R1 分「明见」与「不见之形」→ 按 R2 相绊较轻重 → 认格（R6、R8、R9、R10、R12、R13、R22）→ 读该句的喜与忌（R12 填實、R13 别宫、R11 覊絆）；涉官煞按 R14、R15、R17 看去留，涉煞旺按 R18、R19、R20 分身配与制过；一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷十一·喜忌篇」）。
7. **收口**　输入：整段推演 → 输出：一句格的认法 ＋ 一句该格的喜忌；若用户追问某个具体人的终身吉凶，照实说本 skill 只讲原书的格名与宜忌，不替人断。
   🔴 **CHECKPOINT**：收口前确认——① 没把书里的评价语（一品之尊、極貧無夀、師尼娼婢）说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格名／用词带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿一格套所有人 | 见「純煞有制」就断用户必贵 | 拉回 R23「不可一例而推」，只说格的条件 |
| 把对偶句合成一句 | 把四季库与寅申巳亥生位混讲 | 回到 R4、R5 各自的意思 |
