# 窮通寶鑑·論土：戊土己土的逐月取用

**来源**：sources/qiongtongbaojian.txt（《窮通寶鑑》論戊土、論己土、论四季月之土） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户拿一个戊土日主的盘，问某月该取丙、甲、癸里的哪几个字。
- 用户拿一个己土日主的盘，问同一类逐月取用。
- 用户读到「三春戊土，无丙照暖」不懂，问为什么土要丙、甲、癸三样。
- 用户问「先丙后甲」「先甲后丙」「先丙后癸」「先癸后丙」这些次序差在哪。
- 用户问四季月之土（辰戌丑未）里为什么未土为极旺。
- 用户问「土逢季月见金多，终为贵论」这类书里的断语怎么读。

**不应触发**：
- 用户问的是木／火／金／水日主的逐月取用 → 各转 bazi-qiongtong-mu／bazi-qiongtong-huo／bazi-qiongtong-jin／bazi-qiongtong-shui。
- 用户问的是五行总纲 → 转 bazi-qiongtong-wu-xing。
- 用户手上只有一句「你属牛、今年运怎样」，没有四柱 → 先按 bazi-hub 的硬闸门走，缺柱不排。
- 用户要批流年大运、断终身、判寿夭疾病、替人做婚姻或职业决定 → 本 skill 不接。

## R：原文锚点

1. 三春戊土，无丙照暖，戊土不生，无甲疏噼，戊土不灵，无癸滋润，万物不长。正二月先丙后甲，癸又次之。三月先甲后丙，癸又次之，因戊土司权故也。（《窮通寶鑑》論戊土·三春戊土）
2. 三月戊土司令，不见丙甲癸者，愚而且贱。甲癸透者，科甲。丙癸透者、生员。甲癸俱藏者，只可云富，有癸异途。（《窮通寶鑑》論戊土·三月戊土）
3. 四月戊土，阳气发升，寒气内藏，外实内虚，不畏火炎，无阳气相催，万物不长，故先用甲疏噼，次取丙癸为佐。（《窮通寶鑑》論戊土·四月戊土）
4. 五月戊土，仲夏火炎，先看壬水，次取甲木，丙火酌用，用癸力微。（《窮通寶鑑》論戊土·五月戊土）
5. 六月戊土，遇夏干枯，先看癸水，次用丙火甲木。（《窮通寶鑑》論戊土·六月戊土）
6. 七月戊土，阳气渐入，寒气渐出，先丙后癸，甲木次之。（《窮通寶鑑》論戊土·七月戊土）
7. 八月戊土，金洩身寒，赖丙照暖，喜水滋润，先丙后癸，不必木疏。（《窮通寶鑑》論戊土·八月戊土）
8. 九月戊土当权，不可专用丙，先看甲木，次取癸水，却忌化合。（《窮通寶鑑》論戊土·九月戊土）
9. 十月戊土，时值小阳，阳气略出，先用甲木，次取丙火。（《窮通寶鑑》論戊土·十月戊土）
10. 十一二月严寒冰冻，丙火为专，甲木为佐。（《窮通寶鑑》論戊土·十一二月）
11. 辰戌丑未，四土之神。惟未土为极旺，何也？（《窮通寶鑑》论四季月之土）
12. 书曰：土逢季月见金多，终为贵论，而在未月尤甚。（《窮通寶鑑》论四季月之土）
13. 正月己土，田园犹冻，盖因腊气未除，余寒未退，故丙为尊。（《窮通寶鑑》論己土·正月己土）
14. 二月己土，阳气渐升，虽禾稼未成，万物出土，田园未展，先取甲木疏之，忌合。次取癸水润之。（《窮通寶鑑》論己土·二月己土）
15. 三月己土，正栽培禾稼之时，先丙后癸，土暖而润，随用甲疏，三者俱透天干，必官居黄阁。（《窮通寶鑑》論己土·三月己土）
16. 三夏己土，杂气才官，禾稼在田，最喜甘沛，取癸为要，次用丙火。（《窮通寶鑑》論己土·三夏己土）
17. 三秋己土，万物收藏之际，外虚内实，寒气渐升，须丙火温之，癸水润之（《窮通寶鑑》論己土·三秋己土）
18. 总之，三秋己土，先癸后丙，取辛辅癸。九月土盛，宜甲木疏之，余皆酌用。（《窮通寶鑑》論己土·三秋己土）
19. 三冬己土，溼泥寒冻，非丙暖不生，取丙为尊，甲木参酌。（《窮通寶鑑》論己土·三冬己土）

## I：核心解释

《窮通寶鑑》论土这一块，是按「月令气候」给一个字一个字排用神次序的。它的逻辑可以拆成几条：

1. **土要成就三件事**：照暖、疏噼、滋润。三春戊土一句把根子讲透了——「无丙照暖，戊土不生，无甲疏噼，戊土不灵，无癸滋润，万物不长」（R1）。丙主暖、甲主疏、癸主润，三者是土的用神正选，缺一就断一条路。
2. **次序随月令调**：正二月「先丙后甲，癸又次之」，三月因为「戊土司权」改成「先甲后丙」（R1）。同一本三春，前后两个月的次序不一样，差别就在当月谁当令。
3. **燥湿决定取谁**：夏天土燥，取水为先。四月「先用甲疏噼，次取丙癸」（R3）、五月「先看壬水，次取甲木」（R4）、六月「先看癸水」（R5）；到了秋天土寒，又回到「先丙后癸」（R6、R7）。冬天更冷，「丙火为专，甲木为佐」（R10）。
4. **九月与十月是转折**：九月戊土当权「不可专用丙，先看甲木，次取癸水」（R8），十月「先用甲木，次取丙火」（R9）——土旺之月先理土本身，再谈暖润。
5. **己土是三件事的另一种配**：己土为田园之土，正月「故丙为尊」（R13）；到三月「先丙后癸…随用甲疏」（R15）；夏月「取癸为要，次用丙火」（R16）；秋月「须丙火温之，癸水润之」（R17），但总纲又说「先癸后丙，取辛辅癸」（R18）——月内前后段不同，次序也换。冬月「取丙为尊，甲木参酌」（R19）。
6. **旺月的例外**：四季月之土里书先分「未土为极旺」（R11），因为它带火气生土；其余三土带木气、金气，故「虽旺而不旺」。这就是九月戊土、六月己土为什么要单独改次序的原因。
7. **书里的评价语**：像「愚而且贱」「下贱之命」这类，是原书对某一类结构的评价语，引用时要标明是书里的说法（R2）。本 skill 只把它当书里的读法，不落到具体人头上。

## A1：来源应用

书上给的做法，是「先定月令气候 → 再排用神次序 → 最后看看需要的字有没有透干、藏支」。

- **判月令气候**：先看日主是戊还是己、生在哪个月（或哪个季段）。春月余寒（R1、R13），夏月火炎土燥（R3、R4、R5、R16），秋月金洩身寒（R6、R7、R17），冬月严寒（R10、R19）。
- **排字序**：照上面对应的那条原文抄次序。戊土春月先丙后甲、夏月先水后木、秋月先丙后癸、冬月丙甲并用；己土春月丙先、夏月癸先、秋月「先癸后丙，取辛辅癸」（R18）、冬月丙先甲佐。
- **看透藏定轻重**：原书对同一序里的字还分「两透」「藏支」。例如三月戊土「甲癸透者，科甲。丙癸透者、生员。甲癸俱藏者，只可云富」（R2）；十月戊土「甲丙两出，富贵中人」（R9 下文）。透干的字比藏支的得力。
- **土旺月先理土**：九月戊土「当权」，书先看甲木疏土（R8）；六月己土己土当权仍「先用壬水」（《窮通寶鑑》論己土·六月辛金前后诸条可互看，此处只据土篇）——总之土旺先给土出路。
- **四季月之土的特例**：未月极旺、见金结局者「不贵即富」（R11、R12）；书明说这是书里的评价，不是本 skill 的承诺。
- **一句话口径**：戊土看「暖不暖、疏不疏、润不润」，己土看「田园有没有冻、有没有浸」。

**书里没有的、不要加**：原书论土只讲逐月取用与透藏轻重，不讲后世流派的「旺衰计分」「自动取用程序」，也不把「用神」当成可以脱离月令单算的东西。书上把这些字叫「用神」（如「用神妻子仝前」），本 skill 沿用书里的叫法。

## A2：典型触发场景

1. 用户排出一个戊土日主、生在三月的盘，问「书上说先甲后丙，我这一盘到底先取谁」。
2. 用户拿己土日主、生在酉月，问「三秋己土先癸后丙，可我的癸藏支，算不算数」。
3. 用户读到「三春戊土，无丙照暖，戊土不生」不懂，问丙、甲、癸各管什么。
4. 用户拿一个生在未月的土命，问「土逢季月见金多」是什么意思。
5. 用户同一张盘问「戊土和己土论法一样吗」，想对照两条。
6. 用户问「冬天己土为什么先丙不先癸」。

## E：执行步骤

1. **确认日主与月令**　输入：用户的话、四柱 → 输出：日主是戊还是己、生月（或季）。若只有季段没有月份，先标「时段内不唯一」。
   🔴 **CHECKPOINT**：缺年月日时任一柱就停下，缺什么说什么，不占位硬排；缺柱时把用户引到 bazi-hub 补盘。
2. **对号取次序**　输入：日主＋月令 → 输出：从 R 节抄出当月那条次序（如戊土七月「先丙后癸，甲木次之」）。
   🔴 **CHECKPOINT**：抄的是原书次序，不是自己按五行生剋推的。
3. **看透藏排轻重**　输入：四柱干支 → 输出：序里的字哪些透干、哪些藏支，按书里「两透／藏支」的说法排轻重。
4. **给依据与取用条件**　输入：第 2、3 步结果 → 输出：两句必备——原书出处（《窮通寶鑑》論戊土·某月）＋ 凭什么这么取（月令气候、透藏）。
   🔴 **CHECKPOINT**：只报次序不出处，或只出处不讲取用条件，都退回补齐。
5. **收口**　输入：整段推演 → 输出：一段月令读法 + 一条取用次序 + 一句出处；结尾说明本 skill 到此为止，不接流年大运与终身断。
   🔴 **CHECKPOINT**：确认没有把书里的评价语（「愚而且贱」「下贱之命」）当成对用户的判决。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿别的日主套土的次序 | 用户是庚金日主也答「先丙后癸」 | 先确认日主；不是戊己就转 bazi-qiongtong-jin 等篇 |
| 只报次序不出处 | 答「三月戊土先甲后丙」却不指出根据 | 补《窮通寶鑑》論戊土·某月的出处与取用条件 |
| 把次序当死板配方 | 说「戊土一律先丙」 | 拉回 R1 与 R8、R9：次序随月令与司权变 |
| 缺柱硬排 | 只有生日就排出四柱下断 | 停下，说缺哪柱、要到什么程度才能排 |
| 把书里的评价语当判决 | 说用户「一定愚而且贱」 | 标明那是书里的说法，不落到具体人头上 |
| 越过范围批流年大运 | 顺势断某年会怎样 | 收口在月令取用，不接流年大运与终身 |

**边界规则**：
1. 只做戊土、己土的逐月取用，不替别的日主取用。
2. 只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 报用神必须同时给原书依据与取用条件。

**自查清单**：
- [ ] 每条 R 都是原书原话，且给出了「篇名＋月」的出处吗？
- [ ] 报次序时同时给了出处和取用条件吗？
- [ ] 有没有把书里的评价语说成对用户的判决？
- [ ] 缺柱时是照实说，还是硬排了？

**安全兜底**：涉及就医、用药、危机时，只做提醒与陪伴，不做诊断。

## 📖 练习手册

- **次序默写**：合上 R 节，写出戊土三春、三夏、三秋、三冬各一个先后序，再回去对原文。
- **同月两干对照**：取同一个三月，写下戊土与己土各自的次序，标出为什么不同。
- **透藏举例**：给一句「甲癸透／藏」的话，写出它对轻重的两种结果，各配一条原文。
- **评价语辨认**：从 R 节挑两句书里的评价语，改写成本 skill 的口径（只讲读法，不下判决）。

## 🚫 反例黑名单（不要做的事）

1. 拿庚辛壬癸或甲乙丙丁日主来问，也照土的次序答。
2. 只报「先甲后丙」这种次序，不给《窮通寶鑑》篇名与月份。
3. 把「先丙」「先甲」说成铁的公式，忽略书里随月令与司权而变的写法。
4. 缺出生柱就凭生日硬排出四柱往下断。
5. 把「愚而且贱」「下贱之命」这类书里的评价语，当作对眼前这个人的判决。
6. 顺口批出流年大运、终身吉凶、疾病寿夭。

## 灰色地带

- **用户只给季段没给月份**：先按季段给整段次序，并标明「段内不唯一」，同时说要到具体哪个月才能收窄。
- **同一月书里出现两条次序**（如己土三秋既写「须丙火温之，癸水润之」，总纲又写「先癸后丙」）：两条并列给出，说明是书里月内分段的差异，不替用户挑一条拍板。
- **用户要「取用」还要「断吉凶」**：取用照讲，断吉凶的部分说明本 skill 只到月令取用，不接流年大运与终身。
- **用户引的是转述而非原书**：只按 sources/qiongtongbaojian.txt 的原话答；转述里的字句与原书不合时，以原书为准并指出差异。
- **土的用神与书里评价语同时出现**：用神照讲，评价语标明「书里这么说」，不让它变成对此人的断语。
