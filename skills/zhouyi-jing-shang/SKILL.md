## 触发条件

**应该触发**（用户会怎么说话）：
- 问上經某一卦的卦辞或爻辞「书里怎么写」「出在哪一卦哪一爻」——如「乾卦的卦辞是什么」「有没有『亢龍有悔』这句、是哪一爻」。
- 复述一句卦爻辞，想知道它在上經哪一卦、上下文是什么、这一爻处什么位置。
- 带着一件具体的事，想知道照上經某卦某爻这一类处境该怎么读（宜进还是宜守、这一步该不该现在迈）。
- 提到上經的卦名或用语：乾、坤、屯、蒙、需、訟、師、比、小畜、履、泰、否、同人、大有、謙、豫、隨、蠱、臨、觀、噬嗑、賁、剝、復、无妄、大畜、頤、大過、坎、離；潛龍勿用、亢龍有悔、履霜堅冰至、黃裳元吉、密雲不雨、元亨利貞、无咎。

**不应触发**（看起来像但其实不是）：
- 问下經（卦三十一 咸 及以下）的卦爻辞 → 走下經那一支。
- 问十翼（彖／象／文言／繫辭／說卦／序卦／雜卦）或两家注疏的体例 → 走对应的传与读法一支。
- 要起卦、抽签、排盘、算命、批流年、断终身 → 本支不做占筮，照实说明只做读法与处境归类。
- 要医疗、法律、投资结论 → 不给结论，只做读法。
- 纯技术问题、单一事实查询（天气、价格、时间）、闲聊 → 直接回答。

## I：核心解释

先分清「哪一句是经、哪一句是注」，再谈读法。

1. 上經三十卦（乾一 – 離三十）每一卦都由「卦辞 ＋ 六爻爻辞」组成（乾坤另有用九／用六）：**卦辞**给这一卦的处境命名与宜忌，**爻辞**给这一处境里六个位置各自的边界（如「初九：潛龍勿用」＝位置在最下、时机未到）。R 1–94 逐卦抄的就是这一层**經文**。
2. 「卦名＋卦次」是坐标，不是装饰：同一句「无咎」，出在屯与出在坤不是一回事。报卦必须给全三样——**卦名 ＋ 卦次 ＋ 原文**，再加一条「为什么是这一卦」的对应（见「判读口径」）。
3. 四家不是一回事：**經文**是文王、周公所系（即卦辞爻辞本身）；**王弼注**是魏王弼对经的注；**朱熹本義**是宋朱熹对经传的注，多按筮法与实际占断读；**孔穎達疏**是唐孔颖达等对王弼注的疏。R 95–100 各标一层，可对读。
4. 两家注疏取法常有出入。例：「乾·元亨利貞」——孔疏作**四德**读（R 95「是乾之四德也」），朱熹本義作**占辭**读（R 96「以斷一卦之吉凶……所謂彖辭者也」）。两说都摆，**各标出处，不合读、不调停**。
5. 书里的吉凶词（元亨、无咎、凶、悔亡、悔吝）是**经文本身的用语**，是这一卦这一类处境的边界记法——它说的是「在这一类处境里，这样走记作无咎、那样走记作凶」，不是对某人某事的**事实**判决。
6. 象征层只命名处境、不承诺结果。一律写「倾向／按书里这一卦这一类读」，不写「一定／必然／命中／保证」。

## A1：来源应用

书上原样给的做法（不是我的发挥）：

- **先认卦，再认爻**：一句爻辞要先落到「哪一卦·哪一爻」上，爻位（初、二、三、四、五、上）本身就是处境的位置说明——「初九：潛龍勿用」（R 2）在卦之下位，「九五：飛龍在天」（R 3）在尊位，「上九：亢龍有悔」（R 4）在极位；同一卦里位置不同，许可的动作不同。
- **卦辞给宜忌成对**：屯「勿用有攸往，利建侯」（R 10）——同一处境里「不宜推进」与「宜先立条件」并列；訟「中吉，终凶」（R 20）——争讼有上限，止在中间。
- **用九／用六是总义**：乾「用九：見群龍，無首，吉」（R 5），王弼注「九，天之德也。能用天德，乃見『群龍』之義焉」（R 97）——王弼把用九读成「天德」；朱熹本義另按筮法读用九（本义原文见 `sources/zhouyi-benyi.txt`）。两说分栏，不合成一句。
- **注疏各自标层**：读一句经文时，把孔疏的活动（R 95、R 100）与王弼注的活动（R 97、R 98、R 99）分开摆，读者自己看谁解谁的。

## A2：典型触发场景

1. 「『潛龍勿用』是哪个卦？卦辞是什么？」 → A 路（文本解读）：乾（卦一）·初九，附卦辞 R 1。
2. 「我今年想争一个位置，但资历还不够，能不能强上？」 → B 路（处境读法）：对照乾（卦一）初九／九四／上九（R 2、R 4）与屯（卦三）「勿用有攸往，利建侯」（R 10），归到「时机未到、宜先立条件」一类。
3. 「我们两边吵起来了，要不要告到底？」 → B 路：对照訟（卦六）「中吉，终凶」（R 20）与上九「或錫之鞶帶，終朝三褫之」（R 21），归到「争端有上限」一类。
4. 「跟人合作，我该敞开还是留一手？」 → B 路：对照否（卦十二）「不利君子貞」（R 32）与謙（卦十五）「亨，君子有終」（R 44）。
5. 「刚接手的烂摊子，先修还是先推新？」 → B 路：对照蠱（卦十八）「元亨，利涉大川。先甲三日，後甲三日」（R 51）。
6. 「『亢龍有悔』这句书里到底在说什么？」 → A 路：乾（卦一）上九（R 4）＋王弼注（R 97）。

## E：执行步骤

**第 1 步｜分流（两路共用）**　输入：用户原话 → 输出：走哪一路。
- 判据只一条——**输入里有没有他要问的那件具体的事**：
  - 只有卦／句、没有那件事 → 走 **A 路（文本解读）**，即第 1 → 2 → 3 步；
  - 带着一件具体的事要读 → 走 **B 路（落到处境上的读法）**，即第 1 → 4 → 5 → 6 步。
- 🔴 **CHECKPOINT**：拿不准就先按 A 路把文本讲清，再问一句他有没有具体的事要套。最多问 2 个问题。

**第 2 步（A 路）｜认卦归义**　输入：他问的卦／句 → 输出：卦名＋卦次＋原文＋这一卦（这一爻）的处境命名。
- 🔴 **CHECKPOINT**：认错卦、认错爻不如不认。认不准就照实说还缺什么，**不硬套一卦**。

**第 3 步（A 路）｜摆书里的条件并收口**　输入：卦／句 → 输出：逐字原文＋出处 ＋ 书里给这一处境的许可与不许可（宜进／宜守／宜先立条件）＋两家注疏**分栏并陈**（本義／疏各标出处，不同处不合读）。
- 收口：只讲书里怎么讲，**不替用户决定、不预测结果**。

**第 4 步（B 路）｜归处境**　输入：他的事 → 输出：一类处境 ＋ **凭哪一条**（卦辞／爻辞／注疏的哪一句）这么归 ＋ 一条「为什么是这一卦」的细节对应（拿他提问里的哪个细节对上了它）。
- 🔴 **CHECKPOINT**：只丢一个卦名、说不出对上了哪一点，等于没给依据；对应不上就改卦或降低断言力度。信息不足以归到哪一卦哪一爻时，说清还缺什么，**不许硬套**。

**第 5 步（B 路）｜给方向**　输入：处境归类 → 输出：「按书里这一类读，偏 X」（宜进／宜守／宜先立条件）＋ 出处。
- 只做读法层面的事：这类处境下书里给的动作边界、宜进还是宜守、这一步该不该现在迈。**不做**：替用户决定、预测结果、断吉凶成事。

**第 6 步（B 路）｜收口并落一步**　收口：不起卦、不占卜、不抽签、不排盘、不算命、不批流年、不断终身；结尾落一个今天／这周能打勾的动作。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把疏文当经文 | 把孔疏或王弼注的话当卦辞爻辞报给用户，出处标成《周易》 | 回 `sources/zhouyi-zhengyi.txt` 认准这一段是经、是注、还是疏；R 节分层标清 |
| 两句合成一句 | 把朱熹本義与孔疏的说法揉成一句，看不出是谁的 | 两说分栏，各标出处，**不调停** |
| 引卦不给卦次 | 只写「屯卦说勿用有攸往」，没有卦次与原文 | 补全卦名＋卦次＋原文三样 |
| 硬套一卦 | 用户信息不足，仍按一个卦给结论 | 说清还缺什么，不硬套；只做最宽泛的分类 |
| 越界占筮 | 用户要「算一卦」，就起卦、抽签、断吉凶 | 照实说明本支只做读法与处境归类，不进行占筮 |
| 把吉凶词当判决 | 写「你这件事无咎」「必然吉」 | 标明是书里的用语：「按书里这一类读，偏无咎／偏凶」，不当作事实结论 |
| 报卦无依据 | 只丢卦名，说不出提问里哪一点对上了 | 补一条细节对应；补不上就改卦或降力度 |

**边界规则**：
1. 只读上經（卦一 乾 – 卦三十 離）；下經与十翼不在此支范围。
2. 引文逐字繁体原文，**异体字照本抄**，不改写成今字、不动标点。
3. 卦必须带卦名与卦次；爻辞带爻题。
4. 象征层只命名处境、不承诺；书里的吉凶词标明是书里的用语。
5. 内部归类名只作自己选路线的依据，**不进给用户的回答**；回答里只说用户自己讲的事与人。
6. 不越界：不起卦、不占卜、不预测结果、不替用户决定、不批流年、不断终身。

**自查清单**：
- [ ] 每条引文都能回到 `sources/` 三本源文件逐字对上（归一只留字形）。
- [ ] 报卦给了三样：卦名＋卦次＋原文，并有一条「为什么是这一卦」的细节对应。
- [ ] 层标清了：經文／王弼注／朱熹本義／孔穎達疏 各是哪一层。
- [ ] 两家注疏不同处两说并陈，没有调停成一句。
- [ ] 没有出现「一定／必然／命中／保证」；吉凶词已标明是书里的用语。
- [ ] 收口没有起卦、占卜、预测、替用户决定。
- [ ] 回答里没有出现任何内部归类名（成员 slug、目录名、「属于 XX 类处境」）。
- [ ] 结尾落了一个能打勾的动作。

**安全兜底**：涉及就医／用药／心理危机时，只做提醒与陪伴，不做诊断；涉及法律、投资、人身安全时不给结论、不替用户拍板。

## 📖 练习手册

1. **分层练习**：任取一句（如「乾·初九：潛龍勿用」），在 `sources/zhouyi-zhengyi.txt` 里把经、王弼注、孔疏三段分开抄出来，各标一层；再看 `sources/zhouyi-benyi.txt` 里朱熹本義怎么说。
2. **归义练习**：合上本页，拿 5 句上經爻辞（如「不遠復，無祗悔，元吉」「无平不陂，无往不复」），逐一写「这一卦＋卦次＋这一爻在什么位置」，再回 R 节核对。
3. **两说并陈练习**：取一处两家取法不同的地方（如「乾·元亨利貞」），分别用孔疏读法与朱熹本義读法各写一句，中间不写「其实两者是一回事」。

## 🚫 反例黑名单（不要做的事）

1. ❌ 把孔疏或王弼注的话当经文的卦辞爻辞报出去，出处标成《周易》。
2. ❌ 只写「某卦说……」，不给卦次、不给原文——等于没给依据。
3. ❌ 把朱熹本義与孔疏的不同读法揉成一句，读者看不出哪句是谁的。
4. ❌ 用书里的吉凶词给用户的现实处境下判决（「你这件事无咎」「必然吉」）。
5. ❌ 用户只给了一件事、信息不足以归卦，却硬套一个卦给结论。
6. ❌ 用户说「帮我算一卦」，就起卦、抽签、排盘、断吉凶。
7. ❌ 回答里出现成员 slug、目录名或「你的处境属于 XX 类」这种内部归类名。
8. ❌ 把「无咎」写成「无过错＝一定没事」，或用现代术语给经文背书。

## 灰色地带

- **一句话同时像两卦**：不硬选一卦。先各读一遍（各属哪一类、宜进还是宜守），再说还需要用户补哪一点来定夺；确有多面则两卦对照并指明读的顺序。
- **经与注疏读法冲突**：不裁决。把经、注、疏、本義各摆一处，写明各自取法，让用户看到分歧本身。
- **用户只报卦名不给事**：先按 A 路把这一卦的卦辞爻辞讲清；他要落到事上时再走 B 路。
- **用户要的就是占断结果**：照实说明本支只做读法与处境归类，不做占筮、不预测；可以退一步只讲这一卦这一类处境的书里条件。
- **异体字与版本差异**：三本用字不一（无／無、于／於），照本抄并在括注标出来源；用户若问哪个是「对」的，只说各本如此，不裁定。
