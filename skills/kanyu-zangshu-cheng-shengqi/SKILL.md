# 葬者乘生气：相地的第一原理

**来源**：sources/zangshu.txt（《葬書》内篇一开篇诸条） ｜ 证据等级：firsthand（原书原话）

## R：原文锚点

1. 葬者乘生氣也。（《葬書》内篇一）
2. 五氣行乎地中，發而生乎萬物。（《葬書》内篇一）
3. 人受體于父母，本骸得氣，遺體受廕。（《葬書》内篇一）
4. 經曰：氣感而應鬼，福及後人。（《葬書》内篇一）
5. 是以銅山西崩，靈鐘東應。（《葬書》内篇一）
6. 木華于春，栗芽於室。（《葬書》内篇一）
7. 蓋生者氣之聚，凝結者成骨，死而獨留，故葬者反氣入骨，以廕所生之法也。（《葬書》内篇一）
8. 此章乃錦囊一書之關鍵也，已下諸篇不過註腳而已。生氣者即一元運行之氣也，在天則周流六虛，在地則發生萬物。天無此則氣無以資，地無此則形無以載。（《葬書》内篇一·《錦囊》注）
9. 五氣即五行之氣，乃生氣之別也，夫一氣分而為陰陽，析而為五行，雖運於天實出於地。行則萬物發生，聚則山川融結，融結者，即二五之精、妙合而凝也。（《葬書》内篇一·《錦囊》注）
10. 父母骸骨，為子孫之本，子孫形體，乃父母之枝，一氣相廕，由本而達枝也。（《葬書》内篇一·《錦囊》注）
11. 且夫生氣藏於地中，人不可見，惟循地之理以求之，然後能知其所在。葬者苟能知其所在，使枯骨得以乘之，則地理之能事畢矣。（《葬書》内篇一·《錦囊》注）
12. 然而古人葬骨而蔭子子孫富貴者，蓋亦多矣。（《葬書》内篇一·《錦囊》注）
13. 是知人之心通乎氣，而氣通乎天。（《葬書》内篇一·《錦囊》注）
14. 乾父之精，坤母之血，二氣感合，則精化為骨，血化為肉，復藉神氣資乎其間，遂生而為人。（《葬書》内篇一·《錦囊》注）
15. 蓋一念即神也，神趍則氣應，地靈而人傑（《葬書》内篇一·《錦囊》注）

## I：核心解释

**第一原理不是「地好不好看」，是「這口氣聚不聚、能不能被乘到」。** 内篇一第一节把整本书压成一句「葬者乘生氣也」，注疏说这一句是「錦囊一書之關鍵」，底下诸篇「不過註腳而已」（R8）。也就是说，后面讲的形势、风水、支垄，都是替这句话做注脚。所以相地要先弄清：要乘的到底是什么。

1. 要乘的「生氣」不是某种玄气，书里把它说成「一元運行之氣」——在天周流、在地发生万物（R8）。它「藏於地中，人不可見」，只能「循地之理以求之」（R11）。这决定了相地的方法：不是去肉眼找气，而是顺着地的纹理去推它该在哪儿。
2. 生气再往下分就是五行之气，书里叫「五氣」；「五氣行乎地中，發而生乎萬物」（R2）。注疏解释「五氣即五行之氣，乃生氣之別也……行則萬物發生，聚則山川融結」（R9）。读法：山川的聚与散，就是这口气的行与止的外形。所以看形势，本质是看气的行止，不是单纯看山好不好看。
3. 气与人的连接走的是「本—枝」同一条线：父母骸骨是「本」、子孙形体是「枝」，二者「一氣相廕，由本而達枝」（R10）。这是「本骸得氣，遺體受廕」（R3）的机制来源——不是隔空赐福，是同气之间的相接。
4. 由此才有「氣感而應鬼，福及後人」（R4）。这里要说清：这句话是经文；它讲的是同气感召这一层，不是一句发财发贵的保证。书里的「鬼」指的是所感应的那一端，不是后世意义上的灵异实体；「福及後人」是这套机制的表述，不是承诺。
5. 书里举感应之证：銅山崩而靈鐘應（R5）、木華于春而家藏之栗亦芽（R6）。两条都在说明「一氣之感召」，不是拿自然现象给吉凶背书。读的时候要认出这是书里的比方。
6. 落到葬法上，就是「反氣入骨，以廕所生」：生者是气之聚，凝结成骨，死而独留；把枯骨安在生气所在处，让气反过来入骨（R7）。这是「乘生气」在葬法上的落点，也是全书从原理转到方法的那一道门。
7. 注疏对这套机制自己也有过疑惑：它先承认「遺體受廕」看着像「惑世誣衆」，又举「古人葬骨而蔭子子孫富貴者，蓋亦多矣」（R12），最后把它归到「人之心通乎氣，而氣通乎天」（R13）。这一段是《錦囊》注的议论，不是经文；讲的时候要标清楚。
8. **一句话的读法**：相地第一原理 = 找生气所在（R11）→ 让枯骨乘到它（R7）→ 由「本」达「枝」（R10）。三件事缺一不可，而书里对「怎么找」只给了方向（循地之理），具体认法散在后面几篇。

9. **形的来源也有一条注疏链**：天地精气「二氣感合，則精化為骨，血化為肉，復藉神氣資乎其間，遂生而為人」（R14）。所以「骨」不是普通物质，是父母二气所化、又由神气所资的那一份；人死则「神氣飛揚，血肉消殨，骨雖獨留」，故才有「反氣入骨」这一步可走。
10. **最后一步落在「一念」上**：注疏说安葬时子孙「一念與之吻合」，于是「一念即神也，神趍則氣應，地靈而人傑」（R15）。这是《錦囊》注把「乘生气」收进人心这一层——同气感召之外，还要有人的心念相接。
11. **把 R8 到 R15 连起来看**，整条链是：一元之气 → 分而为五行 → 行乎地中 → 父母受之成形、骨赖神气而留 → 本骸得气、遗体受廕 → 气感而应 → 反气入骨。相地第一原理就长在这条链的末端，前面每一环都是它的前提。

**常见误解要拆开**：
- 把「生氣」当成可以随便揣测的神秘东西——书里说它「不可見」，只能沿纹理推（R11），推不出就说推不出。
- 把「福及後人」当成确定预言——它是同气感召的表述，不是保证。
- 把注疏的举证（靈鐘、栗芽）当成经文，或当成科学证据。
- 以为第一原理能直接给出「某地能不能葬」的答案——它只给方向，具体判地要交给形势、支垄各类。

## A1：来源应用

书上给的是原理与方向，不是一套量表：

- **相地的落脚点只有一个**：「使枯骨得以乘之，則地理之能事畢矣」（R11）。书上把「知道生气所在并且乘到」当作相地的完成态，其余都是过程。
- **找气的方向**：因为气「藏於地中，人不可見」，办法是「循地之理以求之」（R11）——顺着地的纹理推。具体怎么顺纹理认，书里交给形势、支垄各类说法去展开（见本族形势、支垄等篇）。
- **感应链的通用读法**：本骸得气 → 遺體受廕 → 氣感而應（R3、R4）。注疏以銅山靈鐘、栗芽之类作比（见 R5、R6 及其注），要点在「一氣之感召」这四个字。
- **心与气这一层**：注疏把机制收到「人之心通乎氣，而氣通乎天」（R13）。这是《錦囊》注的看法，可讲，但要标为注。
- **葬法归到一句**：反氣入骨、以廕所生（R7）。书里把「乘生气」的结果命名为「反氣入骨」——气不是停在骨外，是反过来入骨。
- **评价语要标明**：内篇一本身很少下「必发大贵」的断语；真正带评价语的是雜篇的品类条（「葬王者」等都是书里的说法）。本 skill 引用时不把它当事实承诺。

## 练习手册

- **一句拆三层**：把「葬者乘生氣也」拆成「气是什么」「气怎么到人」「怎么落到葬」三层，每层各写一句白话，再回原书对一遍有没有挂靠。
- **经文/注疏分栏**：任取内篇一一整段，把经文挑一栏、《錦囊》注挑一栏，看自己能不能一次分对。
- **不许承诺练习**：把「福及後人」改写成一句不含「一定 / 必然 / 保证」的解释，看还能不能讲清同气感召。
- **举证归位**：把「銅山西崩，靈鐘東應」这句话归到「书里的比方」这一栏，并写一句为什么它不能当证据。

## 反例黑名单

1. 用现代科学名词（如某个物理或地质概念）解释生气——那是拿后世科学给原书背书，书里没有。
2. 说「葬对了这块地就必发大贵」——书里的贵贱断语是评价语，不是承诺。
3. 把《錦囊》注的举例（銅山靈鐘、栗芽）当成经文，或当成科学证据。
4. 用户只给一句「这块地怎么样」就开判生气有没有乘到——缺形势描述时应先说要补什么。
5. 顺着用户话头给实地下葬步骤（朝向、深浅、择时）——本 skill 不接这活。
6. 把「鬼」直接讲成后世意义上的灵异实体——书里讲的是所感应的那一端，不是鬼故事。

## 灰色地带

- **用户要「原理 + 一点实操」**：先给原理，实操只指方向（循地之理、求气之所在），具体认形交形势类 skill；不越界作现场指导。
- **经注混排的一段话**：用户给的一整段往往经文与《錦囊》注连在一起，先分栏再讲；分不干净时按「短句为经、〈…〉内为注」处理并说明这只是形式判据。
- **用户带着「灵不灵」的预期**：不写成自我否定腔，也不写成兜售腔；只把书里的机制讲清，把「灵验与否」留在书里的说法之外，交由用户自己判断。
- **注疏内部自相存疑处**：注疏既说「烏能受蔭」，又说「葬骨而蔭子子孫富貴者蓋亦多矣」（R12），两边并存。遇到就问用户想听的是经文的机制，还是注疏的议论，不要替注疏下结论。
