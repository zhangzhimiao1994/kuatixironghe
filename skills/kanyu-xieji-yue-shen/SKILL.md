# 堪舆择日·義例三·月神（天德月德类）

**来源**：《欽定協紀辨方書》卷五·義例三 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「天德、月德是什么？哪几个月份落在哪个方向或哪一天？」
- 「天德合、月德合跟天德、月德什么关系？」
- 「月空是不是就是月德的对家？为什么一个宜一个忌？」
- 用户要按**月**取用天德、月德这一组吉神，并问它的起例与宜忌。

**不应触发**（看起来像但其实不是）：
- 用户问的是**建除十二神**（建除满平定……）→ 转建除类 skill。
- 用户问的是**年**方位神煞（太岁、岁破、三煞）→ 转年神类 skill。
- 用户问的是**日家**三合、驿马、黄黑道、贵人禄马 → 转日神／黄道贵人／禄马类 skill。
- 用户要现场动土、下葬的作业指导 → 不接（见 B 节）。

## R：原文锚点

1. "乾坤寳典曰天道者天之元陽順理之方也其地宜興舉衆務向之上吉"（《欽定協紀辨方書》卷五·義例三）
2. "天徳者天之福徳也所理之方所值之日可以興土功營宮室"（《欽定協紀辨方書》卷五·義例三）
3. "天道即是天徳專言其方則曰天道兼日干與方向言之則曰天徳其實一也"（《欽定協紀辨方書》卷五·義例三）
4. "天寳歴曰月徳者月之徳神也取土修營宜向其方宴樂上官利用其日"（《欽定協紀辨方書》卷五·義例三）
5. "天寳歴曰天徳合者合徳之神也所理之方宜營構宫室修築城垣所値之日宜覃恩肆赦命將出師禱禮山川祈請福願"（《欽定協紀辨方書》卷五·義例三）
6. "月徳合者五行之精符會為合也所理之地衆惡皆消所値之日百福並集利以出師命將上冊受封祠祀星辰營建宫室"（《欽定協紀辨方書》卷五·義例三）
7. "月徳自南而東丙甲壬庚月空自北而西壬庚丙甲乃天徳之衝神也"（《欽定協紀辨方書》卷五·義例三）

## I：核心解释

卷五·義例三是「月神」的主卷：一批按月轮转的吉神。白话讲：

1. **天道与天德是一回事，只是说法不同**（R3）。「专言其方则曰天道，兼日干与方向言之则曰天德」。天道是「天之元阳顺理之方」，其地宜兴举众务、向之上吉（R1）；天德是「天之福德」，所理之方、所值之日可以兴土功、营宫室（R2）。
2. **天德的起例有干支与卦位两套**。正月丁、二月坤、三月壬、四月辛、五月乾、六月甲、七月癸、八月艮、九月丙、十月乙、十一月巽、十二月庚。书旁征博引，说明它是「三合之气」：寅午戌月三合火局，故以火为德。
3. **月德是月中之阳德**（R4）。「月德者月之德神也」，正五九月在丙、二六十月在甲、三七十一月在壬、四八十二月在庚。书按语说：月为阴，「阴无德，以阳之德为德」，故月德一律取阳干（甲丙庚壬），不用乙丁辛癸。
4. **天德合、月德合是「德之合」**（R5、R6）。天德合者「合德之神」，取各月天德所合之干（如正月天德在丁，合即在壬）；四仲之月天德居四维，故无合。月德合者「五行之精符会为合」，正月在辛、二月在巳……所理之地众恶皆消，所值之日百福并集。
5. **月空是月德的冲神**（R7）。书引历神原始：「月德自南而东（丙甲壬庚），月空自北而西（壬庚丙甲）」，月空乃天德之冲神。起例是寅午戌月在壬、亥卯未月在庚、申子辰月在丙、巳酉丑月在甲。书中按语问：月空既是月德的仇敌，何以名之为「空」？答曰「仁者无敌」——月德所在，莫敢与对，此方之神「固有而不有」，故如十二神「天空」之例，反以为宜上表章之奏书。
6. **同卷还有大批月神**：天赦（春戊寅、夏甲午、秋戊申、冬甲子）、天愿、母仓、月恩、四相、时德、王官守相民日、四击、九空、五墓、四耗、四废、四忌四穷、九坎九焦、五虚、八风触水龙、宝义制专伐日、八专、无禄、重日五合五离、解神、复日、鸣吠日等，各有起例与宜忌。
7. **天德的取义有两种解释并存**：一说它是「三合之气」（寅午戌月三合火局，故以火为德），正月丁、九月丙、五月乾；一说「天德不加于戊己」，子午卯酉之月只用巳亥寅申不用四墓。书说「论说纷纷如此」，并自下按语辨正，判其「举其一义而未举其全」。
8. **天道与天德的分别只在说法**：书明说「天道即是天德，专言其方则曰天道，兼日干与方向言之则曰天德，其实一也」。判读时凡问方位说天道，问日干兼方说天德。
9. **同卷诸神的起例方式各异**：天恩从六十甲子取（甲子至戊辰等十五日），天赦从四季取（春戊寅、夏甲午、秋戊申、冬甲子），母仓取「生当时五行之辰」，月恩取「阳建所生之干」，四相取四时王相之干，时德取四时所生之阳辰。

## A1：来源应用

书上给的具体做法（不是我的发挥）：

- **天道方位**（R1）：正月九月在南方，二月在西南，三月七月在北方，四月十二月在西方，五月在西北，六月十月在东方，八月在东北，十一月在东南。宜兴举众务、向之上吉。
- **天德起例**（R2 及同卷）：正月丁、二月坤、三月壬、四月辛、五月乾、六月甲、七月癸、八月艮、九月丙、十月乙、十一月巽、十二月庚。所理之方、所值之日可以兴土功、营宫室。
- **月德起例**（R4）：正五九月在丙、二六十月在甲、三七十一月在壬、四八十二月在庚。取土修营宜向其方，宴乐上官利用其日。
- **天德合起例**（R5）：正月壬、三月丁、四月丙、六月己、七月戊、九月辛、十月庚、十二月乙；四仲之月无合。
- **月德合起例**（R6）：正五九月在辛、二六十月在巳、三七十一月在丁、四八十二月在乙。所理之地众恶皆消、所值之日百福并集。
- **月空起例**（R7）：寅午戌月在壬、亥卯未月在庚、申子辰月在丙、巳酉丑月在甲。所理之日宜设筹谋、陈计策（因与贵人相对，如天空之奏书）。
- **一组辅神**：天恩（甲子至戊辰等十五日）、母仓（春亥子、夏寅卯……）、月恩（阳建所生之干）、四相（春丙丁、夏戊己、秋壬癸、冬甲乙）、时德（春午夏辰秋子冬寅）等，各有宜忌。
- **天赦**：春戊寅、夏甲午、秋戊申、冬甲子；「其日可以缓刑狱、雪冤枉、施恩惠」。书按：宜施恩赦罪，但「谓必天恩之日乃可施恩」是拘论，刑赏不可因日而曲法。
- **天愿**：正月至十二月各有一日（正月乙亥、二月甲戌……）；书辨曹震圭之说「支离难通」，而取起例所载十二辰的正义。
- **月恩**：正月丙、二月丁、三月庚、四月己……取「阳建所生之干」，「子母相从」。
- **四相／时德**：四相春丙丁、夏戊己、秋壬癸、冬甲乙（不用庚辛）；时德春午、夏辰、秋子、冬寅，取四时所生之阳辰。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报神煞名不给卷次 | 「这个月月德好」不说卷几 | 补卷五·義例三条目＋宜忌依据；补不出＝不合格 |
| 把天道与天德当两回事 | 分别讲成两个神、两套起例 | 按书「其实一也」合一说明，只在「专言方」时称天道 |
| 把月空当纯凶 | 见月空就说大凶 | 按书「固有而不有」之义，兼说其宜上表章一面 |
| 把坊本说法当书的主张 | 拿坊本对天德的臆解当真 | 书旁征三合之说并有辨正，坊本一律标「（补充）」 |
| 缺月份就硬判 | 用户只说「最近」 | 点明缺月建／节气，缺则不算 |
| 越界到日时 | 拿月德去断某时辰吉凶 | 转日神／黄道贵人／禄马类 skill |
| 把天赦宜赦说成必然 | 「天赦日犯法也没事」 | 书明说刑赏不可因日而曲法，照书辨正 |
| 把月空当纯凶之神 | 见月空即断大凶 | 按书「固有而不有」，兼说其宜奏书一面 |

**边界规则**：
1. 本 skill 只管**卷五·義例三**这一批月神；建除在卷四，日神在卷六，时与黄黑道在卷七。
2. **报神煞必须同时给起例来源与宜忌依据**；只报神煞名而不给卷次＝不合格。
3. 象征层只命名、不承诺：写「按书里这一类读」，不写「一定／必然／命中／保证」。
4. 不替用户拍板，不给医疗、法律、投资结论。
4. 本 skill 不涉卷五内的日辰神煞（鸣吠日、重日、五合五离等）的取用；那些按事类取用，须与日辰神煞类 skill 相参。

## 练习手册

1. **月德默推**：任取一月，凭三合局推出月德、月德合、月空三干，再回卷五核对。
2. **天德卦位**：写出四仲之月天德所居的四维卦，并说明为何四仲之月无天德合。
3. **一句辨讹**：找出书里对某月神起例的辨正之语，用自己的话复述「书为什么不采某说」。
4. **天德默排**：凭记忆写出十二个月天德所在的干或卦，再回卷五核对四仲之月的例外。
5. **三合推德**：任取一月，由其三合局推出月德、月德合、月空，写出推演的每一步。

## 反例黑名单

1. **不要**只报神煞名而不给出处——违反本族硬口径。
2. **不要**把天道与天德讲成两个不相干的神。
3. **不要**把月空一律说成大凶——书明说它「固有而不有」。
4. **不要**把天德月德说成「必然获福」——书只给倾向。
5. **不要**用现代词给月德背书，也不要写成自我否定的腔调。

## 灰色地带

- **方与日两用**：天德、月德既指方位又指日辰（「所理之方、所值之日」）。用户问的是方还是日要说清；含糊时两栏并列。
- **同名异义**：天德既是月神，卷七黄道十二神里也有一个「天德」（又改名宝光）。书已说明「以无别为嫌」，遇到时必须点明是哪一套，不可混用。
- **起例分歧**：如天德用干还是用卦，历代讨论纷纷，书自己也说「论说纷纷如此」。此时照录书的态度，不替它定于一尊。

- **方与日的取舍**：天德、月德既是方又是日。用户只问「这个月好不好」时，先明确他问的是方还是日，再分栏作答。
- **起例纷争**：天德用干或用卦、用不用四墓，历代争论。书并存诸说并判「论说纷纷」；遇到时照录各说，不替它定于一尊。
- **同名的天德**：卷五月神天德与卷七黄道十二神天德（宝光）同名异实。遇到时必须点明是哪一套，不可混用。
- **月神的层级限制**：卷五月神按「月」取用，不用于断某一天的全体吉凶；遇到跨层取用者，先归月层再答。
- **同名诸神须先辨**：天德、月德、德合等名年、月、日、时各层都有，遇问先问清是哪一层、哪一卷，再起例，切忌一名到底。
- **三件套的写法**：报一个月神，标准写法是「神煞名 → 卷五·義例三某条起例 → 宜忌（并注明是书上认真说的还是书已辨正者）」，三样缺一即不合格。
- **月德一律用阳干**：书按「月为阴，阴无德，以阳之德为德」，故月德取甲丙庚壬四阳干，不用乙丁辛癸；且三合只有四行，故月德无戊。遇到用户问「为什么月德没有戊土」时，照此义解。
- **天恩天赦的取法有别**：天恩从六十甲子取十五日（天以始）、天赦从四季取四日（地以中）。遇到把天恩天赦混为一日者，按取法分说。
- **月空与奏书**：书以月空为「天德之冲神」，又因其「固有而不有」而比之十二神之「天空」，故月空得宜上表章之义。遇到用户把月空一律当凶者，照此义补其另一面。
- **德合的三传**：天德合、月德合皆取「德之所合」，其取义是「德体也，合则其用也」。遇到用户问德与德合何以并重时，照此解。
