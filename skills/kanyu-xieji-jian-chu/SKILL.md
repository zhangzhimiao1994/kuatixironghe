# 堪舆择日·義例二·建除十二神

**来源**：《欽定協紀辨方書》卷四·義例二 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「黄历上写今天是『建』日／『破』日，到底什么意思？」
- 「除危定执成开是黄道吉日，建破平收满闭是黑道，对不对？」
- 「某月哪几天是建日、哪天是满日？」「建日能不能结婚？」
- 用户要按**月**排建除十二神，并问各日的宜忌与同位异名。

**不应触发**（看起来像但其实不是）：
- 用户问的是**年**方位神煞（太岁、岁破、三煞）→ 转年神类 skill。
- 用户问的是**月德、月空、天德**这一类按月轮转的吉神 → 转月神类 skill。
- 用户问的是**黄道黑道十二神**（青龙明堂天刑……）→ 转黄道贵人类 skill；那是另起一套起例。
- 用户要现场动土、下葬的作业指导 → 不接（见 B 节）。

7. "建者一月之主故從建起義而㕘伍於十二辰古之所謂建除家言也"（《欽定協紀辨方書》卷四·義例二）

## I：核心解释

建除十二神是择日里最日常的一层：黄历上那个「建／除／满／平……」就是它。白话讲：

1. **起例很简单**（R1）。十二日一周：建、除、满、平、定、执、破、危、成、收、开、闭。**每月交节就重排**，法从月建上起「建」，顺行十二辰。正月建寅，则寅日为建、卯日为除，依次顺排。
2. **古已有谱**（R2、R7）。淮南子给出正月各辰的建除归属。「建者一月之主」，故从建起义——它是这一月里的主日。
3. **吉凶的大口诀**（R3）：除、危、定、执、成、开为吉，建、破、平、收、满、闭为凶。这是历书里最通行的一句。但书自己提醒：这只是大纲，「未可以执一而论」，还要看各日叠了哪些吉凶神。
4. **十二神各有「同位异名」**（R4、R5 等）。同一天，建除家叫它「建」，丛辰家可能叫它「兵福」「小时」「土府」；除日又叫「吉期」「兵宝」；满日又叫「福德」「天巫」「天狗」。书把这些异名**统一到建除之下**（R6），理由就是那句「古有建除家丛辰家，时师已莫识其统系」——名目太乱，书来归拢。
5. **吉凶的剂量有前提**：书说「以建除论吉凶未甚彰显著明」，真正生吉凶的是「参以万事，错以二气五行」（见 R 节上下文），建除只是骨架。
6. **关键的一条内部张力**：同一「建」日，历书说「建日不利行师」，可在「兵福」名下又说「利行师」。书的解释是：月建所在，「我用则我利用之，则为兵福矣；若敌在建方则不利」——要看是谁用、用在什么处境（详见 A1）。
7. **建除与月厌是一阴一阳**：月建（阳建）左旋，月厌（阴建）右旋，二者相值则「阴阳参杂」。书引淮南「堪舆徐行，雄以意知雌」说明建厌关系，并以周礼「观天地之会」郑注「以厌建当之」为据。
8. **阴阳不将**：堪舆家的嫁娶吉日。以月建为阳（正月起寅顺行）、月厌为阴（正月起戌逆行），分于卯酉、会于子午；「厌前干支自相配者为阳将，厌后干支自相配者为阴将」，厌前干配厌后支者为阴阳不将。阳将伤夫、阴将伤妇、阴阳俱将夫妇俱伤、阴阳不将夫妇荣昌。
9. **大会小会与从辰诸名**：阴阳大会（正月甲戌、二月乙酉……）、小会（二月己酉、三月戊辰……），以及行狠、了戾、孤辰、单阴、纯阴、孤阳、纯阳、岁薄、逐阵、阴阳交破、阳破阴冲等，书判「皆从厌建起义」，合不将日观之，「堪舆家择日之道备矣」。

## A1：来源应用

书上给的具体做法（不是我的发挥）：

- **十二神起例**（R1）：正月寅日起建，顺行十二辰；每月交节重排，故一节内会「叠两值日」。
- **吉凶口诀**（R3）：除危定执成开吉，建破平收满闭凶。
- **兵福即建**（R4）：兵福与月建同行；月建所在为「王相之方」，我用我利，故为兵福；敌据建方则不利。书又引礼记，说「建虽兵福，要须视此建为何月之建」。
- **小时即月建**（R5）：小时是「当时之旺辰」，忌结姻亲、开仓库。
- **同位异名全表**：建〈兵福、小时、土府〉，除〈吉期、兵宝〉，满〈福德、天巫、天狗〉，平〈阳月天罡、阴月河魁、死神〉，定〈时阴、官符、死气〉，执〈枝德、小耗〉，破〈大耗〉，成〈天医、天喜〉，收〈阳月河魁、阴月天罡〉，开〈时阳、生气〉，闭〈血支〉。
- **月建**：诸神之统帅，「俗谓之月中天子」，宜封建视事，不宜兴造土功、结亲。
- **月厌〈地火〉**：正月起戌逆行十二辰，为阴建，所理之方可禳灾祈福，所值之日忌远行归家移徙嫁娶。
- **厌对〈六仪、招摇〉**：厌对为月厌所冲之辰（正月起辰逆行），忌嫁娶、乘船渡水；六仪与之同位而忌喜相反，书判为「厌对忌嫁娶、六仪宜视事临官」。
- **阴阳不将／大会小会**：堪舆家的嫁娶吉日取法，详见卷四后段；书对坊本妄分「岁位岁对岁前岁后」「天子皇后卿士庶民」有明确驳正。
- **月建**：正月建寅顺行十二辰，为「月中天子」，所理之方战攻宜背，所值之日宜封建视事，不宜兴造土功、结亲。
- **月厌〈地火〉**：正月起戌逆行十二辰，忌远行归家、移徙嫁娶；所理之方可禳灾祈福。书明说「地火即是月厌」。
- **厌对〈六仪、招摇〉**：正月起辰逆行十二辰。书定「厌对忌嫁娶、六仪宜视事临官」，两存其义。
- **建除同日异名对照**：建＝兵福＝小时＝土府；除＝吉期＝兵宝；满＝福德＝天巫＝天狗；平＝阳月天罡、阴月河魁、死神；定＝时阴、官符、死气；执＝枝德、小耗；破＝大耗；成＝天医、天喜；开＝时阳、生气；闭＝血支。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报神煞名不给卷次 | 「今天建日不能结婚」不说卷几 | 补卷四·義例二条目＋宜忌依据；补不出＝不合格 |
| 把口诀当铁律 | 逢破日一律大凶，不看叠了哪些神 | 按书「未可以执一而论」补讲轻重相参 |
| 混淆两套黄黑道 | 把「除危定执成开」当成青龙明堂那套黄道 | 说明这是建除吉凶口诀，黄黑道十二神另起一例（卷七） |
| 把坊本用法当书的主张 | 拿坊本「岁位岁对」分天子庶民之说当真 | 书明驳其不可为法，一律标「（补充）」 |
| 缺月建就硬排 | 用户只说「这个月」不给节气 | 点明缺月份／节气，缺则不算 |
| 越界到日时贵人 | 拿建除去断某时辰的贵人禄马 | 转黄道贵人／禄马类 skill |

**边界规则**：
1. 本 skill 只管**建除十二神及卷四同卷的月建、月厌、阴阳不将等**；月德等月神在卷五，日神在卷六，时与黄黑道在卷七。
2. **报神煞必须同时给起例来源与宜忌依据**；只报神煞名而不给卷次＝不合格。
3. 象征层只命名、不承诺：写「按书里这一类读」，不写「一定／必然／命中／保证」。
4. 不替用户拍板，不给医疗、法律、投资结论。
4. 阴阳不将、大会小会属堪舆家择日之法，只在卷四范围内；其坊本流变（分岁位岁对、天子庶民）书已删去，一概不采用。

## 练习手册

1. **十二神默排**：任取一个月建，凭记忆把十二辰与十二神一一对应排出，再回卷四对。
2. **同位异名表**：写出建、除、满三日各自的同位异名，并说明为什么书要把它们归到建除之下。
3. **轻重相参**：取一个「破」日，先写口诀判凶，再试着找出它叠了什么吉神而可以缓读，体会书说的「未可以执一而论」。
4. **建厌对排**：任取一月，同时排出月建（阳建）与月厌（阴建）两条十二辰序，标出二者相值相离之处。
5. **不将推演**：按「厌前干配厌后支」之法，任取一月推得阴阳不将之日，再回卷四核对。

## 反例黑名单

1. **不要**只报建除名而不给卷次——违反本族硬口径。
2. **不要**把「除危定执成开吉」当成不用再看的铁律。
3. **不要**把建除十二神与黄道黑道十二神（青龙明堂……）混为一谈，两者起例不同。
4. **不要**把「建日不利行师」与「兵福利行师」当成书自相矛盾——书已解释是看谁用、在什么处境。
5. **不要**用现代词给建除背书，也不要写成自我否定的腔调。

## 灰色地带

- **建日两说**：历书「不利行师」与兵福「利行师」并存，书判为「视此建为何月之建」。遇到时两说并陈，点明取决于使用者所处位置。
- **同名异实**：满日既称福德（宜祭祀）又称天狗（忌祷祀），书判「非谓凡为满日皆天狗也」，仅戌日值满者为例外。遇到时按具体日支细分。
- **口诀与神煞相冲**：口诀判吉之日若叠了凶神，或口诀判凶之日叠了吉神，书只给倾向、不给断语；此时并列两方，留待用户按事项自参。

- **建除与堪舆两系并用**：嫁娶择日既取建除吉凶，又取堪舆家的不将、大会小会，两系判吉可能相反。书判「各从其所用」；遇到时两栏并陈，不强行合一。
- **交节叠日**：每月交节会「叠两值日」，同一自然日可能跨两个建除名。遇到时以节气为界说明归属。
- **书删之目**：书对坊本「岁位岁对、天子庶民分用」明确删去。遇到时说明书为何删，不把删去的说法当书的主张。
- **口诀只作骨架**：书说「止以建除论吉凶，未甚彰显著明」，真生吉凶者在「参以万事、错以二气五行」。遇到只背口诀的用户时，先给骨架，再点明还要相参其他神煞。
- **交节与月建**：建除以交节换月建，故同一自然日可能跨两月建。遇到日期恰在交节前后的情形，先确认节气时刻归属，再定建除名。
- **三件套的写法**：报一个建除日，标准写法是「建除名 → 同卷同位异名 → 卷四·義例二某条起例 → 宜忌（并注明是口诀大纲还是相参所得）」，三样缺一即不合格。
- **建除家与丛辰家**：书说建除、丛辰两家的名目「散而无纪、殽而无序」，故「类聚之而悉统于建除」。遇到用户拿出一个生僻神名时，先判断它是不是某建除日的异名。
- **破日与危日**：书说「物无成而不毁，故继之以破」「救破以危」——破日虽凶，危日取其「心能危者事乃成」之义，故口诀里危为吉。遇到破危相连的日子，按书义分说，不混作一谈。
