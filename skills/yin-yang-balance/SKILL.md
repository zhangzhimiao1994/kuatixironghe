# 阴阳平衡分析框架

> 本 skill 只提供身心与系统的调节视角，**不作医疗判断、不替代就医**；文中“阳盛”“阴盛”等表述是系统分析的隐喻映射，不是医学诊断。

## ⛔ 硬规则 0：先抽离，再谈分析（凌驾于本 skill 其它一切步骤）

**触发信号**：用户把“阴阳失调 / 脾胃虚 / 宫寒 / 湿气重 / 气血两虚”这类说法直接扣在自己身上，问“我是不是……”。

**第一条铁律——第一句必须先抽离，绝不允许接上去给辨证。**
- 开头先把这个说法本身拆掉，再谈别的。模板：“**阴阳失调是个流传很广的说法，它不是一个能拿来定病的诊断。**” / “脾胃虚是个民间的笼统说法，扣不到具体哪个人头上。”
- **禁止输出任何证型判断**：不得说“你这是上热下寒 / 下虚上盛 / 阳盛阴虚 / 阴虚火旺 / 肝郁脾虚”，也不得给“哪边拖得久，哪边更接近你真实底子”这类**教用户自己推出证型**的话。凡是“所以你属于某证”的门，一律关死。
- **不得把用户的自我标签升级成结论**：他说“我是不是阴阳失调”，回答里不能再出现“是的，你确实偏……”或“从你的描述看，基本可以判断为……”。

**允许做的（说清楚）**：可以用这套书的语言，帮他把“**他自己讲出来的现象**”归归类，把话说回他嘴里——例如“你一边容易燥、一边又畏寒，说明冷热两堆表现是同时存在的”。**只描述他给出的现象，不给现象贴病名，也不由归类推出“你是什么证”。**

**必须打开的门**：把方向指向正规医疗机构——“这些表现要不要紧、算什么情况，得让正规医疗机构的医生看了才算，别用网上的说法给自己定病。”

**适用范围**：完整的“归阴阳→判盛虚→用对立面纠正”流程，**只在用户分析的是非身体系统（团队、项目、作息节奏），或明确说只是想做思维练习时**才展开；一旦用户是在问“我身体怎么了”，就只做现象归类 + 就医提醒，**不做盛虚判断、不给纠正方向**。

## 触发条件

**应该触发**：
- 用户描述某系统/身体/组织出现“一方过强一方过弱”的对立失衡（热vs冷、快vs慢、强vs弱、兴奋vs抑制）。
- 用户问“该加强弱的还是压制强的”“该补还是该泄”——需要先判断失衡方向。
- 系统在两个极端之间摇摆，需要判断谁盛谁虚、找纠正方向。
- 语言信号：“一边X一边Y，感觉很不平衡”“总是太X，缺少Y”“怎么判断是该补还是该泄”“系统在两个极端之间摇摆”“过度的X导致了Y的问题”。

**不应触发**：
- 纯信息查询、不需要分析的场景。
- 只有单一变量、没有对立面的问题（如“如何提高效率”，需先找到对立面“效率vs质量”才能展开）。
- 需要精确数值的场景（阴阳框架只给方向，不给精确数字）。
- 纯二元对立的选择题（“A好还是B好”）——这是选择题，不是阴阳分析。

## R：原文锚点

1. “阴阳者，天地之道也，万物之纲纪，变化之父母，生杀之本始，神明之府也。治病必求于本。”（《黄帝内经·素问》·据公版原文核·阴阳应象大论篇第五）

2. “阴胜则阳病，阳胜则阴病。阳胜则热，阴胜则寒。重寒则热，重热则寒。”（《黄帝内经·素问》·据公版原文核·阴阳应象大论篇第五）

3. “阴平阳秘，精神乃治；阴阳离决，精气乃绝。”（《黄帝内经·素问》·据公版原文核·生气通天论篇第三）

## I：核心解释

阴阳平衡分析法是一个用于**分析**系统失衡、并找纠正方向的结构化框架。**它不是诊断工具**——无论对象是身体还是组织，本框架只给“用对立面看问题”的视角，不给病名、不下结论。

其核心操作分为三层:

1. **归阴阳**: 将任何现象归入阴阳两个对立面。阳代表主动、温热、外向、兴奋; 阴代表被动、寒凉、内敛、抑制。这不是贴标签, 而是建立一种“用对立面看问题”的视角。

2. **判盛虚**: 判断哪一方过盛、哪一方不足。“阳胜则热, 阴胜则寒”——失衡必然表现为某一方的症状。关键是区分“某一方过盛”还是“另一方不足”, 因为纠正方向完全不同。


3. **用对立面纠正**: 阳盛则补阴抑阳, 阴盛则补阳抑阴。纠正的方向永远是向对立面借力, 而不是直接压制过盛方。
   🛑 **STOP**：请确认上一步的分析结果后再继续。


4. **平衡态是目标**: “阴平阳秘, 精神乃治”——系统恢复平衡时, 功能自然正常。平衡不是静态的50/50, 而是动态的相互制约。

这个框架的威力在于: 任何复杂系统, 只要能归阴阳, 就能用同一套逻辑分析。

## A1：来源应用

### 案例 1: 阳盛则热的病理表现
- **问题**: 某人出现发热、口渴、面红等亢奋症状, 如何理解其本质?
- **方法论的使用**: 将症状归阴阳——热、亢奋、外向均属阳, 判定为“阳胜”。根据“阳胜则热, 阳胜则阴病”, 阳气过盛不仅产生热象, 还会消耗阴液(津液受损)。
- **结论**: 表面是“热”, 实质是阴阳失衡——阳过盛而阴受损。
- **结果**: 治疗方向不是单纯降温, 而是“热者寒之”的同时兼顾养阴, 防止阳盛伤阴导致“阴阳离决”。

### 案例 2: 阴阳匀平的平人标准
- **问题**: 如何定义健康状态?
- **方法论的使用**: 用阴阳平衡标准定义健康——“阴阳匀平, 以充其形, 九候若一, 命曰平人”。
- **结论**: 健康不是“没有病”, 而是阴阳处于动态平衡, 充养形体, 脉象调和。
- **结果**: 这一标准将“平衡”从抽象概念变为可操作的诊断标准——通过脉象(九候)是否调和来判断阴阳是否平衡。

> 注：“阴阳匀平，以充其形，九候若一，命曰平人”一句据公版原文出《素问》调经论篇第六十二，已据公版原文核。

## A2：典型触发场景

### 用户会在什么情境下需要这个 skill?

1. **系统失衡分析**: 用户描述某个系统出现“一方过强一方过弱”的矛盾, 如团队中“推的人太多拉的人不够”, 或身体“上火但手脚冰凉”。
2. **对立冲突诊断**: 问题是两股相反力量在对抗——热与冷、快与慢、兴奋与抑制、扩张与收缩——需要判断谁盛谁虚。
3. **纠正方向迷茫**: 用户知道某个方面出了问题, 但不确定该“加强弱的”还是“压制强的”, 需要找到正确的干预方向。

### 语言信号 (用户的话里出现这些就应激活)

- “一边X一边Y, 感觉很不平衡”
- “总是太X, 缺少Y”
- “怎么判断是该补还是该泄”
- “系统在两个极端之间摇摆”
- “过度的X导致了Y的问题”

### 与相邻 skill 的区分

- 与 `five-elements-network` 的区别: 阴阳平衡处理**两极对立**关系(一对矛盾), 五行生克处理**多要素网络**关系(五个要素的连锁)。问题只有两个对立面时用阴阳, 有三个以上要素相互影响时用五行。
- 与 `biao-ben-priority` 的区别: 阴阳平衡解决“**方向**”问题(该补还是该泄), 标本缓急解决“**顺序**”问题(先治哪个后治哪个)。
- 关系: `zheng-xie-assessment`（contrasts-with）——阴阳平衡处理“两极对立”的盛虚方向, 正邪虚实处理“自身vs外部”的力量对比; 常串联使用: 先用阴阳判盛虚方向, 再用正邪判虚实策略。`seasonal-regimen`（composes-with）——四时调养是阴阳平衡在时间维度上的应用: 春夏养阳、秋冬养阴。

## E：执行步骤

当 skill 被激活后, agent 应按以下步骤执行:

1. **归阴阳: 将现象归入对立面**
   - 列出当前系统中所有异常表现, 将每一项归入“阳面”(主动/温热/外向/亢奋)或“阴面”(被动/寒凉/内敛/抑制)。
   - 完成标准: 所有异常表现已归入阴阳两列, 且两列的定义一致(不混用不同维度的阴阳)。
   **输入**：系统中所有异常表现 → **输出**：阴阳两列归类清单。
   🔴 **CHECKPOINT**：把阴阳两列归类展示给用户，确认归类维度一致后再继续。

2. **判盛虚: 判断失衡方向**
   - 统计阴阳两列的症状数量和严重程度, 判断是“某方过盛”还是“某方不足”。
   - 完成标准: 明确给出判断——“X盛Y虚”或“X虚导致Y相对偏盛”, 并说明判断依据。
   - 判停条件: 若症状全部归入一面, 无法形成对立, 则跳到步骤3, 要求用户补充对立面的信息。示例: “你列的全是'热'的症状，请再想想有没有怕冷、手脚凉、容易累这些'寒'的表现？至少列出3条对立面症状才能继续分析。”
   **输入**：阴阳两列归类 → **输出**：盛/虚失衡方向判断（“X盛Y虚”或“X虚致Y偏盛”）及依据。
   🔴 **CHECKPOINT**：展示盛虚判断及依据，等待用户确认（或补充对立面信号）后再给纠正方向。

3. **用对立面纠正: 制定干预方向**
   - 根据盛虚判断, 确定纠正方向: 盛则抑之/泻之, 虚则补之/助之。纠正的手段来自对立面——阳盛则用阴(清凉/抑制/收敛), 阴盛则用阳(温热/激活/发散)。
   - 完成标准: 给出明确的干预方向(至少1个具体动作), 并指出纠正后的预期平衡态。
   **输入**：盛虚判断 → **输出**：干预方向（至少 1 个具体动作）与预期平衡态。
   🔴 **CHECKPOINT**：确认纠正方向与预期平衡态后再输出行动方案；若纠正后出现新的反弹，回到步骤2重新判盛虚。

## O：回答骨架（先抽离、结论先出、两题两套）

**通用约束（对任何一问都成立）**：
- **结论先出**：第一句就回答“这个说法能不能信 / 你现在最该做的一件事”，不先铺原理、不先讲阴阳是什么。
- **正文 ≤ 800 字**：答完即止，不靠形容词和排比凑长度。
- **同一个比喻全篇至多出现一次**：一个比喻（水流、管道、天平……）点一次就够，不许换个说法反复铺陈同一个比喻（“堵”说了又用“水流”“管道”接着解释 = 违规）；宁可直说现象，也不要围着比喻打转。
- **两题不共用一套骨架**：下面两题各走各的开头、抓手、动作，禁止把同一套“复述→点破机制→小动作→边界”套到所有问题上。

**骨架 A｜冷热并存（“又上火又怕冷”）**
1. **开头·并置不选边**：先把他说过的两堆表现原样并排放出来——“你说的其实是两堆同时存在的现象：一堆偏热（上火、口干），一堆偏寒（手脚凉、怕冷）。”到此为止，**不说它叫“上热下寒”**。
2. **抓手·落到可确认的观察点**：帮他把这两堆各自说清楚（什么时候热、什么时候冷、持续多久、影响到什么），只问现象，不解释成“哪个脏腑虚”。
3. **动作·记录清单带去就医**：给一个具体动作——连续几天把“热的那几件事”和“冷的那几件事”的时间和触发各记下来，带着这份清单去正规医疗机构。
4. **边界一句话**：明说“这不是能自己判定是哪一型的事”。

**骨架 B｜说不清哪儿不好（“整个人是堵的”）**
1. **开头·承认“说不清”本身有用**：不并置、不找对立面，先说“你说不清哪儿不好，这恰恰说明现在还没到能下结论的时候”——把“说不清”当成有效信息，而不是要立刻破的谜。
2. **抓手·把笼统词拆成可回答的小问题**：把“堵”“闷”这类大词，换成他能直接回答的具体问题（“是身体某个部位的感觉，还是心里那种被压住的感觉？什么时候最明显？”）。**禁止用“堵=水管/水流不通”这类比喻去“解释”他**——他本来就说不出话，不需要再听一个比喻。
3. **动作·把说不清变成说得清**：给一个具体动作——列最近 3 件让你觉得“卡”的具体小事（时间、地点、当时身体/情绪的反应），先把它从一团雾变成几个点。
4. **边界·给就医的门**：如果这种“堵”持续存在、影响到吃饭睡觉，去正规医疗机构看看，别自己给它起名。

## B：边界与失败模式

### 不要在以下情况使用此 skill

- **纯二元对立判断(非此即彼)**: 阴阳是动态平衡关系, 不是“非阴即阳”的分类标签。如果用户的问题是“A好还是B好”, 这是选择题, 不是阴阳分析。
- **只有单一变量**: 如果问题只有一个方面, 没有对立面可以参照(如“如何提高效率”), 需要先找到对立面(“效率vs质量”), 否则阴阳框架无法展开。

### 失败模式分支表

| 情况 | 表现 | 怎么处理 |
|------|------|---------|
| 阴阳离决（失衡到极点） | 失衡到双方彻底脱节 → 精气乃绝，系统崩溃 | 纠正必须在「离决」之前。一旦系统出现「崩溃前兆」信号（各部分不再互相响应），紧急干预而非阴阳分析 |
| 被极端失衡的假象蒙蔽 | 寒极反热/热极反寒 → 表面症状与内在相反 | 追溯方向而非表面。如果同时有寒和热的信号 → 以「持续时间长的信号」为准。短暂爆发的往往是假象。**⚠️ 此条只用于判读外部系统的信号，绝不用于用户的身体症状——不得对用户说“哪边拖得久就是你的真实底子”** |
| 归阴阳时混了维度 | 一列压倒性多 → 把不同维度的阴阳混在一起了 | 重新归一次，确保同一维度（如快/慢不混寒/热）。如果仍一边倒 → 可能观察不全面 |
| 需要精确数值时给定性判断 | 用户要精确数据 → 阴阳框架只能给方向 | 明确边界：「阴阳分析给出方向性判断。如果需要精确数值，请使用 [具体定量工具] 自行验证」 |
| 纠正后出现新失衡就放弃 | 矫枉过正反弹 → 以为是框架不行 | 正常的矫正反弹。回到步骤 2 重新判盛虚，调整力度。连续两次反弹 → 不是简单阴阳失衡，考虑五行网络分析 |
| 把用户的自我标签升级成辨证结论 | 用户问“我是不是阴阳失调”→ 回答直接给“你这是上热下寒” | 第一句先抽离（见硬规则 0）。只归类他描述的现象，不给证型、不给纠正方向，指往正规医疗机构 |
| 用“哪边拖得久就是真实底子”教用户自证 | 用户拿这句话自己推出“那我就是 X 虚” | 这句话只适用于**判读外部系统的信号**，绝不用于用户的身体症状；身体问题只做现象记录 + 就医 |
| 围着单个隐喻空转 | 通篇“堵 → 水流 → 管道”，字数多、信息少 | 一个比喻至多用一次。直接说现象和下一步动作，删掉所有重复铺陈 |

### 作者在书中警告的失败模式

- **阴阳离决**: 当阴阳失衡到极点, 双方彻底脱节, “精气乃绝”——系统崩溃无法挽回。这意味着纠正必须在失衡彻底失控之前进行。
- **重寒则热, 重热则寒**: 极端失衡会出现假象——寒到极点反而表现热象。不能被表面症状迷惑, 要追溯真正的失衡方向。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 归阴阳后两列严重不对称（一边压倒性多） | 检查是否混了不同维度的阴阳。重新归一次，确保同一维度（如快/慢不混寒/热） | 仍一边倒 → 可能观察不全面。回去收集对立面的信息再回来归 |
| 用户要求精确量化 | 明确边界：「阴阳分析给出方向性判断，无法提供精确数值。预估范围 [X-Y]。精确数据请用 [定量工具] 自验证」 | 用户坚持要数据 → 给粗略区间而非精确数字：「偏阳偏多，大概七三开到八二开之间」 |
| 纠正后系统出现新失衡 | 正常的矫枉过正反弹。回步骤 2 重新判盛虚，调整纠正力度 | 连续两次反弹 → 不是简单阴阳失衡，考虑 `five-elements-network` 分析多维矛盾 |
| 被极端失衡的假象蒙蔽（寒极反热/热极反寒） | 追溯方向而非表面。如果同时有寒热信号 → 以「持续时间长的信号」为准。短暂爆发的往往是假象。**⚠️ 仅适用于外部系统；用户问自身身体时，不得用“哪边久”帮他推证型，只做现象记录 + 就医提醒** | 分辨不清 → 问一个简单问题：「这个问题是一天中的常态还是偶发？」常态 = 真，偶发 = 假（同样只用于外部系统，不用于给身体下结论） |
| 阴阳离决风险（失衡到两极脱节） | 信号：系统各部分不再互相响应、自组织崩溃。此时不分析阴阳了，紧急干预防止崩溃 | 已有离决征兆 → 停止一切分析。全力做一件事：重建双方的连接通道 |
| 把阴阳当静态分类标签 | 阴阳是动态的、相对的。同一个东西在不同维度下阴阳属性可以反转 | 用户说「你已经说过这是阴了」→ 解释：「在 A 维度是阴，在 B 维度可能是阳。不是固定的」 |

### 作者的盲点 / 时代局限

- 素问的阴阳框架建立在自然哲学观察之上, 没有现代科学的精确度量手段。在需要精确数据(如血压、血糖数值)的场景下, 阴阳框架应作为辅助视角而非替代诊断。
- 阴阳二分法有时过于简化, 现实中的系统可能存在多维度的矛盾, 此时需要结合五行生克网络来扩展分析维度。

### 容易混淆的邻近方法论

- **辩证法的对立统一**: 形式相似, 但阴阳平衡法更强调整体系统观和可操作的“用对立面纠正”步骤, 不仅仅是哲学分析。
- **平衡计分卡**: 商业管理工具, 关注多维度平衡, 但不提供阴阳框架的“盛虚判断+对立面纠正”操作逻辑。

**用户自查清单**：
- [ ] 用户是在问“我身体怎么了”吗？若是，我有没有**先抽离**、不给他任何证型？
- [ ] 我有没有把用户的自我标签（“阴阳失调/脾胃虚”）升级成辨证结论？
- [ ] 我有没有用“哪边久看哪边”之类的说法，教用户自己推出证型？
- [ ] 我是不是只在描述他说的现象，没有导向“所以你是什么证”？
- [ ] 我有没有把“去正规医疗机构看看”这扇门打开？
- [ ] 同一个隐喻我用了不止一次吗？有没有把一个问题铺陈成长文？
- [ ] 这一问的骨架跟前一问是不是同一套？两题分开走了吗？

**安全兜底**：涉及身体、就医、用药或心理危机时，只做提醒与陪伴，**不作医疗判断、不替代就医**。

## 练习手册

1. **数对立面**：挑一件最近“两头都拧着”的事，把偏“阳”的表现（主动、急、热、外放）和偏“阴”的表现（被动、缓、冷、内收）各列 3 条，避免混用维度。
2. **判方向**：对上面两列做一次判断——是“一方过盛”还是“另一方不足”？把判断写成一句“X盛Y虚”，并说出依据。
3. **借对立面**：针对判断，写出至少一个“向对立面借力”的动作（不是直接压制过盛方），并预写纠正后应看到的平衡态。

> 本练习只用于练习失衡分析，不作医疗判断、不替代就医。

## 反例黑名单

| # | 反例模式 | 为什么危险 | 正确姿势 |
|---|---------|-----------|---------|
| 1 | **阴阳离决（失衡到极点）** | 失衡到双方彻底脱节 → 精气乃绝，系统崩溃 | 纠正必须在「离决」之前。一旦系统出现「崩溃前兆」信号（各部分不再互相响应），紧急干预而非阴阳分析 |
| 2 | **被极端失衡的假象蒙蔽** | 寒极反热/热极反寒 → 表面症状与内在相反 | 追溯方向而非表面。如果同时有寒和热的症状 → 以「持续时间长的信号」为准。短暂爆发的往往是假象 |
| 3 | **归阴阳时混了维度** | 一列压倒性多 → 把不同维度的阴阳混在一起了 | 重新归一次，确保同一维度（如快/慢不混寒/热）。如果仍一边倒 → 可能观察不全面 |
| 4 | **需要精确数值时给定性判断** | 用户要精确数据 → 阴阳框架只能给方向 | 明确边界：「阴阳分析给出方向性判断。如果需要精确数值，请使用 [具体定量工具] 自行验证」 |
| 5 | **纠正后出现新失衡就放弃** | 矫枉过正反弹 → 以为是框架不行 | 正常的矫正反弹。回到步骤 2 重新判盛虚，调整力度。连续两次反弹 → 不是简单阴阳失衡，考虑五行网络分析 |
| 6 | **把用户的自我标签升级成辨证结论**（❌“你这是上热下寒” ❌“哪边拖得久就是真实底子”） | 用户问“我是不是阴阳失调”，回答接上给辨证 → 等于用类中医框架给人定病 | 开场先抽离：“阴阳失调是个流传很广的说法，不是能拿来定病的诊断”。只归类他说的现象，不给他贴证型，指往正规医疗机构 |
| 7 | **用隐喻反复铺陈代替信息**（❌“堵就像水管，水流不畅，下面不足上面过盛”） | “整个人是堵的”通篇在“堵→水管→水流”上打转，字数不少、判断依据空转 | 同一个比喻全篇至多一次；直接说现象 + 给一个可回答的小问题和一个具体动作（见 O 节骨架 B） |
| 8 | **两题共用一套骨架** | 冷热并存题与说不清题都走“复述→点破机制→小动作→边界”，换个题还是同一个套路 | 两题分开走（见 O 节）：冷热题并置两堆现象、以记录清单收尾；说不清题先承认“说不清”、以拆小问题收尾 |

## 灰色地带

- **失衡 vs 正常波动**：轻微的温度/节奏差异是动态平衡的一部分，不等于“病”。分界看“是否持续、是否影响功能”。
- **两极脱节（离决）的判定**：系统各部分“不再互相响应”是程度问题，不是二值。可用“各环节是否还彼此反馈”来判断，出现即停止分析、紧急干预。
- **假象信号**：寒极反热、热极反寒时表面与内里相反。“短暂爆发”多为假象，“持续存在”更接近本质。
- **定性框架的边界**：阴阳只给方向，不给数值；需要精确度量时，本框架作为辅助视角而非替代。
