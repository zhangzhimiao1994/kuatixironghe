# 滴天髓闡微·六親論：夫妻·子女·父母·兄弟·何知章·女命章·小兒·才德

**来源**：sources/ditianxu.txt（《滴天髓闡微》六親論，L2890–3911） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户问子平里「妻、子、父、母、兄、弟」这六亲各自拿哪个星来定。
- 用户读到「生我者为父母，偏正财星是也；我生者为子女，食神伤官是也」不懂，问为什么这样更定。
- 用户问「以财为妻」和「以财为父」两种旧说哪个对、书上怎么辩的。
- 用户问何知章「何知其人富？财气通门户」「何知其人贫?财贫神反不真」这一类问答怎么读。
- 用户问「喜神看与杀相连」「子女根枝一世传」是讲什么。
- 用户问「论夫论子要安样」（女命章）或「德胜才者，局合君子之风」（才德）在说什么。

**不应触发**：
- 用户问的是奮鬱、恩怨、閒神 → 转 bazi-ditian-fen-yu-en-yuan。
- 用户问的是從象·化象·假從·假化·順局·反局·戰局·合局·君象臣象母象子象 → 转 bazi-ditian-cong-hua-ju。
- 用户问的是性情·疾病·出身·地位·歲運·貞元 → 转 bazi-ditian-xing-qing-ji-bing。
- 用户要本 skill 判某人的婚姻成败、子息有无、父母存殁或寿命 → 本 skill 不接，只讲书里怎么取象。
- 用户手里只有一句「我属虎、今年婚姻怎样」，没有四柱 → 先按 bazi-hub 的硬闸门走，缺柱不排。

## I：核心解释

六親論这一块，头一件事不是「断」，而是**定六亲各归哪个星**；星定错了，后面所有的取象都错。本书先给出「更定」的分配法（R2），再用夫妻、子女、父母、兄弟四篇分别讲取用活法，最后以何知章的问答、女命章、小儿、才德收束。

1. **六亲定星（任注的更定）**：「生我者为父母，偏正财星是也；我生者为子女，食神伤官是也。」（R2）同段还给出「我克者为妇妾……同我者为兄弟」（即我克为财、同我为比劫）。这是本书对旧说「以财为父、以官为子」的更正——它先讲理由：若财为父、官为子，则「父反以子管治」，于伦常有碍。
2. **夫妻取财星，但要看喜神**：首句「夫妻因缘宿世来，喜神有意傍天财」（R1）——看妻在财星，而财星是否得力要看它是不是喜神、财神。原注给了活法：财弱用助财、财旺身弱喜比劫、财伤印要官星之类。
3. **子女先立两说，再通变**：原注按旧法「大率依官看子」（R3），任注则更定「以食伤为子女」（R5），并说这只是「先将食伤认定」，再「看日主之衰旺，四柱之喜忌」；所以又落到「大率身旺财为子，身衰印作儿」（R6）这条通变的总纲。子女篇的两句经文正是提醒「依官」还是「依食伤」要活看（R4）。
4. **父母看岁月**：「父母或降与或替，岁月所关果非细」（R7）——父母之象关在年月两柱（岁与月），看的是这两柱对日主是喜是忌、对喜神是护是伤。
5. **兄弟看比劫禄刃，与提纲财神较轻重**：「兄弟谁废与谁兴，提用财神看重轻」（R8）——比肩、败财、禄、刃都算兄弟，要与月令提纲之神和财神喜神较轻重。
6. **何知章是「以喜忌通门户」的连环问答**：富贵贫贱吉凶寿夭各配一句口诀，其共同的抓手是**财官能不能「通门户」、喜忌能不能各得其所**。「何知其人富？财气通门户」（R9）、「何知其人贵？官星有理会」（R10）为正例；「何知其人贫?财贫神反不真」（R11）等为反例。任注把这条收成一句：「以忌神为病，以喜神为药，有病有则吉，有病无药则凶」（R14）。
7. **寿夭两句仍归「性定」「气浊」**：「何知其人寿？性定元神厚」（R15）讲的是四柱安顿和平、元神厚；「何知其人夭？气浊神枯了」（R16）讲的是气浊神枯那一类结构。这两句是书里对结构的读法，不是对某人的寿数判决。
8. **女命章与男命同理，夫星＝用神、子星＝喜神**：「论夫论子要安样，气静平和妇道章」（R17），并明说「不可专论官星为夫、伤食为子」（R18）。它顺手否掉了「三奇二德」「咸池驿马」这类说法。
9. **小儿看「四柱和平、气势攸长」**：「论财论杀论精神，四柱和平易养成，气势攸长无削丧，杀关虽有不伤身」（R19）——重点在四柱和平、行运不逢削丧，而不是所谓「关杀」。
10. **才德分「德胜才」与「才胜德」**：「德胜才者，局合君子之风；才胜德者，用显多能之象」（R20）——用「阳在外／阴在内」之类的清浊正邪取向来分两象。

## A1：来源应用

书上给的做法，都是绕「定星 → 看喜忌 → 较轻重」三件事：

- **先定星再论**：夫妻看财星、子女看食伤（并经「身旺财为子，身衰印作儿」通变）、父母看年月、兄弟看比劫禄刃。定星这一步照 R2、R3、R4、R7、R8 抄，不自己按五行生剋另立。
- **财星（妻）的活法**：原注交代「财神薄，须用助财；财旺身弱，又喜比劫；财神伤印者，要官星；财薄官多者，要伤官」——同一颗财星，随日主衰旺与四柱配合换处理方式。
- **食伤（子女）的活法**：任注先「将食伤认定」，再看「日主之衰旺，四柱之喜忌」定夺；同段还给了「日主旺，无印绶，有食伤，子必多」这类一排对照句。
- **年月（父母）的取舍**：原注说「岁气有益于月令者，及岁月不伤夫喜神者，父母必昌」；任注又列了「年月官印相生，日时财伤不犯」等一排对照，落点在年月对日主是喜是忌。
- **比劫（兄弟）的取舍**：原注说「要在提纲之神，与财神喜神较其重轻」，并分了「财官弱，三者显其攘夺之迹，兄弟必强」等几层。
- **何知章的读法**：把「富、贵」当作财官通门户的正例，把「贫、贱」当作财神不真、官星不见的反例；「吉」看喜神为辅弼（R12）、「凶」看忌神辗转攻（R13）；任注统一到「以忌神为病，以喜神为药」（R14）。
- **女命章的读法**：先「安样」，即取「气静和平」为贵，夫星子星随用神喜神取，不搬「三奇二德」「咸池驿马」（R17、R18）。
- **评价语提醒**：这一块原书用了大量断语，如「克妻」「无子而绝」「多女」这类（见夫妻、子女诸命例）。这些是**书里的说法**，引用时要标明；本 skill 不准把它落到具体人身上。

**书里没有的、不要加**：原书论六亲只讲定星与取用活法，不讲后世流派的各种「六亲宫位打分」「喜用神自动判法」；这些都不进本 skill。

## E：执行步骤

1. **确认问的是哪一亲、哪一篇**　输入：用户的话与所引句子 → 输出：判定落在夫妻／子女／父母／兄弟／何知章／女命章／小儿／才德哪一处。
   🔴 **CHECKPOINT**：若问的是奮鬱恩怨閒神或從化局，或性情疾病出身地位岁运贞元，先说明本 skill 只管六親論这一块，并指到对应 skill。
2. **定星并给出处**　输入：所问的那一亲 → 输出：照 R2 给六亲定星法，并标明是「任注的更定」还是「原注的旧法」。
   🔴 **CHECKPOINT**：定星只报星名不出处（如只说「子女看食伤」不讲出自哪一篇、是经是注），退回补齐。
3. **讲取用活法**　输入：定好的星 → 输出：按对应篇的原注／任注给活法（如夫妻财星的助财／喜比劫）。
   🔴 **CHECKPOINT**：抄的是书里的活法，不是自己按五行生剋现推的。
4. **何知章按「通门户／喜忌」收**　输入：用户所问的口诀 → 输出：正例配 R9／R10，反例配 R11，总纲配 R14。
5. **标评价语**　输入：篇中出现的断语 → 输出：把「克妻」「无子」「夭」这类标成「书里的说法」。
   🔴 **CHECKPOINT**：确认没有把书里的断语说成对眼前这个人的判决。
6. **收口**　输入：整段推演 → 输出：一句定星 + 一句取用活法 + 一句出处；结尾说明本 skill 到取象为止，不接婚姻／生育／寿夭的判定。
   🔴 **CHECKPOINT**：用户若给了四柱要「判六亲」，照实说本 skill 不做落人身的判定；缺柱则说要补什么。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把夫妻星当婚姻判决 | 由财星旺衰直接说「你婚必败」 | 拉回 R1 与原注：只讲财星作妻星的取象与活法 |
| 子女两说混用不标 | 一会「官为子」一会「食伤为子」却不分经注 | 分清原注的旧法与任注的更定（R3、R5），再给通变（R6） |
| 缺柱硬算六亲 | 只有一句「我属牛」就断兄弟几人 | 停下，说缺哪柱、要到什么程度才能排 |
| 把书里断语当事实 | 说用户「一定无子」或「一定克妻」 | 标明那是书里的说法，不落到具体人身上 |
| 越过范围断寿夭 | 由「气浊神枯」顺手判某人寿数 | 收口在取象，不判生死寿夭 |

**边界规则**：
1. 只做六親論这一块的取象讲解，不替用户判六亲吉凶落到具体人身上。
2. 只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 经文与原注／任注必须分栏标注；报星必须给出处。

## 灰色地带

- **用户引「以财为父」的旧说**：原书本是**否定**这一说的（任注明说「又以财为父者，乃后人谬也」）；照实讲书里的辩驳与「更定」，不替旧说圆场。
- **用户既问取象又要「看我这一盘」**：取象照讲，落人身的判定说明本 skill 不接，并说缺柱要补什么。
- **同一条断语在不同命例里说得不一样**：书里对同一结构的评价常有出入，据实并列，说明是书里各例的说法，不替用户挑一条拍板。
- **用户把「才德」当作人品评判**：才德两象讲的是四柱清浊正邪的取向，不是给某个人品评分；照实说明。
- **女命章里带古时妇道语**：照实说明这是书中所处时代的用语，本 skill 只取它对夫星子星的取象法，不搬它的褒贬。
