# 吉凶神與生克先後（《子平真詮》篇十八至二十二）

**来源**：sources/zipingzhenquan.txt（《子平真詮》十八·論四吉神能破格／十九·論四凶神能成格／二十·論生克先後分吉凶／二十一·論星辰無關格局／二十二·論外格用舍） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

- 用户问「煞伤枭刃是凶神，怎么还能成格」，想知道凶神在什么情形下反而做正事。

8. 是以格局既成，即使满盘孤辰入煞，何损其贵？格局既破，即使満盘天德贵人，何以为功？（《子平真詮》二十一·論星辰無關格局）

## I：核心解释

篇十八到二十二是一条线：先把「吉神／凶神」这层名目的成见拆掉，再说清成破在哪里分，最后把「星辰」「外格」两样容易喧宾夺主的东西按回月令之下。每一条都能追回上面的原句。

1. **吉神会破格**。书里先拆成见：「财官印食，四吉神也，然用之不当，亦能破格」（R1）。它举四类——食神带煞而透财、春木火旺而见官、煞逢食制而透印、财旺生官而露食，都是「吉神」做坏了事。一句收口：「吉凶喜忌，全在是否合于需要，不因名称而有分别也」（R2）——吉凶不挂在名字上，挂在合不合这一个盘的需要上。
2. **凶神也能成格**。反面同理：「煞伤枭刃，四凶神也，然施之得宜，亦能成格」（R3）。印绶根轻透煞为助、财逢比劫取伤官解、食神带煞得枭、财逢七煞得刃，四样都是「凶神」在做正事。收口一句「财不忌伤，官不忌枭，煞不忌刃……施之得宜，可以戡乱」（R4）：长枪大戟本非美具，用得对可以平乱。
3. **生克要分先后**。「月令用神，配以四柱，固有每字之生克以分吉凶」（R5）是一层；更难的一层是「同此生克，而先后之间，遂分吉凶」（R5）。书里拿正官同见财、伤举例（R6）：丁先戊后，财能解伤，纵不成贵局面也收得住；戊先丁后，财先生官、伤后破格，结局就差。同一组字，次序不同，读法不同。
4. **星辰管不了格局成败**。「八字格局，专以月令配四柱，至于星辰好歹，既不能为生克之用，又何以操成败之权」（R7）——本书记格局只认月令与四柱的生克，孤辰、天德、贵人之类只报吉凶的名目，不参与成败。所以「格局既成，即使满盘孤辰入煞，何损其贵？格局既破，即使満盘天德贵人，何以为功」（R8）。
5. **外格是「月令无用」时的权法**。「外格者，盖因月令无用，权而用之，故曰外格也」（R9）。反过来，「若月令自有用神，岂可另寻外格」（R10）；书里还抬出两句老话「提纲有用提纲重」「有官莫寻格局」当定论（R11）。更不许把「用神被破」误当成「月令无用」，弃月令而就外格。
6. **这一处两家不同（并陈，不调停）**：
   - 本书（篇二十一）：「至于星辰好歹，既不能为生克之用，又何以操成败之权」（R7），格局成败只看月令配四柱。
   - 《三命通會》卷十·巫咸撮要却把神煞写进吉凶断语，如「孤辰隔角重見者多主貧夭」「印臨天乙受盛世之封」。
   两说各标出处摆在一处：这一处两家不同，不选边、也不合成一句话；用户在某一本里读到的口径，就按那一本答。

把抓手收成一张表：

| 抓手 | 原书说法 | 落在哪儿 |
|---|---|---|
| 吉神破格 | 用之不当，亦能破格（R1） | 看合不合需要（R2） |
| 凶神成格 | 施之得宜，亦能成格（R3） | 凶神做正事（R4） |
| 生克先后 | 同此生克而先后分吉凶（R5、R6） | 读次序，不读死字 |
| 星辰 | 不能为生克之用，何操成败之权（R7、R8） | 不参成败 |
| 外格 | 月令无用才权用（R9–R11） | 有官莫寻格局 |

## A1：来源应用

书上给的做法，都落在「先认名目不是结论，再逐条核条件」这一条线上：

- **判吉凶先问合不合需要**：四吉神、四凶神只是名字，成破看「是否合于需要」（R2）；先找「谁在破谁、谁在成谁」，再断。
- **破格的四类要先认全**：食神带煞透财、春木火旺见官、煞逢食制透印、财旺生官露食（篇十八所列，与 R1 同段）——这四类可以直接对盘核。
- **成格的四类反过来认**：印绶根轻透煞、财逢比劫取伤、食神带煞得枭、财逢七煞得刃（R3）。
- **同一组字要读次序**：先财后伤与先伤后财两样（R5、R6）；正官格、印格、食神格、七煞格都各有先后之说（篇二十所列）。
- **神煞不问成败，只作名目**：星辰不作生克之用（R7、R8）；不拿孤辰、天乙去替月令论成败。
- **外格先问月令**：月令无取才权用外格（R9）；月令有取或干头已有财官，就不许另寻外格（R10、R11）。

**书里没有的、不要加**：本书这五篇不列神煞表，也没有「旺衰计分」「自动取喜用」「格局打分」这类后世做法；拿神煞清单或评分法来解释本篇的成败，是硬伤，一律不写。

落盘读法四步：
1. **输入**　用户给出四柱（或已排好的盘）＋ 本 skill 的条件。
2. **逐条核条件**　按书里要求逐项核：四吉神／四凶神各见几位、是透干还是支藏、生克是哪个先哪个后、有无破格或成格之神、星辰要不要算、月令可取还是「无用」（外格才可议）。
