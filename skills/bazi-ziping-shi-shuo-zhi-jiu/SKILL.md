# 論時說之病（子平真詮 篇 29–30）

**来源**：sources/zipingzhenquan.txt（《子平真詮》二十九·論時說拘泥格局／三十·論時說以訛傳訛） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／格局／命理／用神这一类词时，整行不显示、不激活。

**应该触发**：
- 用户问「八字用神专凭月令，月无用神，台寻格局」怎么读，「月令，本也；外格，未也」是什么意思。
- 用户问「今人不知轻重，拘泥格局，执假失真」错在哪里。
- 用户问书里举的那几例（戊生甲寅之月…以为专食之格、丙生子月…以为日禄归时之类）为什么不取外格而立外格。
- 用户问「如此谬论，百无一是，此皆由不知命理，妄为评断」是不是在骂专看格名的人。
- 用户问篇三十说的「八字本有定理，理之不明，遂生导端」指什么。
- 用户问篇三十那四样病（论干支、论格局、论生克、论行运）各针对什么做法。
- 用户问书里为什么说「以俗书体象歌诀为确论」「以拘泥外格为活变」「以伤旺扶弱为定法」是病。
- 用户问《子平真詮》与《三命通會》一路对着说的那些地方到底怎么摆。

**不应触发**：
- 用户问月令专求用神、成败救应、用神变化纯杂 → 转 bazi-ziping-yong-shen-zong-gang。
- 用户问外格用舍的正面取法、诸格分论 → 转本族对应篇目（如 bazi-ziping-ji-xiong-shen 含论外格用舍）。
- 用户问行运、成格变格 → 转 bazi-ziping-xing-yun。
- 用户问《三命通會》的格局总论、喜忌篇格名断语（bazi-sanming-ge-ju、bazi-sanming-xi-ji-pian）之正文 → 转该 skill；本篇与那一路有对着说处，由本 skill 并陈、各标出处。
- 用户要按某人生日报流年大运、断终身寿夭、判疾病生育、替人定婚姻职业 → 本族不接。
- 用户没提八字词，只说「网上算命很乱」 → 泛化词，不激活。

## R：原文锚点

*引文说明：下面每条逐字抄自 sources/zipingzhenquan.txt 二十九、三十两篇，异体字与标点照原样（含原文作「台寻格局」者）；每条后括注篇名。书里的「谬论」「害人不浅」这类评价语只作书里的说法录下，不作对具体之人的判决。*

1. 八字用神专凭月令，月无用神，台寻格局。月令，本也；外格，未也。（《子平真詮》二十九·論時說拘泥格局）
2. 今人不知轻重，拘泥格局，执假失真。（《子平真詮》二十九·論時說拘泥格局）
3. 如此谬论，百无一是，此皆由不知命理，妄为评断。（《子平真詮》二十九·論時說拘泥格局）
4. 八字本有定理，理之不明，遂生导端，妄言妄听，牢不可破。（《子平真詮》三十·論時說以訛傳訛）
5. 如论干支，则不知阴阳之理，而以俗书体象歌诀为确论（《子平真詮》三十·論時說以訛傳訛）
6. 论格局，则不知专寻月令，而以拘泥外格为活变（《子平真詮》三十·論時說以訛傳訛）
7. 论生克，则不察喜忌，而以伤旺扶弱为定法（《子平真詮》三十·論時說以訛傳訛）
8. 论行运，则不问同中有导，而以干支相类为一例。（《子平真詮》三十·論時說以訛傳訛）

## I：核心解释

这两篇是「批评篇」：篇二十九骂「拘泥外格」，篇三十骂「以讹传讹」的四样病。它们不是另立一套取用法，而是先把病指出来。每一条都能追回 R 节。

1. **本与末：月令是经，外格是权**。篇二十九先给判据：「八字用神专凭月令，月无用神，台寻格局。月令，本也；外格，未也」（R1）。意思是取用神首看月令；只有月令确实无可取时，才退而取外格。离开月令去就外格，是把本末倒过来。
2. **病在「拘泥」二字**。「今人不知轻重，拘泥格局，执假失真」（R2）——书里反对的不是用格，而是死抱格名：明明是月令可用之神，偏要判成某个外格。篇二十九随后连举数例，如戊生甲寅之月、时上庚甲，本是明煞有制，却判成专食之格；丙生子月、时逢巳禄，本可作正官之格而归禄帮身，却判成日禄归时。这些都是「不知轻重」。
3. **总评是一句重话**。篇二十九收在「如此谬论，百无一是，此皆由不知命理，妄为评断」（R3）。这句语气很重，是书里的评价语，用作对一类做法的批评，不当对某个具体的人的判决。
4. **篇三十先立总纲再列四病**。篇三十开篇说「八字本有定理，理之不明，遂生导端，妄言妄听，牢不可破」（R4）——理先不明，讹才会传开。接着列四样病：论干支不讲阴阳之理，把俗书体象歌诀当确论（R5）；论格局不知专寻月令，把拘泥外格当活变（R6）；论生克不察喜忌，把「伤旺扶弱」当定法（R7）；论行运不问同中之异，把干支相类当一例（R8）。
5. **四病各有所指**。R5 针对的是拿「大林木、微苗」这类体象歌诀当断命确论的做法；R6 与篇二十九同调，针对舍月令而逐外格；R7 针对不看喜忌、见弱便扶的定法；R8 针对行运不分干支差异、混为一谈。四句合起来，等于把「只认格名与歌诀、不看月令与喜忌」这一路全点了名。
6. **篇三十后半用命例佐证**。篇三十又说世间流传的命例往往被误收误改：如「壬申、癸丑、己丑、甲戌」本为杂气财旺生官，却有人以为乙亥时、作时上偏官；「己未、壬申、戊子、庚申」本为食神生财，却有人欲弃月令、以为戊日庚申合禄之格。书里把这类叫「误收格局」「硬入外格」。

**与三命通會那一路「对着说」的地方（两说并陈，各标出处）**

这一支最要紧的就是这一节——本 skill 不替两家调停、不合成一句。

- **本说（《子平真詮》二十九、三十）**：取用神「专凭月令」，「月令，本也；外格，未也」；斥「拘泥格局，执假失真」（R1、R2）；把「以俗书体象歌诀为确论」「以拘泥外格为活变」「以伤旺扶弱为定法」都列为病（R5、R6、R7）。出处：本 skill R 节。
- **那一路（《三命通會》）**：以格名为纲立说，卷五·論古人立印食官財名義立「四纲六格」、卷五·論雜氣以「杂气财官」立格，卷十·巫咸撮要、卷十一·喜忌篇给出带格名的总断语（如「入格者非富即贵」这类），并以卷二·論天干隂陽生死等「体象」立论。出处：《三命通會》卷五、卷十、卷十一、卷二（本族见 bazi-sanming-ge-ju、bazi-sanming-xi-ji-pian、bazi-sanming-tian-gan）。
- **摆法**：先说本说的原话与出处，再说那一路的做法与出处，直说「这一处两家不同」——一家要「专凭月令、不泥格名」，一家「以格名为纲、以体象立论」。**不选边、不合成一句**；把张力摆出来，判断留给用户。（引文一律只从本 skill 的源文件抄；那一路的具体文句到它自己的 skill 里读。）

## A1：来源应用

书里给的做法，围着「先把月令看够，再谈要不要退而取外格」这一条线：

- **先看月令可取不可取**：篇二十九的判据是「用神专凭月令」（R1）；月令确有可用之神，就不另寻外格。
- **核是不是「拘泥」**：拿一个被断成外格的盘，回头问一句——月令真的无神可取吗？书里举的戊生甲寅、丙生子月诸例，都是在指出「本可不用外格而强判外格」（R2）。
- **四病当检查表用**：篇三十的四句（R5–R8）可以当四项自检——论干支有没有落到阴阳之理（不是背歌诀）；论格局有没有专寻月令；论生克有没有先察喜忌（不是见弱便扶）；论行运有没有辨同中之异。
- **不拿命例当定式**：篇三十提醒流传命例常有误收误改（如被改时柱、被硬入合禄），所以拿书上某个命例来套，要当「书里所载」看，不当铁例。
- **两说各标出处、不合并**：凡本书记法与三命通會那一路不同处（尤其篇二十九、三十），照上节摆两说，不选边。

**书里没有的、不要加**：这两篇是批评，不是新的取用口诀；本书没有给「外格打分」「格局权重」这类后世做法，也不许拿现代流派的评分法来解释「拘泥与否」。

## A2：典型触发场景

1. 用户读到「月令，本也；外格，未也」，问取用神到底要不要先看外格。
2. 用户拿着一个被断成外格（如日禄归时、专食之格）的盘，问书里认不认。
3. 用户问「如此谬论，百无一是」是不是说专看格名的人全错。
4. 用户问「以俗书体象歌诀为确论」到底错在哪，歌诀还能不能用。
5. 用户问「以伤旺扶弱为定法」为什么是病，那不扶弱该看什么。
6. 用户拿书里某个命例（如壬申癸丑己丑甲戌）问为什么会被判错。
7. 用户发现《子平真詮》与《三命通會》在格局上说法相反，问该听哪一家。

## E：执行步骤

本 skill 主活是**落盘读法**；判据是**输入里有没有四柱或出生信息**——给了四柱走落盘，只问出处或句义走文本解读。

1. **分问法**　输入：用户的话与所引句子 → 输出：判定走哪条路。
   - **只问「书里这句什么意思／这一篇专门讲什么」** → 走**文本解读**：认句归篇、摆条件，不必落盘；末尾补一句「给我四柱就能照书读一遍」。
   - **问「我这盘怎么看」且给了四柱或出生信息** → 走**落盘读法**（下四步）。
   - 给了四柱而用户只问出处 → 仍按文本解读答，不硬塞落盘。
   🔴 **CHECKPOINT**：缺年／月／日／时任一柱或缺出生地，照实说缺什么、要到什么程度才能排，**不用占位信息硬排**；时刻只到时段（如「辰时」）时，时柱按该时段整体给，标明「时段内不唯一」。
2. **① 输入四柱**　输入：用户的四柱（或已排好的盘）＋本 skill 的条件 → 输出：把日主、月令、月令所藏与透出、被误判的那个「外格名」列出来。
   🔴 **CHECKPOINT**：这一步只摆材料，不下断语；排盘与藏干是可核的，判「拘泥否」是判读，要回到条文。
3. **② 逐条核条件**　输入：上一步的材料 → 输出：逐项对照书里的条件——**月令可不可取**（月令有无可用之神，R1）；**是不是舍月令就外格**（本可取月令而强判外格者，即书里所斥的「拘泥」，R2、R6）；**所立格名属哪一路**（是月令正格，还是日禄归时、专食、合禄一类外格）；**有没有踩到四病**（拿歌诀当确论、不察喜忌见弱便扶、行运不辨同异，R5、R7、R8）。每一项都写明「满足到哪一步」。
   🔴 **CHECKPOINT**：不许拿可核的计算当结论；判「拘泥」必须指到 R2、R6。
4. **③ 输出一句读法＋出处**　输入：逐条核的结果 → 输出：「按书里这一类读，偏 X」＋**出处**（《子平真詮》某篇）。例如「按篇二十九这一类读，偏于月令本有可取之神，不当另就外格（《子平真詮》二十九·論時說拘泥格局）」。若用户问的正是与《三命通會》的异同，则**两说各标出处并陈**，不合成一句。
   🔴 **CHECKPOINT**：报任何格局或用神必须给出**原书依据（哪一篇）**与**取用条件（凭什么这么取）**两句；只报一句不合格。涉及两家不同处，必须两边都标出处。
5. **④ 收口**　输入：整段推演 → 输出：一句收尾，写明**不应期、不断终身、不落寿夭疾病生育、不替用户决定**——「本篇只读到月令与外格的轻重、以及时说的几样病这一层，不批流年大运、不断终身、不判寿夭疾病生育，也不替你决定婚事职业」。
   🔴 **CHECKPOINT**：收口前确认没有滑到流年大运、寿夭、婚姻上去，也没把「谬论」「百无一是」当成对用户的事实。

**交付口径**：逐步把推演展示出来，结论速览放最前但不得代替推演；一步之中的依据尽量引用户的问法或所给四柱。需要成表的内容走平台原生的表格消息，不把 markdown 表格塞进正文。

## 练习手册

- **本末对读**：把 R1 抄下，各写一句「月令为本」「外格为末」在这一篇里各指什么。
- **四病归位**：照 R5–R8，把「以俗书体象歌诀为确论／以拘泥外格为活变／以伤旺扶弱为定法／以干支相类为一例」分别归到「论干支／论格局／论生克／论行运」四项下（不看书）。
