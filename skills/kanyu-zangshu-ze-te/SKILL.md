# 择其特：众山之中取哪一个

**来源**：《葬書》（舊題郭璞）外篇 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户面对一片并列的山，问「这么多座，到底该取哪一座」；
- 用户直问「是不是最高、最显眼的那座才作数」；
- 用户读到「大则特小、小则特大」，要把它落到自己看到的一片山上；
- 用户问「参形杂势、主客同情是什么意思，会不会我这片山就是这样」；
- 用户说「那几座山大小差不多，我分不出哪座是主」。

**不应触发**：
- 用户问的是「一座山本身的支垄体认」→ 转 `kanyu-zangshu-zhi-long-bian` 或 `kanyu-zangshu-zhi-e-long-lu`；
- 用户问的是「这块已定的地废没废」→ 转 `kanyu-zangshu-shen-fei-ze-xiang`；
- 用户问的是「乘金相水、穴土印木怎么定穴」→ 转 `kanyu-zangshu-si-fa`；
- 用户问的是「这片山是干龙还是枝龙、来龙从哪来」→ 属撼龍經的体系，另调 `kanyu-hanlong-gan-zhi-long`；
- 用户要的是「就选那座、去那里下葬」的现场指令 → 不接，本 skill 只做文本层的取舍归类。

## R：原文锚点

1. "夫重岡疊阜，群城眾支，當擇其特。"（《葬書》外篇）
2. "聖人之于民類，麒麟之於走獸，鳳凰之於飛鳥，亦類也。"（《葬書》外篇）
3. "重岡並出，群阜攢頭，須擇其毛骨廳秀、神氣俊雅之異於眾者為正也。"（《葬書》外篇，《錦囊》注）
4. "大則特小，小則特大。"（《葬書》外篇）
5. "眾山俱小，取其大；眾山俱大，取其小。"（《葬書》外篇，《錦囊》注）
6. "參形雜勢，主客同情，所不葬也。"（《葬書》外篇）
7. "參形雜勢，言真務之不分；主客同情，言汝我這莫辨。"（《葬書》外篇，《錦囊》注）

> 引文说明：第 1、2、4、6 条是经文；第 3、5、7 条是《錦囊》注。第 3 条注里「廳秀」「攢頭」等字照原样抄。注里「真務之不分」一句用字与今写不同，亦照抄。

## I：核心解释

这一节回答的是：**在一片并列的山里，凭什么取其中一座**。它的答案不是「取最高」，也不是「取最大」，而是取那个**異於眾者**。

1. **取「特」，不取「众」**——「當擇其特」。一片重岡疊阜、群城眾支，不能平均看待，要挑出那一个特殊、突出、能自成气局的。
2. **「特」是同类里出类拔萃**——书用「聖人之于民類，麒麟之於走獸，鳳凰之於飛鳥」作比：圣人在人群里、麒麟在走兽里、凤凰在飞鸟里，都是**同类之中见其特**。所以「特」不是异类，而是同一片山群里那个出挑到足以当主的。
3. **特是相对的，不是绝对的「大」或「小」**——「大則特小，小則特大」，注里说「眾山俱小，取其大；眾山俱大，取其小」。也就是说，取特要看**对比**：周围都小，那座稍大的就是特；周围都大，那座稍小的反而成了特。把「特」理解成「固定取最高/最大」是错的。
4. **凭什么认得它是特**——注里给了形貌口径：「毛骨廳秀、神氣俊雅之異於眾者為正」。看得见的是毛骨（形体）与神气（气势）两个层面比众山出众。
5. **什么情形取不出特**——「參形雜勢，主客同情，所不葬也」。注里解释：參形雜勢是「真偽不分」，主客同情是「汝我莫辨」。一片山大小形态杂乱、没有主次，或者主山与客山情态雷同、谁也压不住谁，就属这一节说的「所不葬」——即**取不出那个特，这一片不成局**。

一句话收束：这一节教的不是「哪座山好看」，而是**在一片里做一次取舍**——先看有没有異於眾者，再看它在对比中是偏大还是偏小突出，两者都对上了才叫「特」；若一片参杂、主客难分，答案就是「这里取不出特」。

**取特三层速览**（每一行都能追回上面 R 节）：

| 层 | 看什么 | 书里的话 | 常见误读 |
|---|---|---|---|
| 有没有特 | 一片里有没有一处「異於眾者」 | 夫重岡疊阜，群城眾支，當擇其特 | 把整片一视同仁，不取不择 |
| 特凭什么 | 毛骨（形体）＋神氣（气势） | 須擇其毛骨廳秀、神氣俊雅之異於眾者為正也 | 只看气势不看形体，或反之 |
| 怎么算特 | 按对比取，不看绝对大小 | 大則特小，小則特大 | 误读为「取最高／最大」 |
| 什么取不出 | 参杂、主客雷同 | 參形雜勢，主客同情，所不葬也 | 矮子里拔将军，硬凑一座 |

这张表的关键在第三行：书里给「特」的定义是**相对的**，所以判读时要先把这一片的对比关系摆出来（俱小还是俱大，有没有明显差），再落到具体是哪一处，不能跳过对比直接指一座。

还有一层先后：书里是先看「一片是不是参杂、主客是不是同情」，取不出特就直接落到「所不葬也」；确认能取出特之后，才谈取哪一处、按大还是按小取。也就是说，**「成不成局」在「取哪一处」之前**。用户往往一上来就问「取哪一座」，其实他真正要先回答的是「这一片有没有一个当主的」。

## A1：来源应用

书上给的具体做法（不是本 skill 的发挥）：

- **先立取舍的对象**：把「重岡疊阜、群城眾支」当作一个整体来看，从中择一，不平均用力。
- **认特的形貌口径**：毛骨廳秀、神氣俊雅，且必须「異於眾」。
- **按对比取大取小**：众山俱小取其大，众山俱大取其小；对应经文「大則特小，小則特大」。
- **排除不成局的一类**：參形雜勢（真偽不分）、主客同情（汝我莫辨）→ 所不葬也。
- **书的断语**：这一节把「所不葬」写成一句**书的评断**（所不葬也），引用时标明是书里的说法，不当作绝对禁令去吓人。
- **取舍的范围**：注里用「重岡並出，群阜攢頭」把要看的那一片说成攒在一起、并列争头的一群，判读时也要先把「这一片」的边界划出来，再看里面有没有出头的一处。
- **两句要连起来用**：经文「大則特小，小則特大」与注里「眾山俱小，取其大；眾山俱大，取其小」是一对，判读时先定这一片的大小基调，再定取大还是取小，不能只抄一句就当结论。

## A2：典型触发场景

用户在生活里具体长什么样：

1. 用户对着远处一片连绵的山，问「这么多座，我该取哪一座来用」。
2. 用户说「我看那座最高的最气派，是不是就选它」，想按原书核实。
3. 用户遇到一片山大小差不多、高低错落杂乱，问「是不是这里取不出哪座为主」。
4. 用户读到「大则特小、小则特大」，问「那到底要取大的还是取小的」。
5. 用户说「我那片山，我一直分不清哪座是主、哪些是客」，怀疑落进「主客同情」。
6. 用户问「圣人之于民类、麒麟之于走兽」这句比喻是在说什么——回应：这是书里用同类之中见其特来比方「择其特」。
7. 用户把「参形杂势」当成「风景杂乱不好看」，问这算不算——回应：注里说的是「真偽之不分」，指的是分不出哪是真主，不是审美上的杂乱。

## E：执行步骤

1. **收料并就缺**　输入：一片山峰的大小、形态描述＋待判问题 → 输出：「已给／缺项」清单，缺大小对比、有无异于众者这两样里的哪一样。
   🔴 **CHECKPOINT**：若用户只给一句「一大堆山，选哪个」，没有大小或形态信息，停在这里列缺项（要看：大小对比、有无一处出众、有没有主客朝拱迹象），不进入判断。
2. **找异于众者**　输入：一片山的大小与形貌 → 输出：是否有一处「毛骨廳秀、神氣俊雅之異於眾者」的初判（有／无／说不清）。
3. **按对比定大小取法**　输入：这一片是俱小、俱大还是有明显大小差 → 输出：取法（众山俱小取其大／俱大取其小／按差异取特），并对应经文「大則特小，小則特大」。
   🔴 **CHECKPOINT**：把「谁是特」与「凭什么（对比）」并列展示，请用户确认，再谈这一片成不成局。
4. **排参杂与主客同情**　输入：这一片是否有明显主次、主客是否同情 → 输出：是否落入「參形雜勢、主客同情、所不葬也」那一类。
5. **收口**　输入：上面各栏 → 输出：一段总结，含「取哪一处（倾向）」或「此处取不出特」、「不能下的结论」与待补观察；凡属书的评断（所不葬也等）都标明「这是书里的说法」。收口时先答「成不成局」，再答「取哪一处」，次序不要倒。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把「特」当成「最高/最大」 | 一律说「取那座最高的」 | 回到第 3 步按对比取：众山俱大反取小，特是相对的 |
| 一片参杂仍硬取一特 | 大小杂乱、主客雷同还指定一座为主 | 按书里判为「參形雜勢／主客同情」，落到「取不出特」 |
| 只有一句「选哪个」就开判 | 用户没给大小、形态任何信息 | 回到步骤 1 列缺项，不硬判 |
| 把「所不葬」说成绝对灾难 | 写「这片山必然绝后」之类 | 标明那是书里的评断语，只给「按书里这一类读」的倾向 |
| 越界给现场指令 | 直接指定「就葬那一座、朝某向」 | 本 skill 只到取舍归类为止，作业指导不接 |

**边界规则**：
1. 缺大小对比或有无异于众者的描述时，只列缺项，不硬判取哪一处。
2. 「取特」只给倾向，不写成「取这座必然发」。
3. 书里的评断（所不葬也）是书里的说法，引用即标明。
4. 取不出特时照实说取不出，不用「矮子里拔将军」硬凑一座。
5. 不接阴宅实地作业指导，不给医疗、法律、投资结论，不替用户拍板。
6. 「所不葬」是书里的评断语，只能给「按书里这一类读」的倾向，不写成灾祸预言。

**自查清单**：
- [ ] 取特的理由是「对比」（偏大/偏小），不是「绝对最高」
- [ ] 判断了有没有「參形雜勢、主客同情」这一项
- [ ] 取不出特时明确说了取不出
- [ ] 每条 R 引文都回标了经文还是《錦囊》注

## 练习手册

- **相对取特**：合上 I 节，写出「众山俱小取其大、众山俱大取其小」各自的道理，再说清为什么「特」不能理解成固定取最高。
- **八字认特**：把注里认特的口径「毛骨廳秀、神氣俊雅之異於眾」拆成形体（毛骨）与气势（神气）两层，各举一个自己见过的例子，不许用「气派」这类含糊词代替。
- **排除练习**：给一片山写两种描述，一种能取出特、一种属「參形雜勢／主客同情」，说明后者为什么是「所不葬也」。
- **对比优先**：随手写一片山的大小分布，先不指名，只写「俱小还是俱大、差有多明显」，再据这句判断该取大还是取小。
- **先后训练**：拿一个真实的群山场景，先只回答「成不成局」，再回答「取哪一处」，把两次回答分开写，体会「成局」在「取哪一处」之前。

## 反例黑名单

1. 把「择其特」等同于「取最高的那座」——书里明说大则特小、小则特大，特是相对的。
2. 一片参杂、主客雷同还硬指定一座为主——该判「所不葬也」，取不出特。
3. 只看形态（毛骨）不看气势（神气），或反过来——注里是两层并列。
4. 把「所不葬」说成绝对灾祸——那是书的评断语，只给倾向。
5. 用户没给一片山的任何大小形态就开判——缺料就说缺料。
6. 只看「毛骨」（形体）不看「神氣」（气势），或反过来——注里是两层并列，缺一层就不算判全。
7. 把「参形杂势」读成「不好看」——它是「真偽之不分」，指分不出真主，不是审美判断。

## 灰色地带

- **两处都像特**：一片山里有两座都异于众者——按书写出两处各自出色的地方与对比关系，给两个候选而不硬选一，请用户补主客朝拱的迹象再收窄。
- **似特而非**：某座明显最高最大，但其余全无朝拱、情态散乱——「最高」不一定等于「特」，此时把「形高」和「能作主」分开陈述，提示需现场再看它是否统领全局。
- **主客界限模糊**：分不清哪座主、哪座客时，回注里「汝我莫辨」一句，判入「主客同情」的疑似，只给「疑似」不下断语。
- **一片里两处并列称特**：若两处都「異於眾」，按书里仍是取其一为主；但证据不足时不硬断，只说明两处各自突出的地方，请用户补朝拱迹象再收窄。
- **「特」但不成局**：某处确是这一片里最出挑的一处，可其余诸山情态一律、无一来朝——书里取特是为了成一局之主，此时只给「形上像是特，成局与否存疑」的判断，不下定论。
