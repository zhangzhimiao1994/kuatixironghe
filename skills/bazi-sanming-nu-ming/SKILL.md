# 三命通會·女命與夫星：論女命與八法八格

**来源**：sources/sanmingtonghui.txt（《三命通會》卷七·論女命、卷七·論六親） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户问女命凭什么星为夫、凭什么星为子。
- 用户读到「或問婦人何利利在夫星」不懂，问这句怎么讲。
- 用户问「先觀夫星以定出身之貴賤再㸔子星以察晚年之榮辱」是不是说女命先看夫、再看子。
- 用户问八法八格——純、和、清、貴、濁、濫、娼、淫——各怎么定义。
- 用户问「凡論女命只用月支中財官印三件為竒」是什么意思。
- 用户问夫星到底怎么定、甲日乙日的夫星是不是都取庚。
- 用户问「女命以柔為本以剛為刑以清為竒以濁為賤」这类评语怎么读。
- **用户给出四柱、问「我这盘女命怎么看／夫星在哪」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问的是日時斷（逐日逐时的歌诀与条件）→ 阳干转 bazi-sanming-ri-shi-yang、阴干转 bazi-sanming-ri-shi-yin。
- 用户问月令格局、十神、官煞去留 → 转本族相应 skill。
- 用户要本 skill 判某人的婚姻成不成、能不能生、寿数、病 → 本 skill 不接，只讲书里怎么取象。
- 用户只给一句「我是女的、今年婚姻怎样」、没有四柱 → 先按 bazi-hub 硬闸门走，缺柱不排。
- 用户把古书里的评价语当成对人的评价 → 只作书里的说法来讲，不落人身。

## R：原文锚点

1. 或問婦人何利利在夫星夫利其婦必利夫困其婦必困婦人從夫先觀夫星以定出身之貴賤再㸔子星以察晚年之榮辱（《三命通會》卷七·論女命）
2. 女命以尅我者為夫我生者為子皆要得時乘生旺之氣（《三命通會》卷七·論女命）
3. 純者一也如純一官星或純一煞星有財有印不值刑衝不相混雜是也（《三命通會》卷七·論女命）
4. 清者潔淨之稱女命或一官一煞不相混雜謂之清要夫星得時柱有財生官有印助身無一㸃混濁之氣方為清貴（《三命通會》卷七·論女命）
5. 論曰凡觀隂命先推夫子興衰欲究榮枯次辨日時輕重官為夫財為父財旺夫榮食為子印為母印盛子衰日干不宜太旺月氣務禀中和（《三命通會》卷七·論女命）
6. 乾道成男坤道成女隂陽剛柔各有其體故女命以柔為本以剛為刑以清為竒以濁為賤（《三命通會》卷七·論女命）
7. 凡論女命只用月支中財官印三件為竒（《三命通會》卷七·論女命）
8. 如女人則甲遇庚七煞乙遇庚正官皆夫星也（《三命通會》卷七·論六親）

## I：核心解释

「論女命」这一块，头一件事是**定夫星、子星**，再用一对一对的评语去分等第。它先把落点说明白，然后逐格取象，最后收在一段总论与三格上。下面逐条对应 R。

1. **先立落点**：「或問婦人何利利在夫星夫利其婦必利夫困其婦必困婦人從夫先觀夫星以定出身之貴賤再㸔子星以察晚年之榮辱」（R1）——这一块把女命的着眼点先钉在「夫星」上，再看「子星」；夫利则出身一边，子利则晚年一边。
2. **夫星子星怎么定**：紧接一句把它讲实——「女命以尅我者為夫我生者為子皆要得時乘生旺之氣」（R2）。即：克我者为夫、我生者为子，且要「得時」、乘生旺之气。同书卷七·論六親又落一句到日干上：「如女人則甲遇庚七煞乙遇庚正官皆夫星也」（R8），并说庚是阳为「正夫」，不取辛阴为夫。
3. **把夫星子星引到时上**：这块的活法是把夫子二星「引歸於時」，看夫星子星各在时上得气还是失气，于是分出旺夫伤子、旺子伤夫、伤夫克子、安静守分几类。这是书里对女命的一贯做法。
4. **八法八格是一组评语对**：写在「論曰」之前的是純、和、清、貴等格，之后接一段总论（R5）与另一串「八格」。以「純」「清」为例：純講的是官与煞不混（R3），清講的是「一官一煞不相混雜、夫星得時、柱有財生官、有印助身」（R4）。可见它的抓手是**官煞不混、夫星得时、财印相济**这几件事。
5. **月支三格**：另一处把它收成三条——「凡論女命只用月支中財官印三件為竒」（R7），即从月支里取财、官、印三样来看，并给了三忌（官多、伤重、带合等）。这是八格之外的另一路取法。
6. **柔刚清浊的取向**：「乾道成男坤道成女隂陽剛柔各有其體故女命以柔為本以剛為刑以清為竒以濁為賤」（R6）——书里给女命一套「柔／刚、清／浊」的取向：以柔、以清为取，以刚、以浊为忌。这是**书里的取向语**，读到它要标明出处、标明这是原书的评价。
7. **总论**：「論曰凡觀隂命先推夫子興衰欲究榮枯次辨日時輕重官為夫財為父財旺夫榮食為子印為母印盛子衰日干不宜太旺月氣務禀中和」（R5）——它把整块的读法收成四步：先推夫子兴衰 → 次辨日时轻重 → 官为夫、财为父、食为子、印为母 → 日干不宜太旺、月气要中和。
8. **一句话读法**：定夫星（克我者）、子星（我生者）→ 引归时上看得失 → 用官煞不混、夫星得时、财印相济分格 → 落在「柔／刚」「清／浊」的取向上；书里的评价语只作书里的说法，不落人身。

## A1：来源应用

书上给女命的做法，都绕「定星 → 引时 → 分格」三件事：

- **定夫星子星**：照 R2、R8 取「克我者为夫、我生者为子」，并说阳干为夫不取阴干为夫（甲日乙日的夫星同取庚）。
- **引归时上**：把夫星、子星引到时支，看各在时上得气还是失气；由此才有「旺夫伤子」「旺子伤夫」「伤夫克子」「安静守分」这几类（书里每类都配命例说明）。
- **八法八格**：以「純」「和」「清」「貴」为一端（R3、R4 是「純」「清」的定义），以对应的「濁」「濫」等为另一端；抓手是官煞不混、夫星得时、财印相济。**这些格名与「濁／濫／娼／淫」一类评语都是书里的说法**，引用时必须标明出自原书。
- **月支三格**：照 R7，另从月支取财官印三件，并注意它列的几忌。
- **柔刚清浊**：照 R6 的取向读，不把它当对人的德行评判。
- **评价语提醒**：这一块原书用了大量评价用语——「濁」「濫」「娼」「淫」「克夫」「贱」等等。这些**全是书里的说法**，是原书（明萬民英）在所处方言与语境下对结构的评语；本 skill 引用时一律标明，**绝不落到具体人身上**，也不用作对某人的德行、婚姻或生育的判断。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月令、夫星的干支（克我者、取阳干为夫，如甲日乙日皆取庚）、子星的干支（我生者）、各在哪一柱、透干还是藏支、柱中官煞是否混杂、有财有印无、夫星子星是否引归时上。
2. **逐条核书里的条件**：夫星子星怎么定 → R2／R8（以尅我者為夫我生者為子）；先观夫星再察子星 → R1；官煞不混、夫星得时、财印相济 → R3／R4；月支财官印三件 → R7；柔刚清浊的取向 → R6。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「夫星透而官煞不混杂，按 R3、R4 这一路读，偏『純』『清』的取象」。
4. **收口**：这一句是**书里的读法**，不是对这个人的判断；**「克夫」「賤」「淫」「濁」「濫」「娼」这类评价语只可念、不可落到人身上**；**不应期、不断终身、不落寿夭疾病生育（含婚姻与生育）、不替人决定**。

**书里没有的、不要加**：原书论女命只讲定星、引时、分格与财官印的取用，不讲后世流派的「女命宫位打分」「自动判格」之类；也不拿现代术语去替它背书。命例只作书里的举例，不搬作规律。

- **用户引「以柔为本」问是不是说自己**：这是书里给女命的取向语，不是对某人性子的评定；照实说明，不落人身。
- **用户既问取象又要「看我这一盘」**：取象照讲，落人身的判定说明不接，并说缺柱要补什么。
- **同一条评语在不同命例里说得不一样**：书里对相近结构的评语本就各家不一，据实并列，说明是书里各例的说法，不替用户挑一条拍板。
- **用户把「濁／濫／娼／淫」当成伦理定性**：这些是原书在所处方言语境下对结构的评语，先说明这一点，再只取其取象法，不搬它的褒贬。
- **用户问男女是否同一套**：卷七論女命是专就女命立的读法；定星的原理与卷七論六親相通，但取向语只用于女命这一块，照实说明，不扩大到男命。
