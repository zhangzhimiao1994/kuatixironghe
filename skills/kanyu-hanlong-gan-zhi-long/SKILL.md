# 干龙枝龙：天下大势怎么分

**来源**：撼龍經（唐楊筠松，欽定四庫全書本） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「这块地的大势怎么分？哪条是主脉、哪条是支脉？」
- 「怎么判断哪里是真龙？是不是两水夹住的那一道就是？」
- 「地图上一条山脉一路下来，中间岔出好多条，我该认哪一条？」
- 「『两水夾處是真龍』这句到底在说什么？」
- 用户拿别人的堪舆文字来核对，想弄清「干龙」「枝龙」「罗城」「水口」在一处形势里各指什么。
- 用户想知道「高山有龙、平地也有龙」这两句话怎么并存。

**不应触发**（看起来像但其实不是）：
- 用户问某一座山峰像贪狼还是巨门、这类星峰吉凶怎么断 → 归 `skills/kanyu-hanlong-jiu-xing/`（那里专管九星辨形）。
- 用户已经有穴场圆晕，只问该用顺杖还是逆杖、该盖还是该粘 → 归 `skills/kanyu-dao-zhang-shi-er-fa/`（那里专管认太极与倒杖十二法）。
- 用户已有确切形势，只想弄懂「擔傘」「騎龍」这类条目 → 归 `skills/kanyu-er-shi-si-sha-zang-fa/`。
- 用户要的是「这一处该不该葬、怎么下葬」的实地作业指导 → 本件不接（见 B 节）。
- 用户问某个日子宜不宜下葬 → 那是择日的事，不归本件。

## I：核心解释

《撼龍經》讲龙，第一层不是「看这一座山好不好」，而是「先把天下的干脉分出来」。原书开门就把山河比作人身：須彌山是骨，四肢分出四派世界，南龙入中國，黄河川江是肠胃膀胱（R1、R2）。这是拿身体作比喻来定「大干」的位置——先认大势，再往下追。若一上来就盯一个山头，等于拿着一个脚趾问这个人是谁。

第二层是干枝。书里给的真龙判据并不复杂：**两水夹送、中间那一道**才是真龙，旁的枝枝叶叶围在四周作拱卫（R4）。所以「认龙」在很多场合其实是「认水」——水走到一处合、抱、缠，龙形也就跟着定下来。反过来说，水一散，周围的枝叶也跟着散，中间那道就撑不住了。

第三层提醒：**高山与平地是两套看法，不能混用**（R3、R5、R8）。高山认星峰起伏，平地没有星峰可认，就要在两旁寻水势、看环遶。原书特地堵了一句「莫道髙山方有龍却來平地失真蹤」，就是怕人走到平地就以为没龙了。正确的步子是把看法切换过来，而不是否定平地。

第四层是护托与关锁：龙从腰里落下，回转的余枝会结成城廓、生出捍门，门外再有罗星当住（R6）。罗星有它该在的位置：应当落在罗城之外，与火星相对作前案（R10）。枝多、水绕、外山环抱，才是「平洋龙局段」的完整样子（R4）。

第五层是旁证：龙行到跌断处，两傍往往生出「衣冠吏」样的圆峰，两脚护卫真龙（R9）。这些护卫峰不是真龙本身，却能在判断时帮忙——真龙行处护卫不散，护卫散了，中间那道的可信度就低。

最后一条最省事的判据：到了平地不用找踪，只看有没有环遶（R7）。环遶在，龙就在；环遶不成，就不必硬指。这几层合起来是一条线：大势 → 干枝 → 水夹 → 护托 → 环遶，从大到小收拢。

第六层是「以水代山」的平洋读法。原书说平地过脉「過處如絲或如線」，又说「髙水一寸即是山低水一寸水回環」（《撼龍經》）。在没有星峰可认的地方，水的细微高下就充当了山的高低——高出一寸的水便当山看，低下一寸的水便作回环。这一层是平地认龙的落脚点，也最考眼力；看不出来时，宁可说「看不出」，不要拿别的形式去凑。

要说清的是：干枝是**位置**概念，不是吉凶等级。干只意味着「主干、水夹、护托齐」，枝只意味着「从干分出、围在四周」。同一条枝，只要自身形势自成，也可以是好地。所以本件只辨位置主从，不替地方贴吉凶标签——吉凶留给后头的星形与形势去看。

## A1：来源应用

1. **先分大势**。原书从須彌山四派讲起，落到「惟有南龍入中國」，是把一处形势放进「干脉—支脉」的大框架里去认，而不是孤零零看一个山头（R1、R2）。
2. **认干枝只看水**。原文「两水夾處是真龍枝葉周回中者是」：两道水夹住、周回枝叶把中间那道围出来的，是干；水散、山反的，枝叶就散了（R4）。
3. **高山一套、平地一套**。「髙山須認星峯起平地龍行别有名」（R3），平地要「两傍尋水勢」（R5）。原书还特意说「藕斷絲連正好尋退卸愈多愈有力」——平地龙脉即使中断，也还有丝连可寻，退卸反而更见力。
4. **平洋看龙的三句口诀**（原书原话，为免割裂，整句照录）：
   > "傾從丘阜覔凹窠或有勾夾如旋螺勾夾是案螺是穴水去明堂聚氣多四傍遶䕶如城郭水遶山還聚一窩"（《撼龍經》）
   > "水纒便是山纒様纒得真龍如仰掌"（《撼龍經》）
   > "藕斷絲連正好尋退卸愈多愈有力"（《撼龍經》）
   三句连起来是：先找低丘里的凹窝，看四周像不像城郭一样绕护、水有没有绕回来聚成一窝；水缠就等于山缠；平地龙脉即使藕断，也还有丝连，越退卸越有力。
5. **认罗城与水口**：外山百里作罗城，是真平洋局的排场；龙腰落下的余枝做城廓、生捍门，门外罗星当腰（R4、R6）。罗城是外局，不是穴位；罗星要落在罗城外，不能缩进罗城内（R10）。
6. **看跌断处的护卫峰**。「每逄跌斷過處時两傍定有衣冠吏」，衣冠吏像是圆峰、两脚护卫真龙（R9）。判断时可以顺手核一下：跌断处两旁有没有这类护卫；有，则过脉更像真行。
7. **平地别急着说无龙**。原书「莫道髙山方有龍却來平地失真蹤」（R8）是正面提醒；平洋上找不到星峰时，改用寻水势与看环遶（R5、R7）。
8. **平洋以水代山**。原文「過處如絲或如線髙水一寸即是山低水一寸水回環」（《撼龍經》）：平地没有星峰，就把水的细微高下当作山的高低来认；过脉像丝像线的地方，正是要寻的处所。

## E：执行步骤

1. **收集形势描述**　输入：用户对来龙走向、两水（或几面水）、地形（高山还是平洋）、四周护山的零散描述 → 输出：一张「形势清单」，逐项标有／无／不确定。
   🔴 **CHECKPOINT**：若「有没有两水夹送」或「来龙大致走向」缺一，停下，直接说缺哪一项、要到什么程度才能往下判；不许拿想象出来的地形硬判。
2. **分大势、定干枝**　输入：形势清单 → 输出：一句「大势判断」，说明这是大干过脉还是分枝落平、干在哪、枝在哪，每条判断都回指 R 节原话。
3. **两水夹送检验**　输入：干枝判断加重水的情况 → 输出：真龙候选，并写明依据是「两水夹处周回中者」，还是「水散山反」。
4. **高山／平地读法切换**　输入：地形类型 → 输出：该用「认星峰」还是「寻水势」的读法；平洋的要补上凹窝、绕护、水缠三看，并记住「平地也有龙」（R8）。
5. **护托与水口检验**　输入：真龙候选 → 输出：环遶成不成（R7）、跌断处有无护卫峰（R9）、罗城关锁成不成、罗星位置对不对（R4、R6、R10）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿一个山头当干龙 | 只看某座山峰好不好，不问它上面的干脉从哪来、水怎么夹 | 回到步骤一，先补「来龙走向」与「两水」两项 |
| 平地硬用高山读法 | 在平洋上找星峰，找不到就断定「无龙」 | 切到平地读法：两傍寻水势、看环遶（R5、R7、R8） |
| 把书里的吉语当承诺 | 直接说「此地必发富贵」 | 把原书断语标明是「书里的说法」，只作倾向 |
| 缺两水硬判 | 只有山形、没有水，仍判「两水夹处是真龙」 | 记下缺项，等两水信息齐了再判 |
| 把罗城当穴场 | 看到外山环抱就认定穴位 | 罗城是外局排场，穴位另在枝回处（R6），两件事不要混判 |
| 罗星缩进罗城内 | 见一处圆墩就说是罗星，不管它在不在罗城外 | 按 R10 核对位置：罗星应在罗城外 |
| 把护卫峰当正龙 | 见两傍有圆峰就认作龙身 | 护卫是旁证（R9），真龙仍在两水夹送那道 |
| 把平川直接当无龙 | 一见平地就说「这里没龙」 | 按 R8、R5、R7 切到寻水势、看环遶 |
| 把「干枝」当成吉凶等级 | 以为干必定吉、枝必定次 | 干枝只说位置与主从，吉凶另按星形与形势论 |

**边界规则**：
1. 本件只管「大势怎么分、干枝在哪」，不管具体穴位落点、朝向、深浅。
2. 缺两水或来龙走向时，只做定性描述，不指定真龙。
3. 不接阴宅实地踏勘与下葬作业指导，不替用户拍板。
4. 只给倾向，不做「能不能发、发多大」的判定。
5. 干枝是位置概念，不是吉凶等级；不要用「干」字给地方贴吉标签。

## 练习手册

- **看图分干枝**：取一张有河流的等高线图或航拍图，自己标出「两水夹处」的那一道，写清为什么它不是旁边的枝。
- **原话回填**：合上 A1，把 R4、R5 两句默写出来，再翻回原书补足写错的字。
- **平洋三看**：找一处平原上的城镇，用「凹窝—绕护—水缠」三看去描述它，全程不下吉凶断语；再补一句「这里的罗星在不在罗城外」。
- **水的高下**：在一张平地地形图上，找一处「高水一寸」的缓坡与「低水一寸」的回环处，照原话标注两处各是什么。

## 灰色地带

- **一处两水夹送、但外山不环**：原书两套说法（R4 的「两水夹处」与 R7 的「只观环遶」）会打架。此时把两种读法并列写出，说明各需要补什么才能定，不强行选一。
- **平洋上既看不到明显的水、也无星峰**：按 R7 只做「有没有环遶」的判断；环遶也不明时，照实说「不足以判」。
- **同一形势，干枝两种读法都讲得通**：保留两种，标注各自侧重，请用户补一处关键信息（水口或来龙）再收口。
- **干脉被城镇、田畴遮住**：旧时的眠弓界水今天可能看不到了。此时只说「按现有描述不足以定干枝」，请用户补两水或地势高下的线索，不拿现代地面去替古人硬认。
- **同一形势，高山读法说吉、平地读法说平**：两套读法各自成立时，只写各自的结论与依据，不合成一个「综合吉凶」，也不替用户选边。
