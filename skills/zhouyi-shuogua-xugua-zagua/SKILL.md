# 說卦·序卦·雜卦

**来源**：`sources/zhouyi-jing.txt`（經文，含說卦、序卦、雜卦）、`sources/zhouyi-zhengyi.txt`（正義序卦/雜卦/說卦疏） ｜ 证据等级：firsthand（原书原话）

> 本 skill 只做**读法与篇义归类**：认这一句出自《說卦》《序卦》《雜卦》里的哪一篇、认它是經文还是疏文，再把用户的处境按三传所命的类读一遍。**不进行占筮**——不起卦、不抽签、不排盘、不预测结果、不替用户决定。

## 触发条件

**应该触发**（用户会怎么说话）：
- 直接问三传："帝出乎震是什么意思""說卦的八卦取象怎么排""乾为马坤为牛这些取象哪来的"。
- 问次序与对照："六十四卦为什么是这个次序""序卦怎么讲卦的先后""雜卦和序卦有什么不同""乾刚坤柔、比乐师忧从哪来"。
- 拿着一句传文问"这是哪一篇、书里怎么讲"，或把一件具体的事拿来问"按这几传该怎么读"。

**不应触发**（看起来像但其实不是）：
- 要求起卦、解卦、算一卦、断吉凶、预测结果 → 照实说明这里只做读法与篇义归类，不进行占筮。
- 问某一卦的卦辞/爻辞逐字（走上下经那一支），问通论性大段（走繫辭那一支）。
- 单纯统计字数、版本校勘类问题。

### 《說卦》——八卦取象与"帝出乎震"

3. 天地定位，山澤通氣，雷風相薄，水火不相射。八卦相錯，數往者順，知來者逆。是故易逆數也。（《周易》說卦·第三章）

### 《序卦》——六十四卦次序之理
17. 有天地，然後萬物生焉。（《周易》序卦·上篇）
18. 盈天地之間者，唯萬物，故受之以屯；屯者盈也，屯者物之始生也。（《周易》序卦·上篇）
19. 物生必蒙，故受之以蒙；蒙者蒙也，物之穉也。（《周易》序卦·上篇）
20. 飲食必有訟，故受之以訟。（《周易》序卦·上篇）
21. 訟必有眾起，故受之以師；師者眾也。（《周易》序卦·上篇）
22. 物畜然後有禮，故受之以履。（《周易》序卦·上篇）
23. 履而泰，然後安，故受之以泰；泰者通也。（《周易》序卦·上篇）
24. 有大者不可以盈，故受之以謙。（《周易》序卦·上篇）
25. 有事而后可大，故受之以臨；臨者大也。（《周易》序卦·上篇）
26. 物不可以終盡，剝窮上反下，故受之以復。（《周易》序卦·上篇）
27. 有夫婦然後有父子，有父子然後有君臣，有君臣然後有上下，有上下然後禮儀有所錯。（《周易》序卦·下篇）
28. 物不可以久居其所，故受之以遯；遯者退也。（《周易》序卦·下篇）
29. 物相遇而后聚，故受之以萃；萃者聚也。（《周易》序卦·下篇）
30. 井道不可不革，故受之以革。（《周易》序卦·下篇）
31. 物不可窮也，故受之以未濟；終焉。（《周易》序卦·下篇）

### 《雜卦》——卦德对照
32. 乾剛坤柔。比樂師憂。（《周易》雜卦）
33. 臨、觀之義，或與或求。（《周易》雜卦）
34. 震起也，艮止也。損、益，盛衰之始也。（《周易》雜卦）
35. 謙輕，而豫怠也。（《周易》雜卦）
36. 剝爛也，復反也。（《周易》雜卦）
37. 井通，而困相遇也。（《周易》雜卦）
38. 睽外也，家人內也。（《周易》雜卦）
39. 否、泰，反其類也。（《周易》雜卦）
40. 革去故也，鼎取新也。（《周易》雜卦）
41. 需不進也，訟不親也。（《周易》雜卦）
42. 夬決也，剛決柔也。君子道長，小人道消也。（《周易》雜卦）

### 《周易正義》三传疏——三篇各自的体例
43. 《說卦》者，陳說八卦之德業變化及法象所為也。（《周易正義》說卦·疏）
44. 《序卦》者，文王既繇六十四卦，分為上下二篇。其先後之次，其理不見，故孔子就上下二《經》，各序其相次之義，故謂之《序卦》焉。（《周易正義》序卦·疏）
45. 上《序卦》依文王上下而次序之，此《雜卦》孔子更以意錯雜而對辨其次第，不與《序卦》同。（《周易正義》雜卦·疏）
46. 《雜卦》者，雜糅眾卦，錯綜其義，或以同相類，或以異相明也。（《周易正義》雜卦·疏）

## I：核心解释

三传各管一层，先认在哪一层，再读。

1. **《說卦》管"象与位"**：先把八卦的德（乾健、坤顺……见 R8）、身与物之象（R9–R10、R12–R16）、父母六子（R11）定位下来；再给一张方位次序图——"帝出乎震……成言乎艮"（R5），震東、離南、兌西、坎北（R6–R7）。读象时**先认卦，再取象**：同一卦可有多象（如乾既为天、为君、为父，又为马、为金、为玉，R12），取哪一象看这一处在讲什么。
2. **《序卦》管"次序之理"**：六十四卦不是随机排列，而是"物不可以终X，故受之以Y"这一路的相次之理（R18–R31）。它的句式本身就是读法：**上一步到了极处，下一步随之而来**（如"物不可以終盡，剝窮上反下，故受之以復"，R26）。正義说得清楚：卦的先后次序"其理不見"，孔子才依上下经各序其相次之义（R44）。
3. **《雜卦》管"卦德对照"**：它打乱《序卦》次序，两两对举地给出卦德（"乾剛坤柔""比樂師憂"，R32；"革去故也，鼎取新也"，R40）。正義点明它"錯綜其義，或以同相類，或以異相明"（R46），且"不與《序卦》同"（R45）。**读雜卦要看成对**：每一对是在相互映照，不是单卦的定义。
4. **层要标清**：R1–R42 是**經文**（三传本文）；R43–R46 是**孔穎達疏**。同一层里，朱子本義与孔疏的取法常常不同（这两家怎么读，是另一支 skill 的事）。
5. **卦必须带卦名与卦次**：序卦句里点到具体卦时，报卦一律给"卦名＋卦次＋原文"。

## A1：来源应用

- **帝出乎震（R5–R7）**：以方位次序给八卦排一轮流行，震→巽→離→坤→兌→乾→坎→艮，各系一时一位。读法上把"某一类事处在哪一节点"说清，而不是把它当预言。
- **序卦的"物不可以终X"（R23–R31）**：这类句子给出的是**趋势的接续关系**——通了必塞（泰→否）、剥尽必复（R26）、聚而后升、升而不已必困。读一件具体的事时，用它来命名"现在在哪一步、下一步的势往哪边"。
- **雜卦的对照对（R32–R42）**：如"睽外也，家人內也"（R38）、"否、泰，反其類也"（R39），给的是成对范畴。读法上把事归到"这一对里的哪一端"，说清凭哪一句。
- **疏文的体例（R43–R46）**：表明三传各自的写法（說卦陈德业法象、序卦序相次之义、雜卦错综对辨），是认篇的依据，不是对某人的判决。

## E：执行步骤

1. **先分问法**　输入：用户原话 → 输出：判定这是哪一种问法。
   - **问法 A｜文本解读**："这一句/这一卦书里怎么讲、出自哪一篇"。→ 走认篇归义：认它在《說卦》《序卦》《雜卦》哪一篇、是經文还是疏（R43–R46），摆出书里的条件与取象，逐字给原文与出处。
   - **问法 B｜落到处境上的读法**："我这件具体的事怎么看"。→ 把事归到一类处境：按八卦取象所命的类（R8–R16）、或《序卦》所示的相次之理（R18–R31）、或《雜卦》的卦德对照（R32–R42），说清**凭哪一条**这么读，给"按书里这一类读，偏 X"＋**出处**。
   🔴 **CHECKPOINT**：先分清 A 还是 B，别把 B 当 A 只做训诂，也别把 A 当 B 替人下判断。
2. **认篇与定层**　输入：用户提到的那一句或那一卦 → 输出：篇名（說卦/序卦/雜卦）＋层名（經文/疏）＋該篇的体例一句（R43–R46 里对得上的一条）。引文一律**繁体照抄**，带出处括注。若用户给的线索不足以定篇（说不出语词或卦名），**照实说还缺什么，不硬套一篇**。
3. **报卦给全三样**　输入：事里点到的卦 → 输出：**卦名 ＋ 卦次 ＋ 原文**，并写一条"为什么是这一卦"的细节对应（拿不准就不报卦）。
4. **落到读法与收口**　输入：归类结果 → 输出：说清"按书里这一类读，偏进/偏守/宜缓/宜断"的方向，并**收口**：只做读法与处境归类；**不起卦、不占卜、不预测结果、不替用户决定**。结尾落一个今天/这周能打勾的动作（去核对哪一条、把那句话抄下来对照自己的事）。
   - 书里的吉凶词（"元吉""凶""无咎"这类）若要引，一律注明是**书里的用语**，不当作对用户的事实判决。

## 🚫 反例黑名单（不要做的事）

1. 拿《雜卦》给用户断吉凶、说"你命中如此"——书里的卦德是书里的用语，不是对某人的判决。
2. 把孔疏当经文引（"《雜卦》者，雜糅眾卦……"是疏文 R46，不是經文）。
3. 用户说不清问的是哪一句就硬报一篇一卦，不给"还缺什么"。
4. 把《說卦》的取象当固定符号表死套——同一卦多象，取哪一象要看这一处在讲什么。
5. 用"一定/必然/命中/保证"这类词给结果背书。

## 灰色地带

- **一句同时像两篇**：如某句既像序卦的相次、又像杂卦的对照，两说都摆、各标出处，先给一篇主读、再说明另一篇为何也通，不硬合成一句。
- **经文与疏文对不上**：以经文为文、以疏为一家的说法，标清层，不调停。
- **用户要"算一卦"**：照实说明本 skill 只做读法与篇义归类，不进行占筮；可以陪他读一句原文，但不代占、不预测。
- **信息不足**：只做最宽的归类（说说/序/杂哪一篇），说清还差哪一点才好定篇，不许硬套。
