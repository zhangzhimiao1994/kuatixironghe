# 堪舆择日·義例六·禄马与飞宫

**来源**：《欽定協紀辨方書》卷八·義例六 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「岁禄、飞禄、飞马是什么？今年禄马落在什么方位？」
- 「禄马同到是不是大吉？」「飞宫贵人怎么飞？」
- 「通天窍能压太岁三煞吗？」「走马六壬是什么？」
- 用户要按**年干支＋月建**飞宫，求禄马贵人吉方。
- 用户拿着一份「修方吉方」的结论，想验证它的起例。

**不应触发**（看起来像但其实不是）：
- 用户问的是**年**的方位神煞凶神（太岁、岁破、三煞本体）→ 转年神类 skill。
- 用户问的是**日／时**黄黑道、天乙贵人时 → 转黄道贵人类 skill。
- 用户问的是**建除十二神**或月德类 → 转建除／月神类 skill。
- 用户要现场开山、动土、下葬的作业指导 → 不接（见 B 节）。

## I：核心解释

卷八·義例六排的是**年方一层、逐月飞宫**的禄马贵人与一批修方神煞。白话讲：

1. **岁禄是岁干的临官方**（R2）。「岁禄者，岁干临官方也」——五行之性「临官吉于帝旺」，临官方盛、帝旺太过，故禄命家以临官为禄、以帝旺为刃。起例（R1）：甲年在寅、乙年在卯、丙戊年在巳、丁己年在午、庚年在申、辛年在酉、壬年在亥、癸年在子。
2. **飞禄飞马要看飞宫**（R4）。通书年神立成只取禄马地支一字，以月建入中宫顺飞九宫；选择宗镜兼取本遁天干为「真禄马」，再以月建干支入中宫顺飞九宫。书说二说「皆为有理」，一并存录。
3. **禄马同到是最吉的一景**（R3）。通书口诀说「马到山头人富贵，禄到山头旺子孙，若逢禄马一同到，千祥百福自骈臻」。但这是**通书之言**，书照录而不作保证——判读时须标清是通书的说法。
4. **飞宫贵人另成一法**（R5）。选择宗镜说「贵人禄马皆吉神」，又给出阳贵阴贵的取用差别：阳贵人冬至后用有力、飞在阳宫尤有力；阴贵人夏至后用有力、飞在阴宫尤有力。书补通书有飞天禄马而无飞宫贵人，是「阙略」，取宗镜补之。
5. **通天窍能压诸凶的说法，书明确驳回**（R6、R7）。通书说通天窍是「杨救贫真诀」，不论太岁、三煞、官符、大将军，遇吉星所值便能压之。书按：它只用八干四维、又用双山兼十二支，本来自相出入；且「能压太岁之说既不可为典要，又自不犯三煞，则能压三煞之说更属有名无实」，故宗镜「诋其不足为据」。
6. **同卷还有一批修方神煞**：走马六壬、四利三元、盖山黄道、三元九星、八节三奇、巡山罗㬋、坐煞向煞、灸退、独火、浮天空亡、阴府太岁、天官符、大小月建、丙丁独火、月游火等，各有起例与宜忌；书对其中多名目（如小月建别名「小儿煞」）明确判为「惑世诬民」。
7. **四利三元与盖山黄道**：四利三元以太岁、太阳、丧门、太阴、官符、死符、岁破、龙德、白虎、福德、吊客、病符十二方为序，太阳、太阴、龙德、福德为吉；盖山黄道起于青囊九曜，以本年支对宫之卦为本宫，用小游年变卦法（贪狼黄罗、巨门天皇、文曲紫檀、武曲地皇），通书「止取八卦不用纳甲三合」。
8. **一批修方凶煞**：巡山罗㬋（岁前一位）、坐煞向煞（伏兵大祸夹三煞）、灸退（三合死方，又为六害、飞天独火）、独火（盖山黄道内朱雀廉贞）、浮天空亡（绝命破军之位）、阴府太岁（化气克山家）、天官符（三合临官方）、大小月建（飞宫月建）、丙丁独火、月游火。
9. **书对名目的态度**：书屡说「迎财、进宝、库珠」诸名「殊不雅驯」，改称三合前方、三合后方；又判「小月建曰小儿煞，举世畏忌而不知其由，惑世诬民」。判读时须照录书的改名与批评，不沿用坊本骇人之名。

## A1：来源应用

书上给的具体做法（不是我的发挥）：

- **岁禄起例**（R1、R2）：甲寅、乙卯、丙戊巳、丁己午、庚申、辛酉、壬亥、癸子；取临官为禄，帝旺为刃，故又有岁刃之说。
- **真禄马与飞宫**（R4）：先以五虎遁寻本年禄马干支为真禄马，再以月建入中宫顺飞九宫，寻真禄马落在何宫。
- **贵人禄马的取用差别**（R5）：阳贵人冬至后用、飞在阳宫尤有力；阴贵人夏至后用、飞在阴宫尤有力。
- **通天窍**（R6）：通书说用八干四维，取本年三合长生起「迎财、进宝、库珠」三星及其对宫「大吉、进田、青龙」三星，共十二吉山，用本年三合及其对冲的月日时。
- **四利三元**：太岁、太阳、丧门、太阴、官符、死符、岁破、龙德、白虎、福德、吊客、病符；太阳、太阴、龙德、福德为吉。
- **盖山黄道**：起于青囊九曜，以本年支对宫之卦为本宫，用小游年变卦法，贪狼为黄罗、巨门为天皇、文曲为紫檀、武曲为地皇。
- **三元九星／八节三奇**：九星以入中宫之星为主顺布八宫；三奇（乙丙丁）随贵人游行，八节三奇从八节本宫起甲子阳遁顺飞、阴遁逆飞。
- **一批修方凶煞**：巡山罗㬋（岁前一位）、坐煞向煞（伏兵大祸）、灸退（三合死方）、独火（盖山黄道内朱雀廉贞）、浮天空亡（绝命破军之位）、阴府太岁（化气克山家）、天官符（三合临官方）、大小月建（飞宫月建）、丙丁独火、月游火。
- **走马六壬**：取神后（子）、胜光（午）、功曹（寅）、传送（申）、天罡（辰）、河魁（戌）六阳辰为吉，子年以天罡加辰，每年退行一位。
- **天官符／地官符**：天官符为太岁三合五行方旺之气（申子辰年在亥、巳酉丑年在申……），忌修方，一年占一字；地官符为太岁前五位。
- **巡山罗㬋**：为岁前最近之方，止忌立向、开山、修方；书依起例改正通书之误。
- **独火／浮天空亡／阴府太岁**：独火为盖山黄道内朱雀廉贞；浮天空亡为绝命破军之位（甲己年离壬、乙年坎癸……）；阴府太岁为化气克山家之方。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报神煞名不给卷次 | 「今年禄马在东南，修方吉」不说卷几 | 补卷八·義例六条目＋宜忌依据；补不出＝不合格 |
| 把通书口诀当书的主张 | 「禄马同到必然大吉」 | 标明这是通书之言，书照录而不作保证 |
| 把书已驳回之说当真 | 「通天窍能压太岁三煞」 | 书明说此说「有名无实」，照书驳回 |
| 飞宫算错宫统三山 | 只报一个山名，忘了宫统三山 | 按书「每宫占三位」说明宫与山的对应 |
| 缺年月就硬飞 | 用户只说「想修房」 | 点明年份、月建，缺则不算 |
| 越界到时家 | 拿禄马去断某时辰吉凶 | 转黄道贵人类 skill |
| 把改名后的名目当原义 | 把三合前方说成「迎财」 | 书已改名以「例明义正」，照书用新名并注明旧名 |
| 把大小月建当有大小祸 | 说犯小月建伤小儿、大月建伤宅长 | 书判其「谬为之说，惑世诬民」，照书辨正 |

**边界规则**：
1. 本 skill 只管**卷八·義例六**年方飞宫一类；年神凶煞在卷三，建除在卷四，月神在卷五，日辰神煞在卷六，黄黑道贵人在卷七。
2. **报神煞必须同时给起例来源与宜忌依据**；只报神煞名而不给卷次＝不合格。
3. 象征层只命名、不承诺：写「按书里这一类读」，不写「一定／必然／命中／保证」。
4. 不替用户拍板，不给医疗、法律、投资结论。
4. 本 skill 只涉卷八·義例六；飞宫之法虽杂，凡书已改名、已驳回者，不得当作书的主张。


**来源边界**：
本 skill 依据《欽定協紀辨方書》卷八·義例六原文。书对通书、选择宗镜、坊本诸说多有辨正（如通天窍压凶、小月建小儿煞、大小月建），凡书已辨误者不得当作书的主张。

## 练习手册

1. **岁禄默推**：凭记忆写出十干的岁禄方位，再回卷八核对，并说明为何「临官为禄、帝旺为刃」。
2. **真禄马演练**：任取一年干支，用五虎遁推出真禄马干支，再以月建入中宫飞宫定其方位。
3. **辨说法**：任取通书一条吉断（如禄马同到），找出书中对它的态度，写成「通书怎么说／书怎么判」两栏。
4. **飞宫演练**：任取一年月，以月建入中宫顺飞九宫，定禄马或天官符所落之宫，写出宫统三山。
5. **辨讹三例**：任取通天窍、小月建、大小月建三例，写成「通书／坊本怎么说」与「书怎么判」两栏。

## 反例黑名单

1. **不要**只报神煞名而不给出处——违反本族硬口径。
2. **不要**把通书的吉断当成书的主张——书照录而不作保证。
3. **不要**把通天窍压太岁三煞当真——书明说其说「有名无实」。
4. **不要**把小月建说成「必伤小儿」——书判此类名目「惑世诬民」。
5. **不要**用现代词给禄马飞宫背书，也不要写成自我否定的腔调。

## 灰色地带

- **通书与书的判断并存**：同一条吉方，通书判吉、书或存或驳。遇到时两栏并陈，标明各自来源，不替用户裁断。
- **宫与山**：飞宫以宫（统三山）为单位，用户常问具体某一山。遇到时先说宫、再说该宫所含三山，避免把宫的结论硬套到单山。
- **历本分歧**：飞禄马、通天窍等名称与起例各本不同（如通书无飞宫贵人）。以本书原文为准，注明差异与书的取舍。

- **通书与书的判断并存**：同一条吉方，通书判吉、书或存或驳。遇到时两栏并陈，标明来源，不替用户裁断。
- **宫与山**：飞宫以宫（统三山）为单位。用户常问某一单山，先给宫、再给该宫所含三山，避免把宫的结论硬套到单山。
- **历本分歧**：飞禄马、通天窍、阴府太岁等名称起例各本不同（如通书无飞宫贵人、丁壬年少乾）。以本书原文为准，注明差异与书的取舍。
- **飞宫与定位之别**：禄马、贵人、官符等有「定位」与「飞宫」两种取法（通书取地支一字，宗镜兼取本遁天干为真禄马）。遇到二说并存时，两栏并陈，不替用户裁断。
- **一宫统三山**：飞宫所得是宫，宫统三山。遇到用户要单山结论时，先给宫、再给所含三山，避免把宫的结论硬套到单山之上。
- **三件套的写法**：报一个飞宫吉方，标准写法是「禄／马／贵人 → 卷八·義例六某条起例（含五虎遁取真禄马、月建入中宫飞宫）→ 宜忌（并注明是通书之言还是书的判断）」，三样缺一即不合格。
- **禄马同到的分寸**：通书口诀「禄马一同到，千祥百福自骈臻」是通书的说法；书照录而不作保证。遇到用户据此下断语时，先标明来源，再补书的态度。
- **岁月两层禄马**：禄马有从年支取者，也有从日支取者，「其义例皆与月同」。遇到用户问的是某一日的禄马时，须先确认是从年、月还是日支起，再起例。
