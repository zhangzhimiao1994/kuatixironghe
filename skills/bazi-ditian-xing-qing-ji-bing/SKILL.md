## I：核心解释

这六篇是从「人本身」往外推的：先讲五气落到人身上成什么**性情**，再讲五脏之象与**疾病**的取象，然后讲**出身、地位**这条从格局到清浊的气，最后讲**岁运**与**贞元**这条时间线。

1. **性情是五气的偏全**：经文一句总纲——「五气不戾，性情中和；浊乱偏枯，性情乖逆」（R1）；原注把「五气在天为元亨利贞、赋在人为仁义礼智信之性」（R2）接上。所以论性情看的是四柱偏不偏、浊不浊，不是给某人贴性格标签。
2. **性情各象有固定的方向**：火「火烈而性燥者，遇金水之激」（R3）、水「水奔而性柔者，当火土之神」（R4）、木「木奔南而软怯」（R5）、金「金见水以流通」（R6）；再上「最拗者西水还南」（R7）「至刚者东火转北」（R8）；又分顺逆——「顺生之机，遇击神而抗」（R9）「逆生之序，见闲神而狂」（R10）；又分阳明阴浊——「阳明遇金，郁而多烦」（R11）「阳浊藏火，包而多滞」（R12）；末以羊刃局、伤官格两格收（R13）。
3. **疾病是「五行配五脏」的取象**：任注把「五行在天为五气、在地为五行、在人为五脏」（R14）立为框架；「五行和者，一世无灾」（R15）「血气乱者，生平多疾」（R16）讲和与乱；「忌神入五脏而病凶」（R17）「客神游六经而灾小」（R18）讲忌神与客神的轻重；再由反克说「木不受水者血病」（R19）「土不受火者气伤」（R20），并说「金水伤官……火土印绶……」这一类寒热燥湿之象（R21）。**这一整篇讲的是书里对「某类结构对应某类身体弱处」的取象，不是对人体状况的诊断。**
4. **出身讲「玄机暗里存」**：「巍巍科第迈迈伦，一个玄机暗里存」（R22）——出身最难断，要看支中藏神司命、包罗喜用，而不是明摆的杀印财官；「清得尽时黄榜客，虽存浊气亦中式」（R23）讲清气当权；「秀才不是尘凡子，清气还嫌官不起」（R24）讲有清气而无官爵；「异路功名莫说轻，日干得气遇财星」（R25）讲非科甲那条出身路。
5. **地位看「天然清气发机权」**：「台阁勋劳百世传，天然清气发机权」（R26）；再分「兵权獬豸弁冠客，刃煞神清气势特」（R27）、「分藩司牧财官和，清纯格局神气多」（R28）、「便是诸司并首领，也从清浊分形离」（R29）——品级高低都归到清浊与气机。
6. **岁运讲时间线上的休囚与战冲和好**：「休囚系乎运，尤系乎岁，战冲视孰降，和好视孰切」（R30），任注收到「富贵虽定乎格局，穷通实系乎运途」（R31）。篇内又给出盖头、截脚、战、冲、和、好几种情形的取象口径。
7. **贞元讲元亨利贞与「贞下起元」**：「造化起于元，亦止于贞。再肇贞元之会，胚胎嗣续之机」（R32）——以年月日时为元亨利贞，以大运一段段配元亨利贞，讲的是生生不息那个环；原注还把它引到「身后运」与子孙兴替上。

## A1：来源应用

书上给的做法，都是「先在某一篇里找到对应的那一句，再照它的口径摆取向」：

- **论性情**：先看五气偏全（R1、R2），再按火、水、木、金各象（R3–R6）与拗、刚、顺逆、阳明阴浊（R7–R12）对号，末看羊刃、伤官两格（R13）。
- **论疾病**：先立五行配五脏（R14），再看和乱（R15、R16）、忌神与客神的轻重（R17、R18）、反克与寒热燥湿之象（R19–R21）。**书上这套只作取象讲解，不可当成人身诊断。**
- **论出身**：先看支中藏神、喜用包裹是否「玄机暗里存」（R22），再分清得尽、有清气而无官、异路功名几种（R23–R25）。
- **论地位**：先看「天然清气」（R26），再按兵权、方面、首领几层分（R27–R29）。
- **论岁运**：按 R30、R31 的口径讲休囚系运、战冲和好、盖头截脚这些取象；**只讲口径，不替具体的人批某十年的成败**。
- **论贞元**：按 R32 讲元亨利贞的分配与「贞下起元」之意；**不据此预测任何人的寿数**。
- **报断语必须给两句**：凡引用书里的断语（「科甲」「仕至尚书」「一世无灾」之类），必须同时给出**原书依据（哪一篇、是经是原注还是任注）**与**取用条件（凭什么这么取）**；只报断语不出处的，一律不合格。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、四柱五气偏全（哪一气重、哪一气缺）、偏枯还是中和、有无羊刃局／伤官格、清浊之象、支中藏神与喜用包裹、可归到性情／出身／地位／歲運／貞元哪一篇。
2. **逐条核书里的条件**：性情 → R1、R2 定中和与乖逆，再按各象 R3–R13 对号；出身 → R22–R25；地位 → R26–R29；岁运 → 只讲 R30、R31 的口径；贞元 → R32 的分配；**疾病 → 只作 R14–R21 的取象讲解，绝不下人身诊断**。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「五气偏燥、偏枯，按 R1 这一路读，偏『性情乖逆』的取象」，并给出处（如「《滴天髓闡微》六親論·性情」）；**疾病这一层只给「书里的取象」，不落到这个人身上**。
4. **收口**：这一句是**书里的读法**，不是对这个人吉凶寿夭疾病生育的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：原书这六篇不讲后世流派的「运势打分」「健康指数」「寿元算法」；这些都不进本 skill，尤其不许拿它们去做疾病、寿夭、生育的判断。

9. **收口**　输入：整段推演 → 输出：一句界说 + 一句取向 + 一句出处；结尾说明本 skill 到取象为止，落到健康、寿命、生育、婚姻的都不接。
   🔴 **CHECKPOINT**：收口前确认——① 没把书里的评价语（「科甲」「仕至尚书」「一世无灾」之类）说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不替人决定**，且**疾病部分只做取象、不落人身**（此闸不因落盘而放开）；③ 报的格局或术语带得出卷次或篇名。用户若给了四柱要「看我健康／寿数」，照实说不接；缺柱则说要补什么。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 据八字下疾病诊断 | 由疾病篇的取值直接说「你有肝病／肾虚」 | 拉回 R14–R21：这是书里的五脏取象，不是诊断；建议就医 |
| 据八字预测寿命 | 由「气浊」「一世无灾」类句判某人寿数 | 说明本 skill 不预测寿命，贞元篇讲的也不是某人的寿数 |
| 据八字判生育或婚姻 | 由子女、夫妻之象给生育／婚姻结论 | 不接；只讲书里的取象，不做决定 |
| 把「性情」讲成人格诊断 | 说用户「性格必怎样」 | 拉回 R1：论性情看的是五气偏全，不是贴标签 |
| 替用户批流年大运 | 由岁运篇顺手报某年吉凶 | 收口在口径，只讲休囚战冲怎么读，不替人排十年 |
| 缺柱硬算 | 只有一句描述就断出身地位 | 停下，说缺哪柱、要到什么程度才能排 |

**边界规则**：
1. 只做这六篇的取象讲解，不替用户判终身、不落到具体人身上。
2. 只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 报断语必须同时给原书依据与取用条件。
6. 经文与原注／任注必须分栏标注。

**自查清单**：
- [ ] 每条 R 都是原书原话，并标了是經文还是原注／任注吗？
- [ ] 讲疾病时，说的是书里的取象，而不是对人身的诊断吗？
- [ ] 报断语时同时给了出处和取用条件吗？
- [ ] 有没有替用户批流年大运、预测寿数？
- [ ] 缺柱时是照实说，还是硬排了？

**安全兜底**：涉及就医、用药、危机时，只做提醒与陪伴，不做诊断；用户若有身体不适，直接建议就医。

## 📖 练习手册

- **总纲默写**：合上 R 节，写出性情篇总纲与它的原注各一句。
- **四象对号**：把火、水、木、金四象各配一句原文，写出各自的方向。
- **五脏取象辨认**：从疾病篇挑两句，改写成「书里这么说」（只讲取象，不做诊断）的写法。
- **出身与地位层次**：写出「玄机暗里存」「清得尽」「天然清气」「刃煞神清」各一句，标明层次差别。
- **元亨利贞配法**：写出贞元篇把年月日时配元亨利贞的做法，并说明它不预测寿数。

## 🚫 反例黑名单（不要做的事）

1. 由疾病篇的取值给出「你哪里有病」这类诊断。
2. 由八字的清浊、气机给某人预测寿命、寿数或生育。
3. 由性情篇给用户下「必是什么性格」的标签。
4. 替用户批流年大运、断某年吉凶或终身。
5. 缺出生柱就凭只言片语排出四柱往下断。
6. 用后世流派的「健康指数」「寿元算法」之类说法替原书背书。

## 灰色地带

- **用户把「性情」当心理测评**：照实说明论性情看的是五气偏全与清浊方向，不是心理诊断；若用户确在谈情绪困扰，建议寻求专业帮助。
- **用户把「疾病」篇当自检**：只讲书里的五行配五脏取象，明确它不构成诊断，并建议按身体状况就医。
- **用户问贞元篇的「身后运」**：照实讲书里把它引到子孙兴替的说法，并说明本 skill 不据此谈任何人的生死。
- **岁运篇与「不批流年大运」的张力**：篇内确有运岁的取象口径，可以照书讲解这些口径，但不替具体的人排某十年、不下成败断语。
- **同一结构书里断语有出入**（如有的命例说「一世无灾」、有的说「多病」）：据实并列，说明是书里各例的说法，不替用户挑一条拍板。
