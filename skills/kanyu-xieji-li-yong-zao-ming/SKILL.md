# 利用·选择要论与杨筠松造命歌

**来源**：`sources/xieji.txt`《欽定協紀辨方書》卷三十三·利用一（清乾隆官修，四庫本） ｜ 证据等级：firsthand（原书原话）/ inference（推断，须标注）

## 触发条件

**应该触发**：
- 用户想把「年月日时」配成一组，用来补龙、扶山、相主（造葬、修方、开山立向）。
- 用户问「造命是什么」「为什么要补龙」「为什么专看龙不看山」。
- 用户问杨筠松造命歌（千金歌）怎么读、四要指什么。
- 用户知道坐山朝向与主命生年，想据此挑年月日时。
- 用户问「这样配算不算真造命」，想辨真假。

**不应触发**：
- 用户只问单一神煞的起例（如三煞怎么起） → 义例类条目。
- 用户问具体怎么把凶煞制化、逐条制煞法 → `kanyu-xieji-zhi-sha`。
- 用户问公规历法（节气、中星、昼夜） → `kanyu-xieji-gong-gui`。
- 用户问世俗相沿条目或某说法站不站得住 → `kanyu-xieji-fu-lu` / `kanyu-xieji-bian-e`。
- 用户要断某人富贵寿夭、要现成结论 → 本条只给造命框架，不做命定论。

## R：原文锚点

1. 「選擇之道有體有用龍山方向之一定者體也年月日時之無定者用也補龍扶山制凶助吉以無定而合有定者用之體也弔替飛宫合局相主以無定而合無定者用之用也錯綜參伍精義入神庶足前民而利用矣作利用」（《欽定協紀辨方書》卷三十三·利用一）
2. 「藏神者收藏地中元神也其法選成四柱八字支干純粹成格成局扵以扶補龍氣則地脉旺盛而上騰於墳宅之中」（《欽定協紀辨方書》卷三十三·選擇要論）
3. 「合朔者取初一日太陽太隂合照之義舉一以該百也其法取三竒三徳金水紫白貴人禄馬到山到向自然吉慶」（《欽定協紀辨方書》卷三十三·選擇要論）
4. 「造命之法一看來龍宜何局以補之二看山向何煞宜避何煞可制以何法制之取何吉星照之三看主人本命宜何如以扶之三者俱得而後舉事吉無不利矣」（《欽定協紀辨方書》卷三十三·選擇要論）
5. 「彼選定八字不問龍山主命而槩施之乃假造命也扵古法天淵矣學者當辨别其是非以定從違庻無差悮」（《欽定協紀辨方書》卷三十三·選擇要論）
6. 「天機妙訣值千金不用行年與姓音但看山頭併命位五行生旺好推尋」（《欽定協紀辨方書》卷三十三·楊筠松造命歌）
7. 「一要隂陽不溷雜二要坐向逢三合三要明星入向來四要帝星當六甲四中失一還無妨若是平分便非法」（《欽定協紀辨方書》卷三十三·楊筠松造命歌）
8. 「𦵏以補龍為主而山向亡命次之造以山向主命為重而補龍次之」（《欽定協紀辨方書》卷三十三·論造𦵏）
9. 「凡入其鄉而星峰竒特龍神秀拔富貴無疑入其鄉而山岡撩亂龍神卑弱貧賤無疑禍福之本總屬之龍擇日而不補龍又何必擇知補龍之説而此道之元樞得矣」（《欽定協紀辨方書》卷三十三·論補龍）
10. 「相主者何以四柱八字輔相主人之命也從來皆論生年不論生日有論生日者非古法也」（《欽定協紀辨方書》卷三十三·論相主）

## I：核心解释

造命法的总纲在第一句里：选择之道有体有用。龙、山、方向是「一定者」，是体；年月日时是「无定者」，是用。所谓造命，就是用无定的四柱去合有定的龙与山——补龙扶山、制凶助吉。它不是另找一个吉日，而是把日子造成对这座龙、这方山、这个主人「合适」的一组八字。

1. **体用之辨**：龙与山向是体，年月日时是用。书里把「以无定合有定」称为「用之体」，把「以无定合无定」（吊替、飞宫、合局、相主一类的灵活取法）称为「用之用」。本体立不住，用再花也无益——所以下文才说「宁舍用而取体」。
2. **藏神与合朔——造命之体与用**：藏神＝收藏地中元神，做法是选成四柱八字，支干纯粹、成格成局，用来扶补龙气，使地脉旺盛上腾于坟宅之中，这是造命之「体」；合朔＝取初一日太阳太阴合照之义（举一以该百），做法是取三奇三德、金水紫白、贵人禄马到山到向，自然吉庆，这是造命之「用」。书里还说，必先在年月之内推求山向吉神相迎、岁破三煞阴府等尽行退避不相干犯，才是「神迎鬼避」——这是体中最紧的一环。
3. **造命三步**：一看来龙宜何局以补；二看山向何煞宜避、何煞可制、以何法制之、取何吉星照之；三看主人本命宜何如以扶。三者俱得而后举事。
4. **不用行年与姓音**：造命歌开篇即「不用行年与姓音，但看山头并命位，五行生旺好推寻」。行年指几十几岁之类，姓音即五姓修宅；书里说世俗以此二者分吉凶「谬甚」，故不用。（五姓修宅的是非，另见附錄与辨讹两条目。）
5. **造命四要**：「一要阴阳不混杂，二要坐向逢三合，三要明星入向来，四要帝星当六甲。四中失一还无妨，若是平分便非法」。四要得全为上，失一犹可，失二得二便非法。
6. **补龙是全功之本**：书里说「祸福之本总属之龙」，择日而不补龙，又何必择；又特地点出「古人重龙不重山」——补龙以三合局（或一气局）为主，参以纳音之说。葬与造的侧重不同：葬以补龙为主、山向亡命次之；造以山向主命为重、补龙次之。
7. **相主只论生年**：相主是以四柱八字辅助主人之命，且「从来皆论生年，不论生日」。修造以宅长一人之命为主，葬以亡命为主。
8. **真假造命**：书里最重的一句警告——若不问龙山主命，只拿一副选定的八字一概施之，那是「假造命」，与古法天渊之别。所以本条的每一步都必须回到这座龙、这方山、这位主人身上，否则就是假造命。

## A1：来源应用

**补龙取局（卷三十三·論補龍，以正五行论）**：亥壬子癸四龙属水，生申旺子墓辰，用申子辰为三合旺局上吉，临官在亥亦吉，巳酉丑为印局亦吉，寅午戌为财局次吉，亥卯未为泄局凶，辰戌丑未为鬼煞局尤凶；艮坤辰戌丑未六龙属土，亦生申旺子墓辰，以申子辰为旺局亦土克水财局上吉，寅午戌为印局亦吉，金局泄、木局克皆凶；寅甲卯乙巽龙属木，生亥旺卯墓未，以亥卯未为旺局上吉，临官在寅，申子辰为印局亦吉，巳酉丑为煞局、寅午戌为泄局皆凶；巳丙午丁四龙属火，生寅旺午墓戌，以寅午戌为三合局上吉，亥卯未为印局吉，巳酉丑为财局次吉，申子辰为煞局凶，辰戌丑未土局泄气亦凶；申庚酉辛乾五龙属金，生巳旺酉墓丑，以巳酉丑为三合金局上吉，辰戌丑未土为印局（然相冲不吉），亥卯未为财局次吉，申子辰为泄局凶，寅午戌为煞局尤凶。补龙全在四柱地支（天干气轻、地支力重）；三合字不必全，二字亦可。

**补龙古课示例**：亥龙乾山巽向，曾文辿用壬寅年壬寅月壬寅日壬寅时；亥龙壬山丙向，杨筠松取辛亥年庚子月丙申日丙申时；壬龙子山午向，杨筠松取四癸亥；艮龙甲山庚向，杨筠松取丙辰年丙申月丙申日丙申时。这些课的共同点是补龙为主，又不冲克坐山、不冲克主命，且坐山有吉神、主命或比肩或合财合官，或会合四柱禄马贵人、或禄马贵人到山到向。

**相主诸格（卷三十三·論相主）**：合官（如乙命与庚合）、合财（如壬命与丁合）、比肩（如己命见四己）、印绶（甲命宜四癸、乙命宜四壬，宜正印忌枭印）、四长生（壬生人用四申、丙生人用四寅）、食禄（甲命以丙为食神，丙禄在巳，四柱多用巳）、禄马贵人（宜四柱活动取之）。所忌者，七煞大能克命，天克地冲最凶，太岁冲命最凶，本命羊刃切忌多见；天罡四煞（岁煞）造葬皆忌。

**扶山与立向（卷三十三·論扶山、論立向）**：坐山不必补，但宜扶起不宜克倒——有吉星照、无大凶煞占、八字相合不冲不克即是扶。太岁冲山、三煞阴府年克及伏兵大祸占山则倒。向不必补，但有吉星而无凶煞即可；凶煞指太岁、戊己煞、地支三煞、浮天空亡，其中太岁可坐不可向。

**造葬权变（卷三十四·造葬权法，卷三十三·論造葬亦及）**：凡修造要身命、年月、方向皆利则吉；不得已而作，则可迁居、就所修之方择吉方起工（吉方起手、连及不利之宫），或在大寒后立春前择日完工，谓「岁官交承」。这属变通之法，非真造命。

## E：执行步骤

1. **定龙与山向**　输入：用户给的来龙（入首一节的五行）与坐山朝向 → 输出：龙与山的五行、宜用的三合／印／财局。
   🔴 **CHECKPOINT**：把「龙五行→宜用局→忌用局」与坐山朝向列成一小表展示，等用户确认形势与朝向无误；来龙、坐山都说不清就停在这里问，不许替用户编一个龙来。
2. **定山向的避与制**　输入：坐山朝向与拟用的年月范围 → 输出：山向须避之煞（岁破、三煞、阴府、年克、伏兵大祸等）与可制之煞及制法的方向（细则转 `kanyu-xieji-zhi-sha`）。
3. **定主命**　输入：主人（或亡命）生年 → 输出：相主格（合官／合财／比肩／印绶／四长生／食禄／禄马贵人）及所忌（七煞、天克地冲、太岁冲命、羊刃、天罡四煞）。
4. **取吉星照临**　输入：山向与主命四柱的取法 → 输出：三奇三德、金水紫白、贵人禄马到山到向的取用方向。
5. **成四柱并判定体用**　输入：以上三条的取用 → 输出：一组四柱草案（地支补龙、干支纯粹成格成局）＋体用判定（补龙是否为体、吉星是否为用）。
6. **辨真假造命**　输入：草成的四柱 → 输出：是否「不问龙山主命而概施之」的假造命；真则给出「一看龙、二看山向、三看主命」三者俱得的结论，假则退回第 1 步重来。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 不问龙山主命，直接给八字 | 拿通书一类的「大吉年月」套上去 | 正是书里说的「假造命」；退回第 1 步先定龙与山向 |
| 只补山不补龙 | 只照坐山五行取局 | 书里「古人重龙不重山」，以补龙为主，坐山有吉星无凶煞即可 |
| 拿行年、姓音定吉凶 | 按年龄或姓音分吉凶 | 造命歌明说「不用行年与姓音」；不用此二者 |
| 见合即吉、不顾冲克 | 只挑合官合财，不管地支刑冲 | 四柱切忌地支相冲，冲龙冲山冲主命大凶；合与冲同时看 |
| 把造命说成必然富贵 | 报「必发贵、必兴旺」 | 书里只说造命以补龙相主为宗，福应属书里的话；只给倾向，不写保证 |
| 造葬一体照搬 | 造宅也照葬法以补龙为第一 | 葬以补龙为主、造以山向主命为重，两者侧重不同 |

**边界规则**：
1. 本条只给造命的框架与取用方向，不给阴宅实地作业指导（下葬的现场操作是要人到现场、担后果的事），不接此类请求。
2. **硬口径**：凡报神煞、报宜忌，必须同时给起例来源与卷次依据；只报一个煞名而不说出处＝不合格。**不要把书里已经辨误的世俗说法当成书的主张**（如五姓修宅、周堂之类的是非，见 `kanyu-xieji-bian-e`）。
3. 缺具体日期或事项，就说缺什么、要到什么程度才能判，**不许用占位信息硬判**。
4. 象征层只给倾向，不写「一定／必然／命中／保证」；不给医疗、法律、投资结论；不替用户拍板。

**来源边界**：本条只据卷三十三原文；四柱法、用日法、用时法与逐条制煞法的细则在卷三十四（`kanyu-xieji-zhi-sha`），本条不自造细则。

**安全兜底**：涉及就医、用药、危机时只做提醒与陪伴，不做诊断；不承接阴宅实地作业。

## 练习手册

- **体用默写**：合上本页，写出「龙、山、向为体，年月日时为用」，以及造命三看（看龙补局／看山向避制／看主命扶助），再对照原文。
- **一龙配局**：取一个来龙，按补龙表写出它的旺局、临官、印局、财局与凶局，并说明为什么这样配。
- **真假课辨认**：找几副现成课（或自拟），逐副检查是否问过龙山主命；把「不问龙山主命而概施」的挑出来标为假造命。

## 灰色地带

- **来龙说不清**：城市居宅或远龙难测时，书里给的办法是「宜补坐山与补龙法同」，但仍须先有坐山。用户连坐山都给不出，就只讲框架，不配四柱。
- **一气局与三合局取舍**：地支一气局极妙但难逢难遇，三合局活动易取。书里两可，实操上不硬断孰优，按用户手上的年份能取到什么算什么，并说明各自代价。
- **葬与造的边界**：同一个日期，用于葬与用于造，侧重不同（补龙／山向主命）。用户把两者混在一件事里时，先问清是葬还是造，再定侧重。
- **星曜取用争议**：书里说日最尊，月与三奇、窍马、紫白次之；又明斥玉皇銮驾等星「捏造而无据」。遇到用户提起后者，按书里态度标为无据，不当作可用之吉星。
- **造命与权变**：不得已而作时（岁官交承、迁居修方），书里承认是变通，非真造命。用户问这类取巧之法时，如实说明是权宜，不把它说成与真实造命等值。
