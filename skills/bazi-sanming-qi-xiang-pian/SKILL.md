# 氣象篇：先看气象规模，再论用神出处

**来源**：sources/sanmingtonghui.txt（《三命通會》卷十一·氣象篇，醉醒子撰） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 为 bazi-hub 的子技能，闸门与 hub 同口径：用户没有显式说出八字、四柱、命理、格局、十神这类词，整行不显示、不激活。

## I：核心解释

氣象篇开篇就把看命分成两刀：先看整体气象的规模，再论用神的出处。

1. **两刀次序**。R1 说「先觀氣象規模乃富貴貧賤之綱領，次論用神出處盡死生窮達之精微」——先看整体气象定贵贱方向，再找用神出处讲穷达。开篇还点出今人的毛病是「拘泥格局，遂執假而失真」，又说「不須八字繁華，只要五行和氣」（R2）：重在五行之和，不在字面热闹。
2. **刚柔两种气象**。R3「陽剛不中亢則害也，剛而能柔吉之道也」、R4「柔弱偏枯小人之象，剛健中正君子之風」：刚要有制、能柔才是吉；柔弱偏枯则成小人之象，刚健中正才是君子之风。注里把「亢陽無制」与「五陽生於陰月、干支夾合陰柔」两类各说一句。
3. **一连串「過於」的失衡**。R5–R8 是一组：寒薄与燥烈是寒暖的过头，执實与清冷是通塞的过头，有情是牵迷自脱不得、用力是扶持太过。书里对每一种都给一句后果（難奮發、有凶灾、事難顯豁、思有凄凉、志無遠達、成亦多難）。读的时候要按「哪一种过头」对号。
4. **得所与失垣是一对**。R12「五行各得其所者歸聚成福」、R13「一局皆失其垣者流蕩無依」：五行各得其所则归聚成福；一局都失了垣（不着落、无通根）则流荡无依。
5. **救应的两句**。R10「吉神相我功求相吉之神」、R11「凶物傷身解用傷凶之物」：命哀弱要靠吉神扶佐时，要看相我之神的势力轻重，无根失令则先求助相吉之神；遇凶神克身，就求柱中能制伤我之神的那一味，使它自解不暇。两句都是讲「谁来救」。
6. **一将当关与众凶**。R14「一將當關羣邪自服」、R15「衆凶尅主隻力難勝」：一要处有贵重之神当关，众邪自服；煞重身轻而孤独无助，则不能胜所克。
7. **六合与三刑都能成美**。R16「六合有功權尊六部」、R17「三刑得用威鎮三邊」：刑冲克害本为凶象，得神挽合有力则反为祥；三刑有气、日主刚强则为得用。两句都说「吉凶看能不能用」。
8. **福满与凶多**。R19「福滿須防有禍凶多未必無禎」：用印生身太过的，福满处怕生祸；官煞多的，历尽艰险后否极泰来。阴阳消长、祸福倚伏的意思。
9. **偏枯的例子**。R20「妻多力弱花粉生涯馬弱比多形骸飄泊」：财多而日主孤弱不能任用，则逐财劳苦；这是前面「失垣流荡」的一个具体落点。
10. **格与课的两句**。R18「學堂逢驛馬山斗文章」：身坐长生为学堂，再得驿马交驰，一冲一合，书里说文章挺拔出尘。
11. **命例两则**。注里以「明太祖命戊辰壬戌丁丑丁未」（R21）系到大林龙值天河、四库土全的一格；又以王陽明壬辰辛亥癸亥癸亥系到长流龙归大海的一格。这两条是原书用来印证「大林龍出」「長流龍復歸大海」两格的命例——引用时标明是注里的命例，不作对现实人物的评断。
12. **一句话读法**：氣象篇先看一组四柱整体的刚柔、寒暖、清浊、有情无情是否「得中」，再看用神落在哪里；不平则按「哪一种過於」对号，失衡处看救应。

## A1：来源应用

书上给的做法：

- **先气象、后用神**：先看整体规模定贵贱纲领，再找用神出处讲穷达（R1），不先拘泥于某个格局名（开篇即戒「拘泥格局」）。
- **看刚柔得中**：阳刚要能柔、要藏阴，不犯破克刑冲；柔弱偏枯则不是君子之风（R3、R4 及其注）。
- **对号「過於」**：寒薄、燥烈、执實、清冷、有情、用力六种过头各对一句后果，失衡即按此找病（R5–R8）。
- **看五行有否着落**：各得其所、归聚成福；失垣、无通根、逢空亡死绝则流荡（R12、R13）。
- **找救应**：靠吉神则求相吉之神，遇凶则求能伤凶之物（R10、R11）。
- **看当关之神**：要紧处有贵重之神当关则群邪自服，煞重身轻孤独无助则难胜（R14、R15）。
- **刑合看用**：六合挽合有力、三刑有气日主刚强，都可反为祥（R16、R17）。
- **祸福倚伏**：福满防祸、凶多未必无祯（R19）。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：四柱干支、日主、月令，柱中能看出的刚柔（阳干／阴干、有无制）、寒暖燥湿（水火土分布）、有无刑冲合、有无通根着落。
2. **逐条核书里的条件**：刚柔得中否 → R3「剛而能柔吉之道也」、R4「柔弱偏枯小人之象」；寒暖通塞情力是不是「過於」→ R5–R8；五行是否各得其所 → R12「歸聚成福」、R13「流蕩無依」；靠谁来救 → R10「吉神相我」、R11「凶物傷身」；当关之神与刑合 → R14、R15、R16、R17；福祸倚伏 → R19。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「刚而欠柔，按 R3 这一类读，偏『陽剛不中亢則害也』」，并带出处（如「《三命通會》卷十一·氣象篇」）。
4. **收口**：这一句是**书里的读法**，不是对这个人富贵的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**；书里的评价语（小人、流荡、漂泊）与注中的命例都不落到具体的人身上。

**书里没有的、不要加**：本篇是气象规模的断语与命例，不含「旺衰计分」「自动判气象」这类做法；注里的「明太祖」「王陽明」是原书用来自证两格的命例，只是书里的举例，不作对现实人物的评断。要断某人的终身、寿夭、婚姻，不在本 skill 范围内。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–5 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 6–7 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **分两刀**（文本解读）　输入：用户所引的一句 → 输出：判定这句是在讲「氣象規模」还是在讲「用神出處」，或落在某一类失衡上。
   🔴 **CHECKPOINT**：用户直接问「我这八字是什么格」时，先说明本 skill 走的是先气象、后取用的路子，成格破格要转 bazi-sanming-ge-ju，问用户要哪个。
3. **认失衡**（文本解读）　输入：这句 → 输出：若属「過於」一组，指出是寒暖、通塞、情、力哪一类过头，配原句的后果。
4. **看着落与救应**（文本解读）　输入：整组四柱的规模 → 输出：按 R12、R13 判有无着落，按 R10、R11 讲求谁来救，按 R14、R15 讲当关之神。
5. **刑合与祸福**（文本解读）　输入：涉及刑合或福祸的句子 → 输出：按 R16、R17 讲「能不能用」，按 R19 讲倚伏。
6. **取盘上的料**（落盘）　输入：用户四柱 → 输出：四柱干支、日主、月令，柱中能看出的刚柔（阳干／阴干、有无制）、寒暖燥湿（水火土分布）、有无刑冲合、有无通根着落。
7. **逐条核条件、给读法**（落盘）　输入：第 6 步的料 ＋ 本 skill 的条件 → 输出：
   - 刚柔得中否 → R3「剛而能柔吉之道也」、R4「柔弱偏枯小人之象」；寒暖通塞情力是不是「過於」→ R5–R8；五行是否各得其所 → R12、R13；靠谁来救 → R10、R11；当关之神与刑合 → R14–R17；福祸倚伏 → R19；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷十一·氣象篇」）。
8. **收口**　输入：整段推演 → 输出：一句「先看规模，后取用神」＋一句「哪一种過於、谁来救」；若用户追问某个具体人的终身吉凶，照实说本 skill 只讲原书的气象读法，不替人断。
   🔴 **CHECKPOINT**：收口前确认——① 没把书里的评价语（柔弱偏枯、小人、流荡、漂泊）落成对某人的事实，也没把注里的命例（明太祖、王陽明）说成对现实人物的评断；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格／术语带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 跳过气象直接取用神 | 一上来就报用神，不谈规模 | 拉回 R1 的次序：先规模后用神 |
| 把「過於」一律当凶 | 见「過於」就说命坏 | 按原句分开：每种过头各配一句后果，不说成事实 |
| 把刑合读死 | 说三刑一定凶、六合一定吉 | 回到 R16、R17「得用」「有功」的条件 |
