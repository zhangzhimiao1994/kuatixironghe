# 繫辭上傳

**来源**：`sources/zhouyi-jing.txt`（經文）、`sources/zhouyi-zhengyi.txt`（王弼／韓康伯注＋孔穎達疏）、`sources/zhouyi-benyi.txt`（朱熹本義） ｜ 证据等级：firsthand（原书原话）

> 本 skill 只做**读法**：认篇、分层、并陈两家注疏。**不起卦、不占卜、不预测结果、不替用户决定**。大衍之数、蓍策之数这类内容是**书里讲的揲蓍之法**，转述时标明来历，不替任何人算结果。

## 触发条件

**应该触发**（用户会怎么说话）：
- 直接问到「繫辞上」「系辞上」「天尊地卑」「乾以易知坤以简能」「大衍之数」「形而上者谓之道」这类句子，想知道它出自哪里、在讲什么。
- 想弄清「易简」是什么意思、「设卦观象」和「繫辞焉而明吉凶」是怎么接上的。
- 想弄清大衍之数与揲蓍之法在书里怎么写、诸家怎么说。
- 手里有一件具体的事，想知道「按繫辞上这一路读，偏简还是偏繁、偏守还是偏动」，要一个带出处的读法。

**不应触发**（看起来像但其实不是）：
- 想让我「用大衍之数起一卦」「算出结果」→ 本族不做占筮。
- 想让一篇文章替自己预测结果、下结论 → 只给读法。
- 问的是下经卦爻辞、彖传、象传、说卦 → 走各自的对口 skill。
- 问的是「作易者其有忧患」「天地设位圣人成能」那一路 → 那是繫辞下传。

## R：原文锚点

> 逐字抄自包内三本源文件，繁体照原样。每条带篇名与字形层（經文／王弼韩康伯注／孔颖达疏／朱熹本义）。正義的卷次与经文篇章不完全对齐，这里一律按**经文所属篇章**标（繫辞上／繫辞下）。

## I：核心解释

繫辞上是一篇**通论**：它不是解释某一卦，而是把「易这部书是怎么回事」讲一遍——它是「孔子所述繫辞之传……通论一经之大体凡例，故无经可附」（R30）。所以它没有可附的卦，自己分成上下两篇。

1. **易简是这一篇的骨架**：乾以易知、坤以简能（R2）；易简而天下之理得（R3）。孔疏把它讲成「天以刚阳而尊，地以柔阴而卑，则乾坤之体安定」（R24），朱子讲成「乾健而动，即其所知便能始物而无所谓难」（R32）。
2. **设卦观象 → 繫辞明吉凶**：圣人先「设卦观象」，再「繫辞焉而明吉凶」（R4）；孔疏说「若不繫辞，其理未显」（R26）。**卦象是形，繫辞是把吉凶说出来的那层**。
3. **大衍之数是揲蓍之法**：五十、用四十九、分二挂一揲四归奇（R11–R13）。书里明说这套义有多家（R27），朱子则给出一种来历（R34）。
4. **易有太极、形上形下**：从太极到八卦是一条**生成链**（R16）；「形而上者谓之道，形而下者谓之器」（R18），孔疏解为「道是无体之名，形是有质之称」（R29）。
5. **书不尽言**：立象、设卦、繫辞，都是用来**尽意、尽情伪、尽其言**的（R17）；所以读易先读象与辞，不急着求结果。

### 两说并陈（不调停，各标出处）

- **「大衍之数五十」的来历**：孔疏列京房、马季长、荀爽、郑康成、姚信董遇多家，「义有多家，各有其说，未知孰是」，最后依王弼「演天地之数，所赖者五十」（R22、R27）；朱子本义则明说「盖以河图中宫天五乘地十而得之」（R34）。两说取径不同，都摆出来。
- **「易简」的性质**：王弼注讲「天地之道，不为而善始，不劳而善成，故曰易简」（R21）；朱子讲「乾健而动……坤顺而静」（R32）。一家从天道说，一家从乾坤之性说。
- **篇章次序的取法**：孔疏「从先儒以十二章为定」，按旧本次序讲；朱子本义据程子意见把「天一地二」一节**前移**，并说「此简本在第十章之首，程子曰宜在此，今从之」（见《周易本義》繫辭上大衍章注）。两家对同一章的**位置**取法不同，如实并陈，不合并。

## A1：来源应用

书里给的读法（不是本 skill 的发挥）：

- **认篇**：繫辞上「通论一经之大体凡例」（R30），不系某一卦；看到「天尊地卑」「大衍之数」就知道在繫辞上。
- **分层**：经文在 `zhouyi-jing.txt`；`zhouyi-zhengyi.txt` 的〈 〉是王弼／韩康伯注，带`【疏】`的是孔颖达疏；`zhouyi-benyi.txt` 的〈 〉是朱熹本义。
- **先经后注疏**：经文给字面（R1–R19），注疏给解释与分歧（R20–R35）。
- **照着读，不照着算**：大衍一章讲的是**揲蓍之法**（R11–R13），是书里的方法记载，本 skill 只转述它讲了什么，不利用它替用户求卦。

## E：执行步骤

先判**用户输入里有没有他要问的那件事**，两条路走法不同（判据只有这一条）。

1. **步骤一｜认路（判据：有没有「某件事」）**　输入：用户原话 → 输出：判为「文本解读」还是「落到处境上的读法」。
   - 问「这一句／这一篇书里怎么讲、出自哪一篇」→ 走**文本解读**。
   - 问「我这件具体的事怎么看」→ 走**落到处境上的读法**。
   🔴 **CHECKPOINT**：既问书又问事，先按第 3 步读，再把书里的原话补上。

2. **步骤二｜文本解读**　输入：句子或篇名 → 输出：① 认篇（繫辞上／繫辞下，引文带篇名与层：经文／注／疏）；② 摆书里的字面与条件（如大衍之数怎么用、易简是哪两件事）；③ 有分歧就两说并陈（如大衍来历、易简性质）。
   🔴 **CHECKPOINT**：引文逐字、带出处；拿不准就不引。

3. **步骤三｜落到处境上的读法**　输入：用户那件具体的事 → 输出：① 把事归到繫辞上里的**一类处境**（如「什么都想抓、越做越繁」对 R2–R3 的「易简」；「只看形、不看象与辞就下判断」对 R4、R17）；② 说清凭**哪一条**（引哪句、什么层、什么篇）；③ 给**「按书里这一类读，偏 X」**（偏简／偏守／偏先观象玩辞）＋**出处**。
   🔴 **CHECKPOINT**：只写「按书里这一类读，偏……」，**不写「一定／必然／命中」**，不当成对结果的判决。

4. **步骤四｜收口**　输入：前一步的读法 → 输出：把话收到边界内——**本 skill 不起卦、不占卜、不预测结果、不替用户决定**；大衍之数只当书里的方法记载转述，不替任何人求卦；结尾落一句用户自己能去核实或自己决定的事。
   🔴 **CHECKPOINT**：结尾不出现内部归类名（成员 slug、目录名、「属于 XX 类处境」这类标签）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 用大衍之数起卦 | 给用户排蓍、算数、报结果 | 照实说明本族不做占筮，只转述书里怎么讲 |
| 把疏当经 | 引了孔疏却说是「繫辞曰」 | 回书核：经文在 `zhouyi-jing.txt`，〈 〉是注，`【疏】`是疏 |
| 两家调停 | 把大衍五十的各家说法揉成一句 | 拆开，各标出处，并说明哪家依从哪家 |
| 结果断语 | 「易简，所以你该简化，一定会顺」 | 改成「按书里这一类读，偏简」，标出是书里的用语 |
| 替用户拍板 | 「你应当……」 | 只给读法与方向，决定权留给用户 |
| 章节混淆 | 把「作易者其有忧患」当繫辞上 | 那在繫辞下传，改对口 |

**边界规则**：
1. 只读繫辞上，不把下传各章混进来（下传走对口 skill）。
2. 吉凶词（「吉凶」「悔吝」「无咎」）注明是**书里的用语**。
3. 数据不足以归到哪一章哪一句时**照实说缺什么**，不硬套。

**自查清单**：
- [ ] R 引文逐字、带篇名、标了经／注／疏？
- [ ] 有分歧的地方两说都摆了、各标出处？
- [ ] 有没有写成「一定／必然／命中／保证」？
- [ ] 有没有起卦／占卜／预测／替用户决定？
- [ ] 回答里有没有内部归类名？

**安全兜底**：涉及就医／用药／危机时，只做提醒与陪伴，不做诊断。

## 灰色地带

- **同一句两说都成立**：如大衍之数来历，不判谁对；把两家的依据各自说清。
- **用户只要书、不要读法**：按文本解读走，不硬往处境上引。
- **用户只要读法、不认书**：先给完整读法（归属＋出处），再讲书里的来历；不因他不看书就省掉出处。
- **易简与「抓细节」冲突**：书里「易简」讲的是乾坤之德与圣人法之，不是让人粗疏；两义并陈，照实说明哪一处是书里的分寸。
