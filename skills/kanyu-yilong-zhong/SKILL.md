# 疑龙经·中篇：枝中干、州县都会

**来源**：`sources/hanlongjing.txt`（唐楊筠松《疑龍經》中篇，四庫本）｜互校：`sources/yilongjing.txt`（《疑龍經》中篇，維基文庫本）｜证据等级：firsthand（原书原话）

## I：核心解释

中篇接着上篇的干枝，往下追一层：**干不只在干上，枝里也藏干；落了地方的干，就是州县都会**。每条都能追回上面的锚点。

1. **枝中之干决定格局大小。** 「雖然已識枝中幹，長作京都短作縣」——同一套「干」的判断，放到地方上，走得长的那一段作京都，短的那一段作县。判格局先看这一段干有多长，不先看峰多高。

2. **穷处也有都会。** 上篇说干穷处是疑点，中篇进一步：「只恐尋龍到此窮，两水夾來風蕩散。也有方州并大邑，直到水窮山絶巗。也有城隍一都㑹，深在山原隈僻畔」。水穷山绝、山原僻畔之处，书里认它也可能藏着方州大邑，不必因荒僻就否定。

3. **穷处先转，再看枝上。** 「今日君尋到水窮，砂礫坦然纒䕶竄。右尋無穴左無形，無穴無形却尋轉，尋轉分枝上覔穴」——到穷处若左右都无形穴可认，就顺着分枝回转再找。此时容易「惟見縱横枝葉亂」，识得转换、缠、护托、断这四样，仍可能「狐疑難捉穴」。

4. **分背面的第一法：看缠水的回抱。** 「枝幹亂時分背靣。假如两水夾龍來，便看外纒那邊回」——两水夹龙，看外缠从哪边回抱。回抱、水隈之处是「面」（背底缠山缠水之处为背的反面）。缠护还有大小之分：「護纒亦自有大小，大小隨龍長短來，龍長纒䕶亦長逺，龍短纒䕶亦近挨」。

5. **分背面的第二法：面的宽平、背的陡岩。** 「若是靣時寛且平，若是背時多陡巖。靣時平坦中立穴，局内必定朝水緩」——面宽平、立穴，局内朝水缓而萦纡入怀；背则「水割石巖龍背轉」，浪打风吹、风荡而散。所以「寛平大曲處尋穴，此為大地斷無疑」。

6. **缠山必回转，明堂不可外截。** 「大抵纒山必回轉，莫把明堂向外截。曲轉之形必是靣」——缠山都是回抱的，曲转的那一面才是面。若把明堂向外的方向当作面，就截错了。缠山缠水还常「如扆屏」，向前宽阔的是面，「只恐明堂狹不寛」的则欠。

7. **结穴处有罗星先后的次序。** 「後纒抱來結水口，前頭生腳來相湊。两山两水作一關，更看羅星識先後。羅星亦自有首尾，首逆上頭尾拖水」——水口与两山两水成关，罗星分辨先后；「秤定上下左右手，的有真龍在此中」，要左右上下对称着核。

8. **朝水与案山有顺逆之别。** 「只愛案山逼水轉，不愛順流隨水勢。順流隨水案無力，此處名為破城裏。若是逆水作案山，關得外垣無走氣」——案山逼水回转为有力，随水顺流则无力，书里叫「破城裡」；逆水作案山才能关住外垣不走气。

9. **无水无山时，只要众水聚处。** 「也有真形無朝山，只要諸水聚其間。汪汪萬頃明堂外，内局周回如抱環」——即使没有朝山，只要众水聚在明堂外、内局回环，也成立。这与「两水之中必有山，两山之中必有水」（「山水相夾是機源」）是一体两面：山与水互相夹持，才是机的本源。

10. **十山十水的收束。** 「假如十條山同聚，必有十水歸一處。其間一水是出門，九山同來作門戸」——十条山同聚，十水归一处，其中一水作出门，九山作门户。要「東行看西西山好，西上看東東山妙」，左右互看，十山九水同聚处，居中者为贵：「貴龍居中必異常」。

11. **分贵贱：真龙不肯作朝。** 「真龍不肯為朝見。凡有星峯去作朝，此龍骨裏福潛消」——凡有星峰出去作朝山的，这条龙本身的气就潜消了，书里比作「吏兵與臣僕，終朝跪起庭前伏」。尊星、贵龙出入有帐，「賤龍無帳空雄强」。但也不能只论长：「龍無貴賤只論長，纒龍逺出前更强」——缠龙远出有时反比主身强，须长与贵合看。

12. **鬼山与官星。** 「逆轉之龍有鬼山，鬼山拖脚皆後環」；「識得背靣更識鬼，識鬼之外更識官」——逆转之龙后方拖脚的环抱是鬼山，识了鬼还要识官（官星）。「幹龍若是有鬼山，回轉向前寛處安」；若干龙行尽无鬼山，「須看衆水聚何處，衆水聚處是明堂，左右交牙鎖真氣」。

13. **寻龙要寻顿伏，建都要先识龙关。** 「古人尋龍尋頓伏，葢縁頓伏生尖曲，曲轉之餘必生枝，枝上必為小關局」——顿伏（跌断起伏）才会生出尖、曲，曲转之余分枝，枝上是小关局。「古人建都與建邑，先尋頓伏識龍關」；书里引「升虛望楚」「降觀於桑」「度其夕陽」「陟彼百泉」等语，说明古人卜宅是「詳審」之事（「古人卜宅貴詳審」）。

14. **顿伏处是主干换气、分枝的关节。** 「頓宿之所雖未住，亦有從行并部曲」——顿伏虽是歇脚未住之处，也带着随行的部曲。所以看一段龙，顿伏的位置既是它换气的地方，也是它「必為小關局」的分枝处；判州县级别时，顿伏是绕不过去的一站，不能一路平铺直判。

## A1：来源应用

书上给出的具体做法：

1. **以长短定格局**：同一套干枝判法，长段作京都、短段作县；先量这一段干的长短，再看聚落级别。
2. **穷处不当死地**：水穷山绝、僻畔之处，也按「有都会」的一种可能去核，不先排除。
3. **缠水回抱定面**：两水夹龙，看外缠哪边回抱，回抱为面。
4. **宽平对陡岩**：面时宽平可立穴、朝水缓；背时陡岩、风荡散。
5. **缠山必回转，明堂向内**：凡缠山都回抱，曲转的一面才是面；明堂不可向外截。
6. **水口罗星辨先后**：两山两水成关，看罗星首尾、首逆尾拖水，上下左右对称核。
7. **案山逼水为有力**：逆水作案山能关外垣；顺流随水叫破城里。
8. **无水无山靠众水聚**：无朝山时，只看众水是否聚于明堂外、内局是否回环。
9. **十山十水，居中为贵**：十山九水同聚，居中者异常。
10. **真龙不作朝**：出去作朝山的多是旁从，龙身本身要留作主。
11. **识鬼识官**：逆转之龙后方拖脚环抱是鬼山，识鬼之外还要识官星。
12. **先寻顿伏识龙关**：寻龙先找跌断起伏，建都建邑也先寻顿伏认龙关。

## E：执行步骤

1. **建形势底账**　输入：用户的形势描述、舆图范围 → 输出：事实清单（两水关系、可疑的干段、水穷处、鬼山与官星候选、顿伏位置）。缺项标「缺」。
   🔴 **CHECKPOINT**：先只摊事实，不判贵贱；缺两水关系或聚水情形时先要数据。

2. **枝中干初判**　输入：形势底账 → 输出：枝中干判语与聚落级别倾向（长段/短段），依据是「長作京都短作縣」的长短比较。

3. **穷处复核**　输入：水穷山绝处的水形砂形 → 输出：是「纒䕶竄」的砂砾坦然处，还是「两山两水作一關」处；若左右无形穴，标「寻转分枝再看」。

4. **分背面**　输入：两水夹龙的外缠回抱情形 + 一面的宽平/陡岩 → 输出：面/背判语，并给出立穴倾向。宽平、朝水缓者为面。
   🔴 **CHECKPOINT**：面背未分清时不谈贵贱；面背两说都成立时按「未易分」处理（见灰色地带）。

5. **核罗星与案山**　输入：水口、罗星首尾、案山与水的关系 → 输出：罗星先后是否正确、案山是逼水（有力）还是顺流（破城里）。

6. **分贵贱与鬼官**　输入：众山众水的聚散 + 鬼山官星 → 输出：贵贱倾向与理由（真龙不作朝、居中者贵、长与贵合看），并标出鬼山官星所在。

## 练习手册

1. **背面标注**：取一处两水夹龙的地形，先按缠水回抱标一遍面，再按宽平/陡岩标一遍，比对两次是否一致。
2. **十山十水**：找一处多山多水同聚之地，找出「出门」的那一水与「作门户」的九山，判哪一段居中。
3. **鬼山官星**：在一处逆转之龙后方，指出拖脚环抱的鬼山，并试认官星在哪。
4. **顿伏找关**：在一段长脉上标出跌断起伏之处，说出哪里可能作龙关。

## 灰色地带

- **面背未易分**：两水夹龙、屈曲翻身、两边都像面时，书里说「此山背靣未易分」。此时判「未易分」，看「護身腳」与罗星先后再加区分，不强行二选一。
- **无朝山与无朝水**：无朝山时按众水聚处判，无朝水时按朝山为近侍判；两者都缺时，只出「按聚水与内局回环的一种读法」，不越级。
- **长与贵冲突**：一条缠龙极长却处处作朝，另一条短而居中。按「長與貴合看」，不因长就定贵，把两条并列并说明取捨。
- **平洋与山垄并存**：同一片区域里既有平洋又有高岗时，按「随他地势看高下」，分别看，不拿一套标准硬套另一套。
