# 审其所废、择其所相、避其所害

**来源**：《葬書》（舊題郭璞）内篇「審其所廢」一节 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户已经有一块地在手上（老坟、老宅、祖地、选好的宅基），问它现在这样还能不能算数；
- 用户说「你帮我审一下这块地哪里废了」「哪些该择、哪些该避」「这是生气还是死气」；
- 用户手上有一份别人给的判语，想回原书核对口径；
- 用户问「入首被踩踏/崩破/开垦过，还算不算真穴」；
- 用户问「避死挨生是什么意思，落到我这块地上怎么分」。

**不应触发**：
- 用户只问「葬书是什么书、谁写的」→ 属通识问答，不归本 skill；
- 用户还没给出任何具体形势，只凭一句「我的地好不好」就要断 → 缺料，先补料或转 `kanyu-zangshu-cheng-shengqi` 讲第一原理；
- 用户问的是「平洋还是山垄」这类体认框架 → 转 `kanyu-zangshu-zhi-long-bian`；
- 用户问的是「四法（乘金相水、穴土印木）怎么用」→ 转 `kanyu-zangshu-si-fa`；
- 用户要的是能不能在这里下葬、怎么下葬的现场指令 → 不接，本 skill 只做文本层的形势归类。

## R：原文锚点

1. "謂入首廢壞，真偽莫辨，故不得不詳加審察也。"（《葬書》審其所廢，《錦囊》注）
2. "謂擇其所相輔於我者。"（《葬書》擇其所相，《錦囊》注）
3. "謂避去死氣，以求生氣也。"（《葬書》避其所害，《錦囊》注）
4. "如陽脈落穴，以陰為生，陽為死。"（《葬書》避其所害，《錦囊》注）
5. "經秀嫩光淨圓厚湧動為生，枯老臃腫破碎直硬為死。"（《葬書》避其所害，《錦囊》注）
6. "禍福不旋日。經曰：葬山之法若呼吸，中言應速也。"（《葬書》審其所廢）
7. "蓋穴中之氣，有刑有德，裁剪得法，則為生氣，一失其道，則為死氣"（《葬書》避其所害，《錦囊》注）

> 引文说明：第 1–5、7 条取自经文标题及其后的解释段落，解释段落是《錦囊》注；第 6 条整行属经文，其中「經曰」是经文里再引旧经。哪一条是经文、哪一条是注疏，逐条标在后面。

## I：核心解释

這一節给的是**在一块已经成形的地上做三道复核**：先看它废没废（審其所廢），再看哪些形势是来帮我的（擇其所相），最后看哪些是死气、形煞要躲开（避其所害）。三道合起来才是一次完整的复核，单做一道都是半判。

1. **審其所廢**——「入首廢壞，真偽莫辨」。入首就是脉气进穴的那一段。牛马践踏、上破下崩、年代久远被开垦种作、前人错葬在旁边又围了墙立了拜坛、做过房屋地基被削低填高、被田家取土挖过，这些都会让原本的真伪看不住。注意书里的反转：废坏不等于作废——只要「龍真局正，水淨砂明」，取前后左右四应来印证，酌情开井，仍可找到穴；废坏只是把辨认的难度抬高了，不是一票否决。
2. **擇其所相**——「相輔於我者」，是那些能固定葬口、分辨阴阳顺逆的形势：两肩暗翊（肩高肩低分阴阳）、三分三合与崎急平缓（别顺逆饶减）、蝉翊之砂与虾须之水（定葬口界限）。择相不是挑好看的，是挑**对你这一穴起约束作用的**。书里提醒：择错了会「破肋翻斗、伤龍伤穴、伪浅伤深」。
3. **避其所害**——「避去死氣，以求生氣」。书里的口径是**生死成对、随脉别而定**，没有一刀切的吉凶：阳脉落穴，阴边为生、阳边为死；阴脉落穴，阳边为生；脉一边厚一边薄，薄边为生、厚边为死；两条脉一长一短，短边为生；一大一小，小边为生。形色上，秀嫩、光净、圆厚、涌动为生，枯老、臃肿、破碎、直硬为死。砂水之间反坑、斜飞、直撞、刺射，都算形煞；横过之山像枪像刀，能顺水收拾来用的就用，能避开的避开。此外还提到程子「五患」、刘氏「四恶」也在当避之列（这两项原书只举名，未在本节展开）。
4. **祸福应速**——「禍福不旋日」「葬山之法若呼吸」。这是**书里的说法**，说的是这种感召关系来得快，不是本 skill 承诺的应验时间，引用时要标明是书的评价语。

一句话收束：这一节教的不是「吉不吉」，而是**在同一块地上同时问三遍——废没废、择什么、避什么**，三问都落地了，才轮到谈后面的做法。

**三问速览表**（每问都能追回上面 R 节）：

| 问 | 经文标题 | 要看的是 | 书里给的反转或提醒 |
|---|---|---|---|
| 審其所廢 | 審其所廢 | 入首破坏来源、大八字与金鱼是否可移 | 废坏只抬高辨认难度，不等于作废 |
| 擇其所相 | 擇其所相 | 两肩暗翊、三分三合、蝉翊之砂、虾须之水 | 择错会破肋翻斗、伤龙伤穴 |
| 避其所害 | 避其所害 | 四组生死对子、形色、砂水形煞 | 生死成对、随脉别而定，不是固定吉凶 |
| 应速 | 禍福不旋日 | 感召的快慢 | 这是书里的评价语，非本 skill 的承诺 |

这四行是本节的主干。用户问得再杂，先把他拉回这张表：看他手里的料够回答哪一行，缺哪一行的料就说缺哪一行。

## A1：来源应用

书上给的具体做法（不是本 skill 的发挥）：

- **审废要看什么**：入首的破坏来源（践踏、崩破、开垦、谬扞旁的围墙拜坛、旧居基、取土），再看「大八字」与「金鱼」这两处关键是不是还移得动、还在不在；然后取前后左右四应，证之心目，相度酌量，再谈开井。
- **择相要看什么**：先在小八字下看两肩暗翊，肩高肩低用来分阴阳作用；再看三分三合、崎急平缓，用来别顺逆、定饶减；最后看蝉翊之砂、虾须之水，用来定葬口界限。这三步都属「左右之所相」。
- **避害的生死对子**：把阳脉/阴脉落穴、边厚边薄、双脉长短、一大一小这四组对子先分出来，再拿形色（秀嫩光净圆厚涌动 vs 枯老臃肿破碎直硬）复核，最后把砂水里的形煞（反坑斜飞、直撞刺射、如枪如刀）单列。
- **书的断语是评价语**：本节末尾「祸福不旋日」「應速」这类话，是原书对这类形势的评断口吻，照引并标明，不当作事实承诺。
- **生死是裁出来的，不是天生的**：第 7 条说，穴中之气「有刑有德」，裁剪得法就是生气，一失其道就变成死气。所以判读时不要指着一处说「这永远是死气」，而要说「按书里这一类读，它偏向死气，能否转过来取决于处理是否得当」。

## A2：典型触发场景

用户在生活里具体长什么样：

1. 祖上传下来的一块老坟地，入首被多年的农活踩踏、开垦过，周边还堆过砖、取过土，用户问「这样还算不算真穴」。
2. 用户在看的是一块已经选定的地，两肩一高一低、砂水有一侧斜飞，问「哪边是我该择的、哪边该躲」。
3. 用户读完「避死挨生」一段，问「我这块地上的生死两边具体在哪」。
4. 用户手上有一份别人给的判断（说「这是发地」或「这是绝地」），想按原书看看口径对不对。
5. 用户问「书里说祸福应得很快，是不是真的」。
6. 用户读到「程子五患、劉氏四恶」，问「具体指哪几样」——本节只举名，须照实说原书未在此展开，不替他补全成自己的清单。

## E：执行步骤

1. **收料并就缺**　输入：用户的形势描述 → 输出：一张「已给／缺项」清单，缺入首、穴场现状、左右砂水、废坏史这几样里的哪几样。
   🔴 **CHECKPOINT**：只要缺了**入首与穴场现状**这两样中的任何一样，立即停下，只把缺项列出来请用户补，不进入后面任何一步的硬判。
2. **審其所廢**　输入：入首破坏来源与「大八字／金鱼」是否可移 → 输出：废坏清单（哪几处废、废在什么性质，对照书里的六类来源），并注明「废坏抬高辨认难度、不等于作废」。
3. **擇其所相**　输入：两肩暗翊、三分三合、崎急平缓、蝉翊之砂与虾须之水 → 输出：可择之助清单，逐条写它对你这一穴起什么约束。
   🔴 **CHECKPOINT**：把「可择之助」与「当避之害」并列展示，请用户确认这两栏分得对不对，再往下走。
4. **避其所害**　输入：脉别（阳/阴脉落穴）、边厚边薄、双脉长短、大小、形色、砂水形煞 → 输出：避害清单＋四组生死对子的倾向（每组只给倾向，不写「一定／必然」）。
5. **收口**　输入：上面三栏 → 输出：一段总结，含「不能下的结论」与待补观察；结论里凡属书的评断，都注明「这是书里的说法」。
6. **回标与自校**　输入：本次引到的每一条原文 → 输出：每条后面的出处标记，逐条写清是经文还是《錦囊》注，并过一遍 B 节自查清单。
   🔴 **CHECKPOINT**：自查清单里若有一条没过（例如把注当经、或给了绝对断语），当场改口重写，不把带病结论交出去。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只有一句「我的地好不好」就开判 | 用户没给穴场、入首、砂水任何一项，就开始说吉凶 | 回到步骤 1，只列缺项；退到 `kanyu-zangshu-cheng-shengqi` 讲第一原理 |
| 把「废坏」直接当「作废」 | 一看见被踩踏、开垦过就判死地 | 按书里反转补一句：只要龙真局正、水净砂明，仍可取四应斟酌开井 |
| 生死对子被说成绝对命定 | 写「阳脉落穴必死」「以薄为生就一定发」 | 一律改成「按书里这一类读，倾向是……」 |
| 把注疏当经文 | 引《錦囊》注却不标 | 每条引文回标「经文／《錦囊》注」 |
| 越界给现场指令 | 直接教用户在哪里下葬、挖多深 | 本 skill 只做文本归类，下葬作业指导不接 |

**边界规则**：
1. 缺具体形势描述（入首、穴场、砂水至少两样）时，只列缺项，不硬判。
2. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 原书的断语（祸福应速之类）是书里的说法，引用即标明，不作承诺。
4. 不接阴宅实地作业指导，不给医疗、法律、投资结论，不替用户拍板。

**自查清单**：
- [ ] 三道（审废／择相／避害）都做了，没有只做一道就收口
- [ ] 每条 R 引文都回标了经文还是《錦囊》注

**来源边界**：本 skill 只据《葬書》内篇「審其所廢」一节的经文与《錦囊》注疏（`sources/zangshu.txt`）。不含撼龍經、倒杖、砂法等操作法，也不含择日；需要那些内容时另调本族对应 skill。

## 练习手册

- **三问默写**：合上 I 节，凭记忆写出「审其所废／择其所相／避其所害」各问的是什么、各要看哪几处形势，再对照补漏。
- **对子辨识**：拿一段自己写的形势描述，先把书里那四组生死对子（阳阴脉、厚薄、长短、大小）逐组分好，再补形色一层，看两层的倾向一致还是打架。
- **废中求穴**：假设一块地被踩踏过、开垦过，按书里的反转写一段：在什么条件下仍可取四应斟酌开井，在什么条件下才真作废。
- **出处回标练习**：取本 skill 的六条 R，遮住出处，凭内容判断哪几条是经文、哪几条是《錦囊》注，再对照补漏。

## 反例黑名单

1. 把「入首被破坏」直接等于「这块地作废」——书里明确说废坏只是真伪难辨，仍可于废中审之。
2. 引《錦囊》注却不标「注」——把注疏当经文，是这一族最忌的错。
3. 拿「祸福不旋日」当应验承诺去安慰用户——那是书里的评价语，不是本 skill 的保证。
4. 用户没给形势描述就凭一句问话开判——缺料就说缺料，用占位信息硬判是最坏的一种「像在干活」。
5. 把生死对子写成绝对命定——书里是「随脉别而定」的相对对子，不是固定吉凶。

## 灰色地带

- **废与不废两可**：一处穴场被轻度开垦，但大八字与金鱼尚可辨、四应也齐——书里也承认真伪莫辨是常态，此时只给「倾向仍可取，但需现场再证四应」，不下死判。
- **生死对子互相打架**：例如脉来一边薄（薄为生），但形色偏枯硬（死）——两层不同层，此时分开陈述两层的倾向，不强行合成一个结论，交给用户看哪一层更贴他的实际情况。
- **注与经文语气不同**：经文简短，注疏展开举例。遇到注比经文说得更细的地方，标明「这是注疏的展开」，不把注的细节说成经文的原文规定。
- **「五患」「四恶」只有名目**：本节只出现「程子谓五患，刘氏谓四恶」两个名词，没有铺开内容。用户追问细节时，照实说本节未展开，需要时另作说明，不凭别的书或记忆把它填成一份具体清单。
