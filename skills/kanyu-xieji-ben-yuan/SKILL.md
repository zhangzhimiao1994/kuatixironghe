# 堪舆择日·本原（原理层）

**来源**：《欽定協紀辨方書》卷一·本原一、卷二·本原二 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「择日到底凭什么？为什么用干支五行方位就能定吉凶？」
- 「二十四山是什么？为什么正五行、双山五行、洪範五行算出来不一样？」
- 「三合局为什么是申子辰水、寅午戌火？六合、（五鼠遁／五虎遁）怎么起？」
- 「纳音、纳甲是干什么用的？」「五行长生十二位怎么排？」
- 用户手上已有一份风水或择日的说法（如「此山属双山木」），想追它的原理依据站不站得住。

**不应触发**（看起来像但其实不是）：
- 用户要直接排出某日、某时的神煞与宜忌 → 转查表类 skill（建除／月神／日神／黄道贵人）。
- 用户只问某一年的方位神煞 → 转年神类 skill。
- 用户要实际下葬、动土的现场作业指导 → 不接（见 B 节）。
- 用户要「帮我择个好日子」 → 本 skill 只讲原理，不替用户拍板，也不出具体吉日。

3. "洛書戴九履一左三右七二四為肩六八為足五居中央一六水尅二七火二七火尅四九金四九金尅三八木三八木尅五中土五中土尅一六水此五行相尅之序也"（《欽定協紀辨方書》卷一·本原一）

8. "按雙山五行即三合五行也地支十二取生旺墓三者為三合局而四卦八干各在支前一位今以支前一位之卦干與支雙並而同取地支三合之五行故曰雙山五行"（《欽定協紀辨方書》卷二·本原二）

## I：核心解释

本原是择日的**公理层**：先把「为什么可以拿干支、五行、方位来立例」讲通，后面各卷的神煞起例才有根。每一条都能追回 R 节。

1. **图与书是总纲**（R2、R3）。河图讲**相生**之序：一六水→二七火→三八木→四九金→五十土，左旋相生；洛书讲**相尅**之序：一六水尅二七火……右转相尅。书开篇即引朱子语，把阴阳家的东西归到「图、书、卦、画」这条线上（R1）——这是本书给择日找的总源头，不是后世术家自创。
2. **从卦位到方位**（R5）。天干八、地支十二、四维卦四，合为二十四方位，阴阳家叫「二十四山」。说「山」时「向」已在其中：子山必午向、壬山必丙向。也就是说择日里的「方」和「向」是同一套坐标。
3. **三套五行并存**（R6、R7、R8）。同一座山，书里至少给出三套五行：
   - **正五行**＝八卦干支之五行（亥壬子癸属水、寅甲卯乙巽属木……）；
   - **双山五行**＝三合之气，即「正五行乃五行之质，双山五行乃五行之气」，故推龙气生旺用双山不用正五行；
   - **洪範五行**＝「即正五行而进推其本初之气者」，另有甲寅辰巽戌坎辛申八山属水等一套。
   三套不是谁对谁错，是**分派用途**：定向用正针（正五行），格龙用中针（双山五行），消砂纳水用缝针（三合五行）。
4. **三合取生旺墓**（R4）。申子辰三合水局，是取水「长生申、旺子、墓辰」三辰。火土金木同理。这是全书神煞起例最重的一条骨架。
5. **干支的两套遁法**。五鼠遁定日时之干（甲己日起甲子时），五虎遁定年月之干（甲己年正月起丙寅）。纳音以律吕「同位娶妻、隔八生子」推；纳甲以八卦纳六甲。五行各有「长生、沐浴……胎、养」十二位，阳顺阴逆。
6. **机制的总说法**：以斗柄所指建月、以日月所会定月将（此二条见本原与公规），由天文落到干支，由干支落到五行方位，再由五行方位落到各卷的神煞起例。书里把它归到「敬天」二字，不归到「趋福避祸」——见 B 节。
7. **五行生旺与阳顺阴逆**：木长生亥、火长生寅、金长生巳、水长生申，土则「生于申」与「寄生于寅」两说并存——洪範家取土生于申为「体」，阴阳选择诸家取土生于寅为「用」。由长生顺推十二位（长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养），阳顺阴逆。书明说「此吉凶神煞所由起也」——后面各卷神煞的起例，根都在这里。
8. **纳音与纳甲各成一套**：纳音以六十律「同类娶妻、隔八生子」相推，五行次第为金火木水土；纳甲以八卦纳六甲，甲壬归乾、乙癸归坤、庚辛归震巽、戊己归坎离、丙丁归艮兑。书评「诸术之中，惟纳甲为近理」。

## A1：来源应用

书上给的具体做法（不是我的发挥）：

- **河图／洛书两序可直接背用**：相生序走河图，相尅序走洛书（R2、R3）。
- **二十四山分八宫**：「戌乾亥属乾，壬子癸属坎，丑艮寅属艮，甲卯乙属震，辰巽巳属巽，丙午丁属离，未坤申属坤，庚酉辛属兑」，一卦管三山，不用戊己（中央土无定位）。
- **三针法**：正针＝二十四山之正位（定向用）；中针子位在正针壬子之间（格龙用，双山五行）；缝针子位在正针子癸之间（消砂纳水用，三合五行）。书明说「双山五行即三合五行」，缝针与中针只差一位。
- **正五行口诀**（R6）：亥壬子癸水、寅甲卯乙巽木、己丙午丁火、申庚酉辛乾金、辰未戌丑坤艮土。
- **洪範五行口诀**（R7）：甲寅辰巽戌坎辛申八山属水，离壬丙乙四山属火，震艮巳三山属木，乾亥兑丁四山属金，丑癸坤庚未五山属土。
- **三合四局**（R4）：申子辰水、亥卯未木、寅午戌火、巳酉丑金。
- **六合**：子丑、寅亥、卯戌、辰酉、巳申、午未，取「月建与月将相合」。
- **五行用事**：土于四立前各旺十八日，四季共七十二日，与前四行七十二日合三百六十而成岁。
- **五行用事与生旺十二位**：立春木、立夏火、立秋金、立冬水各旺七十二日，土于四立前各旺十八日，合三百六十而成岁。木长生亥、火长生寅、金长生巳、水长生申。
- **五合化气**：甲己化土、乙庚化金、丙辛化水、丁壬化木、戊癸化火，其源出素问五运六气；书引素问「甲己为土运」等与遁甲「六戊为天门、六己为地户」相发。
- **纳音起数**：甲己子午九、乙庚丑未八、丙辛寅申七、丁壬卯酉六、戊癸辰戌五、己亥四；两干两支合数于四十九内减之，按河图之数定所生之行为纳音。

## A2：典型触发场景

用户在生活里具体长什么样：

1. 拿到一份风水报告，写着「此龙双山属水」，但自己按正五行算子山属水、乾山属金，对不上，来问差在哪。
2. 排盘时出现正针、中针、缝针三套五行，不知道该用哪一套。
3. 好奇「三合为什么是那三个字」，想弄清生旺墓的根据。
4. 看到「纳音」「纳甲」名词，想知道它们在择日里干什么。
5. 想验证一份择日结论的依据是否真出自本书，还是后人加的说法。
6. 想弄清「二十四山为什么四正四山（子午卯酉）不用卦而用支」。
7. 看到「中针格龙、缝针消砂纳水」的说法，想知道两针各差正针一位是怎么回事。

## E：执行步骤

1. **归位**　输入：用户的原始问法 → 输出：判定它落在四个原理支点中的哪一个（图书之序／卦位方位／五行系统／干支起例）。
   🔴 **CHECKPOINT**：先把「你这问题问的是哪一层」说给用户听，等其认下再往下；认错了，后面全错。
2. **取证**　输入：确定的支点 → 输出：从 R 节取对应原话＋卷次写出来，先讲「书上怎么说」，不掺自己的话。
3. **划界**　输入：已给的原话 → 输出：这份原理**能**支持什么、**不能**支持什么（只给倾向，不下断语）。
4. **分说三系统**　输入：用户的具体山向或干支 → 输出：按正五行、双山五行、洪範五行分别算出结果，明确标出「三说并存、各有派用」，不替用户指定用哪套。
   🔴 **CHECKPOINT**：把三套结果并排给用户，请其说明自己所在的传承用哪一套；说不出就停在「并列呈现」，不硬选。
5. **收口**　输入：以上结果 → 输出：一句「本 skill 只到此为止」的边界说明，如用户要具体某日吉凶，转月神／日神类 skill。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报结论不给卷次 | 说「正五行就是这样」却不说卷几 | 补出处；补不出＝不合格，回去翻卷一、卷二 |
| 把后世术家说法当书的主张 | 把通书、坊本的做法说成「书中规定」 | 书对世俗术数之说有辨正（详卷三十六·辨訛）；凡坊本说法一律标「（补充）」 |
| 三套五行混用 | 用双山五行去定向，或拿洪範五行去格龙 | 按三针各归其用重排，明说哪套配哪针 |
| 拿现代词给古义背书 | 用现代科学名词去解释五行方位 | 只就书论书，不加现代解释 |
| 缺地支就硬算 | 用户只给「我家朝南」就问吉凶 | 说清缺什么（具体山向度数、年份、事项），缺则不算 |
| 把体、用两套五行颠倒 | 用洪範五行去断龙气生旺 | 按书「正五行为质、双山五行为气」各归其用 |
| 把土的长生说死 | 只认土生于申，或只认生于寅 | 两说并陈，说明洪範家与选择家取义本就不同 |

1. 本 skill 只管**原理**，覆盖卷一·本原一与卷二·本原二；神煞起例从卷三·義例一起，归各专卷。
2. 涉及具体神煞，一律「要么给全，要么不报」：必须同时给出**起例来源（卷次·例名）**与**宜忌依据**；只报神煞名而不给卷次＝不合格。
3. 象征层只命名、不承诺：一律写「按书里这一类读」「倾向」，不写「一定／必然／命中／保证」。
4. 本 skill 涉及的口诀、起例，一律以卷一、卷二原文为准；卷三以下的神煞起例不在此列。

## 练习手册

1. **口诀默写**：合上 A1，凭记忆写出正五行、洪範五行两套口诀，再回原文补漏，逐字对。
2. **一山三算**：任取一座山（如艮山），分别按正五行、双山五行、洪範五行写出它属什么，标出三套的差异与各自的派用。
3. **追根训练**：拿一份坊间择日结论，逐条问「这条出自本书哪一卷」；答不出的，全部标成「（补充）」并写清它出自哪类坊本。
4. **生旺默排**：任取一行（如金），写出其长生至养的十二位，并标出阳顺阴逆的走向。
5. **五合推演**：写出五组化气及其所本（素问五运），说明「年起月、日起时越五则花甲周而复始」与五合的关系。

## 反例黑名单

1. **不要**把「双山五行＝三合五行」这句忘了去分别讲两套——书里明说就是一回事，只差一位。
2. **不要**用洪範五行去定向、用正五行去格龙，混用会得出与书相反的结果。
3. **不要**把河图相生序与洛书相尅序背反——图上左旋相生、书上右转相尅，方向不能换。
4. **不要**声称本 skill 能出具体吉日——它只到原理层。
5. **不要**拿「阴阳家者流其亦衷诸此」这条去证明择日「科学」——书里的落点是「敬天」，不是预测兑现。

## 灰色地带

- **三套五行分歧**：同一山在不同系统下属性不同，书里并存不判高下。遇到时按「哪套配哪针、用在什么事」分说，绝不强行合一。
- **原理可通、起例存疑**：某些神煞的起例书里自己就说「义不尽传」「尤多袭误」（详见卷三篇首），此时只能照录原文并标明书的态度，不替它辩护也不替它否定。
- **用户要「准不准」**：本 skill 不承接「灵不灵」的判断，只回答「书里怎么立例」。

- **体用之分**：同一五行系统，书分「质」与「气」。遇疑时先问这套五行是用来断什么（定向、格龙、还是消砂纳水），再定用哪一套。
- **口诀与派用**：二十四山「分属五行诸家不同，具各有义」，书不强分高下。遇到时照录各说、注明派用，不替用户裁定。
- **推算前提**（补充）：本书以清乾隆官修历法为据。用户若拿今制历或坊本推算，须注意月建、节气可能差一日；差一日则起例整体移位，此时应先说明前提而不硬算。
- **用途不讲高低**（补充）：本 skill 只回答「书里怎么立例」，不回答「用哪套最灵」。若用户坚持要一处断语，须先取得其山向度数、年份、事项，再转对应专卷；缺则只做原理说明，不下判断。
- **异体与异文**：同一本书里「氣／气」「𦵏／葬」「巳／己」常混用，皆照原文。引用时不动字、不改标点，遇异体照录，不以今字回改。
