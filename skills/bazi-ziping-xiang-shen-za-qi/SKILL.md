# 相神與雜氣取用（子平真詮 篇 15–17）

**来源**：sources/zipingzhenquan.txt（《子平真詮》十五·論相神緊要／十六·論雜氣如何取用／十七·論墓庫刑沖之說） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／用神／格局／命理这一类词时，整行不显示、不激活。

**应该触发**：
- 用户问「相神」是什么，用神定下后别位那个「辅者」怎么认。
- 用户问为什么书里说「伤用神甚于伤身，伤相甚于伤用」，相神与用神哪个更要紧。
- 用户问「相神无破，贵格已成；相神相伤，立败其格」怎么解，举例子（甲用酉官透丁逢壬之类）。
- 用户问辰戌丑未为什么叫杂气，「透干会取其清者用之，杂而不杂也」是什么意思。
- 用户问杂气怎么取用：透干、会支各怎么算，「一透则一用，兼透则兼用」怎么落。
- 用户问「辰戌丑未，最喜刑冲，财官入库不冲不发」为什么被书里说成俗书之说。
- 用户问四墓到底忌不忌刑冲，「刑冲未必成格」这句怎么理解。
- 用户拿着一组四柱，要按这三篇的口径逐条核（相神是谁、破没破；杂气透藏会否、清不清）。

**不应触发**：
- 用户问月令专求用神、成败救应、用神变化纯杂高低 → 转 bazi-ziping-yong-shen-zong-gang。
- 用户问行运、成格变格、喜忌干支有别 → 转 bazi-ziping-xing-yun。
- 用户问正官财印食神偏官伤官阳刃建禄各格的全身喜忌 → 转本族对应诸格篇目。
- 用户问《三命通會》的杂气（如 bazi-sanming-ge-ju 所据的卷五·論雜氣）→ 转该 skill；本篇与那一路有对着说处，两说并陈、各标出处。
- 用户要按某人生日报流年大运、断终身寿夭、判疾病生育、替人定婚姻职业 → 本族不接。
- 用户没提八字词，只说「我最近不顺」 → 泛化词，不激活。

2. 伤用神甚于伤身，伤相甚于伤用。（《子平真詮》十五·論相神緊要）
3. 相神无破，贵格已成；相神相伤，立败其格。（《子平真詮》十五·論相神緊要）
4. 四墓者，冲气也，何以谓之杂气？以其所藏者多，用神不一，故谓之杂气也。（《子平真詮》十六·論雜氣如何取用）
5. 何谓透干？如甲生辰月，透戊则用偏财，透癸则用正印，透乙则用月劫是也。（《子平真詮》十六·論雜氣如何取用）
6. 辰戌丑未，最喜刑冲，财官入库不冲不发——此说虽俗书盛称之，然子平先生造命，无是说也。（《子平真詮》十七·論墓庫刑沖之說）
7. 是故四墓不忌刑冲，刑冲未必成格。其理甚明，人自不察耳。（《子平真詮》十七·論墓庫刑沖之說）

## I：核心解释

这三篇接在「用神总纲」之后：篇十五讲用神定下后那个成全它的字（相神），篇十六讲月令落在四墓时怎么从杂气里取用，篇十七把「四墓喜冲」这句俗说翻掉。每一条都能追回 R 节。

1. **相神是成全全局的那一个字**。篇十五把用神比作君、相神比作相：「月令既得用神，则别位亦必有相，若君之有相，辅者是也」（R1）。书里先给「官逢财生则官为用财为相、财旺生官则财为用官为相、煞逢食制则煞为用食为相」这类常例，随即说「然此乃一定之法，非通变之妙」——真正的判据是收尾那句：**凡全局之格，赖此一字而成者，均谓之相也**。所以相神不是一张固定名单，而是「缺了它这格就不成」的那个字。
2. **相神比用神更要紧**。篇十五给出分量：「伤用神甚于伤身，伤相甚于伤用」（R2）。书里举的例子是：甲用酉官，透丁逢壬，则合伤存官以成格者全赖壬之相；戊用子财，透甲并己，则合煞存财以成格者全赖己之相；乙用酉煞，年丁月癸、时上逢戊，则合去癸印以使丁得制煞者全赖戊之相。这几例都说明：护住那个「相」的字被伤，格就立不住。
3. **相神一破，格立败**。篇十五末段把正反两面并说：「相神无破，贵格已成；相神相伤，立败其格」（R3）。书里的例子是，甲用酉官，透丁逢癸制伤护官，本已成格，却又逢戊，癸合戊而不制丁，便是癸水之相被伤。所以核相神要问一句：那个成全格的字，有没有被别的字合掉、克掉。
4. **杂气是四墓藏得多、用神不一**。篇十六开篇立名：「四墓者，冲气也，何以谓之杂气？以其所藏者多，用神不一，故谓之杂气也」（R4）。书里以辰为例：本藏戊，又为水库、为乙余气，三者俱有，取哪一个？书里的答案是「透干会取其清者用之，杂而不杂也」——杂气不是不能用，是看哪一个透出、哪一个会成局。
5. **取用分透干与会支两路**。篇十六把方法讲实：「何谓透干？如甲生辰月，透戊则用偏财，透癸则用正印，透乙则用月劫是也」（R5）；会支则是逢申与子会局，则用水印。落到分寸上是「一透则一用，兼透则兼用，透而又会，则透与会并用」，并补一句「其合而有情者吉，其合而无情者则不吉」。篇十六后半便用「有情／无情」「有情而卒无情／无情而终有情」把这层翻来覆去讲。
6. **四墓喜冲是俗说，书里不认**。篇十七一上来就翻案：世称「辰戌丑未，最喜刑冲，财官入库不冲不发」，但「此说虽俗书盛称之，然子平先生造命，无是说也」（R6）。书里的理由是：杂气既然透干会支就已取用，何必再劳刑冲？如甲生辰月戊土透即是偏财、申子会即是印绶；戊土不透，即便辰戌相冲，财格也不甚清。
7. **四墓不忌刑冲，但也未必成格**。篇十七给出的分寸句是：「是故四墓不忌刑冲，刑冲未必成格。其理甚明，人自不察耳」（R7）。书里还细分：财官属土，冲则库启（如甲用戊财而辰戌冲）；财官为水，冲则反累（如己生辰月壬透为财，戌冲则劫动）。并指出四墓之冲是「土自为冲」的冲动之冲，与子午卯酉的冲克之冲不同。

## A1：来源应用

书里给的做法，围着「先用神定相神、再看杂气透藏、最后问四墓冲不冲」这一条线：

- **先认相神**：用神从月令取定后，问一句「全局赖哪一个字而成」——那个字就是相神（R1 收尾句）。书里的常例（官逢财生、财旺生官、煞逢食制）只是示例，不是死表。
- **核相神有没有破**：看它有没有被合、被克、被牵制。书里的判据是「相神无破，贵格已成；相神相伤，立败其格」（R3），并给了「有情而化无情、有用而成无用」这一层。
- **杂气取用按透与会两条腿走**：透干者，一透一用、兼透兼用；会支者，逢三合会局则用会出之神；透而又会则并用（R5 所在全篇）。再看合的是有情还是无情。
- **四墓不当作一律喜冲**：篇十七明说「财官入库不冲不发」是俗书之说，书里无此说（R6）；要分财官属土（冲则库启）与属水（冲则反累），并记住「刑冲未必成格」（R7）。
- **篇十五只讲相神这一层**：某格全身的成败救应、变化纯杂，属用神总纲（篇八起），本篇不越界去讲。
- **不做「求刑冲开库」那一路**：篇十七明确反对「月令本非四墓…便求刑冲」「日临四库求冲以解」这类做法，称为谬论。

**书里没有的、不要加**：本篇不讲「入库必冲才发」的定式（书里正反对它），也不讲给杂气打分、按权重取舍——取用靠的是「透干会支」「清浊」「有情无情」这一套说法，照书讲即可。

## E：执行步骤

本 skill 主活是**落盘读法**；判据是**输入里有没有四柱或出生信息**——给了四柱走落盘，只问出处或句义走文本解读。

1. **分问法**　输入：用户的话与所引句子 → 输出：判定走哪条路。
   - **只问「书里这句什么意思／这一篇专门讲什么」** → 走**文本解读**：认句归篇、摆条件，不必落盘；末尾补一句「给我四柱就能照书读一遍」。
   - **问「我这盘怎么看」且给了四柱或出生信息** → 走**落盘读法**（下四步）。
   - 给了四柱而用户只问出处 → 仍按文本解读答，不硬塞落盘。
   🔴 **CHECKPOINT**：缺年／月／日／时任一柱或缺出生地，照实说缺什么、要到什么程度才能排，**不用占位信息硬排**；时刻只到时段（如「辰时」）时，时柱按该时段整体给，标明「时段内不唯一」。
2. **① 输入四柱**　输入：用户的四柱（或已排好的盘）＋本 skill 的条件 → 输出：把日主、月令、月令所藏、天干透出、地支会合列出来。
   🔴 **CHECKPOINT**：这一步只摆材料，不下断语；藏干十神是可核的，取用与清浊是判读，要回到条文。
3. **② 逐条核条件**　输入：上一步的材料 → 输出：逐项对照书里的条件——**月令可不可取**（若为辰戌丑未四墓，就看是杂气取用还是本气取用，R4）；**透还是藏**（透干一透一用、兼透兼用；会支则用会出之神，R5）；**相神是哪一个、有破无破**（赖此一字成格者为相，被合被克者为破，R1、R3）；**四墓冲不冲**（财官属土则冲启、属水则冲累，且在「刑冲未必成格」的分寸内看，R6、R7）。每一项都写明「满足到哪一步」。
   🔴 **CHECKPOINT**：不许拿可核的计算当结论；报「相神」必须指到 R1 收尾句那一层，报「杂气取用」必须指到 R5。
4. **③ 输出一句读法＋出处**　输入：逐条核的结果 → 输出：「按书里这一类读，偏 X」＋**出处**（《子平真詮》某篇）。例如「按篇十六这一类读，偏于透癸取印、会申子成局，杂而不杂（《子平真詮》十六·論雜氣如何取用）」。
   🔴 **CHECKPOINT**：报任何格局或用神必须给出**原书依据（哪一篇）**与**取用条件（凭什么这么取）**两句；只报一句不合格。
5. **④ 收口**　输入：整段推演 → 输出：一句收尾，写明**不应期、不断终身、不落寿夭疾病生育、不替用户决定**——「本篇只读到相神与杂气取用这一层，不批流年大运、不断终身、不判寿夭疾病生育，也不替你决定婚事职业」。
   🔴 **CHECKPOINT**：收口前确认没有滑到流年大运、寿夭、婚姻上去，也没把「貴格」「立败其格」当成对用户的事实。

**交付口径**：逐步把推演展示出来，结论速览放最前但不得代替推演；一步之中的依据尽量引用户的问法或所给四柱。需要成表的内容走平台原生的表格消息，不把 markdown 表格塞进正文。

- **认相练习**：照 R1 收尾句，给「官逢财生」「财旺生官」「煞逢食制」各指出用神与相神，再说一句「谁伤了相神格就败」。

- **冲不冲推演**：举己生辰月壬透为财的例子，按篇十七说戌冲是启库还是劫动，只讲书里之理，不下吉凶。

## 反例黑名单

1. 把相神答成一张固定名单，不按 R1「赖此一字成格者」去认。
2. 定完用神就断格成，不核相神有没有被破（违 R2、R3）。
3. 一见辰戌丑未就求刑冲开库，顺了书里明斥的俗说。
4. 反过来一刀切说四墓必忌冲，不顾篇十七「财官属土冲则库启、属水冲则反累」的分寸。
5. 没有月令或不给四柱却硬取杂气、硬报相神。
6. 在本篇越界去断贫富贵贱、寿夭疾病，或替用户决定婚事职业。

## 灰色地带

- **相神与用神同一字时怎么算**：篇十五说相是「赖此一字而成者」，有时成全格的字与用神所指不同（如合伤存官之壬）。用户若问某字算用还算相，照书说：用神从月令取，相神看它是不是成全全局的那个字，两层不并成一句。
- **杂气「有情而卒成无情」**：篇十六说甲生辰月逢壬为印又逢丙，似成格而卒不成，要「壬干透而支又会申会子」才无碍。遇到正好卡在丙火有无、戌辰冲不冲的，照原书条件摆两说，不给「一定成／一定败」。
- **四墓之冲的两义**：篇十七把四墓之冲叫「冲动之冲」、子午卯酉叫「冲克之冲」。用户问某冲是冲克还是冲动时，照原书分义说，不替用户拍板吉凶方向。
- **与《三命通會》杂气一路对着说**：《三命通會》卷五·論雜氣（见 bazi-sanming-ge-ju）走的是「藏蓄於四季之中」、以杂气财官立格一路；《子平真詮》篇十七则明说「财官入库不冲不发」是俗书之说。两说各标出处、并陈，本 skill 不替两家调停、不合成一句。
- **篇十六末的「旁悟」**：书里说「如此之类，不可胜数，即此为例，旁悟而已」，意思是所举只是例子。用户拿一个书上没举的组合来问时，照书里已给的判据（透藏、会支、有情无情）类推，并说明是照理推，不是书上原文所断。
