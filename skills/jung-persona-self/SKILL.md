## I：核心解释

1. **人格四层结构**：
   - **Persona（面具层）**：你给世界看的脸。职业角色、社会身份、礼貌性微笑。它保护内在，正常且必要。
   - **Ego（意识层）**："我"的感觉。致命错觉——它以为自己是全部。
   - **Shadow（阴影层）**：被Ego拒绝的部分。愤怒、自私、欲望，但也有关在里面的创造力、笑声、野性。
   - **Self（自性核）**：超越所有对立面的完整。不是"更好的你"，而是"全部的你"。Self像太阳，Ego像行星绕它转。

2. **Persona陷阱**：最常见心理灾难="我=我的Persona"。退休/被裁员=整个自我的死刑，因为 Persona 被抽走了但其他层没有发展。

3. **Shadow不是邪恶**：生命力、愤怒（保护边界）、性欲（生命力的来源）全关在Shadow里。越压抑Shadow，它越会从你最没防备的地方冲出来。

4. **Self是终点也是起点**：个体化不是加法（增加新品质），是减法（去除"我是谁"的错误认知）+ 整合（把分裂的部分接回来）。

## A1：来源应用 — 炼金术隐喻

荣格用炼金术作为个体化隐喻。四个阶段对应 Persona→Self：

| 炼金阶段 | 心理阶段 | 触发 |
|---------|---------|------|
| **Nigredo（黑化）** | Persona瓦解 | 中年危机、重大失败、丧失 |
| **Albedo（白化）** | 面对 Shadow，回收投射 | 开始看自己，不再怪别人 |
| **Citrinitas（黄化）** | 整合 Anima/Animus 的洞见 | 创造性领悟 |
| **Rubedo（红化）** | Self 实现——完整，不是完美 | 哲人石：能炼出金子的东西 |

Nigredo 是抑郁的，但不是病理的——是必要的腐烂。

### 步骤2：Shadow 回收

**输入**：步骤 1 的面具表 + 用户对"讨厌的人"和"羡慕的人"的描述。
**内部产出**：3-5 个 Shadow 元素命名（不必全挖，够启动即可）——这是内部叫法，对用户要用大白话描述（“那个被你锁在门后、你一提起就硌得慌的部分”），不把“Shadow／阴影”当名词敲给他（见「输出纪律」2）。

🔴 **CHECKPOINT — 触发条件：用户处于急性危机（刚经历重大丧失/有自杀意念/重度抑郁发作）**：不要深入 Shadow 工作，Shadow 需要 Ego 有一定承受力 → **跳转 B 节失败模式表「Shadow 回收引发羞耻淹没」**。

不要想"我的阴暗面"——那还是评判。换"我的不给看袋子"：

- 你最讨厌别人有什么特质？（很可能是你自己的 Shadow）
- 你偷偷羡慕谁的生活方式？（你的 Shadow 想要的）
- 小时候你喜欢做什么，但被说"没用/不像样子"？（创造力在 Shadow 里）
- 你在什么情景下会失控——暴怒、崩溃、冲动行为？（Shadow 跑出来了）

🔴 **CHECKPOINT — 触发条件：用户出现自责/羞耻/自我厌恶（"我原来这么不堪"）**：立即执行安全容器话术 → **跳转 B 节失败模式表同一行替代动作**："你不需要喜欢阴影——只需要承认它存在。这不是道德审判，是回收被放逐的部分。被放逐不是你的错——是文化/家庭/教育替你做了选择。"

找一个安全方式表达 Shadow：写、画、动、喊——不是对别人，是对自己。

**话术模板 — 空椅子对话法**（当用户说"我不知道怎么面对这些 Shadow 元素"时使用）：

> ⚠️ 下面 1–4 是**内部组织思路**，回答里必须说成连贯的话（“你先把这个‘总替你把门关上’的部分请到对面椅子上……”），**不得**照抄成 1/2/3/4 的编号清单（输出纪律 3）。

1. **命名它**：给这个 Shadow 元素一个名字——"愤怒的守卫"、"被关起来的艺术家"、"那个敢说不的自己"。
2. **给它一把椅子**：想象它坐在对面的空椅子上。问它三个问题：
   - "你想保护我什么？"（Shadow 最初是对痛苦的防御）
   - "你在怕什么？"（如果被承认，会有出现什么危险）
   - "你想让我知道什么？"（它被关起来之前想说什么）
3. **听它说完**：不打断、不反驳、不评判。如果情绪涌上来，让它通过——哭、骂、笑，不是压抑。
4. **告诉它**："我看到了。你不必继续用破坏的方式出现。我们可以一起找到别的表达方式。"

**如果用户说"我坐在椅子上但什么也感受不到"** → 改为写信：用非惯用手给 Shadow 写一封信（绕过 Ego 审查），再用惯用手回信。

### 步骤3：Persona 的重新谈判（内部决策，回答层不得排成“保留／缩小／探索”三栏）

**输入**：步骤 1 的面具表 + 步骤 2 的 Shadow 元素。
**内部产出**：一个保留/调整/摘除的三级分类决策——**内部决策，回答里用说话的方式讲**（“有两副你不用动，留着挺好；有一副纯粹是讨好别人才戴的，可以悄悄少戴一点”），不排三栏填空。

🔴 **CHECKPOINT — 触发条件：用户没有可依赖的安全关系（< 1 个可透露真实感受的人）**：**不要建议用户大范围摘面具**。改为："先在独处中练习对自己诚实，再讨论如何在最低风险的关系中尝试 5% 的真实。"无安全关系时摘面具可能导致社会性孤立 → **跳转 B 节「Persona 谈判引发恐慌」**。

|------|------|-----------|
| **保留** | 真心愿意戴的 | |
| **缩小比例** | 纯粹讨好别人而戴的 | |
| **探索底下** | 完全不敢摘的——底下有宝藏 | |

（上表为内部对照，不进回答；回答层把结论说成句子，并落到一个可指认的动作上。）

**话术模板 — 渐进真实法**（当用户说"缩小比例具体怎么做？我不敢"时使用）：

> ⚠️ 下面 1–3 是**内部梯度**，回答里讲成一件具体的、这次就能做的小事（给他一个场景、一句原话），**不得**排成“1. 2. 3.”的编号清单（输出纪律 3、4）。

不要求一步摘面具。用 5-10-20% 渐进法：

1. **5% 真实**：下周在最低风险场景中做一件"稍微不那么讨好"的事。例如：
   - 别人问"吃不吃辣"时，以前会说"都行"，这次说"我不太吃辣"
   - 同事约不想去的聚餐，说"今天有点累，下次吧"
   - 不说"你穿得很好看"当你不觉得时——沉默也可以
2. **10% 真实**：找一个相对安全的人（家人/老朋友），在对话中透露一件不重要的真实感受。例如："其实我不太喜欢这份工作"
3. **20% 真实**：在某个中等风险的场景中，保留一件你不肯"优化掉"的东西。例如：会议中不删除那句"我不确定我们方向对不对"，不把真实感受包装成对方更爱听的版本

**关键原则**：只在**能承受后果**的场合卸下百分比。不做无准备的"坦白"。每一次缩小比例，都是在测试"真实的我能在这个关系里存活吗"。

### 步骤4：寻找象征 — Self 导航

**输入**：用户近一年的梦/直觉/无法解释的吸引。
**输出**：2-3 个 Self 象征候选（圆形/四方/钻石/太阳/树的梦，特定人或地方的吸引）。

Self 不直接说话，通过象征沟通。过去一年中：

- 有没有反复出现的梦？（特别是圆形、四方形、钻石、太阳、树的梦）
- 有没有某种无法解释的吸引？（一个人、一个地方、一项活动）
- 有没有"被什么东西引导"的感觉？

**这些是 Self 的指路牌——不是神谕，但值得认真对待。**

🔴 **CHECKPOINT — 触发条件：用户说"我没有梦/直觉/吸引"或"这些没有意义"**：Self 不一定通过宏大的方式出场。问："你最近有没有看到什么东西让你停下来看了几秒？有没有听到一句话让你心里动了一下？一本书/一首歌/一个画面让你莫名其妙想回看？"如果仍然没有 → 回到步骤 3 先从 Persona 谈判入手——有时 Self 要等你准备好了才说话。不要编造意义。

### 步骤5：承受完整

**输入**：步骤 3 的谈判结果 + 步骤 4 的象征。
**输出**：一个对"孤独 vs 联结"的现状评估 + 最低风险行动。

最后一关不是"找到 Self"，而是**承受成为完整的自己所需要的孤独**。

当你不按剧本演了——不当好孩子、不做好员工、不演完美伴侣——会有人不舒服。有人离开。这很痛。

但留下来的关系是真实的。独处的能力（不孤独地独处）是 Self 整合的自然结果。

🔴 **CHECKPOINT — 触发条件：用户反馈"我变了，身边的人全走了"，且伴随痛苦/绝望**：评估孤独是否可承受。如伴随自杀意念 → 转专业帮助。如可承受 → 正常化："个体化会选择同伴。" → **同时检查 B 节「个体化进程引发关系断裂」**。

### 边界规则

1. **不是鼓励反社会**：脱下面具不等于可以肆无忌惮。Persona 有保护社会的功能。
2. **Shadow整合不是释放**："我接受我很愤怒"≠"我可以随便发火"。整合=承认+选择用什么做什么。
3. **Self不是Ego膨胀**：真正接近 Self 的人变得谦卑、有联结感、更少自我中心。
4. **个体化没有终点**：你会反复经历 Nigredo-Albedo-Citrinitas-Rubedo，每次更深的螺旋。
5. **严重抑郁需要专业帮助**：Persona 瓦解伴自杀意念→精神科帮助。框架是地图，不是救护车。

## 🚫 反例与黑名单

以下场景**禁止**调用此 skill，或必须降级处理：

1. **多重人格/解离性身份障碍的诊断需求** → 转介精神科。荣格的人格层次≠临床解离。
2. **青春期自我探索** → 正常发展任务，不需介入——除非伴随持续痛苦或功能损害。
3. **以"找自我"为名回避现实责任**（"我要去流浪找自己"但需照顾家人）→ 要求同时面对方便与不方便的真相。
4. **用此 skill 合理化社交回避**（"我不需要任何人，我是完整的 Self"）→ 防御性隔离，不是个体化。真实个体化增加联结能力。
5. **声称"我已完全整合/自我实现"** → 终结态宣告是 Ego 的伪装。流行说法称荣格临终前仍在个体化、仍在"成为"——但此为流行转述，未在全集找到原话。
