# 人元司令與月令分野

**来源**：sources/sanmingtonghui.txt（《三命通會》卷二·論人元司事） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问「人元」是什么、为什么支中所藏叫「司事之神」。
- 用户问正月建寅里哪个干当令几日（艮土五日、丙火五日、甲木二十日）。
- 用户问月令分野怎么分、按什么分到六十甲子里。
- 用户问为什么古法用神多取诸月令、为什么说「月令用神」。
- 用户问玉井那一套分法（甲丙庚壬各三十五日、乙丁辛癸各三十五日、戊己各五十日）是什么意思。
- 用户问「土旺四季，各有十八日」「各得七十二日」这种分法从哪来。
- 用户读到「又支中所藏止以月論，年日時不論」想问为什么。

**不应触发**（看起来像但其实不是）：
- 用户问十干体象句或「在天为雷为风」这类天象取象 → 转 bazi-sanming-tian-gan。
- 用户问十二支各自的体象、名与取象 → 转 bazi-sanming-di-zhi。
- 用户问某柱纳音是什么 → 转 bazi-sanming-na-yin。
- 用户要排盘、给一组四柱算流年大运吉凶 → 本维度不接流年大运、不断终身。
- 用户只说「我几月生的」「我生日那天」这类泛化的话，没有点出人元／司事／月令分野等显式请求 → 不激活。

## I：核心解释

这一段讲「月令里谁当值」，是取用神的落脚处。

1. **人元的定义**。书把「轻清者為十干主禄」叫天元，「重濁者為十二支主身」叫地元（R1）；而「支中所藏者主命」，叫「人元」，又叫「司事之神」，在命术里就是「月令用神」（R2）。所以「人元」不是另一个干支，是支里所藏的那几个干，按当月当值来算。
2. **月令用神与「不可损伤」**。书引经说「用神不可損傷，日主最宜健旺」（R2）——月令当值的那个干既叫用神，就有一条「不可损伤」的原则；这是书给月令用的口径。
3. **一套逐月的司事分法**。书给的正法是：正月建寅，寅中有艮土用事五日、丙火长生五日、甲木二十日；二月建卯，甲木七日、乙木二十三日……一直到十二月建丑（R3）。书后面还把这些日数单独排成一张表，按正月到十二月的次序（R6–R17）。这套分法把一月中当值的气按日数切开。
4. **这套分法要配四时**。书说这十二支「各藏五行為人元以配四時」，春夏秋冬循环无端、岁功成而一年毕（R4）——司事是按四时的环转走的，不是孤立地看某一支。
5. **另有一套玉井分法**。书又考玉井，把一年按干分：甲丙庚壬各三十五日、乙丁辛癸各三十五日、戊己各五十日，合计三百六十日（R5）。这与前面的按月司事是两套不同的分法。
6. **醉醒子的口径**。醉醒子说「金木水火分旺四時各得七十二日，土旺四季各有十八日，共三百六十日乃成嵗焉」（R18）——这是第三套口径，按五行分旺。
7. **分野与长生要分清**。书辨「分野者聚一方之旺氣，長生者歸母成孕」（R19），并在别处说「其説足以破淵源之誤」（R20）——它把「分野」和「长生」两个概念分开，并否定了渊源把诸神按几日几日的争法。
8. **藏止以月论一句**。书最后强调「又支中所藏止以月論，年日時不論，人命重提綱厥有㫖哉」（R21）——司事只看月令，年月日时里只有月这一柱定提纲，这是这一段的落点。

## A1：来源应用

书上给的读法，分几步落地：

- **认人元**：凡见「月令用神」「司事之神」，按 R2 说明它就是支中所藏、当月当值的干。
- **查司事日数**：按 R3 或 R6–R17 查当月哪个干当值几日（如正月寅：艮土五日、丙火五日、甲木二十日）。要说明这是书里的一套分法。
- **分套对读**：遇到玉井分法（R5）或醉醒子分法（R18），标明是与前面按月那套并列的另一套，不混着算。
- **落提纲**：按 R21，司事只看月令一柱，年日时不论。
- **一句可带走**：人元司令 = 支中所藏 + 当月当值；取用神先落到月令提纲上。

**书里没有的、不要加**：原书不把司事日数折成「权重分数」或「强弱指数」；也说「支中所藏止以月論」，不把年日时也套上同一套日数。把这些加进来只能标「（补充）」并说明依据。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把三套分法混着算 | 拿玉井的三十五日去套按月的日数 | 拉回 R5、R18：玉井与醉醒子是并列的另一套，不混着算 |
| 把年日时也套司事日数 | 说年月日时四柱都各藏若干日 | 拉回 R21：支中所藏止以月论，年日时不伦 |
| 把司事日数折成分数 | 算出「某干强度 0.27」这类值 | 删掉现代算法，只按原句列日数 |
| 把「分野」当「长生」 | 说分野就是长生、两词通用 | 拉回 R19：分野聚一方之旺气、长生归母成孕，书里分作两事 |
| 借司事放排盘 | 讲着讲着开始排四柱、判吉凶 | 拉回本 skill 范围，排盘转 bazi-hub |
| 只给泛化词就激活 | 用户说「我几月生的」就论月令 | 泛化词不算；要显式点出人元／司事／月令分野才接 |

1. 只讲人元的定义、逐月司事日数、几套分法的对照与「以月论」这一落点，不接排盘与批断。

## 练习手册

- **三名目记**：合上 R 节，写出天元、地元、人元各指什么，各挂一条原句。
- **一月一查**：任挑三个月份，按 R6–R17 写出当值的干与日数，并说明这是按月那套。
- **两套对照**：把按月司事的甲木日数与玉井的「甲丙庚壬各三十五日」并排写，说明为什么不能混。
- **一句提纲**：把「支中所藏止以月论」用自己的话讲一遍，说明它对取用神意味着什么。

## 灰色地带

- **用户问「月令用神和后世说的喜用神是不是一回事」**：只说书里这一段把支中所藏当值者叫「月令用神」（R2），不替书里认后世流派的术语；用户若拿别的说法来比，照实说这是两套口径。
- **三套分法互相冲突**：按月司事（R3）、玉井（R5）、醉醒子（R18）三种日数并不一致；照实说这是书里并列的几套分法，各自成立，不替书里调和成一套。
- **用户问「为什么土在四季各十八日，可正月寅里又有艮土五日」**：一处是醉醒子的五行分旺（R18），一处是按月司事的逐月切开（R3）；两处并列，不硬凑成一句。
- **用户把「司事之神」当成有神灵在值班**：按 R2 回到原意——「司事之神」只是支中所藏当值之干的称谓，不是神灵；不落神秘化解释。
- **用户要「司事 + 顺便断我一命」**：司事照讲，断命部分照实说本 skill 不接，转 bazi-hub，并说明缺什么信息（年、月、日、时、出生地）就不能排。
