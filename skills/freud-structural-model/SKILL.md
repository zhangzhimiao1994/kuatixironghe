# 结构模型：自我-本我-超我

**基于**：*The Ego and the Id* (1923b) + *New Introductory Lectures on Psycho-Analysis* (1933a)

## 触发条件

### 应该触发
- 用户在纠结两个以上的冲突需求
- 用户说「我不知道自己想要什么」或「我应该这样做但我不想」
- 用户在过度自我批评
- 用户在三种不同的要求之间被撕扯
- 触发词：「纠结」「应该但不想」「控制不住」「我在和自己打架」「不懂自己为什么这样」

### 不应触发
- 简单的二元选择（只有一个冲突）
- 纯认知问题（没有情感层面的冲突）
- 丧失后严重的自我谴责+低价值感 → `freud-mourning-melancholia`（自尊已受损，不只是冲突）
- 持续的焦虑+回避行为+「我不知道怕什么」→ `freud-anxiety-defense`（焦虑是主角，冲突是配角）

## R：原文锚点

> 说明：以下中文为**中译，译自英文全集**（Ivan Smith 编 *Freud – Complete Works*），非逐字原文；英文原句已逐字回书核，见各条括号内。

> 「自我与本我的关系，像一个骑手驾驭一匹比他强壮得多的马。骑手如果不想被甩下去，常常不得不把马引到它自己想去的方向。」（《精神分析新论》1933a，第三十一讲；原句 *The ego's relation to the id might be compared with that of a rider to his horse.*）（已据英文全集核）

> 「可怜的自我……同时侍奉三个严酷的主人：外部世界、超我和本我。」（《精神分析新论》1933a，第三十一讲「心理人格的解剖」；原句 *it serves three severe masters... the external world, the super-ego and the id*）（已据英文全集核）

> 「你不是自己房子的主人。」（《精神分析道路上的一个困难》1917a *A Difficulty in the Path of Psycho-Analysis*；原句 *the ego is not master in its own house*）（已据英文全集核）

> 「这种潜意识罪疚感在很多神经症中扮演决定性角色，是康复的最大障碍。」（《自我与本我》1923b，第三章；原句 *in a great number of neuroses an unconscious sense of guilt of this kind plays a decisive economic part and puts the most powerful obstacles in the way of recovery*）（已据英文全集核）

## I：核心解释

自我（Ego）同时为三个主人服务：
1. **本我（Id）**：「我要这个，现在就要」——遵循快乐原则
2. **超我（Super-ego）**：「你不应该/不配」——被内化的父母/权威的声音
3. **外部现实**：「不能这样做，有后果」

```
        本我（Id）
        「我要，现在就要」
        遵循快乐原则
            ↓ 压迫→
外部世界 ← 自我（Ego） → 超我（Super-ego）
「不行，   ↑   中介者      「你不配」
有后果」    ↕   谈判者      被内化的父母/权威
           焦虑←三方矛盾的结果
```

（追 R 第 2 条：自我同时侍奉三个严酷的主人。）

**骑手与马**：自我驾驭本我，像骑手驾驭一匹更强壮的马；骑手若不想被甩下去，常常得把马引向它自己想去的地方。（追 R 第 1 条）

**关键**：自我的大部分也是潜意识的——「你不是自己房子的主人」。（追 R 第 3 条）

**潜意识罪疚感**：「我不配好起来」的感觉不是意识层面的决定，它在潜意识中运作，是康复最顽固的障碍。（追 R 第 4 条）

健康 = 自我能成功谈判三方
症状（焦虑/抑郁/强迫）= 自我无法谈判，崩溃或症状形成

## A1：来源应用 —— 书上的做法

1. **三向拆解**：把任何冲突拆成 本我（真的想要什么）/ 超我（谁在说应该、不配）/ 现实（能做什么）三路——这是本模型的操作核心。
2. **命名来源**：把超我的外部来源（父母/学校/领导/文化）**命名**，使它不再是内在的无名恐怖。
3. **重新分配权力**：本我需要被听到（给安全出口，不直接满足）；超我需要被审查（过时规则可降级）；现实不可战、只可谈判。
4. **最小可行方案**：三方完全冲突时回归最基本生命维持（休息、吃饭、呼吸），追求「最小的生存方案」而非「完美解决」。
5. **用症状反推模型**（诊断信号表）：

| 症状 | 可能的模型解释 |
|------|---------------|
| 失眠 | 三方的冲突在深夜持续进行→超我审查 或 本我要求浮现 |
| 疲劳但原因不明 | 自我在持续消耗能量做三方谈判 |
| 头痛/身体症状 | 被堵住的本我能量转化为躯体症状（癔症机制）|
| 过度自责 | 超我过度活跃，本我被审判 |
| 无法做出决定 | 自我被三方拉扯→失去谈判能力 |
| 食欲丧失 | 本我最基本的功能（吸收/接受）被超我压制 |

## A2：典型触发场景

- 「我心里像在打架：一边想辞职去旅行，一边有声音说'你怎么这么不负责任'，现实还摆着房贷」→ 三向拆解
- 「我应该留下但我真的不想」
- 「我控制不住自己刷手机到半夜，然后又自责」
- 「我不懂自己为什么这样」
- 「我不知道自己想要什么」

## E：执行步骤

### 第一步：三向拆解
**输入**：用户当前的困难。 **输出**：本我/超我/现实三路回答。
让用户对他当前的困难回答三个问题：
1. 本我问题：「在这件事里，我真的想要什么？」（不要自我审查）
2. 超我问题：「我听到什么声音在告诉我应该怎么做？这个声音从哪来的？谁教的？」
3. 现实问题：「现实中我实际能做什么？选项是什么？」

### 第二步：辨别声音来源
**输入**：特别响的超我声音。 **输出**：被命名的外部来源。
当用户的超我声音特别响的时候，帮助辨别它属于哪个阶段：
- 父亲/母亲的声音？
- 学校/老师的规则？
- 领导/上级的要求？
- 社会/文化的期望？
→ 把这些外部的来源**命名**，使之不再是内在的无名恐怖

### 🔴 CHECKPOINT：超我来源确认
```
🔴 超我声音的源头 = [命名的外部来源]，用户确认这个追溯对不对？
- 对 → 继续第三步
- 不对/不准确 → 重新追溯，不跳过
确认？
```

### 第三步：重新分配权力
**输入**：三方需求。 **输出**：各自的处理方式。
- 本我需求是合法的，应该被听到——给它一个安全出口（不是直接满足）
- 超我需求需要被**审查**——有些超我要求是不合理的过时规则，可以降级
- 现实限制是客观的——不要与之战斗，要与之谈判

### 第四步：最小可行方案
**输入**：三方冲突的程度。 **输出**：一个最小生存方案（或降级）。
在三方中找到最小公分母：
- 「现在能做什么，既不完全背叛自己，也不会被现实彻底碾压？」
- 如果三方完全冲突→回归到最基本的生命维持（休息、吃饭、呼吸）

### 🔴 CHECKPOINT：三步后验证

在第一步「三向拆解」完成后，确认：
```
🔴 验证：本我需求 = [用户说的真正想要的东西]，超我声音来源 = [追溯到的外部来源]，确认？如果不对，重新回答本我/超我问题。
```

在第四步结束后，确认：
```
🔴 验证：最小可行方案 = [方案]，是否可行？如果做不到/更糟 → 降级到基础生命维持（休息、吃饭、呼吸），停止分析。
```

## B：边界与失败模式

### 失败模式分支表

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 用户无法回答「本我真正想要什么」 | 改问：「如果你完全不需要对任何人交代——你最想做什么？」 | 跳过第一步，从第二步（追溯超我来源）开始 |
| 用户追溯不到超我来源 | 问：「谁第一个让你觉得自己不够好？」不限于父母——可能是老师/领导/伴侣 | → 如果仍无法追溯，降级为「基础自我关怀」方案（休息、吃饭、呼吸），不强行分析 |
| 三向完全冲突、最小方案也不可行 | 立即降级为「基础生命维持」——不推导解决方案 | → 建议休息后重新评估，或转 `freud-mourning-melancholia`（可能已进入忧郁） |
| 分析后用户感觉更糟 | 停止分析，确认：是释放后的正常波动，还是创伤被激活？ | → 如果是后者，转 `freud-trauma-hysteria` 的危险信号处理 |

### 边界规则
- 此模型是心理动力的隐喻，不是脑科学的事实
- 如果用户显示出精神病性症状（现实检验失败），此模型不适用于自助
- 急性危机（自杀想法）→ 需要立即专业帮助，不是分析

### 用户自查清单（原自检脚本）

在完成每一步后执行以下自检（用 ✅ / ⚠️ / ❌ 标注）：

```
[ ] 第一步：用户能否说出本我需求？（能=✅，需退化问题=⚠️，不能=❌转fallback）
[ ] 第二步：超我来源是否被追溯并命名？（是且用户确认=✅，追溯不准=⚠️，追溯不到=❌转fallback）
[ ] CHECKPOINT: 超我来源确认通过？（是=✅）
[ ] 第三步：三方需求是否都被识别？（是=✅，缺一方=⚠️补充）
[ ] 第四步：最小可行方案是否产出？（有方案且用户认可=✅，方案不可行=⚠️降级，无方案=❌转fallback）
[ ] CHECKPOINT: 三步后验证通过？（是=✅）
[ ] 全局：分析过程中用户是否变得更糟？（否=✅，出现波动=⚠️观察，创伤被激活=❌转trauma-hysteria）
```

**通过标准**：至少 5 项 ✅，无 ❌。如有 ❌，立即执行对应 fallback。

### 安全兜底
若出现自杀想法或急性危机：**立即停止分析——需要立即专业帮助，不是分析。提供 12356（心理援助热线）或当地精神卫生中心**。若用户出现精神病性症状（现实检验失败）：**此模型不适用于自助，转专业临床处理**。若分析过程中出现创伤被激活迹象（解离/闪回/压倒性恐慌）：**停止，转 `freud-trauma-hysteria` 的危险信号处理（稳定化优先）**。

## 练习手册

- **三张纸条**：对一件纠结的事，分别写「本我要什么」「超我说什么（谁说的）」「现实允许什么」，三张并排看。
- **超我溯源**：把最常听见的「你不应该/不配」写下来，旁边配一个外部来源（人/场景/年代）。
- **最小方案打勾**：三方僵住时只做三件事——休息、吃饭、呼吸，写下并打勾。
- **症状反查**：本周出现的失眠/疲劳/头痛，对照诊断信号表填一栏「可能的三方解释」。
- **重命名练习**：把一个「无名恐惧」改写成一句带主语的句子（如「那是父亲的声音在说……」）。

## 反例黑名单 —— 不要做的事

1. **不要把三个声音的结论直接抛给用户「你就是超我太强」** —— 要通过提问让用户自己辨认声音来源
2. **不要在追溯超我来源时暗示「你父母害了你」** —— 超我来自内化过程，不是简单归咎
3. **不要在用户无法回答时强行推进** —— 如果用户「不知道想要什么」，这是信号不是失败，用退化问题
4. **不要把「最小可行方案」包装成「解决方案」** —— 这是临时休战协议，不是永久和平
5. **不要在用户出现躯体化症状时只用结构模型分析** —— 身体信号可能需要 `freud-trauma-hysteria`

## 灰色地带

1. **「焦虑是主角还是配角」**：内心冲突常伴焦虑，判断标准是焦虑是否独立于冲突持续存在——若是，转 `freud-anxiety-defense`。
2. **本我需求 vs 逃避的借口**：区分「真正想要」与「回避不适」很微妙，靠追问「不需要对任何人交代时你会做什么」来逼近，不轻易定论。
3. **超我并非全是坏的**：有些超我要求是合理的社会规范，不一律降级；只审查「过时且不可协商」的部分。
4. **最小方案的危险**：长期停留在「休息、吃饭、呼吸」会掩盖需要专业介入的慢性状态——数周无改善即升级。
5. **结构模型 vs 哀悼忧郁**：当冲突里夹着「我不配」时，优先核对自尊是否受损，避免把忧郁当纯冲突处理。
