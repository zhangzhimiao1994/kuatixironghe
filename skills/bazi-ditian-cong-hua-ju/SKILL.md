## I：核心解释

这一大块讲的是**旺衰到极处时的「顺逆」问题**：日主一面倒了怎么处理，合了化不化怎么讲，几股力气并旺又无主时怎么办，以及战、合、君、臣、母、子这些象各自的方向。全部落在同一个原则上——**可顺不可逆、要「损上益下／损下益上」地给出路，而不是硬克硬制**。

1. **从象分真假**：经文说「孤立无气唯有从，依得财官享富贵」（R1，原书注明这句「原文缺，此后人按原注意补」）。原注给真从的条件——「日主孤立无气，无地人元，绝无一毫生扶之意，财官强甚，乃为真从也」（R2）。任注又把从象扩成「非专论财官」，另有从旺、从强、从气、从势四从：其中「从旺者，四柱皆比劫，无官杀之制，有印绶之生，旺之极者，从其旺神也」（R3）。
2. **化象讲合化与化神**：「化得真者只论化，化神还有几般话」（R4）——合化成立后，先论所化之神，再看化神自身衰旺有余不足来定喜忌。任注把化象说成「贞妇配义夫，从一而终，不生二心」（R5），既化之后不再作争合妒合论。
3. **假从、假化是「真而不真」的两类**：「真从之象有几人，假从亦可发其身」（R6）、「假化之人亦多贵，孤儿异姓能出类」（R7）——局中有比劫、印绶暗生之类，从得不干净，但行运安顿、抑假扶真，也能兴起；书上同时点出这类人多「不能免祸」「心术不端」或「执滞偏拗」。
4. **顺局（从儿）是「我生」一路顺下去**：「一出门来只见儿，吾儿成气构门闾：从儿不管身强弱，只要吾儿又得儿」（R8）——月建逢食伤、四柱食伤旺，不论日主强弱，只顺食伤之势，且要「儿又得儿」（局中有财），转成生育之意。任注明说它的忌讳——「从儿格最忌印运，次忌官运」（R9）。
5. **反局四句讲四种「颠倒之妙」**：经文一口气给了「君赖臣生」（印旺用财止水）、「儿能救母」（子制克母之神）、「母慈灭子」（印太旺反灭火，只能顺母而助子）、「夫健怕妻」（日主旺而财重，得金反被克）四反（R10）。
6. **战局与合局讲两边打起来怎么办**：「天战犹自可，地战急如火」（R11）——天干相克事缓、地支相冲事急；「合有宜不宜，合多不为奇」（R12）——合要看宜不宜，合多了反而不流通、不奋发。
7. **君象·臣象·母象·子象是一组「上下取平」的象**：君象「君不可抗也。贵乎损上以益下」（R13），任注点明「损上者，泄上也，非克制也，上泄则下受益矣」（R14）——对上位之神用泄不用克；臣象「臣不可过也，贵乎损下而益上」（R15）；母象「知慈母恤孤之道，始有瓜瓞无疆之庆」（R16）；子象「知孝了奏亲之方，始克谐成大顺之风」（R17）。四象都讲母子君臣之间**不可损一方、只能助其势让两边都安**。

## A1：来源应用

书上给的做法，都绕「先判从与不从／化与不化，再定顺逆方向，最后给损上还是损下」三件事：

- **判从**：先看日主是不是「孤立无气、绝无一毫生扶之意、财官强甚」（R2）；再分所从之神（从财、从官）与四从（从旺、从强、从气、从势，R3 及同段）。
- **判化**：看是不是「合而能化、得辰」之类成立；既化之后「只论化」、「从一而终」（R4、R5）。
- **量真假**：局中有比劫暗生、印绶暗扶、食伤破印之类，从之不真即为假从假化（R6、R7）；书上说假者「只要行运安顿，假行真运，亦可取富贵」。
- **顺局取方向**：食伤旺的顺局，取「儿又得儿」（有财）为美，忌印忌官（R8、R9）。
- **反局取方向**：四句各是一类颠倒，落到具体处是「该泄的不该克、该助的不该损」（R10）。
- **战与合**：天战可缓、地战宜急（R11）；合要审宜不宜（R12）。
- **四象取平**：君象泄上益下（R13、R14）、臣象损下益上（R15）、母象助子（R16）、子象安母（R17）。
- **报格局要给两句**：断一个从或化，必须同时给出**原书依据（哪一篇、是经是原注还是任注）**与**取用条件（凭什么这么取）**；只报格名不出处不合格。
- **评价语提醒**：这一块原书带断语（如「名高翰苑」「仕至尚书」「不禄」），这些是**书里的说法**，引用时标明，不落到具体人身上。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月令、四柱的比劫／印绶／官杀／财／食伤分布，日主是「孤立无气」还是「有生扶」，局中合了几处、有没有辰这类化神之地。
2. **逐条核书里的条件**：日主是否「孤立无气，无地人元，绝无一毫生扶之意，财官强甚」→ R1／R2；四从之从旺看「四柱皆比劫，无官杀之制，有印绶之生，旺之极者」→ R3；合而能不能化 → R4／R5；从得不真（有比劫印绶暗生）→ R6／R7；顺局看是不是「儿又得儿」（局中有财）→ R8，忌印忌官 → R9；反局看该泄该助 → R10；战合看天战地战、宜不宜 → R11／R12；君臣母子四象看该损上还是损下 → R13–R17。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「日主无一处生扶、财官俱旺，按 R1／R2 这一路读，偏『真从』，出处《滴天髓闡微》六親論·從象」。
4. **收口**：这一句是**书里的读法**，不是对这个人的判定；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：原书讲从化顺反只讲到「顺逆方向」与「损益之法」，不讲后世流派的「从格自动判法」「化气计分」；这些都不进本 skill。

   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《滴天髓闡微》六親論·從象」）。
9. **收口**　输入：整段推演 → 输出：一句格名 + 一句取用条件 + 一句出处；结尾说明本 skill 到取象为止，不接流年大运与终身断。

## 📖 练习手册

- **真假对照**：合上 R 节，写出真从的条件与假从能发的原因各一句，并指出差别在哪。
- **四从默写**：写出从旺一句原文，再补出同段从强、从气、从势各说的是什么。
- **顺逆方向**：给顺局与反局各写一句，标明「该顺什么、该忌什么」。
- **四象取平**：把君象与臣象两句并列，写出「损上益下」和「损下益上」各用泄还是用克。

## 🚫 反例黑名单（不要做的事）

1. 只报「从财格」「化气格」这类格名，不给原书篇名与取用条件。
2. 把「从」与「化」说成一回事。
3. 由从格、化格顺手判某人终身成败、顺口批流年大运。
4. 把「心术不端」「不能免祸」这类书里的评价语，当作对眼前这个人的判决。
5. 缺出生柱就凭一句描述排出四柱往下断。
6. 用后世流派的「从格自动判法」之类说法替原书背书。

## 灰色地带

- **从象首句原书自标「原文缺」**：照实说明这句是后人按原注意补的，讲时把它与 R2 的原注一起给，不把补句当成无疑的经文。
- **一局既像从旺又像从强**：据实并列书里从旺与从强的条件，说明差别在印比之轻重，不替用户归一类。
- **化象里「化神还有几般话」**：书上讲的是化神自身有余不足再定喜忌，据实讲这层，不多推。
- **从儿格与伤官格容易混**：顺局原注明说此与伤官不同；照实说明两者的分野，不混讲。
- **用户把四象当人事关系**：君臣母子是取象用的名分，不是现实里的君臣母子；照实说明。
