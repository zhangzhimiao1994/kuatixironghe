# 支垄之辨：平洋与山垄两套体认

**来源**：sources/zangshu.txt（《葬書》内篇二至内篇四） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户问「支垄之辨」到底辨什么、为什么难。
- 用户拿着一处平地，问「没有山，这个怎么看」。
- 用户问「地貴平夷，土貴有支」是什么意思。
- 用户读到「地勢原脈，山勢原骨」不懂。
- 用户问「觀支之法，隱隱隆隆」是看什么、怎么认。
- 用户问山地和平地是不是两套完全不同的看法。

**不应触发**：
- 用户问「风水」这个词的定义、得水藏风 → 转 kanyu-zangshu-cang-feng-de-shui。
- 用户问「势来形止」「千尺为势百尺为形」 → 转 kanyu-zangshu-shi-lai-xing-zhi。
- 用户问相地第一原理「乘生气」是什么 → 转 kanyu-zangshu-cheng-shengqi。
- 用户问某地贵贱断语、像什么品 → 转 kanyu-zangshu-xing-shi-pin-lei。
- 用户要求现场点穴、给葬位与深浅 → 本族不接。

## I：核心解释

支垄之辨，是这套书里最吃功夫的一块。它要回答的是：**同一口气，在土里怎么认、在石里怎么认。**

1. **先说分野**：内篇二开篇就把地形分成两种——「丘壟之骨，岡阜之支」（R1）。注疏解释：「丘壟為陰，岡阜為陽……壟高不能自立，必藉石載土而後能聳也。」（R12）垄是带石的、靠石载土才耸得起的高地；支是土山、靠毛脊来辨认。这是支垄两套体认的起点。
2. **认法不同**：「地勢原脈，山勢原骨」（R3）——平地看的是土里的脉络，山地看的是石里的骨脊。注疏说得更直白：「平夷之地多土，陡瀉之地多石，故支之行必認土脊以為脈，壠之行則當求石脊以為骨也。」（R11）
3. **平地怎么认**：「地貴平夷，土貴有支」（R4）——平地以平坦为贵，可贵的不是平，是平土里还藏着「支」。认的办法是「觀支之法，隱隱隆隆」（R6）：似有似无是「隱」，微微隆起是「隆」。注疏把它讲成一串比方：「其體段若盞中之酥，雲中之雁，灰中線路，草蛇蹤」（R14）——像杯盏里浮的酥、云里的一点雁、灰里的一条线、草间的一道蛇迹，生气就在这隐约之间走。
4. **支气怎么走**：「支之所起，氣隨而始；支所終，氣隨以鐘。」（R5）支从哪儿起、气就跟着开始；支到哪儿终、气就在那儿聚。所以平地的读法是看毛脊的起与终。
5. **山垄怎么认**：「山者勢險而有也，法葬其所會。」（R8）山虽险峻，但险中另有不险之穴；做法是找它「止聚融會」的地方。注疏补：「勢雖險峻，而其中復有不險之穴，但當求其止聚融會處而葬之，則善矣。」（R13）
6. **总纲是「乘其来」**：「乘者其來」（R9）——认气是从哪儿来的，由「来」知道它「止」在哪儿。注疏：「言生氣之所從來，因其來而知其止，故葬者得以乘之，不使有分寸之違也。」（R15）
7. **经里的印证**：「經日：地有吉氣，土隨而起；支有止氣，水隨而比。」（R7）地有吉气，土就随之凸起；支有止气，水就与它相比邻。这是支龙行度的经文表述——「土随而起」「水随而比」两句，正是平地认支的要诀。
8. **难在哪里**：注疏自己承认「支壠之說，景純著書不爲不明第，後人不通其義，注釋雖多，悉皆非是」（R2）。也就是说，连注疏都说前人解错了不少——这是本主题的特殊性：书里承认它难，读的人也常把支垄认反。遇到似支非支、似垄非垄的情形，本 skill 只给辨认方向，不硬下结论。

9. **支里也有最难认的一种**：注疏说有一等「支體而得城之情性者，直如擲搶，急如繃線，謂之倒火硬木，此陽中含陰也」（R16）——明明是平地之支，行度却刚急如掷枪、绷线。书里说这种「法當避殺」，是支龙里至难体认者。
10. **垄里也有反着来的一种**：反过来，「以隴為體而得支之情性者，大山翔舞垂下，及至平地，變為支體，謂之下山水」（R17）——高山垂到平地变成支体，是「陰中含職」的一种，也不能照山垄的直法去葬。
11. **平地认支的具体样子**：注疏给了一串形状——平夷之地「微露毛脊，圓者如浮漚，如星，如珠，方者如箱，如印，長者如玉尺，如蘆鞭，曲者如幾如帶」（R18）；「及其止也，則如雞窠旋螺之狀」（R19），形止脉尽而一水交度。
12. **归到一句话**：支垄之辨不是背名词，是两条看地的手感——山地认石骨、寻止聚融会；平地认土脊、寻毛脊起终。两处最后都落到「乘其来」（R9）。
13. **一张对照表**：

| 项目 | 支（平洋） | 垄（山垄） |
|---|---|---|
| 阴阳 | 冈阜为阳（R12） | 丘垄为阴（R12） |
| 认什么 | 土脊为脉（R11） | 石脊为骨（R11） |
| 气怎么走 | 支起气始、支终气钟（R5） | 势险而有、法葬其所会（R8） |
| 看什么 | 隐隐隆隆（R6） | 止聚融会处（R13） |
| 反着来的一种 | 支带刚急（R16） | 垄垂变支（R17） |

## A1：来源应用

书上给的是辨认的方向，不是一张分类表：

- **先分阴与阳**：垄为阴（多石、高耸），支为阳（多土、平缓）（R12）；两者取用不同。
- **平地作业法**：认平土里的「隱隱隆隆」之毛脊（R6、R14），顺毛脊看它的起与终，起处气始、终处气钟（R5）。
- **平地合格的样子**：注疏说支「貴乎平坦夷曠，為得支之正體」（R10）——平坦夷旷是支的正体；再看土中是否有「支之紋理」，平缓恰软、不急不燥，则表里相应（R10）。
- **山地作业法**：在险峻里找「止聚融會」处（R8、R13），而不是见高就葬。
- **共同总纲**：因「来」知「止」，乘其来（R9、R15）。
- **读错就等于认反气**：注疏把支垄之辨称「葬法中之綱領」（R12 所在条），认错方向，气就从「生气」变成「杀气」（这句是本 skill 依原书脉络的转述，属（补充））。
- **评价语提醒**：内篇二至四讲的是辨认之法，很少下贵贱断语；贵贱断语在雜篇品类条。

## A2：典型触发场景

1. 用户在一处平原，问「这里没有山，凭什么看龙」。
2. 用户读到「地貴平夷，土貴有支」，以为「平就是好」。
3. 用户把山垄的认法（找山脊）套到平地上，想纠正。
4. 用户问「隐隐隆隆」到底在说什么、看不见怎么办。
5. 用户问「支垄之辨」为什么书里说难、难在哪儿。
6. 用户已经给了地形描述，想先归类是支还是垄。

## E：执行步骤

1. **收地形**　输入：用户的描述 → 输出：先判定证据指向支（多土、平缓）还是垄（多石、陡峻），或证据不足。
   🔴 **CHECKPOINT**：信息不足（不知道多土还是多石、有无毛脊）就先列出缺什么，不硬归类。
2. **分栏讲两套认法**　输入：归类结果 → 输出：支按 R4/R5/R6/R14 讲（看毛脊起终），垄按 R8/R13 讲（求止聚融会）；两栏各挂原句。
3. **落到「乘其来」**　输入：认法讲完 → 输出：用 R9/R15 收口——不管支垄，都是因来知止。
4. **拆经文与注疏**　输入：用到的条 → 输出：把经文（R1、R3、R4、R5、R6、R7、R8、R9）与《錦囊》注（R2、R10、R11、R12、R13、R14、R15）分栏，注疏一律标「《錦囊》注」。
5. **提示难度**　输入：用户的追问 → 输出：用 R2 说明书里自承这支最难、注家多误；遇似支非支的，给方向不下结论。
6. **收口**　输入：整段推演 → 输出：一句辨认方向 + 缺项照实说；若用户要贵贱断语，转 kanyu-zangshu-xing-shi-pin-lei。
   🔴 **CHECKPOINT**：收口前检查有没有把「支为阳、垄为阴」讲反，有没有把平地当成「没形势可看」。

**形势取数（相地前置，可选）**：手里只有地名或经纬度、没有现场形势描述时，可用包内 `tools/xingshi.py` 取数（高程/高差/坡度坡向/八向遮护/水系方位），拿到一份可核对的形势描述再判读；映射关系与局限见 `docs/形势取数与映射表.md`。**先查再跑（硬规定）**：取数前先跑 `python tools/install_deps.py`（含数据源连通体检）或 `python tools/xingshi.py --check`；有不可用项就停下、报清楚，**不许跑到一半才发现取不到**。取不到就照实写——「取到 0 条」≠「现场没有」。**三种入口**：① `--url` 直接吃地图 App 的分享链接（高德/百度），自动解出坐标与地名、并按高德 GCJ-02／百度 BD-09 转成 WGS-84（不转会系统性偏 500–1200 m）；② `--place` 给地名（会列候选让你核对）；③ `--lat/--lon` 直给，用 `--crs` 说明是哪家地图读的。另有一级 **`--area KM` 区域大势粗读**：出区域整体倾斜方向与高带／低带方位（标注「粗读」，分辨率更粗）。水系有两层：OSM（带河名，乡野常缺漏）＋ **离线河网**（无河名，但按河流级别排干枝，补乡野缺漏）。**取数不等于判读**——地理量翻成书里术语的那几步是「（补充）」，回答里要保留这个标注；仍不点穴、不给葬法、不接阴宅实地作业指导。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把山垄的认法套到平地 | 在平原上找「石骨」「高山止聚」 | 回到 R4/R6/R14：平地认的是土脊毛脊的隐隐隆隆 |
| 把平地当「没形势可看」 | 说平地无山就看不了 | 回到 R5/R7：支有起有终、土随而起、水随而比，照样有得看 |
| 阴/阳讲反 | 说垄是阳、支是阴 | 按 R12 纠正：丘壟为阴、岡阜为阳 |
| 缺地形描述却硬归类 | 只凭一句「这块地不错」就判支或垄 | 列缺项（多土/多石、有无毛脊、起终、水），不硬归 |
| 把辨认讲成一步点穴 | 直接给葬位与深浅 | 只给辨认方向，作业指导转形势类或说明本族不接 |
| 把注疏当经文 | 把 R2、R14 之类标成经文 | 注疏统一标「《錦囊》注」 |

**边界规则**：
1. 只讲支垄的辨认之法与两套体认，不接现场点穴与择地指导。
2. 该给贵贱断语的场合一律转 kanyu-zangshu-xing-shi-pin-lei。
3. 不给医疗、法律、投资结论。
4. 象征层只给倾向，不写「一定 / 必然 / 命中 / 保证发财发贵」。
5. 书里自承「支垄最难、注家多误」（R2），遇到似支非支的情形要照实承认拿不准，不许硬判。

**来源边界**：本 skill 只据 sources/zangshu.txt 内篇二开篇、内篇三「地勢原脈」条、内篇四「地貴平夷」至「乘者其來」诸条；不引外篇、雜篇。外篇另有「支欲伏於地中，壟欲峙於地上」的说法，本 skill 不取，以免越界。

## 练习手册

- **两地对照表**：给自己熟悉的一处山地与一处平地，各写「看什么、到哪里算止、该注意什么」，只填做法方向，不写吉凶。
- **毛脊描摹**：找一处平原或缓坡，用「隱隱」「隆隆」两个词各造一句描述，练把隐约的地势说出口。
- **阴阳归位**：默写「丘壟为阴、岡阜为阳」并各举一个辨认特征，纠正自己容易记反的地方。
- **乘其来练习**：任取一处地形，只写「它从哪来、可能止在哪」，不写吉凶。

## 反例黑名单

1. 把平洋当「没形势」，说无山就看不了。
2. 拿山垄的标准（石骨、高山止聚）去量平地。
3. 把垄与支的阴阳属性讲反。
4. 用户只给一句描述就判支或垄。
5. 把辨认之法直接推演成现场点穴、给葬位深浅。
6. 把《錦囊》注（如「盞中之酥、雲中之雁」的比方）当成经文。

## 灰色地带

- **似支非支、似垄非垄**：原书与外篇都承认有这种情形；本 skill 只给辨认方向与要补的信息，不硬归一类。
- **一处地半山半原**：先分段描述，再分别按两套读法走；不强行归一类。
- **用户要「支垄 + 吉凶」一条龙**：支垄辨认照讲，吉凶断语转 kanyu-zangshu-xing-shi-pin-lei，并说明两者是两层。
- **用户质疑「书里自己都说注家都错，那你还讲什么」**：照实承认这支原书自承难、注家多误（R2）；本 skill 只把书上给的方向讲清，不冒充能定案。
