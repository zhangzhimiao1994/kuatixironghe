# 哀悼与忧郁模型

**基于**：*Mourning and Melancholia* (1917e)

## 输出纪律（硬要求，先于任何分析）

1. **先复述处境，再说理论**：回答第一段必须用**用户自己的细节**复述他的处境——他说的那些具体时刻、那句原话（例如「别人一句话，你都能想成是自己做错了」）。复述完才可以谈模型；不允许开口就是「力比多」「认同」「超我」。
2. **不得替用户断言他说不出的成因**：凡是「你的自责其实是在替某人/某段关系扛着」「这跟某段丧失有关」这类读法，**一律写成可证伪的假设，不写断语**，并用「符合 / 不符合」两列请用户自己对照：
   - 符合：若是这个读法，会出现 X
   - 不符合：若不是，会出现 Y
   只有用户对照后自己说「对」，才往下推进。禁止说「你就是」「你其实是在替 TA 扛」。
3. **贴近而不定义**：可以说「有一种可能，值得你自己对照看看」；不可以说「你就是」。让用户自己发现，不替他解读。
4. **正文 ≤800 字**：一次回答正文不超过 800 字，宁可留白让用户接话，不倾倒理论。
5. **安全线（见下方「安全兜底」，不改动）**：不诊断、不病理化、不替代心理治疗与就医；出现持续低落、失去生活能力或自伤念头 → 立即停止分析，走热线通道（12356 / 当地精神卫生中心）。
6. **反转假设的准入门槛（硬规则）**：反转假设——即「懊悔/自责其实是替某人/某段关系在兜着」——**只有在用户已交代丧失对象、且自责背后的自尊受损同时成立时**才可提出。两者缺一（无丧失对象，或自尊未受损）→ 一律不得提反转，转 `freud-structural-model` / `freud-anxiety-defense`。

## 触发条件

### 应该触发
- 用户出现持久的自我谴责和低价值感
- 用户处于某种丧失后：失去人、失去工作/地位、失去健康、失去自我形象
- 用户说「我不够好」「我不配」「一切都怪我」
- 用户有自杀意念
- 丧失后：自我谴责听起来像在说别人
- 触发词：「走不出来」「放不下」「我活该」「我不配」「都是我害的」「没有我会更好」

### 不应触发
- 单纯的情绪低落、明确的现实挫折反应
- 有明确生理原因的抑郁（需先排除器质性）
- 内心冲突但自尊完好（「我应该但不想」）→ `freud-structural-model`
- 以焦虑/回避为主，丧失不是主线 → `freud-anxiety-defense`

## R：原文锚点

> 说明：以下中文为**中译，译自英文全集**（Ivan Smith 编 *Freud – Complete Works*），非逐字原文；英文原句已逐字回书核，见各条括号内。

> 「对象的影子落在ego上。」（《哀悼与忧郁》1917e；原文 *the shadow of the object fell upon the ego*——力比多撤回自我、与被抛弃对象认同之处）（已据英文全集核）

> 「哀悼中，世界变得贫乏和空虚；忧郁中，是自我本身变得贫乏和空虚。」（《哀悼与忧郁》1917e，论哀悼与忧郁之别的章节；原句 *In mourning it is the world which has become poor and empty; in melancholia it is the ego itself.*）（已据英文全集核）

> 「人不能杀死自己，除非能把自己当作一个对象来对待。自杀是把针对对象的敌意转向自身。」（《哀悼与忧郁》1917e，论忧郁机制之处；原句 *the ego can kill itself only if... it can treat itself as an object - if it is able to direct against itself the hostility which relates to an object*）（已据英文全集核）

## I：核心解释

```
丧失（对象）→ 原本应释放的力比多没有投向新对象
→ 力比多撤回自身（ego）→ 通过「认同」将失去的对象内化到ego中
→ 「对象的影子落在ego上」
→ ego被分为两半：批判性代理（后来的超我）vs 被对象染色的ego
→ 批判性代理攻击被对象染色的ego
→ 自我谴责 = 对被内化的对象的谴责（被转移的指控）
```
（追 R 第 1 条：对象的影子落在 ego 上。）

### 核心诊断工具：区分哀悼和忧郁

| 特征 | 哀悼 | 忧郁 |
|------|------|------|
| 丧失 | 意识知道失去了什么 | 潜意识知道失去了什么/谁，但不知道失去了ta的「哪部分」 |
| 自尊 | **完好** | **严重受损** |
| 自我谴责 | 无 | 有——且过度、与实际不符 |
| 本质 | 正常、健康的过程 | 需要处理的病理状态 |
| 自杀风险 | 低 | **高**（自我正在把矛头对准自己） |

（追 R 第 2 条：哀悼是「世界」变空，忧郁是「自我」变空。）

## A1：来源应用 —— 书上的做法

1. **逐段记忆、逐一期待的现实检验**：哀悼的目标是接受丧失是永久的→释放力比多→投向新对象；不是「忘掉」，而是逐段告别。
2. **反转自我谴责**：自我谴责若与实际不符、听起来像在说别人，就把它「反过来」看——它适不适合某个你失去/对你失望的人？这是把「被转移的指控」还原回去的关键工具。**注意：反转向来是假设、不是断语**——必须配「符合/不符合」两列让用户自己对照，不得替他下「你是在替某人扛」的结论。
3. **识别矛盾情感**：忧郁的核心是对丧失对象的爱与恨并存；恨无法直接表达（人已离去或不能攻击）→ 恨转向自己。
4. **不病理化正常哀悼**：自尊完好 = 正常哀悼，给空间、不分析；只有自尊受损才启动忧郁机制。
5. **持续时长不是唯一判据**：个体差异大，无固定时间表；但自我谴责模式持续超 2 个月无改善 → 建议专业评估。

## A2：典型触发场景

- 「我妈去世后我整个人就垮了，觉得都是我没照顾好她，我不配过得好」
- 「我丢了工作之后一直觉得自己这么没用，配不上任何机会，我活该」
- 「别人没有我会更好」
- 丧失（人/地位/理想/自我形象/健康/希望）后开始自我贬低，且自我谴责听起来像在指责另一个人

## E：执行步骤

### 第一步：确定丧失
**输入**：用户描述的「变差」起点。 **输出**：丧失对象的初步定位。
问用户：
- 你最近失去了什么？（人/地位/理想/自我形象/健康/希望）
- 什么时候开始感觉自己变差的？
→ 如果用户在丧失/改变后开始自我贬低 → 高度怀疑忧郁机制的激活

### 🔴 CHECKPOINT：鉴别后确认（第一步后）
```
🔴 验证：丧失对象 = [用户提到的失去]，自尊受损 = [是/否]，如果「否」→ 这是正常哀悼不是忧郁，给空间不分析。确认？
```

### 第二步：反转自我谴责
**输入**：用户的自我谴责原句。 **输出**：该谴责是否对号入座到某个被内化对象。
关键的问法：**「如果你刚才对自己说的那些话，反过来看看——它们适不适合另一个人的特征？那个你失去/或对你失望的人？」**

例子：
- 用户说「我这么没用，根本配不上别人的帮助」
  → 把这句话反过来：是不是对某个让ta失望的人说的？
- 用户说「我是个负担」
  → 可能是内化了某个人说的话，或ta想对那个人说的话

> **硬约束**：「反转」是一个**可证伪的假设**，不是结论。提出来时必须同时给「符合 / 不符合」两列（若是这个读法会出现 X；若不是会出现 Y），请用户自己对照，不得替他断言「你其实是在替某人扛」。用户对不上，就停在复述与观察，不强行归因。

### 🔴 CHECKPOINT：反转后确认（第二步后）
```
🔴 验证：自我谴责的内容，反向后是否对应 [某个被内化对象]？如果是 → 忧郁机制确认。如果不是 → 可能不是忧郁，转 freud-structural-model 或 freud-anxiety-defense。
```

### 第三步：识别矛盾情感
**输入**：用户对丧失对象的情感。 **输出**：爱与恨是否并存。
- 对已失去的对象有**爱**吗？有**恨**吗？
- 矛盾情感（ambivalence）= 忧郁的核心
- 恨无法直接表达（人已离去或不能攻击）→ 恨转向自己

### 🔴 CHECKPOINT：矛盾情感确认
```
🔴 对丧失对象的矛盾情感 = [用户表达的爱与恨]
- 只有爱/只有恨 → 可能不是典型的矛盾情感忧郁，转 freud-structural-model 检查是否是三角冲突
- 爱+恨并存 → 忧郁机制进一步确认，继续第四步
确认？
```

### 第四步：完成哀悼工作
**输入**：被确认的矛盾情感。 **输出**：逐段告别的推进（或转介）。
- 哀悼是**逐段记忆、逐一期待**的现实检验过程
- 目标：接受丧失是永久的 → 释放力比多 → 投向新对象
- 如果矛盾情感太强 → 哀悼可能停滞 → 需要专业帮助

## B：边界与失败模式

### 失败模式分支表

| 触发条件 | 一线修复 | 仍失败兜底 |
|---------|---------|-----------|
| 用户在第一步说「我不知道失去了什么」 | 问：「什么时候开始觉得自己变差的？那段时间发生了什么？」不限于明确丧失——理想/希望/自我形象的丧失也是丧失 | 仍无法识别 → 转 `freud-structural-model`（可能是三角冲突伪装成丧失） |
| 「反转自我谴责」后不匹配任何对象 | 不是忧郁——可能是结构性冲突或焦虑 | → 转 `freud-classic-hub` 重新路由 |
| 用户说「我知道该放下但做不到」 | 正常化：「哀悼不是放下，是逐段告别。卡住不是失败。」 | 如果超过2个月无改善 → 建议专业评估 |
| 哀悼停滞——反复回到同一段记忆 | 确认是否矛盾情感太强（爱+恨并存）→ 帮助命名：「你对TA同时有爱和恨，两种都是真的」 | 如有自杀意念 → 立即停止，给热线 |
| 替用户断言他说不出的成因——如「你其实是在替某人/某段关系扛」「这跟某段丧失有关」 | 撤回断语，改写成**可证伪的假设**，并给「符合 / 不符合」两列（若是这个读法会出现 X；若不是会出现 Y）请用户自己对照 | 用户完全无从对照、并无此体验 → 不下结论，停在复述与观察，转 `freud-classic-hub` |

### 边界规则
- 内源性抑郁（生物学基础）≠ 心因性忧郁——此模型主要适用于后者
- 正常哀悼的持续时间因人而异，无固定时间表
- 如果自我谴责的模式持续超过2个月且没有改善 → 需要专业评估

- 「死了更好」
- 「我不应该存在」
- 「别人没有我会更好」
- 任何关于结束生命的具体计划

## 练习手册

- **丧失清单**：写下你最近（或一直）失去的东西，人/地位/理想/自我形象/健康/希望各列一行，标出「何时开始变差」。
- **把谴责翻过来**：抄下你对自己说过最狠的 3 句话，逐句反过来问：「这话更像是在说谁？」不急着下结论，只记下联想。
- **爱与恨两栏**：对那个你失去的人，左边写「爱的地方」，右边写「恨的地方」，两边都允许存在。
- **逐段告别**：选一段共同的记忆，写下它，再写一句「这件事是过去式了」。一次一段，不贪多。
- **求助刻度**：每周给自己打一个 0–10 的「低价值感」分，看趋势而非单日数值。

## 反例黑名单 —— 不要做的事

1. **不要在第一步判断「哀悼 or 忧郁」之前就开始分析忧郁机制** —— 先鉴别，再深入
2. **不要对正常哀悼的人说「你这是忧郁」** —— 正常哀悼自尊完好，别把健康过程病理化
3. **不要在「反转自我谴责」时说「你其实是在骂TA」** —— 让用户自己发现，不替你解读
4. **不要在用户说自杀意念后继续任何分析** —— 不管分析到哪一步，立即停止，给热线
5. **不要在用户说「我想通了」但情绪毫无变化时轻信** —— 忧郁的「想通」可能是理智化防御，观察情绪是否同步
6. **不要替用户断言他说不出的成因** —— 不要说「你其实是在替某人扛」「你这就是某段丧失」；这类读法只能写成可证伪的假设，并给出「符合 / 不符合」两列让用户自己对照
7. **不要一上来就讲理论** —— 第一段必须先用用户自己的细节复述他的处境，之后才允许引入模型
8. **不要在缺「丧失」前提时提反转假设** —— 用户没交代丧失对象、或自尊完好（只是被别人一句话带着自责），不得说「你其实是在替某人/某段关系兜着」；两条件（已交代丧失对象 + 自尊受损）同时成立才允许，否则转 `freud-structural-model` / `freud-anxiety-defense`

## 灰色地带

1. **哀悼与忧郁的连续谱**：丧失早期人人都会自责，是否进入忧郁取决于「自尊是否严重受损」和「谴责是否与现实不符」，不靠单一句话定性。
2. **只有爱 / 只有恨**：可能不是典型矛盾情感忧郁，也可能是尚未浮现的矛盾——不轻易排除，转 `freud-structural-model` 核对三角冲突。
3. **器质性 vs 心因性**：若兴趣/食欲/睡眠的丧失有明确生物学底色，本模型只作辅助，不能替代医学评估。
4. **「想通了」的两种**：情绪同步跟上 = 真整合；情绪纹丝不动 = 可能是理智化防御，需观望而非庆祝。
5. **文化性哀悼表达**：不同文化对哀悼时长与表达方式的规范不同，不用统一时间表去衡量「正常」。
