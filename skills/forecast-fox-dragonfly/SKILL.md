# 龙蜻蜓之眼：多视角聚合，别戴绿镜片

**来源**：《Superforecasting》第3章「Keeping Score」（EXPERT POLITICAL JUDGMENT / DRAGONFLY EYE）、第5章「Supersmart?」（THESIS, ANTITHESIS, SYNTHESIS / DRAGONFLY FORECASTING）、附录「Ten Commandments for Aspiring Superforecasters」第5条 Look for the clashing causal forces at work in each problem | 证据等级：firsthand

## 触发条件

**应该触发**：
- 用户对一件复杂的事只给出一个解释，或反复用同一套道理套不同问题（"关键就一点……"）
- 用户问"我是不是只看到了一个角度""这个判断有没有盲区""帮我找个反对意见"
- 用户面对两份互相打架的道理（正题 / 反题），想知道怎么合成一个判断
- 用户先入为主地认定了一边，却要为一个有风险的决定下注
- 用户在团队里听到"一边倒"，想主动引入不同声音

**不应触发**：
- 命题还含糊、无法判定 → 先走 `forecast-calibrate-claim`
- 要从零把一个清晰命题估成概率 → `forecast-fermi-baserate`
- 已经有一个明确判断，来了新消息要更新 → `forecast-update-postmortem`
- 只是判断某道题值不值得花力气 → `forecast-triage-question`
- 纯事实查询或算术 → 直接做

## I：核心解释

1. **狐狸 vs 刺猬是一道真的分水岭**：书里把专家分成两类——"刺猬"围绕一个"大想法"（Big Idea）组织思考，"狐狸"则用许多工具、从许多来源取证。EPJ 数据显示狐狸在**校准与分辨率两项上都赢**，是真有前瞻。（R1、R2）
2. **刺猬的病根是"绿镜片"**：大想法像一副永不摘下的绿镜片，看什么都染成同一种颜色。它偶尔能凸显真实的东西，但更常扭曲现实；而且信息越多越糟——因为全透过同一副镜片看，只会增加自信、不增加准确。（R3）
3. **绿镜片的反直觉后果**：当刺猬在自己最懂的领域做预测时，准确度反而下降。对"大想法"越熟，越看不见与它不符的事实。（第3章 EXPERT POLITICAL JUDGMENT）
4. **狐狸的做法叫"聚合"**：不只用一个分析视角，而是用一个又一个；不只从一个来源，而是从许多来源取证，再合成一个结论。独自一人也能做——这套流程只是在"一个脑袋里"完成。（R4）
5. **龙蜻蜓之眼是它的比喻**：蜻蜓每只眼由成千上万个小透镜构成，每个透镜占一个略微不同的位置、给一个独特视角；成千上万个视角汇进大脑，才合成出近乎全向的超清视力。视角越多，判断越锐利。（第3章 DRAGONFLY EYE）
6. **合成不等于和稀泥**：先有"外部视角"和"内部视角"，再把它们**合并**成一个判断——就像两只眼睛的视角在大脑里合成为一个画面。它是真正的收敛，不是在两边各退一步摆摆样子。（R7）
7. **正反合会把你变成"混种"**：古典辩证里正题遇反题生出合题；在龙蜻蜓之眼里，是一个视角又遇一个视角、再遇一个视角，全都要合成一张图。做得好，你会从"鸽派"或"鹰派"变成"鸽鹰"——对何时该硬、何时该软有分寸感。（R8）
8. **主动搜寻冲突，是狐狸的刻意练习**：走出自己、真的换个角度看现实很难，"自我中心视角"会坚称它看见的就是客观现实。狐狸更愿意去试——不管靠性情、习惯还是刻意努力，他们都会做这件苦差事。（R6）
9. **为证伪先备好信号**：与其嘴上说"我保持开放"，不如在事前就列出**什么迹象会把我推向对面**。这样"改向"才是在按规则行动，而不是临时找台阶。（R9）
10. **把信念当假设，不当宝贝**：书里给超级预测者的一句话总结——信念是要被检验的假设，不是要被守护的财宝。（R10）

## A1：来源应用 — 书里怎么找视角、怎么合成

1. **"脑袋里的群众"（the crowd within）**：研究者发现，只要让人**先假设自己最初的判断是错的、认真想为什么会错、再重估一次**，这个第二次判断与第一次合并后，准确度的提升几乎等于另找一个人重估。让几周时间过去再重估，效果也一样。（第5章 THESIS, ANTITHESIS, SYNTHESIS）
2. **把判断写下来，请人挑错**：超级预测者 Bill Flack 常把推理写给队友看、请他们批评。写下来本身也是"自我反馈"——帮他从判断里退开一步来审视："我同意吗？有洞吗？我是不是该找点别的来补？如果我换成别人，会被这套说辞说服吗？"（第5章 THESIS, ANTITHESIS, SYNTHESIS）
3. **假装"另一边的我"**：George Soros 说自己的一个关键习惯就是**从自己身上退开一步**，评判自己的思考、给自己一个不同的视角。书里也记了 David Rogg 分享分析、主动去问队友在想什么的做法。（第5章 THESIS, ANTITHESIS, SYNTHESIS）
4. **"柯克船长"式的第三视角**：书里用一个猜数游戏说明：理性"瓦肯人"是一种视角，会偷懒的人性是一种视角，而**把前两种视角聚合起来考虑的人**又是第三种视角（Spock / McCoy / Kirk）。视角不必止于三个——理论上没有上限。（第3章 DRAGONFLY EYE）
5. **主动开放心态（AOM）**：心理学家 Jonathan Baron 的量表用这类陈述来测它——"人应当考虑与自己信念相悖的证据""注意反对者比注意赞同者更有用""改变主意是软弱的表现（反向计分）""直觉是决策的最佳向导（反向计分）"。超级预测者在这套量表上得分很高，而且**言行一致**。（第5章 THESIS, ANTITHESIS, SYNTHESIS）
6. **把信息来源本身做成"多元化"**：Doug Lorch 建了一个含数百个信息源的库，按意识形态倾向、题材、地域打标签，再写程序优先挑出多样的内容来读。他"不只是开放，而是主动地开放"。（第5章 THESIS, ANTITHESIS, SYNTHESIS）
7. **多手辩证的真实样子**：书里一位超级预测者在判断 OPEC 是否减产时写道"一方面……另一方面……第三方面……"，最后给出"感觉偏否，80%"。这正是龙蜻蜓之眼在运转。（第5章 DRAGONFLY FORECASTING。作者另注：结果沙特确实没有减产，令许多专家大跌眼镜）
8. **拿一副"牌桌"练视角取用**：职业扑克手 Annie Duke 让学生看见：非高手看到对手加注就默认对方牌强——可他们自己拿到稳赢的牌也常常不加注（怕吓跑对手）。他们从没想过自己的行为也在向对手传递信号。视对手为另一个"自己"，是视角取用的入门练法。（第3章 DRAGONFLY EYE）

## A2：典型触发场景

- "我一眼就看穿了这件事，没什么复杂的。"
- "这世界上的事说到底就一个道理：……"
- "他们都错了，就我看明白了。"
- "两个朋友给了完全相反的建议，我怎么合起来？"
- "帮我找找我的判断有什么盲区 / 给我一个反对意见。"
- 团队讨论一边倒，用户想主动引入不同声音。

## E：执行步骤

### 步骤1：先查"绿镜片"——你的解释是不是一副永不摘下的眼镜

**输入**：`question_or_judgment`（待判的事）+ 用户给出的理由。
**输出**：一句诊断——"这是狐狸式多视角，还是刺猬式单一视角？"

- 问自己：我是不是在用**同一个大想法**去套这件事？这个想法我是不是已经用了很多次、很少被它说服放弃过？
- 自检问题：如果它错了，会有什么现象我**看不见**？我最近是不是只增加了"支持它"的信息，而自信涨了、准确没涨？（R3、第3章 EXPERT POLITICAL JUDGMENT）

🔴 **CHECKPOINT — 触发条件：用户坚称"这就是唯一正确的道理"，拒绝谈别的可能**：别正面顶。先请他把这个"大想法"说成一句可检验的话，再问："假如现实与它相反，世界上会是什么样？"把"想法"变成可被证据挑战的**假设**（R10），再进入步骤2。

### 步骤2：主动搜寻冲突视角（不止两个方向）

**输入**：`current_perspectives` + `sources_consulted`。
**输出**：一份视角清单，至少包含"与你当前判断相冲"的一到数条。

- 别等别人来反对——**主动去找**：其他预测者怎么想？专家怎么说？外部视角（历史上这类事多常发生）与内部视角（这次有何特殊）各是什么？（R4、R6、第5章）
- 用"多手辩证"展开：一方面……另一方面……第三方面……把它写出来，而不是只在心里过一遍。
- 可以借用"脑袋里的群众"：认真假设自己判断错了，去想**为什么会错**，再重估一次（A1.1）。

🔴 **CHECKPOINT — 触发条件：找来的"反对意见"其实是同一个视角的变体（都是同一副镜片在看）**：喊停。要的是**不同来源、不同机制**的视角，不是同一观点换个人说。可让用户把视角的"来源"与"底层假设"分开列——来源重了，就不算新视角。

### 步骤3：正反合——合成一个判断，而不是各退一步

**输入**：步骤2的视角清单。
**输出**：一个收敛后的判断 + 一句话说明"哪些视角被吸收、哪些被压过、为什么"。

- 把外部视角与内部视角**合并**，像两只眼睛合成为一个画面（R7）；视角多时，把它们叠成一张图（R8）。
- 允许细分辨：合成后的判断往往是"偏哪边、偏多少"，而不是非黑即白。含混地说"也许吧"不是合成，是没做（第5章 DRAGONFLY FORECASTING 的 80% 示范）。

🔴 **CHECKPOINT — 触发条件：用户把"合成"做成了"两边都不得罪"**：拉回。合成必须能落到一个可判对错的判断上（如"感觉偏否，80%"）。若两边理由真的势均力敌、也说不清，就明说"暂时判不了"，而不要伪装成一个判断。

### 步骤4：事前写下"什么会让我改向"

**输入**：步骤3的合成判断。
**输出**：双方各列若干条"会把自己推向对面"的迹象，写在判断旁边。

- 按书里的做法：**每一方都事先列出会把自己推向对方的信号**（R9）。这样日后改向是在履行既定规则，不是临场找借口。
- 留下推理记录（写清日期与理由），便于将来请人挑错、也便于复盘（见 `forecast-update-postmortem`）。

🔴 **CHECKPOINT — 触发条件：用户说"我永远也不会改主意"**：这多半是自尊压在了信念上。回到 R10——把信念当假设来测试，而不是当财宝来守护；并温和提醒：狐狸在**校准与分辨率**上都赢过刺猬（R2）。

### 步骤5：请一个"外人"来审这份判断（可选但推荐）

**输入**：步骤3、4产出的判断与信号清单。
**输出**：一处或几处被指出的漏洞 + 修正后的判断。

- 参考 Bill Flack：把判断说出来 / 写下来，请人批评；或自己扮演"别人"，问"如果我是旁人，会被这套说辞说服吗？"（A1.2）

## B：边界与失败模式

### 失败模式分支表

| 情况 | 表现信号 | 立即执行替代动作 |
|------|----------|------------------|
| 绿镜片 | 同一套道理反复套用，只见支持它的证据 | 🛑 用"若相反会是什么样"把它变成可检验假设；主动找冲突视角 |
| 假多视角 | 找来的"反对意见"都是同源的变体 | 🛑 核对来源与底层假设；来源重复不算新视角 |
| 和稀泥 | "两边都有道理，看情况吧" | 🛑 逼落到一个可判对错的判断；说不清就明说说不清 |
| 只增自信不增准确 | 信息一大把，观点却越来越笃定 | 🛑 检查信息是否来自同一副镜片；引入不同来源 |
| 事后才谈"我对面" | 结果出来后说"我早知道会反过来" | 🛑 没有事前写下的改向信号就不算数；下次先列信号 |
| 视角过载 | 越找越乱，无法收敛 | 🛑 先排优先级：哪些视角能改变判断结果，先合成它们 |
| 涉及就医 / 自伤 / 危机 | 议题关于病情、生死、要不要撑下去 | 🛑 放下框架，转专业资源与人的支持，不诊断 |

### 边界规则

1. **本 skill 只做视角聚合与合成，不替用户拍板**：最终判断仍由用户自己下。
2. **视角要有独立性**：不同来源、不同底层机制才算新视角（R4）。
3. **合成必须可判对错**：容不下"也许""两边都有理"这种不落地的结果（第5章 80% 的示范）。
4. **不承诺视角越多越好**：视角多到无法收敛时，先按"能否翻转结论"排序，再合成。
5. **不提供投资 / 医疗 / 法律的专业判断**。
6. **安全兜底**：涉及就医、自伤、心理危机时放下本框架，指向专业资源，不诊断。

### 用户自查清单

- [ ] 我查过自己是不是在用单一"大想法"套所有事
- [ ] 我主动找过至少一个真正相冲突的视角（不同来源）
- [ ] 我用了"外部视角 + 内部视角"再合成
- [ ] 我的合成了一个可判对错的判断，不是和稀泥
- [ ] 我事前写下了"什么会让我改向"的信号
- [ ] 我留下了判断与理由，供日后挑错

**勾了 5 项以上**：龙蜻蜓之眼在工作。
**≤ 2 项**：多半还戴着绿镜片、或没真去搜冲突视角 → 回步骤1 或步骤2。

## 📖 练习手册

- **绿镜片体检**：拿最近三个判断，问"我是不是用了同一套道理"，把重复出现的那个"大想法"写下来，试着替它找一个反例。
- **三手辩证**：挑一件争议事，强制写出"一方面 / 另一方面 / 第三方面"，最后收敛到一个百分比判断。
- **脑袋里的群众**：对一条已有判断，认真假设它是错的、想出三个它会错的原因，再重估一次，和原判断并列比较。
- **改向信号清单**：给当前最重要的一个判断，双方各写三条"会把我推向对面"的迹象，贴在判断旁边。
- **换个来源**：刻意订阅一两个与你立场不同的信息源，连读一周，记下你被说服或更坚定的理由。

## 🚫 反例与黑名单

1. **用"我经验丰富，一眼看穿"封住所有讨论** → 🛑 这正是刺猬的特征；对最熟的领域准确度反而可能下降。
2. **把"我保持开放"当口头禅，却从不找相反证据** → 🛑 要用事前写下的改向信号来证明开放（R9）。
3. **把"多视角"做成同源意见的堆砌** → 🛑 不同来源、不同机制才算数（R4）。
4. **把合成做成折中与拖延** → 🛑 合成要落到可判对错的判断；判不了就明说。
5. **只收集支持自己的信息** → 🛑 信息越多只会越自信、不越准（R3）。
6. **用"他很自信"当裁判** → 🛑 自信与准确只是弱相关；书里明确反对把"底气足"当能力。
7. **在就医 / 危机语境里做视角游戏** → 🛑 停，转专业资源。

### 灰色地带（需谨慎判断）

8. **确实有一个占据绝对主流的解释**（如"重力会让球落下"）→ 狐狸不等于逢事都要反着说；当证据一边倒时，聚合的结论本就该偏向那一边。要区分"绿镜片"和"常识"。
9. **用户只能给出一个视角，因为确实只掌握一个来源** → 先补来源（步骤2），而不是硬凑相反意见；来源受限时，明说这个判断的证据基础薄弱。
10. **团队讨论一边倒，但领导者明确要求不要有杂音** → 引入异见要讲方式；可参考书里"建设性对抗"与"精准提问"的做法，先私下请人备好反对意见再拿出来。
11. **"和稀泥"和"诚实的不可判定"怎么分** → 和稀泥是回避落点；诚实是能说清"哪两股力量势均力敌、需要什么新信息才能判"。后者应明确写出需要的证据。
