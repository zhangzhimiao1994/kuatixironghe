# 格局總論與諸格：子平为什么只论财官印食

**来源**：sources/sanmingtonghui.txt（《三命通會》卷五·論古人立印食官財名義、論正官、論偏官、論雜氣；卷十·㸔命口訣、巫咸撮要；卷十一·喜忌篇） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

**应该触发**：
- 用户问「格局」在书里到底指什么，子平为什么把名目收在印食官財四样上。
- 用户问「六格」是哪六种、其余诸格跟六格是什么关系。
- 用户问「正官者乃甲見辛乙見庚之例」这句怎么读，正官格凭什么条件成立。
- 用户问「四柱純煞有制定居一品之尊，畧見一位正官官煞混雜反賤」为什么要把官与煞放在一起看。
- 用户问「雜氣者乃辰戌丑未」什么意思，杂气格与正官正财格有什么不同。
- 用户问「入格者非富即貴，不入格者非貧即夭」是不是在给具体的人下判决。
- 用户直接把卷五开篇「論古人立印食官財名義」里的句子拿来问出处。
- **用户给出四柱、问「我这盘算不算入格／取哪一格」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问官煞两停怎么去留、官化鬼还是鬼化官 → 转 bazi-sanming-guan-sha。
- 用户问正财偏财各主什么样的人、财多身弱怎么讲 → 转 bazi-sanming-cai。
- 用户问印綬喜什么忌什么、倒食是什么 → 转 bazi-sanming-yin-shou。
- 用户问食神伤官怎么用、伤官为什么要伤尽 → 转 bazi-sanming-shi-shang。
- 用户问喜忌篇列出的格名（壬騎龍背、六乙鼠貴、日祿歸時）怎么断 → 转 bazi-sanming-xi-ji-pian。
- 用户要按某人生日报流年大运、断终身、断寿夭 → 本族不接。
- 用户没提八字词，只说「我最近运气差」 → 泛化词，不激活。

## R：原文锚点

1. 徐子平論格局獨以印食官財四者為綱（《三命通會》卷五·論古人立印食官財名義）
2. 生我者有父母之義故立名印綬（《三命通會》卷五·論古人立印食官財名義）
3. 我尅者是人受制於我之義故立名妻財（《三命通會》卷五·論古人立印食官財名義）
4. 徐子平識破此理故只論財官印食分為六格而人命之富貴貧賤夀夭窮通舉不外是其餘格局不過自此而推之耳（《三命通會》卷五·論古人立印食官財名義）
5. 正官者乃甲見辛乙見庚之例隂陽配合相制有用成其道也故正官為六格之首止許一位多則不宜（《三命通會》卷五·論正官）
6. 四柱純煞有制定居一品之尊畧見一位正官官煞混雜反賤（《三命通會》卷五·論偏官）
7. 雜氣者乃辰戌丑未辰中有乙戊癸為水土庫（《三命通會》卷五·論雜氣）
8. 大凡㸔命先㸔月支有無財官方㸔其他月令為命也（《三命通會》卷十·㸔命口訣）
9. 入格者非富即貴不入格者非貧即夭一格二格非卿即相三格四格財官不純非刑卒多是九流（《三命通會》卷十·巫咸撮要）
10. 財官印綬全備藏蓄於四季之中（《三命通會》卷十一·喜忌篇）

## I：核心解释

《三命通會》卷五开篇先不算命，先交代「格局」这套名目是怎么来的。把它讲清，就是把「四纲—六格—诸格」这条链子讲清。

1. **先说四纲的立名**。篇首「徐子平論格局獨以印食官財四者為綱」（R1）。为什么是这四样？书里用一句话给每一样定性：生我者立名印綬（R2），我尅者立名妻財（R3）；我生者为食神、尅我者为官煞，同理类推。也就是说，四纲不是四组断语，而是把「五行生克与我」的四种关系各取一个名字。
2. **再说六格与诸格的关系**。「徐子平識破此理，故只論財官印食分為六格，而人命之富貴貧賤夀夭窮通舉不外是，其餘格局不過自此而推之耳」（R4）。书里的意思是：正官、偏官、正財、偏財、印綬、食伤（伤官附于食神一门）这一层是纲；其余格名都是从这六个里推衍出来的，不是另立一套。
3. **六格之首是正官**。「正官者乃甲見辛乙見庚之例，隂陽配合相制有用成其道也，故正官為六格之首，止許一位多則不宜」（R5）。一句里既有立格的条件（甲见辛、乙见庚这类阴阳配合），也有数量的分寸（一位为宜，多了不宜）。
4. **官与煞一起看**。论正官最后要与偏官对读：「四柱純煞有制定居一品之尊，畧見一位正官官煞混雜反賤」（R6）。纯煞有制是「以煞为用」一路，官煞混见则两神交战——这是书里把官煞并存当作一个专门题目来处理的原因。
5. **杂气另成一路**。「雜氣者乃辰戌丑未，辰中有乙戊癸為水土庫」（R7）。辰戌丑未四库各藏三件十神，所以「雜」；书里说财官印绶「藏蓄於四季之中」（R10），透干或逢冲刑才发，压伏则不发。
6. **入格与不入格是一句总断**。「入格者非富即貴，不入格者非貧即夭，一格二格非卿即相，三格四格財官不純非刑卒多是九流」（R9）。这是《三命通會》卷十《巫咸撮要》里的总纲语，语气很重，要当「书里的说法」看，不当对某一个人的判决。
7. **取格的次序**。卷十《㸔命口訣》给了入手处：「大凡㸔命先㸔月支有無財官，方㸔其他，月令為命也」（R8）——先看月支有没有财官可用，再论其他；月令无可取时才看他格。这一条与卷五「以月令为纲」的口径是一致的。
8. **一句话读法**：格局这套东西，是「把与日主发生关系的十神各立一名」（R2、R3），以六格为纲（R1、R4），正官居首（R5）、官煞对看（R6）、库气另论（R7、R10）；判成不成格，先问月支（R8），再问透藏与制化。

|---|---|---|
| 立名 | 生我者立名印綬、我尅者立名妻財（R2、R3） | 四纲各有其名 |

## A1：来源应用

书上给的做法，都落在「先定月令可取之财官，再逐格核条件」这一条线上：

- **先看月支**：㸔命先看月支有无财官，月令无可取才看他格（R8）。书里把「月令为命」当作取格的第一道门。
- **看透藏**：四库藏三件十神，透干者为显、藏支者为蓄；正官格「天干透出如甲見辛酉」才成支藏干透之局（见卷五·论正官，与 R5 同篇）。
- **看数量与纯度**：正官「止許一位，多則不宜」（R5）；官煞并见另按去留处理（R6 所论）。
- **看入格与否**：以「入格／不入格」分两路看，书里的总纲语见 R9；这句是书里的评价语，不是对某人的判词。
- **杂气格另核**：辰戌丑未藏气以「透干」「冲刑」「压伏」三项定发不发（R7、R10）。
- **不越篇**：卷五开篇诸条只讲立名与立格条件；某格的全身喜忌，落到本人族里对应的十神篇去讲。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月支（月令）所藏十神、各柱天干透出的印食官財、四库（辰戌丑未）与四生（寅申巳亥）落在哪几支。
2. **逐条核书里的条件**：先看月支有无财官（R8）→ 月令可取之神为何（R1、R4 的四纲六格）→ 正官是否一位、阴阳是否配合（R5）→ 官煞是否并见（R6）→ 是否杂气、透干或逢冲刑才发（R7、R10）。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「月支藏官而天干透出，按 R5 这一路读，偏正官格」，并给出处（如「《三命通會》卷五·論正官」）。
4. **收口**：这一句是**书里的读法**，不是对这个人贵贱的判定；**不应期、不断终身、不替人决定**。

**书里没有的、不要加**：本篇不讲具体排盘步骤，也没有「旺衰计分」「自动取喜用」「格局打分」这类后世做法；拿现代命理流派的评分法来解释「入格／不入格」是硬伤，一律不写。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–4 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 5–6 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **认句归篇（文本解读）**　输入：用户所引句子 → 输出：判定它出自卷五开篇立名、某格分论、还是卷十/卷十一的总纲，回对 R 节第几条。
   🔴 **CHECKPOINT**：若句子其实是喜忌篇格名（壬騎龍背、六乙鼠貴、日祿歸時之类），先说明要转 bazi-sanming-xi-ji-pian，不在这里讲断语。
3. **拆立名（文本解读）**　输入：涉及「印綬／妻財／官煞／食神」的句子 → 输出：用 R1–R3 把「生我、我生、尅我、我尅」四种关系与四个名字对上。
4. **摆六格与诸格（文本解读）**　输入：涉及格名数量的问法 → 输出：用 R4 说明六格为纲、其余自此而推；不另立格名表。
5. **取盘上的料（落盘）**　输入：用户四柱 → 输出：日主天干、月支所藏十神、各柱透出的印食官財、四库与四生落在哪几支。
6. **逐条核条件、给读法（落盘）**　输入：第 5 步的料 ＋ 本 skill 的条件 → 输出：先看月支有无财官（R8）→ 月令可取之神（R1、R4）→ 正官是否一位、阴阳配合（R5）→ 官煞是否并见（R6）→ 杂气是否透干或逢冲刑（R7、R10）；一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷五·論正官」）。
7. **收口**　输入：整段推演 → 输出：一句「月令取何神」＋一句「凭什么条件立这一格」；若用户在追问某个具体的人，照实说明本 skill 只讲立格读法，不替人断终身。
   🔴 **CHECKPOINT**：收口前确认——① 没把 R9、R6 里的评价语（非富即貴、非貧即夭、反賤）说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格局／用词带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把格局讲成格名清单 | 一口气列十几个格名，不建立名之纲 | 拉回 R1、R4：先四纲、再六格，其余自此推 |
| 用后世术语给立格背书 | 拿某某计分、自动取喜用解释「入格」 | 删掉后世名词，只按 R1–R7 的原句讲 |
| 把评价语落到人身上 | 见「不入格者非貧即夭」就说某人贫困短寿 | 标明这是书里的总纲语，不当对某人的判决 |
| 越篇去讲全身喜忌 | 在总论里把官煞去留、财印喜忌全展开 | 官煞转 guan-sha、财转 cai、印转 yin-shou、食伤转 shi-shang |
| 把总纲当断语套用 | 拿「一格二格非卿即相」替用户判官位 | 只讲书里怎么分入格不入格，不替人判贵贱 |
| 缺月支仍硬取格 | 没有出生月就替人定格 | 照实说要补生月；月令不明确就说不能取格 |

**边界规则**：
1. 只讲卷五开篇与诸格总论、卷十㸔命口诀与巫咸撮要、卷十一喜忌篇里的立格口径，不接具体人的终身、寿夭、婚姻、职业、医疗结论。
2. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 书里的断语（大貴、貧夭、反賤、非卿即相）引用时标明是书里的说法。
4. 缺出生年月日时任一柱或缺出生地，照实说要补什么，不用占位信息硬排。
5. 三命通會源文里卷九～卷十二有两份，引哪一份都照抄原样，不在两份之间改字。

6. 把书里的总纲语（R9）当成对用户的事实判词。

## 灰色地带

- **「其余格局自此而推」推到哪里为止**：R4 只说其余格由六格推衍，没给完整格名表。用户若问某一具体格名算不算「推出来的」，照原书说它属推衍一层，能对回本族哪一篇就对哪一篇，不硬造格名谱系。
- **正官与官煞并存两条看似打架**：R5 说正官止许一位，R6 说官煞混见反賤。按原句，一位是立格的纯度要求，并存是另立去留题——遇到冲突就说这是原书按「单见／并存」分两路，不替用户拍板归哪一路。
- **「辰戌丑未」是否一律算杂气**：R7、R10 说四库藏气故杂。用户若问丑月明明当令算不算杂，就照原句讲库气透冲才发的口径，不给「一定」。
- **用户拿总纲问「准不准」**：不写自我否定腔，也不写兜售腔；只讲这句在原书里怎么用（分入格不入格），判断留给用户。
- **杂气与月令并用**：书里杂气格与月令正官正财可以两层并存。遇到同一柱既能取月令又带库气的，先讲两层各看什么，不替用户择一。
