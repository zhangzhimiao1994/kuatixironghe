# 窮通寶鑑·論金：庚金辛金的逐月取用

**来源**：sources/qiongtongbaojian.txt（《窮通寶鑑》論庚金、論辛金） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户拿一个庚金日主的盘，问某月该取丁、甲、丙、壬里的哪几个字。
- 用户拿一个辛金日主的盘，问同一类逐月取用。
- 用户读到「非丁莫造，非丙不暖」不懂，问庚金冬天为什么先要丙、丁。
- 用户问「先丙后癸」「先甲后丁」「先壬后甲」这些次序差在哪。
- 用户问「秋金锐锐最为奇，壬癸相逢总不宜」这句口诀怎么读。
- 用户问辛金为什么「先己后壬」「先壬后甲」。

**不应触发**：
- 用户问的是木／火／土／水日主的逐月取用 → 各转 bazi-qiongtong-mu／bazi-qiongtong-huo／bazi-qiongtong-tu／bazi-qiongtong-shui。
- 用户问的是五行总纲 → 转 bazi-qiongtong-wu-xing。
- 用户手上没有四柱、只凭一句生日问运 → 先按 bazi-hub 的硬闸门走，缺柱不排。
- 用户要批流年大运、断终身、判寿夭疾病、替人做婚姻或职业决定 → 本 skill 不接。

## R：原文锚点

1. 正月庚金，木旺之际，有土皆死，不能生金，且金之寒气未除，先用丙暖庚性，又虑土厚埋金，须甲疏洩。（《窮通寶鑑》論庚金·正月庚金）
2. 总之，正月庚金，丙甲为上，丁火次之。（《窮通寶鑑》論庚金·正月庚金）
3. 二月庚金，柱中自然有乙，当令之乙，见庚必输情于乙，此金有暗强之势，如秋金一理，故二月庚金，专用丁火，借甲引丁，借庚噼甲。（《窮通寶鑑》論庚金·二月庚金）
4. 三月庚金，戊土司令，无生金之理，有埋金之忧，故先甲后丁，不用庚噼甲。（《窮通寶鑑》論庚金·三月庚金）
5. 四月庚金，长生于巳，巳内有戊。丙不镕金，故不畏火炎，丙亦可作用，但先壬水，方得中和（《窮通寶鑑》論庚金·四月庚金）
6. 五月庚金，丁火旺烈，庚金败地，专用壬水，癸又次之。（《窮通寶鑑》論庚金·五月庚金）
7. 六月庚金，三伏生寒，顽钝极矣，先用丁火，次取甲木。（《窮通寶鑑》論庚金·六月庚金）
8. 七月庚金，刚锐极矣。专用丁火煅炼，次取甲木引丁（《窮通寶鑑》論庚金·七月庚金）
9. 故曰：秋金锐锐最为奇，壬癸相逢总不宜，如逢木火来成局，试看福寿与天齐。（《窮通寶鑑》論庚金·七月庚金）
10. 八月庚金，刚锐未退，用丁用甲，丙不可少。（《窮通寶鑑》論庚金·八月庚金）
11. 九月庚金，戊土司令，最怕土厚埋金，宜先用甲疏，后用壬洗，则金自出矣。忌见己土浊壬。（《窮通寶鑑》論庚金·九月庚金）
12. 十月庚金，水冷性寒，非丁莫造，非丙不暖。（《窮通寶鑑》論庚金·十月庚金）
13. 十二月庚金，寒气太重，且多湿泥，愈寒愈冻，先取丙火解冻，次取丁火炼金，甲亦不可少。（《窮通寶鑑》論庚金·十二月庚金）
14. 故正月辛金，先己后壬。己为君，庚为佐。（《窮通寶鑑》論辛金·正月辛金）
15. 辛金珠玉，最怕红炉，辛逢卯日子时，名曰朝阳。（《窮通寶鑑》論辛金·正月辛金）
16. 二月辛金，阳和之际，壬水为尊，见戊己为病。（《窮通寶鑑》論辛金·二月辛金）
17. 三月辛金，戊土司令，辛承正气，母旺子相，先壬后甲。（《窮通寶鑑》論辛金·三月辛金）
18. 四月辛金，时逢首夏，忌丙火之燥烈，喜壬水之洗淘。（《窮通寶鑑》論辛金·四月辛金）
19. 五月辛金，丁火司权，辛金失令，阴柔之极，不宜煅炼，须己壬兼用（《窮通寶鑑》論辛金·五月辛金）
20. 六月辛金，己土当权，辅助太多，恐掩金光，先用壬水，取庚佐之。（《窮通寶鑑》論辛金·六月辛金）
21. 七月辛金，壬不在多，故书云：水浅金多，号曰体全之象，壬水为尊，甲戊酌用可也，癸水不可为用。（《窮通寶鑑》論辛金·七月辛金）
22. 八月辛金，当权得令，旺之极矣，专用壬水淘洗火，故云：金见水以流通。（《窮通寶鑑》論辛金·八月辛金）
23. 九月辛金，火土为病，水木为药。（《窮通寶鑑》論辛金·九月辛金）
24. 十月辛金，时值小阳，阳气渐升，寒气将降，先用壬水，次取丙火（《窮通寶鑑》論辛金·十月辛金）
25. 十一月辛金，癸水司令，为寒冬雨露，切忌癸出冻金（《窮通寶鑑》論辛金·十一月辛金）
26. 十二月辛金，丙先壬后，戊己次之。（《窮通寶鑑》論辛金·十二月辛金）

## I：核心解释

《窮通寶鑑》论金这一块，把庚金与辛金分成两条完全不同的路子：庚是刚金、喜火炼；辛是柔金（珠玉）、喜水淘。逐月次序就围绕这两条。

1. **庚金的底色是「火炼」与「土埋」的对治**：正月庚金「先用丙暖庚性，又虑土厚埋金，须甲疏洩」（R1）；总结一句「丙甲为上，丁火次之」（R2）。三月「戊土司令…有埋金之忧，故先甲后丁」（R4）；九月「最怕土厚埋金，宜先用甲疏，后用壬洗」（R11）。凡是土重之月，第一件事就是甲木疏土。
2. **庚金的夏月求水**：四月「先壬水，方得中和」（R5）、五月「专用壬水，癸又次之」（R6）。夏天火炎，庚金要靠壬癸解炎。
3. **庚金的秋月求丁**：六月「先用丁火，次取甲木」（R7）、七月「专用丁火煅炼，次取甲木引丁」（R8）、八月「用丁用甲，丙不可少」（R10）。秋金锐锐，书给了口诀「秋金锐锐最为奇，壬癸相逢总不宜」（R9）。
4. **庚金的冬月求丙丁**：十月「非丁莫造，非丙不暖」（R12）、十二月「先取丙火解冻，次取丁火炼金」（R13）。冬金寒冻，丙丁是解冻与成器两件事。
5. **辛金的底色是「水淘」与「土埋」的对治**：正月「先己后壬」（R14），己为君、庚为佐；三月「先壬后甲」（R17）、六月「先用壬水，取庚佐之」（R20）、八月「专用壬水淘洗火」（R22）。辛金靠壬水洗出自家的光，土多则「恐掩金光」（R20）。
6. **辛金的水不是越多越好**：七月「壬不在多…壬水为尊，甲戊酌用可也，癸水不可为用」（R21）；辛金喜壬而忌癸，书里讲得很直。
7. **偏燥与偏寒各有对策**：旺月焦燥则用甲疏土（R23「火土为病，水木为药」）；冬月寒冻则先丙（R24、R25、R26）。同是辛金，七月重「泄」、十二月重「暖」，次序就不同。
8. **书里的口诀与评价语**：像「秋金锐锐最为奇」「辛金珠玉，最怕红炉」（R9、R15），是原书的口诀与断语，引用时标明是书里的说法，不当作对某人的判决。

## A1：来源应用

书上给的做法，是「先定月令寒暖 → 再排用神次序 → 最后看需要的字透干、藏支」。

- **先分刚柔**：日主是庚还是辛。庚金体刚，重火炼与疏土；辛金体柔，重水淘与去土。同一月两条路子不一样。
- **按令排次序**：
  - 庚金——正月丙甲为上、丁次（R2）；二月专用丁火、借甲引丁（R3）；三月先甲后丁（R4）；四月先壬（R5）；五月专用壬水（R6）；六月先用丁火、次甲（R7）；七月专用丁火、次甲（R8）；八月用丁甲、丙不可少（R10）；九月先甲疏、后壬洗（R11）；十月非丁莫造、非丙不暖（R12）；十二月先丙解冻、次丁炼金（R13）。
  - 辛金——正月先己后壬（R14）；二月壬水为尊（R16）；三月先壬后甲（R17）；四月喜壬（R18）；五月须己壬兼用（R19）；六月先用壬水、取庚佐之（R20）；七月壬水为尊（R21）；八月专用壬水（R22）；九月水木为药（R23）；十月先用壬水、次丙（R24）；十一月忌癸冻金（R25）；十二月先丙后壬（R26）。
- **看透藏定轻重**：原书对同一序里的字分「两透／一透一藏／俱藏」。如庚金正月「丙甲两透，科甲显荣。二者透一，亦有生监。丙藏甲透，异路功名」（R2 下文）。透干的字比藏支的得力。
- **土多先疏**：凡戊己当令或土重之月（三月、六月、九月），庚辛都先看甲木有没有出来疏土（R4、R11、R23）。
- **一句话口径**：庚看「炼不炼、埋不埋」，辛看「淘不淘、掩不掩」。

**书里没有的、不要加**：原书论金只讲逐月取用与透藏轻重，不讲后世流派的「旺衰计分」「自动取用程序」。本 skill 沿用书上「用神」的叫法（如「妻子用神仝前」之类），不加自造的判定步骤。

## A2：典型触发场景

1. 用户排出庚金日主、生在午月，问「书上说专用壬水、癸又次之，我壬藏支算不算」。
2. 用户拿辛金日主、生在寅月，问「先己后壬，己为君、庚为佐」是什么意思。
3. 用户读到「秋金锐锐最为奇，壬癸相逢总不宜」，问这句口诀讲什么。
4. 用户同一张盘问「庚金和辛金论法一样吗」，想对照两条。
5. 用户拿生在戌月的辛金，问「火土为病，水木为药」怎么落到字上。
6. 用户问「冬天庚金为什么非丁莫造、非丙不暖」。

## E：执行步骤

1. **确认日主与月令**　输入：用户的话、四柱 → 输出：日主是庚还是辛、生月（或季）。只有季段没月份时标「时段内不唯一」。
   🔴 **CHECKPOINT**：缺年月日时任一柱就停下，缺什么说什么，不占位硬排；缺柱时把用户引到 bazi-hub 补盘。
2. **对号取次序**　输入：日主＋月令 → 输出：从 R 节抄出当月那条次序（如庚金五月「专用壬水，癸又次之」）。
   🔴 **CHECKPOINT**：抄的是原书次序，不是自己按五行生剋另推的。
3. **看透藏排轻重**　输入：四柱干支 → 输出：序里的字哪些透干、哪些藏支，按书里「两透／一透一藏／俱藏」的说法排轻重。
4. **给依据与取用条件**　输入：第 2、3 步结果 → 输出：两句必备——原书出处（《窮通寶鑑》論庚金·某月／論辛金·某月）＋ 凭什么这么取（月令寒暖、透藏）。
   🔴 **CHECKPOINT**：只报次序不出处，或只出处不讲取用条件，都退回补齐。
5. **收口**　输入：整段推演 → 输出：一段月令读法 + 一条取用次序 + 一句出处；结尾说明本 skill 到此为止，不接流年大运与终身断。
   🔴 **CHECKPOINT**：确认没有把书里的口诀与评价语（「非夭则贫」这类）当成对用户的判决。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿别的日主套金的次序 | 用户是戊土日主也答「先壬后甲」 | 先确认日主；不是庚辛就转对应各篇 |
| 庚辛混为一谈 | 把辛金也按「丙甲为上」取 | 拉回 I 节：庚重火炼、辛重水淘，两条路子分开 |
| 只报次序不出处 | 答「辛金八月专用壬水」却不指出根据 | 补《窮通寶鑑》論辛金·八月辛金的出处与取用条件 |
| 把口诀当定论 | 说「壬癸相逢总不宜，所以你留不住财」 | 标明那是书里的口诀（R9），只讲读法不下判决 |
| 缺柱硬排 | 只有生日就排出四柱下断 | 停下，说缺哪柱、要到什么程度才能排 |
| 越过范围批流年大运 | 顺势断某年会怎样 | 收口在月令取用，不接流年大运与终身 |

**边界规则**：
1. 只做庚金、辛金的逐月取用，不替别的日主取用。
2. 只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 报用神必须同时给原书依据与取用条件。

**自查清单**：
- [ ] 每条 R 都是原书原话，且给出了「篇名＋月」的出处吗？
- [ ] 报次序时同时给了出处和取用条件吗？
- [ ] 有没有把书里的口诀、评价语说成对用户的判决？
- [ ] 缺柱时是照实说，还是硬排了？

**安全兜底**：涉及就医、用药、危机时，只做提醒与陪伴，不做诊断。

## 灰色地带

- **用户只给季段没给月份**：先按季段给整段次序，并标明「段内不唯一」，同时说要到具体哪个月才能收窄。
- **用户问的是庚辛之前那段金性总说**（如「金无火炼，不能成器」这类金性寒暖的话）：那段在原书里是庚辛逐月条之前的通说，本 skill 的取用只据庚辛逐月各条；用户若只想直读那段原文，可照原文直讲，但不据此替人取用。
- **同一月庚辛两条似乎冲突**：先分清问的是刚金还是柔金，分别按两条答，不在一条上硬下结论。
- **用户引的是转述而非原书**：只按 sources/qiongtongbaojian.txt 的原话答；转述里的字句与原书不合时，以原书为准并指出差异。
- **用户要「取用」还要「断吉凶」**：取用照讲，断吉凶的部分说明本 skill 只到月令取用，不接流年大运与终身。
