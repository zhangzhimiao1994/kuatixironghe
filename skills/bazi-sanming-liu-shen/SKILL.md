# 六神篇：十神之间的牵制与翻覆

**来源**：sources/sanmingtonghui.txt（《三命通會》卷十一·六神篇） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

**应该触发**：
- 用户问「正官佩印不如乘馬」到底在说用印还是用财。
- 用户问「七煞用財豈宜得祿」为什么用财反怕得禄。
- 用户读到「印逢財而罷職財逢印以遷官」，觉得同一组财印说法相反，想弄清分别的条件。
- 用户问「食神孑立逢梟」是什么意思、为什么说无救。
- 用户问「羊刃重逢破局」与「羊刃喜合嫌衝」各有何指。
- 用户读到「衆煞混行一仁可化」，问这里的「仁」指什么。
- 用户问六神篇里怎么论父母、夫妻、子息（印綬臨財、比肩伏馬、子位妻宫）。
- 用户直接引用六神篇中某一句，要求回到原书讲清。
- **用户给出四柱、问「我这盘财印／官煞怎么用」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问某个八字是成格还是破格、该归哪一格 → 转 bazi-sanming-ge-ju。
- 用户问「壬騎龍背」「六乙鼠貴」「日祿歸時」这些格名怎么断 → 转 bazi-sanming-xi-ji-pian（喜忌篇）。
- 用户问看命为什么先看月令、为什么以日干为主 → 转 bazi-sanming-ji-shan-pian（繼善篇）。
- 用户问一组四柱整体清浊、刚柔、寒暖的规模 → 转 bazi-sanming-qi-xiang-pian（氣象篇）。
- 用户要按某人的生日报流年大运、断终身、断寿夭 → 本族不接。
- 用户没提八字词，只是说「我最近运气差」 → 泛化词，不激活。

## I：核心解释

六神篇讲的不是六种固定的吉凶，而是一张「谁在用谁、谁在克谁」的关系网。要读它，先把开头两句当总纲。

1. **总纲：六神可变通**。篇首两句是 R1：「五行妙用難逃一理之中，進退存亡要識變通之道，正官佩印不如乘馬」。书里先把「一理」立住，再说明官、煞、印、財、食、傷的吉凶会因主客不同而翻覆——所以下面每一条几乎都是「在什么条件下这一神由吉转凶、由凶转吉」。
2. **用官的两条口径**。「正官佩印不如乘馬」（R1）不是说印一律不如财；书里注（R20）说明：用官之法大要健旺清高，官旺宜印、官弱宜財，此不易之理；又说身旺官轻而多见印綬，则日主愈强而官愈弱，所以才喜财旺之地生官。注里还引壺中子「官輕不若煞輕」（R21）作旁证。
3. **用煞用财与归禄之忌**。「七煞用財豈宜得祿」（R2）：煞旺太过、日主无依，又用财生煞，是「棄命相從」之势；一旦岁运归禄，日主恃强与煞相战，书里说凶可知。这里说的是去留趋势，不是给某个人下判决。
4. **财印的两用与两害**。「印逢財而罷職財逢印以遷官」（R3）：原局靠印绶的，行财乡克了印，拄中无比肩为救，书里说罢职投闲；原局靠财的，再行财旺之地主不能胜，反要印旺流年助根本，书里说进爵迁官。同一组财印，坏在印、成在财，只看原局用的是哪一头。
5. **食神制煞与梟神夺食**。「命當夭折食神孑立逢梟」（R4）：七煞伤身原无正印为解，独靠一位食神制煞；若梟神有力克我食神，而柱中又无偏财遇敌，书里说纵煞伤身。这里的「夭折」是书里的评价语，不是对某人的寿命判断。
6. **羊刃的破局与喜忌**。「運至凶危羊刃重逢破局」（R5）：专言用财无煞者大忌羊刃，岁运重逢羊刃、劫财破局，书里列出丧家、囚狱、伤妻克子这类说法。另一句「幇身羊刃喜合嫌衝」（R18）说羊刃本是帮身之物，大怕身旺逢之，得一重煞与刃作合可化为权星，官与刃相冲战则成恶煞——同是羊刃，合与冲两路。
7. **官与比劫的争**。「争正官不可無傷」（R6）：柱中比刃多而只有一位官星，必然争夺，一见有祸，不如运至伤官伤尽官星，比肩无争才安。「歸七煞最嫌有制」（R7）：年月透出一位七煞，比肩知畏而归之；岁运一遇食神制煞，反使比肩复乱，书里说散财破业。
8. **官煞互变**。「官居煞地難守其官，煞在官鄉豈能變煞」（R8）：注里说得直白——官为纯雅之贵，煞乃奸邪之暴客；官居煞党其势不能独立，必混化而为煞；煞虽在官星礼义之乡，终不由礼义而变煞为官。
9. **印对煞的两条路**。「印解兩賢之厄財勾六國之争」（R11）、「衆煞混行一仁可化一煞倡亂獨力可擒」（R12）、「印居煞地化之以德煞居印地齊之以刑」（R13）：三句合起来是一层意思——煞多用印制、以仁化之，煞少用食制、以力擒之；印在煞地则以德化，煞在印地则以刑齐。哪条路，看煞势众寡。
10. **煞暗无明制也要寻**。「煞無明制當尋伏敵之兵」（R10）：明无制伏之人不可便以凶断，要在四柱支神中深求食神暗伏，或遇刑冲、或就三合，也算伏敌之兵。
11. **财与比劫**。「一馬在廐人不敢逐一馬在野人共逐之」（R14）：马即财，是比肩必争之物；财明透而四柱特立无遮拦，好比马在廐，比肩不敢争逐；财隐于支库，则比肩竞图窃取。
12. **六亲的落点**。父母看印与财（R15），夫妻看财与比肩伏马（R16），子息看官煞落于时位（R17）。这些是书里以十神位置系属六亲的读法，不是替某人断家庭结果。
13. **一句话读法**：先看「谁在用谁」（官用印还是用财、煞用财还是用印、印护身还是煞化印），再看「岁运把哪一边助起」——同一组十神，因主客与岁运不同而翻覆，这就是 R1 说的「進退存亡要識變通」。

## A1：来源应用

书上给的做法，都落在「先定原局重用哪一神，再看岁运把它助起还是削去」：

- **用官**：官旺宜印、官弱宜财；身旺官轻而印多者，喜财旺之地生官克印（R20）。注引壺中子「官輕不若煞輕」（R21）作旁证。
- **用煞**：煞旺用财是弃命相从之势，最怕岁运归禄与煞相战（R2）。
- **用印**：印重煞轻终不为贵，要行财旺之运克太过之印、生不及之煞，煞印相停才能超越；若印轻逢财反为大害（R9）。
- **制煞**：煞无明制就在支神里寻食神暗伏、刑冲、三合，作伏敌之兵（R10）；煞势众则用印制、以仁化之，煞势孤则用食制、以力擒之（R12）。
- **用刃**：刃是帮身之物，喜与煞作合化权，嫌与官冲战（R18）；权刃再行权刃之乡、财官再遇财官之地，书里各列其说（R19）。
- **用财**：财明透特立则比肩不敢争；财隐支库反招窃取（R14）。
- **六亲**：父母看印綬与财是否临于一处（R15），夫妻看财下是否原伏比肩（R16），子息看时位的官煞财气是否得用、逢不逢刑害孤虚（R17）。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：原局以哪一神为用（官、煞、印、财、食、刃）、该神在哪一柱、透干还是藏支、与之相制相化的那一神（比劫、食伤、枭、羊刃）在不在。
2. **逐条核书里的条件**：认「谁在用谁」（R1、R2、R3、R9）→ 看制化路径（煞多用印制、煞少用食制 R12；无明制则寻暗伏 R10）→ 羊刃看合冲（R18、R5）→ 财看明透与支库（R14）→ 六亲落点（R15–R17）。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「用印而财透无救，按 R3 这一路读，偏『印逢財而罷職』」，并给出处（如「《三命通會》卷十一·六神篇」）。
4. **收口**：这一句是**书里的读法**，不是对这个人的判决；**不应期、不断终身、不替人决定六亲**。

**书里没有的、不要加**：本篇是十神关系的断语集，不讲具体排盘步骤，也没有「旺衰计分」「自动取喜用」这类后世做法；需要断某一个人的终身、寿夭、婚姻，都不在本 skill 范围内，也不在本族范围内。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–5 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 6–7 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **认句（文本解读）**　输入：用户所引的六神篇句子 → 输出：把它对回 R 节第几条，读出这句用的是哪两神（如官与印、煞与财、印与煞）。
   🔴 **CHECKPOINT**：分不清是「用神」还是「被用之忌神」时，先按原句的动词（用、佩、罢、迁、制）定主客，不猜。
3. **定原局靠哪一头（文本解读）**　输入：这句话 → 输出：说清在什么原局条件下这句成立（如「原用印綬不以官煞為倚者」）。
4. **配注文（文本解读）**　输入：经文一句 → 输出：能配到注就给注（R20、R21 已列），注里的话标明是注、不是经文。
5. **讲翻覆点（文本解读）**　输入：经文 + 注 → 输出：指出由吉转凶或由凶转吉的那个条件（归禄、行财乡、逢梟、重逢羊刃、填实等）。
6. **取盘上的料（落盘）**　输入：用户四柱 → 输出：原局以哪一神为用（官、煞、印、财、食、刃）、该神在哪一柱、透干还是藏支、与之相制相化的那一神（比劫、食伤、枭、羊刃）在不在。
7. **逐条核条件、给读法（落盘）**　输入：第 6 步的料 ＋ 本 skill 的条件 → 输出：认「谁在用谁」（R1、R2、R3、R9）→ 看制化路径（煞多用印制、煞少用食制 R12；无明制则寻暗伏 R10）→ 羊刃看合冲（R18、R5）→ 财看明透与支库（R14）→ 六亲落点（R15–R17）；一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷十一·六神篇」）。
8. **收口**　输入：整段推演 → 输出：一句「谁在用谁」＋一句「岁运帮哪边」；若用户在追问某个具体人，照实说明本 skill 只讲十神关系读法，不替人断终身。
   🔴 **CHECKPOINT**：收口前确认——① 没把书里的评价语（夭折、罢职、伤妻克子）说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不替人决定六亲**；③ 报的十神关系／用词带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|

## 灰色地带

- **同一组财印两说**：R3 一处说「罢职」一处说「迁官」，看似矛盾。按原句，坏印还是迁官取决于原局靠的是印还是财——遇到冲突就说这是原书按主客分两路，不替用户拍板归哪一路。
