# 天干·地支·干支總論

**来源**：sources/ditianxu.txt（《滴天髓闡微》通神論，清任鐵樵注） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**不应触发**（看起来像但其实不是）：

- 用户要排盘、给一组四柱算流年大运吉凶 → 本维度不接流年大运、不断终身。
- 用户只说「我属什么的」「我生日那天」这类泛化的话，没有点出八字/四柱/干支/日主等显式请求 → 不激活。

## I：核心解释

这三段从「一个干支本身是什么」讲到「干支之间怎么相互补」。

1. **天干分阳刚阴柔**。经文先立两极：「五阳皆阳丙为最，五阴皆阴癸为至」（R1）——丙是阳中之阳，癸是阴中之阴。接着立性格：「五阳从气不从势，五阴从势无情义」（R2）。原注说五阳得阳气即能成阳刚之势、不畏财杀，五阴得阴气即从势（木盛从木、火盛从火……）。
2. **十干的体象各一段**。甲乙丙丁戊己庚辛壬癸各有一句经文，讲的是该干在不同处境里的倾向：甲木「脱胎要火」「春不容金，秋不容土」「火炽乘龙，水宕骑虎」（R3）；乙木「怀丁抱丙，跨凤乘猴」「藤萝系甲」（R4）；丙火「能煅庚金，逢辛反怯」（R5）；丁火「抱乙而孝，合壬而忠」（R6）；戊土「怕冲宜静」（R7）；己土「宜助宜帮」（R8）；庚金「得水而清，得火而锐」（R9）；辛金「热则喜母，寒则喜丁」（R10）；壬水「通根透癸，冲天奔地」（R11）；癸水「合戊见火，化象斯真」（R12）。原注与任注逐句给出理由（如甲「生于春初，木嫩气寒，得火而发荣」、丙「合柔顺而寓和平」）。
3. **任注不认歌赋式比拟**。任注点出一路流传的比拟——甲作梁栋、乙作花果、丙作太阳、丁作灯烛、戊作城墙、己作田园、庚作顽铁、辛作珠玉、壬作江河、癸作雨露——并说这些「比拟失伦」「相沿已久，牢不可破，用之论命，诚大谬也」（R13）。他要求的是从体象的性情取用，不是拿物象套。
4. **地支分动静强弱**。经文：「阳支动且强，速达显灾祥；阴支静且专，否泰每经年」（R14）。任注把子寅辰午申戌划为阳、丑卯巳未酉亥划为阴，并说阳支性动而强、吉凶之验恒速；阴支性静而弱、祸福之应较迟——在局在运都按这个意思消息。他另说「以本气为主，寅必先甲而后及丙，申必先庚而后及壬」。
5. **地支的冲、刑、穿**。「生方怕动库宜开，败地逢冲仔细推」（R15）给三类的处置：寅申巳亥生方忌冲动；辰戌丑未四库宜冲开（但有不尽宜）；子午卯酉四败逢冲要仔细——用金水则可冲、用木火则不可冲。「支神只以冲为重，刑与穿兮动不动」（R16）把重心压在冲上，刑与穿则「有动不动之异」。原注说冲必是相克（及四库兄弟之冲）所以必动；刑穿之间有相生相合者存，故有动不动（R19）。任注更直说「所谓暮库逢冲则发者，后人之谬也」（R20），并认为刑与害「不足为凭」。冲还有明暗：「暗冲暗会尤为喜，彼冲我兮皆冲起」（R17），以喜神为我、忌神为彼，宁可我去冲彼，不可彼来冲我。轻重上，「旺者冲衰衰者拔，衰神冲旺旺神发」（R18）。
6. **干支總論讲覆载**。「阴阳顺逆之说，《洛书》流行之用，其理信有之也，其法不可执一」（R21）。任注借这一章否定把阳生阴死、阴生阳死拿来死断——「阴阳同生同死可知也」。判一柱的干支关系，落在两点：干以载之支为切、支以覆之干为切（R26）；要「天地顺遂」，不要「阴阳乖悖」（R22）。天干一气要地支能载（R23），地支三物（寅卯辰、巳午未、申酉戌、亥子丑之方）要天干能容（R24）。往上还有一层：上下要情协，左右要同志；能「始其所始，终其所终」（R25）的则是书里说的富贵福寿一路。

## A1：来源应用

书上给的读法，分三段落地：

- **读单干**：先看该干是哪一极（丙为阳之至、癸为阴之至，R1）、从气还是从势（R2），再按该干那一段经文取性情（R3–R12），逐句配原注的理由。
- **读单支**：按阳支／阴支定动静强弱（R14）；地支本身以本气为主（任注：寅先甲、申先庚）。
- **读冲刑穿**：冲为核心——生方、库地、败地三类处置不同（R15）；刑穿有动不动之异（R16、R19）；明冲之外还有暗冲暗会（R17）；冲的轻重按旺衰分「拔」与「发」（R18）。任注另提醒：暮库逢冲则发的说法是后人之谬（R20），刑害不足为凭。
- **读干支之间**：干以支为载、支以干为覆（R26），求天地顺遂（R22）；天干一气要地载（R23）、地支三物要天容（R24）。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干是十干哪一干、四柱地支各是阳支还是阴支、各柱干支的载覆（哪一干覆在哪一支上）、有无冲刑穿与会合、天干是否一气／地支是否成方。
2. **逐条核书里的条件**：该干从气还是从势 → R1、R2；地支动静强弱 → R14；冲刑穿属生方／库地／败地哪一类、刑穿动不动 → R15、R16、R19，旺衰定「拔」与「发」→ R18；干支载覆 → R26；天地是否顺遂、天干一气能否地载、地支三物能否天容 → R22、R23、R24。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「日主庚金坐寅，按 R14、R26 这一路读，偏『干以载之支为切』的取象」，并给出处（如「《滴天髓闡微》通神論·干支總論」）。
4. **收口**：这一句是**书里的读法**，不是对这个人吉凶寿夭的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：原书不给「十干两两组合打几分」这类算法，也不把刑穿列成吉凶表；拿现代名词把天干体象折成强弱指数，是书里没有的做法，要加只能标「（补充）」并说明依据。

## A2：典型触发场景

1. 用户第一次读十干体象那十段韵文，想逐句弄懂。
2. 用户问「甲木参天，脱胎要火」为什么甲木要见火。
3. 用户问乙木为什么说「藤萝系甲，可春可秋」、「虚湿之地，骑马亦忧」又是什么意思。
4. 用户读到「五阳从气不从势，五阴从势无情义」，想知道书里怎么解释。
5. 用户问地支为什么分阳支阴支、动静快慢是不是真不一样。
6. 用户读到「旺者冲衰衰者拔，衰神冲旺旺神发」，想弄清冲到底谁拔谁发。
7. 用户问刑、穿是不是也算一种「冲」，原书认不认。
8. 用户问「天全一气，不可使地德莫之载」是不是说全阳干就不好。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–5 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 6–7 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **确认问的是天干、地支还是干支之间**（文本解读）　输入：用户的话与所引句子 → 输出：判定落在十干体象／地支冲刑穿／干支覆载哪一段。
   🔴 **CHECKPOINT**：若用户其实在问天道地道等六章纲，或形象方局八格体用，先说明本 skill 只管天干、地支、干支总论，转对应 skill，问用户要哪个。
3. **出经文与注**（文本解读）　输入：定下的段 → 输出：先摆经文原句，再摆原注或任注，标明哪句是經文、哪句是注。
4. **讲机制**（文本解读）　输入：经文与注 → 输出：白话讲清该干／该支／该组干支的性情与相互补，每一步挂回原句。
5. **给判读口径**（文本解读）　输入：机制 → 输出：按 R 节说清「凭什么这么取」——单干看阴阳从气从势，单支看动静本气，冲看旺衰与明暗。
6. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干是十干哪一干、四柱地支各是阳支还是阴支、各柱干支的载覆、有无冲刑穿与会合、天干是否一气／地支是否成方。
7. **逐条核条件、给读法**（落盘）　输入：第 6 步的料 ＋ 本 skill 的条件 → 输出：
   - 该干从气还是从势（R1、R2）→ 地支动静强弱（R14）→ 冲刑穿属生方／库地／败地哪类、刑穿动不动（R15、R16、R19）、旺衰定「拔」与「发」（R18）→ 干以载之支为切、支以覆之干为切（R26）→ 天地是否顺遂、天干一气能否地载、地支三物能否天容（R22、R23、R24）；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《滴天髓闡微》通神論·干支總論」）。
8. **收口**　输入：整段推演 → 输出：一句可带走的话（干看性情、支看冲，干支之间看覆载与顺遂）。
   🔴 **CHECKPOINT**：收口前确认——① 没把「旺者冲衰衰者拔」（R18）当成本 skill 对人下的结论，也没把刑穿编成吉凶表；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格局或术语带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把十干体象当成物象比拟 | 说甲木就是栋梁、丙火就是太阳 | 拉回 R13：任注明说这类比拟「比拟失伦」「诚大谬也」 |
| 把冲刑穿编成吉凶对照表 | 列出刑=凶、穿=害、库冲=发 | 拉回 R16、R19、R20：冲必动，刑穿有动不动，暮库必冲是后人之谬 |

**边界规则**：
1. 只讲天干、地支、干支总论三段的经文与注，不接流年大运批断、不断终身、不判寿夭。
2. 不依据一组四柱给人做婚姻、职业、医疗决定；书里若有疾病、寿夭一类的条文，引用时标为「书里的说法」，不落到具体的人身上。
3. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
4. 经文与注必须分栏标注，原注与任注不混。
5. 缺出生年／月／日／时任一柱就说缺什么，不拿占位信息硬排。

## 练习手册

- **十干一句记**：合上 R 节，给十个天干各写一句「它要什么、怕什么」，各挂回原句。
- **阳阴对照**：把「五阳从气不从势，五阴从势无情义」用自己的话讲一遍，再各举一个干为例。
- **冲的三种地**：把生方、库地、败地三类的处置各写一句，说明哪类要冲、哪类要慎冲。
- **旺衰判冲**：给一组干支（一旺一衰相冲），按 R18 写出「谁拔谁发」，只写方向不下吉凶。

## 反例黑名单

1. 把甲木丙火答成栋梁、太阳、城墙、珠玉这类物象——R13 的任注明着否定。
2. 把刑、穿、库冲列成吉凶对照表——R16、R19、R20 讲的是动不动、可不可凭。
3. 把「旺者冲衰衰者拔」直接读成对某人的断语。
4. 用「能量」「指数」一类现代名词替干支体象背书。
5. 把「干为天元」那段或「取用干支之法」当经文。
6. 用户只说「我属什么」「我生日那天」就激活并论干支。

## 灰色地带

- **用户问「十干体象能不能拿来论命」**：不写自我否定腔，也不写兜售腔；只把书里给的性情与判读口径讲清，是否据此判断留给用户。
- **「从势」与「从气」遇同一柱该怎么办**：书里五阳从气、五阴从势是就本性而言；遇具体一柱，任注反复说「须观日主之衰旺」，遇说不清时就说这是书里就本性给的倾向、具体仍要合全柱看，不替用户拍板。
- **刑穿既有「动不动」又「不足为凭」**：两者并存——原注给动不动之分（R19），任注更重冲而轻刑害（R16、R20）；用户若追问，两说都摆，说清是经文与注的侧重不同。
- **库地既「宜开」又有「不宜」**：经文说库宜开（R15），任注说暮库逢冲则发是后人之谬（R20）；照实说这是书里并存的口径，具体要看四柱干支有无引出。
- **用户把「天全一气」理解成全阳干一定好**：按 R23 回到原意——天干一气要地支能载，不能载就是偏枯，不是「全阳就好」。
