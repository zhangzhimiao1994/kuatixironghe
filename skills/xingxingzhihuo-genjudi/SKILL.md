# 星星之火根据地 — 从边缘突破到波浪式扩张

**来源**：《毛泽东选集》星星之火，可以燎原(1930) 等 ｜ 证据等级：firsthand

## 触发条件

**应该触发**：
- 资源有限但野心大，面临"全面铺开还是聚焦突破"的选择。
- 团队出现"流寇"倾向（追风口不深耕）。
- "应该一线城市还是下沉市场先切入""ToB还是ToC""垂直行业还是通用场景"。
- "要不要趁势扩张""是不是该进入新市场了""怕扩张太快崩了"。
- "我们这么小能做大吗""市场已经被占了""不知道从哪里突破"。

**不应触发**：
- 已有稳固基本盘，只需优化 → 不适用。
- 市场规模有限、无需扩张 → 不适用。
- 问题在执行层面而非战略路径 → 不适用。
- 市场窗口极短（如政策红利只有 3 个月）→ 用集中优势兵力的速决战。

## R：原文锚点

> "这里用得着中国的一句老话：'星星之火，可以燎原。'这就是说，现在虽只有一点小小的力量，但是它的发展会是很快的。它在中国的环境里不仅是具备了发展的可能性，简直是具备了发展的必然性。……我们看事情必须要看它的实质，而把它的现象只看作入门的向导，一进了门就要抓住它的实质，这才是可靠的科学的分析方法。"（星星之火，可以燎原，1930年1月）（已据原文核）

> "朱德毛泽东式、方志敏式之有根据地的，有计划地建设政权的，深入土地革命的，扩大人民武装的路线……政权发展是波浪式地向前扩大的。"（星星之火，可以燎原，1930年1月）（已据原文核）

> "红军第四军的共产党内存在着各种非无产阶级的思想，这对于执行党的正确路线，妨碍极大。"（关于纠正党内的错误思想，1929年12月）（已据原文核）

## I：核心解释

1. 弱小力量的壮大需要三步：边缘突破（找到巨头忽视的真空地带）→ 根据地建设（在那里建立有壁垒的基本盘）→ 波浪式扩张（从根据地向外逐圈扩展）。
2. **边缘突破**：不要在巨头重兵把守的中心地带竞争，而是找到对手覆盖不到、不屑于做、或做不好的边缘缝隙。关键不是"哪里有机会"，而是"哪里有结构性真空"。
3. **根据地建设**：根据地不是临时的客户群，而是有壁垒的基本盘（高客户粘性+高复购+口碑传播+数据积累）。在根据地里建立绝对优势，做成该细分市场的第一。
4. **波浪式扩张**：不是跳跃式地进入不相邻的市场，而是每次扩张都与现有根据地相邻——共享用户群、渠道、或能力，降低扩张风险。每一步都是"巩固→扩展→再巩固"。
5. 核心禁忌是"流寇主义"：打一枪换一个地方，看似热闹但没有任何积累。追逐风口而不深耕行业，频繁转型而不建立壁垒——最终在任何领域都没有根基。
6. 判断星星之火能否燎原的关键：不是看力量大小，而是看结构性条件是否支持发展——是否存在不可逆的趋势、不可填补的真空、不可复制的优势。

## A1：来源应用

### 应用1：星星之火 — 从边缘根据地到全国胜利的逻辑推演 (c06)
- **问题**：1930年红军极度弱小，党内弥漫"红旗到底打得多久"的悲观情绪。
- **方法使用**：毛泽东没有用鸡汤安慰，而是用矛盾分析法论证结构性条件：中国是半殖民地→统治阶级内部矛盾不可调和→军阀混战→农村权力真空→红色政权可以存在和发展。
- **结论**：不是"希望"会赢，而是"逻辑上必然"会赢——因为结构性条件决定了星星之火必然燎原。
- **结果**：从1930年不到1万人的红军，经过波浪式推进，最终在1949年取得全国胜利。

### 应用2：波浪式推进 — 根据地的扩张节奏 (c23)
- **问题**：如何从一个小根据地发展壮大，既不冒进也不保守。
- **方法使用**：反对两种极端——"流寇主义"（到处游击不建根据地）和"保守主义"（只守不扩）。提出"波浪式推进"：先建根据地→巩固→向周围扩展→再巩固→再扩展。武装力量也从乡赤卫队→区大队→县总队→地方红军→正规红军逐级升级。
- **结果**：从井冈山一个根据地起步，波浪式推进到全国胜利，被证明是在资源极度有限条件下的最优策略。

### 应用3：游击战"做眼"策略 — 根据地的围棋思维 (c16)
- **问题**：在敌人占领区如何建立和保持根据地。
- **方法使用**：用围棋比喻——每个游击根据地就是一颗"做眼"的棋子，单个看很小但多个互为犄角形成反包围。关键是"巩固地向前发展"——不能只扩张不巩固，也不能只巩固不扩张。
- **结果**：敌后抗日根据地从零发展到最后控制一亿人口区域。

## A2：典型触发场景

1. **早期选择切入点**：产品做出来了，但不确定先打哪个市场。用户会说："应该一线城市还是下沉市场先切入""ToB还是ToC""垂直行业还是通用场景"。
2. **扩张节奏焦虑**：基本盘还没稳就想全面铺开，或者守着基本盘不敢扩张。用户会说："要不要趁势扩张""是不是该进入新市场了""怕扩张太快崩了"。
3. **团队出现"流寇"倾向**：频繁换方向、追逐热点、没有深耕任何领域。用户会说："我们尝试了很多方向但都没做透""每次看到新机会就想跟进"。
4. **从0到1的信心危机**：力量太小、资源太少，团队对未来悲观。用户会说："我们这么小能做大吗""市场已经被占了""不知道从哪里突破"。

**语言信号**：用户提到"切入点""先做哪个市场""扩张节奏""基本盘""根据地""深耕vs广撒网""要不要换方向"等词汇时，应优先激活此skill。

**与相邻skill区分**：
- vs 不对称战略：本skill = "在哪打、怎样扩张"（路径选择），后者 = "用什么范式竞争"（战略定义）
- vs 三阶段持久战模型：本skill = 空间路径（从边缘到中心），后者 = 时间阶段（防御→相持→反攻）
- vs 集中优势兵力：本skill = "在哪里建根据地"，后者 = "在选定的点上如何集中资源打穿"

## E：执行步骤

### 步骤1：找到边缘真空地带
- 绘制市场地图，标注巨头/头部玩家的覆盖范围和薄弱环节。
- 找到"真空地带"的三个条件：(1)巨头覆盖不到或不屑于做；(2)有真实且持续的需求；(3)你能在这个领域建立壁垒。
- **完成标准**：至少识别出3个候选的边缘切入点，每个都用"巨头为什么不做/做不好"来论证其真空属性。

🔴 **CHECKPOINT**：把「候选真空地带 + 巨头为什么不做」的论证展示给用户，确认选定切入点后再进入步骤2

**输入**：市场地图与巨头覆盖情况 → **输出**：3 个以上候选边缘切入点及真空属性论证。

### 步骤2：在选定点建立根据地
- 选择最有把握的那个切入点，集中全部资源建立"根据地"——不是做几个客户就走，而是做到该细分市场的绝对第一。
- 根据地的标志：(1)该领域客户占有率第一；(2)客户复购/续约率高；(3)客户自发口碑传播；(4)积累了领域特有的数据/经验/关系网络。
- **判停点**：如果在选定点尝试6个月仍未形成任何上述标志，重新评估是否选错了点——可能不是真空地带，或你的能力不匹配。

🔴 **CHECKPOINT**：确认根据地已形成（4个标志至少达成3个）后再进入步骤3扩张

**输入**：选定的切入点 → **输出**：该细分市场第一的“根据地”（四个标志至少达成三个）。

### 步骤3：波浪式扩张
- 根据地稳固后（上述4个标志至少达成3个），选择与根据地"相邻"的扩展方向——共享客户群、共享渠道、或共享核心能力。
- 每次扩张的节奏：先小范围验证（1-2个月）→ 巩固成果 → 再扩大范围。不是"一年开10个城市"，而是"一个城市做透再开下一个"。
- **完成标准**：画出扩张路线图（未来12个月），每一步都标注：从哪个根据地出发、共享什么能力/资源、巩固标准是什么。

**输入**：稳固的根据地 → **输出**：未来 12 个月的扩张路线图。

## B：边界与失败模式

### 失败模式分支表

| 情况 | 表现 | 怎么处理 |
|------|------|---------|
| 流寇主义(ce13) | 追逐风口不深耕，频繁换方向不建壁垒 | 回到步骤2，先把一个点做透、建成根据地 |
| 八月失败(ce03) | 条件不成熟时强行冒进，脱离根据地孤军深入 | 区分"有利时机"和"不利时机"，不脱离根据地 |
| 盲动主义(ce10) | 不愿做"细小严密"的基础工作，只想"大干" | 认下建根据地的慢工，避免"打一枪换一个地方" |
| 单纯军事观点(ce12) | 只关注产品功能，不重视用户体验和生态 | 打胜仗不骄傲、打败仗不消极，同步建用户基础 |

- **流寇主义(ce13)**：追逐风口不深耕，频繁换方向不建壁垒。"打一枪换一个地方"看似热闹，但在任何领域都没有根基，被深耕者轻易击败。
- **八月失败(ce03)**：在条件不成熟时强行冒进——不看时机分兵冒进，脱离根据地孤军深入。结果边界和湘南同归失败。核心错误是不区分"有利时机"和"不利时机"。
- **盲动主义(ce10)**：不愿做"细小严密"的基础工作，只想"大干"。觉得建根据地太慢太笨，直到发现自己在每个领域都没有根基。
- **单纯军事观点(ce12)**：只关注产品功能，不重视用户体验和生态建设。打赢了产品战却失去了用户基础——"打胜仗就骄傲，打败仗就消极"。

### 边界规则

1. **市场窗口期极短时**：如果机会稍纵即逝（如政策红利只有3个月），来不及建根据地就要全面铺开——此时用集中优势兵力的速决战而非波浪式推进。
2. **已有成熟基本盘时**：如果你已经是某领域的头部，需要的不是"边缘突破"而是"正面扩张"或"防御加固"。
3. **资源充足、市场明确时**：如果资源充裕且市场路径清晰，可以用更激进的扩张策略，不必拘泥于波浪式推进。

### 用户自查清单

- [ ] 我识别出 ≥3 个候选真空地带，并论证了"巨头为什么不做"
- [ ] 我选定的切入点有真实需求且我能建壁垒
- [ ] 我的根据地标志至少达成 3 个，才谈扩张
- [ ] 我的每次扩张都与现有根据地"相邻"（共享客户/渠道/能力）
- [ ] 我画出了 12 个月扩张路线图，并把"巩固"写进每一步

**勾选 4+ 项**：路径清晰。**≤2 项**：回到对应步骤重做，尤其别跳过步骤2。

**安全兜底**：若扩张压力已造成持续的情绪耗竭或心理危机，只做提醒与陪伴，不做诊断，指向专业资源（心理援助热线 12356；紧急情况拨 120/110）。

### 作者盲点

- 毛泽东强调"波浪式推进"，但对扩张速度的具体把控标准论述较少。商业启示：扩张速度不能一刀切，需要根据市场反馈动态调整——如果扩张速度快于巩固速度，就是冒进；如果巩固时间长于市场窗口期，就是保守。

## 📖 练习手册

拿一张纸画出你所在赛道的"市场地图"：① 标出巨头/头部玩家的覆盖范围，找出 ≥3 个真空地带，各写一句"巨头为什么不做/做不好"；② 选出最有把握的一个，列出根据地四标志（市占第一/高复购/口碑/数据积累），现在能达成几个；③ 画出未来 12 个月"波浪式"扩张路线图，每一步标清共享什么能力、巩固标准是什么（补充）。

## 🚫 反例与黑名单

1. **追风口不深耕、频繁换方向** → 流寇主义(ce13)；先把一个点做成根据地。
2. **脱离根据地孤军深入** → 八月失败(ce03)；看清有利/不利时机。
3. **不愿做基础工作只想"大干"** → 盲动主义(ce10)；承认建根据地的慢工。
4. **只做产品不建用户基础** → 单纯军事观点(ce12)；同步积累口碑与生态。
5. **跳跃式进入不相邻市场** → 每次扩张都要与现有根据地相邻，降低风险。

### 灰色地带（需谨慎判断）

- **市场窗口极短（如政策红利 3 个月）** → 不硬套波浪式推进；用集中优势兵力打速决战，事后补建根据地。
- **已有成熟基本盘、想再扩张** → 这不是"边缘突破"，而是"正面扩张/防御加固"，改用相应 skill。
- **"相邻"的边界模糊（新市场看似相邻实则不同）** → 用共享客户/渠道/能力三条逐项核对，任一条不成立就要慎重。

## 跨 skill 协作链

- **不对称战略** (composes-with): 不对称战略解决"用什么范式竞争"，根据地建设解决"在哪打、怎样扩张"。先确定竞争范式，再规划从边缘到中心的扩张路径。
- **集中优势兵力歼灭战** (contrasts-with): 根据地建设强调"扩张"——从一个点波浪式扩展到全局，是空间维度的路径规划；集中优势兵力强调"聚焦"——在关键局部集中资源彻底解决，是资源维度的投放策略。扩张与聚焦需要根据阶段灵活切换。
