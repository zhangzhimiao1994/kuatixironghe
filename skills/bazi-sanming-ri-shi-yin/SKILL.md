# 三命通會·日時斷（陰干）：六乙·六丁·六己·六辛·六癸日的時上斷法

**来源**：sources/sanmingtonghui.txt（《三命通會》卷八·日時斷、卷九·日時斷、卷十·㸔命口訣） ｜ 证据等级：firsthand（原书原话）

**应该触发**：
- 用户读到「六乙日生時丁丑 食神相助遇財官月通金氣化為福 不是尋常下賤㸔」这类时上歌诀，问怎么解。
- 用户问阴干日主——乙、丁、己、辛、癸——落在某个时支上，书上给什么象与条件。
- 用户问「以下六乙日所忌月分與上同時亦併論」这种注句是什么意思。
- 用户问癸日见壬子时、辛日见戊子时为什么单称一格。
- 用户问阴干在昼生夜生上与阳干有什么不同。
- 用户把己日/辛日的歌诀与阳干那几组混着问，想弄清分界。
- **用户给出四柱、问「我这盘怎么看」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

- 用户问的是阳干日主（甲丙戊庚壬）的时上断法 → 转 bazi-sanming-ri-shi-yang。

- 用户问月令格局、十神、官煞财印食伤分论 → 转本族相应 skill。

- 用户只给一句「我生日那天怎样」、没有四柱 → 先按 bazi-hub 硬闸门走，缺柱不排。

## R：原文锚点

1. 以下六乙日所忌月分與上同時亦併論（《三命通會》卷八·六乙日丑時斷）
2. 六乙日生時丁丑 食神相助遇財官月通金氣化為福 不是尋常下賤㸔（《三命通會》卷八·六乙日丑時斷）
3. 六丁日生時庚子 身衰鬼旺暗中藏月無救助多貧夭 得坐身强又吉昌（《三命通會》卷八·六丁日庚子時斷）
4. 六已日生時甲子 明見官星暗有財 倚托若通於月氣 平生衣祿自天來（《三命通會》卷九·六已日甲子時斷）
5. 六辛日生時戊子 印綬學堂坐食神 不見丙丁同午破 必是榮華貴顯人（《三命通會》卷九·六辛日子時斷）
6. 六癸日生時壬子 青雲得路最為奇 若無己土衝尅破 自有功名顯達時（《三命通會》卷九·六癸日子時斷）
7. 以下六已日所忌月分與上同時犯併論（《三命通會》卷九·六已日乙丑時斷）
8. 六般陰命男犯禄鬼倒食須取日主反凶作吉餘並同前却以夜生為順（《三命通會》卷十·㸔命口訣）

## I：核心解释

阴干日主的日時斷，与阳干那一套同出一辙，都是把**日干配時支**成一个格，先定象、再给条件；只是所管的日主不同——乙、丁在卷八，己、辛、癸在卷九。读法与阳干那组并列，但取象的星与条件各各不同。

1. **月忌与时忌并论**：阴干这几组每段前也有同样的注句，例如「以下六乙日所忌月分與上同時亦併論」（R1）、「以下六已日所忌月分與上同時犯併論」（R7）。意思一致：月分所忌与时上所忌，并到一处论。
2. **逐干逐时取象**：乙日丑时取的是「食神相助遇財官」这一路（R2）；丁日子时转成「身衰鬼旺」与「得坐身强」（R3）；己日甲时是「明官暗財」（R4）；辛日子时是「印綬學堂坐食神」（R5）；癸日子时是「青雲得路」（R6）。同一日干换一个时支，象就换一套。
3. **歌诀与条件两句并用**：歌诀给象（如 R4 的「明見官星暗有財」、R6 的「青雲得路」），散文把月气、倚托、通不通气以及所忌月分连起来；两句齐了才是完整的一条断。
4. **单称之格的提醒**：辛日戊子时被单称「印綬學堂」，癸日壬子时被单称「青雲得路」（R5、R6），都是后文另立一格来论的入口；读时注意它们不只是普通的一格。
5. **阴干的昼夜化气**：卷十把阴干单独交代一句——「六般陰命男犯禄鬼倒食須取日主反凶作吉餘並同前却以夜生為順」（R8）。这是说阴干命遇禄鬼倒食时，取法与阳干相对，以夜生为顺。
6. **一句话读法**：阴干日時斷＝以日干与時支定格、先抄歌诀取象，再照散文补月气与倚托，月忌与时忌并论；凡事回书取象，不落人身。

## A1：来源应用

书上给阴干这组的做法，同样是「逐个对号」：

- **定位**：先认定日干与时支。乙、丁二日的格在卷八，己、辛、癸三日的格在卷九。书里查不到这一格，就照实说没有，不自己补。
- **歌诀取象**：抄出该格歌诀，逐句解它命的星——如 R2 的食神财官、R3 的身鬼、R4 的明官暗财、R5 的印綬学堂、R6 的青云得路。
- **散文取条件**：把散文里的「通金氣月／身有倚托／無救助／所忌月分」等条件补齐；象与条件两样都要，缺一不算。
- **月忌并论**：照 R1、R7，把所忌月分与时上所忌并起来看。
- **阴干的相对取法**：遇到禄鬼倒食，按 R8 的思路——阴干以夜生为顺、取日主反凶作吉，与阳干相对。
- **评价语提醒**：歌诀里会出现「下賤」「貧夭」这类词（见 R2、R3），那是**书里的评价语**，引用时要标明它出自原书；本 skill 不把它落到具体人身上。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干是哪一干（乙丁己辛癸）、時支是哪一支、属卷八（乙丁）还是卷九（己辛癸）的哪一格、日时两柱的星、四柱所忌月分。
2. **逐条核书里的条件**：日主是否阴干 → 月分所忌与时忌是否并论（R1／R7）；该格歌诀取了什么象 → R2（乙）／R3（丁）／R4（己）／R5（辛）／R6（癸）；遇禄鬼倒食时的相对取法 → R8（阴干以夜生为顺、取日主反凶作吉）。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「日主为癸、時支子，按 R6 这一路读，偏『青雲得路』的取象」，并给出处（如「《三命通會》卷九·六癸日子時斷」）。
4. **收口**：这一句是**书里的读法**，不是对这个人吉凶的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：这一块原书只有逐格的歌诀与条件，没有「时上评分」「时柱权重」之类名目；己／已／巳、夘／卯 这类异体在源文本里本就混用，照抄所引那一处的原样，不替它统一。

   🔴 **CHECKPOINT**：异体字（已／巳／己、夘／卯、㸔 等）照原样抄，不改写成今字。

8. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干是哪一干（乙丁己辛癸）、時支是哪一支、属卷八（乙丁）还是卷九（己辛癸）的哪一格、日时两柱的星、四柱所忌月分。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|

1. 只做《三命通會》卷八、卷九日時斷（阴干）的取象讲解，不替用户判命运。

3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 报一条断须同时给出处（卷次·篇名）与取用条件。

## 🚫 反例黑名单（不要做的事）

2. 把阳干（甲丙戊庚壬）的格拿去解阴干的日时。

## 灰色地带

- **用户引一句歌诀问「这是不是我」**：歌诀是书里对「日干＋時支」这一格的取象，不是对某人的判决；照实讲象，落人身的部分说明不接。
- **同一时支在两处说法不同**：多半是不同日干（甚至阴阳不同）的两格，先分日干，再各自照抄。
- **用户要「取象＋判我这一盘」**：取象照讲，判定说明不接，并说要补哪些柱。
- **条目里己／已／巳 写法混用**：源文本本就混用，照抄所引那一处的字形，不在两处之间「折中」。
- **书里断语与用户期望相反**：据实说这是书里对该格的评语，不下对人身的判断。
