# 用事：御用六十七事、民用三十七事

**来源**：sources/xieji.txt（《欽定協紀辨方書》卷十一·用事） ｜ 证据等级：firsthand（原书原话）／ inference（推断，须标注）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问「明天嫁娶、这周安葬、最近动土，宜什么忌什么」。
- 用户问「开市要避开哪些神」「出行要碰到哪些吉神才行」。
- 用户要一份按事排的清单：这件事该看德合赦愿，还是该避月破三煞。
- 用户问「御用六十七事、民用三十七事各是什么」、或「我这事归哪一类（御用还是民用）」。
- 用户把一件事和几张日期放在一起，问哪几天合、为什么合。

**不应触发**（看起来像但其实不是）：
- 用户只问某个神煞的起例与轮值日 → 归 `kanyu-xieji-li-cheng`（卷九·立成）。
- 用户只问某一天整天的吉凶轻重怎么取舍、德神能解到哪一步 → 归 `kanyu-xieji-yi-ji`（卷十·宜忌）。
- 用户问某个神煞的名义由来 → 归义例各卷的 skill（`kanyu-xieji-yue-shen`／`kanyu-xieji-ri-shen`）。
- 用户要相地看形势、点穴、看朝向 → 不归本 skill。

## I：核心解释

卷十一开篇把两套排法点明：铺注万年书「以事為經以神為緯」，选吉日时「以神為目以事為綱」——**事与神互为经纬**，看事的时候把神当网去筛，看神的时候把事当纲去领。这就是「选择由事起」：择日不是先问「这天好不好」，是先问「我要办的是什么事」。

1. **三种事目合一编**：大清会典载万年书有御用六十七事、民用三十七事，通书载选择六十事；本卷「以次合為一編」，并按事之次第把宜忌分注到每件事下面。用事这一卷的骨架就是这份事目表。
2. **每事分列宜神与忌神**：每条事的写法是「某事 宜〔一串吉神〕忌〔一串凶神〕」，例如嫁娶宜天德月德…不將，忌月破三煞月厌厌对大时天吏四废四忌四穷五墓往亡八专亥日。查一件事，就看它这一条。
3. **先事次第，再较轻重**：原话「依事之次第察其所宜忌之日而分註之則輕重去取可辨矣」——先在事目里定位这件事，再按卷十的轻重等第定去取。用事给「哪些神宜／忌」，宜忌卷给「宜与忌哪个胜」。两卷必须合用。
4. **事有御用民用两阶**：御用六十七事细而全（含出师、选将训兵、安抚边境等），民用三十七事约而近（出行、移徙、疗病、破土、安葬等）。同一类事在两阶里的名称与颗粒度不同，找事时要两阶都看一眼。
5. **无宜日的事也有规矩**：原话末尾交代疗目针刺「與療病同」、鼓铸苫盖「與修造同」、远回乘船渡水「除所忌之外無日不宜」——有些事本身没有专属吉日，只按所忌趋避即可。（补充）这提醒：查不到「宜」不等于不能做，可能是本书体例里它本就不设专宜。
6. **宜神与忌神不是对半分的**：同一条事里，宜神多是德合赦愿这类贵神，忌神多是月破三煞月厌大时天吏四废五墓这类凶神；用户问「为什么宜的少、忌的多」，答案是用事卷写忌比写宜细，细在凶神的枚举上。
7. **同一神在不同事下位置不同**：例如「六合」在嫁娶、宴会、般移下出现，在出师、安葬下不出现；一个神宜哪些事、不宜哪些事，要在各事条里逐条看，不能从一个事推到另一个事。
8. **三份事目各有出处**：御用六十七事、民用三十七事出自大清会典所载万年书，另有通书所载选择六十事；本卷「以次合為一編」。通书六十事里还多出「上冊受封、襲爵受封、移徙、遠迴、療目、針刺、修倉庫、鼓鑄、苫蓋、醞釀、開倉庫、出貨財、補垣塞穴、乘船渡水」等条目，是御用、民用两份事目之外的补充。
9. **事目是「经」、神是「纬」，两向都能查**：从一件事出发查它的宜忌神（以神为纬），或从一个神出发查它出现在哪些事下（以事为纲）。两种查法用同一套事目，方向不同而已。

## E：执行步骤

1. **定位事名与事阶**　输入：用户说的那件事 → 输出：它对应御用六十七事里的哪一条、民用三十七事里的哪一条（两阶都查），并写出该事名义。
   🔴 **CHECKPOINT**：把「你要办的是〔某事〕，它在御用／民用里叫〔某名〕」复述给用户确认；事名对不上（如用户说「搬家」对应「般移／移徙」）当场对齐。
2. **取该事的宜神与忌神**　输入：事名 → 输出：卷十一该条下的「宜〔…〕忌〔…〕」两串神名，附卷次依据。
3. **回卷九补起例**　输入：宜／忌神名 → 输出：每个神名的起例来源（卷九类目），使神名可查、可核。
   🔴 **CHECKPOINT**：若用户给了具体日期，把该日在这些吉凶神上的落点标出来；**若没给具体日期或缺月建，明写缺什么，不许用占位日期硬判**。
4. **回卷十较轻重**　输入：该日命中的宜神与忌神 → 输出：按六等定从宜或从忌（见 `kanyu-xieji-yi-ji`），说明德神能否化解。
5. **落成一条建议**　输入：事名＋宜忌＋去取 → 输出：一句话说明这件事「宜看哪些神、忌避哪些神、这一天按书里读偏宜还是偏忌」，并说明这是按原书体例的倾向，决定权在用户。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 报宜忌不给起例与卷次 | 「嫁娶避月破就行」 | 硬口径：报事之所宜所忌必须同时给起例来源（卷九类目）与卷次依据（卷十一·用事）；不齐不给结论 |
| 无事名就开单 | 用户问「最近好日子」 | 缺什么说什么：要先给具体事名（嫁娶／安葬／开市），无事项不出宜忌 |
| 只查一阶事目 | 用户说「出行」，只查御用漏了民用 | 御用与民用两阶都查，名称不同者当场对齐 |
| 把事的宜忌当整天吉凶 | 拿一条事的宜忌否定整天 | 用事给事的宜忌，整天轻重归卷十；不越界 |
| 无具体日期硬排 | 编一个日子说「这天合」 | 缺日期缺月建照实说，不造占位 |
| 替用户拍板 | 「就这天，去办」 | 只给倾向与依据，决定权交回用户 |

**边界规则**：
1. **报神煞／报宜忌必须同时给起例来源与卷次依据**：起例来源写清是哪一例（卷九），事条依据写到卷与篇（《欽定協紀辨方書》卷十一·用事）。只报一个名字不给出处＝不合格。
2. **数据不足照实说**：没给具体日期、没给具体事项，就说缺什么、要到什么程度才能判，不许用占位日期硬判。
3. **只给倾向、不当断语**：按原书体例写成「按此类读」，不落『一定／必然／命中／保证』这类话；不涉医疗、法律、投资结论，也不替用户拍板。

**来源边界**：本 skill 只据 sources/xieji.txt（《欽定協紀辨方書》）卷十一·用事的三份事目与各事宜忌条目。神煞起例在卷九，宜忌轻重在卷十；引用邻卷必注明卷次。

**自查清单**：
- [ ] 事名在御用与民用两阶都核过
- [ ] 每条宜／忌都附了起例来源与卷次依据
- [ ] 没有把事的宜忌当成整天吉凶

- [ ] 没有写「一定／必然／命中／保证」

## 练习手册

- **两阶对齐**：取御用里的「般移」「求醫療病」「裁製」，找出它们在民用三十七事里的对应名称（移徙／療病／裁衣），写清异名关系。
- **抄一条事**：挑「安葬」，把它的宜神与忌神各抄一遍，再逐个回卷九找出起例类目。
- **反查事主**：给一个吉神（如六合），问它出现在用事卷的哪几条事下，列出这些事名。
- **对照两条事**：把「祭祀」一条的宜神、忌神各抄一遍，再与「祈福」一条逐字对照，标出两条共有与独有之神。
- **两阶默写**：默写御用六十七事与民用三十七事各一遍，标出只在其中一阶出现的事名。

## 反例黑名单

1. **报宜忌不给起例与卷次** —— 不合格。
2. **无事名就给「好日子」** —— 用事由事起，先有事再有宜忌。
3. **只查御用或只查民用一阶** —— 两阶名称与颗粒度不同，须并查。
4. **把一条事的宜忌当成整天吉凶** —— 整天轻重归卷十。
5. **无日期硬排或替用户拍板** —— 缺什么说什么，决定权交回用户。
6. **把三份事目当成同一份** —— 御用、民用、通书各有出处与颗粒度，合编时须分别标明。
7. **只写事名不写宜忌神** —— 用事卷的价值在「宜〔…〕忌〔…〕」两串，缺了神名等于没查。

## 灰色地带

- **一事在多条下都出现**：按用户实际要办的那个动作定事名，不把相邻的事（开市／立券／交易／纳财）混成一条。
- **用户用口语名（如「搬家」「开张」）**：先对齐到事目里的正式名（般移／移徙、開市），对齐不了则说明事目未收。
- **御用与民用同一事名称不同**：两阶都写出，以用户所处场景选一阶为主，另一阶作为对照。
- **一条事在卷十一只写了忌、没写宜**：照实说该条「无宜日」，只能按所忌趋避，不替它编一个宜神清单。
- **用户同时要几件事**：每件事各自成条，逐条给宜忌，不用一件事的结果覆盖另一件。
- **用户说的事在三份事目里都查不到**：照实说御用／民用／通书三份均未收，不替它新立一条；可指明最接近的邻近事条作参照。
