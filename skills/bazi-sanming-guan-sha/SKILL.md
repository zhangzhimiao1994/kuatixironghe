# 官煞去留與官鬼互變

**来源**：sources/sanmingtonghui.txt（《三命通會》卷五·官煞去㽞並官鬼互變雜論、官煞混雜、論正官、論偏官；卷十一·喜忌篇） ｜ 证据等级：firsthand（原书原话）

## 触发条件

## I：核心解释

官与煞是同一组关系（尅我者）的阴阳两面：阳干见阴尅、阴干见阳尅为正官，隔七位相克为七煞。两样同时出现叫「混雜」，卷五专设「官煞去㽞並官鬼互變雜論」来处理。

1. **混雜这个题目由喜忌篇引出**。「喜忌篇云煞官混雜，類有去官留煞，亦有去煞留官」（R2）。「類有」是要点：不是一律要留官，也不是一律要留煞，得看柱里谁重谁轻。
2. **去留先看轻重与透藏**。「凡㸔去留要詳柱中官煞孰重孰輕，天干透者易去，月支所藏者難去」（R3）。透在天干的容易去掉，藏在月支的不容易去掉——这是判断的第一把手。
3. **阳日与阴日去留的两条路**。「五陽日食神能去煞又能㽞官，五陽日傷官但能去官不能留煞」（R4）。书里接着说阳日伤官要去官留煞须得羊刃合煞；阴日则食神能去煞却不能留官、伤官能去官又能留煞。同一组食伤，在阳日阴日里作用不同。
4. **去留各论贵与权**。「元理賦云去煞留官當論貴，去官留煞主威權」（R5）。书里把两条路各给一句评价语，这是书里的说法，不作对某人的判词。
5. **两停怎么办**。「經曰官煞兩停，喜者存之，憎者去之」（R6）。两势相当，就看有物生扶会和的（力专）宜存，有物破损伤害的（力散）宜去。喜忌篇里同一句写作「憎者棄之」（R11）——两处一字之异，照原样引，不折中。
6. **混雜退一步回到财印**。「人命官煞俱有謂之混雜，只取財印為用」（R9）。官煞并见而难分去留时，书里不硬分，改从财、印两头取用；这一条与上面的去留法互相补。
7. **官鬼互变的两句**。「精紀云凡命鬼多而主本却在有氣之地，其鬼化官；若主本無氣，官有氣，即官化鬼」（R7）。「季主云旺迅逄鬼，鬼化官；衰迅逄官，官化鬼」（R8）。两句说的是同一件事：官与鬼的名分随日主（主本）有没有气而翻——主强则鬼可作官，主弱则官反成鬼。这是「互變」的确解。
8. **混雜的书里评价语**。「煞官混雜不貧則夭」（R10）——这句在论正官篇里，语气很重，引用时必须标明是书里的说法。
9. **一句话读法**：先数官煞轻重、看透藏（R3），再分阳日阴日看食伤能去谁留谁（R4），两停则存扶去害（R6），分不清就回到财印（R9）；官与鬼的名分则随主本旺衰翻（R7、R8）。

## A1：来源应用

书上给的做法，是「先算轻重透藏，再按日主阴阳分两路，两停则存扶去害，难分就回财印」：

- **轻重透藏**：先比官煞哪一个重、哪一个透在干、哪一个藏于支（R3）。
- **阳日**：食神可以去煞又能留官；伤官只去官不能留煞，须得羊刃合煞才成去官留煞（R4）。
- **阴日**：食神能去煞却不能留官，日主自能留之；伤官能去官又能留煞（同上篇，见 R4 所属段落）。
- **两停**：官煞势力相当，取有物生扶会和者存、有物破损伤害者去；两者俱有扶合而无破害，书里说反为贫贱（R6）。
- **难分时**：官煞俱有、去留不清，就「只取財印為用」，柱中有财则行财运发福（R9）。
- **互变**：主本有气则鬼化官，主本无气则官化鬼（R7、R8）；书里另举「丁」等纳音真五行见乙庚为例说明名分随位而变（同篇）。
- **评价语提醒**：R5 的「貴／威權」、R10 的「不貧則夭」都是书里的评价语，引用标明是书里的说法。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干（阳还是阴）、正官与七煞各在哪一柱、孰透干孰藏支、柱中有无食神／伤官／羊刃／财印。
2. **逐条核书里的条件**：官煞孰重孰轻、透者易去藏者难去（R3）→ 分阳日阴日看食神伤官各能去谁留谁（R4）→ 两停则存扶去害（R6／R11）→ 难分则退取财印（R9）→ 官鬼名分随主本有气无气而翻（R7、R8）。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「官轻煞重而透干，按 R3 这一路读，偏易去官」，并给出处（如「《三命通會》卷五·官煞去㽞並官鬼互變雜論」）。
4. **收口**：这一句是**书里的读法**，不是对这个人吉凶的判定；**不应期、不断终身、不替人决定**。

**书里没有的、不要加**：本篇不列「去留规则表」这类后人整理；也不谈流年大运的岁运并临怎么断。凡书里没有的合并规则，一律不造。

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。

4. **逐条核条件、给读法（落盘）**　输入：第 3 步的料 ＋ 本 skill 的条件 → 输出：
   - 按 R3 排轻重、看透藏（透者易去、藏者难去）→ 按 R4 分阳日阴日看食神／伤官各能去谁留谁（阳日伤官须羊刃合煞）→ 轻重相近按 R6 存扶去害、仍不清则按 R9 退取财印 → 官鬼名分按 R7、R8 随主本有气无气而翻；

5. **收口**　输入：整段推演 → 输出：一句「留谁去谁」＋一句「凭什么（轻重／透藏／阴阳）」；若用户在追问某个具体人的吉凶，照实说明本 skill 只讲去留读法，不替人断终身。
   🔴 **CHECKPOINT**：收口前确认——① 没把 R5、R10 里的评价语（當論貴、主威權、不貧則夭）说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的官煞去留／用词带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把去留讲成定额 | 断然说官煞混见一定要留官 | 拉回 R2「類有」与 R3「详轻重」，逐柱分 |
| 只用轻重不看透藏 | 只比谁重，不管透干还是藏支 | 补 R3：透者易去、藏者难去 |
| 阳日阴日一把抓 | 拿一套食伤去留法套所有日主 | 分 R4 的阳日／阴日两路 |
| 把互变讲成玄谈 | 大谈鬼神灵应 | 落回 R7、R8「主本有气无气」 |
| 越界批岁运 | 替用户算哪一年官煞并临 | 只说原句讲的柱中条件，不替人排岁运 |
| 缺柱仍定去留 | 没有月支就断言月支所藏者难去 | 照实说要补出生月与时柱，不用占位信息硬排 |

**边界规则**：
1. 只讲卷五官煞去留与官鬼互变、官煞混雜、论正官偏官，与喜忌篇官煞那几行，不接具体人的终身、寿夭、婚姻、职业、医疗结论。
2. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 书里的断语（當論貴、主威權、不貧則夭）引用时标明是书里的说法。
4. 喜忌篇与卷五的异文（憎者去之／憎者棄之）两处照抄，不折中。
5. 缺出生年月日时任一柱或缺出生地，照实说要补什么，不用占位信息硬排。

## 📖 练习手册

- **数轻重**：给自己记住的一组四柱，数出官几位、煞几位，哪一位透干、哪一位藏支，写出按 R3 该先动哪一个。
- **阴阳对照**：把 R4 的阳日一路与阴日一路各抄成一行，圈出「能去煞」「能留煞」两处差别。
- **两停推演**：按 R6 写出「喜者存之」与「憎者去之」各指什么物，不给书外条件。
- **互变一句话**：用 R7、R8 各写一句白话，只讲主本有气无气，不引申吉凶。

4. 把「鬼化官」讲成灵应玄谈，脱离「主本有气无气」。
5. 替用户算岁运并临、断终身（越界）。
6. 把喜忌篇与卷五的一字之异自行折中改字。

## 灰色地带

- **两处异文**：同一句在卷五作「憎者去之」、喜忌篇作「憎者棄之」。两处都照抄，遇到用户追问哪一处为准，就说这是两份源文的异文，本 skill 不改字、不折中。
- **官煞混雜与「只取財印」的先后**：R2–R6 讲去留，R9 讲混雜难分时退到财印。用户若问两者是不是矛盾，按原句说去留是首选一路、财印是退一步，不替用户拍板用哪一路。
- **去留到底「留」给谁**：书里「留官」「留煞」都指留下柱中那一神为用。用户若问留官是否等于走官运、留煞是否等于走煞运，照原句只讲柱中条件，不替人排运。
- **主本有气无气的分寸**：R7、R8 只说「有氣／無氣」，没给精细尺度。用户若追问到什么程度算有气，照实说书里只给这两句，不给刻度。
- **用户拿「不貧則夭」问吉凶**：不写自我否定腔，也不写兜售腔；标明这是书里的评价语，只讲这句在原书里的条件，判断留给用户。
