# 論十天干體象與取象

**来源**：sources/sanmingtonghui.txt（《三命通會》卷二·論天干隂陽生死、卷二·十干分配天文、卷一·論十干名字之義） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问十天干各自的「体象」那一句怎么讲（甲木乃十干之首、乙木继甲之后……癸水继壬之后）。
- 用户问「在天为雷为龙，在地为梁为栋」这类句子里的天象、地象各指什么。
- 用户问「十干分配天文」为什么把甲配雷、乙配风、丙配日、丁配星、戊配霞、己配云、庚配月、辛配霜、壬配秋露、癸配春霖。
- 用户问「论天干阴阳生死」里的「阳生阴死、阳死阴生」是不是说甲木在亥长生、在午死。
- 用户问「论十干名字之义」里甲乙为什么属木、壬癸的字义从哪来。
- 用户读到「木不南奔」「火无西向」「金沉水底」「水不西流」不懂。
- **用户给出四柱、问「我这盘日主怎么看／这盘十干体象怎么看」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**（看起来像但其实不是）：
- 用户问十二支各自的体象、藏遁、十二支分配地理 → 转 bazi-sanming-di-zhi。
- 用户问正月寅中哪几个干各司事几日 → 转 bazi-sanming-ren-yuan。
- 用户问六十甲子纳音取象 → 转 bazi-sanming-na-yin。
- 用户要排盘、给一组四柱算流年大运吉凶 → 本维度不接流年大运、不断终身。
- 用户只说「我是什么命」「我属什么」这类泛化的话，没有点出天干／日主／体象等显式请求 → 不激活。

## I：核心解释

这一段讲的是「一个天干是什么」，分三层：体象句、天象取象、名字之义。

1. **体象句的句式**。十段的句式统一：「某干……在天为何、在地为何，谓之阳某／阴某」（R1–R10）。甲在天为雷为龙、在地为梁为栋，是阳木（R1）；乙在天为风、在地为树，是阴木（R2）；丙在天为日为电、在地为炉为冶，是阳火（R3）；丁在天为列星、在地为灯火，是阴火（R4）；戊在天为雾、在地为山，是阳土（R5）；己是真土，清气上升、浊气下降（R6）；庚在天为风霜、在地为金铁，是阳金（R7）；辛在天为日月、为太阴之精、在地为金为山石之矿，是阴金（R8）；壬在天为云、在地为泽，是阳水（R9）；癸在天为雨露、在地为泉脉，是阴水（R10）。
2. **体象句里都带一条「性」**。光是天象地象还不够，每段还夹一句该干喜什么、畏什么：壬水「喜陽土而為堤岸之助，畏陰木而為盗氣之憂」（R9）；庚金「掌天地肅殺之權」（R7）；丁火「為萬物之精，文明之象」（R4）。取象不是贴标签，是配性。
3. **天象取象另立一套**。「十干分配天文」把十干各配一个天象：甲为雷、乙为风、丙为日、丁为星、戊为霞、己为云、庚为月、辛为霜、壬为秋露、癸为春霖（R11–R20）。它给的理由是可见的自然现象：甲「雷者陽氣之嘘也」（R11）；乙「長生在午，敗在巳」，午而畅茂故为风（R12）；丙「離為火為日」（R13）；丁「丙火死而丁火遂從生……在天之日薄而星迴」（R14）；庚「乃酉方陽金」故配月（R17）；辛「八月……白露為霜，草木黄落而變衰」（R18）。
4. **名字之义讲方与令**。十干之名先按方定：东方甲乙、南方丙丁、西方庚辛、北方壬癸、中央戊己（R21）。再就字义讲：甲乙位木、得春之令，甲是「陽内而陰尚包之，草木始甲而出」（R22）；最后落到数目——甲丙戊庚壬为阳、乙丁己辛癸为阴，「五行各一陰一陽，故有十日」（R23）。
5. **「阳生阴死」是书里自己的一层**。体象句多用了长生、死地的说法（乙長生在午敗在巳、丙火死而丁火遂從生），书里把十干分阴阳刚柔、各按长生十二宫讲生死；这是书里的口径，不是别的书的标准。

## A1：来源应用

书上给的读法，分三段落地：

- **读单干的体象**：先按 R1–R10 读出该干的天象、地象与阳／阴之名，再把该段里夹的喜畏配进去（壬喜阳土畏阴木、庚掌肃杀、丁为文明）。
- **读天象取象**：按 R11–R20 取该干配的天象，并照书里给的理由（雷为阳气之嘘、乙午而生、丙離为日、辛八月建禄白露为霜）。
- **读名字之义**：先定方与令（R21、R22），再落到阴阳十日之数（R23）。
- **一句可带走**：天干取象是「象 + 性」两件——天象地象定它的样子，喜畏定它要什么、怕什么。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：四柱各柱的天干、日主是哪一干、柱中各干落在体象句（R1–R10）的哪一段、天象取象（R11–R20）配哪一象。
2. **逐条核书里的条件**：该干的体象句与喜畏 → R1–R10（如壬「喜陽土而為堤岸之助，畏陰木而為盗氣之憂」、庚「掌天地肅殺之權」、丁「為萬物之精，文明之象」）；天象取象与书里给的理由 → R11–R20（雷为阳气之嘘、乙午而生、丙離为日、辛八月建禄白露为霜）；名字之义与方令 → R21、R22，阴阳十日之数 → R23；十干阴阳生死 → 书里按长生十二宫的那一层口径。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「日主为壬而柱见阴木，按 R9 这一类读，偏『畏陰木而為盗氣之憂』」，并带出处（如「《三命通會》卷二·論天干隂陽生死」）。
4. **收口**：这一句是**书里的读法**，不是对这个人命运的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**；体象是「象 + 性」的取象，不坐实成某物象、不当生死判词。

**书里没有的、不要加**：原书不把体象折成「强弱分」或「能量值」，也不给十干两两组合打表；把这些加进来只能标「（补充）」并说明依据。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–6 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 7–8 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **确认问的是哪一个天干、哪一层的取象**（文本解读）　输入：用户的话与所引句子 → 输出：判定落在体象句／天象取象／名字之义哪一层，以及是十干中的哪一个。
   🔴 **CHECKPOINT**：若用户问的是十二支、人元司令、纳音，先说明本 skill 只管天干，转对应 skill，问用户要哪个。
3. **出体象句**（文本解读）　输入：定下的干 → 输出：摆 R1–R10 中该干的原句，标明天象、地象与阳／阴之名。
4. **配天象取象**（文本解读）　输入：体象句 → 输出：摆 R11–R20 中该干的天象句与原句给的理由。
5. **讲名字之义**（文本解读）　输入：用户追问字义或方令 → 输出：R21、R22，再落到 R23 的阴阳十日之数。
6. **给判读口径**（文本解读）　输入：机制 → 输出：说清「凭什么这么取」——象定样子、性定喜畏、方令定字义。
7. **取盘上的料**（落盘）　输入：用户四柱 → 输出：四柱各柱的天干、日主是哪一干、柱中各干落在体象句（R1–R10）的哪一段、天象取象（R11–R20）配哪一象。
8. **逐条核条件、给读法**（落盘）　输入：第 7 步的料 ＋ 本 skill 的条件 → 输出：
   - 该干的体象句与喜畏 → R1–R10；天象取象与书里给的理由 → R11–R20；名字之义与方令 → R21、R22，阴阳十日之数 → R23；十干阴阳生死 → 书里按长生十二宫的那一层口径；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷二·論天干隂陽生死」）。
9. **收口**　输入：整段推演 → 输出：一句可带走的话（该干的天象地象 + 喜畏 + 字义各一句）。
   🔴 **CHECKPOINT**：收口前确认——① 没把体象句当成对某个具体八字日主的断语，也没把「阳生阴死」这类书里的说法落成对某人的生死结论；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格／术语（体象句／天象取象／名字之义）带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把体象当物象套死 | 说甲日主就是栋梁、丙日主就是太阳、命里必有某象 | 拉回 R1、R3：体象是配性与象的取象，不是对具体命的断言 |
| 把「阳生阴死」当生死判词 | 说甲木生在亥、死在午就注定如何 | 拉回本段：这是书里按长生十二宫给的口径，不落到具体人 |
| 混淆「戊土为霞」与「戊土阳土」两层 | 说戊土既是雾又是霞说不通 | 拉回 R5、R15：一层是体象（在天为雾在地为山），一层是天象取象（为霞），两层并列 |
| 拿现代名词给取象背书 | 说甲木「象征生命力」、天干有「能量流向」 | 删掉现代措辞，只按原句讲象与性 |
| 借取象放排盘 | 讲着讲着开始排四柱、判吉凶 | 拉回本 skill 范围，排盘转 bazi-hub |
| 只给泛化词就激活 | 用户说「我属什么」「我生日那天」就论天干 | 泛化词不算；要显式点出天干／日主／体象才接 |

**边界规则**：
1. 只讲十天干的体象句、天象取象与名字之义，不接排盘与批断。
2. 不依据八字给出疾病诊断、寿命预测、生育判断、婚姻决定；书里若有这一类条文，引用时标为「书里的说法」，不落到具体的人身上。
3. 不批流年大运、不断终身。
4. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
5. 体象句、天象取象、名字之义三层要分栏标注，不混成一条。

**自查清单**：
- [ ] R 节每条都标了是体象句、天象取象，还是名字之义。
- [ ] 没把体象答成对某个具体命的断言。
- [ ] 没把「阳生阴死」当成本 skill 对人下的结论。
- [ ] 没引入现代科学名词或现代命理流派术语。
- [ ] 泛化词没有当作触发。

**安全兜底**：涉及就医／用药／危机时，只做提醒与陪伴，不做诊断（见 hub 的安全标记）。

## 练习手册

- **十干一句记**：合上 R 节，给十个天干各写一句「在天为何、在地为何、是阳是阴」，各挂回原句。
- **象与性配对**：把体象句里的天象地象与喜畏分开列，说明为什么取象要配性。
- **天象十配**：把甲雷、乙风、丙日、丁星、戊霞、己云、庚月、辛霜、壬露、癸霖连成一句，各配书里给的一个理由。
- **方令对位**：写出十干按方（东西南北中）与按阴阳（甲丙戊庚壬／乙丁己辛癸）的两套分类，各挂一条原句。

## 反例黑名单

1. 把体象句读成对某个具体八字的断言。
2. 把「阳生阴死」当成对某个人寿夭的判词。
3. 把「戊为雾／为山」与「戊为霞」混成矛盾。
4. 用「能量」「象征生命力」一类现代名词替取象背书。
5. 把体象句、天象取象、名字之义三层的出处混作一层。
6. 用户只说「我属什么」就激活并大谈十干。

## 灰色地带

- **用户问「同一干既有体象又有天象，用哪一个」**：一层定样子（体象）、一层补一个自然现象（天象），两说并存；用户若追问，两说都摆，说清是书里并列的两套取象。
- **「阳生阴死」与「五行同生同死」的说法相冲**：本 skill 只照书里这一层讲——书把十干分阴阳刚柔、按长生十二宫讲生死；别的书里的相反口径不在这里替它调和，遇到就问清用户问的是哪一本。
- **用户问「十干取象和十二支取象能不能拼成一句」**：天干归本 skill，十二支归 bazi-sanming-di-zhi；要拼就分别引两处原句，并说明是两段合看。
- **用户把「在天为雷为龙」当成实指天上有龙**：按 R11 回到原意——「雷者陽氣之嘘也」，是取象的比喻，不是实指。
- **用户要「十干取象 + 顺带断命运」**：十干体象与天象取象照讲，凡涉及断命运的部分不在本 skill 范围内，指回 bazi-hub；要排盘先补齐四柱与出生地，缺一项就不硬排。
