# 納音：六十甲子納音

**来源**：sources/sanmingtonghui.txt（《三命通會》卷一·總論納音、卷一·論納音取象、卷一·釋六十甲子性質吉凶、卷一·六十甲子納音取象） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问六十甲子纳音是怎么定出来的、按什么算。
- 用户问「同類娶妻，隔八生子」是什么意思。
- 用户问「甲子乙丑海中金」为什么会取成海中金。
- 用户问「海中金、爐中火、大林木、路傍土」这一批名目各怎么取象。
- 用户问「纳音取象出自黄帝」这说法书里认不认。
- 用户问纳音（洪範五行）与正五行是什么关系、还能不能用。
- 用户读到「以干為祿定貴賤，以支為命定脩短，以納音為身察盛衰」想问什么意思。
- 用户问「六十甲子性質吉凶」里那句〈為寶物喜金木旺地……〉在说什么。
- **用户给出四柱、问「我这盘纳音怎么看／这盘整体怎么读」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**（看起来像但其实不是）：
- 用户问某一干「在天为雷在地为栋」这类体象或天象取象 → 转 bazi-sanming-tian-gan。
- 用户问十二支各自的体象、名与取象、藏遁 → 转 bazi-sanming-di-zhi。
- 用户问月令里谁司事几日 → 转 bazi-sanming-ren-yuan。
- 用户要排盘、给一组四柱算流年大运吉凶 → 本维度不接流年大运、不断终身。
- 用户只说「我是什么命」「我属什么」这类泛化的话，没有点出纳音／六十甲子／取象等显式请求 → 不激活。

## I：核心解释

这一段讲「纳音是什么、怎么定、怎么取象、还值不值得用」。

1. **纳音的定法**。书引笔谈说：六十甲子纳音本「六十律旋相為宮法」，「一律含五音」，气始于东方而右行、音起于西方而左行，「陰陽相錯而生變化」（R1）。这是把纳音比作乐律的旋宫。
2. **口诀与相生例**。书引「納音之法同類娶妻，隔八生子」（R2），并举相生的例子：「甲子金之仲同位娶乙丑，隔八下生壬申金之孟」（R3）——同位相配、隔八相生，按这个次序把六十甲子的纳音串起来。
3. **另有一套数法**。书又列了几种算法：一说「一六為水，二七為火，三八為木，四九為金，五十為土」（R4）；一说「子午數至庚，丑未數至辛，寅申數至戊，卯酉數至己，辰戌數至丙，巳亥數至丁」（R5），数到七属金、三属火、九属木、一属土、五属水。书把这些放在一起，最后归一句「大抵六十甲子歴也，納音律也，支干納音之別也，此天地自然之數河圖生數也」（R6）。
4. **取象的总原则**。书说黄帝把甲子「分輕重而配成六十，號曰花甲子」，这个「花」字「誠為奥妙」，圣人借意喻之，但「不可著意執泥」（R7）——取象是借意，不是死扣物象。
5. **取象怎么落**。书给的总例是：甲子乙丑「何以取象為海中之金？蓋氣在包藏，有名無形，猶人之在母腹也」（R8）。换一套说法，又按支的旺衰讲：「甲子乙丑子屬水，又為湖，又為水旺之地，兼金死於子、墓於丑，水旺而金死墓，故曰海中金」（R9）。所以取象要在「气之包藏」与「支之旺衰」两头看。
6. **六十字各有名与一段解释**。书把六十四（六十）甲子各配一个名目——甲子乙丑海中金、丙寅丁卯爐中火、戊辰己巳大林木……（R13–R15），每个名目下面另有一段取象的解释（如海中金者「寶藏龍宮，珠孕蛟室，出現雖假於空衝，成器無藉乎火力」，R16）。
7. **十干为何能取成金木水火土**。书专门解释：取象时十干有可以為金、不可以為金的分别，「雖因所值之數不同，而五行類化類從之妙，其理亦不可不知」（R17）——同一个干在某一个甲子名目下可以被当成这一类五行，是因为类化类从。
8. **来历与用法之争**。书替纳音立源：「再按納音取象出自黃帝，故諸術家皆宗之」（R18）；又辩说纳音即洪範五行，「不可舉一廢一」，谈命的人「本之以五行為經，叅之以納音為緯」，才能尽命数之理（R19）。另有一段讲禄命身：「以干為祿定貴賤，以支為命定脩短，以納音為身察盛衰」（R10）——这是书里给纳音定位的一句，属于书里的说法。
9. **性质吉凶别录一段**。「释六十甲子性质吉凶」把每个甲子配一句断语式的夹注，如「甲子金」下注「為寶物，喜金木旺地，進神，喜福星、平頭、懸針、破字」（R11、R12）——这是书里并列的评价语，读的时候要标明是书里的说法。

## A1：来源应用

书上给的读法，分几段落地：

- **定纳音**：先按书里的律法（R1–R3）或数法（R4–R5）说清「这个甲子的纳音是金／木／水／火／土」是怎么来的，并标出「六十甲子历也，納音律也」（R6）这层分别。
- **取名目**：按六十甲子的名目表（R13–R15）给出该甲子的名（海中金、爐中火、大林木……）。
- **讲取象**：取象从两头讲——一头是气之包藏（R8 的「有名無形，猶人之在母腹」），一头是支之旺衰（R9 的「金死於子墓於丑」）；每个名目下面另有一段的解释（R16）。
- **辨十干取象**：遇到「某干为何能取成某五行」，按 R17 说清是类化类从，不是本行。
- **定位与读法**：要交代位置，按 R10（禄命身）、R18–R19（出自黄帝、与洪范五行不可举一废一）来说；并提醒 R7 一句「不可著意執泥」。
- **一句可带走**：纳音 = 六十甲子各配一个乐律式的五行名，取象要在气与支两头看，借意而不死扣。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：四柱各柱的干与支、按名目表（R13–R15）定出的各柱纳音、日干（禄命身三分里以干为禄、以支为命、以纳音为身）。
2. **逐条核书里的条件**：该柱纳音的取象两头，气之包藏 → R8「有名無形，猶人之在母腹也」，支之旺衰 → R9「金死於子墓於丑」；纳音在禄命身里的位置 → R10「以納音為身察盛衰」；经与纬这层分别 → R6「六十甲子歴也，納音律也」；与洪范五行的用法 → R19「不可舉一廢一」，以五行为经、纳音为纬。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「日柱纳音为身而气在包藏，按 R8 这一类读，偏『有名無形』」，并带出处（如「《三命通會》卷一·論納音取象」）。
4. **收口**：这一句是**书里的读法**，不是对这个人盛衰的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**；取象是借意，不坐实成某物象。

**书里没有的、不要加**：原书不把纳音折成吉凶分数，也不给「纳音组合表」；这些加进来只能标「（补充）」并说明依据。书里那批「大貴」「贫夭」类的断语属于书里的评价语，引用时要标明。

## A2：典型触发场景

1. 用户第一次读到「甲子乙丑海中金」，想知道这名字怎么来的。
2. 用户问「同類娶妻，隔八生子」这句口诀怎么算。
3. 用户问「納音取象出自黃帝」是不是真的、书里怎么说。
4. 用户问某一个甲子（如丙寅丁卯）为什么取成爐中火。
5. 用户问纳音和正五行（子平用的五行）是什么关系、还值不值得看。
6. 用户读到「以納音為身察盛衰」，想知道纳音在禄命身里算哪一件。
7. 用户问「六十甲子性质吉凶」里那些「喜金木旺地、進神」的夹注在说什么。
8. 用户问「海中金者寶藏龍宮珠孕蛟室」是不是在说海里有龙宫。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把取象当实指 | 说海中金就是海里有金、爐中火就是炉子里真有火 | 拉回 R7、R8：取象是「借意」比喻，「不可著意執泥」 |
| 把书里的评价语当断语 | 照抄「大貴」「贫夭」当成对某人的判决 | 标明这是书里的说法，不落到具体的人身上 |
| 把纳音当成唯一标准 | 说只看纳音五行、正五行可以废掉 | 拉回 R19：与洪范五行「不可舉一廢一」，以五行为经、纳音为纬 |
| 把数法当唯一算法 | 只拿「子午数至庚」一套去算，忽略律法 | 拉回 R1–R5：书里并列了律法、数法等几套，标明来源 |
| 把纳音折成分数 | 算出「纳音强度 0.3」这类值 | 删掉现代算法，只按原句讲 |
| 只给泛化词就激活 | 用户说「我是什么命」就论纳音 | 泛化词不算；要显式点出纳音／六十甲子／取象才接 |

**边界规则**：
1. 只讲纳音的定法、取象、名目表、性质夹注与来历，不接排盘与批断。
2. 不依据八字给出疾病诊断、寿命预测、生育判断、婚姻决定；书里若有这一类条文，引用时标为「书里的说法」，不落到具体的人身上。
3. 不批流年大运、不断终身。
4. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
5. 律法、数法、取象、性质夹注几层要分栏标注，不混成一条。

## 练习手册

- **一甲一名**：任挑三个甲子，按 R13–R15 写出它们的纳音名，各配一句该名目下的解释。
- **口诀拆解**：把「同類娶妻，隔八生子」拆成两个动作各写一句，并用 R3 的例子说明。
- **两头取象**：挑「甲子乙丑海中金」，分别按 R8（气之包藏）与 R9（支之旺衰）讲一遍取象理由。
- **经与纬**：把「本之以五行為經，叅之以納音為緯」用自己的话讲一遍，说明纳音在书里是什么位置。

## 反例黑名单

1. 把海中金、爐中火这类取象当实指。
2. 把「大貴」「贫夭」这类书里的评价语当成对某人的断语。
3. 说只看纳音、正五行可以废掉。
4. 把某一家数法当成六十甲子纳音的唯一算法。
5. 把纳音折算成「强度」「分数」这类现代数值。
6. 用户只说「我是什么命」就激活并大谈纳音。

## 灰色地带

- **用户问「纳音到底还准不准、要不要看」**：不写自我否定腔，也不写兜售腔；只摆书里的两说——R18、R19 主张纳音与洪范五行不可举一废一，又以五行经、纳音纬来用；判断留给用户。
- **律法与数法结果不一致时**：书里并列了律法（R1–R3）和数法（R4–R5）；照实说这是书里并存几套定法，不替书里判定哪一套为准。
- **一个甲子有两套说法（气之包藏 vs 支之旺衰）**：两说并存，都摆；说明是书里从两头讲取象，不硬合。
- **用户把纳音之「身」与日主搞混**：按 R10 回到原意——书里「以納音為身」是禄命身三分里的一件，不替书里认后世日主的那一套；两处口径不同，照实说。
- **用户要「纳音 + 顺便断我一命」**：纳音照讲，断命部分照实说本 skill 不接，转 bazi-hub，并说明缺什么信息（年、月、日、时、出生地）就不能排。
