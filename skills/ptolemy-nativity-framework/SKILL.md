# 论命总纲：起源、上升度数与"五步取用"

**来源**：《Tetrabiblos》BOOK THE THIRD, CHAPTER I「PROEM」、CHAPTER II「THE CONCEPTION AND THE PARTURITION, OR BIRTH」、CHAPTER III「THE DEGREE ASCENDING」、CHAPTER IV「DISTRIBUTION OF THE DOCTRINE OF NATIVITIES」（Ptolemy，Ashmand 英译本）｜ 证据等级：firsthand

## 触发条件

**数据前提**：本 skill 属「象征」层，必须先有出生信息（出生日期、时间、地点，足以排出星盘）才谈得上解读；没有出生信息时只能复述书上的规则本身，不能对着具体的人下任何推断。全篇不写成命定论——这套方法给的是"取用与描述的顺序"，不是对人生的断言。

**应该触发**：
- 用户拿出（或愿意提供）出生日期、时间、地点，说"按托勒密这一路给我读一张盘"
- 用户问"一张星盘该从哪读起、先看什么、宫位怎么定"
- 用户问"我出生时间记不准／不确定，盘还能不能用"
- 用户要按主题问事（父母、兄弟姐妹、性情、身体…），想知道"每个主题该看哪个宫位、由哪颗星主管"
- 用户问"这套占星到底凭什么算、它的依据是什么"

**不应触发**：
- 用户只是要某个具体主题的解读 → 直接进对应主题的 skill（`ptolemy-kin-significations`、`ptolemy-birth-circumstances`、`ptolemy-lifespan-prorogation`、`ptolemy-body-and-disease`、`ptolemy-mind-quality-and-disorder`）
- 用户要的是"星座到底是不是迷信"这类立场之争 → 不是本 skill
- 用户要按别的体系解读（中国四柱、现代心理占星等）→ 不是本 skill（本维度只走托勒密《Tetrabiblos》）
- 用户既没有出生信息、也不打算提供，只想聊占星八卦 → 只讲规则，不进入取用

## I：核心解释

1. **一套因果，两类事件**：普遍事件（战争、灾荒、城邦之变）与个人事件（命主一生）的因果"本质上是同一个"，都来自日月与行星的运动；差别只在寻找"起点"的方式——普遍事件起于日月食与行星的显著过境，起点多而杂；个人事件只有一个起点，就是"被造的肉身"。（R1、R2）
2. **起源只有一个：受孕还是出生**：按书里，受孕时刻是"人的种子"这一意义上的开始，出生才是"人本身"的开始——婴儿出生时才获得感官动作、身体与四肢的运动等只属于人性的品质。所以查不到受孕时刻时，以出生时刻为始完全成立，而且在效力上"与受孕相等、甚至更完整"。若能确知受孕时刻，可用来补推先天的体质与心性，因为它只关涉"出生之前"的事。（R3、R4）
3. **上升度数的推定**：古代的计时工具（水钟、日晷）不可靠，所以书里给了一套从"常规上升度数"回推"真正上升度数"的方法：取分娩前最近的一次新月或满月，锁定那个度数；再看哪些行星凭"三重性、宫位、擢升、界、相"这五项权利主管它；以那颗主管行星在分娩时所落的度数，来校正真正的上升度数。这一做法后世专称『上升度数校正法』。（R5、R6）
4. **五步取用**：任何主题都先定位——① 这个主题对应黄道上哪个"宫位"（例如中天对应事业、太阳的位置对应父亲）；② 谁凭那五项权利主管该宫位，谁就是该事件的主星，多人主管则取权利最多者；③ 主星与宫位所在星座的"性质"决定事件长什么样；④ 主星的"力量强弱"决定事件有多强（宇宙层面：在自家位置／东出／顺行＝强，不在自家位置／西没／逆行＝弱；星盘层面：在角宫或续宫＝强，从角宫退落＝弱）；⑤ 主星相对太阳与上升的晨出/昏没、在角宫还是续宫，决定事件发生时间的早晚。（R8–R12）
5. **只认"可循的因果"**：书里明确把"抽签与数字"这类"不受任何系统因果支配"的占法排除在外。也就是说，这套体系自称有一条可以复述、可以追查的因果链，不是任意起卦。（R13）
6. **靶与射手**：书里把被赋予主题的"宫位"比作靶，把行星的实际效力与"看盘者的判断"比作射手方向——规则之外还留了一层"综合判断"的位置，不是套公式出结论。

## A1：来源应用 — 书里给的具体做法

- **起源的选择**：受孕时刻可考时，取受孕时的天象推先天体质与心性；不可考时，以出生时刻为始。（第三卷第二章）
- **上升度数的推定（上升度数校正法）**：先按"上升的度数表"定常规上升度数 → 取分娩前最近的新月或满月（新月取日月合相之度，满月取分娩时在地平线以上的那一个发光体之度）→ 看哪些行星以 三重性／宫位／擢升／界／相 五项权利主管该度数 → 唯一合格者，取它在分娩时所落的度数，其"数字"即真正上升的度数；若有两人以上同样合格，取与常规上升度数最接近者；仍相等，则取与角宫关系更强、自身状态更好者。又：若那颗行星到常规上升度数的距离，大于它到常规中天度数的距离，则应把所得数字记到中天，其余角宫随之调整。（第三卷第三章）
- **主题的宫位分配**：出生之前的情形＝父母；出生前后都有＝兄弟姐妹；出生当时及随即＝男女性别、孪生、畸形、能否养育；出生之后＝寿命、体格、身体的伤病、心性与心智疾病、财富与荣显、职业、婚姻与子嗣、朋友、旅行、死亡的方式。（第三卷第四章）
- **五步取用**：先在黄道上定位主题对应的宫位，再取主星，再看主星与宫位所在星座的性质，再看主星力量的强弱，最后看主星相对太阳与上升的晨昏、角宫或续宫，以定时间早晚。（第三卷第四章）
- **不越界**："抽签与数字"一类不受系统因果支配的占法，书里明说弃置不谈。（第三卷第四章）

## A2：典型触发场景

## 输出纪律

**用户面上不得出现任何元话／内部指涉**（单列的一条硬规则，任何一步判读都受它约束）：写给用户的回答里，**不得出现"本 skill""这套系统""那一卷""我在读的那本书""根据本文件""按本文档规定"这类指回解释者自身的说法**；也不得向用户解释自己的规则、不得引书名／卷章名／作者名。要引据时，只用**一行白话**把倾向指回书上那一类（如"书上把这类归成……"），不报书名章名；要交代局限时，直接说用户听得懂的处境（如"手里没有你的盘可算"），**不说"本 skill 没接排盘工具"这类内部话**。判读只说用户这件事与书上那一类征象，全程不出现解释者、系统、文件、卷册的痕记。**同理，答案里不得出现方括号占位符**——本文件用成对方括号圈出空位来标记模板，写时要把那个空位直接用白话填上，不得把带方括号的记号原样写出去。**也不得替用户读心或替他预设结论**：不写“你早就觉得……”“你心里其实……”这类替他认定动机、替他讲出他没说的话的句子；他自己给的几条，只能把“它们像不像同一件事”交回他自己核，不得替他下“这几条多半指向同一个地方”这类推断。

## E：执行步骤

### 步骤1：确认数据与层

**输入**：出生日期、时间（越精确越好）、地点；以及用户想问的主题。
**输出**：一句"数据够不够读、要不要先校正上升度数"的判断。
**CHECKPOINT — 触发条件：用户完全没有出生时间，连大致时段都没有**：说明书里的上升度数校正也依赖"分娩前最近的新月/满月"，缺少时间就只能讲规则、不给具体判断；不要凭空替他定盘。
**CHECKPOINT — 触发条件：本环境没有真实排盘手段（无出生时间地点，或没有排盘工具／权威数据）**：**本 skill 不自带排盘，也绝不虚构盘面配置**（若环境有 Python：照 `docs/排盘与星历.md` 用**国内镜像** `python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pymeeus` 装库、跑 `tools/paipan.py` 取真盘；**有真盘才可报具体配置**。拿不到真盘，按下文降级）。此时只用用户讲述的**行为/经历**做判据（如"你在什么时刻最有劲"），给**读法层面的倾向**（"这类倾向在书上对应哪一组征象"），**不得报出任何具体的盘面配置**（如"你的中天落在水性""土星在摩羯"这类具体断言），除非那是用户自己提供或可验证的。若用户确要做盘面判读，先说明"需要先有真实排盘（出生时间地点 + 排盘工具／权威数据）"，把这个前提摆到面上再谈。**但"只给读法层面的倾向"有下限**：仍须用**一句白话**把倾向指回书上那一类（只给类别、不堆术语），**不得只把用户自己的行为/经历换句话复述当作判读**（见步骤6 硬要求1"文本锚点下限（一行白话）"）。

### 步骤2：定起源

**输入**：是否有可确知的受孕时刻。
**输出**：一个明确的"以出生为始"或"以受孕为始（并注明只用于出生前）"。
**CHECKPOINT — 触发条件：用户想用受孕时刻去推出生之后的发展**：按书，受孕起源只提供"出生之前"的推断，超出即越界。

### 步骤3：推定上升度数

**输入**：常规上升度数 + 分娩前最近的新月/满月度数 + 各行星在那五个权利上的归属。
**输出**：校正后的上升度数（或"无法校正，停在常规上升度数"的说明）。
按第三卷第三章 的流程逐步走，多人合格时按"数字最接近 → 角宫关系最强"排序。
**CHECKPOINT — 触发条件：查不到新月/满月的度数，或无法确定谁主管**：停在常规上升度数，并明确标出"未校正"，不得假装校正过。

### 步骤4：定位主题宫位并选出主星

**输入**：用户想问的主题。
**输出**：该主题对应的宫位 + 主管该宫位的行星（主星）。
按第三卷第四章 第一步、第二步执行；主星取权利最多者。
**CHECKPOINT — 触发条件：用户问的主题属于别卷（职业、婚姻、旅行、死亡方式等）**：只做"定位"，不越界解读，把解读交给对应卷的规则。

### 步骤5：出"性质—强弱—时机"三层

**输入**：主星与宫位所在星座、主星的力量状态、主星相对太阳与上升的位置。
**输出**：一段"事件性质 / 力量大小 / 时间早晚"的三层描述。
按第三卷第四章 第三步到第五步执行。
**CHECKPOINT — 触发条件：用户要求"断定一定会发生"**：守住边界——这是"读盘的取用顺序与描述框架"，不是保证；把它当作古代体系的读法，不是对现实的判决。

### 步骤6：把判读落到用户这件事上（结论先行 → 判据一行一条 → 一个动作 → 边界一句）

**输入**：步骤4定位的主题宫位与主星 + 步骤5的"性质—强弱—时机"三层 + 用户的现实处境（本例：学的是心理学、在体制内做行政、想弄清"到底该做什么"）。
**输出**：一段**结论先行**的短判读 + 3–4 条用户能自己核对的**一行一条**判据 + 一个能打勾的动作 + 一句边界。
**硬要求（缺一不可，且必须放在任何反问、转出之前）**：

1. **结论先行（2–3 句，不逐层报账）**：第一段直接给出这一次的判读——这件事在这套读法里看叫什么、倾向是什么。以职业取向为例：把"中天"主星的性质与强弱收成一句大白话——例如"这套读法把你的职业取向读成：你更被那种‘自己拿主意、看得见成果’的活吸引，这股劲在你身上偏强"。措辞用"偏向／更像／倾向于"，不用"一定／必然／命中"。
   - **禁止六步流水**：不得把"位置→主星→星座→性质→强弱→时机"逐层报账写给用户看。那条取用链是**内部推演**，用户面上只出现结论与判据；确需交代依据时，最多半句带过（如"按其主星的性质看"），不展开。
   - **文本锚点下限（一行白话即可；无真实排盘时同样适用）**：**即使没有真实排盘，判读也必须用一句大白话，把这条倾向指回书上那一类**——写成"这在书上归那种爱掌控、看得见成果的一类"这种口气：用日常词说清是哪一类，**只给类别、不报任何具体配置**（不写"你的中天落在水性""土星在摩羯"这类具体断言）。**全篇至多一处锚点、至多一句**；**禁止为凑锚点而堆术语**——不得把一长串生僻术语串在一起，不得引书名／章名／拉丁词，不得与中式命理名词并排。**不得只把用户自己的行为/经历换句话复述当作判读——复述不是判读**；判读要落到书上可指认、又能用白话讲清的那一类上。缺了这一条，本步判读即失败。
2. **硬抓手：≥2 条可对核的对照 + 一行一条判据（缺了算没给抓手）**——**治"抓手不多／偏通用"的关键一条**：
   - **先给 ≥2 条对照**：每条都写成**他能拿自己最近的具体经历去对**的形式——一组二选一（或几选一）的具体处境，要他"各想一件最近的事，各写一行"，而不是只给一句能点头的泛描述、也不是只有一个"是／不是"的空判据。例：「你更有劲的时候，是"我自己定怎么干"，还是"别人定我执行"？——两种各想一件最近的事，各写一行。」对照必须落在他真做过的事上、带可指认的细节（什么时候、在做什么），能二选一，也说得出"不对"。
   - **再给判据（3–4 条，与对照可互相覆盖）**：每条 ≤ 一行，格式固定为——`如果你【是……】→ 这条倾向成立；如果【不是……】→ 这条不成立。`现象取自用户自己的生活（"你在……的时候会……""你更常……而不是……"），交给他自己核对；不符的也照实写，不替他下判断。
   - **只给泛描述或空洞判据、没有一条能让他拿经历去对，本轮判读即失败**。
3. **一个动作（今天／本周真能做完、有可指认产出）**：一件今天或这周能做、有明确时间边界、能打勾的**具体**小事，且要**对接上面某一条对照**——例如"把这周你最有劲的那个下午记下来（几点、当时在做什么，一句话），本周内拿这句话去问一个熟你的人：‘你看我那时候是在干哪一类活？’"。不写"去追随你的热爱"这类无法打勾的话，**也不得只落成"记三条""想一想"这种通用动作**——记几条不是产出，"记完拿它去做什么"才算，动作里必须有一个具体去处。
4. **边界一句（收束）**：把上面说完之后再说——这套读法只帮你把这件事读清楚、给你一把自己核对的尺子，**不替你决定**走哪条路、选哪份工作。这句只能放在判读之后，不得拿它顶替判读本身。
5. **不虚构盘面（本条只禁"报配置"，不禁"给文本锚点"）**：本 skill 不自带排盘（有 Python 时照 `docs/排盘与星历.md` 用国内镜像装库、跑 `tools/paipan.py` 取真盘，有真盘才可报配置）。用户没提供、本环境也没有真实排盘手段时，**只**用他的**行为/经历**做判据、只给"读法层面的倾向"（"这类倾向在书上对应哪一组征象"），**不得报出任何具体盘面配置**（如"你的中天落在水性""土星在摩羯"）；若要做真正的盘面判读，必须先说明"需要先有真实排盘（出生时间地点 + 排盘工具／权威数据）"，把这个前提摆到面上再谈。**注意**：不打具体配置**不等于**可以不落文本锚点——无真实排盘时仍须按硬要求1 的**文本锚点下限（一行白话）**，用一句白话把倾向指回书上那一类（只给类别），**不得退化成复述用户自己的经历**。
6. **不给"值不值得"的价值裁决**：可以给处境判断与倾向（措辞用"偏向／更像／倾向于"，如"这类处境下……"），但**不说"这值得你争""你应该去／留"**这类替用户下价值结论的话；值与不值交还给用户自己判断。

**不得拿“没有真实排盘”当托辞**：交代前提（需要真实排盘）至多半句带过；即便手里没有盘，本轮判读仍必须按硬要求2 给足 **≥2 条可对核的对照**、按硬要求3 给一个**今天／本周能做完的具体动作**。把“排不出盘”当成本轮少给抓手的理由，算失败。

**长度硬上限**：这类回答的**正文目标 ≤ 800 字**。理由：越是象征层，越不能靠术语堆叠显得专业；超标时先删的是解释性铺陈，不是判读本身。

**禁止伪精确**：
- 不得把象征层的读法说成"可算出的结论"（如"盘算出你适合做心理咨询"）；一律写成"这套读法把它读成……"。
- 不得凭盘给性格/能力下"你就是……"式断言；只给倾向，不给能力定论。
- **不得虚构盘面**：没有真实排盘就**不报任何具体配置**（落宫、星座、宫位状态等），只讲"读法层面的倾向"，别用"中天在×、某星在×座"这类具体断言冒充读盘；需要盘面判读时，先摆出"要先有真实排盘"这一前提。
- **不得把"不报配置"退化成"复述用户经历"**：没有真实排盘时，判读仍须按硬要求1 的**文本锚点下限（一行白话）**，用一句白话指回书上那一类（只给类别、不堆术语）；把用户自己的话换一种说法讲回去，不算判读。
- **不得替用户做价值裁决**：不给"值不值得、该不该"的结论，只给处境判断与倾向。

**CHECKPOINT — 触发条件：用户问的主题属别卷（职业、婚姻、旅行、死亡方式等）**：仍要在本步把"总纲层面的取用"在**内部**真正跑完（定位→主星→性质→强弱→时机），再按上面四条**结论先行**地给出判读；别卷细节结论与安全敏感判断（健康、寿数等，按边界规则第 6 条处理）留给对应 skill，并让用户知道更细的部分还能另作一读。不得以"这属别卷"为由，把落点缩成"我不能答"。

### 步骤7（分支）：用户不信这套 / 没有可用出生信息时的落点

**触发**：用户明说"我不信这些／这是迷信"，或始终拿不出可用的出生信息，却仍抛出"你觉得我的人生还有没有别的可能"这类**抽象**问题。

**这类回答不许这样收尾**：不得以"你可以自己选""人生有无限可能""相信你自己""跟随内心""路在你自己脚下"这类**通用鸡汤**代替抓手——那等于说教，是本 skill 明令禁止的失败形态（见反例黑名单第 6 条）。

**输出（硬要求，缺一不可，且必须放在任何反问、转出之前）**：
1. **先正面接住问话（1–2 句，不得绕开、不得只谈方法，更不得替他定性内心）**：回答开头必须先直接回应他真正抛出的那两件事——① "我的人生还有没有别的可能"这个问法本身值得被认真对待（承认他问的是一个真问题，不是一句搪塞或客套）；② "我妈非要我算"背后是关系压力（承认这个请求不完全是他的，里面夹着另一个人的期待和催促）。这两句要**正面接住**，**不得跳过、不得绕开、不得只谈"按书里的方法怎么读"**；接住之后才进入下面的结论与抓手。**接住 ≠ 替他定性内心**：不得写"你早就觉得有东西没被算进去""你心里其实早就不信"这类**替他认定动机、替他讲出他没说的话**的句子——他抛出来的只有那两句问话，回答就只接那两句，不替他补内心戏。
2. **明说能给他什么、不能给他什么，并下判断（2–3 句，不得只把问题弹回去）**：接住之后，第一段直接**下判断**——**给不了**：不替他证明有"另一种人生"的安排、**不保证、也不推翻**他"不信"这个立场（信不信是他自己的事，我不替他定）；**能给的**：把一件他其实反复在做、却一直没当回事的事摆到明处，让他自己看那是不是"另一种可能"的线索。不逐层报账、不排盘、不报任何盘面配置。
3. **三条抓手：各换句式、不成清单、不预收结论**：把"我的人生还有没有别的可能"这类抽象问题，落成 **2–3 条他能自己核实的具体变量**，但**绝不能写成一张模板化清单**——不是把同一句"能指到就成立／只说得出一团模糊就不算"复制三遍，也不是排成"①…②…③…"的逐条打勾表。三条必须**各问一个不同侧面、各换一种问法**，**不得三条都用一个反问句、也不得三条都是"最近一次……是几点／在哪儿"这种同一形状**：
   - 问**具体场景**（"那个觉得能不一样的当下，你说得出是几点、在哪儿、正在做什么吗？"）——最近一次"觉得可以不一样"的当下，几点、在哪儿、正在做什么、下一秒怎么被拉回原样；
   - 问**他推掉的事**（"这阵子有没有哪件事，你因为不信这个就推了？当时你怎么回绝的？"）——因为"不信这个"而具体推掉的机会或动作，谁提的、拿什么理由回绝；
   - 问**某个具体时刻**（"最近一次想起你妈这个要求，是什么时候？"）——是她开口的当下、半夜睡不着，还是别人问他"以后打算"的时候。
   **三条问完必须紧接一句收束**，但这句话**只能是"把联想交回他自己核"的问法**（"这三条你自己摆一起看，像不像在说同一件事？"），**不得替他下"这三条多半指向同一个地方"这类预设结论**——像不像同一件事，由他自己判断。**不得**三条问完就断、把三条干晾在原地当清单，也**不得**替它们收成一个替他定的结论。
   （上列是三条各自要问到的侧面；措辞随用户的具体处境变，但不得退回同一句式，也不得用"你可以自己选""人生有无限可能"这类通用鸡汤代替。）
4. **一个能打勾的动作（落在今天／本周真能做完的一件事，不是"记三条"）**：动作必须是**今天或本周就能真正做完、有可指认产出**的一件小事，并**对接前面某一条抓手**——例如"挑上面第一条里那个时刻，把当时在做什么写成一句话发到自己的备忘录；本周之内，拿这句话去问一个信得过的人：‘你看我那时候，是在干什么？’"。**不得是"想一想""感受一下"这类无法打勾的虚动作，也不得只落成"记满三个打个勾"这类通用动作**——记几条不是产出，"记完拿它去做什么"才算；动作必须带明确的时间边界和一个**具体的去处**，不是"继续观察""慢慢体会"这类空话。
5. **边界收束（一句）**：保留现有边界——不排盘、不报任何盘面配置、不替用户决定、不说"值不值得"、不说"该不该信"；把"要不要信、要不要算"还给他自己。这句只能放在判读之后，不得顶替判读本身。

**长度硬上限**：本分支正文同样 **≤ 800 字**；超标先删解释性铺陈，不删抓手与动作。

**CHECKPOINT — 触发条件：用户要求本 skill 对"信不信占星"下结论**：守住边界——本 skill 只讲托勒密文本的取用方法，既不替占星学辩护、也不证伪；把落点收回到"他自己能核实的变量"上。

### 边界规则

1. **需要出生信息**：本 skill 属象征层，出生日期、时间、地点是硬前提；缺一样就降级为"讲规则"。
2. **起源规则要守**：受孕起源只推断"出生之前"的事，出生起源覆盖此后的一切。
3. **不写成命定论**：书里给的是取用与描述的框架；本 skill 呈现为"古代文本如何组织读盘"，不是对个人命运的判决。
4. **不越卷**：第三卷第四章列出的主题分属不同卷；本 skill 只负责"总纲与取用顺序"。
5. **体例统一、不与其它体系混用**：本 skill 只走托勒密《Tetrabiblos》的口径，不掺入其它占星或命理体系。**全篇只说一种话**——术语一律用中文（宫位、主星、三重性、擢升、界、相、角宫、续宫、晨出、昏没），不把中、西两套术语并列展示；正文引用卷章一律写中文（第三卷第一章，等等），英文卷章名只保留在 R 节引文里。**用户用中式出生信息（如农历生日、节气）时**，只把它当作出生时刻的数据来源，**不得在回答里把西式占星名词与中式命理名词并排摆出来**。
6. **安全兜底**：涉及健康、寿命、心理状态的主题，一律转对应主题的 skill，并按其安全标记处理（🏥 涉及健康一律不作医疗判断、不替代就医；寿数只作古代文本记录，不作断言）。
7. **不虚构盘面（配下限：须给文本锚点）**：本 skill 不自带排盘（有 Python 时照 `docs/排盘与星历.md` 用国内镜像装库、跑 `tools/paipan.py` 取真盘）。没有真实排盘（出生时间地点 + 排盘工具／权威数据）时，只用用户的行为/经历做判据、只给读法层面的倾向，绝不报出任何具体盘面配置；要做盘面判读须先把"需要真实排盘"这一前提摆到面上。**这一条是"报配置"的禁令，不是"给锚点"的豁免**：无真实排盘时，判读仍须按步骤6 硬要求1 的**文本锚点下限（一行白话）**，用一句白话指回书上那一类（只给类别、不堆术语），**不得只把用户自己的经历换句话复述当成判读**。
8. **不给价值裁决**：可以给处境判断与倾向，但不替用户下"值不值得、该不该"的结论，把价值判断交还给用户。

## 📖 练习手册

**画取用骨架**：拿一张盘，只填表——主题 / 对应宫位 / 主星 / 主星力量 / 时间线索。不给结论，先把骨架摆出来。

**校一遍上升**：按第三卷第三章 的次序，把常规上升度数、新月或满月度数、五项权利的主管行星逐条写下来，看自己会不会在中途"想当然"。

**溯源一句**：从 R 节任挑一句，写下它在自己的话里是什么意思，再回头核对书里的原意。

## 🚫 反例黑名单

1. **没有出生信息就替人"读盘"** → 🛑 先要数据，否则只讲规则。
2. **把常规上升度数当成真正上升度数** → 🛑 该校正就校正，不能假装。
3. **用"抽签、数字"补足依据** → 🛑 书里明确弃置。
4. **把框架读成宿命** → 🛑 这是古代文本对"读盘顺序"的组织，不是对个人的判决。
5. **越卷解读** → 🛑 只做总纲与定位，具体主题交给专门 skill。
6. **用通用鸡汤代替具体抓手** → 🛑 "你的人生有很多可能，关键在于你自己选择""你可以自己选""相信你自己""跟随内心"这类话若用来**代替具体抓手，就等于说教**；对"不信这套／没有可用出生信息"的用户问"我的人生还有没有别的可能"，必须落成 **≥2 条用户能自己核实的具体变量**（如"最近一次觉得可以不一样的具体场景""因不信这个而拒绝过的具体机会""哪些具体时刻会想起母亲的要求"）+ 一个能打勾的动作（见 E 步骤7）。该分支另有**三条同属此处的硬要求，缺一即失败**：① **回避问话、只谈方法** → 开头必须先正面接住"还有没有别的可能"与"我妈非要我算"背后的关系压力（1–2 句），不得绕开、不得只谈方法；② **三条抓手写成模板化清单** → 三个抓手不得全写成"能指到就成立／不算"、也不得排成"①…②…③…"的逐条打勾表，必须**各换句式**（一条问场景、一条问拒绝过的事、一条问具体时刻），且三条问完必须紧接一句"这三条摆在一起能看出什么"的收束；③ **打卡没有去处** → "记满三个打勾"之后必须带一个具体下一步（摆在一起看共同点／拿一条去问一个人／下周带着三条回来再看）。

7. **为满足锚点而堆术语** → 🛑 为了凑"文本锚点下限"，把一长串生僻术语／书名章名／拉丁词塞进一句、或与中式命理名词并排展示，读起来像术语清单。锚点**一行白话**即可（"这在书上归某一类那一类"），**全篇至多一处、至多一句**；**宁可只说一类，不要串词**（见 E 步骤6 硬要求1）。

8. **泻出内部话／元话** → 🛑 回答里写"本 skill""那一卷""我在读的那本书""按本文档规定"这类指回解释者自身的说法，或向用户解释自己的规则、报书名章名。用户面上只出现他与书上那一类征象：引据只说"书上把这类归成……"，交代局限只说"手里没有你的盘可算"（见"输出纪律"）。

9. **替用户读心／替他预设结论** → 🛑 不得写"你早就觉得……""你心里其实……"这类替他认定动机、替他讲出他没说的话的句子；他自己给的几条，只能把"像不像同一件事"交回他自己核，不得替他下"这几条多半指向同一个地方"这类推断（见"输出纪律"、E 步骤7 硬要求1、3）。

10. **判读没有硬抓手／动作落成通用招** → 🛑 判读除一行白话锚点外，必须给 **≥2 条他能拿自己最近的具体经历去对的对照**（各写一行），缺了等于没给抓手；结尾动作必须是**今天／本周真能做完、有可指认产出**的一件事（带具体去处），**不得只落在"记三条""想一想"这类通用动作上**（见 E 步骤6 硬要求2、3，步骤7 硬要求4）。

11. **答案里出现方括号占位符** → 🛑 本文件用成对方括号标出模板空位，用户面上**不得出现方括号**；把空位直接用白话填上（见"输出纪律"）。

### 灰色地带（需谨慎判断）

9. **出生时间只有整点**：能做"粗略定位"，但要在每一步注明误差；越靠近角宫的判断越不可靠。
