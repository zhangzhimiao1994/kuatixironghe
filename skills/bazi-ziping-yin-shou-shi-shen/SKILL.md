## I：核心解释

篇 35–38 接着正官与财往下走，是《子平真詮》「十神分论」的第二段：印綬一路、食神一路，各分「论本神」与「论取运」两篇。它讲的是**这两路在月令取用里怎么立、身与印食谁欠谁、怎么成格**，不是给某个人下判词。每一条都能追回上面的原句。

1. **印綬先立「生身」这一义**。「印绶喜其生身」（R1）——印是生我的，所以喜。紧跟着一句是本书的立格总纲：「**正偏同为美格，故财与印不分偏正，同为一格而论之**」（R1）。这一句是《子平真詮》的取法特点：它把正印、偏印合成一格来论，不与偏正立两套名字。
2. **印透官的两用**。「有印而透官者，正官不独取其生印，而即可以为用，与用煞者不同」（R2）。印格见官，官不一定只当「生印」的配角，本身也可取为用——这是印与官并见时本书给的读法。
3. **身旺印强不算太过**。「身旺印强，不愁太过，只要官星清纯」（R3）。凡格常忌太过，本书独在印格上说身旺印强不愁——因为印有其正当用处（生身、护官），只要官星清纯便成立。
4. **印旺可泄秀、印浅则寒贫**。「有印而用伤食者，身强印旺，恐其太过，泄身以为秀气」（R4）；反过来「若印浅身轻，而用层层伤食，则寒贫之局矣」（R5）。书里给的分寸是：印旺有余才拿伤食来泄，印浅身轻再加伤食就只有出没有入。这里的「寒贫之局」是书里的评价语。
5. **印多可以权用财，印轻则忌破印**。「有印多而用财者，印重身强，透财以抑太过，权而用之，只要根深，无防财破」（R6）；「若印轻财重，又无劫财以救，则为贪财破印，贫贱之局也」（R7）。同一本书里，财对印有「抑太过」与「破印」两种读法，判据在**印重还是印轻**——这是本书在印财关系上的分水岭。
6. **印取运的总法**。「印格取运，即以印格所成之局，分而配之」（R8）。与正官取运一样，取运只按「所成之局」分而配之，是**大略之法**，不到某一个盘就不落具体某年。
7. **食神先系在生财上**。「食神本属泄气，以其能生正财，所以喜之。故食神生财，美格也」（R9）。食神本是泄我之气，书里认它可用的理由很明确——能生正财。「财要有根，不必偏正叠出，如身强食旺而财透，大贵之格」（R10），又给食神生财一条的成立条件：财要有根、身强食旺而财透。
8. **食神忌印、忌官都有例外**。「至于食神忌印，夏火太炎而木焦，透印不碍」（R11）——食神忌印是一般，夏火太炎、木已被焦时，透印反不碍事。「食神忌官，金水不忌，即金水伤官可见官之谓」（R12）——食神忌官也是一般，金水一路不忌。本书讲食神的忌，**是带条件的忌**，不是一刀切。
9. **食神取运的总法**。「食神取运，即以食神所成之局，分而配之」（R13）。同 R8，按「所成之局」分而配之，仍是大略。

**两说并陈（不调停）**：《三命通會》也有印綬、食神的分论，取法与本书不同，两家摆开、各标出处、不选边——
- **印綬**：《三命通會》卷五·論印綬把正印、偏印分出两路，说「凡格喜身旺，惟印綬喜身弱」，又说「印多則清孤不免」、偏印另名「倒食」（吞啖煞）。《子平真詮》篇 35 则说「财与印不分偏正，同为一格而论之」（R1）、「身旺印强，不愁太过」（R3）——**一个「正偏分论、喜身弱、忌印多」，一个「正偏不分、身旺印强不愁太过」**，此处两家不同，不并成一句。
- **印财关系**：《三命通會》卷五·論印綬直说「忌財星以財能破印」，财一概是印的忌物。《子平真詮》篇 35 说印重身强时「透财以抑太过，权而用之」（R6）、只有「印轻财重」才是「贪财破印」（R7）——**一个把财一律当破印之忌，一个按印重印轻分两路**，此处两家取法不同，不互相调和。
- **食神**：《三命通會》卷五·論食神说「食神大忌偏印為倒食」「食神宜食生食旺，不可食衰食絶」「食神生旺勝似財官」（另有「食神重見變為傷官令人少子」这类书里的说法）。《子平真詮》篇 37 先把食神系在「能生正财」上（R9），且把忌印忌官都写成带例外的一般（R11、R12）——**一个重在生旺、主忌倒食，一个重在生财、忌有例外**，此处两家不同，不选边。

## A1：来源应用

书里给的做法，都落在「先认这两路怎么立，再逐条核条件」这一条线上：

- **印綬正偏同格**：按 R1，取印绶时不另分正印偏印两套名字。
- **印透官可两用**：见官先问它是「生印」还是本身可取为用（R2）。
- **印格先问身印谁重**：身旺印强不愁太过（R3）；印旺才以伤食泄秀（R4），印浅身轻反忌层层伤食（R5）。
- **印财按印之轻重分路**：印重可权用财抑太过（R6），印轻财重则成贪财破印（R7）。
- **食神先看能不能生财**：能生正财方可喜（R9）；成食神生财格要财有根、身强食旺而财透（R10）。
- **食神之忌带条件**：忌印要看是否夏火太炎、木焦（R11）；忌官要看是否金水一路（R12）。
- **取运只作大略**：印格取运（R8）、食神取运（R13）都按「所成之局，分而配之」，到某一个盘再「分而配之」。
- **不越篇**：本篇只讲印綬与食神两路的立格与取运大略；用神总纲、正官与财、偏官伤官、相神吉凶神都落到本人族对应的 skill 去讲。

**书里没有的、不要加**：本篇不讲排盘起例，也没有「旺衰计分」「自动取喜用」「格局打分」这类后世做法；拿现代命理流派的评分法来解释「身旺印强不愁太过」「食神忌印透印不碍」是硬伤，一律不写。

## E：执行步骤

1. **判问法**　输入：用户的话 → 输出：判据是**输入里有没有四柱或出生信息**。
   - 没有四柱，问「书里这句什么意思／这一篇专门讲什么」→ 走**文本解读**（认句归篇、摆条件），不必落盘；结尾补一句「给我四柱就能照书读一遍」。
   - 给了四柱，问「我这盘怎么看」→ 走**落盘读法**（下面四步）。
   - 给了四柱但用户**只问出处**，也按文本解读答，不硬塞落盘。
   🔴 **CHECKPOINT**：若用户只是给生日求排盘、或问的是别篇（用神总纲／正官财／偏官伤官等），先说明该走哪个 skill，不在这里硬答。
2. **落盘①：输入**　输入：用户的四柱（或已排好的盘）＋ 本 skill 的条件（印綬一路、食神一路） → 输出：把要核的对象摆出来——月令取何神、印或食神透在哪柱、有无官煞伤食、身与印食谁重。
   🔴 **CHECKPOINT**：缺年、月、日、时任一柱或缺出生地（真太阳时用），照实说缺什么、要到什么程度才能排，**不许用占位信息硬排**；出生时刻只到时段时，时柱按该时段整体给出并标明「时段内不唯一」。
3. **落盘②：逐条核条件**　输入：第 2 步摆出的对象 → 输出：按书写明的取用条件**逐项核**，核的是——**几位／透还是藏／有破无破／月令可不可取**：
   - 印：身与印谁重（R3、R4、R5）；印财并见时印重还是印轻（R6、R7）；是否透官、官可两用否（R2）。
   - 食：能不能生财、财有没有根（R9、R10）；忌印是否落在「夏火太炎木焦」的例外（R11）；忌官是否落在「金水不忌」的例外（R12）。
   逐条写明这盘满足到哪一步、卡在哪一条。
   🔴 **CHECKPOINT**：核的是**书里写明的条件**，不许拿「旺衰计分」「自动取喜用」这类后世做法替代。
4. **落盘③：输出读法**　输入：第 3 步的逐条结果 → 输出：一句「**按书里这一类读，偏 X**」＋**出处**（《子平真詮》篇名，如三十五·论印绶／三十七·论食神）；只报格名不出处不合格。
   🔴 **CHECKPOINT**：措辞一律「倾向／按书里这一类读」，书里的「美格」「大贵之格」「贫贱之局」等评价语要标明是**书里的说法**。
5. **落盘④：收口**　输入：整段推演 → 输出：一句这一路在说什么 ＋ 一句按书里往哪看 ＋ 一件用户今天能查证或能改的读法动作。**收口必须落全四条**：① **不应期**（不说哪年发生）；② **不断终身**（不给一生一句定）；③ **不落寿夭疾病生育**（书里如有这类条文只作书里的说法引，不落到具体的人身上）；④ **不替用户决定**（婚姻／职业／医疗不拍板）。
   🔴 **CHECKPOINT**：收口前确认没滑到流年大运、寿夭、子女上去；若用户追问，照实说明本 skill 只讲这两路的立格与取运大略。
