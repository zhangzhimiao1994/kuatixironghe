# 論十二支體象與藏遁

**来源**：sources/sanmingtonghui.txt（《三命通會》卷二·論地支、卷二·十二支分配地理、卷一·論十二支名字之義） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问十二支各自的体象那一句怎么讲（子十二支之魁、丑虽隆冬……亥地六阴）。
- 用户问某一支「藏」什么干、书里怎么称呼这些藏干（藏官藏印、壬墓癸还魂、庚寄戊母）。
- 用户问「十二支分配地理」里子为墨池、寅为广谷、辰为草泽、未为花园这些取象凭什么。
- 用户问「论十二支名字之义」里子丑寅卯……戌亥各从何得名。
- 用户问地支的刑冲合会（子刑卯、子午冲、申子辰三合）在论支体象时怎么用。
- 用户读到「大抵五行用法总无真实生死衰旺亦假名耳」想问这句是什么意思。

**不应触发**（看起来像但其实不是）：
- 用户问十天干各自的体象与天象取象 → 转 bazi-sanming-tian-gan。
- 用户问正月寅中「己土七日丙火五日甲木十八日」这类司事日数 → 转 bazi-sanming-ren-yuan。
- 用户问某柱纳音是什么 → 转 bazi-sanming-na-yin。
- 用户要排盘、给一组四柱算流年大运吉凶 → 本维度不接流年大运、不断终身。
- 用户只说「我属什么生肖」这类泛化的话，没有点出地支／藏干／体象等显式请求 → 不激活。

19. 未為花園花園屬之未不屬之卯何也卯乃木旺自成林麓未乃木庫如人築墻垣以䕶百花也（《三命通會》卷二·十二支分配地理）

## I：核心解释

这一段讲「一个地支是什么、里面藏着什么」，分三层：体象句、名与取象、藏遁。

1. **体象句的句式**。十二支各有一段，先讲时令气候，再讲该支的刑冲合会与所含之气。子是「十二支之魁，溪澗江洋之水」，但「必過大雪之期，一陽來復之後方能成旺」（R1）；丑虽隆冬，天时已转二阳，「丑中己土之煖能生萬物，辛金養地」（R2）；寅「氣聚三陽，有丙火生焉」，并带出寅刑巳、合申、旺于卯、库于未（R3）；卯「氣稟繁華」（R4）；辰「為水泥之濕」，含乙之余气、癸之还魂（R5）；巳「六陽之極」，庚寄、戊归禄（R6）；午「炎火正升，入中氣則一隂生」（R7）；未「隂深而火漸衰」（R8）；申「水土長生之地」（R9）；酉「金色白水流清」（R10）；戌「洪鑪之庫」（R11）；亥「六隂雨雪載塗」（R12）。
2. **「藏遁」在体象句里已经点出**。书讲某支时会把所藏之气连带说出：辰中有乙之余气、癸之还魂（R5）；巳中庚金寄生、戊土归禄（R6）；午中庚无用、己归垣（R7）；未中有乙木、丁火，并判「藏官藏印不藏財」（R8）。所以「藏」不是另起一套，而是随支体象带出来。
3. **名与取象另立一套**。「论十二支名字之义」按字义与方位讲名：子是在北方至阴寒水之位，「一陽肇生之始，故陰極則陽生」（R14）；午「陽尚未屈，陰始生而為主」（R15）。「十二支分配地理」再各配一个地理之象：子为墨池（R16）、寅为广谷（R17）、辰为草泽（R18）、未为花园（R19）；取象的理由都回到该支的方、令、所含之物（未为花园是因为「未乃木庫」，而不是卯）。
4. **刑冲合会与三合**。体象句里夹着支与支的关系：寅刑巳、合申（R3），亥「其用在三合之有心」（R12）。三合、刑、冲是论支时随体象一起出来的。
5. **一句总纲**：地支虽分生死衰旺，但书里最后说「大抵五行用法總無真實生死衰旺亦假名耳」（R13）——这是书自己的话，提醒这些名目（长生、死、旺、衰）是借名，不是实有其事。

## A1：来源应用

书上给的读法，分三段落地：

- **读单支的体象**：按 R1–R12 读出该支的时令、气候、所含之气与它带出的刑冲合会，逐句挂原句。
- **读藏遁**：把体象句里点到的「余气／还魂／寄生／归禄／藏官藏印」挑出来，当作该支所藏之气，不另编藏干表；月令里谁司事几日另见 bazi-sanming-ren-yuan。
- **读名与取象**：按名字之义定方与字（R14、R15），再按分配地理配一个地理之象（R16–R19），说明取象的理由。
- **一句可带走**：地支取象是「时令 + 所含 + 关系」三件——先看它当令不当令，再看它含什么，最后看它和别的支刑冲合会如何。

**书里没有的、不要加**：原书不把十二支折成「分数」或列成现代藏干权重表；这些加进来只能标「（补充）」并说明依据。分配地理里那些象（墨池、广谷、草泽）是书里的比喻，不是实指。

## A2：典型触发场景

1. 用户第一次读十二支体象那十二段，想逐段弄懂。
2. 用户问「子十二支之魁」为什么子排在十二支之首。
3. 用户问「丑中己土之煖、辛金養地」是不是在说丑的藏干。
4. 用户问「辰为水泥之湿……甲至此虽衰而有乙之余气」怎么讲藏遁。
5. 用户问「未中有乙木有丁火，是藏官藏印不藏财」为什么这么判。
6. 用户读到「大抵五行用法总无真实生死衰旺亦假名耳」，想知道书是不是自己否定了生死衰旺。
7. 用户问「子为墨池、寅为广谷、辰为草泽」这些地理取象凭什么。
8. 用户问地支的刑、冲、三合在论支体象时怎么用。

## E：执行步骤

1. **确认问的是哪一支、哪一层**　输入：用户的话与所引句子 → 输出：判定落在体象句／名与取象／藏遁哪一层，以及是十二支中的哪一支。
   🔴 **CHECKPOINT**：若用户问的是天干、月令司事日数、纳音，先说明本 skill 只管地支,转对应 skill，问用户要哪个。
2. **出体象句**　输入：定下的支 → 输出：摆 R1–R12 中该支的原句，标出时令、所含之气与刑冲合会。
3. **讲藏遁**　输入：体象句 → 输出：把该支带出的余气／还魂／寄生／归禄／藏官藏印挑出来讲，挂回原句。
4. **配名与地象**　输入：用户追问字义或取象 → 输出：R14、R15 的名字之义，再配 R16–R19 之类的地象与原句给的理由。
5. **给判读口径**　输入：机制 → 输出：说清「凭什么这么取」——时令定当令、所含定藏、关系定刑冲合会。
6. **收口**　输入：整段推演 → 输出：一句可带走的话（该支的时令 + 所含 + 与邻支的关系各一句），并带 R13 一句总纲。
   🔴 **CHECKPOINT**：收口前确认没把体象句当成对某个具体八字的断语，也没把「藏官藏印」当成对某人的事实判决。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把体象当物象套死 | 说某支就是龙蛇、就是墨池、某命必见某象 | 拉回 R1、R18：取象是配时令与所含的比喻，不是对具体命的断言 |
| 另编藏干表 | 抛开 R5–R8，自造一份藏干权重表 | 拉回 R5–R8：藏遁随体象句带出，不另编表；日数另见 bazi-sanming-ren-yuan |
| 把「亦假名耳」读成否定五行 | 说书自己承认生死衰旺全是假的、没用 | 拉回 R13：这是书自己的话，讲「名是借名」，不是取消这层用法 |
| 拿现代名词给取象背书 | 说某支「能量强」「信息量大」 | 删掉现代措辞，只按原句讲时令、所含与关系 |
| 借体象放排盘 | 讲着讲着开始排四柱、判吉凶 | 拉回本 skill 范围，排盘转 bazi-hub |
| 只给泛化词就激活 | 用户说「我属什么」就论地支 | 泛化词不算；要显式点出地支／藏干／体象才接 |

**边界规则**：
1. 只讲十二支的体象句、名与取象、藏遁，不接排盘与批断。
2. 不依据八字给出疾病诊断、寿命预测、生育判断、婚姻决定；书里若有这一类条文，引用时标为「书里的说法」，不落到具体的人身上。
3. 不批流年大运、不断终身。
4. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
5. 体象句、名与取象、藏遁三层要分栏标注，不混成一条。

- [ ] 没另编藏干表、没有把藏遁和月令司事日数混为一谈。
- [ ] 没引入现代科学名词或现代命理流派术语。
- [ ] 泛化词没有当作触发。

**安全兜底**：涉及就医／用药／危机时，只做提醒与陪伴，不做诊断（见 hub 的安全标记）。

## 练习手册

- **十二支一句记**：合上 R 节，给十二支各写一句「它当什么令、里面含什么」，各挂回原句。
- **藏遁摘句**：把体象句里出现的「余气／还魂／寄生／归禄／藏官藏印」逐一摘出，写明出自哪一支、哪一句。
- **名象对位**：把子、寅、辰、未四个地象与它们的字义各配一条原句，说明取象的理由。
- **一句总纲**：把「大抵五行用法总无真实生死衰旺亦假名耳」用自己的话讲一遍，说明它提醒了什么。

## 反例黑名单

1. 把十二支体象读成对某个具体八字的断言。
2. 抛开原句另编一份藏干表或权重表。
3. 把「亦假名耳」读成书自己否定生死衰旺、因而这套名目没用。
4. 把地象（墨池、广谷、草泽、花园）当实指。
5. 把体象句、名字之义、地理取象、总纲几层的出处混作一层。
6. 用户只说「我属什么」就激活并大谈十二支。

## 灰色地带

- **用户问「地支到底藏不藏干」**：书里藏是随体象句带出的（辰含乙余气癸还魂、未含乙木丁火），没有单独列成一张表；照实说这是书里的讲法，月令里谁司事几日要到 bazi-sanming-ren-yuan 才给分法。
- **体象句既讲生死又讲「亦假名耳」**：两说并存——书用长生死旺这些名目讲体象（R1–R12），又用 R13 提醒这些名是借名；用户若追问，两说都摆，说清是书自己并列的一层提醒。
- **同一支名字之义与分配地理两处取象不同**：一处按字义与方（子为北方寒水），一处配一个地象（子为墨池）；两处并列，不替书里把两套合成一套。
- **用户把「藏官藏印」当成对某人婚姻子女的判词**：按 R8 回到原意——这是就未支所含之气的称谓，不是对具体人的断语；涉及婚姻、子女一律不落到人身上。
- **用户要「支体象 + 顺便断我一命」**：十二支体象照讲，断命部分照实说不在本 skill 范围内，指回 bazi-hub；若真要排，先补齐年、月、日、时与出生地，缺一项就不硬排。
