# 用神總綱：专求月令、以成败论高低

**来源**：sources/zipingzhenquan.txt（《子平真詮》序、凡例，及篇八·论用神／篇九·论用神成败救应／篇十·论用神变化／篇十一·论用神纯杂／篇十二·论用神格局高低／篇十三·论用神因成得败因败得成／篇十四·论用神配气候得失） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

**应该触发**：
- 用户问《子平真詮》里的用神到底怎么取，是不是「专求月令」。
- 用户问月令没有可取之神（日与月同）时怎么办，建禄月劫算什么。
- 用户问「成中有败，必是带忌；败中有成，全凭救应」怎么读。
- 用户问用神为什么会「变化」、又为什么分「纯、杂」。
- 用户问格局的「高低」凭什么分，有情、有力无力各指什么。
- 用户问「因成得败、因败得成」是怎么发生的。
- 用户问用神为什么还要「配气候」（调候），冬木逢水、夏木火盛怎么讲。
- 用户引序或凡例里的句子（如「月令为经，诸神为纬」「舍月令别取用神之格局」）问出处。

**不应触发**：
- 用户问相神是什么、杂气（辰戌丑未）怎么取用 → 转 bazi-ziping-xiang-shen-za-qi。
- 用户问四吉神能破格、四凶神能成格 → 转 bazi-ziping-ji-xiong-shen。
- 用户问「拘泥格局、以讹传讹」之病 → 转 bazi-ziping-shi-shuo-zhi-jiu。
- 用户问十干十二支、阴阳生克生死、十干配合 → 转 bazi-ziping-gan-zhi-xing-qing。
- 用户问行运怎么取 → 转 bazi-ziping-xing-yun。
- 用户要按某人生日批流年大运、断终身、断寿夭 → 本族不接。
- 用户没提八字词，只说「我最近运气差」 → 泛化词，不激活。

## I：核心解释

篇八到篇十四是《子平真詮》的骨头：先立「用神专求月令」这条纲（篇八），再把成败救应、变化、纯杂、高低、因成得败、配气候一层层铺开。序里那句「观其论用神之成败得失……至详且悉」（R1），说的就是这一串。

1. **纲：用神专求月令**。「八字用神，专求月令，以日干配月令地支，而生克不同，格局分焉」（R3）。取用的第一道门是月令：拿日干去配月令那个地支，生克关系一定，格就分出来了。这一条是全书的立足点。
2. **用神分善不善、顺用逆用**。「财官印食，此用神之善而顺用之者也；煞伤劫刃，用神之不善而逆用之者也。当顺而顺，当逆而逆，配合得宜，皆为贵格」（R4）。财官印食顺着用（相生、护持），煞伤劫刃逆着用（制伏）；顺逆各得其宜，就成贵格。这里的「贵格」是书里的评价语。
3. **月令无可取时的退路**。篇八自己留了口子：「然亦有月令无用神者，将若之何？如木生寅卯，日与月同，本身不可为用，必看四柱有无财官煞食透干会支，另取用神」（R5）。日与月同（如甲生寅月），月令本身不能当用神，就退而在四柱里找透干会支的财官煞食另外取用——建禄月劫一类的格就出在这里。
4. **成与败、带忌与救应**。篇九先把格分成与败两类，再点出转关处：「成中有败，必是带忌；败中有成，全凭救应」（R6）。成格又被打坏，多半是因为带了忌神；败格还能救回，全靠有个救应之神。成败不是一次定死，是在四柱里看有没有带忌、有没有救应。
5. **变化从月令所藏而来**。「用神既主月令矣，然月令所藏不一，而用神遂有变化」（R7）。月令一支往往藏几位神（不止四库），透出来的那一位可能就把本气顶替了，用神于是变了样；变之而善格愈美，变之不善格遂坏。
6. **变化之中分纯杂**。「用神既有变化，则变化之中，遂分纯、杂。纯者吉，杂者凶」（R8）。纯是「互用而两相得」，杂是「互用而两不相谋」——两神相生相成是纯，相克相背是杂，纯杂又都从变化里出来。
7. **高低论在有情与有力无力**。篇十二把格局的贵贱收在两句话上：「然其理之大纲，亦在有情、有力无力之间而已」（R9）。有情是两神之间有生护照顾、不是凑合；有力无力是那颗神在四柱里站不站得住（得禄、有根之类）。篇里又举出「有情而兼有力、有力而兼有情」为格之最高者。
8. **成败还会互相反转**。「八字之中，变化不一，遂分成败；而成败之中，又变化不测，遂有因成得败，因败得成之奇」（R10）。篇十三说：一个看起来成格的局面，因为某个字一合一带，反倒坏了；一个看起来败格的局面，因为某个字一合，反倒清而成格。这类反转不能死执。
9. **还得配气候互参**。「论命惟以月令用神为主，然亦须配气候而互参之」（R11）。取用以月令为主，但月令之外要看寒暖燥湿。篇十四举里正是：「伤官见官，为祸百端，而金水见之，反为秀气。非官之不畏夫伤，而调候为急，权而用之也」（R12）——常例里伤官见官是祸，落到金水一路就变秀气，因为这里调候比常例更急，是权用。

把这一路收成一张表：

| 层 | 原书说法 | 落在哪儿 |
|---|---|---|
| 纲 | 用神专求月令（R3） | 取用第一门是月令 |
| 顺逆 | 财官印食顺用、煞伤劫刃逆用（R4） | 善不善各有用法 |
| 退路 | 月令无用神则另取（R5） | 建禄月劫出此 |
| 成败 | 带忌则败、救应则成（R6） | 成败看带忌与救应 |
| 变化 | 月令所藏不一（R7） | 透出者可变本气 |
| 纯杂 | 两相得为纯、两不相谋为杂（R8） | 从变化里分 |
| 高低 | 在有情、有力无力（R9） | 贵贱收在此 |
| 反转 | 因成得败、因败得成（R10） | 不死执一格 |
| 配气候 | 兼配气候互参（R11、R12） | 调候为急则权用 |

## A1：来源应用

书上给的做法，都落在「先认定月令可取之神，再逐条核成败救应与纯杂高低」这条线上：

- **先问月令**：八字用神专求月令（R3）。入手先看月令这一支能取哪一位神（本气、透出的藏气、会支会局），格名随之而定。
- **月令无取再退**：日与月同、月令本身不可为用时，才在四柱里找透干会支的财官煞食另取（R5）；这是建禄月劫一路，不是随手在外头另立格。
- **核成败**：成格的条件（官逢财印无刑冲破害之类）与败格的条件（官逢伤克刑冲之类）在篇九列得很细；判的时候还要看有没有「带忌」、有没有「救应」（R6）。
- **核变化与纯杂**：月令所藏不止一位时，看透出的是谁、会不会支（R7）；两神相见是「两相得」还是「两不相谋」，定其纯杂（R8）。
- **核高低**：在已成的格里分等，看两神之间「有情无情」与那颗神「有力无力」（R9），并注意篇十二所说有情兼有力、有力兼有情者为最高。
- **核反转**：遇到看似成格或看似败格的局面，回到篇十三，看有没有因合因带而反转（R10），不死执。
- **核气候**：最后拿寒暖燥湿对一遍，看有没有「调候为急」而当权用之处（R11、R12）。
- **要有出处**：报任何一格或用神，都要给「哪一本、篇名」与「凭什么这么取」两句（STYLE 第三节第 9 条）。只报格名不出处不合格。

**书里没有的，不要加**：本 skill 不讲现代命理流派的「旺衰计分」「喜用神自动判法」「格局打分」这一类做法。原文判成败纯杂靠的是「带忌／救应」「两相得／两不相谋」「有情／有力无力」这套说法，照书讲即可；拿后世的评分法来解释「高低」是硬伤。

**一个不替它们调停的地方**：本篇原书立足点是「用神专求月令」（R3）；评注本的凡例却补一句「然用神非尽出于月令，故于舍月令别取用神之格局，特别提出」（R2）；而《三命通會》那一路（如卷十·㸔命口訣「先㸔月支有無財官」、卷十一·喜忌篇的诸格断语）虽也重月令，却另立一大套格名断语。三处各有出处，摆在一起读，本文不选边、不合成一句话。

## A2：典型触发场景

1. 用户第一次问《子平真詮》取用神的规矩，想知道是不是一律以月令为准。
2. 用户读到「然亦有月令无用神者」，问甲生寅月这种日与月同的盘到底怎么取用。
3. 用户读到「成中有败，必是带忌；败中有成，全凭救应」，想弄清「带忌」和「救应」各指什么。
4. 用户问用神为什么要「变化」、透出一个字怎么就把格改了。
5. 用户问「纯者吉，杂者凶」里的纯、杂怎么分。
6. 用户问两个都成的格，凭什么说一个高一个低。
7. 用户读到「伤官见官，为祸百端，而金水见之，反为秀气」，觉得与前文相打架，想问这里为什么「权而用之」。
8. 用户直接引序或凡例一句，要求回到原书讲清出处与上下文。

## E：执行步骤

**先分两种问法**（判据：输入里有没有四柱或出生信息）：
- 只问「书里这句什么意思／这一篇专门讲什么」、没给四柱 → 走 **文本解读**（认句归篇、摆条件），不必落盘；结尾补一句「给我四柱就能照书读一遍」。
- 给了四柱或出生信息（问「我这盘怎么看」）→ 走 **落盘读法**（下四步）。给了四柱但用户只问出处，也按文本解读答，不硬塞落盘。

落盘读法四步：

1. **步骤一·输入四柱**　输入：用户的四柱（或已排好的盘）＋ 本 skill 的取用条件 → 输出：确认月令这一支是哪一地支、日干是哪一干，把它标出来备用。
   🔴 **CHECKPOINT**：缺出生年/月/日/时任一柱、或缺出生地（定真太阳时用）就照实说缺什么、要到什么程度才能排，不用占位信息硬排；出生时刻只到时段（如「辰时」）时，时柱按该时段整体给出并标明「时段内不唯一」。
2. **步骤二·逐条核条件**　输入：标好的四柱 → 输出：按 R 节逐项核——月令可取哪一位神（R3）、日与月同否（R5）、克忌与救应在哪两个字（R6）、月令藏几位透哪一位（R7）、两神是两相得还是两不相谋（R8）、两颗神是有情还是有力无力（R9）、有没有因合反转（R10）、有没有调候为急处（R11、R12）。核到哪一步就说到哪一步，没满足的直说没满足。
   🔴 **CHECKPOINT**：月令取何神、某格条件满足到什么程度属于可核的规则；而「成不成贵格」「高低」属判读，必须挂在原书条文上，不许把可核的计算当结论。
3. **步骤三·输出判断**　输入：逐条核的结果 → 输出：一句「按书里这一类读，偏 X」＋ **出处**（《子平真詮》篇名）。X 只到「月令取何神、成败救应落在哪、偏纯偏杂、偏哪一层高低、有没有调候为急」这个粒度。
   🔴 **CHECKPOINT**：每条判断都要带出处；没原话可挂就直说此处讲不到，不替它编。
4. **步骤四·收口**　输入：整段推演 → 输出：一句这一篇在说什么 ＋ 一句按书里往哪看 ＋ 一件用户今天能做的读法或查证动作。
   🔴 **CHECKPOINT**：收口前确认——**不应期**（不说哪年发生）、**不断终身**（不一生一句定）、**不落寿夭疾病生育**、**不替人决定**（婚姻职业医疗一律不拍板）。书里的「大貴／孤貧」只作书里的说法念，不落到人身上。

**交付口径**：逐步把推演展示出来，结论速览放最前但不得代替推演；一步之中的依据尽量引用户的问法或所给的四柱。需要成表的内容走平台原生的表格消息，不把 markdown 表格塞进正文。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |

**边界规则**：
