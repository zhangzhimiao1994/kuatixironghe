# 堪舆择日·義例一·年神

**来源**：《欽定協紀辨方書》卷三·義例一 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「今年太岁在哪个方向？能不能在那边动土？」
- 「岁破、大将军、白虎、劫煞、三煞分别在哪，宜忌是什么？」
- 「有人跟我说某年不宜修造某个方位，依据是什么？」
- 用户要按**年**一层排神煞方位，并问它的起例与宜忌。

**不应触发**（看起来像但其实不是）：
- 用户要按**月**排神煞（月德、月厌、建除十二神）→ 转月神／建除类 skill。
- 用户要按**日／时**取用（三合、驿马、黄黑道、贵人禄马）→ 转日神／黄道贵人／禄马类 skill。
- 用户只想弄懂「干支五行方位为什么能立例」 → 转原理层 skill。
- 用户要现场动土施工指导 → 不接（见 B 节）。

## R：原文锚点

1. "選擇神煞古有建除堪輿叢辰諸家顧其義不盡傳起例尤多襲誤今頗為蒐輯擇其近理而雅馴者加之解釋正其舛誤庶吉凶之義因例可尋而不惑於世俗術數之説也作義例"（《欽定協紀辨方書》卷三·義例一）
2. "凡以敬天云爾如曰若是則福不若是則禍則術士之曲説而非其本原也"（《欽定協紀辨方書》卷三·義例一）
3. "曾門經曰歲德者歲中德神也十幹之中五為陽五為隂陽者君道也隂者臣道也君德自處臣德從君也所理之地萬福咸集衆殃自避應有修營並獲福祐"（《欽定協紀辨方書》卷三·義例一）
4. "黄帝經曰太歲所在之辰必不可犯"（《欽定協紀辨方書》卷三·義例一）
5. "歲星右行於天太歲左行於地"（《欽定協紀辨方書》卷三·義例一）
6. "廣聖厯曰歲破者太歲所衝之辰也其地不可興造移徙嫁娶逺行犯者主損財物及害家長惟戰伐向之吉"（《欽定協紀辨方書》卷三·義例一）
7. "神樞經曰劫煞者歲之隂氣也主有殺害所理之方忌有興造犯之主有劫盜傷殺之事"（《欽定協紀辨方書》卷三·義例一）
8. "考原曰劫煞災煞歲煞是為三煞如曹氏説則三合五行絶胎養之位也"（《欽定協紀辨方書》卷三·義例一）

## I：核心解释

卷三·義例一是全书神煞起例的**总门**：先把「为什么有神煞」「神煞的例从哪来」定下来，再逐条排年神。白话讲：

1. **书对神煞的基本态度**（R1、R2）。篇首即说：选择神煞本有建除、堪舆、丛辰诸家，但「其义不尽传，起例尤多袭误」，本书是**蒐辑、择其近理而雅驯者、正其舛误**。所以读年神先要知道：书不是在为一切术家说法背书，而是在**甄别**。总论最要紧一句是——「若曰若是则福、不若是则祸，则术士之曲说」，书的落点是「敬天」，不是「趋福避祸」的保证（R2）。
2. **岁德是岁中德神**（R3）。十干之中五阳五阴，阳为君道、阴为臣道，「君德自处，臣德从君」。起例：甲德在甲、乙德在庚、丙德在丙、丁德在壬……即五阳干自得，五阴干取其合。
3. **太岁是百神之统**（R4、R5）。书上说太岁「人君之象，率领诸神」，所在之辰「必不可犯」。太岁左行于地、岁星右行于天，二者行度不异。太岁对位即**岁破**（R6）：其地不可兴造、移徙、嫁娶、远行。书里还辨明：太岁「其方固上吉之方，而非下民之所敢用」，是「避尊」之义，不是那里真有凶神。
4. **年神两条主线**：一条随太岁四方配合（大将军、奏书、博士、力士、蚕室这一组四维神），一条随三合取「绝、胎、养」之位即**三煞**（劫煞、灾煞、岁煞）。书里对三煞给了一个更稳的说法：**宜向不宜坐**（R8），即三煞之方「皆太岁之所恶而不可居」，不是因为它能敌太岁而怕它。
5. **神煞要成对看**：书里反复说「美恶不嫌同位、吉凶不嫌同名」。同一辰可能既是吉神又是凶神（如岁枝德之辰又为死符、小耗），判读要「各从其所用」，不能见名就断。
6. **存废并有**：书对黄幡、豹尾、五鬼、飞廉等，明说「亦与黄豹尾同，可有可无者也」「实则无所关系」，是**存其名而不重其力**。这正是本书与世俗术家不同的地方。
7. **年神的两套生成方式**：一类「随岁干起」（岁德、岁德合、岁干合，取天干），一类「随岁支起」（太岁、岁破、大将军、丧门、太阴，取地支），又有一类「从岁支三合起」（官符、白虎、劫煞、灾煞、岁煞，取三合前辰后辰）。三合前后又分文武：前辰为文曰官符，后辰为武曰白虎。
8. **丧门、太阴、弔客、官符一组**：丧门居岁前二辰、太阴居岁后二辰、弔客居岁后二辰、官符居岁前四辰。书按：岁后二位与岁前二位必属三合，「为太岁所冲克、与冲克太岁者皆死地」，故前为丧门、后为弔客，其义「美恶不嫌同位，各从其所用」。
9. **岁刑与自刑**：巳酉丑刑申酉戌、寅午戌刑巳午未、申子辰刑寅卯辰、亥卯未刑亥子丑，辰午酉亥为自刑。书赞「翼氏风角四语」最明，并对曾门经、储泳之说各加辨正。

## A1：来源应用

书上给的具体做法（不是我的发挥）：

- **岁德起例**（R3）：五阳干自得（甲丙戊庚壬即以为德），五阴干取其合（乙德在庚、丁德在壬、己德在甲、辛德在丙、癸德在戊）。
- **岁德合**：以岁德五合之干为合，甲年在己、乙年在乙……岁德属阳、岁德合属阴，「并使用上吉，有宜无忌」。
- **太岁与岁破**（R4、R6）：太岁所在辰不可犯；岁破为太岁所冲之辰，不可兴造移徙嫁娶远行。
- **大耗即岁破**：为建囷仓、纳财帛等事重着其义，另立一名。
- **三煞**：劫煞（三合绝位）、灾煞（胎位）、岁煞（养位）；申子辰年在巳午未、寅午戌年在亥子丑、巳酉丑年在寅卯辰、亥卯未年在申酉戌。用法「宜向不宜坐」（R7、R8）。
- **伏兵大祸**：夹处三煞之间，以三合相克之阳干为伏兵、阴干为大祸，忌出兵行师及修造。
- **四维四神**：奏书（岁后维）、博士（岁前维，与奏书对冲）、力士（岁前维）、蚕室（岁后维，与力士对冲）；另有蚕官、蚕命，用五子元遁起。
- **岁刑**：巳酉丑刑申酉戌等，忌攻城兴工；**金神**：以年干五虎元遁逢庚辛及纳音金之位起，忌筑城、建宫、上梁、出军、嫁娶。
- **岁干合**：甲年在己、乙年在庚……取与岁干相合者；书说它与岁德、岁德合相为表里，故历书「不必复著其名」，但「各各有义」仍存其目。
- **岁枝德**：常居岁前五辰（李鼎祚说），取「甲既在子则巳上必己，甲之合也」；其辰又为死符、小耗，书说「美恶不嫌同位」。
- **太岁出游日**：共二十五日（甲子东游、丙子南游、庚子西游、壬子北游、戊子游中宫，各至其巳日还位）。书详辨鹤神与日游神「暗相相应」，判其为「天罡煞气之游行」。
- **出游日的用法**：太岁出游则诸神煞皆无；书又斥「出游之日四方皆空」之说是误解，其方仍当有所忌。

## E：执行步骤

1. **定年**　输入：用户给的年份或年支 → 输出：确认是哪一年的太岁方位（年支即太岁所在）。
   🔴 **CHECKPOINT**：把太岁方位与「岁破＝对宫」先摆出来，请用户确认年份无误；年份错，后面全错。
2. **定位**　输入：确认的年份＋用户要问的方位／事项 → 输出：把相关年神（岁德、太岁、岁破、三煞、大将军等）各落在何处列成一表。
3. **给例**　输入：上表 → 输出：每个神煞后头都挂**起例来源（卷三·義例一内哪一条）**与**宜忌依据**；缺一样就不许写。
   🔴 **CHECKPOINT**：把「神煞名＋卷次＋宜忌」三件套摆给用户核，只报神煞名而不给卷次＝不合格，退回补齐。
4. **分用**　输入：三件套齐备 → 输出：按书里态度分「书上认真说的」与「书上明说存而不重的」两类，只给倾向，不下断语。
   🛑 **STOP**：不替用户拍板能不能动工，只说明书里怎么立例、怎么忌。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报神煞名不给卷次 | 「你犯了太岁」却不说卷几、宜忌何据 | 补卷次·例名＋宜忌依据；补不出＝不合格 |
| 把世俗术家说法当书的主张 | 把坊本「年神方位图」的用法说成书中规定 | 书有辨正（详卷三十六·辨訛），坊本一律标「（补充）」 |
| 把书里已辨误的说法当真 | 拿「黄幡豹尾必有凶」去嚇用户 | 书明说二神「固虚设也」，照书澄清 |
| 见名就断 | 一辰既是吉神又是凶神时只挑一面说 | 按「美恶不嫌同位」两条都列，各从所用 |
| 缺年份就硬判 | 用户只说「我家朝南」 | 点明缺年份、缺具体事项，缺则不算 |
| 越界到月日时 | 拿年神去断某一天的宜忌 | 转月神／日神类 skill |
| 把卷三与卷八的年神混表 | 拿阴府太岁、天官符当卷三·義例一条目 | 按卷次分派，卷三为義例一，卷八为義例六 |
| 把太岁出游日说成四方皆空 | 认为出游日到处都可动土 | 按书：出游只空其本向，非四方皆空 |

**边界规则**：
1. 本 skill 只管**年**一层，覆盖卷三·義例一；月神在卷五、日神在卷六、时与黄黑道在卷七。
2. **报神煞必须同时给起例来源与宜忌依据**；只报神煞名而不给卷次＝不合格。
3. 象征层只命名、不承诺：写「按书里这一类读」，不写「一定／必然／命中／保证」。
4. 不替用户拍板，不给医疗、法律、投资结论。
4. 本 skill 不涉卷八的阴府太岁、天官符、大小月建等年方飞宫神煞，那些归年方禄马类 skill。


**来源边界**：
本 skill 依据《欽定協紀辨方書》卷三·義例一原文；卷九立成、卷十宜忌为查表与轻重所据，本 skill 只引其名不作表。书对世俗术家之说有明确批评，凡书已辨误者不得当作书的主张。

## 练习手册

1. **年神定位表默写**：取任意一年支，凭记忆写出太岁、岁破、三煞三者的方位，再回卷三核对。
2. **三件套训练**：任选一个年神，强迫自己写全「神煞名＋卷次·例名＋宜忌依据」，写不全就回去翻原文。
3. **辨讹练习**：从书里挑三个「存而不重」的年神（如黄幡、豹尾、飞廉），说明书为什么明说其「可有可无」。
4. **成组默写**：写出「丧门、太阴、弔客、官符」各居岁前岁后几辰，并说明书为何判其「各从其所用」。
5. **自刑推演**：列出三刑与自刑各条，说明「辰午酉亥为自刑」的四组。

## 反例黑名单

1. **不要**只报神煞名而不给出处——这是本族硬口径，违反即不合格。
2. **不要**把「犯太岁就有祸」当真——书明说其方「固上吉之方」，是避尊之义。
3. **不要**把三煞说成「能敌太岁」——书说它是太岁所恶、可向不可坐。
4. **不要**拿年神去断具体的某一天吉凶——越界。
5. **不要**用现代科学词给年神背书，也不要写成「迷信」的自我否定腔。

## 灰色地带

- **一辰两义**：同一辰兼为吉神与凶神（如岁枝德之辰又为死符、小耗），书说「各从其所用」。遇到时两条并陈，按用户所问事项定取舍，不强行合一。
- **书存而不重之神**：书对黄幡、豹尾、五鬼、飞廉明说「可有可无」「无所关系」，此时照录其名并转述书的评价，不替它加力也不擅自删除。
- **历本不一**：不同历本对某些年神入历与否不同，书亦随录（如岁枝德「今历日岁转吉神无此条」）。遇到时以本书原文为准，注明差异。

- **三合前后互文**：同一位神在岁前、岁后因三合关系而换名（前丧门、后弔客）。遇到时看用户所问方位落在前还是后，再定名。
- **书判「虚设」之神**：黄幡、豹尾、飞廉等被书判为「可有可无」「与黄豹尾同」。遇到时照录并转述书的评价，不替它加力也不敢擅删。
- **历本入历不一**：岁枝德、岁干合等书说「今历日岁转吉神无此条」。以本书原文为准，注明历本差异，不替历家补漏。
- **方与向之别**：书里年神之方多分「坐」「向」（如太岁可坐不可向之说）。遇到用户只给朝向时，先换算坐向再起例，不把朝向直接当坐山。
- **一层之神不越层**：年神只管一年的方位宜忌，不能拿来断某一天的吉凶；跨层取用是本族最常见的误用，遇到时先归层再答。
- **三件套的写法**：报一个年神，标准写法是「神煞名 → 卷三·義例一某条起例 → 所主宜忌（并注明是书上认真说的还是书上判为虚设者）」，三样缺一即不合格。
- **岁支三合与文武之分**：官符居三合前辰为文、白虎居三合后辰为武，「前阳而后阴」。遇到只报官符（不报白虎）的历本时，说明书「不用白虎」的取舍，不把历本取舍当书的主张。
- **两个太岁之别**：周礼冯相氏的「太岁」是岁星相应的十二岁，今历的「太岁」是岁之神；书辨「举太岁以表岁星则可，谓太岁即岁星则不可」。遇到混称时先辨名。
