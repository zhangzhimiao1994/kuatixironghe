# 藏风得水：什么叫「风水」

**来源**：sources/zangshu.txt（《葬書》内篇二） ｜ 证据等级：firsthand（原书原话）

## I：核心解释

「风水」这个词在原书里不是讲房子的，它是一句定义。要讲清它，得先把那句定义句拆开。

1. **定义句**：「古人聚之使不散，行之使有止，故謂之風水。」（R3）意思是：把生气聚住、不让它被吹散；把生气的运行引到某处、让它停住——这两件事合起来，就叫风水。所以「风水」讲的是**气的聚与止**，不是泛泛的地理好不好看。
2. **为什么要聚、为什么要止**：因为气的天敌是风、气的止法是水。经曰「氣乘風則散，界水則止」（R2）——气一遇到风就散，遇到水界就停下。这是风水二字背后的两条物理式表述。
3. **轻重之分**：「風水之法，得水為上，藏風次之。」（R4）在书里，止住气靠的是水，所以得水排在藏风之前；藏风是防气散，得水是让气止。两件事都要，但书给了次序。
4. **外气与内气**：「外氣橫形，內氣止生」（R5）——水在土外横过叫外气，气在土内叫内气；外面有横过的水把这个形界住，里面生气自然就止。注疏补一句：「水流土外，謂之外氣；氣藏土內，謂之內氣。故必得外氣形，則內之生氣自然止也。」（R15）
5. **两套地形、两套取用**：高垄的地「生氣浮露，最怕風寒，易為蕩散」（R13），所以求城郭完密把气聚起来；平支的地「生氣沉隱，不畏風吹」（R14），不以宽旷为嫌，只求横水把气止住。同一条「藏风得水」，落到两种地形上是两种做法。
6. **气的形态链**：「夫陰陽之氣，噫而為風，升而且為雲，降而為雨，行乎地中而爲生氣。」（R9）同一种气，散出来是风、升上去是云、降下来是雨、行在地中就是生气。「夫土者氣之體，有土斯有氣，氣者水之母，有氣斯有水。」（R10）三者环环相扣：土是气的形體，水由气生。
7. **深浅也归到这套**：「藏於涸燥者宜淺，藏於坦夷者宜深。」（R7）垄地（涸燥）宜浅、平地（坦夷）宜深；「淺深得乘，風水自成」（R8）——深浅拿对了，风水才算成。
8. **一句话读法**：风水 = 水界气止（得水为上）+ 城郭藏风（藏风次之），而深浅要随支垄调整。

9. **「氣之盛雖流行，而其餘者猶有止；雖零散，而其深者猶有聚。」**（R6）这一句给「聚」与「止」一个分寸：气盛时虽在流行，其余者仍有止处；气虽零散，其深处仍有聚处。注疏分举两端——高垄落势雄壮，各有结作，「但當求其聚處，而使之不散耳」（R17）；平支四畔旷阔，气隐零散，「但當求橫水之攔截，使之有止耳」（R18）。
10. **于是得水与藏风不是「要么要么」，而是按地形分重心**：高垄的重心在聚（藏风），平支的重心在止（得水）；这就是注疏说的「支壠之取用不同」。
11. **再往上一层**：「經曰：土形氣形，物因以生。」（R11）注疏说「生氣附形而有依土而行，萬物亦莫不非因之而生也」——聚气止气不只是葬法，还是万物由此而生这一层的落法。
12. **深浅是同一件事的纵向一步**：干旱之地取浅浮的气，平夷之地取深沉的气；深浅与聚止，是生气在横向与纵向上两处收束的方式。
13. **把这条收成一张表**：

| 抓手 | 原书说法 | 落在哪儿 |
|---|---|---|
| 气的天敌 | 氣乘風則散（R2） | 所以要藏风 |
| 气的止法 | 界水則止（R2） | 所以要得水 |
| 定义 | 聚之使不散、行之使有止（R3） | 风水二字的来处 |
| 轻重 | 得水為上、藏風次之（R4） | 水排在先 |
| 内与外 | 外氣橫形、內氣止生（R5） | 外水界住内气 |
| 地与地之间 | 高垄求聚、平支求止（R17、R18） | 两套取用 |
| 深与浅 | 淺深得乘、風水自成（R8） | 随支垄调深浅 |

## A1：来源应用

书上给的做法，都是围绕「聚气」「止气」两件事：

- **藏风的落点**：求「城郭完密，前後左右環圍區穴」（R12），使气有聚、不被荡散。高垄之地尤其怕风，注疏说那就像人深居密室，「稍有罅隙通風」便能成疾。
- **得水的落点**：高垄之地或从腰落，「雖無大江攔截，亦必有池塘以止內氣」；平支之地「但得橫水攔截，何嫌寬曠」。二者都以得水为上（见 R4 及其注）。
- **平支不以宽旷为嫌**：注疏说平支之穴「亦如人在廣寞之野，雖八面無蔽，己自不覺」，所以不因空旷而弃，只看横水有没有把气止住。
- **深浅口诀**：垄地宜浅取浮气，平地宜深取沉气；这是「淺深得乘」（R8）的落法。注疏引《祕寶經》：「陽脉沉潛深處取，陰龍浮露淺中求。坦夷涸燥無過此，卻與排星事不侔。」——并顺手否定了「多用九星白法以定尺寸者」。这一句是《錦囊》注的引文，引用时要标明。
- **一句口诀可带走**：注引楊公「明堂惜水如惜血，堂裏避風如避賊」（R16）——把「水如血、风如贼」的轻重讲得很直白，是注里的说法。
- **评价语提醒**：内篇二基本不下「必发大贵」的断语，它讲的是聚气与止气的做法；真正带评价语的是雜篇品类条。

**书里没有的、不要加**：原书内篇二只讲聚气止气与深浅，不讲罗盘、不讲水口立向、不讲二十四山；这些都不在本 skill 范围，需要操作类内容时另找本族的操作源书，本 skill 不补。

## 灰色地带

- **用户问「风水」是不是迷信**：不写自我否定腔，也不写兜售腔；只把书里的定义句与两条物理式讲清，判断留给用户。
- **一条描述里山地平地混着**：先问是哪一种，或两套做法都列，让用户对号；不硬归一类。
- **用户要「定义 + 判我这块地」**：定义照讲，判地的部分转形势类 skill，并说明缺哪些信息（水口、周边、朝向、支垄属性）。
- **得水与藏风在具体处冲突**：书里给了次序（得水为上），但没说任何情况都压倒藏风；遇到冲突就说这是书上给的次序、具体仍要形势配合，不替用户拍板。
- **用户把「明堂」「金魚」当摆设词**：这些是原书讲水界气止时的具体物象，先按原书讲它们在气与水上的作用，再说明它们不是招财物件。
- **一处地既有山又有水、说法互相打**：先分清问的是藏风（防气散）还是得水（求气止），分别按 R4 的次序与两套地形的做法答，不在同一条上硬下结论。
