# 堪舆择日·義例四·日辰神煞

**来源**：《欽定協紀辨方書》卷六·義例四 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「这个月哪几天是三合日？宜做什么？」「驿马日是哪天？」
- 「劫煞、灾煞、月煞是不是就是三煞？它们怎么定的？」
- 「六合日宜嫁娶吗？跟月害、月刑什么关系？」
- 「往亡日、归忌日不宜做什么？」「反支、四离四绝是什么？」
- 用户要按**月份／月建**排定供择日取用的一类日辰神煞。

**不应触发**（看起来像但其实不是）：
- 用户问的是**建除十二神**（建除满平定……）→ 转建除类 skill。
- 用户问的是**天德、月德、月空** → 转月神类 skill。
- 用户问的是**时家**黄道黑道、天乙贵人、喜神、四大吉时 → 转黄道贵人类 skill。
- 用户问的是**年方**禄马、飞宫贵人、通天窍 → 转禄马类 skill。
- 用户要现场动土、下葬的作业指导 → 不接（见 B 节）。

8. "廣聖歴曰歸忌者月内凶神也其日忌逺行歸家移徙娶婦"（《欽定協紀辨方書》卷六·義例四）

## I：核心解释

卷六·義例四接着排一批「按月建逐月轮转、供择日取用」的神煞。白话讲：

1. **三合是最核心的一组**（R1）。「三合者异位而同气」：寅午戌火、巳酉丑金、申子辰水、亥卯未木。其日宜结会亲姻、和合交易、修营起土、立木上梁。起例按月建分（R2），如正月（寅）得午戌日、二月（卯）得未亥日……
2. **驿马〈天后〉**（R3）。驿马是「驿骑」，正月起申逆行四孟。其日宜封赠官爵、诏命公卿、远行赴任、移徙迁居。书引储泳祛疑说，说明它是「先天三合数」推出来的；又引曹震圭按语；并辨明曹氏「五行将病得见妻子」的说法「妄谬已甚」，只取它「绝处逢生」之意。
3. **三煞（劫煞、灾煞、月煞）**（R4）。劫煞是「劫害之辰」，忌临官视事、纳礼成亲、战伐行军、出入兴贩。书按语明说：**月劫煞义与岁劫煞同**，且月灾煞也「义与岁灾煞同」——即卷三的三煞到月一层是同一套义理。
4. **月害〈六害〉**（R5）。月害是「阳建所害之辰」，忌攻城野战、牧养群畜、结会亲姻、请医巫、纳奴婢。考原解为「月建者众神之首，冲其所合是以害」。
5. **六合**（R6）。六合是「日月合宿之辰」，宜会宾客、结婚姻、立契券、合交易。同卷还有「无翘」，书辨明「六合天愿皆宜嫁娶吉日，又以为无翘而忌之」是自相矛盾，判其「应删」。
6. **一组凶辰与宜忌日**：大时〈大败、咸池〉（忌出军攻战筑室会亲）、游祸（忌服药请医）、天吏〈致死〉（忌临官赴任远行词讼）、归忌（R8：忌远行归家移徙娶妇）、往亡（R7：忌拜官上任远行归家出军征讨嫁娶寻医）、反支（忌上表章）、四离四绝（分至前一日、四立前一日，忌出行征伐）、月忌日（每月初五、十四、二十三）。
7. **九神一组**：要安、玉宇、金堂、敬安、普护、福生、圣心、益后、续世，书判其为**祭祀择日**之占，「上表章修造诸事者并不复用」。
7. **同卷神煞的三大来源**：一类「随月建取合冲」（三合、六合、临日、月害），一类「随三合取绝胎养」（劫煞、灾煞、月煞），又一类「随月建取三合之沐浴临官死气」（大时、游祸、天吏）。
8. **兵吉、五富、天仓、天贼一组**：兵吉「皆太阳后四辰」，逐月渐退一辰，示「兵家无有妄进」；五富取三合长生之六合；天仓居太阳后四辰，为太阳之收日，又为收之六合；天贼为月厌之收日，「仓之后必有盗」。
9. **九神与九神总论**：要安至续世九神「皆以对冲两两相比」，书判其「与堪舆、建除、五行、历家之旨俱不符合」，意者「丛辰等家之遗绪」，所存者唯「专为祭祀择日之占」。至于月忌日（每月初五、十四、二十三），书取「中宫五黄」之说，判「廉贞生土之说不可信」，明说「以卑犯尊则凶」。

## A1：来源应用

书上给的具体做法（不是我的发挥）：

- **三合**（R1、R2）：寅午戌火、巳酉丑金、申子辰水、亥卯未木；正月在午戌、二月在未亥……至十二月在丑巳。宜结会亲姻、和合交易、修营起土、立木上梁。
- **驿马**（R3）：正月起申逆行四孟（寅申巳亥），申子辰马在寅、寅午戌马在申、亥卯未马在巳、巳酉丑马在亥。宜封赠官爵、远行赴任、移徙迁居；又曰天后，为月中福神。
- **劫煞**（R4）：正月起亥逆行四孟；与岁劫煞同义。
- **月煞〈月虚〉**：正月起丑逆行四季；忌停宾客、兴穿掘、营种植、纳群畜。
- **月刑**：与岁刑同；**月害**（R5）：正月起巳逆行十二辰；忌攻城野战、结会亲姻、请医巫、纳奴婢。
- **六合**（R6）：正月在亥逆行十二辰；宜会宾客、结婚姻、立契券、合交易。
- **大时〈大败、咸池〉**：正月起卯逆行四仲；忌出军攻战、筑室会亲。
- **游祸**：正月起巳逆行四孟；忌服药请医、祝神致祭。
- **天吏〈致死〉**：正月起酉逆行四仲；忌临官赴任、远行词讼。
- **九神**：要安至续世，正月起寅、二月起申……两两对冲，专为祭祀择日之占。
- **归忌**（R8）：孟月丑、仲月寅、季月子；忌远行归家、移徙娶妇（书并辨「并忌嫁娶」之说当止）。
- **往亡**（R7）：正月寅、二月巳、三月申……忌拜官上任、远行归家、出军征讨、嫁娶寻医。
- **四离四绝**：分至前一辰为四离，四立前一辰为四绝，忌出行征伐、出军远行。
- **临日**：正月午、二月亥、三月申……书判「宜为临民受讼之吉占」，并纠正枢要历「以为忌」之误。
- **兵吉**：正月子丑寅卯、二月亥子丑寅……逐月渐退一辰，「兵家不可以妄进」。
- **天仓／天贼**：天仓正月起寅逆行十二辰；天贼正月在丑逆行十二辰。
- **四离四绝**：离为分至前一辰，绝为四立前一辰，忌出行征伐；书引玉门经与曹震圭说解之。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报神煞名不给卷次 | 「这天是驿马日」不说卷几 | 补卷六·義例四条目＋宜忌依据；补不出＝不合格 |
| 把年月两层的三煞搞混 | 拿年三煞的方去当日三煞的日 | 分清「年在方、月在日」，各按本卷起例 |
| 把书已辨误之说当真 | 「六合日又犯无翘，忌嫁娶」 | 书明判无翘之说自相矛盾「应删」，照书澄清 |
| 见名就断 | 只挑神煞名对应的吉或凶一面 | 按「美恶不嫌同位」，同辰两义并列 |
| 缺月建就硬排 | 用户只说「最近想办事」 | 点明缺月份／节气与具体事项，缺则不算 |
| 越界到时家 | 拿归忌、往亡去断某时辰吉凶 | 转黄道贵人／禄马类 skill |
| 把九神当修造吉日 | 拿要安至续世去择开山动土 | 书明说九神专为祭祀而设，「上表章修造诸事者并不复用」 |
| 把月忌日归到廉贞说 | 用「廉贞火生土」去解释月忌 | 书明说廉贞生土之说不可信，取中宫五黄之义 |

**边界规则**：
1. 本 skill 只管**卷六·義例四**这一批「按月建取用」的日辰神煞；建除在卷四，月德类在卷五，时与黄黑道在卷七，年方禄马在卷八。
2. **报神煞必须同时给起例来源与宜忌依据**；只报神煞名而不给卷次＝不合格。
3. 象征层只命名、不承诺：写「按书里这一类读」，不写「一定／必然／命中／保证」。
4. 不替用户拍板，不给医疗、法律、投资结论。
4. 本卷内的上朔、反支、气往亡等，其义尚有历代异说；书随录并加辨正，凡书已辨误者不得当作书的主张。


**来源边界**：
本 skill 依据《欽定協紀辨方書》卷六·義例四原文。书对曹震圭等旧说多有辨正，又明说九神「专为祈禳而设」；凡书已辨误者不得当作书的主张。

- [ ] 书已辨误之说没有当作书的主张。

## 练习手册

1. **三合默排**：任取一月，凭记忆写出该月的三合日与三煞所在，再回卷六核对。
2. **成组归并**：把本卷神煞按「三煞组／九神组／凶辰组／择日吉辰组」归类，体会书怎么把散神归拢。
3. **辨讹一句**：找出书里对曹震圭或旧历的一处辨正，用自己的话复述「书为什么不采某说」。
4. **成组归并**：把本卷神煞按「合冲取用／三煞取用／月建所生」三类归档，各举二例。
5. **月忌推演**：由「自初一至初五、自初五至十四、自十四至二十三皆距九日」推出月忌三日，说明其数理。

## 反例黑名单

1. **不要**只报神煞名而不给出处——违反本族硬口径。
2. **不要**把年三煞的方位当成月三煞的日辰，两层起例不同。
3. **不要**把「六合日忌嫁娶（无翘）」当成书的主张——书已判其应删。
4. **不要**把九神（要安至续世）说成修造吉神——书说专为祭祀择日而设。
5. **不要**用现代词给日神背书，也不要写成自我否定的腔调。

## 灰色地带

- **同名异层**：三合、劫煞、灾煞在年、月两层同义而立例不同。遇到时先问清用户说的是哪一层，再按下例。
- **九神性质**：书说九神「以寅申卯酉两两相比，皆不可得而符合」，意者「丛辰等家之遗绪」，只可用于祭祀。遇到时照书的态度给范围，不替它扩张用途。
- **吉凶相冲**：某日既是吉神所值又叠凶神，书只给倾向、不给断语；此时并列两方，按用户事项自参，不强行裁断。

- **同名异层**：三合、劫煞、灾煞在年、月两层义同而例不同。遇到时先问清用户说的是哪一层，再起例。
- **九神定性**：书判九神来源不明、只可用于祭祀。遇到时照书给范围，不替它扩张用途。
- **检验之辨**：书引「宋武帝以往亡起兵」之例，但判「不必以一事之无验而遽谓其可废」。遇到「某日不准」的质疑时，照书态度回应，既不承诺也不否定。
- **日辰神煞不与年方混**：本卷神煞随月建逐月轮转，属「取日」之用；年月两层的三煞、太岁之方另属他卷。遇到混问者，先分层再答。
- **吉凶相参**：同一日辰常叠数神，书只给倾向而不作断语。遇到用户要「一句话结论」时，先给倾向，再说清须取得的具体事项。
- **三件套的写法**：报一个日辰神煞，标准写法是「神煞名 → 卷六·義例四某条起例 → 宜忌（并注明是书取之义还是书已辨误者）」，三样缺一即不合格。
- **月害取「冲其所合」**：考原说「月建者众神之首，冲其所合是以害」，故月害之辰即月建所合之支被冲之位。遇到用户问某支为什么被害时，照此义解，不另造他说。
- **六合与无翘**：书判六合日宜嫁娶，而「无翘」之说与本义相悖，故「应删」。遇到历本仍载无翘者，说明书为何删而不擅从。
