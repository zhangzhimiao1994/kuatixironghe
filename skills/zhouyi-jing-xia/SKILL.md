## 触发条件

**应该触发**（用户会怎么说话）：
- 问下經某一卦的卦辞或爻辞「书里怎么写」「出在哪一卦哪一爻」——如「咸卦的卦辞是什么」「『憧憧往來，朋從爾思』是哪一爻」。
- 复述一句卦爻辞，想知道它在下經哪一卦、上下文是什么、这一爻处什么位置。
- 带着一件具体的事，想知道照下經某卦某爻这一类处境该怎么读（宜进还是宜守、这一步该不该现在迈）。
- 提到下經的卦名或用语：咸、恆、遯、大壯、晉、明夷、家人、睽、蹇、解、損、益、夬、姤、萃、升、困、井、革、鼎、震、艮、漸、歸妹、豐、旅、巽、兌、渙、節、中孚、小過、既濟、未濟；憧憧往來、不恒其德、羝羊觸藩、鳥焚其巢、君子豹變、有孚、悔亡、无咎。

**不应触发**（看起来像但其实不是）：
- 问上經（卦一 乾 – 卦三十 離）的卦爻辞 → 走上經那一支。
- 问十翼（彖／象／文言／繫辭／說卦／序卦／雜卦）或两家注疏的体例 → 走对应的传与读法一支。
- 要起卦、抽签、排盘、算命、批流年、断终身 → 本支不做占筮，照实说明只做读法与处境归类。
- 要医疗、法律、投资结论 → 不给结论，只做读法。
- 纯技术问题、单一事实查询（天气、价格、时间）、闲聊 → 直接回答。

## I：核心解释

下經三十四卦（咸三十一 – 未濟六十四）接着说上下卦之后的事：从夫妇之道（咸、恆）一路推到事之终（既濟、未濟）。

1. 下經每一卦同样由「卦辞 ＋ 六爻爻辞」组成：**卦辞**给这一卦的处境命名与宜忌，**爻辞**给这一处境里六个位置各自的边界。R 1–103 逐卦抄的就是这一层**經文**。
2. 「卦名＋卦次」是坐标，不是装饰：同一句「有孚」「悔亡」，出在損与出在困不是一回事。报卦必须给全三样——**卦名 ＋ 卦次 ＋ 原文**，再加一条「为什么是这一卦」的对应（见「判读口径」）。
3. 四家不是一回事：**經文**是文王、周公所系（即卦辞爻辞本身）；**王弼注**是魏王弼对经的注；**朱熹本義**是宋朱熹对经传的注，多按筮法与实际占断读；**孔穎達疏**是唐孔颖达等对王弼注的疏。R 104–107 各标一层，可对读。
4. 两家注疏、两本用字常有出入。例：革卦卦辞，孔疏本作「己日乃孚」（R 107），朱熹本義本作「已日乃孚」（R 106）；咸·九四「憧憧往來」，本義作「心之感物當正而固乃得其理」（R 104），孔疏作「凡物始感而不以之於正，則至於害」（R 105）。两说都摆，**各标出处，不合读、不调停**。
5. 书里的吉凶词（亨、无咎、悔亡、凶、吝）是**经文本身的用语**，是这一卦这一类处境的边界记法，不是对某人某事的**事实**判决。
6. 象征层只命名处境、不承诺结果。一律写「倾向／按书里这一卦这一类读」，不写「一定／必然／命中／保证」。

## A1：来源应用

书上原样给的做法（不是我的发挥）：

- **先认卦，再认爻**：一句爻辞先落到「哪一卦·哪一爻」上，爻位本身就是处境的位置说明——「初九：曳其輪，濡其尾，無咎」（R 99）在既濟之初，「上六：濡其首，厲」（R 100）在既濟之极；同一卦里位置不同，许可与警告不同。
- **卦辞给宜忌成对**：蹇「利西南，不利東北」（R 39）——同一处境里两向并列；損「有孚，元吉，無咎可貞，利有攸往。曷之用？二簋可用享」（R 41）——先立条件再谈动作。
- **两本用字要照本抄**：革卦「己日／已日」（R 106、R 107）分属两本，各标出处；咸·九四两家读法不同（R 104、R 105），分栏并陈。
- **注疏各自标层**：读一句经文时，把孔疏的活动与王弼注的活动分开摆，读者自己看谁解谁的。

## A2：典型触发场景

1. 「『憧憧往來，朋從爾思』是哪个卦？卦辞是什么？」 → A 路（文本解读）：咸（卦三十一）·九四，附卦辞 R 1。
2. 「两个人刚在一起，我要不要使劲表达心意？」 → B 路（处境读法）：对照咸（卦三十一）九四（R 3）与六二「咸其腓，凶。居吉」（R 2），归到「感应初起、宜正而固、不宜纷扰求应」一类。
3. 「跟人翻脸了，还要不要继续拉扯？」 → B 路：对照睽（卦三十八）「小事吉」（R 21）与蹇（卦三十九）「利西南，不利東北」（R 39）。
4. 「事情推到一半推不动了，硬顶还是退？」 → B 路：对照蹇（卦三十九）上六「往蹇來碩，吉。利見大人」（R 41）与解（卦四十）「利西南」（R 42）。
5. 「老办法不灵了，改还是不改？」 → B 路：对照革（卦四十九）「己日乃孚，元亨利貞，悔亡」（R 82）与鼎（卦五十）「元吉，亨」（R 84）。
6. 「『不恒其德，或承之羞』这句书里在说什么？」 → A 路：恆（卦三十二）九三（R 5）。

## E：执行步骤

**第 1 步｜分流（两路共用）**　输入：用户原话 → 输出：走哪一路。
- 判据只一条——**输入里有没有他要问的那件具体的事**：
  - 只有卦／句、没有那件事 → 走 **A 路（文本解读）**，即第 1 → 2 → 3 步；
  - 带着一件具体的事要读 → 走 **B 路（落到处境上的读法）**，即第 1 → 4 → 5 → 6 步。
- 🔴 **CHECKPOINT**：拿不准就先按 A 路把文本讲清，再问一句他有没有具体的事要套。最多问 2 个问题。

**第 2 步（A 路）｜认卦归义**　输入：他问的卦／句 → 输出：卦名＋卦次＋原文＋这一卦（这一爻）的处境命名。
- 🔴 **CHECKPOINT**：认错卦、认错爻不如不认。认不准就照实说还缺什么，**不硬套一卦**。

**第 3 步（A 路）｜摆书里的条件并收口**　输入：卦／句 → 输出：逐字原文＋出处 ＋ 书里给这一处境的许可与不许可（宜进／宜守／宜先立条件）＋两家注疏**分栏并陈**（本義／疏各标出处，不同处不合读；两本用字不同时照本抄并标出来源）。
- 收口：只讲书里怎么讲，**不替用户决定、不预测结果**。

**第 4 步（B 路）｜归处境**　输入：他的事 → 输出：一类处境 ＋ **凭哪一条**（卦辞／爻辞／注疏的哪一句）这么归 ＋ 一条「为什么是这一卦」的细节对应（拿他提问里的哪个细节对上了它）。
- 🔴 **CHECKPOINT**：只丢一个卦名、说不出对上了哪一点，等于没给依据；对应不上就改卦或降低断言力度。信息不足以归到哪一卦哪一爻时，说清还缺什么，**不许硬套**。

**第 5 步（B 路）｜给方向**　输入：处境归类 → 输出：「按书里这一类读，偏 X」（宜进／宜守／宜先立条件）＋ 出处。
- 只做读法层面的事：这类处境下书里给的动作边界、宜进还是宜守、这一步该不该现在迈。**不做**：替用户决定、预测结果、断吉凶成事。

**第 6 步（B 路）｜收口并落一步**　收口：不起卦、不占卜、不抽签、不排盘、不算命、不批流年、不断终身；结尾落一个今天／这周能打勾的动作。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把疏文当经文 | 把孔疏或王弼注的话当卦辞爻辞报给用户，出处标成《周易》 | 回 `sources/zhouyi-zhengyi.txt` 认准这一段是经、是注、还是疏；R 节分层标清 |
| 两句合成一句 | 把朱熹本義与孔疏的说法揉成一句，看不出是谁的 | 两说分栏，各标出处，**不调停** |
| 擅改版本次序用字 | 把本義本的「已日」改成疏本的「己日」（或反之），当成一处 | 照本抄，两本并陈并标出来源 |
| 引卦不给卦次 | 只写「革卦说己日乃孚」，没有卦次与原文 | 补全卦名＋卦次＋原文三样 |
| 硬套一卦 | 用户信息不足，仍按一个卦给结论 | 说清还缺什么，不硬套；只做最宽泛的分类 |
| 越界占筮 | 用户要「算一卦」，就起卦、抽签、断吉凶 | 照实说明本支只做读法与处境归类，不进行占筮 |
| 把吉凶词当判决 | 写「你这件事悔亡」「必然吉」 | 标明是书里的用语：「按书里这一类读，偏悔亡／偏凶」，不当作事实结论 |
| 报卦无依据 | 只丢卦名，说不出提问里哪一点对上了 | 补一条细节对应；补不上就改卦或降力度 |

**边界规则**：
1. 只读下經（卦三十一 咸 – 卦六十四 未濟）；上經与十翼不在此支范围。
2. 引文逐字繁体原文，**异体字照本抄**，不改写成今字、不动标点。
3. 卦必须带卦名与卦次；爻辞带爻题。
4. 象征层只命名处境、不承诺；书里的吉凶词标明是书里的用语。
5. 内部归类名只作自己选路线的依据，**不进给用户的回答**；回答里只说用户自己讲的事与人。
6. 不越界：不起卦、不占卜、不预测结果、不替用户决定、不批流年、不断终身。

**自查清单**：
- [ ] 每条引文都能回到 `sources/` 三本源文件逐字对上（归一只留字形）。
- [ ] 报卦给了三样：卦名＋卦次＋原文，并有一条「为什么是这一卦」的细节对应。
- [ ] 层标清了：經文／王弼注／朱熹本義／孔穎達疏 各是哪一层。
- [ ] 两家注疏不同处两说并陈，没有调停成一句；两本用字不同处照本并陈。
- [ ] 没有出现「一定／必然／命中／保证」；吉凶词已标明是书里的用语。
- [ ] 收口没有起卦、占卜、预测、替用户决定。
- [ ] 回答里没有出现任何内部归类名（成员 slug、目录名、「属于 XX 类处境」）。
- [ ] 结尾落了一个能打勾的动作。

**安全兜底**：涉及就医／用药／心理危机时，只做提醒与陪伴，不做诊断；涉及法律、投资、人身安全时不给结论、不替用户拍板。

## 📖 练习手册

1. **分层练习**：任取一句（如「咸·九四：憧憧往來，朋從爾思」），在 `sources/zhouyi-zhengyi.txt` 里把经、王弼注、孔疏三段分开抄出来，各标一层；再看 `sources/zhouyi-benyi.txt` 里朱熹本義怎么说。
2. **归义练习**：合上本页，拿 5 句下經爻辞（如「不恒其德，或承之羞，貞吝」「鳥焚其巢，旅人先笑後號咷」），逐一写「这一卦＋卦次＋这一爻在什么位置」，再回 R 节核对。
3. **两本并陈练习**：取「革·己日／已日」一处，分别按孔疏本与朱熹本義本各写一句用字与读法，中间不写「其实一样」。

## 🚫 反例黑名单（不要做的事）

1. ❌ 把孔疏或王弼注的话当经文的卦辞爻辞报出去，出处标成《周易》。
2. ❌ 只写「某卦说……」，不给卦次、不给原文——等于没给依据。
3. ❌ 把朱熹本義与孔疏的不同读法揉成一句，读者看不出哪句是谁的。
4. ❌ 把两本不同的用字（如革·己日／已日）擅自统一，抹掉版本差异。
5. ❌ 用书里的吉凶词给用户的现实处境下判决（「你这件事悔亡」「必然吉」）。
6. ❌ 用户只给了一件事、信息不足以归卦，却硬套一个卦给结论。
7. ❌ 用户说「帮我算一卦」，就起卦、抽签、排盘、断吉凶。
8. ❌ 回答里出现成员 slug、目录名或「你的处境属于 XX 类」这种内部归类名。
9. ❌ 把「悔亡」写成「不会有遗憾＝一定没事」，或用现代术语给经文背书。

## 灰色地带

- **一句话同时像两卦**：不硬选一卦。先各读一遍（各属哪一类、宜进还是宜守），再说还需要用户补哪一点来定夺；确有多面则两卦对照并指明读的顺序。
- **经与注疏读法冲突**：不裁决。把经、注、疏、本義各摆一处，写明各自取法，让用户看到分歧本身。
- **两本用字不一**：不裁定哪本「对」，照本并陈并标出来源；用户若问，只说各本如此。
- **用户只报卦名不给事**：先按 A 路把这一卦的卦辞爻辞讲清；他要落到事上时再走 B 路。
- **用户要的就是占断结果**：照实说明本支只做读法与处境归类，不做占筮、不预测；可以退一步只讲这一卦这一类处境的书里条件。
