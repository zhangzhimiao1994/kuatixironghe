# 势来形止：千尺为势、百尺为形

**来源**：sources/zangshu.txt（《葬書》内篇三） ｜ 证据等级：firsthand（原书原话）

## I：核心解释

「势来形止」这四个字，是内篇三的骨。「势」「形」两字跟现代汉语里的意思不完全一样，得先归位。

1. **气的行与聚，看两个不同的距离**：「夫氣行乎地中，其行也因地之勢，其聚也因勢之止。」（R1）注疏说：「其始也則因地之勢而知其行也，其次也又因勢之止而知其聚也。」（见 R1 所在条注）**行**看的是地的势，**聚**看的是势在哪儿止住。这就是后文「势」与「形」分工的来处。
2. **做法只有八个字**：「葬者原其起，乘其止。」（R2）注疏把这八字展开：「善葬者，必原其起，起以觀勢，乘其止以扞穴。」（R14）——先追它的起处看势，再乘它的止处定穴。
3. **势与形各是什么**：「千尺為勢，百尺為形。」（R3）注疏说得分明：「千尺言其遠，指一枝山之來勢也。百尺言其近，指一穴地之成形也。山川形勢豈真有尺度之拘，特言其髣彿耳。」（R13）所以**势是远看的一条来势，形是近看的一穴成形**；千尺百尺是比方，不是拿尺去量。
4. **什么叫全气**：「勢來形止，是謂全氣，全氣之地，當葬其止。」（R4）远势来了、近形止住了，就叫全气；全气的地方，要把葬点落在「止」上。这一句是内篇三的核心断语。
5. **全气之地的融结之情**：书里连着用好几个比方形容它——「宛委自復，回環重復」（R5）说势与局弯环回抱；「若踞而候也」（R6）像人蹲踞而有所待；「若攬而有也」（R7）像贵人端坐、随手一揽什么都有；「欲近而卻，欲止而深」（R8）说拥卫之山要来朝拱、潴蓄之水要止聚渊澄。
6. **形气之验**：「來積止聚，沖陽和陰。」（R9）来山凝结、止水融会，阴阳交济；「土高水深，鬱草茂林。」（R10）水深则土厚、气冲和则草木茂——注疏引程子说这正是「地之美者」的验。
7. **书里的形容语**：「貴若千乘，富如萬金。」（R11）这是**书里对全气之地的形容**，不是承诺；读的时候要标清它是形容，不是保证。
8. **经的收束**：「經曰：形止氣蓄，化生萬物，為上地也。」（R12）形止住了、气蓄起来了，就是上地。
9. **「止」这个字最要紧**：注疏说「止之一字，乃錦囊要旨，故諄諄而屢言之」（R15）——全书反复讲「止」，是因为千里求龙、五尺入手，「纔差一指，盡廢前功」（R17）。注还引《指南》：「立穴若還裁不正，縱饒吉地也徒然。」（见 R17 所在条注）
10. **一句话读法**：原其起以观势（远）→ 察其止以定穴（近）→ 得全气之地则葬其止。势与形是同一段气的远镜头与近镜头。

11. **注疏把「聚」落在「乘」上**：堂局完密、形穴止聚，则生气藏蓄于中，「善葬者因其聚而乘之」——全气之地也要人去「乘」，不是摆在那里自动生效。
12. **止处为何最难**：书里把「止」提到「錦囊要旨」的高度（R15），因为同一片大局里，止与不止往往只差一线；注疏用「千里求龍，五尺入手，纔差一指，盡廢前功」（R17）形容这个落差。
13. **势与形的分工**：势是「一枝山之來勢」（远），形是「一穴地之成形」（近）（R13）。看势要问「它从哪来」，看形要问「它在哪儿止」；两问合起来，才是「原其起、乘其止」。
14. **全气之地的常态与难处**：书里并不说全气之地罕见，反而说「世之葬者，不乏全氣之地，但於其止處則有昧焉耳」——难得的不是全气，是认出止处。
15. **把内篇三收成一张表**：

| 词 | 书里指什么 | 出处 |
|---|---|---|
| 势 | 远看的一条来势 | R3、R13 |
| 形 | 近看的一穴成形 | R3、R13 |
| 原其起 | 追来势的起处看势 | R2、R14 |
| 乘其止 | 在止处定穴 | R2、R14 |
| 全气 | 势来形止 | R4 |
| 止 | 全篇要旨 | R15 |

16. **三处常见误解要拆**：其一，把「千尺百尺」当尺子去量；其二，把「貴若千乘，富如萬金」当承诺；其三，只看脚下这一穴的形，不问远来的势。三条在 B 节都给了退路。

## A1：来源应用

书上给的是看地的次序与落点：

- **次序**：先观远势之来，再察近形之止（R13、R14）。书里把两个距离分得很清，不混着看。
- **止处的地位**：「全氣之地，當葬其止」（R4）。书上把全地的地方也分两种情况：得全气之地不算最稀罕，难在认出它的「止处」——注疏说「世之葬者，不乏全氣之地，但於其止處則有昧焉耳」。
- **全气是什么样**：书里靠一串比方来认（R5–R10）：势要宛委回环、局要若踞若揽、山要趋揖朝拱、水要止聚渊澄、土要高深、草木要茂盛。
- **「止」是要旨**：注疏把止字提到「錦囊要旨」的高度（R15），并给出「差一指尽废前功」的警示（R17），可见书上把「止处」当成全篇最吃紧的一步。
- **形容语与断语分家**：「貴若千乘，富如萬金」（R11）是形容语，不是承诺；真正带贵贱断语的是雜篇品类条（本 skill 不取）。
- **「原其起」不只是记起点**：注疏说「起以觀勢」（R14）——追起处的目的是看清整条来势的走向与转折，宛委、顿息都在这一眼里，不是记一个坐标点。
- **全气是「势来＋形止」两件都齐**：只来不止、或只止不来，都不能叫全气（R4）；书上把这两件当一对，缺一件就先说缺哪一件，再谈别的。

## 练习手册

- **远近分野**：站在一处山地上，先记下「远的来势」，再记下「脚下这一穴的成形」，各写一句；不许写吉凶。
- **止处寻找**：任取一条熟路，只回答「它可能在哪儿止」，并写出你依据的是形还是水。
- **比方归位**：把「若踞而候」「若攬而有」「欲近而卻，欲止而深」三条各配一个自己的白话说法，看能不能不靠吉凶词讲清。
- **形容语剥离**：把「貴若千乘，富如萬金」改写成不含「富贵」二字的描述，练不把形容当承诺。

## 灰色地带

- **势好形不好 / 形好势不好**：书里在雜篇有专条论势形顺逆（属另一 skill），本 skill 只讲到「势来形止为全气」；遇到顺逆问题转 kanyu-zangshu-xing-shi-pin-lei。
- **一处地看不出止处**：照实说看不出，并列出需要补的信息（水口、周边、朝向）；不硬指一个点。
- **用户要「势形 + 贵贱」**：势形读法照讲，贵贱转品类 skill，并说明是两层。
- **用户问「全气之地是不是保证发达」**：把 R11 标成形容语，说明书里的断语也不是承诺，判断留给用户。
- **有势无形**：先按「原其起」讲清来势，再说明缺近形描述（止处、周边、朝向）时不判全气，请用户补上再谈。
- **把「势」当成口语里的『气势』**：书里的势指远来的一条形势（R3、R13），不是气势、气派；先把词义归位再讲。
- **用户要「千尺百尺」的实数换算**：直接说不换算——书里明说「豈真有尺度之拘」（R13），千尺百尺只作远近的比方。
