# 乘金相水、穴土印木

**来源**：《葬書》（舊題郭璞）外篇 ｜ 证据等级：firsthand（原书原话）

## R：原文锚点

1. "乘金相水，穴土印木。"（《葬書》外篇）
2. "此言穴中證應之玄策也。"（《葬書》外篇，《錦囊》注）
3. "金亦生氣之異名，言即其尖圓之所止也。"（《葬書》外篇，《錦囊》注）
4. "相水者，言金魚界合相輔於左右也。"（《葬書》外篇，《錦囊》注）
5. "穴土者，土即中央之義，謂穴於至中，取沖和之氣，即葬口是也。"（《葬書》外篇，《錦囊》注）
6. "印木即兩邊蟬湖之砂，夾主蝦須之水，以界穴地。"（《葬書》外篇，《錦囊》注）
7. "夫土欲細而堅，潤而不澤，裁肪切玉，備用五色。"（《葬書》外篇）
8. "沖和之處，則必有五色異土以應之。"（《葬書》外篇，《錦囊》注）
9. "大幾作用之法，隨宜料理，千變萬化，本無定方，全在人心目靈巧，以類度類，觸而長之"（《葬書》外篇，《錦囊》注）

引文说明：第 1、7 条是经文；第 2–6、8、9 条是《錦囊》注。第 1 条经文的四法（乘金、相水、穴土、印木）各三到四字，其后经文如土色、沖和两条，是书里另起的证应条目，与四法同属这一段的证应体系。第 6 条里蟬湖照原样抄，今或写作蟬翼，不改字。

## I：核心解释

这一段的关键，是先把「四法」的**身份**摆正：注里第一句就说「此言穴中證應之玄策也」——四法是**用来证实穴心位置的四样应证**，不是四招可以拆开单用的花样。

1. **乘金**——「金亦生氣之異名，言即其尖圓之所止也」。金在这里是**生气的别名**；所谓乘金，就是认取那个**尖圆之势所止**的地方来承受生气。所以「乘金」落到形上是「尖圆之所止」，落在理上仍是乘生气。
2. **相水**——「相水者，言金魚界合相輔於左右也」。金鱼即水界交合之处；相水看的是**穴的两侧水势是否界合、是否辅于左右**。
3. **穴土**——「穴土者，土即中央之義，謂穴於至中，取沖和之氣，即葬口是也」。土取「中央」之义：把穴安在**至中**的地方，取的是**沖和之气**，这个位置书里就叫**葬口**。
4. **印木**——「印木即兩邊蟬湖之砂，夾主蝦須之水，以界穴地」。两侧的蝉湖之砂夹住中间的虾须之水，用来**界定穴地**的边界。这是把穴的四界「印」下来。
5. **四法合看，缺一不证**——四样分别是上（尖圆止处）、左右（金鱼界合）、中（穴于至中）、边界（蝉湖夹虾须）。它们合起来构成「穴中证应」，所以书里说这是「玄策」（窍要之策），不是随手取一样就能定穴的。
6. **土色是穴土一层的实证**——「夫土欲細而堅，潤而不澤，裁肪切玉，備用五色」，注里说「沖和之處，則必有五色異土以應之」：沖和之处会以五色异土相应。这是把「取沖和之气」从理落到了看得见的土上。
7. **作用无定方**——四法是「证应」，落到具体处理，书里说「目力之巧，工力之具，趨全避闕，增高益下」，且「隨宜料理，千變萬化，本無定方，全在人心目靈巧」。也就是说，四法给的是**认取的口径**，不是一套固定尺寸的施工图；注里还串了一长串（水底眼、剪刀交、羅紋土宿、十字天心、蟹眼水之类）别名，书里自己也承认「卒難通曉」。

一句话收束：这一节回答的是**「凭什么说这里就是穴心」**——金认上、水认左右、土认至中、木定边界，四样都应上了才叫「穴中證應」；书上给的是认取口径，具体处理「本無定方」。

**四法定位速览**（每一行都能追回上面 R 节）：

| 法 | 认的是哪一处 | 书里的话 |
|---|---|---|
| 乘金 | 上：尖圆之势所止 | 金亦生氣之異名，言即其尖圓之所止也 |
| 相水 | 左右：金鱼界合辅于左右 | 相水者，言金魚界合相輔於左右也 |
| 穴土 | 中：穴于至中、取沖和、即葬口 | 穴土者，土即中央之義，謂穴於至中，取沖和之氣，即葬口是也 |
| 印木 | 边界：蝉湖之砂夹虾须之水以界穴地 | 印木即兩邊蟬湖之砂，夾主蝦須之水，以界穴地 |

这张表最要紧的是它**四项各管一个方位**：上、左右、中、边界，合起来才是完整的一次「证应」。所以用户若只拿出其中一项，判定里就要写明另外三项缺不缺，不能拿一项顶全套。

另外要记住它的大前提「此言穴中證應之玄策也」：四法的作用是**印证**穴心，不是主动去「造」一个穴；所谓「乘」「相」「穴」「印」四个字，说的都是向着已经存在的形势去认取、去印证。

## A1：来源应用

书上给的具体做法（不是本 skill 的发挥）：

- **逐词释义**：乘金＝认尖圆之所止（金为生气异名）；相水＝看金鱼界合是否辅于左右；穴土＝穴于至中、取沖和之气，即葬口；印木＝两边蝉湖之砂夹主虾须之水以界穴地。
- **定性**：四法的总性质是「穴中證應之玄策」——证应，不是四个独立招法。
- **土色佐证**：土欲細而堅、潤而不澤、裁肪切玉、備用五色；沖和之处有五彩异土相应。
- **合证**：四样分别管上、左右、中、边界，合起来才是一次完整的证应。
- **认边的两样要分清**：相水认的是「金魚界合相輔於左右」（水这一层），印木认的是「兩邊蟬湖之砂，夾主蝦須之水」（砂与水夹出的边界）。两者位置都在两侧，但一个从水的界合说、一个从砂水夹界说，判读时不要合成一句含混的「两边有水有砂」。
- **作用口径**：目力之巧、工力之具，趨全避闕、增高益下；隨宜料理，本無定方。
- **书的断语**：注里那一长串穴法别名，书里自称「卒難通曉」，本 skill 遇到时只说明它是同套证应的别名，不逐条替它解成自己的玩法。

1. **定性先行**　输入：用户的问题（要释义还是要对证） → 输出：先声明四法是「穴中證應之玄策」这个身份，再逐项展开。
   🔴 **CHECKPOINT**：若用户把它当四招独立法门来用，先停下来纠正身份（证应，不是四个招法），纠正后再释义。
2. **逐项释义**　输入：乘金／相水／穴土／印木任一项 → 输出：该项的经文＋《錦囊》注释义（金＝尖圆之所止；水＝金鱼界合辅左右；土＝至中取沖和即葬口；木＝蝉湖夹虾须以界穴地），并回标出处。
3. **按证据分层**　输入：用户给的穴场证应描述 → 输出：四样各对应上了没有（上／左右／中／边界四项），哪几项缺或说不清。

4. **补土色一层**　输入：土色土质 → 输出：是否合「細而堅、潤而不澤、裁肪切玉、備用五色」「沖和之處有五色異土」的倾向判断。
5. **收口**　输入：上面各栏 → 输出：一段总结，含「本無定方」的提醒、「不能下的结论」与待补观察；凡属书的断语（卒難通曉之类）都标明是书里的说法。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把四法当成四招可拆用 | 写「只乘金就能定穴」 | 回到第 1 步纠正身份：四法是穴中证应，合格要合看 |
| 金鱼界合被说成固定之物 | 硬说金鱼一定指水或一定指砂 | 按注里口径只给「界合辅于左右」的释义，不替它指派 |
| 只有穴心描述就断四法皆合 | 用户没给两侧砂水，就说印木也对上了 | 回到第 3 步列缺项，缺项就不计入证应 |
| 把穴法别名当自创玩法 | 逐条解释水底眼、十字天心等成一套术法 | 只说明它们是同套证应的别名，书里自称难晓，不外扩 |
| 越界给现场指令 | 直接编尺寸、深度、朝向 | 本 skill 只做释义与证应归类，作业指导不接 |

**边界规则**：
1. 缺穴场证应（两侧砂水、穴心位置）时，只给释义与缺项，不硬判证应是否齐备。
2. 四法只作倾向表述，不写成「四法皆合必然发」。
3. 书里的断语（玄策、卒難通曉、五色异土之类）是书里的说法，引用即标明。
4. 穴法别名一长串，不逐条替用户扩成新玩法。
5. 不接阴宅实地作业指导，不给医疗、法律、投资结论，不替用户拍板。

## 练习手册

- **四法各归一位**：合上 I 节，把乘金、相水、穴土、印木分别对到穴的「上／左右／中／边界」四个位置，各写一句理由。
- **身份校正**：写下「如果只懂乘金一招，能不能定穴」，再用书里「穴中證應之玄策」一句反驳自己，说清为什么四样要合看。
- **土色对证**：给一段土色描述（细坚、润泽、颜色），按书里判断它偏「沖和有五色异土」还是偏「枯硬」，并说明这只是一种倾向。
- **缺项点名**：取一处穴场描述，逐项点名乘金、相水、穴土、印木四样对得上没有，凡说不清的一律记成缺项，看最后还剩下几项证应。

## 反例黑名单

1. 把「乘金相水，穴土印木」说成四招可以拆开单用的定穴法——注里明说这是「穴中證應之玄策」，证应要合看。
2. 把「金鱼界合」硬指派成一定指水或一定指砂——书里只说界合辅于左右。
3. 逐条把水底眼、十字天心等穴法别名扩成一套自创玩法——书里自称「卒難通曉」，本 skill 只作别名说明。
4. 用户只给穴心就判四法皆合——缺两侧砂水就缺印木的证应，须列缺项。
5. 用户只给释义要求却硬塞现场开挖指令——越界，作业指导不接。
6. 把四项证应里的某一项说成「没有也不碍事」——书里四法是合看的证应，缺一项就不算证齐。

## 灰色地带

- **经文与注的分工**：经文只四字一句，四法的细目全在注里。遇到注比经文说得更细处，标明「这是注疏的展开」，不把注的细节说成经文原文规定。
- **四法对不齐**：用户给的一处穴场，四项证应里有两三项对不上——按书里四法合看的口径，如实说「证应不齐」，不给「勉强也算穴」的软话，也不下「必非穴」的硬判。
- **别名难晓**：注里那串穴法名目书里自己说「卒難通曉」。用户追问某一条（如十字天心）时，只能说它属同套证应的别名、本节未展开，不凭记忆另讲。
- **土色与穴土不完全重合**：穴土讲的是「至中取沖和」这个位置，土色讲的是土本身的细坚润泽与五色。两者相关但不是一件事：土色好而位置不对，仍不合「穴于至中」；位置对而土色枯硬，也只是倾向偏差。遇到只给一头的描述，分开陈述，不合成为一句。
