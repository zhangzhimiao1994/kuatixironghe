# 立成：起例与查表

**来源**：sources/xieji.txt（《欽定協紀辨方書》卷九·立成） ｜ 证据等级：firsthand（原书原话）／ inference（推断，须标注）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户翻一本通书或时宪书，指着某一列神煞问「这个是怎么起出来的」「从哪个干、哪一支、哪一节起算」。
- 用户要把年、月、日、时四层的吉凶神煞汇成一张能查的表，问该按什么分类。
- 用户问「年神、月神、日神、时神各分几类起例」，或直接问某一类（如「随月建三合」）底下有哪些神。
- 用户拿两份通书对照，发现同一神煞列对不上，问两边的起例差在哪。
- 用户要核一张自己排的神煞表，想知道某一格是根据哪条起例填的。

**不应触发**（看起来像但其实不是）：
- 用户只想要某个具体日子的宜忌结论（这天能不能嫁娶）→ 归 `kanyu-xieji-yi-ji`（卷十·宜忌）。
- 用户问某件具体的事该看哪些神、宜什么忌什么 → 归 `kanyu-xieji-yong-shi`（卷十一·用事）。
- 用户要问神煞名义与义理（为什么叫天德、为什么叫劫煞）→ 归义例各卷的 skill（`kanyu-xieji-yue-shen`／`kanyu-xieji-ri-shen`），立成只管「怎么起、怎么列」。
- 用户要相地看山形水口朝向 → 不归本 skill，归堪舆分支的相地 skill。

## I：核心解释

立成这一卷的定位，从开篇原话就能读出来：义例（理）已经各为一篇讲完了，但「不能一覽而盡其條理」，所以要把神煞「各分起例以類相從」汇成表——它是**查表之具**，不是义理的重复。因此本 skill 的口径是「给方法与表，不给吉凶结论」：神煞叫什么、从哪起，归这一卷；这个神煞是好是坏、值日宜忌，归卷十。

1. **立成按「起例」分类，不按吉凶分类**。原话「各分起例以類相從」规定组织原则：先看一个神是靠什么起出来的，再把它放进对应类目，同一类里列神名与干支／日数。
2. **四层分开起例**。年神一套类目、月神一套、日神一套、时神一套，四层不能混。年神从岁干／岁支／三合／三元／岁纳音起；月神从岁干／三元／岁支／八节九宫／月建三合／四序／厌建等起；日神分「取一定干支」「按年取干支」「按月取日数」「按月朔取日数」「按节气取日数」五类；时神从日干起、从日支起、随月将、随月将及日干支、随日六旬。
3. **表里一行就是一种起例的落点**。「天恩 甲子 乙丑…」是「取一定干支」类的落点；「四離 冬至 夏至 春分 秋分 各前一日」是「按节气取日数」类的落点；「長星 正月〈七日〉」是「按月取日数」类的落点。查表就是先定类目，再在类目里找这一年的干支或这一月的日数。
4. **「月家吉凶神又合建除叢辰諸家以輕重為次第」**说明月神表不是一个体系，而是把建除家、丛辰家等诸家的吉凶神合到一处，再按轻重排。所以月神类目里会同时出现「随月建三合」「随四序」「从厌建起」这些互不相同的起法。
5. **立成给出的是「由起」的入口**。原话「神煞之所由起……今将……另編立成」，意思是：想知道一个神从哪起、哪一天轮值，就在这一卷找类目；想追问它为什么吉、为什么凶，要回到义例与宜忌两卷。（补充）实践上应「先回义例定名义，再回立成定起例，最后回宜忌定取舍」，三步分属三卷。
6. **类目与条目是两层，查表不跳步**。卷九先列类目名（如「年神從嵗干起者」），再在类目下列神煞与干支／日数（如「日神取一定干支者 天恩 甲子 乙丑…」）。查表先归到类目，再落到该类具体行；先看条目再回头猜类目，容易张冠李戴。
7. **「按語」与「起例本体」要分开**。卷九在类目与条目之外偶有「按……」的考订语，那是编者的话，不是起例本体；报起例时引类目名与干支／日数，不拿按语当起例。
8. **通书与时宪书取用不同，立成要并列**：原话说「年神方位通書時憲書取用各有不同」，所以立成不是单一源，而是把通书、时宪书、万年书三处的神煞「彚列成表」。核表时若两本不一致，先看各自取自哪一例，再判定差异来源。

## A2：典型触发场景

1. 用户看通书上印着「天恩」，问「天恩日是怎么定的、一年有哪几天」。
2. 用户想给一个项目排「年方位」与「月吉凶神」两张表，问该按什么起例排、年神和月神分别有几类。

## E：执行步骤

1. **锁定对象与层级**　输入：用户的一句提问 → 输出：判明属于「神煞→起例」「日期→该日神煞」还是「整卷类目归类」，并标出年／月／日／时四层中的哪一层。
   🔴 **CHECKPOINT**：把判明的层级与对象复述给用户（「你要查的是〔某神〕在〔某层〕按什么起例」），确认后再往下。
2. **回义例定名义**　输入：神煞名 → 输出：该神在义例里的名义与所属卷次；若该神不在义例可查范围内，直接说明并转邻 skill，不硬套起例。
3. **套起例类目**　输入：神煞名＋层级 → 输出：它落在立成的哪一类起例（从岁干／从三元／随月建三合／按节气取日数……），并写出该类目在卷九的原文类目名。
4. **列对应干支或日数**　输入：类目＋具体年份／月建／节气 → 输出：该神对应的干支或月内日数（如四离＝二至二分各前一日）。
   🔴 **CHECKPOINT**：若缺年份、缺月建或缺节气，当场列出缺什么、要到什么程度才能排；**不许用占位干支或占位日期硬排**。
5. **汇表**　输入：多条神煞 → 输出：按「年／月／日／时＋起例类别」分组的表，每条附卷九依据（《欽定協紀辨方書》卷九·立成）。
   🔴 **CHECKPOINT**：表只列起例与出处，不写吉凶结论；请用户确认表是否完整，再决定要不要转卷十。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只报神煞名，不给起例与卷次 | 甩一句「这天有天恩」 | 补「起例来源（卷九哪一类）＋卷次依据」；补不齐就不报，回卷九核 |
| 把立成当宜忌用 | 拿起例表说「这天宜嫁娶」 | 立成只给起例与表；吉凶结论回卷十（`kanyu-xieji-yi-ji`） |
| 无具体年月日就硬排 | 自己编一个干支往下推 | 缺什么说什么：要年份／月建／节气，缺则不出表 |
| 拿后世术家说法当原书 | 引通书别本或坊刻起例 | 只引卷九原文；后世说法标（补充）并说明依据 |
| 类目张冠李戴 | 把月神说成年神、把日神说成时神 | 回卷九类目名单逐条对，年／月／日／时不可混 |
| 用有标点的义例句子冒充立成原文 | 引一句「義例」里的说文当起例 | 立成里凡「按……」句属按语，起例本体是类目名与干支／日数 |

**边界规则**：
1. **报神煞／报起例必须同时给起例来源与卷次依据**：起例来源写清是卷九哪一类目，卷次依据写到卷与篇（《欽定協紀辨方書》卷九·立成）。只报一个名字不给出处＝不合格。
2. **数据不足照实说**：没给具体日期、没给层级，就说缺什么、要到什么程度才能判，不许用占位日期硬判。
3. 本 skill 是方法不是数据：不给吉凶、不给宜忌、不替用户拍板。

**来源边界**：本 skill 只据 sources/xieji.txt（《欽定協紀辨方書》）卷九·立成。神煞名义在义例各卷，具体宜忌在卷十，事类在卷十一；越界即引用邻卷而不冒充卷九。

**自查清单**：
- [ ] 每条神煞都带了卷九类目名与卷次依据
- [ ] 年／月／日／时层级没有混
- [ ] 没有越界给吉凶宜忌结论
- [ ] 自己的补充都标了（补充）
- [ ] 正文只留原书语汇，没有夹带外部系统或程序的名词

## 练习手册

- **给神煞判层**：随手挑三个神煞名（如天恩、三合、四大吉時），先判它属年／月／日／时哪一层，再去卷九找它属于哪一类起例，写出类目名。
- **默写日神五类**：合上正文，凭记忆写出日神的五类起例（取一定干支／按年取干支／按月取日数／按月朔取日数／按节气取日数），每类各举一个神。
- **四离四绝自推**：不看原文，先自己写四离、四绝的节气起算规则，再对卷九原文（「各前一日」）改正。
- **分层默写**：把年神十类、月神十九类、日神五类、时神五类的类目名各默写一遍，只看类目名复述每类的大致起法。

## 反例黑名单

1. **只丢一个神煞名不给起例与卷次** —— 硬口径：只报名字不给出处＝不合格。
2. **把立成的起例表当吉凶结论用** —— 起例是「从哪起」，不是「宜不宜」。
3. **年神月神混为一谈** —— 四层各有类目，混层即错。
4. **无日期时编一个干支往下排** —— 数据不足就说缺什么，不造占位。
5. **引通书别本或后世术家起例当原书** —— 只认 sources/xieji.txt 卷九；后世做法一律标（补充）。
6. **把「通书」「时宪书」「万年书」当同一套取用** —— 原书明说三者「取用各有不同」，核表要分别标源。

## 灰色地带

- **同一神名在年／月／日多层都出现**：分别按各层类目各给一条，不合并成一个「总起例」。
- **用户只给「想挑个吉日」而没给神煞名**：说明本 skill 管「怎么起例」，宜忌取舍要转 `kanyu-xieji-yi-ji`，事类要转 `kanyu-xieji-yong-shi`。
- **用户给的是农历日期但没给节气**：属于「按节气取日数」一类的神（四离四绝、气往亡）算不出来，明说缺节气即可，其余类别照常。
- **用户拿的条目只在义例里出现、立成未列**：照实说「卷九未列此条」，改引义例卷次，不替它编一条起例。
- **用户要「一张总表」但不说用途**：先问用途（铺注万年书／核通书／自学），再决定按年／月／日／时哪几层出表，不一股脑全列。
