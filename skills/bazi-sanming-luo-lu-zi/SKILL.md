## I：核心解释

这一篇在原书里叫「消息賦」，篇题下写「珞琭子註育吾子解」（原书标题）。读它的关键是分清**賦文本身**和**夹在〈〉里的各家解**——原书把賦句与注、解混排，解又不止一家（下面几条能看出来）。每条读法都能追回 R 节。

1. **开篇先立「三命」的架子**。「元一氣兮先天，禀清濁兮自然，著三才以成象，播四氣以為年。」（R1）据本篇解，三命是「以干為祿謂之天元，以支為命謂之人元，以納音為身謂之地元」——一句賦就把干、支、納音分成三層立起来。
2. **干祿看「向背」，支命看「逆順」**。「以干為祿向背定其貧富」（R2）：干祿要论向还是背，向祿、背祿决定贫富那一层；「以支為命詳逆順以循環」（R2）：支这一层要看逆顺，阳男阴女从生月顺行、阴男阳女从生月逆行，往來循环。
3. **行運的推法也在这篇里给了口子**。「運行則一辰十歲，折除乃三日為年。」（R3）本篇解把它叫作「古人立運之法」，又说要明「實歴之數」，因为「命有節氣淺深不同，運有就生就節互異」——同一个运，生節前后能差出分量。
4. **赋里反复讲的是「氣」的进退**。「其為氣也，將來者進，成功者退。」（R4）解里用五行的王相休囚说：将来的一步要进、已经成事的一步要退；「當權者用之為福，不當權者用之無益」。这是全赋读气口的一句。
5. **赋最看重「见与不见」**。「見不見之形，無時不有；抽不抽之緒，萬古聨綿。」（R5）解里举「不見寅而見戌」为「不見之祿」，「不見酉而見未」为「不見之官」；又说這種「抽不抽」的緒「出入無疾，往來不窮」。后面那半篇，多是围着这句展开。
6. **由「见不见」生出「无合有合」**。「無合有合，後學難知；得一分三，前賢不載。」（R6）本篇解作：甲与巳合而不见巳、得午，缘「午中有巳祿」；寅与亥合而不见亥、得壬，缘「亥上有壬祿」；又「得一祿而分三祿」。到卷六禄元三会一节，原书把这条落成「禄有三㑹……又謂之得一分三」（R13）与「支作人元運啇途而得失」（R14）。
7. **神煞层也没落下**。「是以河公懼其七煞，宣父畏其元辰。」（R7）赋把七煞、元辰举为「煞之最凶」；同篇解里「當憂不憂頼五行之救助」（R11）又给出对治方向——五行相救可以解。
8. **貴与富分在两层**。「天元一氣定侯伯之遷榮，支作人元運商徒而得失。」（R8）本篇解：干祿那层清秀、吉将加临，人得之而贵；支命那层纯粹、四柱比和，人得之而富。一句赋把「贵」与「富」各挂一层。
9. **寿夭也给了向，不给绝断**。「若乃身旺鬼絶，雖破命而長年；鬼旺身衰，逢建命而夭夀。」（R9）这是书里的说法：受制有轻重、制物则寿。读的时候只读它的倾向，不当作对某个人的事实判词。
10. **禄马是一对反复出现的抓手**。「背祿逐馬守窮途而恓惶，祿馬同鄉不三台而八座。」（R10）本篇解分「背」「逐」二字、又讲禄马同乡。到卷四那两节（R12），珞琭子的「遇而不遇」「禄馬歸着」被拿来收口，意思是禄马要看归着、要看赶上没赶上。
11. **原书自己也怀疑这篇的来历**。「珞琭子世有元理消息賦一篇謂其所作，然觀其文殆後人偽撰，非路琭之本真也。」（R15）这是卷七子平説辯里的一段考据，读赋时要知道：书里既用它，又存疑。
12. **一句收拢的读法**：先认「三命」（干祿／支命／納音身），再看「向背、逆順」，再读「氣的进退」，后读「见不见之形」「無合有合」，最后把神煞（七煞、元辰、禄马）挂到三层上去。赋句与各家解要分开标。

## A1：来源应用

书上给的做法（不是我的发挥）：

- **賦句与注、解要分栏读**。原书把「消息賦」写作「珞琭子註育吾子解」（卷十一标题，见 R 节出处），正文夾〈〉处既有「○瑩和尚曰」「○徐子平解」这类别家，也有「王廷光解」；同一句赋不同家解得未必一样，读的时候要标清是賦文还是注、是哪一家。
- **「见不见」是本篇的抓手**。原书用「甲祿寅，寅為顯見之祿」对「不見寅而見戌」解成「不見之祿」、「不見酉而見未」解成「不見之官」（R5 解）；又用「無合有合」与「得一分三」把「见不见」往合局上接（R6、R13）。这是原书给的读法，不是自造的零件。
- **行運的推法原书给了口子**。「運行則一辰十歲，折除乃三日為年」（R3）后，原书解要「明實歴之數」，并说节气候深浅不同、就生就節互異。要具体排运，本族另有排盤的一节，本 skill 只取原书的这一层口径。
- **珞琭子云在诸格里的用法**。卷四讲六乙「鬼作截福」时引「當憂不憂頼五行之救助」（R11）、讲六庚「禄鬼孤害」时引「遇而不遇禄馬之說」（R12）；卷六讲禄元三会时引「禄有三㑹」「得一分三」（R13）、讲絶地财官时引「支作人元運啇途而得失」（R14）。原书是拿赋句来点格，不是另立一套。
- **考据那一层也要照实带**。卷七「子平説辯」说这篇「殆後人偽撰」（R15）；四库提要亦说所引珞琭子与永乐大典所辑完本「其文迥殊」。这两句属于书里的说法，引用时标明是书里的意见。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、四柱干支（干祿那一层看天干、支命那一层看地支）、四柱里有没有化合成局、见不见之形（如不见寅而见戌之类）。
2. **逐条核书里的条件**：干祿的向背 → R2（以干為祿向背定其貧富）；支命的逆顺 → R2（以支為命詳逆順以循環）；气的进退 → R4（將來者進成功者退）；见不见之形 → R5（不見寅而見戌）；无合有合 → R6、R13（得一分三）。
3. **给读法倾向**：一句「按赋句看这盘合不合这一条，偏 X」——如「干祿向而不背，按 R2 这一路看，这盘合『向祿定其貧富』的前半条」。
4. **收口**：这一句是**按赋句看合不合这一条**，不是对某人的断语；**不推应期、不把赋句当断语、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：原书没有拿现代分数量尺去给珞琭子賦评分；没有「喜用神自动判法」这类后世做法；也没有把「得一分三」「见不见」简化成某种现成口诀。缺什么就说什么，不补。

6. 用户在卷六诸格里看到「珞琭子論」「禄元三會」底下又引珞琭子句，问这两处对不对得上。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。

   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **分清问的是賦句还是命造**（文本解读）　输入：用户的话与被引的句子 → 输出：判是在问赋文与读法，还是在问某个八字。
   🔴 **CHECKPOINT**：若是问某个八字吉凶，先说明本 skill 只讲珞琭子賦的赋句与读法，判命造要转 bazi-sanming-ming-li 或相应格节，问用户要哪个。
3. **认三命的架子**（文本解读）　输入：R1 的赋句 → 输出：用本篇解把「干為祿（天元）／支為命（人元）／納音為身（地元）」三层讲清，各挂原句。
4. **讲向背与逆順**（文本解读）　输入：R2 → 输出：干祿论向背、支命论逆顺两层，分别落到「向祿則生背祿則死」与本篇解的顺逆循环。
5. **讲气的进退**（文本解读）　输入：R4（必要时带 R9）→ 输出：用五行的王相休囚讲「將來者進，成功者退」，并说明同一步运「當權」与否分量不同。
6. **讲见不见与无合有合**（文本解读）　输入：R5、R6 → 输出：先讲「見不見之形」，再用「午中有巳祿」「亥上有壬祿」「得一祿而分三祿」把「無合有合」接上；卷六的 R13、R14 作旁证时标明出自诸格节。
7. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干、四柱干支、有无化合成局、有无「見不見之形」（如不见寅而见戌）。
8. **逐条核赋句条件、给读法**（落盘）　输入：第 7 步的料 ＋ 本 skill 的赋句条件 → 输出：
   - 干祿向背（R2）→ 支命逆順（R2）→ 气的进退（R4）→ 见不见之形（R5）→ 无合有合（R6、R13）；
   - 一句「**按赋句看这盘合不合这一条**」＋ **出处**（如「《三命通會》卷十一·珞琭子註育吾子解」）。
   - 🔴 **此步只到「按赋句看这盘合不合这一条」**：**不推应期、不把赋句当断语**，判命造转 bazi-sanming-ming-li。
9. **收口并报缺**　输入：整段推演 → 输出：一句三命架子 + 一句向背逆顺 + 一句见不见；若用户在问某人，照实说缺哪几柱就不判。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把賦句当命造判词 | 拿 R9 去断某人寿夭 | 拉回「这是书里的说法」这一层，只读倾向 |
| 把注、解当賦文 | 把「徐子平解」「瑩和尚曰」说成珞琭子原句 | 按原书分栏，标清是賦文还是某家注 |
| 拿后世术语给赋句背书 | 用「喜用神计分」「调候打分」解释「將來者進」 | 删掉后世说法，只按原书的王相休囚讲 |
| 凭记忆补赋句 | 写出原书没有的「某某賦云」 | 只引 R 节逐字核对过的句子，核不过就删 |
| 缺柱硬排 | 用户只给生日时段就往下断 | 照实说缺哪几柱、要齐到什么程度才能排 |
| 越界断终身/流年 | 由赋句推某人今年运程 | 不接，说明本 skill 只讲赋句读法 |

**边界规则**：
1. 只讲珞琭子賦（消息賦）的赋句与本篇注、解，以及诸格节里引到的珞琭子句。
2. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 书里的断语（如「長年」「夭夀」「不三台而八座」）引用时标明是书里的说法，不当作对某人的事实判决。
4. 不批流年大运、不断终身、不判生死寿夭，不替用户做婚姻/职业/医疗决定。
5. 不给医疗、法律、投资结论。
6. 缺出生年/月/日/时任一柱或缺出生地，照实说缺什么，不用占位信息硬排。

## 📖 练习手册

- **三命默写**：合上 R 节，凭记忆写出珞琭子赋立三命的那句，再补出干、支、納音各是什么元。
- **赋句定位**：把「見不見之形」「無合有合」两句各配一个本篇解里的例子，说明它俩怎么接。
- **分栏练习**：任取 R 节一句，用原书的写法标出哪一段是賦文、哪一段是注或解。
- **口气对照**：以「將來者進，成功者退」为例，分别用「书里的说法」和「我自己的话」各写一句，注意别把后者混进前者。

## 🚫 反例黑名单（不要做的事）

1. 拿赋句当命造判词，替某个人断寿夭、断贫富终局。
2. 把「徐子平解」「瑩和尚曰」「王廷光解」说成珞琭子本人的话。
3. 用「喜用神计分」「调候打分」等后世说法冒充原书的读法。
4. 凭记忆写赋句，不逐字核源文件。
5. 用户只给生日时辰，就往下排、往下断——先说缺什么。
6. 把四库提要与卷七的考据说成定论，或反过来拿它当「灵驗」的背书。
7. 说珞琭子賦是「某位当代人」的作品或套用到当代人身上。

## 灰色地带

- **书里既用它又存疑**：卷七说这篇「殆後人偽撰」（R15），四库提要又说所引与永乐大典完本「其文迥殊」。两说并存，照实带出，不替原书拍板作者是谁。
- **同一句赋几家解不一**：如「生月帶祿」有王廷光解、瑩和尚解、徐子平解三说。遇冲突就把几家并列标清，不硬归一说。
- **「得一分三」两处说法**：卷十一解作「得一祿而分三祿」，卷六又落成「禄有三㑹……是指臨官之禄」（R13）。两处都是书里的说法，并列呈现，不自行折中。
- **用户要「赋句＋判我这张盘」**：赋句照讲，判盘的部分转 bazi-sanming-ming-li，并说明缺哪几柱。
- **用户把「消息賦」与「元理賦」当同一篇**：原书卷十一有珞琭子註（消息賦），卷十二另有「元理賦〈徐大升著萬育吾解〉」，是两篇，先分清再答。
