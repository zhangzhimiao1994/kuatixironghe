# 公规：祀典、春牛经、气候、更漏中星

**来源**：`sources/xieji.txt`《欽定協紀辨方書》卷十二·公規一、卷十三·公規二（清乾隆官修，四庫本） ｜ 证据等级：firsthand（原书原话）/ inference（推断，须标注）

## 触发条件

**应该触发**：
- 用户问某个节气落在哪一月建、哪一月将（如「立春是几月建」「冬至以后月将是什么」）。
- 用户问到择日所依的历法底座：昼夜永短、日出日入时刻、朦影（晨昏分）、昏旦中星、更漏五更怎么推。
- 用户问官方祀典与迎春、春牛芒神的造法与用日。
- 用户拿一个具体日期，要核对节气、中气、七十二候。
- 用户问「择日到底依什么算」，需要先把历法常例立起来再谈神煞。

**不应触发**：
- 用户直接问某年某日某神煞吉凶 → 归义例类条目（如 `kanyu-xieji-yi-li-nian-shen`）。
- 用户问怎么制煞、补龙扶山修方 → `kanyu-xieji-zhi-sha`。
- 用户问四柱造命、补龙相主 → `kanyu-xieji-li-yong-zao-ming`。
- 用户问世俗相沿的择日小条目（洗头日、太白游方之类） → `kanyu-xieji-fu-lu`。
- 用户问某世俗说法站不站得住 → `kanyu-xieji-bian-e`。

11. 「夏至後三庚為初伏四庚為中伏立秋後初庚為末伏」（《欽定協紀辨方書》卷十二·歲時紀事）

## I：核心解释

公規两卷不是教人趋吉避凶，而是先把「奉天」的常例立起来。原文开头就写：司天首重气候，推昼夜永短来辨寒暑进退，察经纬躔舍来识中星推移，这是「協紀」之本；至于致祭迎春，尤关钜典。换句话说，一切择日都要先有一套时间的尺子——节气、月建、月将、昼夜刻分、更漏中星——尺子不正，后面的吉凶都无从谈起。

1. **昼夜永短的二因**：书里说早晚之故有二，一由日行内外，一由人居南北。日行黄道与赤道斜交，春分后行赤道内，夏至前后昼长夜短（日永）；秋分后行赤道外，冬至前后昼短夜长（日短）。又以人居南北论：中国在赤道北，夏昼长冬昼短，愈北则永短之差愈多，至极下则半年为昼半年为夜。这是把时间钉在地理纬度上的说明。
2. **月建与月将之别**：原文一句最要紧——「月建視節氣斗杓也，月將視中氣太陽也」。月建跟的是节气（斗杓所指），月将跟的是中气（太阳所在）。所以同一个月份里，建与将会因节、气前后而错开。判月建只查节气，判月将只查中气。
3. **日躔过宫与十二次**：每个中气太阳过一次宫，进一个星次，如雨水躔亥宫初度为娵訾之次、春分躔戌宫初度为降娄之次，一路排到冬至躔丑宫为星纪之次。十二次与十二月将一一对应，这是月将表的根据。
4. **昼夜时刻、方位与朦影**：书按京师北极出地三十九度五十五分，逐节气列出日出日入、昼刻夜刻；又列日出入方位（距正东西的度数）与朦影刻分。朦影以太阳距地平下十八度为限，昏刻＝日入加朦影，旦刻＝日出减朦影。各省不同，书里说「以各省北极出地及太陽赤道緯度立算法」。
5. **更漏五更与中星**：卷一三（公規二）说更漏中星起于虞书、月令；今台官相传之法是日入后八刻起更、日出前九刻攒点，起更至攒点共若干刻五分之以为五更，再逐更配中星（如春分戌宫初度：一更戌正初刻鬼宿一，二更亥初二刻三分张宿一……）。星图步天歌附于后，是给中星查对用的。
6. **祀典与春牛是礼制，不是神煞**：祀典列的是定期（正月上辛祈谷、冬至祀天圜丘、夏至祀地方泽、仲春仲秋上丁祭先师孔子等）；春牛经给的是造春牛芒神的用日与形制——冬至后辰日于岁德方取水土，桑柘木为胎骨，牛身高四尺象四时、头至尾八尺象八节，牛头色视年干、牛身色视年支、牛腹色视年纳音，芒神老少视年支。这些是典礼与历法常例，不是吉凶神煞，读时不要把两者混为一谈。
7. **岁时纪事是民间节令的推算例**：同一卷又收岁时纪事，如迎春（立春前一日设春牛勾芒神于东郊，官吏綵仗鼓乐迎春）、龙治水（元旦后第几日得辰即为几龙治水）、得辛（正月上旬第几日值辛）、二社（二分前后近戊为社）、三伏（夏至后三庚初伏、四庚中伏、立秋后初庚末伏）、霉天（芒种后逢丙入、小暑后逢未出等）。这些同样属历法推例，不是吉凶判词。

## A1：来源应用

**祀典择日（卷十二·祀典，照书所列）**：正月上辛日祈谷于上帝；冬至大祀天于圜丘、夏至大祀地于方泽；春分卯时祭大明于朝日坛、秋分酉时祭夜明于夕月坛；四孟月朔时享太庙，孟春同日祭太岁月将之神；岁暮祫祭太庙；仲春仲秋上丁日祭先师孔子；仲春仲秋上戊日祭社稷坛；仲春仲秋择日祭关帝庙、黑龙潭龙神等；仲春仲冬上甲日祭三皇庙；季春己日祭先蚕祠、季春亥日祭先农坛；清明霜降前祭历代帝王庙；六月二十三日祭火神庙；季秋择日祭都城隍庙。

**春牛经造法（卷十二·春牛經，照书所列）**：用冬至后辰日于岁德方取水土成造，桑柘木为胎骨；牛身高四尺象四时、头至尾桩长八尺象八节；牛头色视年干（甲乙青、丙丁红、戊己黄、庚辛白、壬癸黑），牛身色视年支，牛腹色视年纳音，牛角耳尾色视立春日干，牛胫色视立春日支，牛蹄色视立春日纳音；牛尾长一尺二寸象十二月，左右缴视年阴阳；牛口开合视年阴阳；牛笼头拘绳视立春日支干；牛踏板视年阴阳；芒神身高三尺六寸五分象三百六十五日，老少视年支，衣带色、髻、罨耳、行缠鞋袴、鞭杖各有所视；忙闲立牛前后视立春距正旦远近，立牛左右视年阴阳。

**歲時紀事（卷十二·歲時紀事，照书所列）**：迎春——先设春牛勾芒神于东郊，牛头东向，立春先一日府州县官吏綵仗鼓乐迎春于东郊，祭拜勾芒神，迎春牛勾芒神安置各衙门头门内，至立春本日用綵仗鞭春牛；龙治水——看元旦后第几日得辰即为几龙治水；得辛——看正月上旬第几日值辛即为几日得辛；二社——二分前后近戊为社；三伏——夏至后三庚为初伏、四庚为中伏、立秋后初庚为末伏；霉天——芒种后逢丙入、小暑后逢未出（一说芒种后逢壬入、夏至后逢庚出）。这一组是节令推算的旧例，供民俗与年节安排对照。

**气候七十二候（卷十二·氣候）**：自立春「东风解冻、蛰虫始振、鱼陟负冰」起，逐节气列三候，到冬至「蚯蚓结、麋角解、水泉动」、大寒「鸡乳、征鸟厉疾、水泽腹坚」。查某日属哪一候，照此表。

**昼夜时刻、方位、朦影（卷十二）**：按节气列日出日入与昼夜刻分（如春分日出卯正初刻、昼四十八刻、夜四十八刻；夏至日出寅正二刻五分、昼五十九刻五分）；另列日出入方位（冬至出辰入申、夏至出寅入戌等）与朦影刻分（冬至六刻十二分，夏至八刻九分）。书明言各省不同，须以当地北极高度立算。

**更漏五更与中星（卷十三）**：依日入后八刻起更、日出前九刻攒点推五更时刻，并逐更记中星（如春分戌宫初度一更在戌正初刻，中星鬼宿一）。星图步天歌按紫微垣、太微垣、天市垣与二十八宿分部记星，是查中星与认星官的口诀。

## E：执行步骤

1. **定日期与节气**　输入：用户给的公历或旧历日期（或节气名） → 输出：该日所处节气、中气与七十二候。
2. **定月建与月将**　输入：上一步的节气、中气 → 输出：月建（视节气斗杓）与月将（视中气太阳，对应十二次，如雨水后躔亥为娵訾）。
3. **查昼夜时刻与朦影**　输入：节气与该地北极出地高度 → 输出：日出日入时刻、昼刻夜刻、朦影刻分、昏刻与旦刻。
   🔴 **CHECKPOINT**：把「节气—月建—月将—昼夜刻分—昏旦」列成一表展示，等用户确认日期与地点无误再往下；缺地点或日期就停在这里问清。
4. **排更漏与中星**　输入：上一步的昏旦时刻与节气 → 输出：五更时刻与各更所当中星。
5. **对祀典与春牛**　输入：用户的行事目的（祭祀／迎春／制春牛） → 输出：对应的祀典定期或春牛经造法条目。
6. **输出收口**　输入：以上各表 → 输出：三要素（term_anchor 定在哪一节气哪一建将／general_rule 历法常例怎么说／application 落到用户要办的那件事），并标出不确定处。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿公规当吉凶表 | 用户问「这天吉不吉」，却拿昼夜刻分去答 | 说清公规只立常例，吉凶要看义例与宜忌；转相邻条目 |
| 月建月将不分 | 用中气去定月建，或用节气去定月将 | 回到「月建视节气、月将视中气」这一句，分别重定 |
| 凭记忆给刻分 | 不查表，按印象报日出时刻 | 一切刻分、方位、朦影都照卷十二表，无表就不报 |
| 各省刻分照搬京师 | 用户在外地，仍给京师刻分 | 书明言各省不同，须以当地北极高度立算；缺高度就说缺 |
| 春牛形制自己发挥 | 报出书里没有的颜色或尺寸规则 | 只报春牛经所列各项所视（年干／年支／年纳音／立春日干支／年阴阳等） |

**边界规则**：
1. 公规的内容一律按「历法常例／礼制条目」记，不掺吉凶判断；要谈吉凶，交回义例、宜忌类条目。
2. 昼夜时刻、方位、朦影只报书表所列（京师）或书所给算法可推出的；缺地点、缺年月就不硬给数字。
3. **硬口径**：凡涉及具体行事宜忌，必须同时给出起例来源（哪一卷、哪一篇）与卷次依据；只报条目名而不说出处＝不合格。缺具体日期或事项，就明说缺什么，不许用占位信息硬判。
4. 书里若已辨正的世俗说法，不当作书的主张（辨正在 `kanyu-xieji-bian-e`）。

**来源边界**：本条目只据卷十二、卷十三的公规原文，不引后世台历或他家通书的数字；四库本无页码，出处只写卷次与篇名。

**安全兜底**：不接阴宅实地作业指导；不给医疗、法律、投资结论；不替用户拍板。

## 练习手册

- **建将默写**：合上本页，凭记忆写出「月建视节气、月将视中气」两句话，再把十二月将与十二次（娵訾、降娄、大梁、实沈、鹑首、鹑火、鹑尾、寿星、大火、析木、星纪、玄枵）对应排一遍，回头核。
- **一日期三查**：取一个具体日期，查它的节气、月建月将、七十二候，再照卷十二表写出当日的昼刻夜刻与朦影刻分。
- **画一张春牛色表**：任取一年，按春牛经逐项列出牛头牛身牛腹、角耳尾、胫、蹄的颜色与芒神老少、衣带、髻、罨耳、行缠的取法。

## 灰色地带

- **地点缺失**：书给了京师刻分，各省只说「以北极出地立算」，没有现成各省表。用户给不出地点或北极高度时，只报节气与建将，不报刻分，并说明缺什么才能补齐。
- **朝代差异**：四库本祀典列的是清代之制，春牛尺寸也是当时之制。用户若拿他朝的礼制来问，先说清这是《欽定協紀辨方書》所载之制，不替它跨朝代背书。
- **节气与中气边界日**：交节交气当日，建与将会在前后错开，可能同一天属于两种读法。此时不硬断，按用户要办的事（查建还是查将）分别给，并标明落在交界上。
- **时宪与附表差异**：卷十二已给逐节气刻分，卷三十五附錄另存通书旧表；两处细则不同时，以公规正编为准，附錄旧表只作对照（转 `kanyu-xieji-fu-lu`）。
