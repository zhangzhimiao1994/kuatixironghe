# 印綬：生我之源、官印相生与倒食

**来源**：sources/sanmingtonghui.txt（《三命通會》卷五·論印綬、論倒食；卷十·㸔命口訣；卷十一·喜忌篇） ｜ 证据等级：firsthand（原书原话）

## I：核心解释

印綬是「五行生我」那一名。书里论印，落点不在印本身多与少，而在「印能不能护住官星、有没有财来破印」这两件事上。

1. **印是什么**。「印綬者乃五行生我之名，如甲乙在亥子月丙丁在寅卯月之類，乃我氣之源，為生氣，為父母，能䕶我官星使無傷尅」（R1）。一句里三层：我是源（生我）、是父母之象、是护官的东西。
2. **官印相配**。「有官無印即非真官，有印有官方成厚福」（R2）。书里把官与印看成一对：官是印的根（「官星者印綬之根也」，R5），没有印，官就不成其为真官；官印相生才是成局。
3. **印最忌财**。「忌財星以財能破印」（R3）。这是论印綬篇的第一条忌。「印綬生月嵗時忌見財星，運入財鄉却宜退身避位」（R4）——书里把这条落到月与时上，又说运入财乡的后果，这是书里的说法。
4. **有官有财反不忌**。「官星者印綬之根也，印綬有官有財，則財生官、官生印、印生身、身尅財，則榮貴故不忌」（R5）。单有财是破印，但财与官同时有，就转成一个链条：财生官、官生印、印生身——所以书里说这时候不忌。
5. **印与别格身旺身弱相反**。「凡格喜身旺，惟印綬喜身弱」（R6）。别格怕身弱不任，印綬因为本身就是生身之物，所以反过来喜身弱——这一条是印綬最反常的地方。
6. **印多不为好**。「印多則清孤不免」（R7）。书里明说印綬多者清孤，所以印多并不是越多越好；「凡印不論一位二位四位都好，格中不宜見財破印」（R11）说的是「位数不必挑」，但破印之财仍是大忌，两说并不冲突。
7. **印的四个字诀**。「印綬有根逢財則發，逢官則顯，逢合則晦，逢衝則災」（R8）。这是印綬在柱里的四种遭遇，各给一个结果，是书里的说法。
8. **倒食即偏印**。「倒食即偏印之謂，一名吞啖煞，食神最忌見之」（R9）。同一篇把偏印单列一题讲：偏印本是生我之物，但它会去夺食神，所以叫倒食。书里说命带倒食者福薄寿夭，有制合则不然——这些是书里的评价语。
9. **「無天財」的意思**。喜忌篇「月生日干無天財乃印綬之名」（R10）与论印綬篇「印綬被傷」对读：月令生日干，柱中又不带破印之财，才成印綬之名；带财则印受伤。
10. **一句话读法**：先认印（R1），再看有没有官来生根（R2、R5），再看有没有财来破（R3、R4、R10、R11），再看身旺身弱与印的多少（R6、R7），偏印一路另看倒食（R9）。

## A1：来源应用

书上给的做法，是「先认印与官印之配，再查破印之财，再定身之强弱」：

- **认印与官**：印是生我者（R1）；有官无印非真官，官是印之根，二者相生为厚福（R2、R5）。
- **查财**：财能破印，印綬生月又岁时忌见财星（R3、R4）；成名条件是月生日干而柱无天财（R10）。
- **官财并见则转**：印綬有官有财，形成财生官、官生印、印生身之链，书里说不忌（R5）。
- **看身强弱**：诸格喜身旺，印綬独喜身弱（R6）；元局带财伤印而行比劫身旺运，书里说亦能发福（同篇）。
- **看印之多少**：印不论一位二位四位都好，但格中不宜见财破印（R11）；印多则清孤（R7）。
- **四种遭遇**：逢财则发、逢官则显、逢合则晦、逢冲则灾（R8）。
- **偏印一路**：倒食即偏印，食神最忌见之（R9）；柱中身旺财官俱生者可取为福助身，无食则以偏印论（同篇）。
- **评价语提醒**：R4 的「退身避位」、R7 的「清孤」、R9 的「福薄夀夭」都是书里的说法，引用标明来源。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月令、印星的干支（生我者是正印还是偏印、在哪一柱、透干还是藏支）、四柱里有官无官、有财无财。
2. **逐条核书里的条件**：印成不成名 → R1／R10（月生日干無天財乃印綬之名）；有没有官为印之根 → R2／R5（官星者印綬之根也）；有没有财来破印 → R3／R4（忌財星以財能破印）；身之强弱 → R6（凡格喜身旺惟印綬喜身弱）；印之多少 → R7／R11；柱带偏印与食神 → R9（倒食即偏印之謂）。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「印透而柱无破印之财，按 R1、R10 这一路读，偏『月生日干』的印綬之名」。
4. **收口**：这一句是**书里的读法**，不是对这个人的判断；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：本篇不把印綬换算成「学历、文书、贵人」之类现代归属，也没有「印星旺衰计分」；这些都不写。

## 📖 练习手册

- **三层定性**：合上 R 节，把 R1 里印的三层（生我之源、父母、护官）各写一句白话。
- **官印链**：把 R5 的链条「财生官、官生印、印生身、身尅财」抄一遍，标出哪一环是印。
- **强弱对照**：把「诸格喜身旺」与「惟印綬喜身弱」并排写下，各配一句理由（参 R6）。
- **偏印一题**：按 R9 写出倒食的两名与它夺食的缘故，不给书外说法。

2. 见财就断破印，不看有没有官（R5）。
3. 拿「身弱不任」套印綬，忽略「惟印綬喜身弱」（R6）。
4. 说印越多越好，漏掉「印多則清孤」（R7）。
5. 见倒食就替某人断福薄寿夭（R9 是书里的评价语）。
6. 没有月令仍替人断印格，或拿占位信息硬排。

## 灰色地带

- **印多与「一位二位四位都好」并存**：R11 说位数不必挑，R7 说印多则清孤。按原句，前者是说不必挑位数、后者是说多则清孤，两者各有所指；用户若问是否矛盾，就说这是原书两个角度的说法，不替用户拍板。
- **财破印与官财生印的两说**：R3 说财破印，R5 说有官有财则不忌。按原句，关键在有没有官做中间一环；遇到冲突就说这是原书按有无官分两路，不替用户择一。
- **「天財」到底指什么**：R10 只说「月生日干無天財乃印綬之名」，未详列天财是何物。用户若追问，照实说书里只到这一步，不代拟定义。
- **倒食有制合者反贵**：论倒食篇说「前忌倒食逢制合反貴，切不可一見倒食便以凶論」。用户若问自己带倒食是否一定不好，按这句说明须看有没有制合，不下定论。
- **用户拿「清孤」问自己**：不写自我否定腔，也不写兜售腔；标明是书里的评价语，只讲原句条件，判断留给用户。
