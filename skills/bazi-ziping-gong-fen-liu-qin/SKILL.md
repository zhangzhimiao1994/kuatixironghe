# 宮分六親與妻子：宫位与用神两套，各看各的

**来源**：sources/zipingzhenquan.txt（《子平真詮》篇二十三·论宫分用神配六亲／篇二十四·论妻子） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

- 用户问六亲在八字里怎么配，是按宫位排还是按十神定。
- 用户问「正印为母、偏财为父」为什么这么取。

## I：核心解释

篇二十三、二十四讲的是「六亲怎么落到八字上」。篇二十三先立两套配法（宫分、用神），再说要参合局中喜忌；篇二十四专讲妻子一层，把妻宫、妻星与子息分开看。

1. **六亲存于命**。「人有六亲，配之八字，亦存于命」（R1）。这一句先把话说定：六亲不是另立一套，也是拿八字的宫位与十神去配。
2. **第一套是宫分法**。「其由宫分配之者，则年月日时，自上而下，祖父妻子，亦自上而下。以地相配，适得其宜，不易之位也」（R2）。年月日时四个宫位自上而下排，祖父、妻、子也自上而下配过去——这是按「地」的位置配，位子是固定的。
3. **第二套是用神法（十神定六亲）**。「其由用神配之者，则正印也母……正印为母，则偏才为父矣。正财为妻……夫为妻纲，妻则从夫」（R3）。这里书里把每个十神为什么配那位亲都给了理由：正印是生我的，取「生我」之义为母；偏财受我克制却是父亲，因为偏财是母之正夫；正财受我克制是妻，取「妻从夫」之义；官煞克我却是子女，因为官煞是财所生，财既为妻妾，官煞便为子女（R4）。比肩为兄弟则「理之显然」（R5）。
4. **两套要参合局中喜忌**。「然后以六亲配之用神。局中作何喜忌，参而配之，可以了然矣」（R6）。书里的做法是：先看四柱里年月或日时那个位置是财是官是伤是刃，再拿局中的喜忌去对，六亲的吉凶（书里原话是「或吉或凶」）由此参出来——不是宫位一摆就定死。
5. **妻一层：宫与星分看**。篇二十四从「大凡命中吉凶，于人愈近，其验益灵」（R7）说起，把切身的事排在前面。「以妻论之，坐下财官，妻当贤贵；然亦有坐财官而妻不利，逢伤刃而妻反吉者」（R8）——书里明说不能死执：妻宫坐财官本是吉，可落在印格里反而不美；妻宫坐伤官本是凶，落在财格、煞格里反倒能生财、能制煞。为什么？「此盖月令用神，配成喜忌」——还是拿月令用神配成的那套喜忌在定。
6. **妻宫之外还看妻星**。「既看妻宫，又看妻星。妻星者，干头之财也」（R9）。妻宫是日支那个位子，妻星是天干透出来的财；透而成局、透而破格，书上各有说法，还要防坐下刑冲。
7. **子息先看时支**。「所以八字到手，要看子息，先看时支」（R10）。书里看子息的路子是：先看时支那个宫位（看子星在其中生旺还是死绝），再拿时干那颗子星配上；宫、星、喜忌三者合看。
8. **一句话读法**：六亲在书里是「宫位（年月日时为地）＋ 用神（十神定名）」两套并行，而以「局中喜忌」参合（R1–R6）；妻子一层再分妻宫／妻星、时支／时干（R7–R10）。

## A1：来源应用

书上给的做法，都落在「宫位与十神两套并摆，再以局中喜忌参合」这条线上：

- **摆宫位**：年月日时自上而下，依次配祖父、妻、子一类的切身之亲（R2）；位子固定，看的是那个宫位上坐了何物。
- **定名分**：用十神各安一名——正印母、偏才父、正财妻、官煞子女、比肩兄弟（R3、R4、R5）。报六亲时把「宫位上是谁」与「名义上是谁」都说清。
- **参喜忌**：先看四柱里那个位置是财官伤刃中的何物，再拿局中喜忌去配（R6）。同一颗星落在不同格里有吉有凶，不宫位一摆就断。
- **妻分两层**：妻宫看日支财官（及有没有刑冲），妻星看干头之财（透而成局还是透而破格）；书里明说宫吉星未必吉、宫凶星未必凶（R8、R9）。
- **子息看时**：先看时支那个宫，再拿时干子星配上（R10）；宫、星、喜忌合看。
- **要有出处**：报任何一处六亲的读法，都要给「哪一本、篇名」与「凭什么这么配」两句（STYLE 第三节第 9 条）。
- **评价语只念不落人**：篇里「贤贵」「反吉」「刑克」「难偕老」以及子息口诀里的「多子」「无子」「夭亡」之类，都是**书里的说法**，只能照念；**不许据此判具体某人的婚姻、生育与寿夭**（STYLE 第三节第 3、6 条）。

**书里没有的，不要加**：本 skill 不讲现代命理流派的「夫妻宫打分」「六亲指数」「自动判克夫克子」这类做法。原文配六亲靠的是「宫位＋十神＋局中喜忌」这套说法，照书讲即可。

**一个不替它们调停的地方**：本书《子平真詮》配六亲走「宫位与用神并摆、以月令用神配成喜忌参合」（R3、R6、R8）；《三命通會》那一路另有女命、夫星一套讲法（如卷十一论女命「貴眾則舞裙歌扇」之类，另见 bazi-sanming-nu-ming），《滴天髓闡微》六親論又自有一套（另见 bazi-ditian-liu-qin）。几处各标出处、摆在一起读，本文不选边、不合成一句话。

## E：执行步骤

**先分两种问法**（判据：输入里有没有四柱或出生信息）：
- 只问「书里这句什么意思／这一篇专门讲什么」、没给四柱 → 走 **文本解读**（认句归篇、摆条件），不必落盘；结尾补一句「给我四柱就能照书读一遍」。
- 给了四柱或出生信息（问「我这盘怎么看」）→ 走 **落盘读法**（下四步）。给了四柱但用户只问出处，也按文本解读答，不硬塞落盘。

落盘读法四步：

1. **步骤一·输入四柱**　输入：用户的四柱（或已排好的盘）＋ 本 skill 的配亲条件 → 输出：标出年月日时四个宫位各是哪一支、日支（妻宫）是哪一个，以及天干上有没有透出财（妻星）。
   🔴 **CHECKPOINT**：缺出生年/月/日/时任一柱、或缺出生地（定真太阳时用）就照实说缺什么、要到什么程度才能排，不用占位信息硬排；出生时刻只到时段（如「辰时」）时，时柱按该时段整体给出并标明「时段内不唯一」。
2. **步骤二·逐条核条件**　输入：标好的四柱 → 输出：按 R 节逐项核——宫位上坐了何物（R2）、该物按十神配的是哪位亲（R3–R5）、落到本盘月令用神配成的喜忌里是吉是凶（R6）、妻宫与妻星各是什么（R8、R9）、子息宫与子星在时支时干何处（R10）。核到哪一步说到哪一步，没满足的直说没满足。
   🔴 **CHECKPOINT**：能说的是「夫星/妻星在哪、宫位坐了何物、取用条件满足到什么程度」；**不许**滑到「克夫」「无子」「何时离婚」「生几个」——这些都是书里的说法或本族不接的活。
3. **步骤三·输出判断**　输入：逐条核的结果 → 输出：一句「按书里这一类读，偏 X」＋ **出处**（《子平真詮》篇名）。X 只到「六亲配在哪个宫、名义是哪位、落在喜忌的哪一边」这个粒度。
   🔴 **CHECKPOINT**：每条判断都要带出处；没原话可挂就直说此处讲不到，不替它编。
4. **步骤四·收口**　输入：整段推演 → 输出：一句这一篇在说什么 ＋ 一句按书里往哪看 ＋ 一件用户今天能做的读法或查证动作。
   🔴 **CHECKPOINT**：收口前确认——**不应期**（不说哪年发生）、**不断终身**（不一生一句定）、**不落寿夭疾病生育**、**不替人决定**（婚姻职业医疗一律不拍板）。篇里的「贤贵／刑克／多子／夭亡」只作书里的说法念，**不落到人身上**。

**交付口径**：逐步把推演展示出来，结论速览放最前但不得代替推演；一步之中的依据尽量引用户的问法或所给的四柱。需要成表的内容走平台原生的表格消息，不把 markdown 表格塞进正文。
