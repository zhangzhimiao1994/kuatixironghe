# 形势品类：势与形的吉凶读法

**来源**：sources/zangshu.txt（《葬書》雜篇） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户问「占山之法，以势为难，而形次之」这三次序是什么意思。
- 用户读到「势如万马自天而下，其葬王者」之类，问怎么读。
- 用户问书里把势和形分成哪些品类、哪些吉哪些凶。
- 用户拿一处地形来问「它像书里的哪一类」。
- 用户问「势与形顺者吉，逆者凶」怎么讲。
- 用户问动物形状（牛卧马驰、媵蛇委蛇之类）在书里算什么。

**不应触发**：
- 用户问「风水」定义、得水藏风 → 转 kanyu-zangshu-cang-feng-de-shui。
- 用户问平洋与山垄之别 → 转 kanyu-zangshu-zhi-long-bian。
- 用户问「势来形止」的机制、千尺为势百尺为形 → 转 kanyu-zangshu-shi-lai-xing-zhi。
- 用户问相地第一原理「乘生气」 → 转 kanyu-zangshu-cheng-shengqi。
- 用户要现场点穴、给葬位、要发财发贵的保证 → 本族不接。

## I：核心解释

雜篇是全书唯一大段讲「品类」的地方：把势和形分成一条条，各配一句**书里的评价语**。读这条 skill 的关键，是分清「书上说它主什么」和「事实上会怎样」。

1. **先看难度次序**：「占山之法，以势为难，而形次之，方又次之。」（R1）书里说三件事里势最难、形次之、方位又次之。难在哪里，下文有交代：势有隐显、有佯诈花假（R30），所以最难；形有大小真似，「形若不真，穴仍由似」，所以也难；方（方位）相对最易。
2. **势的品类**：书里用「势如……」起头，一条一条排下来。吉的一路——「势如万马自天而下，其葬王者」（R2）、「势如巨浪花，重岭叠障，千乘之葬」（R3）、「势如降龙，水绕云从，爵禄三公」（R4）、「势如重屋，茂草乔木，开府建国」（R5）。凶的一路——「势如惊蛇，屈曲徐斜，灭亡家国」（R6）、「势如矛戈，兵死形因」（R7）、「势如流水，生人皆鬼」（R8）。
3. **形的品类**：同样用「形如……」起头。偏吉——「形如负峙……王侯崛起」（R9）、「形如燕察，法葬其曲，胙土分茅」（R10）、「形如侧垒……九棘三槐」（R11）、「形如覆釜，其岭可富」（R12）、「形如植冠，永昌且欢」（R13）。偏凶——「形如投算，百事错乱」（R14）、「形如乱衣，荡女淫妻」（R15）、「形如灰囊，灾舍焚仓」（R16）、「形如覆舟，女病男因」（R17）、「形如横几，子绝孙死」（R18）、「形如卧剑，诛夷逼督」（R19）、「形如仰刀，凶祝伏逃」（R20）。
4. **动物类另有一路**：「牛卧马驰，蛮舞凤飞」（R21）、「媵蛇委蛇」（R22）、「鼋鼍鱼鳖，以水别之」（R23）、「牛富凤贵」（R24）、「媵蛇凶危」（R25）。这一路讲的是「应形真」——形与物相肖则相应。
5. **总则一：要止伏，不要飞走**：「形类百动，葬者非宜，四应前按，法同忌之。」（R26）注疏解释说，形势要「止伏如尸居之不动」才可，若飞定摆窜、于我无情，就要忌。
6. **总则二：势形顺逆**：「夫势与形顺者吉，势与形逆者凶，势吉形凶，百[缺]一，势凶形吉，祸不诈日。」（R27）注疏说，势与形都以止伏为顺、飞走摆窜为逆；顺则吉、逆则凶；势吉形凶尚可希一日之福，势凶形吉则祸不待终日。
7. **方位那一路另成一套**：「经曰：地有四势，气从八方。寅申巳亥，四势也；震离坎兑乾坤艮巽，八方也。」（R28）注疏把四势解作四长生、八方解作八势，并说后来「六秀六贵、分金三十吉龙」这类说法都源于此。书上明说「以势为难，而形次之，方又次之」（R1），所以方位在势形之后。
8. **评价语的性质**：这些「其葬王者」「千乘之葬」「灭亡家国」都是**书里的评价语**。注疏自己也提醒过「其葬王者，言其贵也，不得拘之」（R29）——不要死抠。引用时必须标明是书里的说法，不当作事实承诺。

9. **评价语与事实要分开**：R2–R25 每一条都是「书里的说法」。书里说「其葬王者」，注疏紧跟一句「言其贵也，不得拘之」（R29）；说凶条，注疏也说「未可以其凶而弃之」（如横几、卧剑一类）。所以对品类时，既要给出处，又不要把断语说死。
10. **难在势，不难在方**：书里把势列最难（R1），理由是与形相比，势更容易有「佯诈穴」「花假」（R30）；形次之，是因为「形若不真，穴仍由似」；方位再次之，是因为它有定法可循。
11. **把雜篇收成一张表**：

| 层次 | 书里说法 | 出处 |
|---|---|---|
| 势 | 以势为难 | R1 |
| 形 | 而形次之 | R1 |
| 方 | 方又次之 | R1 |
| 顺逆总则 | 势与形顺者吉，逆者凶 | R27 |
| 飞走之忌 | 形类百动，葬者非宜 | R26 |
| 四势八方 | 只作方位一路 | R28 |

12. **读品类的一条纪律**：先把描述归到势、形、方哪一层，再对品类，最后过一遍顺逆总则（R26、R27），并把所有贵贱词标成「书里的说法」。缺哪一层的描述，就先补哪一层，不跳层硬对。

## A1：来源应用

书上给的是「对品类」的读法，不是一张保证表：

- **先判是势还是形还是方**：按 R1 的三层次序，用户给的描述落在哪一层就先讲哪一层。
- **对品类给出处**：每类都回到具体条目（R2–R25），不凭印象归类。
- **用总则筛**：凡「飞走摆窜、于我无情」者按 R26 归到「忌」；凡势形顺逆冲突者按 R27 判顺逆。
- **分清方位一路**：涉及寅申巳亥、震离坎兑之类，说明它属「方」这一路（R28），在势形之后。
- **评价语标明归属**：一切贵贱断语都标「书里的说法」，并引注疏「不得拘之」（R29）提醒读者别死抠。
- **承认花假**：注疏承认有「佯诈穴，亦有花假」（R30），所以对品类时要说清这是难处，不硬认。
- **不跳层**：用户若直接问方位（寅申巳亥、震离坎兑之类），先提醒按 R1 的三层次序，势形在前、方位在后；不要把方位提前当总纲。

## E：执行步骤

1. **定位层次**　输入：用户的描述 → 输出：判定它落在势、形、方哪一层（R1）。
   🔴 **CHECKPOINT**：先确认用户给的是远的一条势、近的一穴形，还是方位；说不清就先问。
2. **对品类**　输入：层次与描述 → 输出：从 R2–R25 里挑最贴的一到两类，各给出处；贴不上的照实说不贴。
3. **过总则**　输入：已对上的品类 → 输出：按 R26（止伏为可、飞走为忌）与 R27（顺吉逆凶）复核一遍。
4. **标评价语**　输入：品类里的贵贱断语 → 输出：标「书里的说法」，并引 R29「不得拘之」；不把断语说成承诺。
5. **提花假**　输入：用户要一个确定归类 → 输出：用 R30 说明书里自承有佯诈花假，遇疑难只给倾向，不硬定。
6. **收口**　输入：整段推演 → 输出：一条分类结论（势/形/方 + 品类 + 顺逆）+ 缺项照实说。
   🔴 **CHECKPOINT**：收口前检查有没有把评价语当承诺、有没有把「方」这一路提前到势形之前。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把评价语当承诺 | 说「勢如萬馬自天而下」就必出王者 | 标「书里的说法」，引 R29「不得拘之」；不给保证 |
| 用喝形当定论 | 说「这山像龙，所以一定贵」 | 回到 R30：书里自承有佯诈花假；只给倾向 |
| 把方位提前 | 一上来就算寅申巳亥、震离坎兑 | 回到 R1：势在形先、方又次之 |
| 只挑吉条不问凶条 | 只说贵的一路，漏了惊蛇、矛戈、流水 | 吉凶两路都要给，按 R26 过一遍 |
| 缺形势描述却硬归类 | 只凭一句「这地有点像牛」就定品 | 列缺项（远近、止伏、四应、无情有情），不硬归 |
| 把注疏当经文 | 把 R29、R30 标成经文 | 注疏统一标「《錦囊》注」 |

**边界规则**：
1. 只讲品类的读法与出处，不接现场点穴与择地指导。
2. 不给发财发贵、灾祸病亡的保证或恐吓；书里的断语一律标明是书里的说法。
3. 不给医疗、法律、投资结论。
4. 象征层只给倾向，不写「一定 / 必然 / 命中 / 保证发财发贵」。
5. 势、形、方三层次序不可颠倒。
6. 遇「佯诈花假」一律照实说难处，不硬认（R30）。

**来源边界**：本 skill 只据 sources/zangshu.txt 雜篇（自「占山之法」至「穴吉葬凶」诸条），经文与《錦囊》注分列；不引内篇、外篇。雜篇里的「四势八方」「穴有三吉、葬有六凶」等条，本 skill 只在讲「方又次之」时点到，不展开。

## 练习手册

- **吉凶分栏**：把 R2–R8 的势条按吉、凶分两栏默写，再补 R9–R20 的形条，看能记住几条。
- **对号练习**：任取一处熟悉的地形，只判断它更像哪一条「势如……」，并写下你为什么这么对，不许写吉凶。
- **评价语剥离**：把「千乘之葬」改写成一句不带结果承诺的描述，练把评价语与事实分开。
- **三层排序**：默写「势、形、方」的次序，并各配一句原书理由。

## 反例黑名单

1. 说「葬王者」「千乘之葬」是必然结果——那是书里的评价语。
2. 凭山像什么就定品类、下断语（喝形当定论）。
3. 跳过势和形，直接拿方位说事。
4. 只挑吉条讲，不讲凶条，或反过来只吓人。
5. 用户只给一句描述就硬归类。
6. 把《錦囊》注（如「不得拘之」「佯诈花假」）当成经文。

## 灰色地带

- **一条地形同时对得上两类**：不硬选一，把两类都列出并说明各侧重什么；让用户按自己看到的主要特征取舍。
- **吉条里带凶、凶条里带吉**：書里自己也在注中承认过「未可以其凶而弃之」（如横几、卧剑一类）——照实说书里的保留意见，不下定论。
- **用户要「品类 + 保证」**：品类照对，保证不给；把评价语与承诺的分别讲清。
- **用户拿凶条来问「是不是诅咒」**：说明这是书里对形势的评价语，不是对某人的诅咒；本 skill 不给恐吓，也不给安慰，只讲书里的说法。
- **对不上任何品类**：照实说对不上，并列出还缺哪些描述（远近、止伏、四应、有情无情）。
- **用户把某一类当成绝对吉或绝对凶**：书里自己也有保留（如横几、卧剑一类，注中说「未可以其凶而弃之」）——照实说书里的保留意见，不下绝对结论。
