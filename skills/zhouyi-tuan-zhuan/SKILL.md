# 彖传（上下）读法

**来源**：`sources/zhouyi-jing.txt`（经文所载彖传）、`sources/zhouyi-benyi.txt`（朱熹本义）、`sources/zhouyi-zhengyi.txt`（王弼注＋孔颖达疏） ｜ 证据等级：firsthand（原书原话）

> **层分先认清**：`周易正義` 把「经＋王弼注＋孔颖达疏」混排在一处。引用时必须分清——哪句是**传文**（彖曰）、哪句是**注**（王弼）、哪句是**疏**（正义曰）。本 skill 的 R 节主料一律是**彖传传文**，另附两条**注疏**（本义注／正义疏）供辨说，标记各别。

## 触发条件

**应该触发**（用户会怎么说话）：
- 问「彖曰这句话书里怎么讲、出自哪一卦哪一篇」「彖传是什么」。
- 问到**卦体**（上下二体、刚柔、内外、阴阳升降）的释法；问到**卦德**（健／顺／说／巽／止／险一字之训）；问到**卦时**（「时义大矣哉」「时用大矣哉」「与时消息」）；问到**卦用**（这一卦能拿来做的事——「往有功」「可以王」「养贤」「利涉大川」）。
- 拿一件具体的事，要按彖传这一类释法落到处境上读。
- 直接引彖传用语：统论一卦之体、刚柔始交、险而止、位乎天位、时止则止。

**不应触发**（看起来像但其实不是）：
- 要算一卦、抽签、排盘、预测结果、断某人吉凶成事 → 照实说本维只做读法与处境归类，不进行占筮。
- 问大象「天行健，君子以…」句式或六爻小象 → 那是**象传**，走 `zhouyi-xiang-zhuan`。
- 纯技术（代码报错）、单一事实查询（天气、价格、时间）→ 直接回答。

## I：核心解释

彖传是**释卦辞**的一翼：它对着一卦的卦辞，讲清这一卦**是什么体、有什么德、当什么时、能作什么用**。读彖传只在这四层里认位置，不往外推吉凶。

1. **彖传的职能**：本义说「彖即文王所繫之辭，傳者孔子所以釋經之辭也」（R23）——彖是文王所系的卦辞，彖传是孔子拿来解经的话；正义引王弼《略例》说「統論一卦之體，明其所由之主」（R24）——彖是总论一卦之体、点出这一卦以什么为主。两家各说各的侧重：本义偏「谁作的、解什么」，正义偏「论什么、主什么」。**两说并陈，不合成一句。**
2. **卦体**：先看上下二体、刚柔内外。屯「剛柔始交而難生」（R3）、蒙「山下有險，險而止」（R4）、讼「上剛下險，險而健」（R6）、睽「火動而上，澤動而下」（R16）、坎「天險，不可陞也。地險，山川丘陵也」（R14）——这是拿卦的构造给处境塑形。
3. **卦德**：把一卦缩成一个字之训再展开。需「須也」（R5）、师「眾也。貞，正也」（R7）、艮「止也」（R18）、兑「説也」（R20）；健、顺、巽、说、止、险，都是这一层的用字。卦德决定这一卦「宜进还是宜守」的底子。
4. **卦时**：彖传常以「时」收束。随「隨時之義大矣哉」（R10）、豫「豫之時義大矣哉」（R9）、坎「險之時用大矣哉」（R15）、睽「睽之時用大矣哉」（R16）、颐「頤之時大矣哉」（R12）、小过「與時行也」（R22）、艮「時止則止，時行則行，動靜不失其時」（R18）、丰「天地盈虛，與時消息」（R19）。**时义＝这一卦的处境有什么意义；时用＝这一卦的处境能拿来做什么。**两者都落在「现在是不是这个动作的时候」。
5. **卦用**：彖传给出这一卦可以拿来做的事。师「能以眾正，可以王矣」（R7）、大过「利有攸往，乃亨」（R13）、颐「聖人養賢以及萬民」（R12）、革「湯武革命，順乎天而應乎人」（R17）、节「當位以節，中正以通」（R21）。**用是有条件的用**：同一卦里「宜」与「不宜」并列，许可的动作有边界。
6. **层分**：在 `周易正義` 里，同一段底下「彖曰」是**传**、紧跟的「注」是**王弼**、再下的「正義曰」是**孔颖达的疏**——三层不是一个声音。本义的夹注是**朱熹**的注。R23、R24 两条即为**注／疏**层，读时要与传文分开看。

## A1：来源应用

书里对各卦彖传给的做法，可归到四层（每条都追得回 R 节）：

- **卦体层**：屯「剛柔始交而難生」（R3）——两体初交、情意未通，故名「难生」；讼「上剛下險」（R6）——上体刚、下体险，所以成讼；睽「火動而上，澤動而下」（R16）——两体各行其方向，故名「睽」（乖离）。体不同，处境名就不同。
- **卦德层**：需「險在前也，剛健而不陷」（R5）——前面有险、但因刚健不被陷住，这一卦的底子就是「能等得起」；艮「止也」（R18）——这一卦的根本动作是止。
- **卦时层**：随、豫、坎、睽、颐、小过（R9／R10／R15／R16／R12／R22）都以「时」收口——这一类读法的落点是「现在是不是这个动作的时候」，不是「事情会成会败」。
- **卦用层**：师「能以眾正，可以王矣」（R7）——把众人摆正才谈得上成事；节「當位以節，中正以通」（R21）——到位了才谈节制，守中正才谈得通。

两家对同一处取法有出入时**两说都给、各标出处**：
- 就彖传这条传文本身，**本义**读作「孔子释经之辞」（R23），**正义**（引王弼）读作「统论一卦之体」（R24）——一个从作者／功能说，一个从论述对象说，并列呈现。
- 就乾彖「元亨利贞」，本义说「析元亨利贞为四德以发明之」，并自注「其文义有非文王之旧者」；正义疏则说诸儒分解四德「意各不同」，而「今案：庄氏之说，于理稍密，依而用之」。**两家各取一路，不作调停。**

## E：执行步骤

1. **步骤一（认篇归卦）**　输入：用户的问句与他点到的文本 → 输出：先认清这句是**哪一卦的彖传**（卦名＋卦次），并判它落在**卦体／卦德／卦时／卦用**哪一层。
   🔴 **CHECKPOINT**：报卦必须给全「卦名＋卦次＋原文」三样，并写一句「为什么是这一卦」的细节对应；对应不上就照实说还缺什么，不硬套。
2. **步骤二（问法一：问「书里怎么讲／出自哪一篇」）**　输入：纯文本追问 → 输出：**逐层解读**——认篇归义（这段彖传释的是哪句卦辞）、摆出书里给的条件（卦体／卦德／卦时／卦用各是什么）、附原文与出处。此步只做**文本解读**，不落到用户的私事上。
3. **步骤三（问法二：问「我这件具体的事」）**　输入：一件带背景的具体事 → 输出：把事**归到一类处境**，说清凭哪一条传文（卦辞／彖传／注疏）这么读，给「按书里这一类读，偏进／偏守」＋**出处**。此步只说「这类处境下书里给的动作边界」，**不替用户决定、不预测结果**。
4. **步骤四（两家并陈）**　输入：本义与正义（含所据王弼注）对这一处说法有出入时 → 输出：**两说都展示、各标出处、不调停**；有出入就分列，没出入就明说两家同。
5. **步骤五（分层）**　输入：引用 `周易正義` 的段落 → 输出：标清哪句是**传文**、哪句是**注**（王弼）、哪句是**疏**（正义曰）；不把疏文当传文。
6. **步骤六（收口）**　输入：以上读法 → 输出：落一句可打勾的动作或一句可核实的处境判断。**收口不起卦、不占卜、不预测结果、不替人决定**；用户要「算一卦」就照实说本维只做读法与处境归类。

> **两种问法**：问「书里怎么讲」走**步骤二（文本解读）**；问「我这件具体的事」走**步骤三（落处境的读法）**。两者可先后连用，但问法一不替用户谈私事，问法二不脱离出处。
>
> **输出收口**：结论放最前 3–5 行，其后逐步写出认篇→四层→两家→分层的过程；每一步的依据用用户原话或传文原句；落到一件今天／这周能打勾的事。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把彖传当占辞断吉凶 | 由「时义大矣哉」推出「所以你这事一定会成」 | 退回：彖传只讲体／德／时／用；吉凶词标明是**书里的用语**，不当对某人的事实判决 |
| 经／注／疏混作一句 | 把正义的「正义曰」疏文当成彖传传文引 | 退回步骤五：分清传文、王弼注、孔疏，引用标层 |
| 两家调停成一句 | 把本义与正义的两种读法揉成「两家都认为…」 | 退回步骤四：两说分列、各标出处、不合成一句 |
| 硬套一卦 | 信息不足也报一个卦 | 退回步骤一：说清还缺什么（哪一卦、哪一爻、卦辞哪句），不硬套 |
| 越界替人决定 | 「所以你应该马上启动」 | 退回步骤六：只说这一类处境下书里给的动作边界，决定权归用户 |

**边界规则**：
1. 只读传文，不起卦、不占卜、不抽签、不排盘、不算命，不给医疗／法律／投资结论。
2. 报卦必带卦名＋卦次＋原文＋一句细节对应。
3. 凶吉词（元亨、凶、无咎等）一律标「书里的用语」。
4. 内部归类名（成员 slug、目录名、「属于某类处境」这类标签）只留内部，不进给用户的回答。

**自查清单**：
- [ ] 报卦三样齐全（卦名＋卦次＋原文）并附细节对应？
- [ ] 四层（体／德／时／用）认对了吗？
- [ ] 本义与正义有出入时，两说都展示了、各标出处、没调停？
- [ ] 引正义时分清了传／注／疏？
- [ ] 收口有没有越界（起卦／占卜／预测／替人决定）？

**安全兜底**：涉及就医／用药／危机时，只做提醒与陪伴，不做诊断。

## 📖 练习手册

1. **四层归位**：任取 R 节五条，各判它落在卦体／卦德／卦时／卦用的哪一层，写一句凭据。
2. **两说对读**：拿 R23 与 R24，各写一句本义怎么讲、正义怎么讲，再写「若不调停，该怎么并列」。
3. **分层练习**：在 `sources/zhouyi-zhengyi.txt` 里找一段「彖曰＋注＋正义曰」，标出哪句是传、哪句是注、哪句是疏。

## 🚫 反例黑名单（不要做的事）

1. 由彖传推「你一定会／必然不会」——传文只论体德时用。
2. 把王弼注或孔疏当成彖传原文来引。
3. 把本义与正义说成一致或折中成一句。
4. 只丢一个卦名不给卦次与原文，或报卦不说「为什么是这一卦」。
5. 用户要算命时硬接，或反过来说周易是迷信。

## 灰色地带

- **一卦彖传同时讲两层**（如随兼卦体与卦时、艮兼卦德与卦时）：不硬选一层，两层分别写清，再看用户问的是哪一头。
- **本义与正义一详一略**：若一家只略说而另一家详说，不算「说法不同」；照步骤四明说「一家未详论此处」即可。
- **用户问的是卦辞而非彖传**：先说清这句出在卦辞还是彖传；若属卦辞逐字，则本 skill 只做「彖传如何释这句卦辞」，卦辞本身走经文那一支。
- **信息不足以归卦**：只做最宽的判断（体／德／时／用哪一头），说明还缺哪一点才好归卦，不硬报一卦。
