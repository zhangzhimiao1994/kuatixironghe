# 心性与心智的疾病

**来源**：《Tetrabiblos》BOOK THE THIRD, CHAPTER XVIII「THE QUALITY OF THE MIND」、CHAPTER XIX「THE DISEASES OF THE MIND」（Ptolemy，Ashmand 英译本）｜ 证据等级：firsthand

> **本 skill 的定位**：它讲解的是古代文本对"心性"与"心智紊乱"的分类读法。精神与神经方面的任何问题，都以医生与专业人员的判断为准——本 skill **不作诊断、不替代就医**。

## 触发条件

**数据前提**：本 skill 属「象征」层，需要出生信息（日期、时间、地点，足以排出星盘）才能触发。全篇不写成命定论——心性不是被一张盘定死的。

**应该触发**：
- 用户提供出生信息，问"古典占星里我的性情、心智能量怎么读"
- 用户问"书里说水星管什么、月亮管什么"

- 用户问"古典占星里疯狂、癫痫是怎么判的"（作为文本知识）
- 用户读第十八、十九章，想弄清"心智的疾病"到底在讲什么

**不应触发**：
- 用户要拿星盘判断自己或家人有没有精神疾病、要不要吃药 → 一律指向医生；本 skill **不作诊断、不替代就医**
- 用户问的是身体的伤、损、病 → 走 `ptolemy-body-and-disease`

- 用户问的是亲属、出生情形 → 走对应主题的 skill
- 用户要的是心理咨询、用药建议 → 不是本 skill

## I：核心解释

1. **分工**：书里把心性分成两块——理性的、与理解有关的那一块，看**水星**的位置；纯感受、与理性无关的那一块，看**月亮**及与它相配置的星（无论是应用还是分离）。星座的性质、与太阳和角宫的配置、以及每颗星自身的性质，都会参与。（R1）
2. **星座的三分类型定基调**：热带星座→热心政治、爱出头、勤于神学，同时敏捷、好奇、善发明、慕天文与占卜；双体星座→多変、难被看懂、轻浮、不专、爱音乐、多计策、易生悔意；定固星座→公正、不让步、恒常、审慎、耐心、勤勉、严正、贞洁、记仇、爱荣誉、固执。（R2、R3）
3. **位置定倾向**：东出与上升（尤其在本面）→大方、坦率、自信、勇敢、机敏；东出与中天→有思虑、记忆力好、坚定、审慎、宽大、不易受骗、明断、勤奋；先于/西没→不稳、不敬、懦弱、不耐劳、易受动、谦下、多疑、摇摆、夸口、胆怯、懒散；西没与下中天（白天水星金星昏没、夜里东升）→聪明机巧但不善记、不勤，却好奇隐秘之事（巫术与圣秘）、好机械、好观天象、哲学、鸟占、解梦。（R4、R5）
4. **主星的吉凶相熟**：凶星与这些位置相熟→人邪恶不诚；若没有相反力量压制，则行恶无所顾忌；若被压制，则恶念受挫、易于被逮、受罚。吉星相熟→行善爽快、不受不义、享其正直之利；若被相反情况取代，则其温和反成不利，被轻蔑与指控、被众人所冤。（CHAPTER XVIII）
5. **各行星独掌心智的两面**：书里用很大篇幅列出每颗行星（土星、木星、火星、金星、水星）在"荣耀的位置"与"不荣耀的位置"下，各把心性带向哪一面（如土星荣耀→深沈、严峻、勤苦、敌视罪恶；不荣耀→吝啬、怯懦、阴毒、爱孤独）。这是第十八章最大的一块。**它只是一份古代的类型清单，不是人格评定。**
6. **月亮与太阳的加成**：月亮在南/北界的极处→心性更多变、更善变于技艺；在交点→更敏锐、更实干、更活跃；在上升且增光→增机敏、明澈、坚定、开阔；减光或隐蔽→更沉、更钝、更多变、更怯、更晦。太阳与"心性之主"相熟：位置荣耀→增正直、勤勉、荣誉与一切可称许的品质；位置不利→增堕落、卑劣、残忍、固执、阴郁。（CHAPTER XVIII）
7. **心智的疾病怎么看**：书里说，要看水星与月亮，看它们彼此、对角度、对凶星的关系。若水星与月亮彼此不相连、也都不连上升地平，而有害的星又在上、压过它们或与它们对冲 → 心性染上各种紊乱；具体是哪种紊乱，看当时掌权的星的性质。中度的紊乱由第十八章的性情"过度增长"而来——某种品质的过量就是"道德上的紊乱"；本章讲的是另一类"极其巨大而多样、几乎压倒理智与情感自然进程"的紊乱。（R6）
8. **具体读法（书里的分类）**：癫痫多见于水星与月亮互不相连、或都不连上升地平，且土星与火星占角并掌局——白天以土星为主、夜里以火星为主；反之（夜里土星掌、白天火星掌，尤在巨蟹/处女/双鱼）则发疯。若月亮与太阳面对面，合相时为土星所管、对冲时为火星所管，且尤在射手与双鱼，则成为"着魔者"、脑湿之症。（R7）
9. **可治性**：只有凶星掌局→不可治，但当时也不显（含混、不公开）；吉星木星金星相熟、在东、占角，而凶星在西→虽显眼却可治（木星借医疗外科与饮食药物，金星借神谕与神力）。吉星在西、凶星在东占角→不但不治且最显眼。（R8）
10. **感受性的偏离**：第十九章后半把"感受性心智的偏离"讲成男女两性力量的过与不及——由太阳/月亮与火星/金星在阳性阴性星座的配置判断；火星与金星东出、白昼的位置更阳刚正向，西没、夜间的更阴柔卑下；土星相熟→更污秽、更恶，木星相熟→更体面、更贞洁，水星相熟→更易变、多样、活跃、爱张扬。（CHAPTER XIX）

## A1：来源应用 — 书里给的具体做法

- **水星与月亮**：理性/理解看水星，感受性心智看月亮及与它配置的星。（CHAPTER XVIII）
- **三方类型**：热带/双体/定固星座各给一组心性基调。（CHAPTER XVIII）
- **位置**：东出与上升、东出与中天、先于/西没、西没与下中天，各给一组倾向。（CHAPTER XVIII）
- **行星独掌**：逐颗列"荣耀/不荣耀"两面。（CHAPTER XVIII）
- **月亮的增减光与交点、太阳的善恶配置**：作为加成。（CHAPTER XVIII）
- **心智疾病**：水星与月亮互不连、不连上升地平，凶星在上或对冲 → 各种紊乱；癫痫、疯狂、着魔各自对应的配置；可治性按吉凶星的东/西与角宫位置判。（CHAPTER XIX）
- **两性力量的过与不及**：太阳/月亮与火星/金星在阳性阴性星座的配置，加上东西出与昼夜。（CHAPTER XIX）
