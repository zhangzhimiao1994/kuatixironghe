# 利用·制煞要法

**来源**：`sources/xieji.txt`《欽定協紀辨方書》卷三十四·利用二（清乾隆官修，四庫本） ｜ 证据等级：firsthand（原书原话）/ inference（推断，须标注）

## 触发条件

**应该触发**：
- 用户问某个凶煞（三煞、太岁、岁破、阴府、官符、金神、火星、大月建等）能不能制、怎么制。
- 用户想修方／修山／修向，问怎么「补龙扶山制凶助吉」。
- 用户拿一个凶方问「非修不可，怎么办」。
- 用户问到「克之则伏、冲之则起」，或四柱制煞、月令衰旺的道理。
- 用户问灸退、太岁这类「宜补不宜克」「宜合不宜冲」的煞。

**不应触发**：
- 用户只问造命歌、补龙相主的框架 → `kanyu-xieji-li-yong-zao-ming`。
- 用户只问神煞的起例本身（怎么起三煞） → 义例类条目；本条只讲制化。
- 用户问公规历法 → `kanyu-xieji-gong-gui`。
- 用户问世俗相沿条目或某说法的真伪 → `kanyu-xieji-fu-lu` / `kanyu-xieji-bian-e`。
- 用户要阴宅实地作业指导 → 不接。

## R：原文锚点

1. 「選擇宗鏡曰年家吉凶神起例有八一曰本年天干二曰三合五行三曰本年十二建星四曰本年五虎遁五曰本年納音六曰四方七曰納卦八曰羊刄」（《欽定協紀辨方書》卷三十四·年神總論）
2. 「選擇宗鏡曰坐三煞向太嵗此不能制者也不可犯也三煞在方在向及隂府在山此可制而不易制者也不可輕也其餘紛紛神煞中煞制之小煞不必制有吉星同到自能壓伏」（《欽定協紀辨方書》卷三十四·制煞要法）
3. 「干犯干制如隂府天金神皆以干制干也支犯支制如地官符之類擇其死月死日修之可也三合犯三合制如三煞打頭火天官符以三合局尅之可也納音犯納音制如年尅地金神以納音制之可也」（《欽定協紀辨方書》卷三十四·制煞要法）
4. 「制煞之法宜用四柱尅之而不宜衝尅之則伏衝之則起而反為禍」（《欽定協紀辨方書》卷三十四·制煞要法）
5. 「太陽三竒能降諸煞紫白竅馬能制地官符大将軍以下諸煞禄制空亡貴人降諸煞以本命飛到者最為上太歳飛到者次之同到者尤吉」（《欽定協紀辨方書》卷三十四·制煞要法）
6. 「制煞全看月令必本煞衰月制神旺月乃可惟太嵗灸退另論若諸煞聚㑹或與太嵗同宫則不可制勿犯可也」（《欽定協紀辨方書》卷三十四·制煞要法）
7. 「太歳可坐不可向三煞可向不可坐不易之論也」（《欽定協紀辨方書》卷三十四·制煞要法）
8. 「凡煞皆强梁有餘故宜尅灸退乃休囚不足故宜補」（《欽定協紀辨方書》卷三十四·灸退）
9. 「一要三合局以勝之二要三合得令之月三煞休囚之月三要本命貴人禄馬及八節三竒或日月以照臨之」（《欽定協紀辨方書》卷三十四·三煞 伏兵 大禍）
10. 「月破山方皆凶坐山尤凶造𦵏皆不可犯」（《欽定協紀辨方書》卷三十四·月凶神總論）

## I：核心解释

制煞要法开宗明义分了三个层次：坐三煞、向太岁，这是「不能制者，不可犯也」；三煞在方在向、阴府在山，是「可制而不易制者，不可轻也」；其余纷纷神煞，中煞制之、小煞不必制，有吉星同到自能压伏。所以第一件事不是问「怎么制」，而是先判这个煞落在哪一层——落错层，后面全错。

1. **四法及三种变制**：干犯干制（阴府、天金神，以干制干）、支犯支制（地官符之类，择其死月死日修）、三合犯三合制（三煞、打头火、天官符，以三合局克之）、纳音犯纳音制（年克、地金神，以纳音制）。此外还有化气制（阴府甲己属土，以丁壬木制；乙庚属金，以戊癸火制）、坐宫制（病符小耗这类年家不飞者，以年月日吉照之）、飞宫制（月家打头火，以月家一白或壬癸水德制）。书里还提醒：通书制三煞多用纳音，但纳音力轻，仍当兼地支三合取用。
2. **克与冲之别**：制煞之法宜用四柱克之，不宜冲——「克之则伏，冲之则起，而反为祸」。除太岁、阴府在坐山不宜克之外，其余诸煞如三煞、官符、大将军、伏兵大祸，在坐则重而难制，在向在方则轻而易降。浮天空亡占向则可八字冲之。
3. **全看月令**：制煞必本煞衰月、制神旺月乃可；太岁与灸退另论。若诸煞聚会或与太岁同宫，则不可制，只宜勿犯。凡制凶神要酌其轻重，不可用煞的生旺——如煞属木者忌春令并忌亥卯未日时，用午字则木煞死、用申字则木煞绝。
4. **吉星降煞**：太阳三奇能降诸煞，紫白窍马能制地官符、大将军以下诸煞，禄制空亡，贵人降诸煞；以本命飞到者为最上，太岁飞到的次之，同到者尤吉。小煞不必制，遇吉星自伏。
5. **补与制的分别**：太岁在山在方宜合不宜冲，灸退在山在方宜补不宜克——「凡煞皆强梁有余故宜克，灸退乃休囚不足故宜补」。所以修照两类不同：修吉方宜扶（培植善类），修凶方宜制（收降盗贼，必我强彼弱乃为我用）。
6. **制煞修方、补龙扶山**：书里点明「制煞修方」只就方言（方不怕克），非就山言（坐山宜补，克之则山伤）。真正稳的法子是「先令其星失时无气，更泊死绝休废之乡，得禄马贵人当旺之令修之，化煞为权」——比硬克更稳，怕压伏太过或遇冲合反为祸。
7. **报煞必给起例**：年神起例有八（本年天干、三合五行、十二建星、五虎遁、纳音、四方、纳卦、羊刃）。所以凡报一个煞，必须先说它从哪一例起、属哪一类，再谈制与不制。

## A1：来源应用

**太岁·岁破**：太岁可坐不可向，岁破（太岁所对）不可坐。太岁在山在方，审其叠吉不叠凶，则以四柱合之（一气或三合局），造葬移徙福大而久；叠戊己、年克、阴府、大煞等凶星则又极凶。太岁宜造葬、宜移徙、宜补葺（皆修也），不可拆毁、不可挖窖开池（皆犯也）。书里又按：坐太岁固吉，若子午卯酉年太岁与大煞同位、三煞与岁破同方，则坐之亦不吉。

**三煞·伏兵·大祸**：三煞极猛，伏兵大祸次之。占山造葬皆忌，惟占方可制而修。制法有三：一要三合局以胜之；二要三合得令之月、三煞休囚之月；三要本命贵人禄马及八节三奇或日月照临。三煞在南方巳午未属火，用申子辰月日时；在东方寅卯辰属木，用巳酉丑月日时；在西方申酉戌属金，用寅午戌月日时；在北方亥子丑属水，无土局不能制，忌用辰戌丑未相冲。又分年：子午卯酉年三煞与岁破同方、灾煞最凶；寅申巳亥年岁煞最凶；辰戌丑未年略与子午卯酉等。制之得法自然发福，但此煞最凶，制不得法必至为祸，修主孱弱亦难驾御，不可轻试。

**年月克山家**：洪范五行专论山运，忌年月日时克山运，然止忌开山；新立宅舍修造动土逾月、安葬论之旬日之内不忌，袝葬祖茔、倒堂竖造或现成基址不动地基亦不忌。制之之法，如甲子年作水土山、年纳音属金克山家木运，当取火月日时生旺兼作主火命并禄马贵人制之。

**阴府太岁**：惟忌山头不忌作向修方；正阴府忌修阳宅、安葬不忌，傍阴府忌坐山、修造不妨，用天月德太阳到山制之。宗镜旧说以正五行七煞克之（如甲乙阴府属木，宜以庚克甲、辛克乙，必七月八月金旺木衰乃可制），但书里辨其与坐山同类则不可制、制则克倒坐山。

**灸退**：灸退为三合死地，可向而不可坐。取天道、天德、月德、岁禄、贵人制之。凡煞强梁有余故宜克，灸退休囚不足故宜补——宜择旺相月或月日时一气、或月日时三合补之，则不退而反盛旺；若再加克制则愈休囚愈退败。曾文辿取丙申年辛卯月乙卯日己卯时修卯方（三卯一气局）。

**大将军·太阴**：大将军占方不可修，然有轻重，视其是否飞还本位。太阴、吊客同方为岁后，其方忌兴造，宜太阳、岁德、三合制之。

**官符·白虎·大煞**：官符本非大凶，遇窍马、太阳、紫白，或于其死月以天赦日解之，以修主命贵人禄马临之反吉。地官符遇窍马即吉，不必克；杨筠松为解讼，以命贵解官符，用午月（卯木死于午）、甲午日（天赦）。天官符乃三合中煞，可仿制三煞例以三合局制之，或以年月纳音克之。

**丧门·吊客**：为岁破三合小煞，单修一方止取吉星照；忌岁破三合月日（如子年丧门在寅，修寅方宜用子辰月日时合太岁，忌寅午戌月日时合岁破）。书里说问病寻医、吊孝送丧本不应忌。

**黄幡·豹尾**：随年不同即官符、弔客、白虎、丧门、太岁、岁破，当从各神以为制化；黄幡忌取土开门，豹尾尤轻，惟上轿下轿忌向之，凡凶煞皆然，豹尾却不足忌。

**巡山罗㬋·病符·死符·小耗**：巡山罗㬋忌立向不忌开山修方；病符为旧太岁忌立向，死符为旧岁破忌开山，皆小煞，取山向三合月吉星盖照便可用，日时勿干犯本年太岁岁破。

**岁刑·六害**：辰午酉亥年岁刑即太岁，未申年岁刑即岁破，开山立向修方皆忌，吉不能制；余年止忌修方，太阳六德可化。六害为六合之冲，故忌开山，然惟辰戌年叠灸退、巳亥年叠劫煞、子午年叠岁煞当兼补制，以太阳六德化之。

**蚕室·蚕官·蚕命**：为岁方长生之宫，本无凶义，非凶煞；忌于其方修作蚕室，若养蚕则又应为吉方。

**力士·飞廉**：力士恒居太岁前维，辰戌丑未年与巡山罗㬋同位，太岁同宫不宜抵向，修造亦不可犯；飞廉亦小煞，与白虎、丧门同理，同各煞制之。

**火星（打头火·独火·月游火）**：忌修造不忌安葬，必与年遁丙丁或月家丙丁独火会合方忌，不会不忌。宜用一白水星、水德（壬癸）制之，四柱忌用丙丁寅午戌月日时并丙丁奇九紫助火气。打头火即大煞、为太岁三合旺方又为金匮星，制化得宜则发丁旺家，惟子午卯酉年叠岁君不可犯。

**金神**：忌修方动土，葬事不忌。天金神（庚辛干）以丙丁干制，地金神（纳音金）以纳音火制，更宜丙丁奇、太阳罗星九紫及寅午戌火局。巳月金生、申酉月金旺不可犯；在午未方则火地克之，不待制而自可修。

**浮天空亡**：年为年干纳卦绝命破军之位，以天德月德照之、本命贵人禄马制之，当以六德照之。书里辨其「用月日刑冲之大谬」——以刑冲治凶反召凶。

**破败五鬼**：为年干纳卦之冲，尤小煞，岁月德合制之；太阳三奇紫白有一吉星到方亦可修。

**月厌·五鬼**：月厌为堪舆宗旨，子午卯酉月与建破同方必不可犯，巳亥月次之，寅申辰戌为月三合，丑未月为生气，太阳丙丁照之可用。五鬼为月厌之后、从阴中之阴，亦小煞，太阳三奇紫白禄马贵人盖照皆可用。

**月建·月破**：月建可坐不可向，月破可向不可坐，与太岁岁破同，岁尊而月亲。

**大月建·小月建**：小月建即小儿煞，止忌修方；大月建为月家土煞尤凶，不可制，造葬皆忌。书里按：以理而论，大月建较月建之定位为轻，其「山方中宫只占一处遂无往不忌」之说实为过当，术士之说多自相矛盾。

**四柱法·用日法·用时法**：四柱以年为君、月为相、日为有司、时为胥吏，所贵支干纯粹成格成局、扶龙相主；年切忌冲动太岁，月当旺一时，日之吉凶较年月尤切（日干为君、日支为臣，干重支轻，日干必要旺相切忌休囚）。用时全在帮扶日辰，或与日支干比和、或与日支三合六合即吉；时家吉凶神不必尽拘，惟贵人禄马为吉；忌时破（日支冲时支）、时刑、五不遇（时干克日干）。

**造葬权法**：凡修造要身命、年月、方向皆利；不得已而作，则迁居后就所修之方看作吉，或于吉宫起工连及不利之宫，或大寒五日后立春前择日拆屋竖造、安葬破土，谓「岁官交承」。已过立春后年月凶神方位已定，不可修作。

## E：执行步骤

1. **定煞与落位**　输入：用户给的煞名（或凶方）与所修的山／向／方 → 输出：该煞属哪一层次（不可制／可制而不易制／中煞／小煞），以及落位性质（在坐山／在向／在方／中宫）。
   🔴 **CHECKPOINT**：把「煞名→起例来源与卷次→层次→落位」列成一小表展示，等用户确认；煞名说不清或落位不明就停在这里问，不许替用户猜一个位置。
2. **给起例与依据**　输入：上一步的煞名 → 输出：它的起例（年神八例之一，或月家／日家所属）与卷次依据。
3. **定补制方向**　输入：煞的层次与落位 → 输出：是补还是制（太岁宜合不宜冲、灸退宜补不宜克、中煞制之、小煞不必制），以及用哪一法（干制／支制／三合制／纳音制／化气／坐宫／飞宫）。
4. **查月令衰旺**　输入：煞的五行与拟用月份 → 输出：本煞衰月与制神旺月的可用区间；诸煞聚会或与太岁同宫则输出「不可制，宜勿犯」。
5. **配吉星降煞**　输入：山向与主命 → 输出：太阳、三奇、紫白、窍马、禄马贵人（本命飞到者为上）的取用方向；细则的四柱与用时转 `kanyu-xieji-li-yong-zao-ming`。
6. **收口**　输入：以上各表 → 输出：三要素（sha_class 煞属哪层／treatment_rule 补或制及何法／working_steps 具体月日时取用方向）＋起例来源与卷次依据，并标明「不能制」的部分要如实说不能制。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 落位判错 | 把在向的三煞当在坐处理，或反之 | 先判在坐／在向／在方：太岁可坐不可向，三煞可向不可坐 |
| 用冲不用克 | 拿四柱去冲煞 | 书里「克之则伏、冲之则起」；宜克不宜冲 |
| 不分补制 | 对灸退也用克，对太岁也用克 | 煞强梁有余宜克，灸退休囚不足宜补；太岁宜合不宜冲 |
| 报煞不说起例 | 只报「这是三煞」 | 必给起例（年神八例之一）与卷次依据 |
| 把凶煞说成必发福 | 报「犯三煞反主大富」 | 书里是「制煞修方反获吉福」但附条件；只给倾向，不写保证 |
| 拿被辨误的旧说法当主张 | 用大月建「吉不能制」、金匮即大煞自相矛盾之说 | 这些书里已经辨驳，不作书的主张；详见 `kanyu-xieji-bian-e` |
| 缺日期硬制 | 不知年月就报「这样制就行」 | 制煞全看月令；缺年月就说缺，不硬给 |

**边界规则**：
1. **硬口径**：报神煞、报宜忌必须同时给起例来源与卷次依据；只报一个煞名而不说出处＝不合格。**不要把书里已经辨误的世俗说法当成书的主张**（如大月建「山方中宫无往不忌」、金匮即大煞之吉凶两说，书里已辨其为过当或自相矛盾）。
2. 缺具体日期或事项，就说缺什么、要到什么程度才能判，**不许用占位信息硬判**。
3. 制煞只就修方言；坐山宜补不宜克（克之则山伤）。用户把「制煞」用在坐山上时，退回去辨明是方是山。
4. 象征层只给倾向，不写「一定／必然／命中／保证」；不给医疗、法律、投资结论；不替用户拍板。
5. 不接阴宅实地作业指导。

**来源边界**：本条只据卷三十四原文；神煞的起例详解在义例、立成类条目，宜忌轻重在宜忌类条目，四柱造命框架在 `kanyu-xieji-li-yong-zao-ming`。

**安全兜底**：涉及就医、用药、危机时只做提醒与陪伴，不做诊断。

## 练习手册

- **三层分类默写**：合上本页，写出「不可制／可制而不易制／中煞制之小煞不必制」三层各举两例，再对照原文。
- **四法配对**：把阴府、天金神、地官符、三煞、打头火、天官符、年克、地金神按「干／支／三合／纳音」四法配对。
- **补制判断**：取太岁、灸退、三煞、小耗四个煞，分别写出宜补还是宜制、宜合还是宜冲，并说明理由。

## 灰色地带

- **可制而不易制**：三煞在方在向、阴府在山属此类，书里说「不可轻也」。既不劝用户硬制，也不说绝对不能，只把条件（三合局、休囚之月、吉星照临、修主强健）摆出来，让用户自行掂量，并提醒修主孱弱难驾御。
- **飞宫与定位**：大小月建、官符等有「论飞宫不论定位」的分歧。书里对大月建之说有辨正，遇到这类争议，按书里对定位与飞宫的取舍来讲，标明两说的分别。
- **还宫与飞伏**：煞飞还本位、飞伏同到时，书里嫌其过旺，多以三合局克之。判「还宫」需要知道飞宫起点，缺月建干支就说缺，不硬断。
- **吉星与凶煞同到**：凶煞与吉星会合时，有「与吉星会不为害」「与凶煞会凶」的分判。此时不下一刀切结论，按会合对象分别说。
- **修主强弱**：书里多次提到修主孱弱难驾御凶煞。这是要人到现场判断的事，本条只作提醒，不代判。
