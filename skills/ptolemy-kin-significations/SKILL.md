# 父母与兄弟姐妹：以发光体的"护卫"读亲属

**来源**：《Tetrabiblos》BOOK THE THIRD, CHAPTER V「THE PARENTS」、CHAPTER VI「BROTHERS AND SISTERS」（Ptolemy，Ashmand 英译本）｜ 证据等级：firsthand

## 触发条件

**数据前提**：本 skill 属「象征」层，必须先有出生信息（出生日期、时间、地点，足以排出星盘）才能触发；没有出生信息时只能复述规则。全篇不写成命定论——它给的是古代文本对"亲属关系"的读法，不是对父母、兄弟姐妹的判决。

**应该触发**：
- 用户提供出生信息，问"古典占星里我父母的境遇怎么样"
- 用户问"这张盘里我兄弟姐妹的情况怎么说"
- 用户问"我和父母／兄弟姐妹的关系，盘上有没有指示"
- 用户想弄清"父亲看哪颗星、母亲看哪颗星"
- 用户听过"护卫（doryphory）"这个词，想知道它在这里怎么用

**不应触发**：
- 用户问的是命主自己的寿命 → 走 `ptolemy-lifespan-prorogation`（且那里只作古代文本记录）
- 用户问的是命主自己的身体／疾病 → 走 `ptolemy-body-and-disease`
- 用户问的是命主的性情与心智 → 走 `ptolemy-mind-quality-and-disorder`
- 用户问的是命主的职业、婚姻、旅行 → 属别卷主题，不在本 skill
- 用户要的是关于家人的医学、法律或现实建议 → 不是本 skill

## I：核心解释

1. **父亲与母亲的象征星是固定的**：太阳与土星配父亲，月亮与金星配母亲；把这几颗星彼此的相对位置、以及它们与其它行星恒星的关系摆出来，就说双亲的情况。（R1）
2. **荣显靠"护卫"**：看发光体身边有没有"护卫"（doryphory，书里注为"侍从、卫队"）——发光体同宫或随后一宫的吉星、以及倾向与它一致的星，若是齐全且各自在其权利上站得住，就预示双亲荣显；反之，发光体周围无星相伴、无护卫，则双亲境遇卑微晦暗。（R2、R3）
3. **护卫的性质要对得上**：若护卫的星与发光体"性情不合"（比如火星紧挨着太阳升起，或土星紧跟着月亮），双亲就一生浮沉、上不了台面。若"福点"（part of fortune）的位置与日月护卫相合，双亲的家产稳固；若相冲或凶星组成护卫，家产耗散甚至有负担。
4. **昼夜分工**：白天主要看太阳与金星，夜里主要看土星与月亮。（R5）
5. **混权要算清**：书里提醒，要看是某颗星"独自"掌有运作之因，还是多颗星"分权"；再把它们各自的强弱、性质比一比，才能得出对事件的判断。（R6）
6. **兄弟姐妹看"母亲的位置"**：书里把它与母亲的位置绑在一起（中天所在的星座；白天取金星所在，夜里取月亮所在），并强调这一位置只适用于"同母所出"的兄弟姐妹。（R7）
7. **多寡、性别、长幼、亲疏**：该位置与吉星相配置 → 兄弟姐妹多，人数看吉星的数量与位置（双体星座还是单形星座）；凶星压制或对冲 → 人数少。男性化的星代表兄弟，女性化的星代表姐妹；东出的星代表年长的，西没的星代表年幼的。（R8、R9）

## A1：来源应用 — 书里给的具体做法

- **双亲的境遇**：看太阳/土星（父）与月亮/金星（母）的护卫。护卫由吉星及同性倾向的星组成、且都在自己的权利上稳固 → 荣显；发光体与行星毫无连结、没有护卫 → 卑微晦暗；护卫星性质与发光体不合（火星紧随太阳、土星紧随月亮，或吉星配置不吉） → 一生浮沉、不上不下。福点与日月护卫相合 → 家产稳固；相冲或凶星组成护卫 → 家产耗散、成为负担。（CHAPTER V）
- **更具体的问法**：若还要更细，就把"父母各自的位置"当作上升来另立一张盘来推（白天：父取太阳之位、母取金星之位；夜里：父取土星之位、母取月亮之位），像推父母本人的星盘一样看待。（CHAPTER V）
- **昼夜取舍**：白天以太阳与金星为主看，夜里以土星与月亮为主看。（CHAPTER V）
- **兄弟姐妹**：取母亲的位置与其续宫；与吉星配置则人多数多，看吉星的数量与所在星座（双体或单形）；凶星压制或对冲则人数少，凶星围绕太阳时尤甚。男性化的星为兄弟，女性化的星为姐妹；东出者为长，西没者为幼。若"给兄弟姐妹的星"与"兄弟姐妹宫的主星"和谐，则和睦亲爱；把这份和谐也延伸到福点，则同财同居；彼此不相连或对冲，则互相仇视、欺诈。（CHAPTER VI）
- **只做概略**：书里自己说，兄弟姐妹这一头"只能做一个笼统粗略的考查"，深挖细节是"徒劳的搜寻"。（R10）

## E：执行步骤

### 步骤1：定昼夜与象征星

**输入**：出生信息（足以判断昼盘或夜盘）。
**输出**：父＝太阳与土星、母＝月亮与金星；并标明本盘是昼是夜。
**CHECKPOINT — 触发条件：用户没有出生信息**：只讲规则，不进入具体判断。

### 步骤2：读双亲的"护卫"

**输入**：日月周围同宫及随后一宫的星、吉星与凶星的位置、福点的位置。
**输出**：一段关于双亲荣显／浮沉／家产稳与不稳的粗略描述。
**CHECKPOINT — 触发条件：用户顺势问"我父母还能活多久"**：守住——书里只说"父母寿命要用别的配置另行推断"，本 skill **不作任何寿命或死亡时间断言**；把话头引回"境遇与关系"，涉及父母健康的现实问题一律转现实支持。

### 步骤3：（可选）以父母的位置另立盘

**输入**：昼盘取太阳/金星之位，夜盘取土星/月亮之位。
**输出**：一张用于父母各自情形的"盘"，按通用取用方式读取。
**CHECKPOINT — 触发条件：用户要据此判断父母的具体疾病、离婚、生死**：明确这是古代文本的推演方式，不能替代现实判断，也不下这类断言。

### 步骤4：读兄弟姐妹

**输入**：母亲的位置及其续宫、其上配置的星、吉凶星的压制或对冲、各星的性质与东西出。
**输出**：兄弟姐妹多寡、性别、长幼、和睦或敌对的粗略描述。
**CHECKPOINT — 触发条件：用户想知道"具体是哪一个兄弟姐妹、会不会出事"**：按 R10，书里自己说这类细节是"徒劳的搜寻"——只给概略，不假装能精确到人。

### 步骤5：交代口径与边界

**输入**：前面得出的各项。
**输出**：一段总结：这是古代文本对亲属关系的读法，不是判决；并说明"同母所出"的限定。
**CHECKPOINT — 触发条件：用户把这些话当成对家人的命运宣判**：明确否定命定论，提醒现实里的人际与健康问题以现实方式处理。

## B：边界与失败模式

| 护卫判断脱离上下文 | 只看一颗星就下判断 | 🛑 回到昼夜分工与混权比较 |

| 拿它替代现实建议 | 因盘上的话决定与家人的往来 | 🛑 只作古代文本的读法，现实问题现实处理 |

### 边界规则

1. **读法是记录，不是结论**：本 skill 只转述《Tetrabiblos》第三卷第五、六章对亲属的判法；含"父母寿命"的段落只作**古代文本的记述**，是古代文本的记录，不是可验证的结论，**绝对不作寿命或死亡时间断言**。
2. **只做概略**：兄弟姐妹一项，书里自己限定为粗略考查。
3. **不写成命定论**：亲属关系的走向不由一张盘注定。
4. **需要出生信息**：属象征层，出生日期时间地点是硬前提。
5. **与相邻 skill 分工**：命主自己的寿命走 `ptolemy-lifespan-prorogation`；身体走 `ptolemy-body-and-disease`；心智走 `ptolemy-mind-quality-and-disorder`。
6. **安全兜底（🏥 涉及健康一律不作医疗判断、不替代就医）**：涉及父母的疾病、离世、家庭危机时，只做陪伴与提醒，指向现实的医疗与支持资源，不作医疗判断、不替代就医，也不作预测，也不替用户决定与家人的关系。若出现心理危机或自伤念头，中国大陆可拨 12356；紧急拨打 120 / 110。

**护卫清点**：把太阳与月亮前后一宫的星列出来，标出吉/凶与性质，照书里的判法自己排一遍。
