# 支葬其额、垄葬其麓

**来源**：《葬書》（舊題郭璞）外篇 ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户描述一块地「像山又像平地」，问它到底算支还是算壟；
- 用户直问「支葬其额、垄葬其麓是什么意思，我这块地该葬在哪一头」；
- 用户读到「平夷如掌」「卜支如首、眩壟如點頭」，要把它落到自己手上的地形上；
- 用户问「为什么支要葬额、壟要葬麓，道理在哪」；
- 用户已经有一处疑似「似支之城 / 似壟之支」的地，想按原书看看往哪边归。

**不应触发**：
- 用户问的是「支龙、垄龙的整体体认框架」（支垄之辨的总纲）→ 转 `kanyu-zangshu-zhi-long-bian`；
- 用户问的是「同一片群山该挑哪一座」→ 转 `kanyu-zangshu-ze-te`；
- 用户问的是「乘金相水、穴土印木四法怎么定穴」→ 转 `kanyu-zangshu-si-fa`；
- 用户问的是审核一块已定的地废没废 → 转 `kanyu-zangshu-shen-fei-ze-xiang`；
- 用户要的是「到这里怎么下葬、挖多深」的现场指令 → 不接，本 skill 只做文本层的归类与位置判读。

## R：原文锚点

1. "夫支欲伏於地中，壟欲峙於地上。"（《葬書》外篇）
2. "支城之止，平夷如掌。"（《葬書》外篇）
3. "故支葬其額，城葬其麓。"（《葬書》外篇）
4. "卜支如首，眩壟如點頭。"（《葬書》外篇）
5. "形氣不經，氣脫如逐。"（《葬書》外篇）
6. "緩處何妨安絕頂，急時不怕葬深泥。"（《葬書》外篇，《錦囊》注）
7. "或葬城於頹首，葬支於麓足，則生氣脫散，如馳逐也。"（《葬書》外篇，《錦囊》注）
8. "夫人之葬，蓋亦難矣。支壟之辨，眩目惑心，禍福之差，候虜有間。"（《葬書》外篇）
9. "支葬其頹，緩而急之也；攏葬其麓，急而緩之也。"（《葬書》外篇，《錦囊》注）

引文说明：第 1–5、8 条是经文；第 6、7、9 条取自《錦囊》注段落。第 9 条注里的用字（支葬其頹、攏葬其麓）与经文不同，本书里額／頹、壟／攏／城互用，一律照原样抄，不改成今字。

## I：核心解释

这一节讲的是**两套地形各自该落在哪一头**。先分体段，再谈落点，次序不能颠倒。

1. **先分体段**——「支欲伏於地中，壟欲峙於地上」。支的性向是**隐伏**（伏者隐伏），壟的性向是**隆峙**（峙者隆峙）。同一个走势里，隐伏于地中、近乎平地者偏支，隆峙于地上、成山脊者偏壟。这是判读的起点：分不清支壟，后面额麓就无从谈起。
2. **止处都平**——「支城之止，平夷如掌」。支与壟的葬法虽然不同，但它们的**止处**（脉尽气聚之处）在书里是同一个形容：平夷如掌。注里引的倒杖口诀「斷續續斷，氧受於坦；起伏伏起，氣受于平」和旧说「來不來，坦中裁；住不住，平中取」，都在这句「如掌」上落脚。所以判读时先看止处平不平，不看它原来长在山还是长在平地。
3. **落点相反**——「故支葬其額，城葬其麓」。支葬它的**额**（前端高处、巅首），壟葬它的**麓**（山脚缓处）。书里给的理由是缓急相济：「支葬其頹，緩而急之也；攏葬其麓，急而緩之也」——支性缓，用葬在额上来收（急之）；壟性急，用葬在山麓来松（缓之）。「卜支如首，眩壟如點頭」，注里说「如首如足，亦即巔麓之義」，首对巅、足对麓，说的是同一个意思。
4. **反了就脱气**——「形氣不經，氣脫如逐」。支壟之葬随形势各有**常度**，不按常度就「不經」；具体反成什么样？「或葬城於頹首，葬支於麓足」——把壟葬到高高在上的额首、把支葬到低处的麓足，位置正好颠倒，书里说生气就脱散，像被赶着跑掉一样。
5. **缓急是一句断语**——「緩處何妨安絕頂，急時不怕葬深泥」是书里引的金牛之语，属《錦囊》注里的说法，说的是缓的地方哪怕葬到绝顶也无妨、急的地方不怕葬进深泥。照引时标明这是**书里的说法**，不当作本 skill 的固定操作。
6. **支壟之辨本身就难**——「支壟之辨，眩目惑心」。书里自己承认有「似支之城、似攏之支」「支來而壟止、壟來而支止」，甚至「非支非壟之不可辨者」；它把这种分辨交给「明师耳提面命」，说弄反了（首足倒施）「其禍立至」。也就是说，这一节给的是一套**体认与归类**的框架，不是一张能替代现场的对照表。

一句话收束：这一节回答的是**「这块地该落在哪一头」**——前提是先认出它偏支还是偏壟，再看止处是否平夷如掌，最后按缓急之理定额麓；三者有一项认不准，就先停在归类，不急着下位置。

**支壟判读速览表**（每一行都能追回上面 R 节）：

| 判读步 | 看什么 | 书里的话 | 弄错会怎样 |
|---|---|---|---|
| 分体段 | 隐伏于地中／隆峙于地上 | 夫支欲伏於地中，壟欲峙於地上 | 体段不分，额麓无从谈起 |
| 看止处 | 脉尽处是否平夷如掌 | 支城之止，平夷如掌 | 止处不平，谈不上聚气 |
| 定落点 | 支→额（巅首）／壟→麓（麓足） | 故支葬其額，城葬其麓 | 首足倒施，生气脱散如驰逐 |
| 明缓急 | 支缓故急之／壟急故缓之 | 支葬其頹，緩而急之也；攏葬其麓，急而緩之也 | 把「缓急相济」读成「越高越好」 |

这个次序是死的：体段 → 止处 → 落点，不能跳。用户常一上来就问落点（该葬哪头），先把他拉回体段——体段认不准，落点是空给。反过来，若止处已平夷如掌、体段也清楚，落点这一问就水到渠成，不必再纠结高处低处哪个更「吉」：书里给的是缓急相济的理，不是高下优劣的评比。

## A1：来源应用

书上给的具体做法（不是本 skill 的发挥）：

- **判体段**：先用「伏于地中／峙于地上」把这一处分到支或壟；注里给的口径是「伏者隱伏，峙者隆峙」。
- **看止处**：支城之止一律以「平夷如掌」为准；注里用倒杖口诀与旧说（坦中裁、平中取）来佐证止处之平。
- **定落点**：支葬额（巅首）、壟葬麓（麓足）；用缓急解释——支缓故急之，壟急故缓之。
- **认反例**：支壟互用、首足倒施 → 生气脱散如驰逐；这是判读时要主动排除的错法。
- **书的断语**：金牛之语（缓处安绝顶、急时葬深泥）属注中引说，标明是书里的说法。
- **难处照说**：似支之城、似壟之支，乃至非支非壟，书里明说难辨，交由明师耳提面命——本 skill 遇到这类只指出「疑似」与「需现场再辨」，不硬归。

## A2：典型触发场景

用户在生活里具体长什么样：

1. 用户在老家看了一块地，一半像缓坡、一半像小山脊，问「它到底算支还是算壟」。
2. 用户读到「支葬其额、垄葬其麓」，问「我这块地是不是该往高处（额）葬，还是往山脚（麓）葬」。
3. 用户说「别人告诉我这块地葬在山头，可我看它像是平洋余气」，怀疑落点搞反了。
4. 用户问「支城之止、平夷如掌」到底看什么才叫平如掌。
5. 用户遇到一处「像支又像壟」的地，问该往哪边归、会不会「首足倒施」。
6. 用户问「支城葬法既然不同，为什么止处都用平夷如掌来形容」——回应：书里两套葬法不同，但止处的形容是同一个，先把止处看平，再谈两套落点。

## E：执行步骤

1. **收料并就缺**　输入：用户的地形起伏描述（隐伏还是隆峙）＋待判问题 → 输出：「已给／缺项」清单，缺地形起伏、止处之形这两样里的哪一样。
   🔴 **CHECKPOINT**：若连「偏伏还是偏峙」都说不清，只凭一句「像山又像平地」就停在这里，列出要看的三样（起伏、止处、周边高下）请用户补，不进入落点判断。
2. **判体段归支壟**　输入：伏/峙的起伏描述 → 输出：归类结论——偏支 / 偏壟 / 疑似似支之城 / 疑似似壟之支，并写清归类的依据。
3. **看止处**　输入：脉尽处的形状、水是否交度 → 输出：止处是否合「平夷如掌」的判断（合／不合／说不清）。
   🔴 **CHECKPOINT**：把「体段归类」与「止处判断」并列展示，请用户确认归类对不对，再谈落点。
4. **定落点**　输入：归类结果＋止处判断 → 输出：落点倾向（支→额/首，壟→麓/足），并用缓急之理给出理由；同时对「反向落点」（葬城于頹首、葬支于麓足）标为需要排除的错法。
5. **收口**　输入：上面各栏 → 输出：一段总结，含「疑似与需现场再辨」的部分、「不能下的结论」与待补观察；凡属书的断语（金牛之语等）都标明「这是书里的说法」。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 凭一句「像山又像平地」就定支壟 | 用户没给起伏与止处，就直接说该葬额还是该葬麓 | 回到步骤 1 列缺项；体段认不准就停在归类，不硬定落点 |
| 把「额／麓」当成固定的高低 | 一律说「葬得越高越好」或「一律葬山脚」 | 按书里缓急相济：支缓故急之（额），壟急故缓之（麓），看性向不看好坏 |
| 认不出「似支之城 / 似壟之支」硬归 | 把两可的地硬塞进支或壟 | 标为「疑似」，照书里交现场再辨，不下死判 |
| 拿金牛之语当固定操作 | 不问缓急，直接照「绝顶／深泥」做 | 标明那是《錦囊》注里的断语，是书里的说法，非本 skill 的操作规则 |
| 越界给现场指令 | 直接编出「挖几尺、朝向某方」 | 本 skill 只到归类与落点倾向为止，作业指导不接 |

**边界规则**：
1. 缺地形起伏或止处之形时，只列缺项，不硬判支壟与落点。
2. 「额/麓」只作倾向表述，不写成「葬这里必然发」。
3. 书里的断语（金牛之语、祸福之差之类）是书里的说法，引用即标明。
4. 支壟之辨本身难以文本判死，遇「非支非壟」只指出疑似，交现场再辨。
5. 不接阴宅实地作业指导，不给医疗、法律、投资结论，不替用户拍板。

## 练习手册

- **一句话分辨**：合上 I 节，用「伏于地中／峙于地上」各写一句自己的话，把支与壟的**性向**说清，不要用「高低」代替。
- **缓急换位**：假设同一处地形性向偏缓，按书里写它该葬哪一头、理由是什么；再把它假设为偏急，重写一遍，体会「缓急相济」不是「越高越好」。
- **反例辨识**：默写「支城互用、首足倒施」反成的两种情形（葬城於頹首、葬支於麓足），并说明它违反了哪一条常度。
- **顺序默写**：把「分体段→看止处→定落点」写三遍，每次故意打乱一处次序，看打乱后结论错在哪，再说回正确次序。

## 反例黑名单

1. 把「支葬额、壟葬麓」说成「越高越好／越低越好」——书里用的是缓急相济，不是高下优劣。
2. 止处不看是否「平夷如掌」，只看它原来在山还是在平地——次序颠倒。
3. 遇到「似支之城、似壟之支」硬归一边——书里明说难辨，应交现场再辨。
4. 拿《錦囊》注里的金牛之语（缓处安绝顶、急时葬深泥）当固定操作规则——那是书里的说法，须标明。
5. 用户只给一句「像山又像平地」就开始定落点——缺料就说缺料。
6. 把「支城葬法虽不同、止处都是平夷如掌」读成「支壟可以混着葬」——止处同形，不等于落点可以互换。

## 灰色地带

- **支壟两可**：一处地隐伏之中又带隆峙之形，书里也举过「支来而壟止、壟来而支止」这类交叉情形。此时给两可归类，写明各自的落点倾向，请用户补止处之形再收窄，不强行二选一。
- **止处平但落点难定**：止处已合「平夷如掌」，但额与麓的高下差不大——按书里仍分额麓，只是落点的倾向会弱，此时给弱倾向并说明需要现场再看。
- **注与经文用字不一**：经文说「額／麓」，注里说「頹／麓」「攏／麓」。这是本书异体互用，照原样引用，不替它统一用字，也不因用字不同而判为矛盾。
- **一处兼有伏与峙**：同一片地里既有隐伏的平洋余气、又有隆峙的小脊。书里分体段本是为了定落点，遇到兼有两形时，按主势归体段（哪一形主导止处），把另一种标为「兼形」作补充，不各给一半结论。
