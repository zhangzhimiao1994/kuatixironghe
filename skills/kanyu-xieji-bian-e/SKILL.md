# 辨讹：辨世俗术家之讹

**来源**：`sources/xieji.txt`《欽定協紀辨方書》卷三十六·辨訛（清乾隆官修，四庫本） ｜ 证据等级：firsthand（原书原话）/ inference（推断，须标注）

## 触发条件

**应该触发**：
- 用户问某个择日说法到底站不站得住、是不是术士编的。
- 用户被「合婚大利月」「天狗」「杨公忌」「灭门大祸」这类名目吓到，想知道原书怎么说。
- 用户问「斗首五行是不是杨筠松传的」「玉皇銮驾这些星到底有没有」。
- 用户想知道两个名字是不是同一个煞（名异实同）。
- 用户拿通书或万年书一条旧说法来对质。

**不应触发**：
- 用户只想抄附錄里某个条目的内容与来历 → `kanyu-xieji-fu-lu`（存旧）。
- 用户问怎么制煞、补龙扶山 → `kanyu-xieji-zhi-sha` / `kanyu-xieji-li-yong-zao-ming`。
- 用户问公规历法 → `kanyu-xieji-gong-gui`。
- 用户要断吉凶祸福、要医疗法律投资结论 → 不接。

## R：原文锚点

1. 「術士好竒而嗜利譌言繁興比以為吉彼以為凶自漢褚少孫補史記已言之況又經六代唐宋元明以來其謬説又不知凡幾二十四向而神煞盈千六十甲子而術家盈百以前民利用之具而成惑世誣民之書不可不辨也」（《欽定協紀辨方書》卷三十六·辨譌）
2. 「隂陽家言多病迂泥術士揑造益屬荒唐而惑世誣民則未有如合婚大利月之尤甚者」（《欽定協紀辨方書》卷三十六·男女合婚大利月）
3. 「為是説者不知其所自起而皆托於吕才觀唐書吕才傳其於隂陽術數辨駁甚詳則其為術士之偽托無疑也」（《欽定協紀辨方書》卷三十六·男女合婚大利月）
4. 「然合婚之説北方世俗用之士大夫及南方皆不深信而行嫁大利月則舉世用之而不辨其非」（《欽定協紀辨方書》卷三十六·男女合婚大利月）
5. 「彼昏不知悞以為道家所稱太陽帝君太隂帝君銀河星君遂各揑一玉皇以壓之以致紛紛不一誣罔極矣」（《欽定協紀辨方書》卷三十六·諸家鑾駕星曜）
6. 「按斗首五行不知其所自起為其説者皆托之楊筠松及觀筠松所著諸篇絶無一語論及斗首其為偽托可知」（《欽定協紀辨方書》卷三十六·斗首五行）
7. 「選擇宗鏡則曰神無所不在以此三十五日為神在日其不在日又何在乎」（《欽定協紀辨方書》卷三十六·神在）
8. 「世俗多畏楊公忌通書亦多載之謂其日不宜出行舉事犯之不利皆因未悉其原委故為所惑耳」（《欽定協紀辨方書》卷三十六·楊公忌）
9. 「通書以每月初四初七十六十九二十八凡五日謂之四不祥忌上官赴任臨政親民世俗信之惟謹」（《欽定協紀辨方書》卷三十六·四不祥）
10. 「按紅沙即身壬煞儲華谷以為極數然驛馬亦是極數是不得以極為凶也」（《欽定協紀辨方書》卷三十六·紅沙）

## I：核心解释

卷三十六是全书的校准支。开篇就定调：术士好奇而嗜利，讹言繁兴，你说吉他说凶；二十四向而神煞盈千、六十甲子而术家盈百；把前民「利用之具」变成了惑世诬民的書，「不可不辨也」。所以这一卷的任务不是再添玩法，而是回头把流传的说法逐条过筛。答用户时，要把书里这种「辨」的态度如实带出来，不能和稀泥，也不能替某一方站台。

1. **辨的手法有四**：一看起例（这个煞从哪一例起、能不能自圆其说）；二看名实（名字与所指是不是同一个东西）；三看自相矛盾（同一个煞名在同一書里吉凶两说）；四看托名（说是某人所传，查其書却无一语论及）。
2. **托名之辨**：合婚大利月「皆托于吕才」，书里查唐书吕才传，见其于阴阳术数辨驳甚详，断定「其为术士之伪托无疑」；斗首五行「皆托之杨筠松」，而观杨筠松所著诸篇「绝无一语论及斗首，其为伪托可知」。可见托名是最常见的造假手法。
3. **名异实同之辨**：一浮天空亡也，又名头白空亡、又名八山空亡；一坐煞向煞也，又名翎毛禁向、八山刀砧；六害别名阴中太岁、阴中煞；小耗别名净栏煞；黄道黑道又别立明星黑星。名号旁见侧出，惑人耳目。
4. **自相矛盾之辨**：金匮即大煞，以其旺为吉又以其旺为凶；驿马前一干，以为临官则吉、以为六害则凶。同一马前，吉凶两说，显相牴牾。
5. **名可畏而实无之辨**：冰消瓦解、灭门大祸，凶到极点，究其实则只是一个平收日；杨公忌说其日不利出行举事，查其究竟只是室宿值日之说；上吉七圣的「七圣」把黄帝、元女、文王、周公、孔子、天老、董仲舒凑在一起，书里说「亦可嗤矣」「益为怪谬不伦」。
6. **水土不合之辨**：密日、伏断、太白游方等出于西域历法，西域月日与中国不合，密日之忌安葬启攒、十三宿之宜裁衣「亦出彼地俗忌，并不可从」。
7. **书里也分两层**：学理上辨其非，行政上对久行的民俗则「存其旧」。如五姓修宅、嫁娶周堂、太白游方、长星短星、洗头日，奏议里请删，朝廷之议以「民俗便安遵行已久」仍存时宪书内。所以答用户时要把「书里辨它非」与「书里为何仍收它」两层都讲清，不能只说一半。
8. **与附錄的分工**：附錄（`kanyu-xieji-fu-lu`）负责存旧与注明可疑，本条目负责把是非说到位。凡附錄里标了疑的条目，辨正在这里。

## A1：来源应用

**男女合婚大利月（最重的一条辨）**：书里说夫妇之道、人伦之始，诗书未尝有合婚之说，禄命之法也未曾以男女年月定妨妻妨夫；此说托于吕才，考吕才传知其伪托。又析其法之谬：三元九宫本是年九星入中宫之一星，非谓其年之生命即在是宫，由年衍于人、由男衍于女已属展转支离；又以地理家游年变卦之法两宫相配定吉凶，比儗非伦——地理专取净阴净阳，婚姻则取阴阳配偶，葬之所谓吉正是婚之所谓凶。孤辰寡宿由奇门孤虚推衍，「荒诞无义理」；胞胎相冲、骨髓破、铁扫帚、年月六害、四败生命等，逐条皆无义例。行嫁大利月以女命为主，阳年本命前一月、阴年本命后一月为大利，次月妨媒、次月妨翁姑……「求之阴阳五行九宫八卦堪舆建除丛辰之说，无一可通」，故说「惑世诬民之尤甚者」。书里又说男女合婚北方世俗用之、士大夫及南方皆不深信，而行嫁大利月则举世用之而不辨其非。

**诸家銮驾星曜**：玉皇銮驾、紫微帝星、北辰帝星、撼龙帝星、都天宝照、周仙罗星、星马贵人等，「既非实有此星，又且必无此理」；一帝星之中又有金轮火轮水轮天乙太乙诸名，皆术士捏造。书里反问：择日取日月星辰到山向，是喜山向之光辉，岂谓日月星辰中有神仙？今皆删去不用。

**巡山二十四神煞**：年支神煞随二十四山顺行，从太岁逼近之方起、渐推而远、还归太岁之方（如子年癸名巡山罗㬋凶、丑暗曜凶、艮土宿凶……）。书里说观其名思其义、考其例度其情，其为术士捏造已然明白；唯巡山罗㬋逼近太岁、俗所最畏而亦尚近乎理，故台本取之，余皆不用。

**驿马临官**：即驿马前二干及其对方。书里说同一马前，以为临官即吉、以为六害即凶，显然自相矛盾；三合长生对冲为驿马，与前後干支了无干涉，命吉命凶皆妄谈；今一并删去。

**刀砧火血·逆血刃·九良星·暗刀煞**：逆血刃以八干四维分布六十甲子各占一字而不用十二支，「毫无理路，但取三字之可怕以恐吓愚人」；九良星、暗刀煞亦分布六十甲子、六十月各占十二处，「至为谬妄」。

**支退流财**：支神退方子年起巳逆行十二支，又名流财。书里说阴阳之义正不以进退为吉凶，且非实有一物起巳而逆行；今通书支退唯子丑巳午未酉亥年与起例合、流财唯辰午未酉戌年与起例合，余年皆误，故「今之所谓退者亦非退，而流者亦非流也」。

**神煞同位异名**：浮天空亡别名头白空亡、八山空亡，坐煞向煞别名翎毛禁向、八山刀砧；六害别名阴中太岁、阴中煞，小耗别名净栏煞；黄道黑道别立明星黑星，雷公与天岳吉凶互异（雷公即青龙本吉、天岳即天牢本凶，因讹而为吉凶颠倒）。书里说「神煞一也，而名号旁见侧出，惑人耳目，深可厌恶」。

**斗首五行**：以甲己化土、五子元遁定山属，配元辰、廉贞、贪狼、武曲、破军之名论生克。书里说其说「托之杨筠松」，而杨筠松诸篇无一语论及，为伪托；其大旨「已离其宗」，廉贞贪狼诸名又非卦变本义，别为吉凶格局「更不可问」。

**尊星帝星·神在·上吉七圣**：尊星帝星年起例上元下元甲子起乾六、中元甲子起坎一，书里说其起例「甚无义理」，「大抵亦术士之捏造耳」；神在日三十五日，书里引宗镜「神无所不在，以此三十五日为神在日，其不在日又何在乎」；上吉七圣、大明日是李淳风、贾耽所集之说，「全无义理」，其「七圣」尤怪谬不伦。

**伏断日密日裁衣日·上元下元·四不祥·红沙·章光·五合五离**：伏断以日配宿似旬空路空，然其义「不能通」，「理非自然数非脗合，皆属捏造」；密日乃房虚星昴四宿属日、西语曰密，彼地以为主喜事而中国遂以其日忌安葬启攒，「亦无谓矣」；四不祥从月朔取对七为冲、隔三为破，「不论月建与干支，而以月朔定冲破，甚属不经」，今删去不用；红沙即身壬煞，极数之说不能成立（驿马亦是极数而不为凶）；章光、五合五离（俗术以戊寅己卯为日月合之类，甲乙何以为日月、丙丁何以为阴阳「皆不可晓」）皆附会害理。

**的呼日·殃煞出去方·满德吉庆·冰消瓦解灭门大祸**：的呼日临事之日被呼之人避之，世俗误孝子生命值被呼者甚至不亲殓不临穴，「败俗伤化莫此为甚」，考其所忌之日又毫无义理；殃煞出去方（以月将加死时取天罡河魁下为殃出）奉旨不用；满德吉庆为宗镜所斥之伪吉日；冰消瓦解、灭门大祸按例推之即年支之平收，凶到极处而取快于一日之干支，「虽三尺童子亦知不信」。

**杨公忌·天狗·六道·五符择时·九仙时**：杨公忌乃室火猪日，元旦起角宿顺数，书里说「并非值日之宿而强以角宿起元旦」，「邪说诬民莫此为甚」；天狗由月厌衍出，把月厌、厌对、天喜、红鸾等折中取位硬配头尾口腹背足，「谬悠极矣」；六道（天地兵人鬼死）与五符择时、九仙时皆「谬妄」「无义理」，今日表已删。

**奏议中的应删应改（卷三十六末所载）**：男女合婚、红沙、上兀下兀、四不祥应删；神在日宜删；九丑本于壬遁乃选时之法，通书误以选时为选日；天德月德注时宪书止宜修造动土一类的，与名义不合；五姓修宅「徒滋拘忌」应删。这些都是校订过程中明列的应删应改条目。

## E：执行步骤

1. **认说法**　输入：用户提的说法或名目 → 输出：它是不是卷三十六已辨的条目，以及大致属哪类讹（托名／名异实同／自相矛盾／水土不合／名可畏实无／起例无理）。
   🔴 **CHECKPOINT**：把「说法→所辨条目→讹的类型」列成一小表展示，等用户确认说的到底是哪一条；说法含糊就停在这里问清。
2. **查起例与名实**　输入：确认的说法 → 输出：它的起例来源与卷次依据；起例自相矛盾或名实不符之处。
3. **照书里的辨法逐条辨**　输入：起例与名实 → 输出：书里对该条的辨语要点（伪托的考据、矛盾的指出、水土不合的说明、名可畏而实无的揭示）。
4. **分学理与民俗两层**　输入：书里的辨语 → 输出：学理上的是非（辨其非）与行政／民俗上的处理（存其旧或删去），两层分开说。
   🔴 **CHECKPOINT**：展示「辨其非（学理）」与「存／删（民俗行政）」两栏，明确告诉用户：书里辨它为讹，不等于时宪书立刻不用它——这两件事要分看。
5. **给结论**　输入：以上各栏 → 输出：这条说法是否应当作书的主张；附錄里若也收了，说明两处分工。
6. **收口**　输入：结论 → 输出：三要素（claim_summary 说法是什么／verdict 书里的判定／ground 依据在哪），并标出不确定处。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把已辨误的说法当书的主张 | 报「合婚大利月犯月妨人」「杨公忌不宜出行」 | 这些正是卷三十六要辨的；引书里的辨语，标明为世俗说法 |
| 和稀泥、不表态 | 「信则有不信则无」式敷衍 | 照书里态度如实辨：伪托、矛盾、无理就直说，依据给足 |
| 只辨不管民俗层 | 把一个久行的民俗一刀否定 | 分手理与民俗两层：学理辨其非，民俗上存／删另有交代 |
| 拿辨讹去否定一切择日 | 由辨讹推出「择日全不可信」 | 辨讹辨的是术家捏造之讹，不是否定择日本身；书里另有正编 |
| 报煞却不说起例与卷次 | 只报名不给出处不符本族口径 | 每条都补起例来源与卷次依据 |
| 缺上下文硬判 | 不知用户说的是哪一条就下结论 | 先认准是卷三十六的哪一条，认不准就问 |

**边界规则**：
1. **硬口径（本条的核心）**：报神煞、报宜忌必须同时给起例来源与卷次依据；**不要把书里已经辨误的世俗说法当成书的主张**——本条目就是专门用来把这两者分开的。只报名不给出处＝不合格。
2. 缺具体日期或事项，就说缺什么、要到什么程度才能判，**不许用占位信息硬判**。
3. 象征层只给倾向，不写「一定／必然／命中／保证」；不给医疗、法律、投资结论；不替用户拍板。
4. 涉及婚嫁、丧葬这类人生大事，只转述书里的辨正，不替用户决定婚期或丧仪。
5. 不接阴宅实地作业指导。

**来源边界**：本条只据卷三十六原文（含卷末所载校订奏议中列出的应删应改条目）。附錄（`kanyu-xieji-fu-lu`）里的存旧条目，其是非判定以本条目为准；两者重叠处不重复下断，指回本条目。

**安全兜底**：涉及就医、用药、危机时只做提醒与陪伴，不做诊断。

## 练习手册

- **四辨法练习**：取合婚大利月、斗首五行、金匮大煞、密日四条，分别用「看起例／看名实／看自相矛盾／看托名」判断各属哪一类讹。
- **两层分离**：任取一条被辨误却仍载时宪书的条目（如五姓修宅、周堂），写出「学理上怎么辨」与「行政上为何仍存」两栏。
- **名异实同配对**：把浮天空亡、坐煞向煞、六害、小耗、黄道黑道与其别名各配一次，说明为什么书里嫌它们「惑人耳目」。

## 灰色地带

- **辨其非与存其旧并存**：一条说法在学理上被辨为无义理，却因久行民俗仍载于时宪书（五姓修宅、周堂、太白游方、长短星、洗头日是显例）。处理办法是两栏并列、分别说明，不把「已被辨非」说成「已废不用」，也不把「仍载」说成「书里认可」。
- **只辨其名、未断其实**：有些条目书里只指出起例无理或名异实同，未直接说它吉凶如何（如支退流财、五合五离）。这类只转述书里的辨语，不替它补一个新结论。
- **新法与古法的分歧**：参觜先后、罗㬋计都属火属土，书里说「与算法疎密全无关碍」并主依古改正。遇用户追问，照书里的取舍说，不卷入新旧法之争。
- **条目名相同、所指不同**：同一名目（如「天狗」「六道」「九仙」）在不同术家或不同通书里所指可能不同。先确认用户说的是哪一家的说法，再引对应的辨语。
- **辨讹的边界**：卷三十六辨的是择日术家的捏造之讹；超出这个范围的（如它业之术、他书之误），本条不作判，只说明超出范围。
