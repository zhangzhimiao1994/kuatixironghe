# 命例匯錄與讀法

**来源**：sources/sanmingtonghui.txt（《三命通會》卷一～卷十诸卷所载命例） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问《三命通會》里那些「某人某造、官至某职」的记录怎么读。
- 用户看到「如一命壬申壬子戊午乙卯……所以大貴」这种，问前面的八字和后面的断语是什么关系。
- 用户问原书为什么在讲一个格时会捎带举几个古人的八字。
- 用户问书里这些八字是哪个时代的人、能不能拿来对自己。
- 用户问原书里「五行八字相同而富貴貧賤壽夭之不一」那句是在争论什么。
- 用户问同一格下为什么有的断成「大貴」、有的断成「貧賤」「為道人」。
- **用户给出自己的四柱、问「我这盘怎么看／这盘像书里哪一类读法」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息；仍不许拿任何一条命例去套这个人）。

**不应触发**（看起来像但其实不是）：
- 用户拿自己的八字问吉凶、问官运贫富 → 先按缺柱说明，本 skill 只讲书里命例的读法，判盘回到相应格节与入口。
- 用户问珞琭子賦的赋句读法 → 转 bazi-sanming-luo-lu-zi。
- 用户问十干體象、纳音、人元司令 → 转 bazi-sanming-tian-gan / bazi-sanming-na-yin / bazi-sanming-ren-yuan。
- 用户只给生日、属相这类泛化词，没有问书里命例 → 本维度不因泛化词激活。
- 用户要断终身、批流年大运、判寿夭疾病 → 不接。

## I：核心解释

原书讲一个格、一段调候或一个神煞时，常在末尾缀上「如一命……」或「如某某（官职）某造」。这些就是命例：前面一串四字一组是八字，后面一句是原书对这一造的评语。读它要抓住几条，都能追回 R 节。

1. **它们是「记录」，不是对当世的推断**。四库提要说明这书「中間所載仕宦八字往往及明季之人」（R1），并且怀疑其中「後来坊刻所攙入」。所以书里的命例是明及以前留下的记录，读法上只能当「原书怎么用它」来看，不能拿某个命例去套当代的人（要求里有这一条）。
2. **一条命例成两部分：造 + 评语**。「如虞尚書癸未甲寅戊午丙辰是也」（R3）是「称谓（官职/人名）+ 四柱 + 评语」的样子；「己未辛未丙子癸巳合格大貴」（R20）则只给造与断语。读的时候先拆出这四柱四组，再看领起它的那一句在讲哪个格、哪个神煞。
3. **命例是给「格」做实例的**。「如髙文薦都憲丁亥癸卯丁卯庚子柱多亥子煞印為貴」（R12）挂在论丙丁那一节，用来印证「煞印」这一路；「聞淵尚書庚子甲申庚寅丙戌」（R18）挂在日禄归时下。也就是说，命例不是孤立摆着的，它替前面那条规则作证。
4. **同一条规则，评语可以两样**。论劫煞那一处，原书一口气举了「如辛丑戊戌丁亥壬寅讀書及第改官就祿」（R7）与「如辛丑丁酉乙未戊寅犯官司後大發」（R8）——两造同带某煞，一个读书及第、一个犯官司后才发；再往下又举「己卯丁卯乙卯辛巳殺猪屠户」（R9）。同一抓手，结果天差地别，这正是在提醒：书里的断语要看整体配置，不能只凭一个字。
5. **神煞也能有反例**。论元辰那处，原书说「廣信集取巫伋參政己卯甲申己巳甲戌滕康樞密乙丑壬午乙丑壬午二命豈不犯元辰」（R4）——用两个大贵之造来反问「难道他们就没犯元辰么」，借命例说明元辰这一煞不能单断。
6. **贵人也有贵气厚薄**。「丙申己亥辛未己亥辛巳丙申壬午壬寅俱互換見貴前命有氣為宰相後命無氣為太守」（R5）：同是天乙互换见贵，原书以「有氣／無氣」分出宰相与太守——命例在这里是给「贵气分厚薄」做例证。
7. **读起来真切的也有**。「蘓東坡學士丙子辛丑癸亥己卯」（R6）这样直接点人名与八字，是原书拿读者熟悉的人来钉住一个说法。
8. **断语里还有「父祖」这一层**。「如甲寅癸酉壬戌庚子其父為太平宰相可謂腹中藏貴煞胎裏叫官人是生旺中得鬼制是也」（R10）——一条命例不只讲本命，还可带着前一代。
9. **书自己就争论过同八字的问题**。「何人生天地之中有五行八字相同而富貴貧賤壽夭之不一，其故何也」（R2）是原书的设问；书里从「禀清濁」「得令失令」「積善積惡」几路作答。读命例时把这条问带上，就不会把一条评语当成铁的对应。
10. **书里也留了极端的一类**。「韓信被誅只傷天地轉煞」（R22）是把古史人物拉来做「天地轉煞」的例；「明王崇古少保乙亥辛巳戊申庚申」（R17）则用到明代的人（此造在原书里与「韓魏公」「宋秦檜」同列于食神同窠，R15、R16）。
11. **一句收拢的读法**：先看领起句在讲什么（格／神煞／调候），再把四柱拆开，再读评语，最后问一句「这条评语是书里的说法，还是对某个人的事实判决」——前者照读，后者不落到具体的人身上。

## A1：来源应用

书上给的做法（不是我的发挥）：

- **命例随格出现**。原书把命例放在诸格、诸神煞、诸调候的末尾，用「如一命」「如某某（官职）某造」领起；读法就是回到那一节看它在替哪条规则作证（R3、R12、R18、R20 都是这样）。
- **称谓即官职/人名**。原书常写「虞尚書」「楊博尚書」「孟重侍郎」「高文薦都憲」「聞淵尚書」这类称谓加四柱；四库本无页码，出处记到卷次与篇名即可。
- **评语用词要照读**。书里写「大貴」「富」「貧賤」「殺猪屠户」「為道人」「不禄」等，是书里的评价语；引用时标明是书里的说法，不当作对某人的事实判决。
- **同煞两断的读法**。原书在同一抓手下列出结果相反的两造（R7、R8、R9），意思是断在整体配置、不在单字；这是原书自己给的读法。
- **考据一层照实带**。四库提要（R1）与卷七子平説辯都对这些八字与骆琭子赋的来历存疑，读命例时把这一层带出，不替原书拍板。

**落到盘上的读法**（拿到四柱后，按书里命例的读法走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：四柱按四字一组拆开，日主、月令，柱中显见的神煞与刑冲合（用户给了就照排，不擅自改字）。
2. **逐条核书里的条件**：先看这盘落在书里哪一种读法上——同煞为何两断 → R7／R8／R9（断在整体配置、不在单字）；同八字为何不同果 → R2（禀清濁、得令失令、積善積惡几路）；贵气厚薄 → R5（有氣／無氣）；单煞能否定命 → R4（以大贵之造反问元辰不能单断）。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「同一煞之下，按 R7／R8 这一类读，偏『断在整体配置，不在一字』」，并带出处（如「《三命通會》卷三」）。
4. **收口**：这一句是**书里的读法**，不是对这个人吉凶的判决；**不拿任何一条命例去套这个人**，**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：原书没有拿现代统计或概率去解释这些命例；没有把命例编成「验证数据库」；也没有「某个八字一定出某个结果」的现成对应表。缺什么就说什么，不补。

## A2：典型触发场景

1. 用户翻到卷五论正官，看到末尾一串「楊博尚書……」「劉應節尚書……」，问这些是干什么用的。
2. 用户看到「如一命壬申壬子戊午乙卯……所以大貴」，不知道前面那八个字怎么念、后面怎么接。
3. 用户问书里这些古人的八字是不是真的、是哪个朝代的。
4. 用户想拿书里某条命例来对自己或亲友，问「我这个和他像不像」。
5. 用户看到同一个格下有「大貴」有「貧賤」，问凭什么两样。
6. 用户看到「五行八字相同而富貴貧賤壽夭之不一」，问原书怎么答这个。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–6 步）：讲书里命例怎么读；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 7–8 步）：按书里命例的读法逐条核这盘（仍不许拿任何一条命例去套这个人）。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **分清问的是书里命例还是用户自己**（文本解读）　输入：用户的话 → 输出：判是在问原书所载命例的读法，还是在问用户自己的八字。
   🔴 **CHECKPOINT**：若是问用户自己而没给四柱，先说明本 skill 只讲书里命例怎么读，判盘要回到相应格节与入口，并照实说缺哪几柱。
3. **定位领起句**（文本解读）　输入：命例所在的那一节 → 输出：说清它挂在哪个格／哪个神煞／哪个调候上，这条命例替谁作证。
4. **拆四柱**（文本解读）　输入：命例的八字 → 输出：按四字一组拆出年月日时四柱（原书不标柱名时照原样列），不擅自改字。
5. **读评语**（文本解读）　输入：命例后面的断语 → 输出：照读，并标明是「书里的说法」；遇到「大貴」「貧賤」「殺猪屠户」这类，只当评价语。
6. **遇同煞两断就并列**（文本解读）　输入：同一抓手下的多条命例 → 输出：并列呈现（如 R7 与 R8），说明断在整体配置、不在单字。
7. **取盘上的料**（落盘）　输入：用户四柱 → 输出：四柱按四字一组拆开，日主、月令，柱中显见的神煞与刑冲合（照排，不擅自改字）。
8. **逐条核条件、给读法**（落盘）　输入：第 7 步的料 ＋ 本 skill 的条件 → 输出：
   - 这盘落在书里哪一种读法上：同煞为何两断 → R7／R8／R9（断在整体配置、不在单字）；同八字为何不同果 → R2（禀清濁、得令失令、積善積惡几路）；贵气厚薄 → R5（有氣／無氣）；单煞能否定命 → R4（以大贵之造反问元辰不能单断）；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷三」）。
9. **收口并报缺**　输入：整段推演 → 输出：一句「这盘按书里哪一类读法看」＋一句「书里怎么说」；若用户信息不齐，照实说缺什么。
   🔴 **CHECKPOINT**：收口前确认——① 没把「大貴」「貧賤」「夭夀」「殺猪屠户」这类书里的评价语落成对某人的事实，也没拿任何一条命例去套这个人；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格／神煞／术语带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿命例套当代人 | 说「你这个八字和某尚書一样，所以也能贵」 | 拉回「书里所载是明及以前的记录」这一层，不套当代人 |
| 把评语当事实判决 | 由一条命例推某人一定贫、一定夭 | 标明是书里的说法，只读倾向 |
| 单凭一个字断同煞之命 | 说凡带某煞必犯官司 | 用 R7／R8／R9 的例子说明断在整体配置 |
| 改字凑合 | 把命例里的字按今字写、或换柱 | 逐字照抄源文件，异体字原样 |
| 凭记忆写命例 | 写出书里没有的「某造」 | 只引 R 节核过的句子，核不过就删 |
| 越界断终身/流年 | 由命例推用户今年运程 | 不接，说明只讲书里命例读法 |
| 缺柱硬排 | 用户只给生日时段就往下套 | 先说缺哪几柱、要齐到什么程度 |

**边界规则**：
1. 只读书里所载命例（人名/官职＋八字＋评语）及其所在格、神煞、调候的读法。
2. 命例皆为明及以前的记录，引用时说明；不得用某个命例去套当代的人。
3. 象征层只给倾向，不写「一定／必然／命中／保证发财发贵」。
4. 书里的断语（「大貴」「貧賤」「夭夀」「殺猪屠户」等）引用时标明是书里的说法。
5. 不批流年大运、不断终身、不判生死寿夭、不得依据八字给出疾病诊断、寿命预测、生育判断、婚姻决定。
6. 不给医疗、法律、投资结论。
7. 缺出生年/月/日/时任一柱或缺出生地，照实说缺什么，不用占位信息硬排。

**来源边界**：本 skill 只据 sources/sanmingtonghui.txt，取卷一～卷十诸卷所载命例（以卷三、卷四、卷五、卷六为多）；四库本无页码，出处记到卷次与篇名；不引别书、不引网页。骆琭子赋本身的读法不在此，转 bazi-sanming-luo-lu-zi。

- [ ] 评语都标了「书里的说法」，没落到具体的人身上。
- [ ] 没把任何命例套到用户或当代人身上。
- [ ] 没出现本族禁用的一类专有名词，路径是包内相对路径。
- [ ] 没拿现代科学或后世命理流派术语给古书背书。

**安全兜底**：涉及就医、用药、危机时，只做提醒与陪伴，不做诊断。

## 📖 练习手册

- **拆造练习**：任取 R 节一条命例，把四柱按四字一组拆开，标出哪一节在讲什么（格／神煞／调候）。
- **评语归类**：把 R 节里的评语（「大貴」「為宰相」「犯官司後大發」「殺猪屠户」等）抄出来，各注明是书里的说法。
- **同煞两断**：以 R7 与 R8 为例，写出两造的相同处与不同处，说明为什么断语相反。
- **代际自问**：写下一句提醒自己的话：书里命例是明及以前的人，不可拿来套今天的谁。

## 🚫 反例黑名单（不要做的事）

1. 拿书里某条命例去套用户或亲友，说「和他一样，所以你也会贵/会贫」。
2. 把「大貴」「貧賤」「夭夀」「殺猪屠户」这类评语说成对某人的事实判决。
3. 单凭一个字就断同煞之命，不看整体配置。
4. 凭记忆写命例，不逐字核源文件。
5. 用户只给生日时辰就往下套命例——先说缺什么。
6. 由命例推用户的流年、终身、寿夭疾病。
7. 把四库提要与卷七子平説辯的考据当成定论，或拿它当「灵驗」的兜售。

## 灰色地带

- **同八字不同果**：原书自己就设问「五行八字相同而富貴貧賤壽夭之不一」（R2），并从「禀清濁」「得令失令」「積善積惡」几路作答。遇此就把书里的几路并列呈现，不替原书拍板哪一路为准。
- **书里既收又疑**：提要（R1）说这些仕宦八字或为坊刻搀入，读法上照实带出这层存疑，不因它「像真的」就当真。
- **命例与格名对不上**：原书偶有同造分见两处、职名不一（如某人一处作侍郎、一处作都憲）。两处并列标清各出何处，不自行折中。
- **用户要「命例＋判我这张盘」**：命例照讲，判盘的部分回到相应格节与入口，并说明缺哪几柱；不把命例当模板往用户身上贴。
- **用户问这些古人八字「准不准」**：只讲原书怎么用它、书里怎么说，不作「灵驗」或「迷信」的自我评价。
