3. 两意情通中有媒，虽然遥立意寻追；有情却被人离间，怨起恩中死不灰。（《滴天髓闡微》六親論·恩怨）

7. 喜神不必多也，一喜而十备矣；忌神不必多也。一忌而十害矣。（《滴天髓闡微》六親論·閒神·原注）
8. 有用神必有喜神，喜神者，辅格助用之神也（《滴天髓闡微》六親論·閒神·任注）

13. 此乃贪合不化之意也，既合宜化之，化之喜者，名利自如；化之忌者，灾咎必至。（《滴天髓闡微》六親論·閒神·任注）

## I：核心解释

这三篇是一组：奮鬱讲**气机显晦**，恩怨讲**喜忌的向背与离合**，閒神讲**用喜忌之外那批神怎么摆放**。三篇共用同一套零件——用神、喜神、忌神、闲神、合神。

1. **奋与郁的两个极端**：经文先说结果——「局中显奋发之机者，神舒意畅；象内多沉埋之气者，心郁志灰」（R1）；原注给因——「阳明用事，用神得力，天地交泰，神显精通，必多奋发；阴晦用事，情多恋私，主弱臣强，神藏精泄，人多困郁」（R2）。分野就在**用神得不得力、局气是阳明还是阴晦**。
2. **恩怨是「喜忌」两字的向背**：任注一句话点题——「恩怨者，喜忌也」（R5）。喜神与日主之间有合神引通，就「如中有媒」，恩；喜神被忌神隔占、离间，求合不得，就多怨。经文那句「两意情通中有媒，虽然遥立意寻追；有情却被人离间，怨起恩中死不灰」（R3）说的正是这两种向背，原注又补「喜神合神，两情相通，又有人引用生化，如有媒矣」（R4）。
3. **闲神是用喜忌之外的旁神**：任注先立范围——「自用神、喜神、忌神之外，皆闲神也」（R9）；原注给性质——「喜神不必多也，一喜而十备矣；忌神不必多也。一忌而十害矣」（R7），言下之意：够数的喜忌就顶用，剩下的多是闲神。
4. **闲神「莫动它」的用法**：经文「一二闲神用去么，不用何妨莫动它；半局闲神任闲着，要紧之场作自豪」（R6）——平时不必去动闲神，到岁运撞上破格损用、喜神又顾不上时，闲神反能制化凶神、匡扶喜用，成了「自家」。
5. **闲神篇后两句讲两种「动」法**：「出门要向天涯游，何事裙钗瓷意留」（R10）讲**贪合留连**——日主或喜用被合绊住，有志难伸，任注说这是「贪合不化之意」（R13）；「不管白雪与明月，任君策马朝天阙」（R11）讲**逢冲得用**——日主或喜用所贪恋之他神被冲去，反能从喜用之势而驰骤，原注说这是「日主乘用神而驰骤，无私意牵制也；用神随日主而驰骤，无私情羁绊也」（R12）。

## A1：来源应用

书上给的做法，都在「用神—喜神—忌神—闲神」这套零件里排序：

- **判奋郁**：先看用神得不得力、局气偏阳明还是阴晦（R1、R2）。任注进一步把「年与运」也拉进来——局虽阴晦而运途阳明亦能舒畅，象虽阳明而运途阴晦亦主困郁，所以要连运一起审。
- **判恩怨**：看喜神与日主是**紧贴**还是**远隔**，中间有合神牵引（恩）还是有忌神隔占（怨）（R3、R4、R5）。
- **摆闲神**：先把用神、喜神、忌神认出来，剩下的都作闲神（R9）；不必多动（R6），到岁运破格损用时再看它顶不顶用。
- **辨合与冲**：同是闲神篇，一句讲被合绊住「瓷意留」（R10、R13），一句讲被冲开而「朝天阙」（R11、R12）——是留连还是得用，看合化得成不成、冲得动不动。
- **一句话口径**：奋郁看气机，恩怨看向背，闲神看摆放；三件事都回到「用神有没有势、喜忌有没有各得其所」。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月令、四柱十神分布，先认出用神、喜神、忌神各是哪一个，其余归闲神；再看局气偏阳明还是阴晦、年与运在盘上给到没有。
2. **逐条核书里的条件**：用神得力不得力、局气是阳明还是阴晦 → R1／R2；喜神与日主是紧贴还是远隔、中间有合神牵引（恩）还是有忌神隔占（怨）→ R3／R4／R5；用喜忌之外剩几个闲神 → R9；闲神有没有被合绊住（瓷意留）或被冲开（朝天阙）→ R10／R11／R12／R13。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「日主与用神之间有合神引通，按 R3／R4 这一路读，偏『恩相得』，出处《滴天髓闡微》六親論·恩怨」。
4. **收口**：这一句是**书里的读法**，不是对这个人的判定；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：原书讲这三篇只讲神与神之间的向背离合，不讲后世流派的「心情指数」「运势打分」；这些都不进本 skill。

   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **确认问的是哪一篇、哪一句**（文本解读）　输入：用户的话与所引句子 → 输出：判定落在奮鬱／恩怨／閒神哪一处，以及具体是哪一两句。
   🔴 **CHECKPOINT**：若问的是六亲、從化局或性情疾病诸篇，先说明本 skill 只管这三篇，并指到对应 skill。
3. **摆出零件**（文本解读）　输入：所问的句子 → 输出：照 R5、R8、R9 把用神、喜神、忌神、闲神的界说摆出来，标明哪句是经、哪句是原注／任注。
   🔴 **CHECKPOINT**：摆零件只报界说不给出处，退回补齐。
4. **讲向背或显晦**（文本解读）　输入：定好的篇目 → 输出：奋郁讲阳明阴晦与用神得力与否（R1、R2）；恩怨讲喜神远隔／紧贴、有媒／离间（R3、R4）。
   🔴 **CHECKPOINT**：抄的是书里的用法，不是自己按五行生剋现推的。
5. **讲闲神的「动」与「不动」**（文本解读）　输入：用户问的是闲神 → 输出：先给「莫动它」（R6、R7），再给岁运「要紧之场」与合冲两动（R10、R11、R12、R13）。
6. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干、月令、四柱十神分布；先认出用神、喜神、忌神，其余归闲神；再标出局气偏阳明还是阴晦、年与运给到没有。
7. **逐条核条件、给读法**（落盘）　输入：第 6 步的料 ＋ 本 skill 的条件 → 输出：
   - 用神得力与否、局气阳明阴晦（R1、R2）→ 喜神与日主的向背离合（R3、R4、R5）→ 闲神的界面与去留（R6、R7、R9）→ 合留还是冲得（R10、R11、R12、R13）；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《滴天髓闡微》六親論·奮鬱」）。
8. **收口**　输入：整段推演 → 输出：一句界说 + 一句取用 + 一句出处；结尾说明本 skill 到取象为止，不接运程与终身断。
   🔴 **CHECKPOINT**：收口前确认——① 没把书里对局气的评价语（如「心郁志灰」「困郁」）落成对某人的事实或情绪诊断；② 走落盘路径时已声明**不应期、不断终身、不替人决定**（含不落寿夭疾病生育）；③ 报的格局或术语带得出卷次或篇名。给四柱者照实只报取象与依据，不做落人身的终身判定；缺柱则说要补什么。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把奋郁讲成情绪诊断 | 由局气直接说用户「抑郁」「性格怎样」 | 拉回 R1、R2：只讲神舒意畅／心郁志灰这两种结构，不做情绪或心理判断 |
| 恩怨讲成感情恩怨 | 把「恩怨」理解成人际或情感纠葛 | 拉回 R5：「恩怨者，喜忌也」，讲的是喜神与日主的向背 |
| 把闲神一律当坏神 | 说「有闲神就不好」 | 拉回 R6、R7：闲神本可不动，要紧之场反能作自家 |
| 分不清「留」与「冲」 | 把 R10 与 R11 两句混成一句 | 分开讲：一句是贪合留连，一句是逢冲得用 |
| 缺柱硬算 | 只有一句「我最近很憋屈」就断运 | 停下，说缺哪柱、要到什么程度才能排 |
| 越过范围断运程 | 顺势批出某年吉凶 | 收口在取象，不批流年大运、不断终身 |

2. 只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 经文与原注／任注必须分栏标注。

## 灰色地带

- **用户只说「我很憋屈」不给盘**：不硬接；说明本 skill 讲的是书上对局气的取象，要落到某人得先有四柱。
- **奋郁与恩怨问在同一次**：两篇分别讲，不混成一条；说明它们共用同一套零件但抓手不同。
- **闲神篇原注与任注有分歧**：任注明说「此章本文，所重者在末句」而「原注未免有误」；据实并列，说明是书里注家之间的分歧，不替用户拍板。
- **用户把「朝天阙」当励志句**：照实说明书上它讲的是逢冲得用、不为私情羁绊，不是普通的人生鸡汤。
- **同一句既像奋又像郁**：局气与运途常一明一晦，据实说书里的分法要连运一起看，两种都讲，不替用户归一类。
