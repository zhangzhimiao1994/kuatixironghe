# 九星辨形与星峰吉凶

**来源**：撼龍經（唐楊筠松，欽定四庫全書本） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 「这座山尖尖的，是贪狼吗？」
- 「我听说文曲的山不好，是真的吗？」
- 「古人说的『三吉』是哪几颗星？」
- 「别人给我写的报告里说这里是破军，到底怎么看出来的？」
- 用户给一张山峰照片或一段形状描述，想按九星的象去归类。
- 用户读到「廉貞独火」「武曲一金」这类话，想知道原文与意思。

**不应触发**（看起来像但其实不是）：
- 用户要的是「整条山脉哪一段是干、哪一段是枝、水怎么夹送」 → 归 `skills/kanyu-hanlong-gan-zhi-long/`（那里管大势与干枝）。
- 用户已经有穴场圆晕，只问该盖该粘、用哪一种杖法 → 归 `skills/kanyu-dao-zhang-shi-er-fa/`。
- 用户已有确切形势，只想弄懂某个砂法条目怎么读 → 归 `skills/kanyu-er-shi-si-sha-zang-fa/`。
- 用户想按星形给自己的地「打分」「判等级」「算能发多大」 → 本件不接，原书没有这种玩法。
- 用户问某个日子吉凶 → 那是择日的事，不归本件。

## I：核心解释

九星就是贪狼、巨门、禄存、文曲、廉贞、武曲、破军，加上左辅、右弼（R1）。原书把「三吉」点得很清楚：贪、巨、武三颗，余下还有辅、弼（R1）。这是先立名目，再辨形。名目立好以后，第一件事不是断吉凶，而是认形。

**辨形先于断吉凶**。原书对贪狼说「自有十二様」，尖、圆、平、直、小为上，欹、斜、侧、岩、倒、破、空另一路（R2）。也就是说，同一颗星本身有正形，也有变体和破体，不能拿一个「贪狼」的名字压倒一切。后面分条细辨，全是在这十二样上做分辨。

**每颗星各有其象**：贪狼尖，巨门方而端荘（R3），禄存像倒过来的鼓、下面生脚如瓜瓠（R4），文曲如蛇行、作邪像撒网（R5），廉贞独火、高大嵯峨（R6），武曲像覆着的钟釜（R7），破军像飘动的旗、前高后低（R8），左辅像幞头、前高后低（R9），右弼没有正形、随八曜高低而生（R10）。认形就是把这些「象」逐一对照到眼前的峰上。

**星与星还有祖孙关系**。原书说「火星要起廉貞位生出貪狼由此勢」（R14）：廉贞属火，贪狼由它而生，所以一处尖峰值不值得看，往往先看它上头有没有廉贞作祖。这类关系是判形的旁证，不是吉凶的保证。

**吉凶断语是书里的评价语**。原书在断语一栏里，对禄存说「君切忌醜惡崩欹不綿媚」（R11），对廉贞说「獨火大凶災」（R12），同时又说辅弼「常隨七星轉多在明堂左右見」（R13）。这些话引自书里，是这一体例下的评价，不是事实承诺；真正要判的时候，还得回到形状本身。

还有一层要紧的：星名不是判词。原书一边说禄存「君切忌」，一边又说「莫道禄存全不善大為將相公侯門」（R15）。两处并存，正说明差的是「正形还是丑恶崩欹」，而不是星名本身。

**九星还会互变、分主从**。原书说「九星皆挾文曲行若無文曲星無變變星便看何星多多者為主分惡善」（R16）。意思是龙行途中星与星会换，某一段以哪颗星为主，就看哪颗星多；多者为「主」，其余作配。所以辨形不能只看孤峰，还要看这一段以谁为主。

**平地也能辨星**。原书在讲弼星时说过「八曜入坪皆有蹤」，又说「平裏貪狼皆一同」（《撼龍經》）：平地同样有星形可认，不是只在山上才谈九星；平地看的是低伏的形与隐约的踪，判法与高山一致，只是更考眼力。

## A1：来源应用

原书把九星分两头写：先写每颗星的形（形篇），再写每颗星的断语（断语篇）。两处要合起来看。

1. **贪狼**。形：「貪狼自有十二様尖圓平直小為上」，又分「尖狼」「圆」「平」数种正形（R2）。断语：「貪狼一木勢尖强鬼星秀麗足文章」（《撼龍經》），意思是贪狼属木、形体尖强，配着秀丽的鬼星，书里作文章之应——这是书里的说法。
2. **巨门**。形：端荘、体方、不尖不圆（R3）。断语：「巨門一土少人知端正秀麗如蛾眉」（《撼龍經》），属土，贵在端正。
3. **武曲**。形：像覆钟釜（R7）。断语：「武曲之星號一金卓圭立笏髙千尋」（《撼龍經》），属金，书里作兵权、韬略之应。
4. **禄存**。形：如顿鼓、下生脚如瓜瓠（R4）。断语：「禄存一土君切忌醜惡崩欹不綿媚」（R11）；但原书又说「莫道禄存全不善大為將相公侯門」（R15）——所以禄存不是一概不善，丑恶崩欹的才犯忌。
5. **文曲**。形：正形如蛇行，作邪如撒网（R5）。断语：「文曲一水何孤單」（《撼龍經》），属水，书里说它柔顺、最易见，也最容易生枝生足而散。
6. **廉贞**。形：独火、高大嵯峨（R6）。断语：「廉貞獨火大凶災」（R12），书里又把它唤作红旗、曜气，说它威烈属阳精；但它也是贪狼的祖（R14）。
7. **破军**。形：如走旗、前高后低（R8）。断语：「破軍二金招凶惡」（《撼龍經》），属金，书里说它多是引龙兼作护、作水口。
8. **辅弼**。左辅形如幞头、前高后低（R9），右弼本无正形、随八曜高低而生（R10）。断语：辅弼随七星转、多显在明堂左右（R13），书里作近侍、随龙的定位。
9. **认形的两组字眼**：一组是正的——尖、圆、平、直、小、方、端正；一组是破的——欹、斜、侧、岩、倒、破、空、崩、欹。判形先分这两组，再往星名上靠（R2）。
10. **看主从**。「九星皆挾文曲行若無文曲星無變變星便看何星多多者為主分惡善」（R16）：一段龙里哪颗星多，就以哪颗为主，其余为配；辨形时先定主星，再看配星。
11. **巨门少鬼劫**。「巨門行龍少鬼刼」（《撼龍經》）：巨门端正，行龙时少鬼劫，多靠两傍罗列护卫来关拦。
12. **贪狼上岭下岭**。原书说「上嶺解生朱紫貴下嶺須為朽腐家」（《撼龍經》）：同样一颗贪狼，落在岭上还是岭下，书里的断语不同——上岭作贵、下岭作朽腐。这也是书里的评价语，引用时须标明。

## A2：典型触发场景

1. 用户在山上或看照片，指着某座峰问「这是贪狼还是巨门」。
2. 用户读到「三吉」「輔弼」这类词，不明所指，来问是哪几颗星。
3. 用户听到「文曲一水何孤單」「破軍二金招凶惡」这类断语，想知道原文怎么说、是什么意思。
4. 用户拿一份堪舆文字来核对，里面给某座峰定了星名，想看看形与名对不对得上。
5. 用户想学着按形状给山峰分类，练一练眼力。
6. 用户看到一处尖峰，想知道「是不是贪狼、吉不吉」。
7. 用户想知道「九星里哪些是三吉、哪些要小心」。
8. 用户描述一段山脉，说每座峰形状不一，想知道「以哪一颗为主」。

## E：执行步骤

1. **收形状描述**　输入：用户对山峰的零散描述（尖／圆／方／平／直／欹斜／破碎；有没有脚；是石是土；高耸还是低平） → 输出：一张「形状特征表」，逐项标有／无／不确定。
   🔴 **CHECKPOINT**：若「有没有脚」「是石还是土」「是否破碎」三项缺两项以上，停下，说清缺什么、到什么程度才能辨形；不许凭一个「尖」字就定贪狼。
2. **比对星形**　输入：形状特征表 → 输出：一到两个候选星名，每个候选都写出对应的原文形状句（R2–R10）。
3. **辨正形与变体**　输入：候选星名与形状 → 输出：这一处是正形，还是原书说的欹斜侧岩倒破空的破体（以贪狼十二样为准，其余星同此理）。
4. **引断语（标明是书里的评价语）**　输入：定下来的星名与正／变 → 输出：该星在书里的断语原文与出处，并注明「这是书里的说法」。
5. **收口**　输入：以上各步 → 输出：一句倾向性判断，加缺项，加下一步建议（若还牵连大势与干枝，转 `skills/kanyu-hanlong-gan-zhi-long/`）。
   🛑 **STOP**：只给星名倾向与书的断语，不写「一定」「必然」「命中」「保证发财发贵」。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 只见一个「尖」就定贪狼 | 不顾有脚没脚、是石是土、是否破碎 | 回步骤一，把形状特征表补齐再比 |
| 把变体当正形 | 明明是欹斜破碎，仍按该星的正形吉断 | 用 R2 的「尖圓平直小為上」一条条对照，先定正／变 |
| 把书的断语当承诺 | 直接说「此处出公侯」「必然发财」 | 引原文时标明「这是书里的说法」，只给倾向 |
| 星名与形不符还硬套 | 形状像巨门却因别处听来说「破军」 | 以形状句为准，名从形出 |
| 缺形状描述硬辨 | 只有「这山很好」这类空话 | 列出缺项，暂停，等具体形状 |
| 把九星当吉凶等级表 | 以为贪巨武一律吉、廉破文一律凶 | 每星都有正形与变体（R2、R15），先辨正／变再谈断语 |
| 只看一峰不看四周 | 单说这一峰多正，不问它有没有祖、有没有随从 | 补看周围：有无廉贞作祖（R14）、有无辅弼随护（R13） |
| 只看孤峰不定主从 | 一段龙里各峰不同，仍逐峰孤立断吉凶 | 按「多者為主」（R16）先定主星，再看配星 |

**边界规则**：
1. 本件只做「这峰像哪颗星、书里怎么断」的归类，不做穴位落点、朝向、深浅判断。
2. 断语一律标明来源，只给倾向，不当保证。
3. 不接阴宅实地踏勘与下葬作业指导，不替用户拍板。
4. 星名是形的归类，不是吉凶的判决；正形与变体分开说。

**来源边界**：本件引文全部取自 `sources/hanlongjing.txt` 的《撼龍經》正文；该书为无标点歌诀，引文照抄、不加标点。原书所附各图与后世注本不在本件依据之内。

## 练习手册

- **星形对照表默写**：合上 A1，凭记忆写出九星的「形」与「断语」各一条，再对照原书补漏。
- **看图辨形**：找三张不同形状的山峰照片，分别写下形状特征表，再对 R2–R10 定候补星名，写出「为什么不是另外一颗」。
- **正变之辨**：拿一句「尖而有脚」和一句「尖斜破碎」，分别判该归属哪一种、是正形还是变体。
- **断语标注**：任取一条原书断语，抄下来，在句末补一句「此系书中评价语，非承诺」。
- **主从练习**：取一段有多个峰的地形描述，数各类形状各几座，按「多者为主」定出主星，再写配星。

## 灰色地带

- **一峰兼具两星之形**：如「尖而有脚」「方而带圆」。按原书「尖则贪、方则巨」先各写一条，说明两者各看哪一处特征，请用户补关键一角（顶、脚或身体）再定，不强行选一。
- **正形与变体只差一线**：原书自己就说「欹側似斜斜似側」「圓無欹側四靣同」，边界本就模糊。此时照实说「两可」，给出两种读法各自的原话。
- **断语吉凶打架**：如禄存既被说「君切忌」又被说「大為將相公侯門」。此时并列两处原文，说明差别落在「正形还是丑恶崩欹」，不取其一充作通说。
- **形像某星、断语却难套**：如一处端正的方峰近巨门，但周围无随无护。此时只写形的归类，断语一条标「据现有描述不足」，不替它补。
- **主星与配星数量相近**：一段龙里两种星数差不多。此时并列两种主星读法，说明各以什么为准，请用户补更长的一段以定多寡，不硬断其一。
