# 窮通寶鑑·論水：壬水癸水的逐月取用

**来源**：sources/qiongtongbaojian.txt（《窮通寶鑑》論壬水、論癸水） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户拿一个壬水日主的盘，问某月该取庚、辛、戊、丙、甲里的哪几个字。
- 用户拿一个癸水日主的盘，问同一类逐月取用。
- 用户读到「水冷金寒爱丙丁」不懂，问冬天水为什么先要丙。
- 用户问「先戊后辛」「先用辛金癸水」这些次序差在哪。
- 用户问壬水与癸水同一月为什么取法不同。
- 用户问「土止流水福寿全」这类书里的说法怎么读。

**不应触发**：
- 用户问的是木／火／土／金日主的逐月取用 → 各转 bazi-qiongtong-mu／bazi-qiongtong-huo／bazi-qiongtong-tu／bazi-qiongtong-jin。
- 用户问的是五行总纲 → 转 bazi-qiongtong-wu-xing。
- 用户手上没有四柱、只凭一句生日问运 → 先按 bazi-hub 的硬闸门走，缺柱不排。
- 用户要批流年大运、断终身、判寿夭疾病、替人做婚姻或职业决定 → 本 skill 不接。

2. 凡壬日无比肩羊刃者，不必用戊，专用庚金，以丙为佐。（《窮通寶鑑》論壬水·正月壬水）
3. 二月壬水，寒气初除，有并流之象，不用丙暖，专取戊土辛金。二月壬水，先戊后辛，庚金次之。（《窮通寶鑑》論壬水·二月壬水）

9. 七月壬水，庚金司令，壬得申之长生，源流自远，转弱为强，专用戊土，次取丁火佐戊制庚。（《窮通寶鑑》論壬水·七月壬水）

14. 腊月壬水，先取丙火，丁甲为佐，故水冷金寒爱丙丁。（《窮通寶鑑》論壬水·十二月壬水）
15. 正月癸水，值三阳之候，雨露之精，其性至柔，先用辛金，生癸水之源，次用丙火照暖，名阴阳和合，万物发生。（《窮通寶鑑》論癸水·正月癸水）

18. 三月癸水，要分清明谷雨。清明后、火气未炽，专用丙火，为阴阳合谐。（《窮通寶鑑》論癸水·三月癸水）
19. 四月癸水，喜辛金为用，无辛用庚。（《窮通寶鑑》論癸水·四月癸水）

21. 六月癸水，有上下月之分。下半月庚辛有气，上半月庚辛休囚。（《窮通寶鑑》論癸水·六月癸水）

24. 九月癸水，失令无根，戊土司权，剋制太过，专用辛金发水之源，要比肩滋甲制戊方妙。（《窮通寶鑑》論癸水·九月癸水）
25. 十月癸水，旺中有弱，何也？因亥摇木，洩散元神，宜用庚辛为妙。（《窮通寶鑑》論癸水·十月癸水）
26. 十一月癸水，值冰冻之时，金水无交欢之象，专用丙火解冻，庶不致成冰，又要辛金滋扶（《窮通寶鑑》論癸水·十一月癸水）
27. 十二月癸水，寒极成冰，万物不能舒泰，宜丙火解冻。（《窮通寶鑑》論癸水·十二月癸水）

## I：核心解释

《窮通寶鑑》论水这一块，把壬水与癸水分成两条：壬是江河大水，怕的是泛滥无制；癸是雨露柔水，怕的是干涸无源。逐月次序就围绕这两条。

1. **壬水先管「源」再管「流」**：正月「宜用庚金之源，庶不致汪洋无度」（R1），又补「无比肩羊刃者…专用庚金，以丙为佐」（R2）。水要有庚金生它才不枯，有戊土堤它才不乱。
2. **壬水的夏月求金水**：四月「专取壬水比肩为助，次取辛金发源」（R6）、五月「取癸为用，取庚为佐」（R7）、六月「先用辛金癸水」（R8）。夏天水弱，靠比肩与金源接上。
3. **壬水的秋月求戊与甲**：七月「专用戊土，次取丁火佐戊制庚」（R9）、八月「忌戊土为病，专用甲木」（R10）。同是秋月，七月水得申长生而转强，故取戊土堤之；八月辛金当权、戊土反成病，故专取甲木制戊。
4. **壬水的冬月求丙戊**：十月「专用戊丙」（R12）、十一月「先取戊土，次用丙火」（R13）、十二月「先取丙火，丁甲为佐」（R14），并给一句「水冷金寒爱丙丁」（R14）。水冬司令当权，最要丙火暖之、戊土制之。
5. **癸水先管「源」与「暖」**：正月「先用辛金，生癸水之源，次用丙火照暖」（R15），总结「辛金为主，庚金次之，丙亦不可少」（R16）。辛金发源、丙火解寒，是癸水的两件事。
6. **癸水的春秋重金**：二月「专以庚金为用，辛金次之」（R17）、九月「专用辛金发水之源」（R24）、十月「宜用庚辛为妙」（R25）。木旺泄水之月，靠金补源。
7. **癸水的水不是一味求金**：三月「专用丙火」（R18）、四月「喜辛金为用」（R19）、八月「取辛金为用，丙火佐之」（R23）。月令不同，金与水、水与火的轻重也不同。
8. **书里的断语与口诀**：像「土止流水福寿全」（R4）、「水冷金寒爱丙丁」（R14），是原书的口诀与断语，引用时标明是书里的说法，不当作对某人的判决。

## A1：来源应用

书上给的做法，是「先定月令寒暖 → 再排用神次序 → 最后看需要的字透干、藏支」。

- **先分壬癸**：日主是壬还是癸。壬水汪洋，重「发源」与「堤防」；癸水至柔，重「生源」与「照暖」。同一月两条路子不一样。
- **按令排次序**：
  - 壬水——正月庚金为主、丙为佐（R1、R2）；二月先戊后辛、庚金次之（R3）；三月先用甲疏季土、次取庚金（R5）；四月专取壬水比肩、次辛金（R6）；五月取癸为用、取庚为佐（R7）；六月先用辛金癸水、次甲木（R8）；七月专用戊土、次丁火（R9）；八月专用甲木（R10）；九月专用甲木、次用丙火（R11）；十月专用戊丙、次庚金（R12）；十一月先取戊土、次用丙火（R13）；十二月先取丙火、丁甲为佐（R14）。
  - 癸水——正月先用辛金、次用丙火（R15）；二月专以庚金为用、辛金次之（R17）；三月分清明谷雨、清明后专用丙火（R18）；四月喜辛金为用、无辛用庚（R19）；五月必须庚辛为生身之本（R20）；六月分上下月、下半月庚辛有气（R21）；七月必取丁火为用（见 R22 及其下文）；八月取辛金为用、丙火佐之（R23）；九月专用辛金、要比肩滋甲制戊（R24）；十月宜用庚辛（R25）；十一月专用丙火解冻、又要辛金滋扶（R26）；十二月宜丙火解冻（R27）。
- **看透藏定轻重**：原书对同一序里的字分「两透／一透一藏／俱藏」。如十一月壬水「丙戊两透，富贵荣华」（R13）。透干的字比藏支的得力。
- **土多先疏**：凡戊己当令或土重之月（三月、六月、九月），壬癸都先看甲木有没有出来疏土（R5、R8、R24）。
- **一句话口径**：壬看「发不发源、堤不堤得住」，癸看「有没有源、暖不暖」。

**书里没有的、不要加**：原书论水只讲逐月取用与透藏轻重，不讲后世流派的「旺衰计分」「自动取用程序」。本 skill 沿用书上「用神」的叫法（如「取癸为用」），不加自造的判定步骤。

## A2：典型触发场景

1. 用户排出壬水日主、生在申月，问「书上说专用戊土、次取丁火佐戊制庚，我戊藏支算不算」。
2. 用户拿癸水日主、生在子月，问「专用丙火解冻，还要辛金滋扶，到底先谁」。
3. 用户读到「水冷金寒爱丙丁」，问这句在讲什么。
4. 用户同一张盘问「壬水和癸水论法一样吗」，想对照两条。
5. 用户拿生在酉月的癸水，问「取辛金为用、丙火佐之」怎么落到字上。
6. 用户问「为什么壬水七月要用戊土、八月反而要用甲木」。

## E：执行步骤

1. **确认日主与月令**　输入：用户的话、四柱 → 输出：日主是壬还是癸、生月（或季）。只有季段没月份时标「时段内不唯一」，癸水还要注意书里「上下月分」的说法。
   🔴 **CHECKPOINT**：缺年月日时任一柱就停下，缺什么说什么，不占位硬排；缺柱时把用户引到 bazi-hub 补盘。
2. **对号取次序**　输入：日主＋月令 → 输出：从 R 节抄出当月那条次序（如壬水七月「专用戊土，次取丁火佐戊制庚」）。
   🔴 **CHECKPOINT**：抄的是原书次序，不是自己按五行生剋另推的。
3. **看透藏排轻重**　输入：四柱干支 → 输出：序里的字哪些透干、哪些藏支，按书里「两透／一透一藏／俱藏」的说法排轻重。
4. **给依据与取用条件**　输入：第 2、3 步结果 → 输出：两句必备——原书出处（《窮通寶鑑》論壬水·某月／論癸水·某月）＋ 凭什么这么取（月令寒暖、透藏）。
   🔴 **CHECKPOINT**：只报次序不出处，或只出处不讲取用条件，都退回补齐。
5. **收口**　输入：整段推演 → 输出：一段月令读法 + 一条取用次序 + 一句出处；结尾说明本 skill 到此为止，不接流年大运与终身断。
   🔴 **CHECKPOINT**：确认没有把书里的口诀与评价语（「非贫即夭」「孤苦」这类）当成对用户的判决。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 拿别的日主套水的次序 | 用户是庚金日主也答「先取丙火」 | 先确认日主；不是壬癸就转对应各篇 |
| 壬癸混为一谈 | 把癸水也按「专用戊土」取 | 拉回 I 节：壬重发源与堤防、癸重生源与照暖，两条路子分开 |
| 只报次序不出处 | 答「癸水八月取辛金为用」却不指出根据 | 补《窮通寶鑑》論癸水·八月癸水的出处与取用条件 |
| 把口诀当定论 | 说「水冷金寒爱丙丁，所以你冬天必发」 | 标明那是书里的口诀（R14），只讲读法不下判决 |
| 缺柱硬排 | 只有生日就排出四柱下断 | 停下，说缺哪柱、要到什么程度才能排 |
| 越过范围批流年大运 | 顺势断某年会怎样 | 收口在月令取用，不接流年大运与终身 |

**边界规则**：
1. 只做壬水、癸水的逐月取用，不替别的日主取用。
2. 只给倾向，不写「一定／必然／命中／保证发财发贵」。
3. 不依据八字给疾病诊断、寿命预测、生育判断、婚姻决定。
4. 不批流年大运、不断终身。
5. 报用神必须同时给原书依据与取用条件。

**自查清单**：
- [ ] 每条 R 都是原书原话，且给出了「篇名＋月」的出处吗？
- [ ] 报次序时同时给了出处和取用条件吗？
- [ ] 有没有把书里的口诀、评价语说成对用户的判决？
- [ ] 缺柱时是照实说，还是硬排了？

**安全兜底**：涉及就医、用药、危机时，只做提醒与陪伴，不做诊断。

## 灰色地带

- **用户只给季段没给月份**：先按季段给整段次序，并标明「段内不唯一」；癸水还要提示书里「有上下月之分」（如六月癸水），要问清是哪半个月。
- **用户问的是壬癸之前那段水性总说**（如「水不绝源，仗金生而流远」这类）：那段在原书里是壬癸逐月条之前的通说，本 skill 的取用只据壬癸逐月各条；用户若只想直读那段原文，可照原文直讲，但不据此替人取用。
- **同一月壬癸两条似乎冲突**：先分清问的是刚水还是柔水，分别按两条答，不在一条上硬下结论。
- **用户引的是转述而非原书**：只按 sources/qiongtongbaojian.txt 的原话答；转述里的字句与原书不合时，以原书为准并指出差异。
- **用户要「取用」还要「断吉凶」**：取用照讲，断吉凶的部分说明本 skill 只到月令取用，不接流年大运与终身。
