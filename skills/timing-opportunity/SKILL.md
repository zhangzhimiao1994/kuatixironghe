# 时机选择策略

## 触发条件

- 不确定现在是否是行动的最佳时机。
- 是提前预防还是等问题出现再应对（预防 vs 等待）。
- 问题正在最猛烈时，是否应该立即干预（烈火烹油）。
- 不触发：时机不影响结果的场景、纯方案设计不需要时间维度的场景。

## R：原文锚点

> 上工刺其未生者也, 其次刺其未盛者也, 其次刺其已衰者也。
> 下工刺其方袭者也, 与其形之盛者也, 与其病之与脉相逆者也。
> 无刺熇熇之热, 无刺漉漉之汗, 无刺浑浑之脉。（公版此处缺一字）
> 谨候其时, 病可与期, 失时反候者, 百病不治。
>
> — 灵枢·据公版原文核·逆顺、灵枢·据公版原文核·卫气行

## I：核心解释

时机选择策略是一个"何时干预"优先于"如何干预"的决策框架。

1. **时机优于手段**: "上工治未病"——最高明的干预在问题发生之前。能力高下不看手段复杂程度, 而看干预时机的早晚。

2. **四个时机等级**: 未生(预防) > 未盛(早期) > 已衰(恢复期) > 方袭(高潮期)。越早干预价值越高, 等到高潮期则效果最差。


3. **不可干预窗口**: "无刺熇熇之热, 无刺漉漉之汗"——当问题最猛烈时, 干预反而危险。存在明确的"不可干预"时段, 此时"不做"比"做"更明智。
   🛑 **STOP**：请确认上一步的分析结果后再继续。


4. **时间窗口精确把握**: "刺实者刺其来也, 刺虚者刺其去也"——干预时机精确到"来"和"去"的瞬间。"失时反候者百病不治"——错过窗口等于放弃。

## A1：来源应用

### 案例 1: 军事类比——不攻堂堂之阵
- **问题**: 何时是干预的最佳时机?
- **方法论的使用**: 借用兵法"无迎逢逢之气, 无击堂堂之阵"——不在敌方气势最盛时正面进攻。同理, "无刺熇熇之热"——不在病势最猛时干预。
- **结论**: 干预的最佳时机不是"问题最严重时", 而是"问题即将发生但尚未发生"或"问题已经过峰正在衰退"时。
- **结果**: "方其盛也勿敢毁伤, 刺其已衰, 事必大昌"——等势头衰退再出手, 效果最好。

### 案例 2: 卫气运行时刻表
- **问题**: 干预的精确时机如何确定?
- **方法论的使用**: 卫气运行有固定时刻表——一刻在太阳, 二刻在少阳……干预须在卫气到达目标部位时进行。
- **结论**: 精确的时间窗口可以大幅提升干预效果。
- **结果**: "谨候其时, 病可与期"——按时干预则可预期效果。

## A2：典型触发场景

1. **时机犹豫**: 不确定现在是否是行动的最佳时机。
2. **预防vs等待**: 是提前预防还是等问题出现再应对。
3. **烈火烹油**: 问题正在最猛烈时, 是否应该立即干预。

### 语言信号

- "现在是不是最好的时机"
- "要不要再等等"
- "越早处理越好吗"
- "问题正在最严重的时候, 我该出手吗"

## E：执行步骤

1. **评估当前时机等级**
   - 问题处于哪个阶段: 未生/未盛/已盛/已衰?
   - 完成标准: 明确标注当前阶段和判断依据。
   **输入**：问题所处阶段的信息 → **输出**：当前阶段（未生/未盛/已盛/已衰）及判断依据。

2. **检查是否在"不可干预"窗口**
   - 是否存在"熇熇之热""漉漉之汗"等高危信号?
   - 完成标准: 如果在高危窗口, 输出明确指令"不干预，等待"，并列出何时可以干预的具体信号。
   **输入**：阶段判断与高危信号 → **输出**：是否干预的指令及可干预时机的信号清单。

3. **选择时机策略**
   - 未生→预防性干预; 未盛→早期快速干预; 已盛→等待过峰; 已衰→乘势恢复。
   - 完成标准: 给出明确的时机指令和预期效果。格式: "当前阶段: [未生/未盛/已盛/已衰]。动作: [具体指令]。预期: [效果描述]。"
   **输入**：阶段判断与窗口判断 → **输出**：时机指令（动作＋预期效果）。

🔴 **CHECKPOINT**：给出时机指令前，与用户确认阶段判断与是否处于不可干预窗口，未确认不进入执行。

## B：边界与失败模式

> 本 skill 只提供时机判断的认知视角，**不作医疗判断、不替代就医、不自行尝试针刺**；文中针刺/时机表述仅为隐喻映射；紧急情况（如急救、自伤等）必须立即求助 120 / 110 或急救专业人员，不适用"等待更好时机"。

### 不要在以下情况使用

- **紧急情况**: 有些情况(如心脏骤停)没有"等待更好时机"的选项, 必须立即行动。

### 失败模式

- **永远等待**: "等更好的时机"变成拖延的借口。时机选择框架要求**主动判断**时机, 不是被动等待。
- **教条禁忌**: "不可干预"窗口是相对的, 在现代条件下可能有安全干预手段。

### Fallback（if-then 三段式）

| 触发条件 | 一线修复 | 仍失败 → 兜底 |
|---------|---------|-------------|
| 长时间等待时机仍不成熟 | 等 3 个窗口期过后仍未成熟 → 不是在等时机，是在等条件改变。主动问：「什么条件变了就能行动？」去创造条件而非继续等 | 条件无法创造 → 重新定义可行动范围：「在当前条件下，最小的一步是什么？」 |
| 「不可干预」危险窗口被反复触发 | 分析规律性 vs 偶然性。规律性 → 在下一次进入前提前布局，到了快速通过。偶然性 → 建立预警机制 | 既无规律也无法预警 → 这不是「窗口」，是「常态风险」。不是时机问题，是系统本身的危险特性 |
| 错过了最佳窗口 | 不纠结「如果当时…」。找次佳窗口 + 分析错过原因：是信号识别问题还是决策犹豫问题 | 次佳窗口也已过 → 接受事实：这个轮次已经结束了。从错过中提取教训，为下一个轮次做准备 |
| 周期性窗口和一次性窗口混为一谈 | 区分：周期性窗口（会再来）= 可以等；一次性窗口（错过不再有）= 必须立刻判断做不做 | 分不清 → 先收集信息：这个窗口历史上出现过几次？触发条件是可重复的吗？ |
| 只看时机不看准备度 | 时机 + 准备度 = 成功率。二者缺一不可。问：「时机是到了，但你准备好了吗？人/资源/信息到位了？」 | 准备度严重不足 → 放弃这轮。硬闯比不做的代价更大。标注：下一次窗口前需要补齐 X/Y/Z |
| 等时机变成拖延 | 区分「战略性等待」和「舒适区逃避」。问：「如果明天必须行动，你会做什么？」如果答案很清晰 → 你其实已经准备好了，只是不敢 | 承认拖延 → 设硬性 deadline：「再等最后 X 天，无论如何 X 天后必须行动第一步」 |

## 练习手册

**练习 1 — 判阶段**
拿一件待办的事，判断它处于未生 / 未盛 / 已盛 / 已衰中的哪一阶段，写下判断依据。

**练习 2 — 查危险窗口**
列出"不可干预"的高危信号（相当于"熇熇之热""漉漉之汗"），若命中则明确写下"暂不干预，等待 X 信号出现"。

**练习 3 — 定时机指令与准备度**
按阶段写出"当前阶段 / 动作 / 预期"三句话，并自评准备度（人/资源/信息是否到位）；准备度不足则先补齐。

> 本练习只用于练习时机判断，不作医疗判断、不替代就医、不自行尝试针刺；遇紧急情况立即就医/求助 120 / 110。

## 反例黑名单

| # | 不要做的事 | 为什么 | 正确做法 |
|---|-----------|--------|---------|
| 1 | 无限期等待"最佳时机"——把等待变成拖延 | 时机不会自己变好，等3个窗口期过后仍是"不成熟"→ 不是在等时机，是在等条件改变 | 主动问："什么条件变了就能行动？"然后去创造条件 |
| 2 | 把"不可干预窗口"当成"什么都不做"的借口 | 危险窗口的核心动作是"不做A，但可以做B、C、D" | 先排除危险动作，然后在安全边界内列出所有可做的事 |
| 3 | 错过最佳窗口后沉溺于懊悔，不去找次佳窗口 | "如果当时……"不解决任何问题 | 立即切换到"现在还有哪些窗口？哪个是最不坏的？" |
| 4 | 不区分"周期性窗口"（会再来）和"一次性窗口"（错过不再有） | 对不同类型窗口的态度应完全不同 | 周期性→等下一个循环；一次性→检查是否有替代路径或近似窗口 |
| 5 | 只看时机不看准备度——时机到了但没准备好硬上也翻车 | 时机+准备度=成功率。只满足一个不够 | 每次时机判断必须附带准备度评估：人/资源/信息是否到位？ |

## 灰色地带

- **等待 vs 拖延**：分界看"能否说清在等什么具体条件"；说得出 → 战略等待；说不出 → 拖延，设 deadline。
- **不可干预窗口**：不是"什么都不做"，而是"不做危险动作，只做安全边界内的 B/C/D"。
- **窗口类型**：周期性窗口（会再来）可等；一次性窗口（错过不再有）必须立即判断。
- **时机 vs 准备度**：二者缺一不可；时机到了但准备不足，宁可放弃这轮，硬闯代价更大。
- **紧急例外**：急救、自伤等情形没有"等更好时机"的选项，必须立即求助 120 / 110。
