# 偏正財合論：正财、偏财与两类财的取用

**来源**：sources/sanmingtonghui.txt（《三命通會》卷五·論正財、論偏財、偏正財合論；卷十·㸔命口訣） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

**应该触发**：
- 用户问正财与偏财在书里各怎么立名，为什么一个叫「我之妻」、一个叫「衆人之財」。
- 用户问「財多身弱」与「財少身強」为什么都不作福论。
- 用户读到「財宜藏，藏則豐厚，露則浮蕩」，问什么时候该藏、什么时候露。
- 用户问正财格主什么样的人、偏财格主什么样的人，两段性格断语该怎么读。
- 用户问「偏正二財喜忌大同，唯有喜官星不喜官星小異」这句怎么落到取用上。
- 用户问偏正财合论里列的「生成財」「生合財」「子母財」这些名目是什么意思。
- 用户问「財為養命之源，凡人八字不可無財，但不要太多」该怎么用。
- 用户直接引论正财或论偏财里的句子，要求回书讲清出处。
- **用户给出四柱、问「我这盘财怎么看／身能不能任财」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问某格凭什么条件成立、六格从哪推 → 转 bazi-sanming-ge-ju。
- 用户问财能生煞、财为七煞之根怎么论官煞 → 转 bazi-sanming-guan-sha。
- 用户问印綬怕不怕财、贪财坏印 → 转 bazi-sanming-yin-shou。
- 用户问食神生财、伤官生财怎么用 → 转 bazi-sanming-shi-shang。
- 用户问杂气财官库怎么开、辰戌丑未刑冲才发 → 转 bazi-sanming-ge-ju（库气在总论里）。
- 用户要按某人生日报流年大运、断终身、断贫富寿夭 → 本族不接。
- 用户没提八字词，只说「我今年想理财」 → 泛化词，不激活。

## R：原文锚点

1. 正財者乃甲見巳乙見戊之例受我克制為我之妻（《三命通會》卷五·論正財）
2. 財為養命之源凡人八字不可無財但不要太多多則不清（《三命通會》卷五·論正財）
3. 財宜藏藏則豐厚露則浮蕩（《三命通會》卷五·論正財）
4. 正財之格主人誠實行事儉約賦性聰明惟有慳吝（《三命通會》卷五·論正財）
5. 財多身弱反為富屋貧人（《三命通會》卷五·論正財）
6. 偏財乃甲見戊乙見巳之例非妻所帶乃衆人之財也（《三命通會》卷五·論偏財）
7. 偏財格主人慷慨不甚吝財與人有情而多詐（《三命通會》卷五·論偏財）
8. 偏正二財喜忌大同唯有喜官星不喜官星小異有正財不若有偏財偏財重實其福則厚（《三命通會》卷五·論偏財）
9. 精紀有生成財如甲乙見戊巳土為財申子辰上坐生旺庫（《三命通會》卷五·偏正財合論）
10. 凡財一位務要得時富貴成家（《三命通會》卷十·㸔命口訣）

## I：核心解释

财在书里是「我尅者」一名，书里分成正、偏两样讲，最后又合起来论。这一篇的骨架是：先分名，再论身财强弱，再归到两类财的取用差别。

1. **正财的立名**。「正財者乃甲見巳乙見戊之例，受我克制為我之妻」（R1）。正财是阴阳相配的一路，书里以「妻」相比：财是要我费力才能享用的，所以下面才反复讲身要能任财。
2. **偏财的立名**。「偏財乃甲見戊乙見巳之例，非妻所帶，乃衆人之財也」（R6）。偏财与日主同阴阳，书里说它不是妻带来的，是「众人之财」——这一句是「偏财为什么容易分夺」的来源。
3. **财的总性**。「財為養命之源，凡人八字不可無財，但不要太多，多則不清」（R2）。书里既说不可无，又说不要太多，两头都点到。
4. **身财要相称**。财多身弱，「反為富屋貧人」（R5）——屋大而人小，看得到用不上。反过来财少身强而柱有比劫，书里也说不为福（同篇）。所以这一段的核心不是财多财少，而是「身能不能任」。
5. **藏露两说**。「財宜藏，藏則豐厚，露則浮蕩」（R3）。书里接着说：用财不宜明露，柱见比劫则宜透出，使人共见而不能夺。可见藏露是随有无分夺来定的。
6. **两类财的性格断语**。正财格「主人誠實行事儉約，賦性聰明，惟有慳吝」（R4）；偏财格「主人慷慨，不甚吝財，與人有情而多詐」（R7）。两段是书里对人的评价语，引用时必须标明是书里的说法。
7. **两类财的喜忌差别**。「偏正二財喜忌大同，唯有喜官星不喜官星小異；有正財不若有偏財，偏財重實，其福則厚」（R8）。这是整篇的总结句：两类财在用官星上略有不同，而偏财重实者福厚——仍是书里的评价语。
8. **合论里的几类财**。偏正财合论把财分成「生成財」「生合財」「子母財」「類財煞」等名目，其中「精紀有生成財，如甲乙見戊巳土為財，申子辰上坐生旺庫」（R9）——生旺库俱全为生成财，书里说这类「除貴外須主大富」。这些名目是书里对财位与库位的组合取法，不是断语清单。
9. **入手一句**。㸔命口诀里有一句总纲：「凡財一位務要得時，富貴成家」（R10）——财要得时；这一句与前文身财相称是同一层意思。
10. **一句话读法**：先定财是正是偏（R1、R6），再看身能不能任（R5、R2），再定藏露（R3），最后按两类财的喜忌小异收口（R8）；合论里的诸名目只作财位与库位的组合取法看（R9）。

## A1：来源应用

书上给的做法，都落在「先分正偏、再看身财强弱、再定藏露」这一条线上：

- **分正偏**：正财阴阳相配（R1），偏财同阴阳而称众人之财（R6）。
- **看身能否任财**：财多身弱柱无印助，或财少身强柱有比劫，书里说都不为福（同上篇，见 R5 所属段落）。
- **用财的藏露**：用财不宜明露；柱见比劫则宜透出，使共见不能夺（R3）。
- **两类财的取用**：偏正财喜忌大体相同，差别在喜不喜官星；偏财重实者福厚（R8）。
- **组合名目**：生成财看财位是否坐生旺库（R9）；合论另列生合财、子母财、类财煞、财会煞、名位财、长生财等，都按原书的组合条件看，不扩写。
- **得时**：财一位要以得时为贵（R10）。
- **评价语提醒**：R4、R7、R8 的性格与福厚语，R5 的「富屋貧人」，都是书里的说法，引用标明来源。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月令、财星的干支（正财／偏财在哪一柱、透干还是藏支）、四柱里有无比劫与印。
2. **逐条核书里的条件**：财是正是偏 → R1／R6 的立名；财几位、透还是藏 → R3（宜藏／柱见比劫则宜透出）；身能不能任 → R5「財多身弱反為富屋貧人」＋ R2「不可無財但不要太多」；得不得时 → R10。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「财透而身无印比，按 R5 这一路读，偏『屋大人小』」。
4. **收口**：这一句是**书里的读法**，不是对这个人财力的判断；**不应期、不断终身、不给投资理财置产结论**。

**书里没有的、不要加**：本篇不列「财星旺衰计分」，也不把「财多财少」换算成现代财务判断；不给投资、理财、置产结论。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。

   - **有四柱** → 走**落盘读法**（第 4–5 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **认句归篇**（文本解读）　输入：用户所引句子 → 输出：判定它出在论正财、论偏财、偏正财合论还是㸔命口诀，回对 R 节第几条。
   🔴 **CHECKPOINT**：若用户问的是财生煞、财为煞根那一路，先说明要转 bazi-sanming-guan-sha，不在这里展开。
3. **分正偏、比身财**（文本解读）　输入：书里的名与例 → 输出：按 R1、R6 说清正偏的立名理由，按 R5、R2 说清身财相称这一层的意思。
4. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干、月令、财星在哪一柱、透干还是藏支、有无比劫与印。
5. **逐条核条件、给读法**（落盘）　输入：第 4 步的料 ＋ 本 skill 的条件 → 输出：

   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷五·論正財」）。
6. **收口**　输入：整段推演 → 输出：一句「正财还是偏财」＋一句「身能否任」＋一句「藏还是露」。
   🔴 **CHECKPOINT**：收口前确认——① 没把 R4、R7、R8 的性格断语与 R5 的「富屋貧人」说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不给财务结论**；③ 报的格局／用词带得出卷次或篇名。

## 灰色地带

- **藏与露两条看似相反**：R3 说财宜藏，同篇又说见比劫则宜透出。按原句，藏是因怕浮荡，透是因怕暗夺，两者随柱中有无比劫而定；遇到冲突就说这是原书按分夺条件分两路，不替用户拍板。
- **偏财「福則厚」与「最怕分奪」并存**：R8 说偏财重实福厚，同篇又说偏财最怕分夺。按原句，福厚是在无劫败的前提下说的；用户若问两者怎么并存，照原句给前提，不引申。
- **合论诸名目算不算格**：R9 等名目是财位与库位的组合取法。用户若问「生成財」是不是一个格，按原句说是合论里的一种取法，能对回总论的库气一路就对回去，不另立格。
- **「財多身弱」到什么程度算多**：书里只给「多則不清」与「反為富屋貧人」，没给刻度。用户若追问尺度，照实说书里只到这一步，不给数字。
- **用户拿性格断语问「像我吗」**：不写自我否定腔，也不写兜售腔；标明是书里的评价语，只讲原句条件，判断留给用户。
