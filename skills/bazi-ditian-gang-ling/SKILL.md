# 通神論綱領：天道·地道·人道·知命·理氣·配合

**来源**：sources/ditianxu.txt（《滴天髓闡微》通神論，清任鐵樵注） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**（用户会怎么说话）：
- 用户问「三元」指什么、为什么说它是「万法宗」。
- 用户问「欲识三元万法宗，先观帝载与神功」怎么讲。
- 用户问「坤元合德机缄通，五气偏全定吉凶」是什么意思。
- 用户问「戴天覆地人为贵，顺则吉兮凶则悖」里人为何为贵。
- 用户问「顺逆之机须理会」在说什么、顺与悖怎么分。
- 用户问「理承气行岂有常，进兮退兮宜抑扬」的进退怎么判、旺相休囚是什么。
- 用户问「配合干支仔细详」到底要配合什么、是不是先看用神。

**不应触发**（看起来像但其实不是）：
- 用户问甲木乙木、子午卯酉这些干支本身怎么取象 → 转 bazi-ditian-gan-zhi。
- 用户问两气成象、方局、八格、体用 → 转 bazi-ditian-xing-xiang-fang-ju。
- 用户要排盘、给一组四柱算流年大运吉凶 → 本维度不接流年大运、不断终身；只讲经文立的那层理。
- 用户只说「我运气差」「我身体不好」「我几岁了」这类泛化的话，没有点出八字/四柱/日主/用神等显式请求 → 不激活。

## I：核心解释

这六章是通神論的总纲，讲三件事：一组四柱凭什么分三元、吉凶从哪来、理气怎么进怎么退。

1. **三元是总纲**。经文「欲识三元万法宗，先观帝载与神功」（R1）。任注把三元点上名：「干为天元，支为地元，支中所藏为人元。」（R3）三才统系、万物本原都归到这一步（R2），所以叫「万法宗」。
2. **天道的落法**。原注说天有阴阳，五行「随时显其神功」（R2）——春木夏火秋金冬水季土是同一套气在四时的显用。任注补一层：「阴阳本乎太极，是谓帝载，五行播于四时，是谓神功。」合起来就是先立天地人这套框架。
3. **地道讲偏全**。「坤元合德机缄通，五气偏全定吉凶」（R4）。原注把吉凶落在「赋于人者，有偏全之不一」上：地承天、五行顺以承天，得之偏全不一，吉凶由此分。
4. **人道讲顺悖**。「戴天覆地人为贵，顺则吉兮凶则悖」（R5）。任注把「顺」「悖」讲成两条：天干气弱、地支生之，是「有情而顺」；天干衰弱、地支抑之，是「无情而悖」，故「顺者接续相生，悖者反克为害，故吉凶判然」（R6）。书里举木为例：干是木畏金克，地支有亥子生之、或干有壬癸化之、或支有寅卯通根、或干有丙丁制之，木有生机是顺；反过来支加辰戌丑未申酉党助庚辛之金，木无生理是悖。
5. **知命讲顺逆之机**。「要与人间开聋聩，顺逆之机须理会」（R7）。任注在这一章里骂了一批做法：混看奇格异局、一切神杀、桃花咸池专论女命、金锁铁蛇谬指小儿关煞，以及不论日主衰旺总以财官为喜、伤杀为憎。他把正法收成一句：「子平之法，全在四柱五行。察其衰旺，究其顺悖，审其进退，论其喜忌，是谓理会。」又说书里那四句「用之为财不可劫……」的要点只在一个「用」字——不用的财星尽可劫、不用的官星尽可伤。
6. **理氣讲进退**。「理承气行岂有常，进兮退兮宜抑扬」（R8）。原注拿甲木做例：三月甲木是进之极，进极便是退的机；九月甲木是退之极，退极便是进的机。任注按四季把五行分旺相休囚四条：「将来者进，是谓相；进而当令，是谓旺；功成者退，是谓休；退而无气，是谓囚」，并说日主与喜神宜旺相、凶煞与忌神宜休囚；又说「相妙于旺」「休甚乎囚」——方长之气进得远，方退之气未遽复。他一句总收：「非长生为旺，死绝为衰，必当审明理气之进退，庶得衰旺之真机矣。」（R9）
7. **配合讲用神**。「配合干支仔细详，定人福祸与灾祥」（R10）。任注把这一章定为「辟谬之要领」：配合干支要「正理搜寻详推」，不能丢开四柱干支专从奇格、异局、神杀妄谈。他说「命中至理，只存用神，不拘财、官、印绶、比劫、食伤、枭杀，皆可为用，勿以名之美者为佳，恶者为憎」（R11），审日主衰旺、用神喜忌，当抑则抑、当扶则扶。
8. **一条线穿六章**。天道给框架（三元），地道给偏全，人道给顺悖，知命给「理会」二字，理氣给进退（旺相休囚），配合给用神。六章合起来是一句：先立三元，再察顺悖与进退，最后只用「用神」二字定喜忌，不靠奇格异局神杀。任注另有一句总纲可并读：「命贵中和，偏枯终于有损；理求平正，奇异不足为凭。」（R12）

## A1：来源应用

书上给的读法，都围绕「三元—顺悖—进退—用神」这条线：

- **先立三元**：任一柱先分清天干（天元）、地支（地元）、支中所藏（人元）三层（R3）。这是后面判顺悖的地基。
- **断顺悖**：看天干与地支是接续相生还是反克为害（R6）。原注给的判法是「得于五行之顺与悖」——顺则吉、悖则凶（R5 及原注）。
- **配干支看进退**：任注说五行旺相休囚按四季定——将来者进（相）、进而当令（旺）、功成者退（休）、退而无气（囚）；为日主、为喜神宜旺相不宜休囚，为凶煞、为忌神宜休囚不宜旺相（R8、R9）。
- **落到用神**：审日主衰旺、用神喜忌，当抑则抑、当扶则扶；用神不拘财官印绶比劫食伤枭杀，不以名目美恶定取（R11）。
- **辟谬**：这一部分明确否定「专从奇格、异局、神杀」的取用（R7、R11 的任注），也不认四戊午、四癸亥一类传说命造，任注说这些「究其理皆后人讹传」，遇之「皆作偏枯论」。

**书里没有的、不要加**：这六章只立理与判读口径，不给完整推演步骤表；把旺相休囚折成数字权重、把「顺悖」折成打分，都是书里没有的做法，要加只能标「（补充）」并说明依据，不得冒充古法。

3. **讲机制**　输入：经文与注 → 输出：用白话把这一章的机制讲成一句可带走的话（三元分层／偏全／顺悖／进退／用神）。
4. **给判读口径**　输入：机制 → 输出：按 R 节把「凭什么这么取」讲清（顺悖看相生相克、进退看旺相休囚），每一步都挂回原句。
5. **收口**　输入：整段推演 → 输出：一句总纲（先立三元，再察顺悖进退，只用用神定喜忌，不靠奇格异局神杀）。

## 练习手册

- **三元默写**：合上 R 节，写出「三元」各指什么，各配一句出处。
- **六章串讲**：把天道·地道·人道·知命·理氣·配合六章按顺序各写一句「这一章给的是什么」，串成一段。
- **顺悖配对**：给自己熟悉的一组干支（天干弱、地支强），按 R6 写一份「顺」的走法和一份「悖」的走法，只写方向不下吉凶。
- **进退辨**：拿「相」「旺」「休」「囚」四个字各写一句，说明哪个宜为喜神、哪个宜为忌神。

## 灰色地带

- **用户问「这六章能不能用来算命」**：不写自我否定腔，也不写兜售腔；只把书里立的口径讲清（三元、顺悖、进退、用神），是否据此判断留给用户。
- **用户既要讲纲又要一份四柱断语**：纲照讲，断语部分照实说本维度不批流年大运、不断终身，并说清缺什么信息也不足以落断。
- **「相妙于旺」与「为日主宜旺相」看似打架**：书里两者并存——旺相都属宜，但任注另说相之气方长、旺之退反速，遇冲突就说这是书上并存的两种说法，不替用户拍板。
- **经文只有一句、注却有长段**：经文先摆，注作解释摆；用户若只问经文，不必把整段注全展开，但要标明注的部分。
- **用户把「知命」理解成宿命**：按 R7 回到原意——「顺逆之机须理会」是要人究四柱五行的衰旺顺悖进退喜忌，不是认命。
