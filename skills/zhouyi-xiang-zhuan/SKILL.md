# 象传（大象／小象）读法

**来源**：`sources/zhouyi-jing.txt`（经文所载象传）、`sources/zhouyi-benyi.txt`（朱熹本义）、`sources/zhouyi-zhengyi.txt`（王弼注＋孔颖达疏） ｜ 证据等级：firsthand（原书原话）

> **两种象要分清**：每卦「象曰」之下，**第一句是大象**（释这一卦，如「天行健，君子以自強不息」），**其后各句是小象**（逐爻释，如「潛龍勿用，陽在下也」）。本 skill 以**大象**为主料，小象为辅。小象与大象不是一回事，不可混引。

## 触发条件

**应该触发**（用户会怎么说话）：
- 问「象曰」「大象」「小象」「象传」是什么、怎么用。
- 问「…以…」句式：君子以自强不息、君子以厚德载物、君子以经纶、君子以反身修德、君子以惩忿窒欲、先王以至日闭关、后以财成天地之道。
- 想从一句大象里认出「这一卦给的是一个什么动作」（自强、厚德、经纶、俭德辟难、恐惧修省、思患而豫防）。
- 逐爻问小象（如「潜龙勿用，阳在下也」怎么讲）。
- 拿一件具体的事，要按大象这一类句式落到处境上读。

**不应触发**（看起来像但其实不是）：
- 要算一卦、抽签、排盘、预测结果、断某人吉凶成事 → 照实说本维只做读法与处境归类，不进行占筮。
- 问「彖曰」、卦体／卦德／卦时／卦用 → 那是**彖传**，走 `zhouyi-tuan-zhuan`。
- 纯技术（代码报错）、单一事实查询（天气、价格、时间）→ 直接回答。

## I：核心解释

大象是「取象＋立法」两段：前半用上下二体（或卦之自然之象）给这一卦一个画面，后半用「某以某」给出人在这处境下的一个动作。读大象只在「这个画面 → 这个动作」之间对位，不往外推吉凶。

1. **职能**：本义说「象者，卦之上下兩象及兩象之六爻周公所繫之辭也」（R30）——象传分两截：释上下两象（大象）与释六爻（小象）；本义又说「天行以下先儒謂之大象，潛龍以下先儒謂之小象」（R31），把大小象的界线标明。正义说「此《大象》也。《十翼》之中第三翼，總象一卦，故謂之『大象』」（R32）——大象是总象一卦的那一翼。
2. **大象的两段式**：前半是**象**（天行健／地势坤／云雷／山下出泉／山附于地），后半是**法**（君子以…／先王以…／后以…／上以…／大人以…）。前半是这一卦的画面，后半是人在这画面下可做的动作。
3. **施动者的讲究**：正义说「凡言『君子』，義皆然也」（R33），并指出唯独该卦之义只施于天子者才称「先王」（如复、涣、豫），「兼诸侯」者称「后」（如泰、姤）；其余各卦都称「君子」。**称「君子」还是「先王」「后」，是这一卦动作的层级不同，不是随手写的。**
4. **动作是有限的**：大象只给**一个**动作。谦「裒多益寡，称物平施」、损「惩忿窒欲」、益「见善则迁，有过则改」、震「恐惧修省」——都收在一处可落的手上；它不承诺结果。
5. **小象为辅**：小象逐爻点出这一爻的位、时、应。乾初九「潛龍勿用，陽在下也」（R26）——「阳在下」是**位**；上九「亢龍有悔，盈不可久也」（R28）——「盈不可久」是**理**；夬初九「不勝而往，咎也」（R29）——「咎」是**书里的用语**，不作对某人的事实判决。
6. **两段之间不能错位**：画面（象）与动作（法）是对位的。把「山上有泽」的画面配到「朋友讲习」上、或把「丽泽」配到「反身修德」上，就是错位；报引时须整句连画面一起给。

## A1：来源应用

书里大象给的动作，按处境分几路（每条追得回 R 节）：

- **自处／收拾自己**：乾「自強不息」（R1）、坤「厚德載物」（R2）、损「懲忿窒欲」（R17）、益「見善則遷，有過則改」（R18）、震「恐懼修省」（R23）。这一类的动作落在自己身上，先改的是自己。
- **临事／开局**：屯「經綸」（R3）、蒙「果行育德」（R4）、讼「作事謀始」（R6）、未济「慎辨物居方」（R25）——开局这一类，动作是「先把线理出来／别谋错了开头」。
- **待险／守位**：需「飲食宴樂」（R5）、复「先王以至日閉關」（R12）、蹇「反身修德」（R16）、困「致命遂志」（R20）——前面有险时，动作是「安住、反身、守志」，不是硬冲。
- **聚合／与人**：师「容民畜眾」（R7）、兑「朋友講習」（R24）、咸「虛受人」（R14）、家人「言有物，而行有恒」（R15）。
- **施与／居德**：夬「施祿及下，居德則忌」（R19）、井「勞民勸相」（R21）、泰「財成天地之道，輔相天地之宜，以左右民」（R8）。
- **退避／止**：大过「獨立不懼，遯世无悶」（R13）、随「嚮晦入宴息」（R10）、剥「厚下安宅」（R11）。

**两家对同一处取法有出入时，两说都给、各标出处**：
- 就乾大象「天行健」，**本义**解作「天一而已，但言天行则见其一日一周而明日又一周，若重复之象」——把「健」落成**往复不息**；**正义**（依王弼）则说「天有纯刚，故有健用」「行者，运动之称，健者强壮之名」，并引刘表「详其名也」——把「健」讲成**乾之训**。一个着眼于「运动不休的样态」，一个着眼于「名与训的层次」，**并列呈现，不合成一句。**
- 就爻辞的读法，**本义**逐爻注「其象占如此」（如乾上九「动必有悔，故其象占如此」），读作**象＋占**两截；**正义**（依王弼注）多把爻读作**时位人事**。两家取径不同，不调停。

## E：执行步骤

1. **步骤一（认篇归卦）**　输入：用户的问句与他点到的文本 → 输出：先认清这句是**哪一卦的象**（卦名＋卦次），并判它是**大象**还是**小象**。
   🔴 **CHECKPOINT**：报卦必须给全「卦名＋卦次＋原文」三样，并写一句「为什么是这一卦」的细节对应；对应不上就照实说还缺什么，不硬套。
2. **步骤二（问法一：问「书里怎么讲／出自哪一篇」）**　输入：纯文本追问 → 输出：**文本解读**——先拆大象两段（画面＋动作），认出施动者（君子／先王／后／上／大人）与动作边界，附原文与出处；若问小象，则点出这一爻的位／时／应。此步只做**文本解读**，不落到用户的私事上。
3. **步骤三（问法二：问「我这件具体的事」）**　输入：一件带背景的具体事 → 输出：把事**归到一类处境**，说清凭哪一条象辞这么读，给「按书里这一类读，这一卦给的动作是偏 X」＋**出处**。此步只说「这类处境下书里给的那一个动作」，**不替用户决定、不预测结果**。
4. **步骤四（两家并陈）**　输入：本义与正义（含所据王弼注）对这一处说法有出入时 → 输出：**两说都展示、各标出处、不调停**；有出入就分列，没出入就明说两家同。
5. **步骤五（大小象不混）**　输入：引用某一卦的「象曰」段 → 输出：标清哪句是**大象**、哪句是**小象**；不把爻的小象当卦的大象引，也不把注（王弼）／疏（正义曰）当传文。
6. **步骤六（收口）**　输入：以上读法 → 输出：落一句可打勾的动作或一句可核实的处境判断。**收口不起卦、不占卜、不预测结果、不替人决定**；用户要「算一卦」就照实说本维只做读法与处境归类。

> **两种问法**：问「书里怎么讲」走**步骤二（文本解读）**；问「我这件具体的事」走**步骤三（落处境的读法）**。两者可先后连用，但问法一不替用户谈私事，问法二不脱离出处。
>
> **输出收口**：结论放最前 3–5 行，其后逐步写出认卦→拆两段→认施动者→两家→大小象不混的过程；每一步的依据用用户原话或象辞原句；落到一件今天／这周能打勾的事。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把大象当承诺 | 由「自强不息」推出「所以你照做就一定能成」 | 退回：大象只给那一个动作；吉凶词标明是**书里的用语** |
| 大小象混引 | 把某爻的小象当成这一卦的大象 | 退回步骤五：先分「象曰」下第一句是大象、其余是小象 |
| 画面与动作错位 | 把「山上有泽」的画面配到「朋友讲习」上 | 退回步骤二：整句连画面一起给，对位不对就查原文 |
| 经／注／疏混作一句 | 把正义的「正义曰」疏文当成象传传文引 | 退回步骤五：分清传文、王弼注、孔疏，引用标层 |
| 两家调停成一句 | 把本义与正义的两种读法揉成「两家都认为…」 | 退回步骤四：两说分列、各标出处、不合成一句 |
| 硬套一卦 | 信息不足也报一个卦 | 退回步骤一：说清还缺什么，不硬套 |
| 越界替人决定 | 「所以你该马上加码」 | 退回步骤六：只说这一类处境下书里给的那一个动作，决定权归用户 |

**边界规则**：
1. 只读象辞，不起卦、不占卜、不抽签、不排盘、不算命，不给医疗／法律／投资结论。
2. 报卦必带卦名＋卦次＋原文＋一句细节对应。
3. 凶吉词（吉、凶、咎、无咎等）一律标「书里的用语」。
4. 内部归类名（成员 slug、目录名、「属于某类处境」这类标签）只留内部，不进给用户的回答。

**自查清单**：
- [ ] 报卦三样齐全（卦名＋卦次＋原文）并附细节对应？
- [ ] 分清了这是大象还是小象吗？
- [ ] 大象的画面与动作对位了吗？施动者（君子／先王／后）认对了吗？
- [ ] 本义与正义有出入时，两说都展示了、各标出处、没调停？
- [ ] 收口有没有越界（起卦／占卜／预测／替人决定）？

**安全兜底**：涉及就医／用药／危机时，只做提醒与陪伴，不做诊断。

## 📖 练习手册

1. **拆两段**：任取 R 节五条大象，各写出「画面」与「动作」两截，并标出施动者。
2. **大小象对照**：拿乾卦「象曰」一段，标出哪句是大象、哪几句是小象，各举一例说清区别。
3. **两说对读**：就「天行健」，各写一句本义怎么讲、正义怎么讲，再写「若不调停，该怎么并列」。

## 🚫 反例黑名单（不要做的事）

1. 由大象推「你一定会／必然不会」——象辞只给一个动作。
2. 把某爻的小象当成这一卦的大象引。
3. 把王弼注或孔疏当成象传原文来引。
4. 把本义与正义说成一致或折中成一句。
5. 只丢一个卦名不给卦次与原文，或报卦不说「为什么是这一卦」。
6. 用户要算命时硬接，或反过来说周易是迷信。

## 灰色地带

- **一卦大象与其小象方向不同**（如某卦大象主「进」、某爻小象主「止」）：不硬合成一个方向；先分卦与爻两个层次，再问用户问的是卦还是某一爻。
- **大象句中兼含多个动作**（如泰「财成…辅相…以左右民」）：不拆成几件互不相关的事，按原句的次序读成一个连贯的动作。
- **用户问的是卦辞而非象辞**：先说清这句出在卦辞还是象传；若属卦辞逐字，则本 skill 只做「大象如何释这一卦」，卦辞本身走经文那一支。
- **信息不足以归卦**：只做最宽的判断（自处／临事／待险／与人哪一头），说明还缺哪一点才好归卦，不硬报一卦。
