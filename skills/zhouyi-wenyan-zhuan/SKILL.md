# 文言傳（乾坤两卦）

**来源**：`sources/zhouyi-jing.txt`（經文）、`sources/zhouyi-zhengyi.txt`（王弼注＋孔穎達疏）、`sources/zhouyi-benyi.txt`（朱熹本義） ｜ 证据等级：firsthand（原书原话）

> 本 skill 只做**读法**：认篇、分层、并陈两家注疏。**不起卦、不占卜、不预测结果、不替用户决定**。书里的吉凶词（「元亨利贞」「悔」「咎」）是**书里的用语**，转述时标明来历，不当成对某人的事实判决。

## 触发条件

**应该触发**（用户会怎么说话）：
- 直接问到「文言」「文言曰」「乾文言」「坤文言」，或引「元者善之长也」「亢之为言也」「坤至柔而动也刚」这类句子，想知道它出自哪一篇、在讲什么。
- 想弄清四德（元亨利贞）在文言里怎么被解释，和别处（彖传）有什么不同。
- 想弄清乾卦六爻的爻位说（潜龙、见龙、或跃、飞龙、亢龙）在文言里多出的几层说法。
- 手里有一件具体的事，想知道「按文言这一路读，偏进还是偏退」，要一个带出处的读法。

**不应触发**（看起来像但其实不是）：
- 想让文言替自己下结论、断成败、预测结果 → 本 skill 只给读法，不给判决；照实说明。
- 要「起一卦」「排盘」「算一算」→ 本族不做占筮，只做读法与处境归类。
- 问的是别的卦的文言（文言只有乾坤两卦）→ 照实说文言只系乾坤两卦。
- 问十翼整体、彖传象传释法、繫辭通论 → 走各自的对口 skill。

## I：核心解释

文言是「夫子第七翼」里专门系在**乾、坤两卦**下面的传（R21）。它的位置特殊：**其余六十二卦之理，从这里可以按例推**（R26）。所以读文言不是读两个卦的注脚，而是读一套**范例**——乾坤两卦怎么被读，别的卦照此例推。

1. **四德是一组**：元亨利贞不是四个好字，而是一组**德目**（R1），对应「体仁／嘉会／利物／贞固」四件事（R2）。读法上它先讲「这四个字是什么意思」，再讲「人照着做是什么样」。
2. **六爻是一串时位**：潜、见、乾乾、或跃、飞、亢，是同一条路上的六个位置（R3–R8, R9）。**同一卦里，位置不同，许可的动作就不同**；「亢」是走到尽头还不知退的那一档（R13）。
3. **「知进退存亡」是文言的落点**：R13 把乾的六个位置收成一句——进／退、存／亡、得／丧要同时看见。这是全文言的判断枢纽。
4. **坤的一路是「顺而含」**：坤文言讲的是「顺」（R16「地道无成而代有终」）、「渐」（R14–R15 积善积不善、履霜坚冰），以及把美含在里面（R17）。
5. **两家注疏不是一回事，不合并**（见下）。

### 两说并陈（不调停，各标出处）

- **文言是什么、谁作**：孔疏说「夫子第七翼」，专释二卦经文（R21、R22）；朱子本义说「申彖传象传之意，以尽乾坤二卦之藴，而余卦之说因可例推」——重点在**可例推**，把它当读全部六十四卦的**范例**（R26）。
- **「履霜坚冰至，盖言顺也」的「顺」**：孔疏读作「顺习阴恶之道」，是一条**顺**着积渐下来的链（R24）；朱子本义说「古字顺慎通用，按此当作慎」，读作**慎**，即「当辩之于微」（R29）。同一句，一字之别，两说并存。
- **元亨利贞的性质**：孔疏承王弼，把它讲成天之德、按四时配春夏秋冬（R23）；朱子本义讲「元者生物之始……于人则为仁而众善之长」（R27）。两说取径不同，都摆出来，本 skill 不选边。

## A1：来源应用

书里给的读法（不是本 skill 的发挥）：

- **认篇**：文言只系乾坤两卦；一看到「文言曰」就知道范围，不用到处猜（R26 说明「余卦之说因可例推」，所以乾坤之外的卦没有文言）。
- **分层**：同一句在 `zhouyi-jing.txt` 是经文，在 `zhouyi-zhengyi.txt` 的〈 〉里是王弼注、带`【疏】`的是孔颖达疏，在 `zhouyi-benyi.txt` 的〈 〉里是朱熹本义。**四家对同一句的说法不是一回事**（R1 与 R26–R27）。
- **先读经文再读注疏**：经文给字面（R1–R17），注疏给解释与分歧（R18–R30）。
- **找分歧点**：凡朱子与孔疏取法不同的地方（顺／慎，文言定位），都当成**两个读法**如实摆出，不合成一句。

## E：执行步骤

先判**用户输入里有没有他要问的那件事**，两条路走法不同（判据只有这一条）。

1. **步骤一｜认路（判据：有没有「某件事」）**　输入：用户原话 → 输出：判为「文本解读」还是「落到处境上的读法」。
   - 问「这一句／这一篇书里怎么讲、出自哪一篇」→ 走**文本解读**（第 2 步）。
   - 问「我这件具体的事怎么看」→ 走**落到处境上的读法**（第 3 步）。
   🔴 **CHECKPOINT**：若用户话里既有书、又有事，先按第 3 步读，再把书里的原话补给他。

2. **步骤二｜文本解读**　输入：句子或篇名 → 输出：① 认篇（乾文言／坤文言，引文带篇名与层：经文／注／疏）；② 摆书里的字面与条件（如四德是哪四目、六爻是哪六个位置）；③ 若有分歧，两说并陈（R21–R26 那一组）。
   🔴 **CHECKPOINT**：引文必须逐字、带出处；拿不准就不引，别改写。

3. **步骤三｜落到处境上的读法**　输入：用户那件具体的事 → 输出：① 把事归到文言里的**一类处境**（如「到了一个位置的尽头、还想再往前」对 R13 的「亢」；「一件事在悄悄累积、还没显形」对 R14–R15 的「渐」）；② 说清凭**哪一条**这么读（引哪句、什么层、什么篇）；③ 给一句**「按书里这一类读，偏 X」**（偏进／偏守／偏退）＋**出处**。
   🔴 **CHECKPOINT**：这句「偏 X」只写「按书里这一类读，偏……」的口气，**不写「一定／必然／命中」**，不当成对结果的判决。

4. **步骤四｜收口**　输入：前一步的读法 → 输出：把话收到边界内——**本 skill 不起卦、不占卜、不预测结果、不替用户决定**；最后落一句用户自己能去核实或自己决定的事（如「先想清这件事走到哪一步了」）。
   🔴 **CHECKPOINT**：结尾不出现内部归类名（成员 slug、目录名、「属于 XX 类处境」这类标签）；只谈用户自己讲的那件事、那个人。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把文言当占辞判决 | 写「你抽到/像亢龙，所以必有悔」这类结果断语 | 改成「按书里这一类读，偏 X」，并标出是书里的用语 |
| 起卦／占卜 | 给用户摇一卦、排六爻、算流年 | 照实说明本族只做读法与处境归类，不进行占筮 |
| 把注当经 | 引了一句就说是「文言曰」，实际是孔疏或本义的话 | 回书核：经文在 `zhouyi-jing.txt`，〈 〉是注，`【疏】`是疏 |
| 两家合成一句 | 把「顺」与「慎」调和成「顺慎兼有」 | 拆开，各标出处，两说并存 |
| 替用户拍板 | 「所以你应该……」 | 只给读法与宜进宜守方向，决定权留给用户 |
| 越出乾坤 | 用户问某卦的文言，就替它编一段 | 照实说文言只系乾坤两卦 |

1. 只读文言（乾坤两卦），不扩到别的卦、不扩到十翼其他篇。
2. 吉凶词注明是**书里的用语**。
3. 数据不足以归到哪一条（哪一爻、哪一句）时**照实说缺什么**，不硬套。

## 📖 练习手册

1. **认篇练习**：拿 R 节 5 条，分别写出「这是经文、是谁的注、还是谁的疏」。
2. **分歧找茬**：在 `sources/zhouyi-zhengyi.txt` 与 `sources/zhouyi-benyi.txt` 各找一个讲同一句（如「盖言顺也」）的地方，抄下两家原话，各标出处，不合并。
3. **处境归类**：把自己最近一件「还想再往前推一点」的事，对到六爻的某一位置，写清凭哪一句、偏进还是偏守。

## 🚫 反例黑名单（不要做的事）

1. 不能说「文言说元亨利贞，所以你今年会顺」——这是把德目当结果判词。
2. 不能把孔疏的话当经文引（「文言曰：文言者是夫子第七翼」是错的）。
3. 不能把朱子的「当慎」与孔疏的「顺习」调和成一句。

5. 不能在回答里写「你的判断属于 XX 类处境」或暴露成员 slug／目录名。

## 灰色地带

- **同一句两说都成立**：如「顺／慎」，不判谁对；把两说各自的条件说清，让用户看哪一种更贴他手里的文本。
- **用户只要书、不要读法**：按文本解读走，别硬往他处境上引。
- **用户只要读法、不认书**：先给一次完整读法（归属＋出处），再说明书里的来历；不因为他不看书就省掉出处。
- **偏进偏守说不清**：照实写「按书里这一条读，方向还定不下来」，并说清缺哪一个细节（走到了哪一步、还剩多少余地）。
