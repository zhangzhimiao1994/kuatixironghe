# 疑龙经·下篇：真龙落穴与虚穴

**来源**：`sources/hanlongjing.txt`（唐楊筠松《疑龍經》下篇，四庫本）｜互校：`sources/yilongjing.txt`（《疑龍經》下篇，維基文庫本）｜证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户已经认准一条真龙，问「它到底落穴在哪里」。
- 用户看到主穴贴身之处先有几个小窝小坡，问「为什么会有这些、哪个才是真的」。
- 用户问乳头穴、钳口穴、平坡无左右之穴、水际之穴、直如枪之穴该怎么判。
- 用户说「这里左右抱得挺好，是不是就是正穴」，想知道会不会其实是虚花。
- 用户问「一处龙有三四个形，怎么定哪个是正穴」。
- 用户问裁穴时凭什么定高低、朝山怎么用。
- 用户想拿旧坟做参照，问「旧墳覆」是不是一种验法。

- 用户还停在主干在哪、星峰是不是障眼法这一步 → 转 `kanyu-yilong-shang`（上篇·干上寻龙）。

## I：核心解释

下篇立了一个前提：**真龙快落穴时，先有一层贴身的虚穴，专门惑人**。每条都能追回上面的锚点。

1. **虚穴贴身而来。** 「大抵真龍臨落穴，先為虛穴貼身隨」——真龙接近它的正穴之前，先出现一批贴着真穴的虚穴。所以「識真」之后仍「費心思」，问题不在龙，在穴。

2. **穴形五花八门，不能只认一种。** 「穴有乳頭有鉗口，更有平坡無左右。亦有髙峯下𢃄垂，更有昻頭居隴首」——乳头、钳口、平坡、高峰带垂、昂头居陇首，都是书里见过的穴形。接着又列了平洋四畔无高冈的、临水际无包藏的、如仄掌的、直如枪的、两山合一气的、两水三山同一场的。形态各异，不能拿一套模子套。

3. **只爱左右抱，正是落入虚花的典型。** 「君如識穴不識怪，只愛左右抱者强。此與俗人無以異，多是葬在虛花裏」——只挑左右抱得漂亮的，就与俗人无异，多葬在虚花里。「虛花左右似有情，仔細辨來非正形」——虚花两边像是多情，细看却不是正形。

4. **怪形要认，别一概厌看。** 「怪形異穴人厭看，如何子孫世襲官。只縁怪形君未識，識得裁穴却無難」——人常厌看怪形异穴，可书里把书中的评价语（「子孫世襲官」）系在识得怪形上。要害是：先认怪形，再谈裁穴；认不出就难裁。

5. **裁穴要回到后龙认根。** 「恐君疑穴難取裁，好向後龍身上别。龍上生峯是根荄，前頭結穴是花開。根荄若真穴不假，葢從種類生出來」——龙上生峰是根，前面结穴是花；根真则穴不假。反过来「若不隨星識根種，妄隨虛穴鑿山隈」，跟着虚穴去凿山，就凿错了。

6. **钳、乳要随龙上之星。** 「為鉗為乳為分别。髙低平地穴隨身，豈肯妄下鉗乳穴。穴若不隨龍上星，斷然是假不是真」——钳、乳这类形，必须随龙上的星。穴不随龙上之星，书里说是假的。再验一层是「請君更將舊墳覆」，即拿旧坟覆看（后人的用事）。

7. **龙上星辰预定穴形。** 「我觀星辰在龍上，預定前頭穴形象。為鉗為乳或為坡，或險或夷或如掌。歷觀龍穴無不然，大小隨形無两樣。此是流星定穴法」——前方的穴形，早在龙身的星辰上就定了；大小随形，不两样。所以「大凡識星方識龍，龍神落穴有真踪，真踪入穴有形勢，形勢真時尋穴易，若不識形穴難尋」。

8. **以物象看穴。** 「且如龍形有幾様，近水近山隨物象。如蛇如虎各有穴」——龙形有蛇、虎等物象，各对应其穴（「龍有耳角與腹腸」「虎有鼻唇并眼耳」）。「看他形象宛在中」，形象要看它中心所取之处。

9. **朝山定正穴，中间者为优。** 「最是朝山識正龍。髙低只取朝山定，莫言三穴有仙踪。千里來龍只一穴，正者為優旁者劣」——正穴的高低由朝山定；一龙只一正穴，正者优、旁者劣；「枝上有穴雖有形，不若幹龍為至精」。定上下左右：「左右低時在低處，左右髙時在髙岡」；「穴在南時北上尋，穴在北時南上望」；「只將對將尋真穴，將若真時穴最佳」。

10. **各穴形各有忌。** 「乳頭之穴怕風缺，風若入來人絶滅。必須低下避風吹」；「鉗穴如釵挂壁隈，惟嫌頂上有水來。釵頭不圓多破碎，水傾穴内必生災」；「仰掌要在掌心裏，左右挨排恐非是」；「窩形須要曲如窠，左右不容少偏陂，偏陂不可名窠穴」；「尖鎗之穴要外裹，外裹不牢反生祻」，「只要前山曲抱轉，針着正形官不絶」。

11. **真形必有真案。** 「識得龍真穴始真。真形定是有真案，三百餘形穴穴新」——认了真龙穴才真，而真形必配一个真案山；反过来，假穴往往无真案。「大凡有形必有案」，案山与穴有对应（「譬如至尊坐明堂，列班排牙不撩亂」）；明堂宽阔则气宽大，案山逼迫则人凶顽，案来降我、我去伏案各有读法。

12. **立穴在人心的巧处，但差不离。** 「大凡尋穴非一様，降勢隨形合星象」，书里拿铜人针灸打比方：「穴的宛然方始當」，「忽然針灸失真機，一指隔差連命䘮」——差一指就失机，所以「大凡立穴在人心，心眼分明巧處尋」，正穴要在「重重包褁蓮花瓣」的中心（「正穴却在蓮花心」）。

13. **平洋与山岭各有穴法，不可执一。** 「外縣京國多平洋，也有城邑在高崗。淮甸州縣在水尾，䕫峽山嶺是城隍。隨他地勢看高下，不可執一拘攣他」——平洋、高岗、水尾、山岭各处都有它的城邑与穴形；书里举了冀州壶口落低下、太原落处尖似枪、建康落在坡平地、长安帝垣星外峙等例，结论是「此與窩鉗無以異，只在大小識形難」。判穴不能拿一套模子套所有地势，须随地势看高下。

## A1：来源应用

书上给出的具体做法：

1. **先认虚穴**：真龙临落穴先有贴身虚穴，别把最贴身的小窝当正穴。
2. **回到后龙认根**：龙上生峰是根、前面结穴是花，先核根再定穴。
3. **钳乳随龙上之星**：钳、乳必须随龙上之星；不随星的判假。
4. **以旧坟覆看**：以旧坟的用事作参照验一验（书里给的一层验法）。
5. **看龙上星辰预定穴形**：前方穴形由龙身星辰预定，识星才识龙与穴。
6. **以物象看穴**：蛇、虎各有其穴，看形象居中之点。
7. **朝山定正穴高低**：朝高则穴高、朝低则穴低；一龙只一正穴，正优旁劣。
8. **按形避忌**：乳头怕风缺、钳穴嫌顶上有水、仰掌要在掌心、窝要曲如窠、尖枪要外裹。
9. **真形必有真案**：以案山验真假，假穴无真案。
10. **在莲花心取正穴**：重重包裹之中，正穴在中心。

## E：执行步骤

1. **建穴场底账**　输入：用户描述的落穴区、候选位置 → 输出：事实清单（候选穴形若干、各自左右抱、水的位置、可能的案山、有无旧坟）。缺项标「缺」。
   🔴 **CHECKPOINT**：先点清候选，不判定；缺朝山或案山时先要，不硬判。

2. **辨虚花**　输入：各候选的左右与水情 → 输出：哪些属「左右似有情、細看非正形」的虚花。依据是「虛花左右似有情，仔細辨來非正形」。

3. **回到后龙认根**　输入：穴后龙身的星辰与根荄 → 输出：各候选是否「隨龍上星」，判出「根真则穴不假」的还是「不随星」的假穴。
   🔴 **CHECKPOINT**：凡候选穴「不隨龍上星」者，先判假，不进入下一步定穴。

4. **按形避忌**　输入：每个候选的穴形（乳/钳/平坡/水际/枪等） → 输出：各形的忌处是否犯（乳头风缺、钳顶有水、仰掌离心理、窝有偏陂、尖枪外裹不牢）。犯忌者降级。

5. **以朝山与案山定正穴**　输入：朝山与案山 → 输出：正穴高低倾向，并核「真形必有真案」；假穴无真案的标出来。
   🔴 **CHECKPOINT**：朝山未分清（对面正来 vs 移步欹斜）前，不出正穴高低的结论。

6. **收口**　输入：上五步结果 → 输出：判语卡 `虚实：[真/虚花/假/难断] | 关键依据：[随星/真案/避忌] | 下一步看什么：[具体一物]`；并列「缺什么数据」与「该转哪个 skill」。若还停在主干定位，回上篇；若涉及实地作业，说明本 skill 不做，另议。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把贴身虚穴当正穴 | 认定最贴身的漂亮小窝就是真穴 | 记「先為虛穴貼身隨」，先辨虚花，再回到后龙认根 |
| 只爱左右抱 | 只挑左右抱得漂亮的当穴 | 依「只愛左右抱者强……多是葬在虛花裏」，改看是否随龙上星、有无真案 |

| 无视各形的忌 | 不管乳头怕风缺、钳顶忌水就定穴 | 逐形核忌处，犯忌者降级 |
| 假穴凑真案 | 硬给假穴配一个案山 | 依「真形定是有真案」，假穴无真案即判假 |

## 练习手册

1. **虚花识别**：找一处左右抱得漂亮的小窝，按「仔細辨來非正形」找出它不像正形的具体点。
2. **认根**：给一处穴，回到它后面的龙身，指出哪一处是「根荄」、哪一处是「花開」。
3. **避忌过一遍**：取乳头、钳口、仰掌、窝、尖枪各一例，逐条说出各自的忌处。
4. **真案对假案**：在一处真形与一处疑似的假穴上，各找一次案山，比对「真形有真案」是否成立。

## 反例黑名单

1. 贴身即正穴：把最贴身的漂亮小窝当正穴——下篇说真龙临落穴先有贴身虚穴。
2. 只爱左右抱：左右抱得漂亮就定穴——下篇说这样多葬在虚花里。
3. 不随星当穴：钳乳形好看就定穴——下篇说穴不随龙上星则判假。
4. 无视穴形之忌：不管乳头怕风缺、钳顶忌水就定穴——各形各有忌，须逐条核。
5. 假穴凑案：硬给假穴配案山——下篇说真形定是有真案。
6. 一龙数正穴：把几个形都当正穴——下篇说千里来龙只一穴，正优旁劣。
7. 越界指导实地：直接教怎么下凿、怎么安葬——超出本 skill 范围，且需现场担责。

## 灰色地带

- **怪形与丑形难分**：一处形态既怪又丑，书里说「怪形異穴人厭看」而识得怪形却可裁穴。此时不因丑否决，也不因怪就捧，改看是否随龙上星、有无真案，两说都成立就判「待核」。
- **朝山对面正来又似移步欹斜**：既像正来又像侧偏时，宁按未分清处理，不出正穴高低的结论。
- **旧坟验法的限度**：以旧坟覆看是一层参照，但旧坟后人的境遇另有他家因素；引用时标「旧墳覆是书里的一层参照」，不据旧坟一地就定新穴真伪。
- **无朝山无案山**：两者都缺时，只按形与随星作「倾向」级判语，明说依据不足，不越级定正穴。
