# 三命通會·日時斷（陽干）：六甲·六丙·六戊·六庚·六壬日的時上斷法

**来源**：sources/sanmingtonghui.txt（《三命通會》卷八·日時斷、卷九·日時斷、卷十·㸔命口訣） ｜ 证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户问《三命通會》「日時斷」这一块到底怎么读、怎么用。
- 用户读到「六甲日生甲子時 敗中印綬官生至月通木氣不尋常 反此而言虚名利」这类时上歌诀，问它讲什么。
- 用户问阳干日主——甲、丙、戊、庚、壬——在某个时支上，书上给什么断语与喜忌。
- 用户问「以下所忌月分與時同斷」这一句是什么意思。
- 用户问为什么同一天干落在不同时支上，断语会不一样。
- 用户问卷八与卷九两份日時斷各管哪些日主、怎么分。
- **用户给出四柱、问「我这盘怎么看」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问的是阴干日主（乙丁己辛癸）的时上断法 → 转 bazi-sanming-ri-shi-yin。
- 用户问女命、夫星、子星、八格八法 → 转 bazi-sanming-nu-ming。
- 用户问的是月令格局、十神、官煞去留、财印食伤 → 转本族相应 skill。
- 用户要本 skill 判某人吉凶、批流年大运、断终身 → 本 skill 不接。
- 用户只给一句「我属虎、今年怎么样」，没有四柱 → 先按 bazi-hub 的硬闸门走，缺柱不排。

## R：原文锚点

1. 以上俱以日時為主而以人命年月附之其有官衘不同者此前代命也下同（《三命通會》卷八·六甲日甲子時斷）
2. 以下所忌月分與時同斷（《三命通會》卷八·六甲日甲子時斷）
3. 六甲日生甲子時 敗中印綬官生至月通木氣不尋常 反此而言虚名利（《三命通會》卷八·六甲日甲子時斷）
4. 六丙日生時戊子 財官生旺遇食神月氣相扶為最貴 身衰無倚是常人（《三命通會》卷八·六丙日戊子時斷）
5. 六戊日生時壬子 月通四季墓中財若交身化為真火 水旺運鄉忌目灾（《三命通會》卷八·六戊日壬子時斷）
6. 六庚日生時丙子 身鬼俱衰退神强 有托榮華無托賤 鬼逢生旺壽難長（《三命通會》卷九·六庚日子時斷）
7. 六壬日生時庚子 子上明庚暗損傷 火土月中仍主吉 不通兇狠只平常（《三命通會》卷九·六壬日子時斷）
8. 以上六日年月喜忌當通融活㸔（《三命通會》卷八·六甲日甲子時斷）
9. 是以五陽干晝生為本體夜生作化㸔五陰干夜生為本體晝生作化㸔（《三命通會》卷十·㸔命口訣）

## I：核心解释

「日時斷」是《三命通會》卷八、卷九逐日逐时排出的一套断法：把**日干与時支**配成一小格，先给一首四句歌诀定象，再给一段散文说取用与所忌。阳干日主那几组，甲、丙、戊在卷八，庚、壬在卷九。要读它，先把它的规矩拎出来。

1. **主次之分**：一条总纲把这块的骨架说明白了——「以上俱以日時為主而以人命年月附之」（R1）。也就是：着眼的先落在日与时这两柱，年月退到「附」的位置。
2. **月忌与时忌合并**：日時斷不单看时，还要把月令的宜忌并进来，所以每段前面常有一句「以下所忌月分與時同斷」（R2）——月分所忌，与时上所忌，按同一条办法一起论。
3. **一干一时一格，各有取象**：同一日干，落在不同时支上，取的象就不同。以甲日为例，甲子时看「敗中印綬官生」这一路（R3）；换成庚日子时，主旨转成「身鬼俱衰」与有没有「托」（R6）；壬日子时又是「子上明庚暗損傷」（R7）。所以这一块不能只记一句「甲日如何」，要按时支逐个对。
4. **歌诀加散文，两句并用**：每格先有歌诀（如 R3、R4、R5），后有散文把这些星（官、印、财、食、煞、刃）与月气、倚托、通不通气连起来解释；歌诀给象，散文给条件。
5. **同一干内部的对照**：阳干那几组各有偏向。丙日戊子时重「財官生旺遇食神、月氣相扶」（R4）；戊日壬子时讲「月通四季墓中財」与「水旺運鄉忌目灾」（R5）；庚、壬两组重在「身」与「鬼／刃」的强弱（R6、R7）。
6. **不能死断**：「以上六日年月喜忌當通融活㸔」（R8）——同一格，年月不同，喜忌要通融着看，不是拿一句话套死。
7. **阳干阴干的昼夜化气**：卷十另给一条总法——「是以五陽干晝生為本體夜生作化㸔五陰干夜生為本體晝生作化㸔」（R9）。这是把阳干与阴干在昼生／夜生上分成两套本体的说法，读日時斷里的阳干诸格时会碰到。
8. **一句话读法**：日時斷＝以日干与時支定格，先取歌诀的象，再按散文的条件（月气、倚托、通不通气）分喜忌，月忌与时忌同断，年月通融活看。

## A1：来源应用

书上给的做法，都绕「逐干逐时对号」这件事：

- **先定位**：确认问的是哪一个日干、哪一个时支。阳干日主中，甲、丙、戊三日的格在卷八（卷八按甲乙丙丁戊排），庚、壬二日的格在卷九（卷九按己庚辛壬癸排）。找不到对应条目，就照实说书里没有这一格，不自己补。
- **歌诀取象**：把该格的四句歌诀抄出，逐句解它命名的星与象；例如 R3 的「敗中印綬官生」、R6 的「身鬼俱衰」、R7 的「子上明庚暗損傷」，都是先取象。
- **散文取条件**：同格的散文给条件——「通月氣」「身有倚托」「柱無丙戊」「運行北方」之类；报一条断必须先有歌诀的象，再有散文的条件，两句齐了才算说全。
- **月忌合并**：照 R2，把该格所忌的月分与所忌的时并到一起看。
- **通融活看**：照 R8，年月一变，喜忌要重新掂量，不拿一句话锁死。
- **阳干一体一条总法**：阳干／阴干在昼生夜生上的分法见 R9；涉及化气时按它讲，不另立名目。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干是哪一干（甲丙戊庚壬）、時支是哪一支、属卷八（甲丙戊）还是卷九（庚壬）的哪一格、日时两柱的星、四柱所忌月分。
2. **逐条核书里的条件**：日主是否阳干 → R1「以日時為主而以人命年月附之」定主次；该格歌诀取了什么象 → R3（甲）／R4（丙）／R5（戊）／R6（庚）／R7（壬）；月分所忌是否与时忌同论 → R2；年月喜忌是否要通融 → R8；昼生夜生的本体与化气 → R9。
3. **给读法倾向**：一句「**按书里这一类读，偏 X**」——如「日主为甲、時支子，按 R3 这一路读，偏『敗中印綬官生』的取象」，并给出处（如「《三命通會》卷八·六甲日甲子時斷」）。
4. **收口**：这一句是**书里的读法**，不是对这个人吉凶的判决；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：这一块原书只给「日干＋時支」的歌诀与条件，没有「时上打分」「时柱权重表」这类东西；也不把后世流派的术语塞进来。卷八、卷九里夹着大量前代命例（人名加干支），那些是**书里的举例**，本 skill 只取成规律的歌诀与条件，不逐条搬命例。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–6 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 7–8 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **确认日干与时支**（文本解读）　输入：用户的话与所引句子 → 输出：判定问的是哪一日干、哪一时支，属于阳干还是阴干。
   🔴 **CHECKPOINT**：若日干是乙丁己辛癸，先说明「日時斷·陽干」这一块只管甲丙戊庚壬，阴干各格转 bazi-sanming-ri-shi-yin。
3. **给总纲**（文本解读）　输入：确认在阳干范围 → 输出：用 R1（以日時為主、年月附之）与 R2（所忌月分與時同斷）说明这块的读法。
   🔴 **CHECKPOINT**：不要把「以日時為主」读成「只看日时、年月不管」——原文后面还有「年月附之」。
4. **对号取歌诀**（文本解读）　输入：具体日干加时支 → 输出：抄出对应歌诀（甲引 R3、丙引 R4、戊引 R5、庚引 R6、壬引 R7 之类），逐句解象。
   🔴 **CHECKPOINT**：歌诀要逐字抄，异体字（㸔／㑹／殺／煞 等）照原样，不改写成今字。
5. **补散文条件**（文本解读）　输入：该格散文 → 输出：把「通月氣／身有倚托／所忌月分」等条件说清，让象与条件两句对齐。
6. **标评价语与命例**（文本解读）　输入：条内出现的断语与前代命例 → 输出：把「大貴」「貧夭」这类标成书里的说法；命例只作书里的举例，不当作对具体人的说辞。
   🔴 **CHECKPOINT**：确认没有把书里的断语当成对眼前这个人的判决。
7. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干是哪一干（甲丙戊庚壬）、時支是哪一支、属卷八（甲丙戊）还是卷九（庚壬）的哪一格、日时两柱的星、四柱所忌月分。
8. **逐条核条件、给读法**（落盘）　输入：第 7 步的料 ＋ 本 skill 的条件 → 输出：
   - 日主是否阳干（R1 定主次）→ 该格歌诀取象（R3／R4／R5／R6／R7）→ 月忌与时忌同断（R2）→ 年月通融（R8）→ 昼生夜生的本体与化气（R9）；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷八·六甲日甲子時斷」）。
9. **收口**　输入：整段推演 → 输出：一句取象 + 一句条件 + 一句出处；到取象为止，不判吉凶落到人身上。
   🔴 **CHECKPOINT**：收口前确认——① 没把书里的评价语（如 R6 的「壽難長」）与卷内前列命例说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不替人决定**；③ 报的格局或术语带得出卷次或篇名。用户若给了四柱要「判一下」，照实说本 skill 只在书内取象，不做落人身的判定；缺柱则说要补什么。

**交付口径**：需要呈现成表的内容，走平台原生表格消息，不把 markdown 表格塞正文。

## 灰色地带

- **用户引一句歌诀问「是不是说我」**：歌诀是书里对「日干＋時支」这一格的取象，不是对某人的判决；照实把取象讲清，落人身的判定说明本 skill 不接。
- **同一时支在两处说法不同**：多半是不同日干的两格，先分清日干，再各自照抄，不替它们「折中」。
- **用户要「取象＋判我这一盘」**：取象照讲，判的部分说明不接，并说要补哪些柱。
- **条目里的断语互相打架**：书里逐格所下评语本就各家不一，据实并列，说明是书里各条的说法，不替用户挑一条拍板。
- **卷八、卷九两份文本用字有别**：照抄所引那一份的原样，不在两份之间自行改字。
