# 疑龙经·上篇：干上寻龙

**来源**：`sources/hanlongjing.txt`（唐楊筠松《疑龍經》上篇，四庫本）｜互校：`sources/yilongjing.txt`（《疑龍經》上篇，維基文庫本）｜证据等级：firsthand（原书原话）

## 触发条件

**应该触发**：
- 用户描述一条长山大脉，问「这条脉的主干往哪走」「这几座峰里哪座才是主山」。
- 用户看到一处又高又尖的星峰，问「这是不是就是真龙结穴之处」。
- 用户说手上有舆图或一段山形，两水夹着一条脉，分不清主干与枝条。
- 用户问「为什么书上叫人多在干上找，而不是找那些最显眼的山峰」。
- 用户想先给一处大形势（州县一级）做主干定位，再决定后面往哪看。
- 用户看到一条低平不起眼、却走得很远的长脉，怀疑它是不是主干。

**不应触发**：
- 用户已经锁定一处穴场，要判断是否为虚花、怎么裁穴 → 转 `kanyu-yilong-xia`。
- 用户问某个州县都会落在两水夹里的哪一段 → 转 `kanyu-yilong-zhong`。
- 用户要问起伏剥换、星体变化（贪巨禄文廉武破辅弼）如何一层层换 → 转 `kanyu-bian-xing-pian`。
- 用户要问下葬时杖怎么倒、穴怎么定 → 转 `kanyu-dao-zhang-shi-er-fa`。
- 用户要挑一个日子 → 转 `kanyu-xieji-*` 一系。

## I：核心解释

上篇讲的是一个判断：**追主干，不追显眼的峰**。它每一条都能追回上面五条锚点。

1. **「疑」从哪里来——错把枝当干。** 上篇开头就说，寻龙最难疑处，是「尋得星峰却是枝」：看到一处又高又尖的星峰，往往它只是枝条拱出来的，不是主干本身。所以第一步不是赞峰，而是先问这是干还是枝。

2. **干的第一个特征：长远而连绵。** 「行到中間陽氣聚」承接的是「幹龍長逺去無窮」——干龙走得极远，不在某一节上出彩；它一路「幹上時時斷復斷」，断了又起，枝枝干干反复分合（「分枝劈散亂去，幹中有枝枝復幹」）。因此看干，看的是走势的连续性，不是单点的高低。

3. **干行有顿宿。** 「譬如齎糧適千里，豈無頓宿分内外」——干龙像千里行粮，途中必有歇脚换气的地方。这些顿宿之处也带着随从部曲，是主干长行的关节，不是随手可弃的废段。

4. **干的第二个特征：护从成队。** 干行到关节（关峡）处，两侧有护山随行：「關峽從行并䕶托，矗矗槍旗左右隨」。干自己低平，护山像旗枪一样在两边矗立。这与「正龍身上不生峰，有峰皆是枝葉送」是一件事的两面——干把气势分给两边的枝，自己反而朴素。

5. **旗枪也是星峰，但未必结穴。** 「旗鎗也是星峰作，圓浄尖方髙更卓。就中尋穴穴却無，幹去未休枝早落」——枝龙尽头那杆漂亮的旗枪，本身也是星峰，去那里找穴却常常找不到，因为干还在走、枝却已经断了。这是提醒：看峰要看它归干还是归枝。

6. **枝上也能裁穴，但要分虚花与结胎。** 「枝龍身上亦可裁，半是虛花半是胎」。分法在朝应：「若是虛花無朝應，若是結實䕶送回」——有护送回来的才是结实的。护缠还要数层数：「護纒尚要觀疊數，一疊回來龍身顧」；三重五重抱回来，才谈得上「此就枝龍腰上做」。

7. **干线随水而去，要到「干穷」才收。** 「幹龍尤自隨水去，護送迢迢不囬顧」，所以找穴方向是「的向幹龍窮處覔」——顺着干走到它穷尽处。但穷尽处未必就是结穴：「二水相交穴受風」是书里点名的疑点，风与水交劫之处未必可作穴，到了这里，正是「疑龙」的所在，仍需再核。

8. **干穷处的转机是「回龙」与朝山。** 干穷处要看水交缠的地方：「請君看水交纒處，水外有山來聚㑹，翻身顧母顧祖宗，此是回龍轉身處」。回龙转身，先以朝山的面目出现（「宛轉回龍是掛鈎，未作穴時先作朝」），朝山多是它的宗与祖。这是上篇说的「尋龍大法門」（「两水夾來皆轉揖」）。

9. **州县的正身龙更低平。** 「問君州縣正身龍，大浪横江那有峰。起峰皆是两邊腳，去為小穴為村落」——一座州县的正身，反倒是「正身遶却中央去」的中央那条，两边的峰脚是枝。禄破文廉这些凶星「多作關」，充关门、外拦；「禄存無禄作神壇，破軍不破作近關」。要寻大地，才去寻关局，关局大小看水口山。

10. **入手的次序：先看水，后看峰。** 「尋龍千里逺迢遞，其次五百三百里，先就輿圖看水源，两水夾來皆有氣」。手上没有舆图、没有两水相夹的关系，就还没有判干的底子。水源有长短，「長作軍州短作縣」——格局大小先由水定。枝龙长百里，百里周围作一县；抱龙头的曲岸处「好尋氣無散」。

11. **到了近处，靠朝山定穴的高低。** 「真龍𨼆拙穴難尋，惟有朝山識倖心，朝若髙時髙處，朝若低時低處針」。朝山也分真假：真朝特来入怀，假朝尖圆巧妙却不来、直直去了（「直去名為墜朝山」）。横列的朝要「如魚駢頭蠶比肩」，朝余还能去作水口，与后缠相凑、交牙护断。

12. **明堂要「惜水如惜血」。** 「明堂惜水如惜血，穴裏避風如避賊」；明堂要绕曲内向、抱身横（「明堂遶曲如遶繩，遶在穴前須内向」）。同时要防误认：「時師毎到關峽裏，山水周圍秀且麗」看到四围秀丽就指为明堂，其实可能是「正龍䕶關峽」的泄气之处——「莫將堂局此中看」。

13. **形不真则贵龙之气散。** 「形若真時穴始真，形若不真是虚誑」；外缠不转、内托返的，书里说是「貴龍形氣散」。龙虎背后有衣裾像拜舞袖的（「雖然有袖穴不見」），以及龙下有坪如鳖裙的氊褥之局，都属要分辨的旁证，不能只看袖褥就论贵。

## A1：来源应用

书上给出的具体做法（不是我的发挥）：

1. **先就舆图看水源**：拿到一段区域，先把水找出来；两水夹来才有气可言，水口交牙处才可能藏穴。
2. **关峡处看护托**：干行到关节处，看左右有无枪旗般的护山随行；护从越成队，越像干。
3. **干上不找峰**：正龙身上不生峰，见到峰先归到「枝叶送」里，不要拿星峰的高低当作取贵的依据。
4. **追干到顿宿处**：干行千里必有顿宿，顿宿带部曲，是判断干是否长行的关节。
5. **干穷处找回龙**：顺着干走到穷尽处，看水交缠处水外有没有山来聚会；有，则是回龙转身、挂钩作朝的地界。
6. **朝山定高低**：朝高则穴偏高，朝低则穴偏低；朝山直去不来者，书里叫坠朝山，不取。
7. **横朝看排班**：横列的朝要看成排成列，朝余还能去作水口，与前朝、后缠凑成交牙。
8. **水口交牙**：「水口交牙内局寛，便就寛容平處覔」，书里认这种地方「斷然有穴在此處」，但接着还要看朝水朝山。
9. **明堂分内外**：绕曲内向、抱身横的水是真明堂的样子；关峡四围秀丽而外无拦的，多属护关泄气。

## E：执行步骤

1. **建形势底账**　输入：用户的形势描述、舆图范围或坐标线索 → 输出：一份只含事实的清单（水源与流向、可能的主干走向、疑似的关峡与顿宿位置、已知的朝山与护从层数）。凡用户没给的项，标「缺」。
   🔴 **CHECKPOINT**：把清单摊开，只确认事实，不先下结论；缺水源、缺舆图范围或缺朝山时，先向用户要，不要用想象补齐。

2. **干枝初判**　输入：星峰分布 + 主干走向 + 护从情形 → 输出：干枝判语与依据（对照「正龍身上不生峰」「關峽從行并䕶托」「幹龍長逺去無窮」三条判据，逐条说对上了几条）。

3. **核星峰归干还是归枝**　输入：要判的那处星峰及其左右 → 输出：它是「两边脚」还是主身，并说明「去為小穴為村落」还是仍随干走。

4. **追干到穷处**　输入：主干走向 + 两水相交处 → 输出：干穷处的位置，并标出「二水相交穴受風」这一疑点是否出现。

5. **看回龙与朝山**　输入：干穷处周围的水形与山形 → 输出：是否属回龙转身/挂钩的地界，以及待核的朝山。朝山未定时，明确说「朝山未定，穴之高低无从说起」。
   🔴 **CHECKPOINT**：朝山真假未分清（特来入怀 vs 直去）之前，不输出穴之高低倾向。

6. **明堂与关峡复核**　输入：四围形势 → 输出：是明堂，还是护关泄气之处；依据是水的绕曲内向与否、外有无拦。

7. **收口**　输入：上六步结果 → 输出：判语卡 `干枝：[干/枝/难断] | 关键依据：[三判据对上情形] | 下一步看什么：[具体一物]`；并列「缺什么数据」与「该转哪个 skill」。上篇到此收束，后续若要论枝中干与州县都会，见中篇；要论落穴与虚穴，见下篇。

## 练习手册

1. **干枝对照**：取一段有两水相夹的山脉，先按「显眼山峰」标一遍主干，再按「长远 + 护从」标一遍，写下两次结论差在哪里。
2. **三判据打分**：给一处形势逐条打「正龍身上不生峰 / 關峽從行并䕶托 / 幹龍長逺去無窮」三项，缺项就写「缺」，练不硬判。
3. **朝山真假**：找一处远处尖圆之山，判断它是「特來入懷」还是「直去」，并说明依据。
4. **顿宿练习**：在一段长脉上找一处歇脚换气、带随从的关节，说出它凭什么算顿宿。

## 灰色地带

- **干枝两可**：一段脉既长又有显眼星峰，三判据有的对上有的对不上时，不强行二选一，判「难断」，并把两边的理由都列出，请用户补护从或水口的情形。
- **回龙与坠朝难分**：远处山既有回头之势又似乎直去时，宁可按「疑」处理，标为待核，不先定为朝。
- **只有舆图没有实地**：舆图能看水源与两水相夹的关系，看不清护从层数与朝山性情；此时只出「倾向」级判语，不越级下结论。
- **正身低平又无星换**：「大凡尋龍要尋幹，莫道無星又無換」，遇到无星无换的长脉，不因它平淡就判为无用，须回到水与护从两条再核。
