# 疑龙十问：十个具体疑难怎么读

**来源**：sources/hanlongjing.txt（《疑龍經》附·疑龍十問，四庫本）；互校 sources/yilongjing.txt（維基文庫本） ｜ 证据等级：firsthand（原书原话）/ inference（推断，须标注）

## 触发条件

**应该触发**：
- 用户问祖上抱养、继嗣或僧道承继之家，山川之应算不算数
- 用户问一处坟如何分长房、中房、少房（公位），或几代几座坟的盛衰怎么合看
- 用户拿阳宅与阴宅对比，问同一块地该起屋还是安坟、穴该大还是小
- 用户问主山客山怎么分、某处山形是真是假、哪里是花穴假穴
- 用户问枝龙与干龙的气脉谁接谁、谁先兴谁后衰
- 用户问龙上的星如何博换（剥换）成前头的穴形

**不应触发**：
- 用户只是在问「这条龙旁边的水是什么」→ 归 kanyu-wei-long-pian
- 用户只是拿一处怪石、异形问「这是什么星变的穴」→ 归 kanyu-bian-xing-pian
- 用户要具体点穴、择动土吉日、实地下葬指导 → 不接（见 B）
- 用户拿风水判医疗、法律、投资 → 不接

## I：核心解释

《疑龍經》上中下三篇之后附一篇〈疑龍十問〉，体例是把十个具体疑难各作一问一答。用它的第一件事是**把疑难分到具体的问**——十个问各管一类，不能混着答；分错了问，后面的口径全错。

**十问分工速查**：

| 问次 | 主题 | 它要处理的疑难 | 本书给的口径（书里说法） |
|---|---|---|---|
| 一問 | 抱養及僧道嗣續 | 抱养子、僧道承继之家，山川之应算不算 | 落点在祀事香火明不明；受恩受养如同所生 |
| 二問 | 公位 | 一穴如何分长、中、少三房 | 父母生时无少异，死后何由别荣悴；荣枯当别归于地、归形势 |
| 三問 | 公位盛衰 | 几处坟的盛衰怎么合看 | 气盛气衰有时节；新坟助旧坟；积小成大 |
| 四問 | 陽宅隂宅 | 阳宅与阴宅择穴的根本不同 | 阳宅要穴大宽阔；穴小只宜安坟 |
| 五問 | 陽宅陽地大小 | 居止与葬穴的大小之别 | 居止只要势，水抱山朝必有气；葬穴宜小、居穴大 |
| 六問 | 主客山 | 主山客山怎么分 | 只将水抱便为真；水城反背处为客 |
| 七問 | 形真假 | 一处形势是真是假怎么认 | 假穴无真案，真形案必真；形穴必两三 |
| 八問 | 幹作枝衰 | 枝干气脉谁接谁、谁先谁后 | 大枝分夺全气，小枝不伐自衰羸 |
| 九問 | 穴有花假 | 花穴、假穴怎么认 | 假穴断然生在后；曲是抱里非正穴 |
| 十問 | 博換 | 龙星九变如何剥换 | 由贪入巨入禄文，次第入廉武，破军尽变入辅弼（星变本身另见 kanyu-bian-xing-pian） |

**几条机制（每条都能追回 R 节）**：

1. **问一讲的是「主」，不是血统**。书里说「此山此穴有主者，神靈只向此家住」，又说抱养与亲生「同受生靈無以異」，还拿招魂葬、接花接果、后母前母儿作比。它的落点是祀事香火明不明，不是血统纯不纯。
2. **问二三讲公位与盛衰**。书里先质疑「左长前中右少」和萧梁争公位、河图九宫分位那套说法，说荣枯当归于地、归形势；再讲盛衰有时节，代代长盛靠后来接续得吉多，新坟可助旧坟，所以说「一穴大地䕃十世，小地千墳亦如是」。
3. **问四五讲两宅之别**。阳宅怕穴小，「穴小只宜安墳妙，小穴若為輪奐居，氣脉傷殘俱鑿了」；真要住，则要穴大宽阔、连绵平伏；安葬与居住的取舍正好相反——「葬穴宜小居穴大，葬穴側立居穴寛」。
4. **问六讲主客以水定**。主客两山都端正时不好分，书里的办法是看水抱：「只將水抱便為真，水城反背處為客」。
5. **问七讲真假以案定**。龙有枝干，形穴往往两三并生（蛇形必有雌雄，虎形相配无单只）；分判的关键在案——假穴无真案，真形案必真。
6. **问八讲气脉长短**。干龙多生王侯，枝作干龙也蕃衍；但枝上又生数条枝，小枝龙气脉短，大枝「分奪全氣去」，小枝不伐自衰羸；书里用一瓶数嘴、大树生小枝作比。
7. **问九讲花假**。假穴断然生在后，龙虎虽端而涯必溜；连臂为案横生穴，案外有脚铺茵毡，其间似穴者最易误认；真穴多隐秘，或作钗钳或乳垂。收口一句是「凡是穴郛曲即非，曲是抱裏非正穴」。
8. **问十讲博换**。一星十二节始变，干龙一变少亦九、多至十二重；星按贪、巨、禄、文、廉、武、破、辅、弼的次序剥换，弼星入手必平漫，辅星入首多曲形。这一问与〈變星篇〉同源，见 kanyu-bian-xing-pian。

## A1：来源应用

### 案例 1：继嗣之家先问祀事
- **文本**：「神靈只向此家住」「同受生靈無以異」（《疑龍經》附·疑龍十問）。
- **解读**：书里把承继的落点放在祀事香火，而不是血缘。
- **应用**：遇到抱养、僧道承继之家问「算不算」，先问祀事与承继是否清楚，再谈形势；不要拿血统当唯一尺子。

### 案例 2：分房之争先看新旧真伪
- **文本**：荣枯当归于地、归形势；「新者必為舊者助」（《疑龍經》附·疑龍十問）。
- **解读**：书里认为荣枯归地不归人心爱憎，又说新坟可助旧坟。
- **应用**：几房子孙争分位，先把几处坟的新旧、真伪摆出来，看哪一处是「新者助旧者」，再看合看的结果。

### 案例 3：起屋还是安坟，取舍相反
- **文本**：「穴小只宜安墳妙」「葬穴宜小居穴大」（《疑龍經》附·疑龍十問）。
- **解读**：同一块地，立宅与安葬对穴的大小要求正好相反。
- **应用**：先问用户是要起屋还是安坟，再按相反的方向定穴的取舍。

### 案例 4：主客难分就看水抱
- **文本**：「只將水抱便為真，水城反背處為客」（《疑龍經》附·疑龍十問）。
- **解读**：两山难分主客时，以水抱哪一边为准。
- **应用**：遇到两山相映、形貌相当的场合，先看水抱的方向。

### 案例 5：真假与花穴认案山
- **文本**：「若是假穴無真案，若是真形案必真」「凡是穴郛曲即非」（《疑龍經》附·疑龍十問）。
- **解读**：案山与朝山是辨真假的第一手；穴形曲抱向外者不是正穴。
- **应用**：判断一处是真是假，先落实案山，再看穴形是曲是正。

### 案例 6：气脉长短看枝干
- **文本**：「小枝龍氣脉短」「大枝分奪全氣去，小枝不伐自衰羸」（《疑龍經》附·疑龍十問）。
- **解读**：枝干之间是分气的关系，大枝分走全气，小枝自然见衰；这是本问对「幹作枝衰」的解释。
- **应用**：枝龙上连生几穴而盛衰不齐时，先分清主次与分气的一层，再看各穴自身。

## A2：典型触发场景

1. 家里是抱养、继嗣或僧道承继，回来问祖坟对自家算不算。
2. 同族几房争长中少分位，或几代几座坟的盛衰对不上。
3. 手里一块地，拿不准该起屋还是安坟，或该选大穴还是小穴。
4. 看一处山，两山相映分不出主客，想知道以谁为主。
5. 一处山形似穴而拿不准真假，或看见好几处「像穴」的地方，想知道哪处是真。
6. 一条枝龙上连生几穴，或枝干气脉看着接不上，问谁盛谁衰。
7. 龙上星峰在变，想知道会剥换成什么穴（这类以 kanyu-bian-xing-pian 为主，本 skill 只把问次归位）。
8. 同族里有人说「干龙才发、枝龙无用」，想知道这说法对不对、书里怎么分枝干盛衰。

## E：执行步骤

1. **定问次**　输入：用户原话与处境描述 → 输出：归到第几问（可多问并列）+ 该问在原书的原句锚点。
   🔴 **CHECKPOINT**：把归好的问次与原句摆出来，请用户确认归得对不对，再往下走。
2. **凑数据**　输入：用户给的形势、家世、坟的新旧与房分 → 输出：还缺什么（山形、水口、朝向、周边、房分、坟的新旧真伪、要起屋还是安坟）。
   🔴 **CHECKPOINT**：把缺项列清；缺到不能判就不判，不要用占位信息硬判。
3. **按书口径读**　输入：凑齐的数据 + 对应问的原句 → 输出：按书里这一类的倾向读法；书里的断语（如「此是神仙真法則」「䕃十世」）单独标明是书里的评价语，不作为事实承诺；再给出不确定性。
4. **收口**　输入：上一步的倾向 → 输出：primary 三要素（perspective / insight / action），action 落成一件当下能核对的小事（如「把几处坟的新旧与真伪各记一行」）。
   🛑 **STOP**：给出结果后不自行替用户拍板，不接阴宅实地作业指导。

**交付口径：需要呈现成表的内容，走平台原生的表格消息发**（如飞书用 `send_feishu_table`／`send_feishu_card`），**不把 markdown 表格塞进正文**——这类正文渲染不了表格，会静默丢掉（与 hub「输出纪律」1 同口径）。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把十问混着答 | 拿问一的口径去答问七的真假 | 先回第 1 步定问次，一个疑难只归一到两问 |
| 拿血统当唯一尺 | 见抱养、僧道就说「不算数」 | 回问一，书里讲的是祀事香火明不明 |
| 用占位信息硬判 | 用户只给「我家祖坟好不好」而没有山形 | 回第 2 步列缺项，判不了就说判不了 |
| 把书中断语当承诺 | 说「此地必出公侯」 | 标明那是书里的评价语，改为倾向读法 |
| 越界给作业指导 | 用户要具体点穴、动土方位 | 不接，指回形势与名义的辨认 |
| 与邻 skill 抢题 | 把「龙旁之水」「异穴之形」都收进来 | 前者归 kanyu-wei-long-pian，后者归 kanyu-bian-xing-pian |

**边界规则**：
1. 只做形势与名义的辨认；不做阴宅实地下葬的作业指导。
2. 不给医疗、法律、投资结论。
3. 不替用户拍板。
4. 缺具体形势描述就列缺项，缺到不能判就不判。

**自查清单**：
- [ ] 疑难是否已归到具体的问（一到两问）？
- [ ] 每条断语是否标明是书里的说法，而非事实承诺？
- [ ] 缺项是否列清？有没有用占位信息硬判？
- [ ] 有没有越界去接实地作业或专业结论？

**来源边界**：本 skill 只据《疑龍經》附〈疑龍十問〉一篇，以四庫本（sources/hanlongjing.txt）为准，維基文庫本（sources/yilongjing.txt）仅作互校；不引后世术家说法，不引别族正文。

## 练习手册

- **十问默写**：合上 I 节的表，凭记忆写出十问各自的主题，再对照补漏。
- **一问一归**：拿三个真实疑难，先自己归问次，再回原文找对应原句锚点，检查归得对不对。
- **缺项练习**：取一句模糊提问（如「我家祖坟风水怎么样」），写出要判它还得补哪些形势描述。

## 灰色地带

- **问一在世俗与本书之间的冲突**：世俗多以血统论承继，本书把落点放在祀事香火。两说并存时，先把本书口径与世俗口径分开摆清，不替用户选边。
- **公位之争**：本书质疑「左长前中右少」与九宫分位那套说法。用户若沿用世俗之法，照实说明本书的口径与之不同，不当成对错裁决。
- **十问与〈變星篇〉重叠**：问十（博换）就是星变。以 kanyu-bian-xing-pian 为主，本 skill 只把问次归位并给到原句，不重复推演星变次序。
- **用户只给结论不给形势**：只做最宽的归类（继嗣 / 公位 / 两宅 / 主客 / 真假 / 气脉），不落到具体判读。
