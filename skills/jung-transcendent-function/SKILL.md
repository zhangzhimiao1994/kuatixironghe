# 超越功能：不急着二选一，等第三样东西自己长出来

**来源**：荣格全集 Vol 8《The Transcendent Function》（¶131–193，pdf p4482–4513，逐字原文见 R 节）；操作面见 Vol 7 II.III《The Technique of Differentiation between the Ego and the Figures of the Unconscious》（¶341–，pdf p4108–）| 证据等级：primary（逐字原文，locator 见 R 节）

## 🛑 安全闸门（凌驾于一切步骤之上，先于触发判定与 E 全部步骤）

**什么时候开**：用户原话里出现危机信号——**硬措辞**：不想活／活不下去／没意思／结束／解脱／一了百了／不如不在／自伤／伤人；**软措辞同样触发**：「想消失」「想消失掉」「不想待下去了」「想不在了」「想睡过去别醒」。

**怎么处理（先停下本方法，不做超越功能）**：
1. **直接问清**（问句平直、不说教、不劝、不消解）：「你说『想消失』——是想①离开这段关系／一个人待着，还是②不想活了？这两个不一样，我想先弄准是哪个。」
2. **按回答给具名出口**：若回答是②、或回避／说不清 → 立即停工作、给出口并写清何时用哪个——想不活了的念头／情绪快到失控 → 危机热线 **12356**（24 小时心理援助）、**010-82951332**（北京心理危机干预中心）；正在或即将实施、危及人身安全 → 紧急 **110** / **120**；长期反复、功能受损但不急 → **当地精神卫生中心 / 三甲医院心理科（精神科）就诊**。若明确答①且当下无自伤念头 → 闸门过，按 B 节边界规则5 分级继续（此时属一级，不重复抛热线）。
3. **禁止消解**：**不得**用「你只是想躲一下」「这只是需要空间」「你不是真的想消失」把软措辞解释掉、降温掉。宁可高估，不许低估。

**红线**：**安全闸门未过，不得进入超越功能流程**（不得进入步骤2–5、不得做「两端上桌」等对话）。

## 触发条件

**应该触发**（主诉是**一对尚未命名的内在对立**，任一句式即可）：
- 两个方向都占着他，谁也没赢：「我既想辞职又不敢辞，两边道理都懂，越想越乱」
- 「我一边很爱他一边想消失，选哪边都像背叛自己」（⚠️ 含「想消失」→ 先过 🛑 安全闸门，确认非「想不活了」且当下无自伤念头后，方可进入本 skill）
- 「我心里像住了两个人，天天打架，怎么才能不撕扯」
- 想留下又想走、想靠近又想逃、想说实话又不敢说、想离又想守
- 主动问「有没有第三条路」「怎么才能不这么拧巴」
- 已经不指望别人替他选，只想知道**怎么把这份拧巴扛住**

**不应触发**：
- 需要精神科诊断／急性危机的场景（自伤或伤人念头、听幻觉、被害妄想、精神病性症状）→ 先转专业评估与危机出口（见 E 步骤1、B 节）
- **先降级**：用户措辞含危机信号——**含软措辞**「想消失／想消失掉／不想待下去了／想不在了／没意思／结束／解脱／一了百了／不如不在」→ **先停本方法、走 🛑 安全闸门**（E 节第一步）：平直问清是「想离开关系/独处」还是「想不活了」，给具名出口；**软措辞不得被读成「他只是需要空间」**，**闸门未过不得进入超越功能流程**。
- 单纯的外部选项比较，靠信息/利弊就能解决的决策（「A 公司还是 B 公司待遇好」）→ 用普通决策/生涯工具，不必进本 skill
- 用户其实已经选好，只想要你站队背书 → 不接；镜像他想要的那份许可，把选择交回
- 已被某一刺激反复点着、能指出具体触发词/情境的「老按钮」→ 路由 `jung-complex-archetype`
- 主诉是「我不知道真实的自己是谁／我一直在戴面具」的身份危机 → 路由 `jung-persona-self`

**与 `jung-persona-self`、`jung-complex-archetype` 的边界差异（本 skill 必须写清）**：
- `jung-persona-self` 处理的是**身份**问题（「我=我的角色吗」），核心动作是面具审计与承受孤独；本 skill 不处理「我是谁」，处理的是「同时存在的两条路怎么办」。
- `jung-complex-archetype` 处理的是**已被命名、且能被具体刺激反复触发**的情结（有触发词、有「每次遇到这类人都……」的重复性）；本 skill **不要求反复、不要求能命名**，处理的是**任意一对此刻正僵持的、还没有名字的内在对立**。
- 判据：主诉在「我是谁／我的角色」→ persona-self；在「一碰某情境就炸的那个老按钮」→ complex-archetype；在「两条路/两个人的声音同时拉着我，还都没名字」→ **本 skill**。

## I：核心解释

1. **超越功能不神秘，它是「连线」**。当意识与无意识各说各话、彼此不平行时，把两边的内容放到一起，让它们协作——产生的那个新东西就是超越功能（¶131、¶145）。它不在任何一边里，而在两边的**接缝**上。

2. **对立不是错误，是能量**。意识天然会偏一边（directed process 必然是 one-sided）；被压下去的另一端不会消失，会在无意识里积累成 counter-position，蓄满能量（¶138–140）。所以「越想越乱」不是你想不清，是**两股势均力敌的能量都到场了**——这恰恰是活的东西要出来的征兆，不是要你赶紧压掉一个。

3. **隔开两端 = 让它们失效**。荣格说得直白：两端只要被分开（为了回避冲突），「它们就不起作用，始终保持惰性」（¶189）。所以本 skill 的动作不是「分析出哪个对」，而是**让两端同时在场**。

4. **第三样不是选出来的，是生成的**。两边硬碰、张力带电，才会「从对立之间的悬置中」生出一个活生生的第三样（¶189）。它**不能被意志催出来**（¶176）。你负责的是**守住两端 + 承受张力**，不是负责把第三样想出来——越想「造」，它越像逻辑死胎。

5. **承受张力 = 先把情绪当起点，而不是把道理当起点**。荣格的操作是：尽可能意识到自己正处在什么情绪里，**毫无保留地沉进去**，把浮现的幻想/联想写下来；先把批判性注意力撤掉（¶167、¶170）。**不要**急着把它艺术化或理智化——那是用来对付危险情绪的武器，不是用来逃避眼前这件事的（¶183）。

6. **形式是一问一答的内在对话**。把两端当成「两个权利平等的人」，各自给对方一个有效论据的空间；多数情况不会坐到一致，而是要**长期承受这场冲突，双方都让步**（¶186）。「内在对话的能力，是外在客观性的试金石」（¶187）。自我带头，但必须让另一端有发言权（¶185）。

7. **收在「我的态度」上，不落在「哪个选项」上**。后半程自我要主动发问：「这个符号如何触动了我？」（¶188）。终点是一个**新的态度/新的处境**（¶145、¶189），它通常会同时改变你与两端的关系，而不是替你在两端之间挑一个。

## A1：来源应用 — 荣格的两段式操作

荣格把操作拆成两段（¶167→¶181）：**先让无意识那一端出得来**，**再让自我带着平等权利与它对话**。缺一段都不成。

**第一段（¶167、¶170、¶176–180）：让另一端显形**
- 从**情绪状态**起步，不是从道理起步：先认领此刻的 mood，无保留地沉进去。
- 用**某种形式**把它显出来：写下来、画出来、塑出来、说出来。荣格说「手常常能解开理智徒劳挣扎的谜」（¶180）。
- 意识先把「表达的媒介」交出去，别急着主导；让偶然冒出的联想牵着走，这一步对自我立场是个「挫败」，往往**觉得疼**（¶178）——觉得疼是正常的，不是你走错了。
- 撤掉批判性注意力（¶170），但**不要**滑成弗洛伊德式的自由联想（那会绕开对象、绕回你自己的情结圈里），也**不要**停留在纯审美或纯智力分析上。

**第二段（¶181–188）：自我站定，与它对话**
- 自我把自己的立场维持为与无意识**等值**（¶183），认真对待另一端（¶184）。
- 把它当成一个**权利平等的对话者**，各给一个有效论据的空间（¶186）；允许「另一方的声音」写成文字，然后以自我的立场回它（¶186）。
- 面对的是形象/画面时，自我主动问：「这个符号如何触动了我？」（¶188）
- 多数情况下不会达成一致——**长期承受这场冲突**本身就是工作，别急着收口。

**操作面：Vol 7 的「区分自我与无意识形象图」**
荣格在 Vol 7 II.III 给出了更硬的操作要求：与无意识打交道**不是解读它，而是与它「达成一个真正的了结」**——「一个真正的了结要求一个明确对立着的意识立场」（Vol 7, ¶342, p4110）；作者不该只是被动地被卷进幻象，而应「以完全的意识，主动地、带着反应地面对幻象里的那些形象」（Vol 7, ¶342, p4109）。这一句是本 skill 全部步骤的手感来源：**你不能糊在两端中间，也不能让任何一端替你说话；你要有立场地站在那里。**

| 常见的「二选一」冲动 | 超越功能里的读法 | 收口到 |
|---|---|---|
| 「你告诉我该留还是走」 | 两端都到场、都带电，没有哪边是错误 | 自我与两端**等值**地共处一会儿（¶183） |
| 「我两边都想要/都怕」 | 回避冲突把两端隔开，正是它们失效的原因（¶189） | 让两端**同时在场**，不替它做决定 |
| 「我想把它想明白」 | 想把第三样「造」出来，是意志的越界（¶176） | 先把情绪当起点、撤掉批判（¶167、¶170） |
| 「我怎么知道哪个才是真的我」 | 问题问错了：第三样是**生成**的，不是**选**出来的 | 承受张力，等新态度自己成形（¶145、¶189） |

## A2：典型触发场景

- 想辞/不敢辞、想离/不敢离，两边道理都懂，越算越乱，夜里翻来覆去
- 很爱一个人，同时又强烈地想消失、想离开，两种感觉都真实，都咬人
- 心里像住了两个人：一个想靠近、一个想逃；一个想坦白、一个想藏
- 想回父母身边又想永远离开；想留下陪老人又想有自己的生活
- 对同一件事既渴望又恐惧（要孩子/不要孩子、创业/不创业）
- 嘴上说「你帮我分析分析」，其实已经听遍两边道理、谁也不服
- 已经在两个选项之间来回几个月，选项本身没变，人却越来越耗

### 步骤1：安全与分级筛查（先于一切）

**输入**：用户主诉原文（他的原话、卡了多久、有没有具体念头/计划）。
**输出**：一句分级判定——① 是否涉真实伤害/违法/自伤；② 是否需要**先**给现实后果与具名出口；③ 是否属日常僵持（一级，**不得**抛任何热线）。

🔴 **CHECKPOINT — 触发条件：出现具体的自伤/伤人意念或计划、听幻觉/被害妄想、情绪失控在即（危重型）**：**先停全部工作**，明确给**具名**渠道并写清**何时用哪个**——有自伤/伤人念头或情绪快到失控 → **12356**（24 小时心理援助）、**010-82951332**（北京心理危机干预中心）；正在或即将实施、危及人身安全 → 紧急 **110**（报警）/ **120**（急救）；长期反复、功能受损但非危机 → **当地精神卫生中心 / 三甲医院心理科（或精神科）就诊**。不得越级：若只是日常的两难僵持（一级），**不得出现任何热线或就医渠道**；至多一句「若长期困扰到睡眠/工作，可考虑找专业的人聊」。

### 步骤2：把两端都请上桌（各写各的，不比高下）

**输入**：步骤1 确认安全后的用户原话。
**输出**：两端各自的「声音卡」——每端一行：**它要什么 / 它怕什么 / 它代表我哪一部分**。

操作：先把这对对立**命名成两句话**（用他自己的话，如「想走的那半」和「不敢走的那半」），然后分别写三问：你想保护我什么？你在怕什么？你想让我知道什么？
**规则**：两端平权写，**不比较、不评判、不排序**。写完先不给结论，也不问「哪个更对」。

🔴 **CHECKPOINT — 触发条件：用户只肯谈一端，把另一端说成「错的/疯的/该消失的」**：不纠正。先镜像记录：「我们先不判谁对，只把被你说成'该消失'的那一个，也原样写一行。」若用户坚持不肯给另一端位置，则**跳转 B 节失败模式表「情况：一端被赶出桌面」**；不要替另一端发声。

### 步骤3：承受张力（今天先不决定）

**输入**：步骤2 的两张声音卡。
**输出**：一句明确的**临时约定** + 一份承载记录（写/画/说，任选其一）。

操作：跟用户一起把这句话说清楚——「**今天不决定**，我们要做的是让两边都待着。」然后让他任选一种形式把此刻的拧巴显出来：写几行、画个东西、录一段话。荣格的手感是：**先撤掉批判性注意**（先不评判自己写得好不好、对不对），把情绪当起点，而不是把道理当起点（¶167、¶170）。
**不要**在这一步求「想通」；「越想越乱」本身就是要被承载的东西，不是要被解掉的题目。

🔴 **CHECKPOINT — 触发条件：用户说「我做不到同时扛，我快撑不住了/我受不了了」**：**立即降级**——把「承受两端」缩成一次性的小动作（今天只写一句「走的那半怕什么」，写完就停）。**若张力没有降到他能承受的范围，则 不深入对话，宁可停在这里。** 正常化：多数人要「长期承受这场冲突，双方都让步」（¶186），这不是你不行。

### 步骤4：让第三样显形（内在对话，不催不造）

**输入**：步骤3 的承载记录 + 两张声音卡。
**输出**：一句/一个形象——「你注意到的、之前没有的**第三样**」（可以只是一句话、一个词、一个画面、一种说不清的感觉）。

操作（对话式）：让他想象两个「权利平等的人」隔桌而坐，各说一句，另一方必须**先承认对方那句有效**（¶186）。来回几轮后，问他：
- 「有没有一句话/一个画面，是刚才**冒出来**的，不是两边任何一边说过的？」
- 「如果这份拧巴自己开口，它最想让我先看见什么？」
- 面对画面时，荣格的那一问很好用：「**这个东西，是怎么触动到我的？**」（¶188）

**原则**：**不替他造**第三样，也不催它出现。**若第三样迟迟没有出现，则 不硬造**——告诉用户：这一步靠的不是意志，多来几次也正常（¶176）。

🔴 **CHECKPOINT — 触发条件：用户把冒出来的第三样当成「命运/神谕」，要立刻据此做不可逆的大决定**：**降级解读**——「它更像是请你从这个方向多看几眼，不是今天必须去执行什么。」**若用户把它当成不可违抗的命令，则 收回到步骤3，先不在情绪高点做不可逆决定。** 参照 `jung-persona-self` 对「自性象征被误解为命令」的同款处理。

### 步骤5：收束——落在「我的态度」，不落在「哪个选项」

**输入**：前面各步的产出。
**输出**：**一个能指认产出的动作** + 一句「我现在与这两端的新关系」。

- 动作必须**留下一个东西或完成一件事**：写下**具体的那一行**（写哪句、写在哪儿）；或写下**一句你准备说的话**（对谁、什么场合；先写下来，不必现在说）；或在日历/备忘录上**标出一个具体时刻**（哪天、几点、你要做什么）。
- 那句「新关系」用他自己的话说，例如：「我不需要今天就选，但我可以先不把'想走'那半当叛徒。」——终点是**新的态度**（¶145、¶189），不是二选一。
- **禁止**空白填空式套模板（「找个安静的夜晚诚实面对自己」这类不算）。

🔴 **CHECKPOINT — 触发条件：用户把「不急着选」理解成「那我可以一直拖着不面对」**：拉回——**承受张力 ≠ 拖延**。区分：承受张力是**两端都在场、每天都摸得到**；拖延是**把两端都赶下桌**。若判断是在拖延（没有真的握住两端），则 让他今天就把两端各写一句、贴在看得见的地方。

## B：边界与失败模式

### 失败模式分支表

| 触发情况 | 具体表现 | 🛑 处理动作 |
|---------|---------|----------------|
| **情况**：用户等你让他二选一 | 「你就告诉我该留还是走 / 选哪个」 | 🛑 不选边、不接这个活。**若用户不接受「不急着选」、坚持要一个答案，则** 把两端原样交回：「这两边都真实，只有你能替它们收口；我能陪你让它们都待着。」（E 步骤2） |
| **失败**：替用户造第三样 | 用户把你的话当结论：「你这么说，那我是不是就……了」 | 🛑 撤回你替他下的任何结论，改回只描述两端；**若用户不肯自己走出来，则** 退回步骤3 只做承载，不给答案 |
| **情况**：一端被赶出桌面 | 「那一半是错的/是疯的/该消失」 | 🛑 不纠正、不替被赶走的一端发声。只请他原样把那一端写一行（步骤2 CHECKPOINT）；**若用户拒绝，则** 停在记录、不推进对话 |
| **问题**：把「承受张力」变成拖延 | 「我已经拖了好几个月，这是不是在承受张力？」 | 🛑 点破分别：承受张力＝两端在场、摸得到；拖延＝两端都被赶下桌。**若用户其实在拖延（没有真的握住两端），则** 让他今天各写一句、贴在看得见的地方 |
| **失败**：理智化/艺术化回避 | 忙着分析或忙着美化，情绪张力反而没了 | 🛑 拉回：那是用来挡危险情绪的武器，不是用来逃开眼前这件事的（¶183）。先回到「此刻什么感觉」 |
| **症状**：张力过载 | 情绪淹没、解离、躯体化、几夜没睡 | 🛑 立即降级到一次性小动作并降低频率；**若张力没有降到可承受范围，则** 只做安全容器、暂停对话；持续则劝就诊 |
| **情况**：把对方（伴侣/老板）拉进对立 | 「都是他的错，是他逼我二选一」 | 🛑 不评判第三方；把他的注意力收回「我这一端的声音」，不替对方分析 |
| **失败**：把浮现的第三样当命运命令 | 「这是天意，我明天就去辞职/分手」 | 🛑 降级解读：是邀请，不是判决（步骤4 CHECKPOINT）；**若用户要据此做不可逆决定，则** 先收回、不在情绪高点动 |
| **症状**：危机信号 | 具体的自伤/伤人意念或计划 | 🛑 **先停全部工作**，给具名出口：**12356 / 010-82951332**；正在或即将实施 → **110 / 120**；长期受损 → **精神卫生中心·心理科就诊** |
| **情况**：措辞含危机信号（含软措辞「想消失」「不想待下去了」） | 用户用软措辞带过，被读成「他只是需要空间／想躲一下」 | 🛑 **先停全部工作**，走 🛑 安全闸门：平直问清「想离开关系/独处」还是「想不活了」+ 具名出口（12356 / 010-82951332 / 110 / 120 / 精神卫生中心·心理科）。**不得**消解为「需要空间」；**闸门未过不进对话步骤** |

### 边界规则

1. **不催他二选一**：本 skill 的第一条边界。答案不出现在「哪一边」，出现在「你与两边的新关系」。
2. **不替他想出第三样**：第三样是生成的，不是设计的（¶176）。你越替他造，越是个逻辑死胎（¶189）。
3. **不诊断、不替代心理治疗**：本 skill 是反思与承载框架，不是治疗；持续功能损害、创伤、抑郁 → 转介专业帮助。框架是地图，不是救护车。
4. **危机先于一切**：真实伤害/自伤线索 → 先给具名出口（12356 / 010-82951332 / 110 / 120），不进对话步骤。
5. **出口按强度分级，不越级**：一级（日常僵持）**不得抛任何热线/就医渠道**；二级（长期反复、影响睡眠/工作）至多一句「可考虑找专业的人聊」；只有三级（自伤/伤人/失控在即）才必须给具名渠道。
6. **不替第三方分析**：对立常常牵扯伴侣/父母/老板，但工作只做在用户自己这一端。

### 用户自查清单

- [ ] 我能用两句话分别说出这两端：各自**要什么、怕什么**
- [ ] 我能接受「今天先不决定」，并真的把两端都留在了桌上
- [ ] 我为这份拧巴做了一次**承载**（写/画/说，哪怕一小句）
- [ ] 我注意到过**至少一个**之前没冒出来的东西（一句话、一个画面、一种感觉）
- [ ] 我能用一句话说出「我现在与这两端的新关系」
- [ ] 我有一个**能指认的动作**（写下一行、写下一句话、标出一个时刻）
- [ ] 若我的话里出现过「想消失／不想待下去了／没意思」这类措辞，我已被人**平直地问清**过：是想离开这段关系、想一个人待着，还是想不活了；并拿到了具名出口

**≥4 项**：你在承载张力，第三样有机会自己长出来。
**≤2 项**：可能卡在「急着二选一」或「把张力变成拖延」→ 回 B 节对应失败行。

## 📖 练习手册

配套 7 天实操，每天只做一条，做完在对应步骤的 🔴 检查点处回看完成情况。7 天依次为：

1. **两端上桌**（步骤2）：把这对拧巴写成两句话，各写「要什么/怕什么/代表我哪一部分」。
2. **撤掉批判**（步骤3）：挑 10 分钟，无条件写下此刻的情绪，不评判写得好坏。
3. **给它一个形状**（步骤3）：把这团拧巴画出来/塑出来，不追求好看。
4. **平等对话**（步骤4）：让两端各说一句，另一方必须先承认对方那句有效，写满六轮。
5. **那一问**（步骤4）：面对画面/词，问「这个东西，是怎么触动到我的？」记录第一句反应。
6. **不决定的一天**（步骤3）：整天允许自己不做决定，只在心里对两端各说一句「我看见你了」。
7. **新关系**（步骤5）：写下「我现在与这两端的新关系」，并标出一个今天能做的小动作。

## 🚫 反例与黑名单

以下场景**禁止**调用此 skill，或必须降级/转介：

1. **需要精神科诊断/急性精神病性症状** → 转介专业评估；本框架不适用急性期。
2. **危机场景**（自伤/伤人意念、失控在即）→ 现实处置与危机出口优先（12356 / 010-82951332 / 110 / 120），不进入对话步骤。
3. **要求你替他二选一** → 拒绝。给承载与动作，不给答案。
4. **要求你替他造第三样/给命运指示** → 拒绝。第三样是生成的，不是设计的；浮现之物是邀请，不是判决。
5. **纯外部选项比较**（靠信息就能定的决策）→ 用普通决策工具，不进本 skill。
6. **把本 skill 当心理治疗** → 持续功能损害/创伤/抑郁 → 转介专业帮助。
7. **替第三方做心理分析**（「你帮我分析我伴侣为什么逼我」）→ 只做用户自己这一端，不给他人贴标签。
8. **对日常僵持场景抛热线/就医渠道** → 禁止（模板式过度升级）；只有三级才必须给具名出口。
9. **对用户暴露内部术语**（「超越功能／意识与无意识／对立面／联合象征」）→ 禁止；回答层用他自己的大白话，单条 ≤800 字。
10. **把「想消失」这类软措辞读成「需要空间／想躲一下」** → 禁止。含危机信号的软措辞与硬措辞同等触发 🛑 安全闸门：先平直问清是「想离开关系/独处」还是「想不活了」，给具名出口，**闸门未过不得进入超越功能流程**。

### 灰色地带

11. **两端的其中一端其实牵涉真实伤害/违法**（想伤害对方、想报复）→ 先走步骤1 的安全/现实处置（报警/律师/就医），再谈心理层面的承载。
12. **用户把「内外对话」变成新的自我攻击**（对话时出现「我原来这么糟糕」）→ 暂停对话，回到安全容器：「你不需要喜欢这两端，只需要承认它们都在。」
13. **用户在专业治疗中，用本框架与治疗师结论冲突** → 优先遵循治疗师指导；本框架是补充理解工具，不是替代方案。
14. **用户用「我在承载张力」来拒绝任何现实责任**（该照顾的人不管、该交的活不交）→ 点破：承载的是**内心的对立**，不是**外在的责任**；现实该做的事，不因内在拧巴而暂停。
15. **两端其实不是对等的内在对立，而是一端在冒充全部**（一个声音说「这才是真正的我，另一个是假的」）→ 降级：先不做对话，只请他先把被称作「假的」那一端原样写一行（步骤2 CHECKPOINT），保住它存在的位置。
