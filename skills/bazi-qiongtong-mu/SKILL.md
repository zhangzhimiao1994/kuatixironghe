# 论木：甲木·乙木逐月取用

## R：原文锚点

1. 木性腾上而无所止，气重则欲金任使，有金则有惟高惟敛之德。（《窮通寶鑑》論木）
2. 木赖水生，少则滋润，多则漂流。（《窮通寶鑑》論木）
3. 生木得火而秀，丙丁相同。死木得金而造，庚辛必利。（《窮通寶鑑》論木）
4. 生木见金自伤，死木得火自焚，无风自止，其势乱也。遇水返化其源，其势尽也。（《窮通寶鑑》論木）
5. 木生于春，余寒犹存。喜火温暖，则无盘屈之患。藉水资扶，而有舒畅之美。（《窮通寶鑑》論木）
6. 夏月之木，根干叶燥，盘而且直，屈而能伸。欲得水盛而成滋润之力，诚不可少。切忌火旺而招焚化之忧，故以为凶。（《窮通寶鑑》論木）
7. 秋月之木，气渐凄凉，形渐凋败。（《窮通寶鑑》論木）
8. 冬月之木，盘屈在地，欲土多而培养。恶水盛而忘形。（《窮通寶鑑》論木）
9. 春月之木，渐有生长之象。初春犹有余寒，当以火温暖，则有舒畅之美，水多变剋，有损精神。（《窮通寶鑑》論甲木·三春甲木）
10. 初春尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳，主大富贵。（《窮通寶鑑》論甲木·正月甲木）
11. 正二月甲木，素无取从才从杀从化之理。（《窮通寶鑑》論甲木·正二月甲木）
12. 凡三春甲木，用庚者，土为妻，金为子。用丁者，木为妻，火为子。（《窮通寶鑑》論甲木·三春甲木）
13. 二月甲木，庚金得所，名阳刃驾杀，可云小贵，异途显达，或主武职，但要财资之。（《窮通寶鑑》論甲木·二月甲木）
14. 三月甲木，木气相竭。先取庚金，次用壬水。庚壬两透，一榜堪图。（《窮通寶鑑》論甲木·三月甲木）
15. 三秋甲木，木性枯藁，金土乘旺，先丁后庚，丁庚两全，将甲造为画戟，七月甲堪为戟，非丁火不能造庚，非庚不能造甲，丁庚两透，科甲定然。（《窮通寶鑑》論甲木·三秋甲木）
16. 三春乙木，为芝兰蒿草之物，丙癸不可离也，春乙见丙，卉木向阳，万象回春，须癸滋养根基。（《窮通寶鑑》論乙木·三春乙木）
17. 正月乙木，必须用丙，因天气尤有余寒，非丙不暖，虽有癸水，恐凝寒气，故以丙火为先，癸水次之。（《窮通寶鑑》論乙木·正月乙木）
18. 二月乙木，阳气渐升，木不寒矣，以丙为君，癸为臣，丙癸两透，不透庚金，大富大贵。（《窮通寶鑑》論乙木·二月乙木）
19. 总之夏月之乙木，耑用癸水，丙火酌用，庚辛次之。（《窮通寶鑑》論乙木·三夏乙木）
20. 十月乙木，木不受气，而壬水司令，取丙为用，戊土次之。（《窮通寶鑑》論乙木·十月乙木）

## I：核心解释

1. **木的两条性情与总尺度**：R1 说木「腾上而无所止」——往上长、停不下来；「气重则欲金任使，有金则有惟高惟敛之德」——气太重时就要金来管束，有金，木才有「该高则高、该敛则敛」之德。R2 说木靠水，「少则滋润，多则漂流」——水少干、水多漂。两条合起来：论木先看它气重不重、水多不多，再决定用金还是用水。
2. **生木与死木，取用两套**：R3「生木得火而秀，丙丁相同。死木得金而造，庚辛必利」——活的木得火才秀发，死的木得金才能被造作；R4 是反面：「生木见金自伤，死木得火自焚，无风自止，其势乱也。遇水返化其源，其势尽也。」所以同一个甲木、乙木，先要分活木死木——这是论木取用前的第一步。
3. **四季木的总说法**：春木「余寒犹存」，喜火温暖、藉水资扶（R5）；夏木根干叶燥，欲水盛滋润、切忌火旺（R6）；秋木「气渐凄凉，形渐凋败」（R7）；冬木「盘屈在地」，欲土多培养、恶水盛（R8）。四季各一句总纲，逐月再细。
4. **甲木逐月要点**：三春甲木「渐有生长之象……是以水火二物，要得时相济为美」（R9）。正月甲木「尚有余寒，得丙癸逢，富贵双全。癸藏丙透，名寒木向阳」（R10）——初春先取丙暖、癸润；这里的「富贵双全」「寒木向阳」是书里的评语。R11：正二月「素无取从才从杀从化之理」，两个月都不走从格。R12：三春用庚与用丁，妻子配法不同。R13：二月「庚金得所，名阳刃驾杀」。R14：三月「木气相竭。先取庚金，次用壬水」。R15：三秋「木性枯藁，金土乘旺，先丁后庚，丁庚两全，将甲造为画戟」。
5. **乙木逐月要点**：三春乙木「为芝兰蒿草之物，丙癸不可离也……须癸滋养根基」（R16）——乙木春月要丙癸并见。正月「以丙火为先，癸水次之」（R17）。二月「以丙为君，癸为臣」（R18）。夏月「耑用癸水，丙火酌用，庚辛次之」（R19）。十月「取丙为用，戊土次之」（R20）。
6. **一句话读法**：木喜火暖、赖水润、要土培根，气重时用金收敛；甲木多取庚丁、乙木多取丙癸，且先分活木死木（R3–R4）。

## A1：来源应用

书上给的做法，是按月给「先取某、次用某」：

- **逐月取用要凑两句**：例如三月甲木「先取庚金，次用壬水」（R14）、十月乙木「取丙为用，戊土次之」（R20）。报用神必须同时给出**原书依据**（哪一月、哪一句）与**取用条件**（凭什么这么取）；只报用神名不出处＝不合格（见本族风格卡「判读口径」第 5 条）。
- **活木死木的落点**：原书在「论木」里用干支分了活木（甲寅、乙卯、甲辰、乙巳一类）与死木（甲申、乙酉、甲午、乙未、甲子、甲丑一类）——这里照引，不另立新分类。
- **妻子配法**：书里逐月末常见「用庚者，土妻金子。用丁者，木妻火子」这类配法（见 R12），这是原书给六亲意向的配法；引用时标明是书里的说法，不当作对具体某人的事实陈述。
- **评价语提醒**：逐月里「富贵双全」「大富贵」「科甲定然」「贫夭」「剋子刑妻」「残疾」等，都是书里的评价语，只照原样引并标明，不落到具体的人身上。
- **不接受的做法**：原书只到月令与透藏，不讲现代命理流派的「打分」「喜用神自动判法」；这些一律不加。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主是甲是乙、月支是哪一月、四柱的透藏（丙、癸、庚、丁、壬、戊各在哪一柱、透干还是藏支）、日支与月支的干支合活木还是死木。
2. **逐条核书里的条件**：先分活木死木（R3、R4）→ 对到该干该月的取用句（甲木 R9–R15、乙木 R16–R20）→ 看丙癸／庚丁／壬戊透藏到哪一步 → 见正二月是否「素无取从才从杀从化之理」（R11）。
3. **给读法倾向**：一句「按书里这一类读，偏 X」＋ **出处**（哪一月哪一句，如「《窮通寶鑑》論甲木·三月甲木」）——如「三月甲木木气相竭，按 R14 这一路读，偏先取庚金、次用壬水」。
4. **收口**：这一句是**书里的读法**，不是对这个人的判定；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

## 灰色地带

- **同一月有多种取法**（如五六月甲木、六月先丁后庚）：照原书分月分句给出，不合并成一句「甲木用某神」。
- **用户要一句话用神**：可以给一句，但必须带出处到月，并说明书里是按月变的。
- **用户把「伤官生财」「木火通明」当现代术语**：这些格名原书里就有（如正二月甲木下），照原书用，并给出处。
- **用户要拿月令直接断富贵**：书里有评价语，但只标是书里的说法；本族不批流年大运、不断终身。
- **用户问甲木与乙木能不能一起看**：原书分论甲、乙两节，取用不同，按各自条文给，不混用。
