# 食神與傷官：我生之气的两条路

**来源**：sources/sanmingtonghui.txt（《三命通會》卷五·論食神、論傷官；卷十一·喜忌篇） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／命理／用神／格局这类词时，整行不显示、不激活。

**应该触发**：
- 用户问食神与伤官在书里各怎么立名，为什么一叫「食神」一叫「傷官」。
- 用户问「傷官格務要傷盡方作貴看」是什么意思，伤尽指伤掉什么。
- 用户问「傷官見官，禍患百端」为什么伤官最忌见官。
- 用户读到「傷官用印宜去財，用財宜去印」，问财与印为什么不能两全。
- 用户问「傷官無財可倚，雖巧必貧」该怎么用，是不是说伤官一定要财。
- 用户问食神为什么又叫爵星、夀星，制煞生财的道理在哪。
- 用户问「食神大忌偏印為倒食」为什么食神最怕偏印。
- 用户读「食神重見變為傷官」，问食神多了为什么会变成伤官。
- 用户直接引论食神或论伤官里的句子，要求回书讲清出处。
- **用户给出四柱、问「我这盘食伤怎么看／伤官伤没伤尽」** → 走 E 节的**落盘读法**（判据就是输入里有没有四柱或出生信息）。

**不应触发**：
- 用户问某格凭什么条件成立、六格从哪推 → 转 bazi-sanming-ge-ju。
- 用户问食伤去了官煞、留谁去谁 → 转 bazi-sanming-guan-sha。
- 用户问伤官生财那一路的财怎么取 → 转 bazi-sanming-cai（本 skill 只接食伤本身）。
- 用户问印綬喜忌、倒食之外印的其他事 → 转 bazi-sanming-yin-shou。
- 用户问六神篇里「食神孑立逢梟」「争正官不可無傷」那一套互制 → 转 bazi-sanming-liu-shen。
- 用户要按某人生日报流年大运、断终身、断寿夭 → 本族不接。
- 用户没提八字词，只说「我话太多得罪人」 → 泛化词，不激活。

## I：核心解释

食神与伤官同是「我生者」，只是阴阳顺逆不同：顺数第三位、日干所生且与日主同阴阳者为食神；阴阳相异者为伤官。书里把两样分篇讲，落点都在「我生出去的气是养身还是伤贵」。

1. **伤官的立名**。「傷官者我生彼之謂，乃甲見丁乙見丙之類；甲用辛為官，丁火乗旺盗我之氣，尅制辛金使不輔甲為貴，故名傷官」（R1）。名字本身就是一句断语：它盗日主之气，又克掉官星，所以叫「伤官」。
2. **伤官格的总要求**。「傷官格務要傷盡方作貴看」（R2）。「伤尽」指柱中官星被伤得干净、无一点为患；不是要伤日主自己。书里接着说：月令伤官、四柱无官星才算伤尽；若官星隐隐受伤不尽，岁运再见于己不利（同篇）。
3. **官是伤官的痼疾**。「傷官見官，禍患百端」（R3）。这一条与 R2 是一体两面：伤官怕的不是别的，是官。喜忌篇又从运上说一句「四柱傷官運入官鄉必破」（R12）。
4. **用财与用印的分野**。「傷官用印宜去財，用財宜去印」（R4）。伤官格可以走财、也可以走印，但两样不能同时用：身旺者用财，身弱者用印；用印者须去财方能发福，用财者不论印亦主亨通（同篇）。
5. **无财则虚名**。「傷官無財可倚，雖巧必貧」（R5）。伤官聪明机巧，但本身不聚财，柱中无一点财可倚，据书里说是虚名虚利——这是书里的说法。
6. **食神的立名**。「食神者日干所生順數第三位，乃甲食丙乙食丁之例」（R6）。书里给它两个别名：一名爵星、一名夀星；因为食神能制煞、又能生财，故为福神。
7. **食神贵旺忌衰**。「食神宜食生食旺，不可食衰食絶」（R7）。所以书里说「食神生旺勝似財官」（R8）——食神自身生旺，胜过柱中见财官。
8. **食神的作用链**。食神制伏七煞（使不得克身）、又生起财星（使财不竭），所以书里连称「食神制煞吉非常，財旺妻榮子更强」（R11）。这一条与 R7、R8 是同一层意思。
9. **食神最怕偏印**。「食神大忌偏印為倒食」（R9）。偏印会克掉食神，所以叫倒食，这一题与印綬篇的倒食是同一条，只是站在食神的立场上说。书里又说：食神忌枭也「有不畏者」，某些干支因有合化而不相害（同篇）。
10. **食神多了会变伤官**。「食神重見變為傷官，令人少子」（R10）。食神只宜一位、不宜太多——多了就变性质，书里说其人的结果，这是书里的评价语。
11. **一句话读法**：先认这是食是伤（R1、R6），伤官看官星伤没伤尽（R2、R3、R12）、再看用财还是用印（R4、R5）；食神看自身旺衰（R7、R8）、看它制煞生财的链条（R11）、看有没有偏印来夺（R9），并留意食多变性（R10）。

## A1：来源应用

书上给的做法，是「先认食伤、再分伤官与食神各自的第一病与第一用」：

- **认名**：伤官是日干所生而与日主阴阳相异者（甲见丁、乙见丙之例，R1）；食神是日干所生顺数第三位、与日主同阴阳者（甲食丙、乙食丁之例，R6）。
- **伤官先问官星**：伤官格要伤尽官星才算成（R2）；见官则百端之祸（R3）；运入官乡必破（R12）。
- **伤官次分财印**：用印须去财、用财须去印（R4）；身旺者用财、身弱者用印（同篇）；无财可倚则难聚（R5）。
- **食神先看旺衰**：食神宜生旺，忌衰绝（R7）；食神生旺胜过财官（R8）。
- **食神看作用**：制煞不使克身、生财使不枯竭，故为福神（R11）。
- **食神看偏印**：食神大忌倒食（R9）；但书里也说「忌梟亦有不畏者」，有合化者不相害（同篇）。
- **数量分寸**：食神只宜一位，多则变为伤官（R10）。
- **评价语提醒**：R5 的「雖巧必貧」、R10 的「令人少子」都是书里的说法，引用标明来源。

**落到盘上的读法**（拿到四柱后，按上面这条线走一遍；这是本 skill 的主活，四步）：

1. **取盘上的料**：日主天干、月令、所生之神的干支（是食是伤，看与日主同阴阳还是相异）、在哪一柱、透干还是藏支、四柱里有官无官、有财有印无、有无偏印与食神并见。
2. **逐条核书里的条件**：是食是伤 → R1／R6 的立名；伤官格的官星伤没伤尽 → R2／R3／R12；用财还是用印 → R4／R5；食神自身旺衰 → R7／R8；食神制煞生财的链条 → R11；食神最怕偏印 → R9；食神几位 → R10。
3. **给读法倾向**：一句「按书里这一类读，偏 X」——如「伤官透而柱见官星，按 R2、R3 这一路读，偏『傷官見官』的未伤尽」。
4. **收口**：这一句是**书里的读法**，不是对这个人的判断；**不应期、不断终身、不落寿夭疾病生育、不替人决定**。

**书里没有的、不要加**：本篇不把食神伤官换算成「表达能力、才艺、口才」之类现代归属；也没有「食伤旺衰计分」。这些都不写。

## E：执行步骤

1. **判问法**　输入：用户输入里有没有四柱或出生信息 → 输出：走哪条路。
   - **没有四柱** → 走**文本解读**（第 2–6 步）：讲书里怎么说；末尾补一句「给我四柱就能照书读一遍」。
   - **有四柱** → 走**落盘读法**（第 7–8 步）：按书里的条件逐条核这盘。
   🔴 **CHECKPOINT**：判据只看「输入里有没有四柱或出生信息」；没给就不硬塞落盘，给了而用户只问出处也不硬塞。
2. **认句归篇**（文本解读）　输入：用户所引句子 → 输出：判定它出在卷五论食神还是论伤官、还是喜忌篇，回对 R 节第几条。
   🔴 **CHECKPOINT**：若用户问的是食神去煞留官那一路，先说明要转 bazi-sanming-guan-sha；问倒食本身则转 bazi-sanming-yin-shou（本 skill 只讲食伤立场）。
3. **认食伤**（文本解读）　输入：柱中日主与所生之神 → 输出：按 R1、R6 定这是伤官还是食神，并给出书里的立名理由。
4. **伤官问官**（文本解读）　输入：伤官格的柱情况 → 输出：按 R2、R3 说明官星伤未伤尽、见官之忌；运上按 R12 说，但只讲原书条件，不替人排运。
5. **伤官分财印**（文本解读）　输入：柱中财印去留 → 输出：按 R4 说明用印去财、用财去印，并按身之强弱分立；无财则按 R5 说明书里的说法。
6. **食神看旺衰与作用**（文本解读）　输入：食神格柱情况 → 输出：按 R7、R8 给旺衰口径，按 R11 讲制煞生财；按 R9、R10 讲偏印夺食与食多数变。
7. **取盘上的料**（落盘）　输入：用户四柱 → 输出：日主天干、月令、所生之神是食是伤、在哪一柱、透干还是藏支、有官无官、有财有印无、有无偏印与食神并见。
8. **逐条核条件、给读法**（落盘）　输入：第 7 步的料 ＋ 本 skill 的条件 → 输出：
   - 是食是伤（R1／R6）→ 伤官伤没伤尽（R2、R3、R12）→ 用财还是用印（R4、R5）→ 食神旺衰（R7、R8）与制煞生财（R11）→ 偏印夺食（R9）、食多变性（R10）；
   - 一句「**按书里这一类读，偏 X**」＋ **出处**（如「《三命通會》卷五·論傷官」）。
9. **收口**　输入：整段推演 → 输出：一句「是食还是伤」＋一句「食伤的第一病是什么（伤官病在官、食神病在枭）」；若用户在追问某个具体人，照实说明本 skill 只讲食伤读法，不替人断终身。
   🔴 **CHECKPOINT**：收口前确认——① 没把 R5 的「雖巧必貧」、R10 的「令人少子」说成对某人的事实；② 落盘路径下已声明**不应期、不断终身、不落寿夭疾病生育、不替人决定**；③ 报的格局／用词带得出卷次或篇名。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |

- **立名对表**：合上 R 节，把伤官与食神的立名各写一句，圈出「阴阳相异／顺数第三位」的差别（参 R1、R6）。
- **伤尽一题**：用 R2、R3 写出「伤尽」伤的是谁、伤不尽会怎样，不给书外条件。
- **财印二选**：把 R4 的「用印去财、用财去印」抄一遍，各配一句身旺身弱的条件。
- **食神链条**：按 R6、R11 写出食神为什么被称福神，只写「制煞」「生財」两条。

## 🚫 反例黑名单（不要做的事）

1. 把「傷官格務要傷盡」读成要伤日主。
2. 见伤官格就一律断凶，不看伤尽与用财用印（R2、R4）。
3. 同时取财与印当喜用，违背 R4 的「用一须去一」。
4. 拿口才、才艺这类现代说法解释食神伤官。
5. 见「令人少子」就替某人断生育（R10 是书里的评价语）。
6. 没有月令仍替人断食伤格，或拿占位信息硬排。

## 灰色地带

- **「伤尽」与「伤官用财」并存**：R2 要求伤尽官星，R4 又说伤官可用财、可用印——用财一路并不改变「先要无官」的前提。用户若问两者关系，按原句说明先决条件是官星伤尽，再分财印两路走。
- **食神忌枭也「有不畏者」**：R9 说食神大忌倒食，同篇却又举己亥不畏丁、丙午不畏甲等例，说因合化而不相害。用户若问自己带倒食是否一定不好，按原篇说明须看有没有合制，不下定论。
- **食多变性算不算破格**：R10 说食神重见变为伤官。用户若问这是不是破格，按原句只说性质变了、书里给出其人的结果，不替用户判成不成格。
- **食神「勝似財官」与「宜见财」并用**：R8 说食神生旺胜似财官；论食神篇又说食神宜行财乡。按原句，前者是就食神自身旺衰说，后者是就行运说；遇到冲突就说这是原书两个角度，不替用户拍板。
- **用户拿「雖巧必貧」问自己**：不写自我否定腔，也不写兜售腔；标明是书里的评价语，只讲原句条件（无财可倚），判断留给用户。
