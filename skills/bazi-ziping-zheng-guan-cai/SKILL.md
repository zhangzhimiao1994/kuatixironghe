# 正官與財（子平真詮·篇 31–34）

**来源**：sources/zipingzhenquan.txt（《子平真詮》三十一、论正官／三十二、论正官取运／三十三、论财／三十四、论财取运） ｜ 证据等级：firsthand（原书原话）

## 触发条件

本 skill 属 bazi-* 一族的子技能，跟着 bazi-hub 的硬闸门走：用户没有显式提到八字／四柱／日主／命理／用神／格局／十神这类词时，整行不显示、不激活。

**应该触发**：
- 用户问《子平真詮》「论正官」这一篇讲什么，或问为什么正官明明克身，却要「分所当尊」。
- 用户读到「忌刑冲破害，则以生之护之为喜矣」，问正官喜什么忌什么。
- 用户问「以财印并透者论之，两不相碍，其贵也大」这句怎么读，财与印为什么能并透。
- 用户问「遇伤在于佩印，混煞贵乎取清」各指哪一路，遇伤与混煞各怎么处。
- 用户问「论财」里「财喜根深，不宜太露」与「财旺生官，露亦不忌」是不是矛盾。
- 用户问财格有哪些贵局（财旺生官、财用食生、财格佩印、财用伤官、财带七煞、财用煞印），各凭什么条件成立。
- 用户直接引篇 31–34 里的句子来问出处，或问正官取运、财取运的大略之法。
- 用户问一个盘的正官／财这两路「按书里这一类」偏在哪。

**不应触发**：
- 用户问用神是月令还是别的、格局成败救应、用神纯杂高低 → 转 bazi-ziping-yong-shen-zong-gang。
- 用户问相神紧要、杂气取用、墓库刑冲 → 转 bazi-ziping-xiang-shen-za-qi。
- 用户问四吉神能破格、四凶神能成格、生克先后 → 转 bazi-ziping-ji-xiong-shen。
- 用户问偏官七煞与伤官怎么用 → 转 bazi-ziping-pian-guan-shang-guan。
- 用户问阳刃、建禄月劫、杂格 → 转 bazi-ziping-yang-ren-za-ge。
- 用户问《三命通會》官煞去留或偏正财分论 → 转 bazi-sanming-guan-sha 或 bazi-sanming-cai（本 skill 只把两家摆开，不替它们调和）。
- 用户要按某人生日报流年大运、断终身、断寿夭疾病生育 → 本族不接。
- 用户没提八字词，只说「我最近财运不好」 → 泛化词，不激活。

## R：原文锚点

**引文说明**：下面每条逐字抄自 sources/zipingzhenquan.txt 篇 31–34。书中「大贵」「贫贱」之类俱属书里的评价语，只作书里的说法录下，不作对具体之人的事实判决。凡涉《三命通會》那一路的说法，只在 I／A／B／灰色地带以出处标出，不进本 R 节。

## I：核心解释

篇 31–34 是《子平真詮》「十神分论」的头一段：正官一路、财一路，各分「论本神」与「论取运」两篇。它讲的是**这两路在月令取用里怎么立、怎么护、怎么成格**，不是给某个人下判词。每一条都能追回上面的原句。

1. **正官为什么要「尊」**。篇首先问一个怪问题：官以克身，与七煞一样都制我，为什么独独正官「切忌刑冲破害」、要这样尊它（R1）？书里的答案是义理上的——正官者「分所当尊」，如国有君、家有亲，刑冲破害是「以下犯上」（R2）。所以本篇的落脚点不是吉凶断语，而是**「忌什么、喜什么」的取用条件**。
2. **正官的喜忌一句话**。「以刑冲破害为忌，则以生之护之为喜矣。存其喜而去其忌则贵」（R3）。忌的是刑冲与破害，喜的是「生之护之」——生官者财，护官者印，去忌存喜便是书里说的成格。
3. **财印并透的贵局**。书里把「生之护之」落到财印两神上：「以财印并透者论之，两不相碍，其贵也大」（R4）。关键在「不相碍」——财与印若各安其位、互不相克，是并透；若财印交战，就落到下一条。
4. **财印不能两用时怎么分**。「若财印不以两用，则单用印不若单用财，以印能护官，亦能泄官，而财生官也」（R5）。书里给了取舍的道理：印护官也泄官，财只管生官，所以单凑不成一双时，取财胜于取印。
5. **遇伤与混煞的两路处理**。「然而遇伤在于佩印，混煞贵乎取清」（R6）：官格被伤官来伤，用印去制伤护官；官与煞混杂，则取清——合煞留官，把混杂理成一路。这里书里用的词是**「取清」**，不是另立一套「去留」口诀。
6. **取运的总原则**。「取运之道，一八字则有一八字这论，其理甚精，其法甚活，只可大略言之。变化在人，不可泥也」（R7）。这是篇 32 的开宗语：正官取运（以及后面的财取运）都只是**大略之法**，不可以拿一句话去套每一个盘。③ 输出时据此只能给「大略偏在哪」，不给硬排。
7. **财的价值在生官**。「财为我克，使用之物也，以能生官，所以为美」（R8）。财是什么？书里先按类收口——财帛、妻妾、才能、驿马都算财类（见 R8 所在全句）；再点出财「所以为美」的真因是能生官。
8. **财的根与露**。「财喜根深，不宜太露，然透一位以清用，格所最喜，不为之露」（R9）。这是本篇最要紧的一句分寸：怕的是「太露」（露得多、露得杂），不怕「透一位以清用」——一位透出反而是格所最喜，不算露。下文「然财旺生官，露亦不忌」（R10），更是把「生官」当作露也不忌的理由。
9. **财格的诸贵局**。书里列了财旺生官、财用食生、财格佩印、财用食生兼印、财用伤官、财带七煞、财用煞印等路，各给条件（R11 是财旺生官一条：「身强而不透伤官，不混七煞」；R12 是财用食生一条：「身强而不露官，略带一位比劫，益觉有情」）。这些是**并列的几条路**，不是一张高低排名榜。
10. **月令暗官一层**。「至于壬生午月，癸生巳月，单透财而亦贵，又月令有暗官也」（R13）。书里承认有月令里藏着官、单透财也成立的情形——取用要看月令可不可取，不是只看透出的那一位。

**两说并陈（不调停）**：《三命通會》也有正官、财的分论，取法与本书不同，两家摆开、各标出处、不选边——
- **正官**：《三命通會》卷五·論正官立的是「正官止許一位，多則不宜」，并把官煞并见专门析成一个「官煞去㽞／混杂」题（卷五·官煞去㽞並官鬼互變雜論，如「官煞兩停喜者存之憎者去之」）。《子平真詮》篇 31 则把官煞并见收在「混煞贵乎取清」（R6）、篇 32 说「正官而带煞，伤食反为不碍」——**一个立「去留」的名目，一个讲「取清」的取法**，此处两家不同，不并成一句。
- **财**：《三命通會》卷五·論正財说「財宜藏，藏則豐厚，露則浮蕩」，把财的贵贱收在藏与露、多与少上（又「財多身弱反為富屋貧人」）。《子平真詮》篇 33 说「透一位以清用，格所最喜，不为之露」（R9）、「财旺生官，露亦不忌」（R10）——**一个重「藏」，一个把「透一位清用」也认作格所最喜**，两家对藏露取法不同，不互相调和。

## A1：来源应用

书里给的做法，都落在「先认这两路怎么立，再逐条核条件」这一条线上：

- **正官先看忌与喜**：忌刑冲破害、喜生之护之（R3）；生官者为财、护官者为印。
- **财印并透看「相不相碍」**：两不相碍则并透为贵（R4）；不能两用时按「单用印不若单用财」取（R5）。
- **遇伤佩印、混煞取清**（R6）：官格逢伤以印制伤护官，官煞混杂以合煞留官取清。
- **财先看根与露**：喜根深；怕的是「太露」（多而杂），不怕「透一位以清用」（R9）；财旺生官时露亦不忌（R10）。
- **财格诸局逐条核条件**：财旺生官要「身强而不透伤官，不混七煞」（R11）；财用食生要「身强而不露官，略带一位比劫」（R12）；其余诸局按篇 33 各句核。
- **取运只作大略**：按 R7 的口径，正官取运、财取运都只是「大略言之」，具体到某个盘仍要「随时取用，不可言形」。
- **不越篇**：本篇只讲正官与财两路的立格与取运大略；用神总纲、相神、吉凶神、偏官伤官、阳刃杂格都落到本人族对应的 skill 去讲。

**书里没有的、不要加**：本篇不讲排盘起例，也没有「旺衰计分」「自动取喜用」「格局打分」这类后世做法；拿现代命理流派的评分法来解释「财印并透」「遇伤佩印」是硬伤，一律不写。

## A2：典型触发场景

1. 用户读到「官以克身……何以切忌刑冲破害」，问正官既然克我，书里为什么反过来要尊它、护它。
2. 用户问「财印并透」到底怎么算并透，两不相碍是什么意思。
3. 用户问「遇伤在于佩印，混煞贵乎取清」，遇伤与混煞各是什么情形、各用什么去处理。
4. 用户看到「财喜根深，不宜太露」和「露亦不忌」两句挨着，觉得打架，想弄清各自的边界。
5. 用户问财格到底算哪一路：财旺生官、财用食生、财格佩印、财用伤官……各凭什么条件。
6. 用户直接引篇 31–34 的句子问出处与上下文。
7. 用户拿着自己的四柱，问正官／财这两路「按书里这一类读」偏在哪。

## E：执行步骤

1. **判问法**　输入：用户的话 → 输出：判据是**输入里有没有四柱或出生信息**。
   - 没有四柱，问「书里这句什么意思／这一篇专门讲什么」→ 走**文本解读**（认句归篇、摆条件），不必落盘；结尾补一句「给我四柱就能照书读一遍」。
   - 给了四柱，问「我这盘怎么看」→ 走**落盘读法**（下面四步）。
   - 给了四柱但用户**只问出处**，也按文本解读答，不硬塞落盘。
   🔴 **CHECKPOINT**：若用户只是给生日求排盘、或问的是别篇（用神总纲／偏官等），先说明该走哪个 skill，不在这里硬答。
2. **落盘①：输入**　输入：用户的四柱（或已排好的盘）＋ 本 skill 的条件（正官一路、财一路） → 输出：把要核的对象摆出来——月令取何神、正官或财透在哪柱、有无财印、有无伤煞。
   🔴 **CHECKPOINT**：缺年、月、日、时任一柱或缺出生地（真太阳时用），照实说缺什么、要到什么程度才能排，**不许用占位信息硬排**；出生时刻只到时段时，时柱按该时段整体给出并标明「时段内不唯一」。
3. **落盘②：逐条核条件**　输入：第 2 步摆出的对象 → 输出：按书写明的取用条件**逐项核**，核的是——**几位／透还是藏／有破无破／月令可不可取**：
   - 正官：有无刑冲破害（R3）；财印是否并透、相不相碍（R4、R5）；遇伤有无印佩、混煞是否取清（R6）。
   - 财：根深不深（R9）；是「太露」还是「透一位以清用」（R9），是否财旺生官（R10、R11）；属篇 33 哪一路贵局（R11、R12、R13）。
   逐条写明这盘满足到哪一步、卡在哪一条。
   🔴 **CHECKPOINT**：核的是**书里写明的条件**，不许拿「旺衰计分」「自动取喜用」这类后世做法替代。
4. **落盘③：输出读法**　输入：第 3 步的逐条结果 → 输出：一句「**按书里这一类读，偏 X**」＋**出处**（《子平真詮》篇名，如三十一·论正官／三十三·论财）；只报格名不出处不合格。
   🔴 **CHECKPOINT**：措辞一律「倾向／按书里这一类读」，书里的「大贵」「贫贱」等评价语要标明是**书里的说法**。
5. **落盘④：收口**　输入：整段推演 → 输出：一句这一路在说什么 ＋ 一句按书里往哪看 ＋ 一件用户今天能查证或能改的读法动作。**收口必须落全四条**：① **不应期**（不说哪年发生）；② **不断终身**（不给一生一句定）；③ **不落寿夭疾病生育**（书里如有这类条文只作书里的说法引，不落到具体的人身上）；④ **不替用户决定**（婚姻／职业／医疗不拍板）。
   🔴 **CHECKPOINT**：收口前确认没滑到流年大运、寿夭、婚姻上去；若用户追问，照实说明本 skill 只讲这两路的立格与取运大略。

**交付口径**：逐步把推演展示出来，结论速览放最前但不得代替推演；一步之中的依据尽量引用户的问法或所给的四柱，不引的就不激活该步。需要成表的内容走平台原生的表格消息，不把 markdown 表格塞进正文。

## B：边界与失败模式

| 失败模式 | 长什么样 | 怎么退回去 |
|---|---|---|
| 把正官讲成吉神断语 | 一看正官就说「这命贵」 | 拉回 R1–R3：本篇讲的是忌什么喜什么，不是给断语 |
| 财印并透与财印交战不分 | 见财见印就说并透为贵 | 按 R4：贵在「两不相碍」；交战就落到 R5 的取舍 |
| 把「取清」说成「去留」 | 拿三命通會的去留口诀来讲本篇 | 本篇用词是「取清」（R6），两家摆开不混用 |
