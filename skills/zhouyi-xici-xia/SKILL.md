# 繫辭下傳

**来源**：`sources/zhouyi-jing.txt`（經文）、`sources/zhouyi-zhengyi.txt`（王弼／韓康伯注＋孔穎達疏）、`sources/zhouyi-benyi.txt`（朱熹本義） ｜ 证据等级：firsthand（原书原话）

> 本 skill 只做**读法**：认篇、分层、并陈两家注疏。**不起卦、不占卜、不预测结果、不替用户决定**。爻位与吉凶之动是**书里对卦爻结构的讲法**，转述时标明来历，不当成对某人的事实判决。

## 触发条件

**应该触发**（用户会怎么说话）：
- 直接问到「繫辞下」「系辞下」「作易者其有忧患」「天地设位圣人成能」「二与四同功而异位」「其辞危」这类句子，想知道它出自哪里、在讲什么。
- 想弄清「爻位与吉凶之动」这一路：二多誉、四多惧、三多凶、五多功是在说什么。
- 想弄清「吉凶以情迁」「爱恶相攻而吉凶生」这套通论怎么讲人事。
- 手里有一件具体的事，想知道「按繫辞下这一路读，偏守还是偏动、偏处险还是偏避患」，要一个带出处的读法。

**不应触发**（看起来像但其实不是）：
- 想让我「按爻位起一卦」「算出结果」→ 本族不做占筮。
- 想让一篇文章替自己预测结果、下结论 → 只给读法。
- 问的是上经下经卦爻辞、彖传、象传、说卦 → 走各自的对口 skill。
- 问的是「天尊地卑」「大衍之数」那一路 → 那是繫辞上传。

## I：核心解释

繫辞下是繫辞的**下半通论**：从「八卦成列」讲到作易的来历与爻位之理，重点不在某一卦，而在「易这部书为什么这么写、爻位为什么这么动」。

1. **作易者其有忧患**：这是下篇的枢纽（R4）。孔疏说「明所以作易，为其忧患故，作易既有忧患，须脩德以避患」（R20）；朱子说「夏商之未，易道中微，文王拘于羑里而系彖辞，易道复兴」（R29）。**读易的出发点是忧患，不是炫技**。
2. **天地设位，圣人成能**：天地摆好位子，圣人在其中成其能（R5）；注说「圣人乘天地之正，万物各成其能」（R18），本义说「天地设位而圣人作易以成其功」（R31）。
3. **吉凶生于动**：「吉凶悔吝者，生乎动者也」（R2）；「爱恶相攻而吉凶生，远近相取而悔吝生，情伪相感而利害生」（R7）。孔疏解为「由有所贪爱，有所憎恶，两相攻击」（R24）。
4. **爻位是一张同功异位表**：二与四同功而异位，二多誉、四多惧（近）；三与五同功而异位，三多凶、五多功（贵贱之等）（R8、R9）。孔疏说「凡阴柔为道，当须亲附于人，以得济」（R25）、「三居下卦之极故多凶，五居中处尊故多功」（R26）。
5. **其辞危、要无咎**：易兴于殷末周初，所以「其辞危」；但落点是「惧以终始，其要无咎」（R13）。**看见危险、始终有戒惧，收处是「无咎」**。
6. **不可为典要**：易「变动不居……唯变所适」（R10）。读法上它反对把爻位当成死表格。

### 两说并陈（不调停，各标出处）

- **制器是取象还是取名**：孔疏记韩康伯「直取卦名，因以制器」，并说「韩氏乃取名不取象，于义未善矣」，同时又承认「今既遵韩氏之学，且依此释之」（R28）；朱子本义则从象说，如「盖取诸离」下解「两目相承而物丽焉」（R35）。一家指出毛病仍依从，一家直取象，两说并处。
- **「其出入以度外内使知惧」一句**：朱子本义照实说「此句未详疑有脱误」（R32）；孔疏则给出完整解读（见《周易正義》繫辭下·疏该句下）。一家存疑，一家立说，两存。
- **「作易者其有忧患」的时与事**：孔疏系于「中古」「文王及周公」（R20、R21）；朱子说「文王拘于羑里而系彖辞，易道复兴」（R29）。两家都指文王，但**取径不同**（一家从爻卦之辞起于中古说，一家从彖辞系于羑里说）。

## A1：来源应用

书里给的读法（不是本 skill 的发挥）：

- **认篇**：繫辞下从「八卦成列」到「其辞屈」，是通论下半；看到「作易者其有忧患」「天地设位」「其辞危」就知道在繫辞下。
- **分层**：经文在 `zhouyi-jing.txt`；`zhouyi-zhengyi.txt` 的〈 〉是王弼／韩康伯注，带`【疏】`的是孔颖达疏；`zhouyi-benyi.txt` 的〈 〉是朱熹本义。
- **爻位表照抄**：二四、三五的同功异位是书里的**结构讲法**（R8、R9），用来读卦爻，不用来算某人。
- **找分歧、各自存疑**：凡两家取法不同或一家存疑的地方（制器取象／取名、「其出入以度」），都作为**两个读法**如实摆出（R28、R32、R35）。

## 灰色地带

- **同一句两家都存疑或都立说**：如「其出入以度」，不判谁对；把「存疑」与「立说」各自标明。
- **用户只要书、不要读法**：按文本解读走，不硬往处境上引。
- **用户只想被安慰、不想读书**：先给一次完整读法（归属＋出处），再谈这一路的落点（多半是「惧以终始，其要无咎」）；不做诊断、不给保证。
- **偏守偏动说不清**：照实写「按书里这一条读，方向还定不下来」，并说清缺哪一个细节（离关键位置多近、还剩多少余地）。
