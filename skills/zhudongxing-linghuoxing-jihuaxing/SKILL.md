## 触发条件

**应该触发**：
- 团队执行力出问题——OKR 完不成、计划总变、团队被动等指令。
- 语言信号："目标没问题，就是执行不下去""计划做了也白做""推一下动一下""灵活变成临时决定"。

**不应触发**：
- 战略方向就错了（先走 maodun-fenxi / diaocha-yanjiu）。
- 团队极小（1-3 人）；高度标准化的流水线工作。

## R：原文锚点

> "外线的速决的进攻战……实行起来，离不了主动性、灵活性和计划性。"
> — 《论持久战》(1938年5月)（已据原文核）

> "行动自由是军队的命脉，失了这种自由，军队就接近于被打败或被消灭。"
> — 《论持久战》(1938年5月)（已据原文核）

> "'凡事预则立，不预则废'，没有事先的计划和准备，就不能获得战争的胜利。"
> — 《论持久战》(1938年5月)（已据原文核）

## I：核心解释

1. 执行力不是一个笼统的概念，而是三个独立维度的动态平衡：主动性（主动出击vs被动等待）、灵活性（适应变化vs死守计划）、计划性（提前准备vs临场反应）。
2. **主动性**：团队不是被动等指令，而是主动定义问题、寻找机会、发起行动。主动性的核心是"行动自由权"——失了主动就接近于被打败。
3. **灵活性**：遇到变化时不是死守原计划，而是根据新情况快速调整。灵活性体现在资源调配、方案切换、节奏调整上。
4. **计划性**：虽然有灵活性，但不是临时抱佛脚——事先有周密的准备和预案。计划性提供框架，灵活性在框架内运作。
5. 三者之间存在张力：
   - 太主动会打乱计划（个人英雄主义破坏团队节奏）
   - 太计划会压制主动（过度管理让团队变成执行机器）
   - 太灵活会变成无计划（每次调整都是临时决定）
   - 太不灵活会错过机会（死守计划无视变化）
6. 好的执行不是三者都强，而是三者动态平衡——"有计划的灵活"远胜于"无计划的灵活"或"无灵活的计划"。

## A1：来源应用

### 应用1：游击战争的三要素部署 (c16)
- **问题**：游击队在敌人包围中如何保持战斗力而不被消灭。
- **方法使用**：毛泽东要求游击队同时具备三要素——主动性（主动寻找战机、主动选择战场）、灵活性（分散/集中/转移三种部署灵活切换）、计划性（事先侦察敌情、规划转移路线、准备物资）。"巩固地向前发展"本身就包含三要素的平衡。
- **结论**：游击队如果缺主动性就变成被动挨打，缺灵活性就被敌人围歼，缺计划性就变成流寇。三者缺一不可。
- **结果**：敌后抗日根据地从零发展到最后控制一亿人口区域。

### 应用2：第一次反"围剿" — 三要素的完美配合 (c07)
- **问题**：面对国民党优势兵力围剿，如何以弱胜强。
- **方法使用**：主动性——主动选择战场和战机（不等敌人来决定在哪里打）；灵活性——两次想打谭道源不成果断撤回，等了25天找到张辉瓒再打；计划性——事先侦察敌情、部署兵力、规划歼灭方案。
- **结论**：三要素的完美配合：先有计划（兵力部署），执行中灵活调整（等了25天），始终掌握主动（选择自己的战场）。
- **结果**：一战歼灭张辉瓒部，取得第一次反"围剿"胜利。

## A2：典型触发场景

1. **OKR/目标总是完不成**：目标定得清楚但执行走样，季度末总是差一截。用户会说："目标没问题，就是执行不下去""每个季度都差那么一点"。
2. **计划赶不上变化**：市场环境变化太快，原计划总是被推翻，团队疲于奔命。用户会说："计划做了也白做""每次刚做完计划就变了""干脆不做计划了"。
3. **团队被动等指令**：没人主动发现问题、没人提出改进建议，所有人都在等领导安排。用户会说："推一下动一下""没人主动思考""只会执行不会思考"。
4. **灵活变成了混乱**：团队太"灵活"了，方向三天一变，执行没有章法。用户会说："每次灵活都变成临时决定""没有一天的执行是按计划走的"。

**语言信号**：用户提到"执行力""OKR完不成""计划赶不上变化""团队被动""太死板/太随意""灵活和计划的矛盾"等词汇时，应优先激活此skill。

**与相邻skill区分**：
- vs 战略-战术辩证法：本skill = "执行力的三维度平衡"，后者 = "攻守层级的策略设计"
- vs 十六字诀灵活策略：本skill = "执行力的系统性框架（三个维度）"，后者 = "竞争节奏的四个步骤"
- vs 集中优势兵力：本skill = "怎么执行好"，后者 = "资源怎么集中"

## E：执行步骤

### 步骤1：诊断三要素失衡点
- 用三要素检查清单逐一诊断：
  - 主动性：团队是主动发现问题并行动，还是等指令？有无"行动自由权"？
  - 灵活性：遇到变化时是快速调整还是死守原计划？调整后有无新的方向？
  - 计划性：有没有事先的周密准备？还是每次都是临时抱佛脚？
- **完成标准**：给三要素各打分（1-5分），识别出得分最低的那个要素作为优先修复项。常见失衡模式：
  - 低主动+高灵活+低计划 = "无头苍蝇"型（方向多变但不主动）
  - 高主动+低灵活+高计划 = "机械执行"型（按计划走但不适应变化）
  - 低主动+低灵活+高计划 = "官僚体制"型（有计划但死板）

🔴 **CHECKPOINT**：把三要素评分与最弱要素判断展示给用户确认，确认后再修复

**输入**：团队主动性/灵活性/计划性现状 → **输出**：三要素评分（1-5）与得分最低的优先修复项。

### 步骤2：修复最弱要素
- 主动性不足 → 建立机制：每周每人提出1个主动改进建议、设定"先做再报"的决策权限范围、鼓励小规模试错。
- 灵活性不足 → 建立"计划B"机制：每个重要计划都准备备选方案、设定"触发条件"（当X发生时切换到方案B）、缩短复盘周期（从月度到双周）。
- 计划性不足 → 建立"事前准备"习惯：每次行动前花30分钟做"侦察"（收集信息、预判风险）、建立标准化的行动模板。
- **判停点**：如果三个要素都很低，先从计划性开始修复——有计划才有框架，有框架才能谈主动和灵活。

🔴 **CHECKPOINT**：确认最弱要素已修复并有具体机制后，再进入步骤3建立动态平衡

**输入**：最弱要素判断 → **输出**：针对该要素的修复机制。

### 步骤3：建立动态平衡机制
- 设定三要素的"健康区间"——不是追求每个都是满分，而是维持最低分不低于3分，且三个分数的标准差不超过1。
- 每两周做一次"三要素快检"：主动性有没有提升？灵活性有没有过度？计划性有没有变成死板？
- **完成标准**：在团队工作流程中嵌入三要素检查——每次项目启动时检查计划性，每次周会检查主动性，每次遇到变化时检查灵活性。产出"三要素仪表盘"，让团队可视化当前状态。

**输入**：修复后的三要素状态 → **输出**：嵌入工作流的“三要素仪表盘”。


## B：边界与失败模式

### 不要使用的场景
1. **问题不在执行层面时**：如果战略方向就错了，执行力再强也没用——先回到矛盾分析法或调查研究法确定方向。
2. **团队极小时（1-3人）**：小团队的执行力问题通常是人的问题（能力或意愿），而非系统性问题，此框架过重。
3. **高度标准化的工作**：如果工作流程已经高度标准化（如工厂流水线），主动性和灵活性的空间有限，此框架不太适用。

### 失败模式（来自反例）
- **教条主义(ce01)**：计划性过高变成教条——计划变成了宗教，任何偏离都被视为错误。正确的计划性是"有框架的灵活"，不是"铁板一块的流程"。
- **盲动主义(ce10)**：主动性过强但没有计划支撑——"不顾主客观条件，犯着革命的急性病，不愿意艰苦地做细小严密的群众工作，只想大干"。没有计划的主动是蛮干。
- **极端民主化(ce17)**：灵活性变成议而不决——追求人人同意的决策模式，无限讨论消耗行动力。灵活不等于没有决断。

**失败模式速查（触发情况 → 具体表现 → 🛑 处理动作）**

| 触发情况 | 具体表现 | 🛑 处理动作 |
|---------|---------|-----------|
| 计划性过高的情况：计划变成宗教，任何偏离都算错（教条主义 ce01） | 团队不敢调整，遇到机会也按原计划走 | 回步骤2：改成「有框架的弹性」，保留调整空间；若两次评审都因偏离计划被否就不敢再调整，则先松开评审标准 |
| 主动性过强的问题：没有计划支撑，只想大干（盲动主义 ce10） | 事前侦察与行动模板缺位，失误率上升 | 回步骤2：先补计划性（事前侦察 + 行动模板）；若补了计划仍做不到，则用仪表盘把主动性拉回健康区间 |
| 弹性失控的失败：议而不决，无限讨论消耗行动力（极端民主化 ce17） | 每次调整都要人人同意，决策迟迟不出 | 回步骤2：设定决断机制，弹性不等于没有决断；若讨论三轮仍不决，则由责任人直接拍板 |
| 只维护仪表盘的情况：只维护「三要素仪表盘」而不落到具体行动（指标代替执行） | 分数好看，执行没变 | 每次复检都要带出一件具体动作；若复检连续两次没有动作产出，就暂停仪表盘先把一件事做完 |
| 三要素都低的情况：团队既被动又死板又无准备 | 找不到单一发力点 | 从计划性起步——先有框架才能谈主动与灵活；若计划性补起来后仍不见起色，就依次补主动、灵活 |

### 作者盲点
- 毛泽东对三要素的论述主要面向军事指挥员（个体层面），对如何在组织中系统性地构建这三要素（制度层面）论述较少。商业启示：需要通过组织设计（激励机制、决策流程、信息流转）来系统性地培养三要素，而不能仅靠个人觉悟。

## 📖 练习手册

给你的团队三要素打分做三遍：① 主动性/灵活性/计划性各打 1-5 分；② 找出最低分要素，写一条针对它的修复机制；③ 设一个"三要素仪表盘"，并约定复检节奏（补充）。下次项目启动时，先看一眼仪表盘再开工。

## 灰色地带

- **三要素都低**：从"计划性"起步——先有框架才能谈主动与灵活（补充）。
- **"灵活"与"混乱"难分**：以有无决断机制区分——灵活是换方案后仍有方向，混乱是反复无常。
- **个人 vs 组织**：小团队有时是人的问题，框架过重；先判断是否属系统性问题再套用。
