## 🚀 使用方式

每个 skill 目录内含 `SKILL.md`（通用 markdown skill 格式：`name` + `description` 必备，其余字段读不懂可忽略）。**装完先把依赖装齐**（一律走国内源，官方 pypi.org 在本环境拉不动）：

```
python tools/install_deps.py            # 体检
python tools/install_deps.py --install  # 缺什么装什么（清华源 → 阿里云备选）
```

把 `skills/` 下的目录按**你所用的 agent 的 skill 放置约定**放进去即可——不依赖任何特定的 agent、模型、工具或版本。

## 🧩 怎么扩展

**加一个维度**（一条命令）：

```
python tools/new_dimension.py --prefix <前缀本体，如 ptolemy> --name <维度名> --layer <观察|象征|校准> \
    --signals "<触发信号>" --source "<来源>" --skill <入口skill名> --emoji 🧩
```

它照 `templates/skill-template/` 建好 skill 骨架 → 在 `dimensions.registry.md` 加一行 → 在 hub 的概览表与 H 节补齐 → 同步描述行的层计数 → 跑 `tools/dim_check.py` 自检。**hub 正文不用改**，加多少维都一样。

**往已有维度加 skill**：新目录放进 `skills/`，注册表该维度「skill 数」+1，hub 的 H 节补一行，再跑自检。

**加一个元工具**（如又装了个新工具型 skill）：目录放进 `skills/`，注册表「元工具」表加一行，再跑自检。

**蒸馏数量不预设**：一本书蒸几个 skill，由书的内容结构决定（见 `docs/扩展手册.md`）。

**改完必跑**：

```
python tools/dim_check.py      # 0 错才算完
```

完整流程（含「从一本新书蒸馏」的六步流水线）：见 **`docs/扩展手册.md`**。
